**SSSS — шарнирное опирание.** На каждом крае прогиб равен нулю и изгибающий момент, действующий на край, равен нулю:
край не смещается, но может свободно поворачиваться. Для края x = a: w = 0 и ∂²w/∂x² + ν·∂²w/∂y² = 0, что при w = 0
вдоль края равносильно Δw = 0.

**CCCC — жёсткая заделка.** На каждом крае равны нулю прогиб и угол поворота: w = 0 и ∂w/∂n = 0 (n — нормаль к краю).

**Статус.** Для SSSS при N = 1 используется принятый решатель R3; при N = 2–3 результаты PROVISIONAL / NOT_QUALIFIED,
при N = 4–6 — только исследование. Для CCCC все режимы N = 1–6 — исследовательские: RESEARCH_ONLY / PROVISIONAL /
NOT_QUALIFIED. Все защиты решателя CCCC действуют: при отказе проверки расчёт останавливается, а поле последнего
полушага показывается только как диагностика.

Решение Навье, с которым сравнивается SSSS, к CCCC не относится. Для CCCC используются сохранённые эталоны только при
точном совпадении входных данных.
