1. **Главная** — новый расчёт, открытие проекта или результатов, состояние программы.
2. **Настройка расчёта** — все параметры на одной странице; справа — схема пластины.
3. **Ход расчёта** — итерации, журнал событий и итог расчёта.
4. **Анализ результатов** открывается кнопкой в отдельном окне.

Кнопка «Выполнить расчёт» запускает решатель KK-VIM в отдельном процессе: N = 1 — принятый решатель R3, N = 2–3 — исследовательский решатель R4 (PROVISIONAL / NOT_QUALIFIED). Демонстрационный режим без решателя включается только параметром `--demo`; его данные помечены **TEST DATA**.
