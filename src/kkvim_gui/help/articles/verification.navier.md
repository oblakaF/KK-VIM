**Что это.** Решение Навье — двойной ряд синусов для прямоугольной шарнирно опёртой пластины под равномерной
нагрузкой (классическая теория Кирхгофа–Лява). Программа суммирует ряд до M = 2559 по каждому индексу в точке
(a/2, b/2); это квалифицированный эталон прогиба решателя R3, область 0,2 ≤ b/a ≤ 5. Моменты не сравниваются.

**Как считается.** Эталон вычисляется отдельной программой в отдельном процессе по входным данным a, b, h, E, ν, q —
без КК-ВИМ и без его поля. Пока он считается, вкладка сообщает об этом. Если входные данные вне области эталона или
расчёт эталона не удался, называется причина; значение не подставляется.

**Что показывается.** Прогиб в центре КК-ВИМ и Навье, разность Δw в m и mm, β обоих решений и Δβ/β в процентах,
уровень ряда M и оценка остатка ряда.

**Как понимать.** Навье — точное решение непрерывной задачи; КК-ВИМ решает дискретную задачу на сетке, поэтому
разность включает сеточную погрешность. Это наблюдение, а не оценка точности метода; утверждённого порога согласия нет.
Для SSSS N = 2–6 сравнение — справочные данные: статус PROVISIONAL / RESEARCH_ONLY не меняется. Для CCCC решение
Навье не применяется.
