Вкладка «Итерации» окна анализа показывает, как менялось поле прогиба от полушага к полушагу (ε^∞ и ε^E в
логарифмическом масштабе, с линиями допусков для SSSS N = 1). Полная таблица всех величин каждого полушага открывается
кнопкой «Подробная таблица». Вкладка «Диагностика» показывает дискретную энергию Π_h по полушагам, невязку, параметры
решателя и ограничения маршрута.

Правило остановки SSSS N = 1: CONVERGED (только SSSS, N = 1) — при s ≥ s_min, когда на двух полушагах подряд (s − 1 и s) одновременно ε^∞ ≤ tol_∞ и ε^E ≤ tol_E (NUMERICAL_SPEC.md, разд. 11.3). Одного малого изменения на одном полушаге или выполнения только одного
допуска недостаточно, и до s_min остановки нет.

Малое изменение поля само по себе не доказывает сходимость последовательности: это наблюдение на конечной сетке.
