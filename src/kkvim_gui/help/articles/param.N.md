Метод КК-ВИМ ищет прогиб в виде суммы N произведений функций одной переменной. При N = 1 это одно произведение
w = X(x)·Y(y); при N = 2–6 — сумма двух–шести таких произведений. Число итераций (полушагов s) и число значений
нагрузки в серии задаются отдельно и с N не связаны.

**Статус расчёта зависит от закрепления и N** (он показан под списком N):

- SSSS, N = 1 — принятый решатель R3 в утверждённой области (0,2 ≤ b/a ≤ 5);
- SSSS, N = 2–3 — PROVISIONAL / NOT_QUALIFIED;
- SSSS, N = 4–6 — RESEARCH_ONLY / PROVISIONAL / NOT_QUALIFIED; расчёт выполняется только при явно включённом
  исследовательском режиме;
- CCCC, N = 1–6 — RESEARCH_ONLY / PROVISIONAL / NOT_QUALIFIED.

Больший N сам по себе не делает результат квалифицированным. При смене N все исследовательские настройки
сбрасываются, чтобы исследовательский расчёт не запустился незаметно.
