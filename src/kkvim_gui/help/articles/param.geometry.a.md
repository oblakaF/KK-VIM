Начало координат — в углу пластины: ось x направлена вдоль стороны a, ось y — вдоль стороны b. Пластина занимает
0 ≤ x ≤ a, 0 ≤ y ≤ b; её центр — точка (a/2, b/2).

Сторона a — опорная длина безразмерного прогиба w̄ = w·D/(q·a⁴). Решатель проверяет отношение сторон: допустимо
0,2 ≤ b/a ≤ 5; у исследовательских режимов область может быть уже — тогда расчёт не запускается и называется причина.
