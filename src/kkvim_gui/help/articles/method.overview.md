**Представление решения.** Решение ищется в виде суммы N произведений функций одной переменной
ω_N(x, y) = Σ uᵢ(x)·vᵢ(y), i = 1…N; при N членах это N-е приближение, первое приближение — ω₁ = u(x)·v(y) (авторы:
P81, с. 366, ур. (2); с. 367, Definition 2).

**Шаги.** Задаётся система N функций одной переменной, например u₁⁰(x), …, u_N⁰(x). Из первых N уравнений системы
вариационных условий находятся функции v₁¹(y), …, v_N¹(y); они подставляются в остальные N уравнений, и находится новый
набор функций x: u₁²(x), …, u_N²(x); затем по нему — v₁³(y), …, и так далее. Вычисление одной системы функций по другой
авторы называют одним шагом МВИ (P81, с. 367, Definition 1). В программе это полушаг s; k = ⌊s/2⌋ — число завершённых
циклов (соглашение проекта).

**Вариационные условия.** Функции каждого шага определяются условиями ортогональности невязки уравнения функциям
заданной переменной (P81, с. 367, ур. (3), (4)); в работе P82 то же записано как ортогональное проектирование на
множество функций с заданной частью (P82, с. 78–79, ур. (3), (4)). Начальную систему можно задать по любой из
переменных (P82, с. 78). Авторы отмечают, что при k = 0 МВИ совпадает с методом Власова—Канторовича (P82, с. 80);
по нумерации проекта (вывод проекта, не формулировка авторов) это первый полушаг s = 1.

**Что авторское, а что — проекта.** Представление решения, порядок шагов и вариационные условия напечатаны авторами.
Одномерные краевые задачи шагов решаются в программе методом конечных разностей; разностные операторы, правила
остановки итераций, защиты и численная линейная алгебра — дискретизация и инженерная реализация проекта, проверенные
отдельно, а не часть публикаций. Линейного контрольного примера SSSS в первоисточниках нет; контрольный случай авторов —
защемлённая пластина (CCCC). Расчёт SSSS — проверочная постановка проекта.

**Не путать.** КК-ВИМ — не He's Variational Iteration Method (Ji-Huan He): это другой метод, несмотря на сходство
названия. Связь КК-ВИМ с методом Канторовича–Власова и расширенным методом Канторовича (Kerr) в общем случае
не утверждается: она остаётся предметом проверки по публикациям.

Изображения страниц первоисточников в программу не входят: публикации хранятся только локально (правило проекта).
