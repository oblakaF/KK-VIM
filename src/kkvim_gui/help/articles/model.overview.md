Все размерные величины вводятся в единицах СИ с международными обозначениями (`m`, `mm`, `kPa`, `GPa`). Выбор языка не меняет единицы и числа.

Перед расчётом значения переводятся в m и Pa; исходный текст и единица сохраняются в протоколе. Научные проверки ввода (|ν| < 1, 0,2 ≤ b/a ≤ 5, размер сетки) выполняет сам решатель KK-VIM.

Параметры метода зависят от N: для N = 1 — допуски и пределы остановки R3; для N = 2–3 — режим R4, путь DST и число полушагов (допуски R4 фиксированы решением D-048).
