# R4, N = 2–3: воспроизведение результатов `docs/R4_N23_SCIENTIFIC_CLOSURE.md`

Роль: Literature. Это исследовательский код: он не входит в решатель и не является эталоном проекта.
- Пакеты `kkvim` и `kkvim_reference` **не импортируются**; от рабочего решателя результаты не зависят.
- Сертификаты ранга (N23-2…N23-4, N23-8) вычисляются по замкнутым формулам цели.
- Числа табл. 4.5 (N23-6, N23-7) получены той же независимой рекурсией Парсеваля, что `scripts/r4_q022/q022_table.py`. Алгоритм, усечение
  и старт не менялись; изменена только формула оценки.

## Зависимости

- Окружение проекта по `uv.lock`; эталонные выходы получены на Windows 10, Python 3.14.8, NumPy 2.5.4.
- Сертификату нужен `mpmath` (1.4.1). Он подключается только временно — `uv run --with mpmath` — и в зависимости проекта не входит.
- Единицы: a = 1, b = r, q = D = 1. Все выводимые отношения от масштаба не зависят.

## Что проверяет сертификат

Сертификат проверяет неравенство μ = (E₂^{up}/D^{low}_{N−1})^{1/2} < 1 (теорема N23-4), где:
- **E₂^{up}** — верхняя граница err(N, 2)² (N23-2):
  - пробные векторы t берутся из МНК в double — допустим любой t;
  - невязки вычисляются в интервальной арифметике;
  - для задачи (а) добавляются строгие хвосты по строкам и столбцам (разд. 3.1 документа);
- **D^{low}_{N−1}** — нижняя граница d²_{N−1} (N23-3):
  - три хвоста Мирского на подматрице 12 × 12;
  - каждое собственное число подтверждается законом инерции: в интервальном LDLᵀ матрицы S − tI нужное число пивотов строго
    положительно, и ни один интервал не содержит нуль.

Вывод `CERTIFIED` относится только к указанной ячейке. Корректность направленного округления mpmath.iv — инженерная предпосылка.

## Сравнение с эталоном

- Интервальные выходы детерминированы при фиксированной точности (`iv.prec = 256`).
- В выходе double (`n23_transfer_sharp.py`) возможны отличия в последних битах между платформами (AGENTS.md, разд. 4).
- Целые s_max на границе правила 1/100 — пограничные случаи: их нужно разбирать, а не маскировать допуском.
- Колонка `old` в `transfer_*.txt` должна совпадать с `scripts/r4_q022/expected/table_*.txt` во всех 60 значениях (N = 2, 3) — регрессия.
