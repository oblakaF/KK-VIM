## Зависимости

Окружение проекта по `uv.lock`: Python 3.13 или 3.14, NumPy (эталонные выходы получены на Python 3.14.8, NumPy 2.5.4, Windows 10).
SciPy и mpmath не нужны. Единицы: a = 1, b = r, q = D = 1; усечение — нечётные индексы ≤ M по обеим осям; старт — нечётные синусы; QR заданного набора.

Параметры командной строки: `q022_production.py M S r1,r2,…`; `q022_table.py M S` (десять контрольных r фиксированы в скрипте);

**Тесты.** Быстрые (входят в общий `pytest`, CI; validate, observed, короткая таблица, проверка «разность ≤ оценка»):

    uv run python -m pytest -q tests/cross/test_r4_q022_reproducibility.py

Тяжёлые (M = 4001; сравнение с `expected/*_M4001.txt`):

    KKVIM_Q022_HEAVY=1 uv run python -m pytest -q tests/cross/test_r4_q022_reproducibility.py      # bash
    $env:KKVIM_Q022_HEAVY = "1"; uv run python -m pytest -q tests/cross/test_r4_q022_reproducibility.py   # PowerShell

Сравнение с эталоном — по числам с допуском в одну единицу последнего выведенного знака; целые (s_max, номер полушага) и `inf`/`None` — точно.
Побитового равенства не требуется (AGENTS.md, разд. 4). Целые s_max — пороговые решения: если на другой платформе значение у самой границы 1/100
изменится, это пограничный случай, который надо разобрать, а не маскировать допуском.

## Что именно вычисляется — четыре категории (не смешивать)

| Категория | Где | Статус |
|---|---|---|
| 1. **Аналитически доказанные границы** — рекуррентность Q22-5, следствия Q22-6 (центр через Γ(c)E_s, err_abs, e_rel) | `docs/R4_Q022_ERROR_TRANSFER.md`, разд. 4–6 | доказательства в документе; независимая проверка Reviewer **ещё не выполнена** |
| 2. **Вычисление этих границ в double** — `bound()` в `q022_transfer.py`; столбцы `E/|w0|a`, `E/err_abs`, `centre: bound/w0c`, `g_s` в `production`; `s_max` в `table` | разд. 7.2, 7.3 | формулы строгие, вычисление — в double без интервальной арифметики; округление массивов рекурсии (σ_N, d′_s, err) в оценку **не входит** |
| 3. **Фактическая разность двух конечных последовательностей** — `obs` в режиме `validate`, `E_obs/T` в `observed` | разд. 7.1, 7.4 | точная разность двух конечных вычислений (до округления double); «истинная» цель конечна (ω_{1601}), не ω₀ |
| 4. **Гипотеза Г-1** (нерастяжение по цели) | разд. 8, п. 4 | **не проверяется и не утверждается** тестами; категория 3 даёт только наблюдения, согласующиеся с ней |

Быстрый тест `test_actual_difference_never_exceeds_the_bound` проверяет **следствие** теоремы (категория 3 ≤ категория 2) на малых точно
вычислимых случаях (M1 = 21, M2 = 201, s ≤ 8); доказательством он не является.

## Ограничения

- Строгость оценок (категория 1): рецензия Reviewer `d73f497` — математическое ядро корректно; обозначения λ и формулировка оценки Ê_s исправлены
  в документе (`docs/R4_Q022_ERROR_TRANSFER.md`, разд. 12); пути скриптов в его разд. 7 указывают на `scripts/r4_q022/`.
- Граница хвоста T берётся по оценке QA 0 ≤ S − S_M ≤ (a⁴ + b⁴)π²/(80M⁵) (нечётное M; проверена рецензией `3aaca8e`, разд. 6).
- Константа Γ(c) для центра — сумма по блоку плюс строгая оценка остатка; ω₀(c) в относительных величинах — сумма Навье по блоку (масштаб, не бюджет).
- Отношения сторон: только r ∈ {1, 1/5, 5} (разд. 7.1, 7.2, 7.4) и десять контрольных r (7.3). Обобщение на интервалы r не утверждается.
