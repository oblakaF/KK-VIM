## Команды полного воспроизведения

Из корня репозитория (Python 3.13, окружение `uv.lock`):

```
uv sync --locked
uv run --no-sync python scripts/r3_r7/reproduce.py --workdir <временный каталог вне репозитория>
```

Без `--workdir` каталог создаётся через `tempfile.mkdtemp`. Драйвер:
1. сверяет SHA256 исходных файлов с `metadata.json` (при несовпадении останавливается);
2. копирует их в `<workdir>/scratch/r7/`;
3. запускает с `cwd = <workdir>` по порядку: `calibrate.py` (калибровка на принятом R2: `kkvim.iteration.run_halfsteps`,
   `kkvim.energy.check_history`, только запуск), `margins.py` (заместитель и запасы для R3), `summarize.py`, `extra.py` (сводки),
   `selfcheck.py` (сверка формул с `kkvim.energy`), `export.py` (CSV и `metadata.json` в `<workdir>/docs/results/r3/r7/`); журналы — `<workdir>/logs/`;
4. сравнивает `calibration_r1.csv`, `margins.csv` с сохранёнными — сначала побайтно, при расхождении численно, с проверкой текстовых
   столбцов (категории, флаги); сравнивает `metadata.json`; пишет `<workdir>/reproduction_report.json`.

Время выполнения — около 2–3 минут (основная часть — `margins.py`).

Ручной запуск без драйвера: скопировать восемь исходных файлов в `<dir>/scratch/r7/` и из `<dir>` выполнить
`python scratch/r7/<скрипт>` в том же порядке интерпретатором окружения проекта (`kkvim`, `kkvim_reference` установлены в нём).

## Результат воспроизведения (2026-10-14)

- `calibration_r1.csv` и `margins.csv` — **совпадают побайтно** с `docs/results/r3/r7/`.
- 2178 пар сеток; 6534 строки (s = 2, 3, 4); категории: MANDATORY_CANDIDATE 3150, RESOLVABLE_NO_HEADROOM 558, BORDERLINE 7,
  EXPECTED_UNRESOLVED 641, DIAGNOSTIC_S4 2178 — классификация и области обязательной разрешимости не изменились.
- Воспроизведение R2 — в `calibration_r1.csv` (дискретные Q и запасы шага 7 R2 при a = D = q = 1).
- `metadata.json` отличается двумя полями: `date_utc` (время повторного запуска) и `base_commit` (пусто: `export.py` вызывает
  `git rev-parse HEAD` во временном каталоге, который не является git-репозиторием). Сведения о повторном запуске добавлены в
  `docs/results/r3/r7/metadata.json` (`versioned_scripts`, `reproduction`); исходные поля исследования не изменены.

## Ограничения

- Побайтное совпадение получено на той же машине и в том же окружении (Windows, Python 3.13.15, NumPy 2.5.4). На другой платформе или
  с другой библиотекой BLAS возможны различия в последних разрядах (матричные произведения в `surrogate.py`); тогда сравнение
  `reproduce.py` переходит к численному и показывает относительные расхождения по столбцам. Новые допуски для такого сравнения не вводятся.
- `export.py` при повторном запуске перезаписывает `metadata.json` во временном каталоге без разделов `versioned_scripts` и `reproduction`.
