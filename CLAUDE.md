# CLAUDE.md

Общие обязательные правила проекта находятся в [AGENTS.md](AGENTS.md). Этот файл их не заменяет.

Перед работой:

- прочитать [AGENTS.md](AGENTS.md), [docs/PROJECT_GOALS.md](docs/PROJECT_GOALS.md)
  и [docs/DECISIONS.md](docs/DECISIONS.md);
- если есть, прочитать `docs/STATUS.md` и документ текущей задачи.

В работе:

- в начале ответа кратко назвать цель (ID G…) и текущий шаг;
- выполнять только назначенную задачу;
- до утверждения математической спецификации не реализовывать численный решатель;
- если не хватает научного основания, записать вопрос, а не достраивать метод самостоятельно.

Чтение инструкций не гарантирует отсутствия ошибок. Результат подтверждается проверками,
предусмотренными задачей.
