# CLAUDE.md

Общие обязательные правила проекта — в [AGENTS.md](AGENTS.md); они импортированы строкой выше.
Этот файл их не заменяет и не ослабляет. При расхождении действует AGENTS.md.

Перед работой обязательно прочитать (порядок — AGENTS.md, раздел 1):

- [AGENTS.md](AGENTS.md);
- [docs/PROJECT_GOALS.md](docs/PROJECT_GOALS.md);
- [docs/DECISIONS.md](docs/DECISIONS.md);
- [docs/STATUS.md](docs/STATUS.md);
- постановку текущей задачи, выданной пользователем.

Дополнительно для Claude:

- в начале ответа кратко назвать цель (ID G…) и текущий шаг;
- численный решатель не реализуется до утверждения математической спецификации и явного
  разрешения владельца (AGENTS.md, раздел 3; ROADMAP.md);
- если не хватает научного основания, вопрос записывается в `docs/OPEN_QUESTIONS.md`,
  метод не достраивается самостоятельно.

Чтение инструкций не гарантирует отсутствия ошибок. Результат подтверждается проверками,
предусмотренными задачей.
