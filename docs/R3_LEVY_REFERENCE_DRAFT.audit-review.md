## 1. ЧВ-Л1 — устойчивая форма скобки T_m

**Проверено: верно.**

Формула L-107 (139): T = 1 − (α th α + 2)/(2 ch α)·ch(αt) + α/(2 ch α)·t sh(αt), t = 2η/b ∈ [−1, 1]. Её чётность по t даёт запись через |t| = 1 − s.
Обозначения: z = αs, g = e^{−2α}, E = e^{−α(2−s)}.

1. ch(α|t|)/ch α = (e^{−αs} + E)/(1 + g) и |t| sh(α|t|)/ch α = (1 − s)(e^{−αs} − E)/(1 + g) — деление числителя и знаменателя на e^{α}; верно.
2. Шаг 1 документа. Коэффициент при e^{−αs}: α th α + 2 − α(1 − s) = 2 + αs − 2αg/(1 + g), так как α th α = α − 2αg/(1 + g). Коэффициент
   при E: α th α + 2 + α(1 − s) = 2 + α(1 + th α − s). Верно.
3. Шаг 2: 1 + th α = 2/(1 + g). Отсюда (1 + g)T = (1 + g) − e^{−αs}(1 + αs/2) + αg e^{−αs}/(1 + g) − E[1 + α/(1 + g) − αs/2]. Верно.
4. Шаг 3: g = E·e^{−αs}, поэтому g − E = E·expm1(−z) и αg e^{−αs}/(1 + g) − αE/(1 + g) = αE·expm1(−2z)/(1 + g). Остаток
   1 − e^{−z} − (z/2)e^{−z} = f(z). Итоговая формула документа и функции `_bracket` получена. Верно.

Численный контроль: устойчивая форма против исходной (139) — относительная разность ≤ 2·10⁻³⁶ при 3000 случайных
α ∈ [10⁻³; 316], s ∈ [0, 1] (50 знаков). На краю s = 0 обе части равны 0 точно, это видно по формуле.

**Утверждения об обусловленности** — тоже проверены аналитически:
- f(z) ≥ (z/2)e^{−z} ≥ 0, так как 1 − e^{−z} ≥ z e^{−z} ⇔ e^z − 1 ≥ z. Вычитаемое не больше половины уменьшаемого, отсюда
  обусловленность ≤ 3 — верно.
- N = (1 − e^{−z}) + α(1 − e^{−2z})/(1 + g) ≥ z th α: (1 − e^{−2z})/z убывает по z, и z ≤ α. Отсюда при α ≥ π/2 (что выполнено при r_L ≥ 1)
  обусловленность N − z/2 ≤ 3,4 — верно.
- Обусловленность суммы f + E[…] не доказана — документ честно помечает её [НАБЛЮДЕНИЕ].

## 2. ЧВ-Л3 — лемма о скобке

**Проверено: верно для всех α > 0.** K := 1 − T = [(α th α + 2) ch(αt) − αt sh(αt)]/(2 ch α), K чётна.

| Шаг | Проверка |
|---|---|
| K(0) = P = (α th α + 2)/(2 ch α) > 0; K(1) = [(α th α + 2) ch α − α sh α]/(2 ch α) = 1 | верно |
| K′(t) = α·h(t)/(2 ch α), h(t) = (α th α + 1) sh(αt) − αt ch(αt) | верно (производная пересчитана) |
| h(0) = 0, h′(t) = α²u(t), u(t) = th α·ch(αt) − t sh(αt) | верно |
| u(1) = th α ch α − sh α = 0 | верно |
| u′(t) = sh(αt)·β(t), β(t) = α th α − 1 − αt·cth(αt) при t > 0 | верно |
| x cth x строго возрастает при x > 0: (x cth x)′ = (sh x ch x − x)/sh² x > 0 | верно ⇒ β строго убывает |
| β(1) = α th α − 1 − α cth α < 0, так как th α < cth α | верно |

Заключение леммы:
- β меняет знак не более одного раза (с + на −), и sh(αt) > 0, поэтому u либо убывает на (0, 1], либо сначала возрастает, затем убывает.
- В обоих случаях u > 0 на [0, 1): на участке возрастания u ≥ u(0) = th α > 0, на участке убывания u > u(1) = 0.
- Отсюда h > 0 и K′ > 0 на (0, 1]: K строго возрастает от P до 1.
- Итог: 0 ≤ T ≤ 1 − P < 1; T(±1) = 0; T убывает по |t|, то есть по расстоянию от средней линии. Всё это верно.

Неблокирующее замечание Н-1: в доказательстве явно не сказано, что u(0) = th α > 0. Это нужно в случае β(0+) = α th α − 2 > 0 (α ≳ 2,07),
когда u сначала возрастает. Утверждение верно, шаг стоит дописать.

Численный контроль: на сетке из 110 значений α ∈ [10⁻³; 316] × 201 значения t нарушений 0 ≤ T ≤ 1 − P, T(1) = 0 и монотонности нет.

## 3. ЧВ-Л4 — равномерная оценка поля

**Проверено: верно.**
- **Переход к равномерной оценке.** w − w_M = (4qa_L⁴/(π⁵D))Σ_{m ≥ M+2, нечёт} m⁻⁵ T_m(t) sin(mπx_L/a_L). По ЧВ-Л3 0 ≤ T_m ≤ 1 при каждом
  α_m > 0, и |sin| ≤ 1. Отсюда |w − w_M| ≤ (4|q|a_L⁴/(π⁵D))Σ_{m ≥ M+2, нечёт} m⁻⁵ в каждой точке.
- **Интегральное сравнение.** x⁻⁵ убывает, поэтому для нечётного m ≥ M + 2: m⁻⁵ ≤ ½∫_{m−2}^{m}x⁻⁵dx. Отрезки [m − 2, m] покрывают [M, ∞)
  без наложений. Отсюда Σ ≤ ½∫_M^∞x⁻⁵dx = 1/(8M⁴). Верно.
- **Формула.** (4/π⁵)/(8M⁴) = 1,63388·10⁻³/M⁴. Для LEVY_FIELD_TOL = 10⁻¹⁵ требуется M ≥ 1130,59, наименьшее нечётное — 1131. Верно.
- **Замкнутая пластина, включая края.** Лемма верна при t = ±1 (там T = 0); при x_L = 0, a_L sin = 0. Оценка действует во всех точках
  [0, a] × [0, b], сходимость равномерная и абсолютная (признак Вейерштрасса). Верно.
- **Единицы.** Оценка — в q·a_L⁴/D, так как ряд (139) записан в системе Леви с a_L. Проверено в коде: `levy_field_bounds` умножает её на
  |q|·a_L⁴/D и возвращает в единицах физического прогиба.

Численный контроль (точки x = k/(10M), k = 1…11, и x = ½; s = 1; 0,3; 0,01): фактический хвост ≤ 0,58 (M = 9) и ≤ 0,81 (M = 39) от оценки
при r_L = 1 и 5. Наблюдение документа о достижении оценки у краёв x_L ≈ 0,4/M с этим согласуется.

## 4. ЧВ-Л2 — хвост центра по (140)

**Проверено: верно при любом r_L > 0, в частности при 1 ≤ r_L ≤ 5.**
- **Оценка P_m.** 0 < P_m = (α th α + 2)/(2 ch α) < (α + 2)e^{−α}, так как th α < 1 и 2 ch α > e^α. Неравенство строгое.
- **Отношение соседних членов.** α_m = cm, c = πr_L/2. Неравенство (c(m + 2) + 2)/(cm + 2) ≤ (m + 2)/m равносильно 0 ≤ 4. Отсюда
  τ_{m+2}/τ_m ≤ (m/(m + 2))⁵·((m + 2)/m)·e^{−2c} = (m/(m + 2))⁴·e^{−πr_L} ≤ ρ = e^{−πr_L}. Верно.
- **Геометрическая сумма.** |R_c(M)| ≤ (4/π⁵)Σ_k τ_{M+2+2k} ≤ (4/π⁵)τ_{M+2}/(1 − e^{−πr_L}). Знакопеременность не используется. Верно.
- **Применимость при 1 ≤ r_L ≤ 5.** ρ ≤ e^{−π} = 0,0432, множитель 1/(1 − ρ) ≤ 1,045. Оценка — для формы (140), где полоска 5/384 вычтена в
  замкнутом виде.

Численный контроль (полный хвост, 50 знаков): отношение хвоста к оценке — 0,93–0,95 при r_L = 1, 0,98–0,99 при r_L = 1,4, 0,997–0,998
при r_L = 2, ≈ 1 − 10⁻⁵…10⁻⁷ при r_L = 5 (M = 1, 3, 9, 17). Плотность совпадает с указанной в документе (r_L = 1, M = 1: 3,227·10⁻⁶
против 3,390·10⁻⁶).

## 5. Почему экспоненциальная граница центра не переносится на поле (разд. 5.4)

**Аргументация верна; одна часть — асимптотический довод с наблюдением, а не теорема.**
- **Центр.** Экспоненциальность (140) возникает, потому что полоска выделена точно (5/384), а остаётся ряд с P_m ≤ (α_m + 2)e^{−α_m}. Это
  ЧВ-Л2, строго.
- **Поле (139).** Коэффициент при sin(mπx_L/a_L) на линии η равен m⁻⁵T_m(η). При фиксированной внутренней η K_m = 1 − T_m ≤ (α_m + 2)e^{−α_m s}
  → 0, то есть T_m → 1 и коэффициенты убывают как m⁻⁵, а не экспоненциально.
  - Неравенство K ≤ (α + 2)e^{−αs} проверено: ch(α|t|)/ch α ≤ 2e^{−αs}, а член с sh неотрицателен и вычитается. Нарушений при 2000
    случайных (α, s) нет.
- **Форма с выделенной полоской.** Экспоненциальна при фиксированном s > 0, но при s → 0 поправки K_m → 1 и не малы. Укороченный ряд
  на краях η = ±b_L/2 не обнуляется: остаток равен хвосту синус-ряда полоски.
- **«Ни одна форма не даёт лучше O(M⁻⁴) равномерно».** Это утверждение о достижимости. Оно подкреплено асимптотикой: хвост Σ_{m>M}m⁻⁵ sin(mπx)
  при x ~ 1/M имеет порядок M⁻⁴. Есть и наблюдение: отношение «факт/оценка» ≈ 0,9 у краёв x_L ≈ 0,4/M, у меня 0,81 при M = 39. Формального
  доказательства нижней границы в документе нет; это не требуется — достаточно верхней оценки ЧВ-Л4 (Н-3).
- **Согласованность с L-107 (вопрос А-5).** Утверждение L-107 о быстрой сходимости относится к ряду (140) в центре и к соглашению b ≥ a
  (сноска 2, с. 136; сверка транскрипции, разд. 6). С разд. 5.4 оно не противоречит.

## 6. Перевод оценок от a_L к исходной стороне a

**Проверено: верно.**

- Код:
  - `levy_field_bounds`, `levy_centre_bounds` умножают на |q|·a_L⁴/D;
  - `levy_centre_wbar` умножает (140) на a_L⁴ при a = 1, то есть на r⁴ при r < 1;
  - docstring `levy_field_tail_bound` указывает множитель (a_L/a)⁴. В docstring `levy_centre_tail_bound` такого указания нет — Н-4.
- r_L = b_L/a_L вычисляется в float после точной рациональной проверки. Из max(a, b) ≤ 5·min(a, b) и монотонности округления следует
  1 ≤ r_L ≤ 5 — верно. При b < a значение r_L = 1/r округлено (например, 3,0000000000000004 при r = 1/3); оценки усечения справедливы
  при любом r_L > 0, ошибка представления r_L относится к модели округления.
