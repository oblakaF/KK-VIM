### Р-3. Стартовое подпространство 𝒯_N и ориентация для N = 2–3

**Статус:** PROPOSED. *Обновление 2026-10-21: **ПРИНЯТО — D-049.3**.*

**Суть.** Старт 𝒯_N = span{sin²(iπx/a), i = 1…N}, вычислительный базис sin²(iπx/a), старт по x. Перестановка r ↔ 1/r даёт другую
последовательность, поэтому ориентация фиксируется.

**Основания:**

- CM ВБC-15: два кандидата NS 4.5 — базисы одного 𝒯_N (теперь отмечено в NS 4.5, УФ-3);
- CM ВБC-17: допустимость, симметрия, нагрузки, обусловленность;
- CM ВБC-13, п. 4: дискретная независимость ⇔ N ≤ ⌊nₓ/2⌋;
- `87a15ab`, разд. 3.1 (PASS) и 6, п. 2: «принять, ориентацию фиксировать в протоколе».

**Ограничения:**

- x-оболочка 𝒯_N совпадает с одномерным базисом эталона B (ОВ-М7). Сравнения с B — только при M → ∞ по обеим переменным (QA-M9);
- полный ранг первого полушага доказан только для N = 2 в непрерывной задаче (ВБC-19); N = 3 и дискретно — UNRESOLVED (Р-5);
- nₓ ≥ 8N — инженерное предложение CM, не принятое требование. Доказанные условия: независимость — N ≤ ⌊nₓ/2⌋ (ВБC-13, п. 4);
  точные дискретные формулы коэффициентов — при 2N < nₓ (ВБC-13, п. 3).

**Блокирует:** фиксацию спецификации N = 2–3; ST-1…ST-10 (PL §3).

**Проект формулировки.**
> D-NNN, п. 3. Для КК-МВИ CCCC, N = 2–3, стартовое подпространство — 𝒯_N = span{sin²(iπx/a), i = 1…N}, вычислительный базис sin²(iπx/a),
> первый полушаг — по y при заданных функциях от x. Ориентация записывается в протокол каждого расчёта. Совпадение x-оболочки с базисом
> эталона B учитывается в сравнениях (QA-M9).

### Р-5. Исследовательский режим N = 2–3 при недоказанном дискретном ранге

**Статус:** PROPOSED. *Обновление 2026-10-21: **ПРИНЯТО — D-049.5** (принцип; программирование не разрешено).*

**Суть.** Разрешить исследовательскую реализацию N = 2–3 CCCC без теоремы о дискретном ранге, при следующих условиях:
