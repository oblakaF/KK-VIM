## 3. 27 внешних исходных чисел

### 3.1. Происхождение и постановка (RM 9.8)

- **Происхождение.** Внешний численный расчёт консультанта, передан владельцем в задании 2026-10-19. Это не артефакт проекта: код, журнал
  запуска и среда отсутствуют (RM 9.8; PL П-11).
- **Постановка — со слов задания, реализация консультанта не проверялась:**
  - изотропная пластина Кирхгофа–Лява, CCCC, D∇⁴w = q, q = D = 1;
  - двумерная 13-точечная МКР, фиктивные узлы w₋₁ = w₁, граничная строка D4 = (7, −4, 1);
  - SuperLU (`scipy.sparse.linalg.spsolve`, COLAMD), двойная точность.
- **Нормировка.** α = w_center·D/(qℓ⁴), ℓ — полная короткая сторона (ℓ = 1), длинная сторона rℓ. n — число интервалов по короткой
  стороне, rn — по длинной. У QA та же: `D2Solution.alpha` делит w в центре на q·min(lₓ, l_y)⁴/D.
- **Ориентация осей.** В плане и у QA nₓ = rn, n_y = n (длинная сторона по x). У консультанта оси могли быть переставлены. В точной
  арифметике α от этого не зависит: 𝒜_{D2} переходит в Π𝒜Πᵀ, центральный узел переходит в себя, так как n и rn чётны (RM 9.8). Поэтому
  QA считает обе ориентации.
- **Центр.** При чётных nₓ, n_y центр — единственный узел (nₓ/2, n_y/2) (`r5_cccc_d2.py`, `centre`). Все 27 точек имеют чётные n и rn.
- **Выборка.** n ∈ {32, 48, 64, 96, 128, 192, 256} × r ∈ {1, 2, 3, 5}, без r = 5, n = 256: 7 × 4 − 1 = 27. Печать — 14 значащих цифр.

### 4.2. Наблюдения (данные QA; причина не установлена)

1. **Величина расхождений.** |Δ|/α = 7,6·10⁻¹⁴…1,3·10⁻¹¹ при n = 32–64 и до 2,3·10⁻⁹ при n = 192–256. Наблюдаемая разность D2 − A в тех же
   точках — 1,2·10⁻⁴…8,4·10⁻³ отн. Это разность двух эталонов, а не гарантированная ошибка сетки (QA, разд. 2.1, п. 2; Ф-2).
2. **Собственная ошибка D2 QA мала по сравнению с расхождениями — по оценке.** Наименьшая |Δ|/α = 7,6·10⁻¹⁴, оценка e_D2/α ≤ 8,6·10⁻¹⁷:
   отношение не меньше ≈ 880. Выполнение правила 1/100 (D-049.6, п. 4) этим **не доказано**: бюджет D2 оценённый, но не строго ограниченный (QA,
   разд. 6; ЭР-3).
3. **Близость к неуточнённому решению.** Отношение |внешнее − уточнённое| / |внешнее − неуточнённое| — две процедуры (Ф-1):
   - ближайшая из двух ориентаций — 24/27 точек ближе к неуточнённому, медиана 1,5, диапазон 0,22…487;
   - ориентация плана — 18/27, медиана 1,12.

   Неуточнённая ошибка QA растёт с n примерно как cond·u, до 3·10⁻⁹ отн. при n = 256.
4. **Пять точек вне кандидата.** В них собственная неуточнённая ошибка QA случайно мала (например, 4,9·10⁻¹⁴ при r = 5, n = 48), а
   расхождение с консультантом — 1,3·10⁻¹¹. Член 10·|α_unref − α_ref| строится по ошибке **QA**, а не консультанта. Поэтому B_ext ошибку
   консультанта не ограничивает (QA, разд. 2.1, п. 3; АП-9; REV 1.5).
5. **Ориентация и упорядочение** на уточнённое α не влияют: разность 0 во всех 28 точках. Неуточнённые решения обеих ориентаций записаны в
   CSV (`unref_vs_external`, `unref_transposed_vs_external`).
6. **Центр** (PL §1.5, проверка при NOT_REPRODUCED). У QA центр определён однозначно (3.1). Для консультанта его код проверить нельзя.
   Есть довод по порядку величины [собственная оценка, уровень Б, не проверка кода консультанта]. По одномерной модели RM 9.7 (П-10)
   относительное изменение прогиба при сдвиге на один узел от центра ≈ 8h²: 3,5·10⁻³ при n = 48; 8,7·10⁻⁴ при n = 96; 2,2·10⁻⁴ при
   n = 192. Расхождения в тех же точках (≤ 2,3·10⁻⁹) меньше на 5 порядков и более. Сдвиг центра на узел с данными не согласуется.

### 4.3. Гипотеза, а не установленная причина

- **Согласуется с данными:** последние знаки консультанта — ошибка решения без итеративного уточнения тем же типом решателя (QA, разд. 2.1;
  REV 1.5: «согласуется… хорошо обоснована»).
- **Не установлено:** причина. Кода, среды, порядка операций и версии SuperLU консультанта нет (П-11). Поэтому гипотеза не доказывается и
  не опровергается.
- **Альтернативные дискретизации.** Схема, отличающаяся от D2 на уровне ошибки сетки, дала бы разность порядка 10⁻⁴ и более. Такие схемы
  данные исключают. Но реализацию, отличающуюся от D2 меньше чем на 2,3·10⁻⁹, исключить нельзя: реализация консультанта недоступна (QA,
  разд. 2.1, ЭР-1). Формулировка REV 1.5 «другая дискретизация исключена» в окончательном тексте QA смягчена (ЭР-1). Здесь принимается
  смягчённая.

## 7. Принципиальные ограничения

1. **Код и среда консультанта недоступны (П-11).**
   - Причину расхождений нельзя установить ни новыми расчётами QA, ни анализом.
   - Гипотеза 4.3 остаётся гипотезой.
   - Единственный путь установить причину — материалы консультанта: код, версии, журнал.
2. **B_ext не утверждён.**
   - PL §1.5, п. 2 требует утвердить его до открытия сравнения; этого не сделано. По D-049.6, п. 2 он остаётся инженерным кандидатом.
   - Сравнение уже открыто, и утвердить B_ext теперь значило бы назначить допуск задним числом. Это противоречит AGENTS.md, разд. 4
     («допуски фиксируются до итогового сравнения») и PL §1.5 («не подбирается по внешним значениям»).
   - Поэтому статус CONSISTENT_WITHIN_ROUNDING_MODEL формально недостижим ни для одной из 27 точек.
   - Даже при утверждении 5/27 остаются вне. Правило повышения PL §1.5 («только при REPRODUCED или CONSISTENT **всех** 27») не выполнялось
     бы и тогда.
3. **Непригодность B_ext как критерия** — вывод QA, согласованный Reviewer (REV 1.5): член 10|α_unref − α_ref| описывает ошибку QA, а не
   консультанта. Это **наблюдение и предложение**, решение принимает владелец.
4. **Что не следует из Q2 при любом распоряжении:**
   - правильность D2 относительно ω₀ — ошибку сетки проверяют только A и B (D-049.8, п. 2);
   - допуски для КК-МВИ или Builder;
   - оценка точности A, B или C;
   - статус экстраполяций консультанта.
