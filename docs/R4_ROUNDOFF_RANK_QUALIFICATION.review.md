## 3. Энергетический сертификат ранга

### 3.1. Утверждение и доказательство (проверено независимо)

Обозначения — R4_NUMERICAL_SPEC 2.1 и N23-1 (в): V_h — узловые поля (n_x − 1) × (n_y − 1); a_h(w, v) = D·Σh_xh_y(Δ_hw)(Δ_hv),
l_h(w) = q·Σh_xh_y·w, ‖·‖ = a_h^{1/2} (норма: a_h положительно определена, разд. 2.1); ω_h — минимизатор Π_h на V_h, a_h(ω_h, v) = l_h(v)
(N23-1 (в), п. 5); 𝓡_k := {Z ∈ V_h : rank Z ≤ k}; d_k := min_{Z∈𝓡_k}‖Z − ω_h‖ (минимум достигается: 𝓡_k замкнуто в конечной размерности,
функция коэрцитивна).

**Утверждение (собственный вывод QA, проверен Reviewer).** Пусть W = XYᵀ, X — (n_x − 1) × N, Y — (n_y − 1) × N. Если
‖W − ω_h‖ < d_{N−1}, то

1. rank W = N;
2. dist(W, 𝓡_{N−1}) ≥ d_{N−1} − ‖W − ω_h‖ > 0;
3. ρ_N(W) = σ_N(W)/σ₁(W) ≥ Λ_min·[d_{N−1} − ‖W − ω_h‖]/(Λ_max·‖W‖), Λ = μ^x_m + μ^y_n ∈ [Λ_min, Λ_max].

*Доказательство.*
1. rank W ≤ N, так как W — сумма N членов ранга ≤ 1. Если бы rank W ≤ N − 1, то W ∈ 𝓡_{N−1} и ‖W − ω_h‖ ≥ d_{N−1} по определению — противоречие.
2. Для Z ∈ 𝓡_{N−1}: ‖W − Z‖ ≥ ‖Z − ω_h‖ − ‖W − ω_h‖ ≥ d_{N−1} − ‖W − ω_h‖ (неравенство треугольника).
3. В координатах DST-I (N23-1 (в)) ‖Z‖² = Dh_xh_yΣΛ²Ẑ², поэтому √(Dh_xh_y)·Λ_min‖Ẑ‖_F ≤ ‖Z‖ ≤ √(Dh_xh_y)·Λ_max‖Ẑ‖_F. Для rank W = N
   расстояние в норме Фробениуса до 𝓡_{N−1} равно σ_N (Эккарт–Янг — Мирский [СТАНД.], та же теорема, что в N23-3, п. 3), а σ₁ ≤ ‖Ŵ‖_F;
   сингулярные числа Ŵ и W совпадают (Ψ ортогональна). Отсюда п. 3. ∎

Код QA (`campaign_cell`, ветка «energy route») реализует ровно это:
- ‖W̃ − ω_h‖² = a_h(W̃) − 2l_h(W̃) + ‖ω_h‖² по тождеству Галёркина;
- a_h и l_h берутся по **всем** модам, включая чётные: шум сохранённых массивов учтён;
- ‖ω_h‖² = l_h(ω_h) = h_xh_yΣ(c^x_mc^y_n)²/(μ^x_m + μ^y_n)²;
- сертификат — `up(e) < lo(√D^low)`;
- запас — `(lo(√D^low) − up(e))/lo(√D^low)`;
- п. 3 вычисляется с Λ_max < 4/h_x² + 4/h_y² и Λ_min = μ^x₁ + μ^y₁.

### 3.2. Ответы на обязательные вопросы задания

1. **Из какой теоремы выводится условие.**
   - Само достаточное условие ни на какую теорему не опирается: оно следует из определения d_{N−1} как минимума по 𝓡_{N−1}.
   - Количественная часть — **N23-3** (D^{low}_{N−1} ≤ d²_{N−1}, три хвоста Мирского). Тождества координат — **N23-1 (в)**.
   - N23-1 (в) и N23-3 — собственные выводы проекта уровня Б со статусом PROVEN. Их проверили: рецензия `cee1951` (R4_N23_SCIENCE_REVIEW_PASS), QA `cfa9888`, финальная QA `6eaa973`.
   - **Решением владельца они не утверждены:** D-056 — лишь проект (`R4_N23_INTEGRATION.final.md`, разд. 6). Сам проект D-056.1 касается N23-4, не N23-3.
   - Принятая ВБ-20 (D-045) маршрутом **не используется**. Её монотонность (ВБ-17) верна только для точной последовательности. Маршрут QA — логика ВБ-20 без монотонности, применённая к каждому полю отдельно; формулировка плана («та же логика, что ВБ-20, без монотонности») точна.
2. **Что сравнивается.**
   - Верхний конец абсолютной энергетической нормы ‖W̃(s) − ω_h‖_{a_h}. Здесь W̃(s) — точное произведение сохранённых binary64-массивов «заданный × полученный» полушага s до QR.
   - Нижний конец (D^{low}_{N−1})^{1/2} — абсолютной нижней границы d_{N−1} по подматрице 12 × 12 первых нечётных мод.
   - Обе величины абсолютные, в одной норме; относительные меры e_rel не смешиваются (ср. НБ-7 к ВБ-20).
3. **Одна ли задача и норма.**
   - Да. Обе стороны вычислены в одном объекте `Problem`: a = 1, b = float(r), точные h = a/n и μ, c; D = q = 1.
   - Шаг решателя binary64 и иная арифметика решателя на утверждение не влияют. Ранг — свойство матрицы W̃; задача (в) служит только инструментом оценки.
   - Отличие float(r) от r в задачу не входит: D^low пересчитан для b = float(r), а не взят из N23 (там r точное).
4. **Строгость границ.**
   - ‖W̃ − ω_h‖ — шар arb при 256 битах. Ψ строится по таблице `sin_pi` из 2n значений, массивы решателя переводятся точно; ширина ~10⁻⁶⁰ относительно.
   - D^low — шар следа минус верхние границы λ_j, подтверждённые законом инерции. LDLᵀ шаровой матрицы ведётся без перестановок; пивот, содержащий 0, даёт отказ (`_n_positive`). mpmath служит только для начального приближения.
   - Печать CSV направленная: `energy_err_up` — вверх, `dlow_sqrt_lo` и `energy_margin` — вниз (`_direction`). Флаг сертификата вычислен по шарам, а не по печати; в 2834 строках он согласован с напечатанными числами.
   - Предпосылка — корректность arb (уровень В). **Модель IEEE 754 этому утверждению не нужна**: оно относится к конкретным сохранённым числам.
5. **Что доказано — разд. 3.3.** Полный ранг **сохранённых** полей W̃(s) при s = 2…100 записанных прогонов; точная последовательность этим маршрутом не затрагивается.
6. **Без δ_f и c_d.**
   - В апостериорной форме — **да**. Не используются ни W*(s), ни σ̂_k, ни κ_rep, ни перенос по полушагам. Это главное достоинство маршрута: задача накопления (Н-3) заменяется оценкой каждого поля отдельно.
   - Для рабочего решателя маршрут **сам по себе не применим**. Нужна строгая верхняя граница ‖W̃ − ω_h‖, вычислимая во время расчёта, например e² = 2Π_h(W̃) + ‖ω_h‖² со строгой оценкой округления Π_h. Сейчас R(w) — модель (Н-3 отчёта); кроме того, решатель считает Π_h по сформированному полю fl(XYᵀ), так что нужна граница формирования (источник 5).
   - Требуемая точность невелика. Допустимая относительная ошибка 2Π_h равна (D^low − e²)/(‖ω_h‖² − e²) ≥ 1,5·10⁻⁷ по сохранённым строкам s ≥ 2, а измеренная ошибка P решателя ≤ 5,2·10⁻¹⁵ (`fft`) и 6,3·10⁻¹⁵ (`dense`). Запас ~5·10⁷ — **наблюдение**, не граница.
7. **Запас 0,741.**
   - Определён как (√D^low_lo − e_up)/√D^low_lo. Это безразмерная величина, консервативная, так как отнесена к нижней границе d_{N−1}.
   - Для сертификата достаточен любой положительный запас при строгих концах. 0,741 на много порядков больше ширины шаров (~10⁻⁶⁰), округления печати (10⁻⁹) и расхождения с независимым путём (≤ 6·10⁻⁹, разд. 6).
   - Смысл запаса: сертификат устойчив к любому возмущению поля с ‖Δ‖_{a_h} < 0,741·√D^low.
   - Минимум 0,7415 достигается при s = 2 (N = 3, r = 1/5, n ≥ 640). При s ≥ 3 запас ≥ 0,821 по сохранённым строкам.
   - Минимум совпадает со значением точной последовательности (1 − μ = 0,735 по N23-4 при μ ≤ 0,2646, где μ — верхняя оценка). Значит, запас — свойство метода (err(N, 2)/d_{N−1}), а не округления.
8. **Предпосылки для всех 132 ячеек и s ≥ 2.**
   - (П-1) D^low_{N−1} каждой ячейки при b = float(r), вычисленный офлайн.
   - (П-2) Строгая оболочка ‖W̃(s) − ω_h‖ для каждого записанного поля; вычислена для всех 13 068 полей s = 2…100 (`energy_rank_not_certified_s_ge2` = 0 по всем полушагам, не только по сохранённым строкам; агрегат `aggregate` берёт все s).
   - (П-3) Записанные массивы — массивы решателя этого прогона: прозрачность В-4, побитовые префиксы M1/M0.
   - (П-4) Корректность arb и python-flint 0.9.0 (уровень В).
   - (П-5) N23-1 (в) и N23-3 — проверены, владельцем не утверждены.
   - (П-6) Старт РВ4-1. Малость err(N, 2)/d_{N−1}, обеспечивающая запас, — свойство этого старта.
   - Не требуются: δ_f, c_d, W*, N23-4, ВБ-17/ВБ-20, модель IEEE 754.
   - Не охвачены:
     - другие платформы и порядки BLAS (другие массивы);
     - s > 100, другие сетки, r, старты, N ≥ 4, CCCC;

Точный ранг сохранённых массивов сам по себе разрешим тривиально: det(XᵀX) > 0 и det(YᵀY) > 0 в целых числах (проверено мной на
критических случаях, разд. 6). Но в двоичной арифметике он почти всегда равен N — шум делает матрицы невырожденными. Поэтому
информативен не точный ранг, а **количественная** устойчивость: строгое σ_N(W̃) > 0 относительно ошибки или энергетическое расстояние
