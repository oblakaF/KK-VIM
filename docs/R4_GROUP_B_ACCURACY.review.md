## 1. Независимая проверка (метод)

Собственный код рецензента (scratchpad, не в git). Модули QA не импортировались.
- Обе задачи — непрерывная и дискретная (DST-I, ЧФ-3) — записаны как одна сепарабельная проекционная задача в синусных коэффициентах. Вес (p_m + q_n)², цель T_mn = f_m g_n/(p_m + q_n)².
- Полушаги вычислялись в **mpmath, 40 знаков** (дискретная часть — 34 знака), ортонормирование — модифицированный Грам–Шмидт.
- err² = E(w) − 2⟨w, ω₀⟩_E + E(ω₀): это путь E (тождество В-23), вычисленный без потери точности.
- ‖ω₀‖²_{H_T}: замкнутая сумма по n, явная сумма по m ≤ 4001 и **точный** хвост по m через дзета-функцию Гурвица; ошибка асимптотики ~exp(−π m b/a).
- ω₀(центр): форма Леви через β(5) = 5π⁵/1536 и экспоненциально сходящуюся поправку.
- Объём:
  - все 10 r × N = 2, 3 × s = 1…40 при M = 4001;
  - сходимость по M = 1001…32001 (до 16 001 нечётной моды) для r = 1, 1/5, 5;
  - дискретные цепочки n = 40…2560 (r = 1), n = 320…2560 (r = 1/5, 1/2, 5).

## 2. Энергетическая ошибка (главный результат)

**Определения проверены.**
- err_abs = ‖w_cont − ω₀‖_{H_T}; e_rel = err_abs²/‖ω₀‖²_{H_T}.
- err_abs² = 2[Π(w_cont) − Π(ω₀)] — тождество В-23 (Π(v) = ½‖v − ω₀‖² − ½‖ω₀‖², Π(ω₀) = −½‖ω₀‖²). Предпосылки выполнены: q = const, SSSS, w_cont ∈ H_T как конечная сумма синусов.
- Формула пути D ‖v‖² = D(ab/4)π⁴Σλ_mn v_mn² следует из В-9 и Парсеваля. Строгая граница части ω₀ вне блока верна (проверено также тестом QA).

**Значения r = 1, s ≥ 10 (q = D = a = 1; M = 4001, 40 знаков):**

| N | e_rel | √e_rel (относительная ошибка в энергетической норме) | err_abs | δ_c (s = 10) |
|---|---|---|---|---|
| 2 | 1,050232·10⁻⁶ | **1,0248·10⁻³** | 4,229·10⁻⁵ | −3,7517·10⁻⁵ |
| 3 | 2,400066·10⁻⁸ | **1,5492·10⁻⁴** | 6,392·10⁻⁶ | −3,6315·10⁻⁶ |

e_rel — относительная **квадратичная** ошибка; относительная ошибка в энергетической норме — √e_rel.

Прочие √e_rel (r = 1):
- N = 2: s = 1 — 1,736·10⁻²; s = 2 — 1,060·10⁻³; s = 3 — 1,025·10⁻³.
- N = 3: s = 1 — 6,957·10⁻³; s = 2 — 1,838·10⁻⁴; s = 3 — 1,570·10⁻⁴.

Диапазон по 10 r при s ≥ 10: √e_rel = 5,76·10⁻⁴…1,025·10⁻³ (N = 2) и 8,01·10⁻⁵…1,549·10⁻⁴ (N = 3).

**Совпадение с QA** (`continuous.csv`, 7 значащих цифр), все 20 пар (N, r), s ∈ {1, 2, 3, 4, 10, 20, 40}:
- e_rel по пути D и по пути E — расхождение ≤ 4,2·10⁻⁷ отн. (это уровень округления записи CSV);
- δ_c — ≤ 1,1·10⁻⁶ отн. Максимум при N = 3, r = 1/5, s = 2, где |δ_c| = 8,6·10⁻⁹.

**Что включают бюджеты QA** (код `continuous_case`).

|---|---|---|---|---|

| округление Π(ω₀) ≤ 24u | — | да | — | подсчёт операций; не машинное доказательство; подтверждено 50 знаками в `3aaca8e` и здесь |

| округление самой рекурсии (массивы x, y) | **нет** | **нет** | **нет** | проверено в QA только при M ≤ 81 |

**Независимость путей D и E ограничена.** Оба пути используют одни и те же массивы коэффициентов рекурсии. Их согласие проверяет только итоговое вычисление нормы (отсутствие потери точности при вычитании энергий), но не рекурсию. МНК-контроль, другой алгоритм, охватывает только значение в центре.

**Результаты этой рецензии по открытым местам.**
1. *Округление рекурсии при M = 4001* закрыто численно: независимый 40-значный пересчёт совпадает с double-результатами QA до точности записи CSV во всех 20 случаях. Это вычислительная проверка, не интервальное доказательство; запас — порядка 10²⁰.
2. *Усечение по M.* Разность с M = 32 001 при удвоении M уменьшается в **31,98 ≈ 2⁵** раз на всех пяти удвоениях (сходимость ∝ M⁻⁵) для всех проверенных s и r. При M = 4001:
   - e_rel — ≤ 1,1·10⁻⁸ отн. (N = 3, r = 1/5, 5); ≤ 3,8·10⁻¹¹ (r = 1);
   - δ_c — ≤ 3,9·10⁻⁸ отн. (N = 3, r = 1/5, s = 2).

   Запас по правилу 1/100 — не менее 10⁵. Это **наблюдение**: регулярная асимптотика M⁻⁵ не доказана, строгой оценки переноса по s нет (Q-022).

**Ответы на вопросы задания.**
1. *Доказанный достаточный бюджет* относится только к **усечённой задаче** — КК-МВИ на синусах ≤ M (2001 нечётная мода на ось при M = 4001).
   - Строгие части бюджета: хвосты ω₀ и Π(ω₀).
   - Утверждение QA, что усечённая рекурсия — точная последовательность КК-МВИ ограниченной задачи, верно: энергия диагональна в синусном базисе, полушаг распадается по модам вычисляемой функции.
   - Округление покрыто моделями и независимым пересчётом в 40 знаков, но не строгой оценкой.
2. *Только удвоение M и модель округления* — всё, что касается **неусечённого** непрерывного КК-МВИ: e_rel, err_abs, δ_c, E_∞, L₂ для s ≥ 2. При s = 1 разница с неусечённым методом строго ограничена хвостом ряда (s = 1 — m-усечённый Навье).
3. *Статус RESOLVED* по D-046 и R4_NUMERICAL_SPEC 9.4 требует **доказанного** бюджета. Поэтому:
   - к **точному непрерывному** КК-МВИ при s ≥ 2 его применять нельзя;
   - к **проверенной усечённой задаче** M = 4001 — можно, с оговоркой, что округление учтено моделью и 40-значным пересчётом.
4. *Замена статусов требуется* (И-1). Для неусечённого непрерывного метода при s ≥ 2 — **PROVISIONAL**: численно разрешено с запасом ≥ 10⁵, но без доказанного бюджета переноса (Q-022). UNRESOLVED здесь не нужен: нет признаков недостаточного бюджета.

## 4. Механизм s = 2 (собственный вывод QA, уровень Б)

**Пп. 1–3 доказаны** (проверка рецензента).
- Предпосылки:
  - старт X⁰ — нечётные синусы **по x**; s = 1 — Y-полушаг, s = 2 — первый X-полушаг;
  - полушаги точные; q = const.
- (1) Y¹_j **равна** (не только пропорциональна) строке m_j = 2j − 1 коэффициентов ω₀ (ВБ-23).
- (2) При заданном Y энергия X-полушага в синусных коэффициентах — Σ_m Σ_n λ_mn(x_m·y_n − w_mn)²: независимые задачи по m.
- (3) Для m ∈ L = {1, 3, …, 2N − 1} целевая строка совпадает со столбцом Y¹, минимум равен нулю. Единственность минимизатора для этого не нужна; полный ранг Y¹ доказан (ВБ-22).
- Индексы верны: L — нечётные m ≤ 2N − 1; чётные моды тождественно нулевые.
- Конечное усечение на вывод **не влияет**: те же рассуждения дословно верны для ограниченной задачи.
- Численно (собственный код, M = 4001): после s = 2 максимум ошибки в строках L ≤ 4,6·10⁻¹⁵ от max|ω₀| при r = 1, 1/5, 5. Вклады и доли групп совпадают с T11.

**Пп. 4–5 — объяснение, не доказательство минимальности.**
- С s = 3 строки L действительно получают ошибку, энергия убывает (ВБ-17). Это верно.
- Что |δ_c| минимальна именно при s = 2, **не доказано** — это наблюдение на контрольных r.
- Утверждение «в центре доминируют низкие моды» не универсально:
  - при N = 2, r = 1 четыре группы дают сопоставимые вклады (−1,16; −0,86; −0,86; −0,88 ×10⁻⁵);
  - при r = 1/5 и 5 вклады групп имеют **разные знаки** (частичная компенсация).
- Формулировка «w_mn ~ 1/(mn(m² + n²)²) при единичных весах функционала» смешивает убывание коэффициентов ω₀ с весами функционала. Правильно так: функционал центра имеет веса ±1 у всех мод, энергия — вес λ_mn. Поэтому на единицу энергии ошибки чувствительность центра ∝ λ_mn^{−1/2}, и она больше у низких мод.
- Фраза «вывод „s = 2 лучше s = 10“ по ошибке центра неверен» двусмысленна: по центру s = 2 действительно лучше. Корректно: по энергетической норме s = 10 точнее (доказано, ВБ-17), а по центру — наоборот (наблюдение).
- QA правильно помечает вывод как собственный вывод проекта и **не** приписывает его авторам КК-МВИ.

## 5. Разделение ошибок и сетка

- Тождество w_h − ω₀ = E_disc + E_method — алгебраическое; со знаками выполняется (проверено в 34 знаках).
- **Независимо воспроизведены все E_disc** в центре (n = 40…1280, r = 1, 1/2, 1/5, 5; s = 1, 2, 10) и δ_c полной сетки: совпадение с `grid.csv` до 7 знаков. В частности:
  - −2,7625·10⁻⁷ (n = 640) и −6,9061·10⁻⁸ (n = 1280);
  - N = 3, s = 10: E_disc −2,7504·10⁻⁷ (n = 640) и −6,8760·10⁻⁸ (n = 1280).
- Знаки подтверждены. При r = 1 E_disc и E_method одного знака, кроме N = 3, s = 1. При r = 1/5 и 5 E_disc > 0.
- ω_h − ω₀ **нигде не подменяет** E_disc в таблицах центра и E_∞.
- **Исключение (И-4).** В §7 (T6) и §9, п. 4 «энергетическая различимость» n ≈ 100–520 вычисляется по |e_rel,h − e_rel|/e_rel (`need_e`). Здесь e_rel,h = ‖w_h − ω_h‖²_h/‖ω_h‖²_h — ошибка метода **относительно ω_h**. Это мера согласия дискретной и непрерывной ошибок метода, а **не** ‖E_disc‖ ≤ ‖E_method‖/100 в той же норме, как сформулирован критерий §7.
- **Порядок.** p_c на парах 320/640, 640/1280, 1280/2560 равен 2,0000 (±1·10⁻⁴) во всех проверенных (r, N, s), в том числе s ≥ 2.
  - Сетка n = 2560 в QA отсутствует. Прогноз E(4n) = E(2n)/4 подтверждён на ней с ошибкой ≤ 5·10⁻⁴ (отн., центр).
  - Ричардсон корректно ограничен как исследовательский инструмент. Общий второй порядок при s ≥ 2 не доказан (ЧВ4-7) — QA это прямо указывает.
- Мелочь: §6.3 «0,04–1 %» (отличие δ_c disc от полной сетки при s ≥ 2). По расчёту рецензента при n = 640 — 0,07–1,0 %.

## 6. Научные выводы

- **«Практические s = 2–4».** В отчёте QA такого утверждения нет. Как предположение — **не подтверждено**:
