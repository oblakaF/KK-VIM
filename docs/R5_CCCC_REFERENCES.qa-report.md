## 7. Отклонения и технические замечания

1. **Невязка уточнения D2.** Невязка вычисляется в double-double, а масштабы — точные рациональные числа, округлённые до double-double
   (отн. 10⁻³²). План §1.4 называет для масштабов рациональную арифметику. Влияние такого округления на решение ≈ cond·10⁻³² ≤ 10⁻²², то есть
   далеко ниже u. Совпадение с точной рациональной невязкой проверено тестом D2-9. Точный путь (`residual_exact`) сохранён для малых сеток.
2. **B_ext.** Вычислен, как в плане, по ориентации «длинная сторона по x»; ошибка без уточнения во второй ориентации тоже записана. Кандидат
