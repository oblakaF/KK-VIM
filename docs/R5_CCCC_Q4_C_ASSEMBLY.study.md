## 2. Механизм сокращения (общий для всех вариантов)

**Лемма С-1 (обусловленность шаблонной суммы).** Пусть шаблон с целыми коэффициентами c применяется к сохранённым значениям g:
s = Σ_k c_k g_k. В double, по П-1…П-5 RO 0.4 и [СТАНД.]-оценке суммы:

$$|\mathrm{fl}(s)-s|\le\gamma_k\,\textstyle\sum|c_k||g_k|,\qquad\text{отн. ошибка}\le\gamma_k\,\kappa(s),\quad\kappa(s):=\frac{\sum|c_k||g_k|}{|s|}.$$

**PROVEN** (стандартная оценка; k — число операций).

Для гладкого g с ограниченными производными:

- пятиточечная сумма: κ(Z₅g) ≈ 16|g|/(h⁴|g⁗|);
- трёхточечная: κ(Z₃g) ≈ 4|g|/(h²|g″|).

Для мод вида sin²(jπx/l) это порядка (2n/π)⁴/j⁴ и (n/π)²/j² соответственно — **MODEL** (асимптотика по гладкости).

**Следствие.**

- Ошибка пути B-C в C растёт примерно как u·(2n/π)⁴; ослабляется она усреднением в Грамовой сумме (RV: наклон ~n^3,5, OBSERVATION).
- **Масштабирование не помогает:** деление на h⁴ при диадическом h точно. Ошибка возникает в самой сумме Σc_kg_k, а не в делении (RV 7.2:
  целочисленный шаблон даёт тот же результат). Это прямое следствие леммы С-1 — **PROVEN**.

**Точное представление шаблонных слагаемых.** Коэффициенты 1, 2, 4 — степени двойки. 6 = 4 + 2, 7 = 4 + 2 + 1. Поэтому

- (Z₅g)_i раскладывается в сумму не более чем **семи** точно представимых double: g_{i−2}, −4g_{i−1}, 4g_i, 2g_i, [g_i в углу], −4g_{i+1},
  g_{i+2};
- (Z₃g)_i — в сумму **трёх**: g_{i−1}, −2g_i, g_{i+1}.

Это верно без переполнения: умножение на степень двойки точно, в том числе для субнормальных значений. Значит, единственное округление
шаблона — округление суммы, и её можно вычислить точно — **PROVEN**.

## 3. Три варианта сборки

### 3.1. Вариант 1: точный D4G по binary64-входам, однократное округление, Грам в double

**Определение.**

1. Ŷ₅ := rd(Z₅G) поэлементно: точная сумма слагаемых раздела 2 (целочисленная или рациональная арифметика либо безошибочные
   преобразования) и одно корректное округление.
2. Ĉ = fl(ĥ·fl(Gᵀ·fl(Ŷ₅/ĥ⁴))). Масштабный множитель h/h⁴ = h⁻³ можно применить и один раз к N × N матрице.

**Эквивалентность.** (Z₅G)/h⁴ = D4G точно, включая угловые строки (7, −4, 1). Проверка по построению L²:

- первая строка L²: (−2)² + 1 = 5 на диагонали, −4, 1; вместе с E₂ — 7;
- вторая строка: −4, 6, −4, 1 с нулём вне сетки (условие Дирихле w₀ = 0);
- чётный фиктивный узел входит только через E₂.

Значит, C₁ = hGᵀ(Z₅G)/h⁴ = C в точной арифметике — **PROVEN** (NS 3.1).

**Где округление.**

- (а) Шаблон: одно корректное округление, |Ŷ₅ − Z₅G| ≤ u|Z₅G| — **PROVEN**.
- (б) Масштаб h⁻³ и ĥ = fl(l/n): относительная ошибка нескольких u, мультипликативная, без сокращения. При l = 1 и n³ < 2⁵³ можно взять
  точное целое n³.
- (в) Грамова сумма длины m: |δ_ij| ≤ γ_{m+c}·h⁻³|G_i|ᵀ|Z₅G_j| [СТАНД.].

**Оценка.** Относительно √(C_iiC_jj) множитель Грамового сокращения ρ_ij := |G_i|ᵀ|Z₅G_j|/√((G_iᵀZ₅G_i)(G_jᵀZ₅G_j)).

- По Коши–Буняковскому ρ_ij ≤ ‖G_i‖‖Z₅G_j‖/√(…).
- На диагонали, по неравенству Канторовича для D4 ≻ 0 [СТАНД.], ρ_ii ≤ (κ_D4 + 1)/(2√κ_D4).
- κ(D4) ≤ 16/(h⁴λ_min(D4)) ≤ (2n/π)⁴(1 + O(n⁻²)), так как λ_min(D4) ≥ λ_min(L²) = μ₁².
- Итог: **|Ĉ_ii − C_ii| ≤ γ_{m+c}·½(2n/π)²(1 + o(1))·C_ii — PROVEN**, но с множителем ~n².
- Для гладких наборов ρ = O(1) — MODEL. SCRATCH (разд. 4): 1,73 на гладких, до 8,8·10² на «шероховатых».

**Статусы.**

- Эквивалентность — PROVEN.
- Погрешность шаблона — PROVEN.
- Итоговая оценка C — PROVEN, но не равномерная по n.
- Малость ошибки на наборах Е-4 — VERIFIED в 4 точках (RV 7.2).

**Стоимость.** O(mN) операций сверх текущего пути. Точное целочисленное суммирование семи слагаемых в Python дорого. Векторизуемая
альтернатива — безошибочное сложение (TwoSum, [СТАНД.]) с последующим корректным округлением; оно уже не является «одной операцией NumPy».
По сравнению с решением полушага стоимость пренебрежима — MODEL.

**Ограничения.**

- Оценка C содержит множитель ρ, не ограниченный равномерно.
- П-3: субнормальные Z₅G для гладких наборов практически исключены (|Z₅g| ~ h⁴|g⁗|), но в строгом пути проверяются явно.

### 3.2. Вариант 2: компенсированное вычисление шаблона D4G

**Определение.** Ŷ₅ := Sum2(слагаемые раздела 2) — каскад TwoSum с накоплением поправок (алгоритм Ogita–Rump–Oishi, [СТАНД.]). Дальше —
как в варианте 1.

**Эквивалентность** — та же, что в варианте 1 (PROVEN): изменён только способ вычисления точной суммы.

**Где округление.** По [СТАНД.]-оценке Sum2 для k ≤ 7 точных слагаемых:

$$|\hat Y_5-Z_5g|\le u|Z_5g|+\gamma_{k-1}^2\sum|t|\quad\Rightarrow\quad\text{отн.}\le u\bigl(1+\gamma_{6}^2\,\kappa(Z_5g)/u\bigr)\approx u\,(1+36u\,\kappa).$$

При κ ≲ (2n/π)⁴ поправка 36uκ ≪ 1, пока n ≲ 10⁴. Это охватывает выборку Q3/Q4 (n_f ≤ 1280) с большим запасом. Выше этого предела вариант
теряет точность — **PROVEN** как оценка; порог по n — следствие асимптотики κ, MODEL. Остальное — как в варианте 1, включая множитель ρ.

**Статусы.**

- Эквивалентность — PROVEN.
- Оценка шаблона — PROVEN при [СТАНД.] и П-1…П-5. Не годится при FMA-сокращениях компилятора, нарушающих TwoSum, и при
  переупорядочении операций.
- Совпадение с вариантом 1 — OBSERVATION (SCRATCH: до всех печатных знаков во всех случаях).

**Стоимость.** Около 6 TwoSum (≈ 36 операций) на элемент, векторизуемо в double. Пренебрежимо по сравнению с решением.

**Ограничения.**

- Корректность TwoSum требует строгого IEEE-округления без «оптимизаций» компилятора. В NumPy это выполняется; в другой реализации
  проверяется.
- Тот же множитель ρ в Грамовой сумме.

### 3.3. Вариант 3: симметричная форма через LG и граничные поправки

**Определение.**

$$C=(\text{Ł}G)^{\mathsf T}W(\text{Ł}G)=h\,X^{\mathsf T}X+\frac{2}{h^3}\bigl(g_1g_1^{\mathsf T}+g_mg_m^{\mathsf T}\bigr),\qquad X:=LG=\frac{Z_3G}{h^2}.$$

Две реализации:

- **3 (как в RV):** X̂ = fl(Z₃G/ĥ²) в double;
- **3⁺ (уточнение этого документа):** Ŷ₃ := rd(Z₃G) — точная сумма трёх точно представимых слагаемых (раздел 2) и одно корректное
  округление (или Sum2 — с оценкой варианта 2). Затем X̂ = fl(Ŷ₃/ĥ²).

**Эквивалентность (PROVEN).**

1. ŁᵀWŁ = h·D4 (NS 3.1).
2. Строки ŁG: нулевая — 2g₁ᵀ/h² с весом h/2; внутренние — (LG)ᵢ с весом h; последняя — 2g_mᵀ/h² с весом h/2.
3. Отсюда (ŁG)ᵀW(ŁG) = h(LG)ᵀ(LG) + (h/2)(4/h⁴)(g₁g₁ᵀ + g_mg_mᵀ) = hGᵀ(L² + E₂)G = C, так как L симметрична.
4. Нужно m ≥ 2 (n ≥ 3), иначе e₁ = e_m и угловые поправки складываются в одной строке. Это требование `HalfStep` (И-4).

**Где округление и сокращение.**

- **Вариант 3.** Сокращение остаётся, но в трёхточечной сумме: отн. ошибка X̂ ≤ γ_c·κ(Z₃g) ~ u(n/π)². Ошибка C при этом порядка
  2uκ(Z₃g), а не uκ(Z₅g): квадрат вычисляется Грамовой суммой от X̂, а не шаблоном D4. Оценка — **PROVEN** в первом порядке, множитель ~n²;
  фактическая величина — MODEL.
- **Вариант 3⁺.** Сокращения нет. Доказательство ниже.

**Теорема С-3⁺ (поэлементная оценка C без множителя обусловленности).** Пусть выполнены П-1…П-5, П-3 проверена для Ŷ₃, g₁, g_m. Пусть Ŷ₃
вычислено с |Ŷ₃ − Z₃G| ≤ u|Z₃G| поэлементно. Пусть дальше вычисляются в double:

- X̂ = Ŷ₃/ĥ²;
- Ĉ_L = ĥ·fl(X̂ᵀX̂) (скалярные произведения длины m, в любом порядке);
- Ê = fl(2/ĥ³)·(g₁g₁ᵀ + g_mg_mᵀ);
- Ĉ = fl(Ĉ_L + Ê).

Тогда с некоторым k = m + c (c — небольшое число операций масштаба, подсчитываемое по коду):

$$|\hat C_{ij}-C_{ij}|\le\gamma_{k}\,\sqrt{C_{ii}C_{jj}},\qquad \|\hat C-C\|_2\le\|\hat C-C\|_F\le\gamma_k\,\mathrm{tr}\,C\le N\gamma_k\|C\|_2 .$$

*Доказательство.*

1. X̂ = X(1 + θ) поэлементно, |θ| ≤ γ_{c_x}, где c_x учитывает корректное округление шаблона, ĥ и ĥ². Тогда
   |(X̂ᵀX̂)_{ij} − (XᵀX)_{ij}| ≤ γ_{2c_x}|X_i|ᵀ|X_j|.
2. Округление Грамовой суммы добавляет γ_m|X̂_i|ᵀ|X̂_j| [СТАНД.], масштаб ĥ — ещё два округления. Итого
   |Ĉ_L − hXᵀX|_{ij} ≤ γ_{m+2c_x+2}·h|X_i|ᵀ|X_j| ≤ γ_{m+2c_x+2}·√(a_ia_j), где a_i := h‖X_i‖² = (hXᵀX)_ii (Коши–Буняковский).
3. Ê: каждое произведение и сумма двух слагаемых округляются, масштаб 2/ĥ³ имеет относительную ошибку нескольких u. Поэтому
   |Ê − E|_{ij} ≤ γ_{c_E}(2/h³)(|g₁ᵢ||g₁ⱼ| + |g_mᵢ||g_mⱼ|) ≤ γ_{c_E}√(b_ib_j), b_i := E_ii (Коши–Буняковский для двух слагаемых).
4. Сложение: Ĉ = (Ĉ_L + Ê)(1 + δ). При этом |C_ij| ≤ √(C_iiC_jj) (C ⪰ 0), а √(a_ia_j) + √(b_ib_j) ≤ √((a_i + b_i)(a_j + b_j)) =
   √(C_iiC_jj).
5. Сложить пп. 2–4. Нормы — из |Ĉ − C| ≤ γ_k·ddᵀ поэлементно, d = (√C_ii): ‖ddᵀ‖_F = tr C ≤ N‖C‖₂. ∎

**Статусы.**

- Эквивалентность — **PROVEN**.
- Теорема С-3⁺ — **PROVEN** при П-1…П-5 и [СТАНД.]-оценке скалярного произведения. Множителя κ или ρ нет; рост — только γ_m от длины
  суммы (худший случай для любого порядка суммирования).
- Вариант 3 в double — оценка первого порядка с κ(Z₃g), MODEL по величине. VERIFIED в 4 точках (RV 7.2, до 7,1·10⁻¹⁵ по решению).
- Вариант 3⁺ в точках Е-4 не проверялся (только SCRATCH, разд. 4).

**Дополнительные свойства 3⁺** — **PROVEN** по построению:

- Ĉ симметрична, если X̂ᵀX̂ вычисляется симметрично (например, один треугольник);
- неотрицательно определённая структура C = (ŁG)ᵀW(ŁG) не разрушается сокращением.

**Стоимость.** Шаблон из трёх точек вместо пяти, точная сумма трёх слагаемых или Sum2, одна Грамова матрица N × N. Порядок стоимости тот
же, что у текущего пути. Тот же Ŷ₃ даёт и B = −h⁻¹GᵀŶ₃ (NS 4.2). Это возможное попутное улучшение B; его Грамово сокращение здесь не
оценивается — UNRESOLVED.

**Ограничения.**

- П-3 для Ŷ₃ проверяется явно: |Z₃g| ~ h²|g″|, субнормальных значений на рабочих сетках практически нет.
- k растёт с m (худший случай γ_m). При попарном суммировании — ⌈log₂ m⌉, но порядок BLAS не гарантирован.

## 6. Ограничения и условия

1. **П-1…П-5** (RO 0.4) и [СТАНД.]-оценки: скалярное произведение, TwoSum/Sum2, неравенство Канторовича. Источника в библиотеке проекта

   входят и не исправляются.
3. **Улучшение C не решает всю задачу точности B-C.** Остаются вклад B (10⁻¹⁴…10⁻¹², RV 7.2) и ошибка модального решения (до 3,5·10⁻¹¹).
   Её разложение — UNRESOLVED (RV 7.5). *Ред. Integrator: эти числа — прежнего смешанного построения (поправка в 1.3).*
4. **Бюджет эталона 1/100 (D-049.6, п. 4) станет строже.** Если ошибка B-C уменьшится до уровня модального решения, сертифицированная

5. **A-C** (`coefficients` / `coefficient_system`: плотное L@L, деление на h\*\*2) подвержен тому же сокращению при сборке. Для эталона с
