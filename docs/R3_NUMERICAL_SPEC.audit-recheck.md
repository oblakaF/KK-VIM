## 7. Н-6 — разовый квалификационный прогон QA

**Что есть в редакции 2.**
- 50 десятичных знаков.
- Все узлы каждой квалификационной сетки, на которой выполняется сравнение А-4.
- Норма — относительно max|w¹|; допуск ≤ 10⁻¹³.
- Исполнитель — «Reference — сводка; QA» (12, шаг 1, п. 8).

Нормативно этого достаточно: результат проверки однозначен, отдельный круг Literature не нужен.

**Чего в редакции 2 нет.** Нет уточнений владельца:
- о разовом характере прогона и публикации результата в отчёте;
- о временном окружении `mpmath` вне постоянных зависимостей и обязательного CI;
- о разделимости w¹ = sin(πx/a)·Y¹(y).

Противоречий с ними нет: спецификация не требует ни Builder-теста, ни CI для этого сравнения.

**Проверка разделимости.**
- В-29 по MATH_SPEC 9.1 имеет вид w¹ = X⁰(x)·Y¹(y) с X⁰ = sin(πx/a). Это видно и в моём расчёте первоначального аудита (разд. 4):
  Y¹ зависит только от y, a, b.
- Поэтому повышенная точность нужна только в n_y + 1 ≤ 641 узлах y на сетку. Значения поля во всех узлах восстанавливаются
  произведением.
- Погрешность sin(πx_i/a) в double (≈ 10⁻¹⁶) на три порядка меньше допуска 10⁻¹³. Ради буквального соблюдения «50 знаков» удобно
  вычислять и X⁰ в узлах (≤ 641 значений) в 50 знаках и перемножать до округления.
- Требование проверки всех узлов и допуск ≤ 10⁻¹³ при этом не меняются.

**Готовая формулировка для D-040 (неблокирующее О-2):**

> А-10б, s = 1: сравнение эталона Парсеваля с В-29, вычисленной с 50 десятичными знаками, — **разовый квалификационный прогон QA**
> с публикацией результата в отчёте QA. Сравниваются все узлы каждой квалификационной сетки, на которой выполняется сравнение А-4;
> норма — относительно max|w¹|; допуск ≤ 10⁻¹³ не меняется. Так как w¹(x, y) = sin(πx/a)·Y¹(y), достаточно вычислить в 50 знаках
> Y¹ в n_y + 1 ≤ 641 узлах y и sin(πx_i/a) в n_x + 1 узлах x. Значения поля во всех узлах восстанавливаются произведением в той же
> точности. `mpmath` используется только во временном окружении (например, `uv run --with mpmath`). В постоянные зависимости проекта,
> основного решателя и обязательных CI-тестов он не добавляется.
