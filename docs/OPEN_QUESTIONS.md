# Открытые вопросы KK-VIM

Реестр нерешённых вопросов. ID постоянные; закрытый вопрос остаётся в реестре со статусом CLOSED
и ссылкой на документ, где записан ответ.

**Порядок решения.** Вопросы о формулах и алгоритме сначала решаются чтением первоисточников
(`references/primary/`, ссылки по шаблону AGENTS.md). К владельцу проекта обращаются только
при нехватке источника или при необходимости выбрать объём проекта.

**Принятые решения здесь не пересматриваются:** N — число членов, k — число итераций (D-003);
закрепления SSSS и CCCC (D-007); граничные условия без навязывания u0 = v0 = 0 в независимой
задаче изгиба (D-023); Биргер после базового релиза (D-012); вложенность МППУ (внешний цикл) →
МВИ (внутренний цикл) (D-022); CCCC — авторский контрольный случай, SSSS с решением Навье —
проверочная постановка (D-024); раздельные верификация реализации и исследование точности (D-025);
поэтапная приёмка MATH_SPEC.md: часть A — допуск к R2, часть B — до R4 (D-029).
Вопросы ниже касаются того, как эти решения выражаются через источники.

**Гипотезы.** Рабочие гипотезы в вопросах помечены словом «гипотеза». Это не подтверждённые
утверждения авторов.

**Метки и страницы:** P80, P82 — как в `docs/DECISIONS.md`; P81, P81-S — по
[`references/INDEX.md`](../references/INDEX.md), раздел 3; страницы по печатной нумерации.

**Исполнители** — роли D-020 (обязанности ролей ещё не описаны, см. Q-014).
Literature — чтение и цитирование источников; Reviewer — независимая проверка; владелец —
выбор объёма проекта.

**Статусы:** OPEN — открыт; CLOSED — закрыт с указанием основания.
**Блокирует** — что нельзя завершить или начать до закрытия вопроса.

**Источники.** Вопросы решаются только по оригинальным публикациям из `references/`. Материалы
прежних проектов не используются ни как ответ, ни как подсказка (D-026).
