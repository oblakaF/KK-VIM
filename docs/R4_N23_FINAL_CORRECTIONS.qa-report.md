## 3. И-1: независимое подтверждение строгих нижних границ

### 3.1. Математическая проверка

Обозначения документа: ‖X‖² = c₀Σ(α_m + β_n)²X_mn², err(N, s)² = c₀E, d_k² = c₀D(k), ‖ω₀‖² = c₀W₀.

1. **Числитель.** D^{low}(k) — сумма подтверждённых законом инерции нижних границ t_j собственных чисел (N23-3, проверено Reviewer).
   Значит, c₀D^{low}(k) ≤ d_k². В коде используется нижний конец интервала `dN1`, `dN`.
2. **Знаменатель.** W₀^{up} ≥ W₀ (QA перепроверил слагаемые по разд. 3.1 документа; q = D = a = 1).
   - λ_mn²Ω_mn² = 256/(π⁴m²n²λ_mn²).
   - Блок m, n ≤ 161: интервальная сумма.
   - Строки m > 161: λ_mn ≥ π²m² ⇒ Σ_n ≤ 32/(π⁶m⁶), а Σ_{m>M, нечёт.} m⁻⁶ ≤ 1/(10M⁵).
   - Столбцы n > 161 в строке m: при t = 0 λ_mnΩ_mn ≤ 16ρ_mb²/(π⁴mn³), откуда вклад ≤ 256ρ_m²b⁴/(10π⁸m²M_c⁵).
   - Код (`n23_rank_certificate.py`, стр. 170–179) суммирует столбцовые хвосты по каждой из 81 строки m ≤ 161 и добавляет хвост строк.
     Блок с хвостами покрывает все пары (m, n) ровно один раз.
   - Верхний конец берётся из интервала `(W0 + W0_tail).b`, нижний — из `W0.a` (блок положительных слагаемых).
3. **Дискретная задача (в).**
   - Нижний конец — блок 40 × 40 нечётных мод.
   - Верхний конец — полные строки первых min(n_x/2, 81) мод плюс оценка остальных строк. Она верна, потому что
     (μ_m + μ_n)²Ω̂² = c_m²c_n²/(μ_m + μ_n)² ≤ c_m²c_n²/μ_m² при μ_n > 0 (стр. 231–236).
4. **Сокращение c₀.** `iv.sqrt(c0*D) / iv.sqrt(c0*W0)`: в интервальном делении нижний конец — lo(√(c₀D))/hi(√(c₀W₀)). Множитель c₀ — интервал,
   поэтому оценка не хуже (D^{low}/W₀^{up})^{1/2} и лишь консервативнее неё. Тест Builder проверяет эквивалентное условие без c₀:
   p²·hi(W₀) ≤ lo(D).
5. **Положительность знаменателя.** W₀^{up} ≥ W₀^{low} > 0 — сумма положительных слагаемых. Независимо: W₀ ≥ 4,3157·10⁻⁵ при r = 1/5 (разд. 3.2).
6. **Округление.** Каждое значение — нижний конец интервала, округлённый вниз в точных дробях (`outward(..., False)`).
   Направление проверяется программой при печати.
7. **N23-4 и N23-8 от ‖ω₀‖ не зависят.** μ = (E₂^{up}/D^{low}_{N−1})^{1/2} и d_N^{low}/err(N,2)^{up} знаменатель W₀ не содержат.

## 4. И-5 и проверка всех 554 опубликованных сертификатов

### 4.1. Разбор `scripts/r4_n23/n23_rank_certificate.py`

1. **Источник строгих оценок.** Опубликованные μ, enc, err₁, err₂, d_{N−1}/‖ω₀‖, d_N/‖ω₀‖ вычисляются операциями `iv` из интервалов (`report`,
   стр. 271–285). Номинальные значения mp участвуют только как пробные величины:
   - собственные числа `mp.eigsy` → t_j, каждое подтверждается законом инерции;
   - пробные векторы `lstsq` в double, точно переведённые в `iv`.

   Строгость от этих пробных величин не зависит. Множитель 1 ± 2⁻²⁰⁰ и округление к ближайшему из прежнего `outward` удалены.
2. **Перевод в десятичную запись.** `exact()` переводит конец интервала (знак, мантисса, порядок) в точную дробь; бесконечность и NaN
   отвергаются. Число знаков определяется приближённо и уточняется циклами в точных дробях. Затем ceil/floor в целых, проверка
   «печать = округлённое значение» и проверка направления (`value ≥ e` или `value ≤ e`).
3. **CERTIFIED** = `exact(mu.b) < 1` — от верхнего конца интервала, а не от строки.
4. **Ветви.** continuous, discrete и dense вызывают один и тот же `report`; dense — это `continuous_case` в 201 точке r.
5. **Хвосты и округление.**
   - Хвосты E₂, E₁ и W₀ (а) — по разд. 3.1 документа.
   - (в) конечна; оценка строк > 161 для E₂ и W₀ — разд. 3.1.
