## 2. Принятые формулы энергетического теста (не изменены)

[ПРИНЯТО, NUMERICAL_SPEC.md, 4.1, 10.2–10.4; реализация R2 — `src/kkvim/energy.py`]:
- Π_h(w) = ½a_h(w, w) − l_h(w), a_h(w, v) = DΣh_xh_y(Δ_hw)(Δ_hv), Δ_h = L_x + L_y во внутренних узлах;
- P_s = Π_h(w⁽ˢ⁾), ΔP_s = P_{s−1} − P_s, Q_s = ½‖w⁽ˢ⁾ − w⁽ˢ⁻¹⁾‖²_{a_h} (двумерная сборка по полю разности);
- γ_s = hρᵀd_f (невязка одномерной системы, 10.2); ΔP_s = Q_s − γ_s алгебраически;
- R(w) = u(⌈log₂N⌉ + 16)Ŝ(w), Ŝ(w) = DΣh_xh_y|Δ_hw|(|Δ|_hw) + |q|Σh_xh_y|w|, N = (n_x − 1)(n_y − 1);
  R_f = 4u(max(n_x, n_y)/π)²‖w⁽ˢ⁾‖_{a_h}‖d‖_{a_h};
- τ_s = |γ_s| + 10[R(w⁽ˢ⁻¹⁾) + R(w⁽ˢ⁾) + R_f]; E1: ΔP_s ≥ −τ_s; E2: |ΔP_s − Q_s| ≤ τ_s; **разрешимость: Q_s ≥ 10τ_s**; статусы
  NOT_APPLICABLE (s = 1), PASS / FAIL / UNRESOLVED.

Запас разрешимости — m_s = Q_s/(10τ_s); тест разрешён при m_s ≥ 1.

**[ВЫВОД ПРОЕКТА ЧВ-Р7-1] Верхняя оценка запаса при неизвестной γ.** Обозначим τ_R = 10[R(w⁽ˢ⁻¹⁾) + R(w⁽ˢ⁾) + R_f]. Так как τ_s = |γ_s| + τ_R ≥ τ_R,
m_s ≤ m_up := Q_s/(10τ_R), и m_s ≥ 1 ⇔ |γ_s| ≤ g_allow := Q_s/10 − τ_R = τ_R(m_up − 1). Значит, при тех же Q, R, R_f запас, вычисленный
с γ = 0, — **верхняя** граница фактического, а требование к будущему решателю формулируется как |γ_s| ≤ g_allow.

**[ВЫВОД ПРОЕКТА ЧВ-Р7-2] Масштабная инвариантность запаса.** При w = (qa⁴/D)w̄(x̄, ȳ) и h ∝ a (фиксированные r, n_x, n_y) Q_s, R(w), R_f
однородны одной степени — q²a⁶/D: D·h_xh_y·(Δ_hw)² ~ D·a²·(qa²/D)²; |q|h_xh_y|w| ~ q·a²·qa⁴/D; R_f ~ ‖w‖_a‖d‖_a. Поэтому m_s зависит только
от r, n_x, n_y, s (в точной арифметике модели) и не зависит от a, q, D, E, t, ν. Это позволяет считать при a = q = D = 1.

**Асимметрия r и 1/r.** Пластина 1/r со стартом по x — это второй старт пластины r (ЧВ-R1). Последовательности различны, поэтому
и запасы при r и 1/r различны. Для семейства I (n_x = n_y) перестановка сторон переводит сетку в ту же сетку.

## 5. Погрешность заместителя и неизвестные эффекты

Правила разд. 5–7 записаны **до** первого расчёта при r ≠ 1, после калибровки r = 1 (`scratch/r7/RULES_fixed_before_R3.md`,
SHA256 `cee66304c12fb7f06b581de75748853b6ae92e507e9ed090c32791bf8967dadc`, 2026-10-14 14:35:55 +08:00; запуск расчёта R3 — позже).

| Составляющая | Чем оценена | Статус |
|---|---|---|
| 1. Точное непрерывное Q_s | рекурсия Парсеваля, `energy(s).change_norm2/2` (столбец `Q_cont`) | ЗАМЕСТИТЕЛЬ, квалифицированный эталон |
| 2. Дискретизация энергии | дискретная форма a_h на выборке непрерывного поля (`Q_sur`) | ЗАМЕСТИТЕЛЬ |
| 3. Ожидаемое Q_s решателя R3 | Q_sur с неопределённостью e_sur (ниже) | предварительно |

| 5. Неизвестные эффекты решателя R3 | γ_s (невязка одномерных систем), округление факторизации, поле из сохранённых множителей | UNRESOLVED до решателя |

**Модель неопределённости [ИНЖЕНЕРНЫЙ ВЫБОР, зафиксирован заранее]:** e_sur = 2C_s[(h_x/ℓ_min)² + (h_y/ℓ_min)²]/2, ℓ_min = min(a, b), C₂ = 12,6,
C₃ = C₄ = 7,15; при r = 1, n_x = n_y = n это 2C_s/n² — вдвое больше калибровочного закона. Длина ℓ_min выбрана потому, что одномерные
множители R3 имеют погранслои ширины ~min(a, b)/π (В-29: ch(πy_c/a); на X-полушаге — ch(πx/b)). Модель пессимистична при сильной
вытянутости (при r = 0,2 и r = 5, n = 20: e_sur = 0,82 для s = 2 и 0,46 для s = 3), тогда как фактическое отношение Q_sur/Q_cont при n = 20
во всех r лежит в пределах −2,7…−5,4 % — тот же порядок, что при r = 1 (−3,8 %). Это наблюдение не заменяет калибровку на дискретном решателе R3.

**γ_s.** Для будущего решателя R3 неизвестна. Поэтому используется m_up (γ = 0, верхняя граница, ЧВ-Р7-1), а требование к решателю
записано как |γ_s| ≤ g_allow = τ_R(m_up − 1). Источник ориентира — R2: |γ_s| ≤ 1,1·10⁻⁶τ_s. Принимать γ_s = 0 как фактическую невязку
R3 нельзя; это условие проверяется на решателе.

**R_f, R.** Формулы 10.3 с нормами и полями заместителя; при r = 1 совпадение с дискретными — разд. 4. Для прямоугольника форма R_f
с max(n_x, n_y) — верхняя оценка той же модели (ЧВ-R3, подтверждён рецензией черновика R3, разд. 6).

**Категории (правило, зафиксированное заранее).** m_low = m_up(1 − e_sur), m_high = m_up(1 + e_sur):
- **MANDATORY_CANDIDATE** — m_low ≥ 4 и min(n_x, n_y) ≥ 20;
- **RESOLVABLE_NO_HEADROOM** — 1 ≤ m_low < 4 (или m_low ≥ 4 на грубой сетке);
- **BORDERLINE** — m_low < 1 ≤ m_high;
- **EXPECTED_UNRESOLVED** — m_high < 1.

Множитель 4 [ИНЖЕНЕРНЫЙ ВЫБОР] — запас одного удвоения сетки (при фиксированном Q_s τ_R растёт ~n²); при r = 1 он воспроизводит
принятое правило R2 (s = 3: 5,75 при n = 160 — обязательный, 1,35 при n = 320 — нет). Он не выведен из данных R3.

**Чувствительность к погрешности калибровки.**
- При r = 1 ни один случай с min(n) ≥ 20 не меняет категорию в пределах измеренной ошибки C_s/(n_xn_y).
- Ни в одном случае с min(n) ≥ 20 интервал [m_low, m_high] не пересекает 4; BORDERLINE (пересечение 1) — только 7 грубых сеток
  с s = 2: (20,4), (12,4), (8,4), (4,4), (4,8), (4,12), (4,20). Там e_sur = 1,57 > 1 — модель неинформативна, хотя m_up ≥ 4·10⁷.
- Вывод о категориях на сетках с min(n) ≥ 20 устойчив к модели e_sur в её пределах; устойчивость к фактической ошибке решателя R3 — UNRESOLVED.
