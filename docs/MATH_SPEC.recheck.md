## 4. Б-2 — невырожденность алгоритма (разд. 4.6, В-22/В-25): **PASS**

**Условие 3 разд. 4.6.** Пусть f(y) = ∫₀ᵃq(x, y)X⁰(x)dx. Тогда ℓ_{X⁰}(Ỹ) = ∫₀ᵇ f Ỹ, причём f ∈ L₂(0, b)
(Коши–Буняковский и Фубини: ‖f‖ ≤ ‖X⁰‖‖q‖_{L₂(Ω)}). C_c^∞(0, b) ⊂ V_b плотно в L₂, поэтому ℓ ≡ 0 на V_b ⇔ f = 0 п. в.
При q = const ≠ 0 функция f постоянна и равна q∫X⁰, так что условие равносильно ∫₀ᵃX⁰ ≠ 0. **Верно.**

| Случай | Проверка |
|---|---|
| sin(πx/a) | ∫ = 2a/π (численно 0,63662 при a = 1); F = 2qa/π. Допустима |
| sin²(πx/a) | ∫ = a/2 (0,5); F = qa/2; условия 1–2 для CCCC выполнены. Допустима |
| sin(2πx/a) — контрпример | Условия 1–2 выполнены, ∫ = 0, ℓ ≡ 0. Единственное решение — Y¹ ≡ 0, отсюда w⁽¹⁾ = 0. На s = 2: A_Y = B_Y = C_Y = F_Y = 0, задача вырождена. **Контрпример верен** |

**Совместная индукция В-22:**
1. **Первый Y-полушаг.** X⁰ ≢ 0 ⇒ A_{X⁰} > 0 ⇒ по В-20 существует единственное Y¹ ∈ V_b.
2. **Последовательные одномерные решения (P(s) ⇒ шаг s).**
   - A > 0, поэтому решение существует и единственно (В-20).
   - При q = const решение принадлежит C^∞ (бутстреп В-21 с постоянной правой частью) и удовлетворяет главному условию (из V)
     и естественному условию f″ = 0 (В-21).
   - Предпосылка Леммы о полушаге выполнена, поэтому w⁽ˢ⁾ = P_{M_s}ω₀ ∈ D(T_SS).
3. **Энергия при s = 1.** По В-23 Π(w⁽¹⁾) = −½‖w⁽¹⁾‖²_{H_T}. Y¹ ≢ 0: иначе a(Y¹, ·) ≡ 0 = ℓ, что противоречит условию 3.
   Тогда ‖X⁰Y¹‖_{L₂} = ‖X⁰‖‖Y¹‖ > 0, и по В-7 ‖w⁽¹⁾‖_{H_T} > 0. Следовательно, Π(w⁽¹⁾) < 0.
4. **Энергетическое неравенство в индукции.** Для j = 2, …, s:
   - w⁽ʲ⁻¹⁾ ∈ M_j: при j = 2 нужно X⁰ ∈ V_a, что следует из условия 1; при j ≥ 3 нужно, чтобы предыдущий вычисленный
     множитель лежал в V;
   - w⁽ʲ⁾ — минимум Π на M_j (проекция по P(j)).

   Отсюда Π(w⁽ˢ⁾) ≤ … ≤ Π(w⁽¹⁾) < 0 = Π(0), т. е. w⁽ˢ⁾ ≢ 0 и вычисленный множитель ≢ 0. Это P(s + 1).
5. **Знакопостоянство** множителей нигде не используется.

Вывод: из Π(w⁽¹⁾) < 0 и точной минимизации на каждом M_s действительно следует невырожденность всех последующих множителей
(A > 0 на каждом полушаге). Порочного круга между В-22 и В-25 больше нет: обе части доказываются одной индукцией.
Формально это индукция по всем предыдущим шагам («P(1) ∧ … ∧ P(s) ⇒ P(s + 1)»), так как в п. 4 используются P(2), …, P(s)

## 7. Энергетический тест Q-021 (разд. 7): **PASS**

- **Тождество.** ‖w − ω₀‖² = 2Π(w) + ‖ω₀‖² верно для любого w ∈ H_T, так как [w, ω₀] = (q, w). Отсюда
  Π(w) − Π(ω₀) = ½‖w − ω₀‖² и e_s = (Π(w⁽ˢ⁾) − Π(ω₀))/|Π(ω₀)| (проверено).
- **Точная убыль.** Π(w⁽ˢ⁻¹⁾) − Π(w⁽ˢ⁾) = ½‖w⁽ˢ⁻¹⁾ − w⁽ˢ⁾‖²_{H_T}. Это теорема Пифагора: w⁽ˢ⁻¹⁾ − w⁽ˢ⁾ ∈ M_s
  и w⁽ˢ⁾ − ω₀ ⊥ M_s.
- **Условия.** Тождество справедливо при: точной минимизации на замкнутом M_s (проекция), w⁽ˢ⁻¹⁾ ∈ M_s, s ≥ 2. Для s = 2 нужно
  X⁰ ∈ V_a. Нужны также одни и те же T, q и граничные условия. Сюда же относятся невырожденность (В-22) и, в доказанной
  области, q = const.
- **Невозрастание и строгое уменьшение.** Невозрастание при точной минимизации доказано. Строгое уменьшение не требуется
  и не утверждается.
- **Неподвижная точка.** Равенство ⇔ w⁽ˢ⁾ = w⁽ˢ⁻¹⁾. Проверено для обеих чётностей. Например, при чётном s:
  X^{s}Y^{s−1} = X^{s−2}Y^{s−1} и Y^{s−1} ≢ 0 ⇒ X^{s} = X^{s−2}. Тогда полушаг s + 1 получает тот же заданный множитель,
  что полушаг s − 1, и по единственности последовательность стабилизируется. Сокращение на множитель опирается
  на невырожденность В-22 — она доказана.
- **Начало теста.** С s = 1 (Π(w⁽¹⁾) ≤ Π(0) = 0); X⁰ приближением не является. Корректно.
- **Непрерывная и дискретная постановки** разведены (разд. 7.4, Н-10). Неравенство для w_h верно только при w_h ∈ M_s;
  дискретный тест — NUMERICAL_SPEC.md.
- **Сходимость энергии и точность.** Сходимость энергии **не** объявляется доказательством точности относительно Навье.
  Напротив, для квадрата доказано, что энергетическая ошибка N = 1 не стремится к нулю. Для справки: численно
  e₁ = 0,0049, т. е. w⁽¹⁾ — гармоника m = 1 (В-29), а ∬w⁽¹⁾ = 0,0016942 против ∬ω₀ = 0,0017025 qa⁶/D при a = 1.
  Это справочное значение не предлагается как критерий.
