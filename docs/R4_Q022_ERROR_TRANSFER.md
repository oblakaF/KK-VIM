## 1. Постановка

Рекурсия Парсеваля вычисляет непрерывную последовательность с модами m, n ≤ M (M нечётно). Нужна оценка
E_s := ‖w_s − w′_s‖, где w_s — поле **неусечённой** непрерывной последовательности (цель ω₀), w′_s — поле усечённой рекурсии, s = 1, 2, …;
N = 2–3, старт — нечётные синусы X_i⁰ = s_{2i−1} (РВ4-1), одинаковый для обеих последовательностей (M ≥ 2N − 1).

## 2. Усечение как возмущение цели [ВЫВОД ПРОЕКТА Q22-1]

**Утверждение.** Пусть ω_M — проекция ω₀ на S_M ⊗ S_M (коэффициенты при m, n ≤ M), τ := ω₀ − ω_M. Усечённая рекурсия есть **точная** непрерывная
последовательность КК-МВИ (в полном H_T) с целью ω_M вместо ω₀ и тем же стартом.

*Доказательство.* (1) Синусы a-ортогональны: [φ_mn, φ_kl]_{H_T} = D(ab/4)λ_mn²δ_mkδ_nl. (2) По ВБ-9 Y-полушаг с заданным U (dim N) — проекция цели на
M(U) = U ⊗ V_b в H_T. Так как скалярное произведение блочно-диагонально по y-модам n, M(U) = ⊕_n U ⊗ ⟨sin ν_ny⟩, и проекция распадается по n:
столбец n поля — Λ_n-ортогональная проекция столбца n цели на U, Λ_n := diag_m(λ_mn²) (разд. 3). Утверждение верно для любой цели в H_T. (3) Если U ⊂ S_M (коэффициенты при m ≤ M), а цель — ω_M,
то столбцы n > M цели равны нулю и их проекции — нули; столбцы n ≤ M цели лежат в S_M и их проекции совпадают с вычисляемыми рекурсией (Грам по Парсевалю
при m ≤ M и правая часть F/n — точные). Значит, полушаг с целью ω_M даёт поле в S_M ⊗ S_M, совпадающее с рекурсией. (4) То же для X-полушага; по индукции
с общего старта ⊂ S_M. ∎ (Утверждение формулировалось QA и Reviewer `3aaca8e`, разд. 5.1; здесь — полное доказательство.)

**Следствие.** Q-022 — это вопрос **устойчивости последовательности КК-МВИ к возмущению цели**: ω₀ ↦ ω_M, ‖τ‖ мал. Строгая оценка величины цели
[ПРИНЯТО: QA `r4_energy_reference`, проверено `3aaca8e`, разд. 6]: ‖τ‖² = (64q²ab/(π⁸D))(S − S_M), 0 ≤ S − S_M ≤ (a⁴ + b⁴)π²/(80M⁵) при нечётном M,
т. е. ‖τ‖/‖ω₀‖ = O(M^{−5/2}) — в H_T хвост убывает **медленнее**, чем поточечный (O(M⁻⁴)).

## 3. Инвариантность и блочная структура [ВЫВОД ПРОЕКТА Q22-2, Q22-3]

**Q22-2 (почему правило ЧВ-21 растёт как 4ˢ) — методическое обоснование, не теорема (З-1).** По ВБ-16 поля w_s зависят только от оболочек наборов; масштаб и любое A ∈ GL(N) на каждом полушаге
поля не меняют. Правило ЧВ-21 оценивает относительные ошибки **коэффициентов** A, B, C, F (представления), которые меняются и при изменении масштаба,
на поле не влияющем (формулировка Q-022). Поэтому оценки ниже строятся **только** для инвариантов: полей (норма H_T), оболочек (главные углы),
сингулярных чисел полей. Это устраняет зависимость оценки от масштаба представления, но **не** гарантирует более медленного роста: оценка Q22-5
также растёт как Π(1 + g_s), а при N = 3 (g_s ≫ 3) — быстрее 4ˢ.

**Q22-3 (блочная форма полушага).** Для Y-полушага с заданной оболочкой U ⊂ ℓ²_x (dim N): P_{M(U)} = ⊕_n P_U^{(n)}, P_U^{(n)} = X̂(X̂ᵀΛ_nX̂)⁻¹X̂ᵀΛ_n — Λ_n-ортогональный
проектор на U (X̂ — любой базис U). Для Навье-цели X̂ᵀΛ_nω_·n = (16q/(π²D n))·Σ_m x_m/m ∝ F/n (исправлено по З-2: при весе λ_mn² с множителем π⁴ — π², не π⁶), а X̂ᵀΛ_nX̂ = ν_n⁴a + 2ν_n²β + γ (в нормировке ЧВ4-18) — это и есть
рекурсия ĉ_n = (4/(nπD))(ν_n⁴a + 2ν_n²β + γ)⁻¹F [ПРИНЯТО ЧВ4-18]. Угол между M(U) и M(U′) в H_T: sin Θ(M(U), M(U′)) = sup_n sin Θ_{Λ_n}(U, U′), и
‖P_{M(U)} − P_{M(U′)}‖ = ‖P_{M(U)}(I − P_{M(U′)})‖ = ‖(I − P_{M(U)})P_{M(U′)}‖ = sup_n sin Θ_{Λ_n}(U, U′) (равные конечные размерности блоков) [СТАНД.].
X-полушаг — симметрично (Λ^x_m = diag_n(λ_mn²), блоки по x-модам m).

## 4. Угол оболочек через ошибку поля [ВЫВОД ПРОЕКТА Q22-4]

**Утверждение.** Пусть w, w′ — поля ранга ≤ N и ровно N соответственно, U, U′ — их x-оболочки, C, C′ — матрицы коэффициентов. Тогда для всех n

$$\sin\Theta_{\Lambda_n}(U,U')\ \le\ \frac{\|w-w'\|_{H_T}}{D^{1/2}\,\nu_1^{2}\,\sigma_N^{L_2}(w')},\qquad \nu_1=\pi/b .\qquad(\star)$$

Для y-оболочек (X-полушаг) — то же с κ₁ = π/a вместо ν₁.

*Доказательство.* (1) Λ_n^{1/2} = diag_m(λ_mn) = diag_m(ν_n² + κ_m²) переводит Λ_n-геометрию в евклидову: Λ_n-углы между range C и range C′ равны евклидовым углам между
range(Λ_n^{1/2}C) и range(Λ_n^{1/2}C′). (2) Теорема Ведина [СТАНД.] при rank C ≤ N (σ_{N+1}(Λ_n^{1/2}C) = 0): sin Θ ≤ ‖Λ_n^{1/2}(C − C′)‖₂/σ_N(Λ_n^{1/2}C′).
(3) Числитель: поэлементно ν_n² + κ_m² ≤ (ν_n/ν₁)²(κ_m² + ν_k²) для всех k ≥ 1 (оба множителя ≥ 1), откуда ‖Λ_n^{1/2}(C − C′)‖₂ ≤ ‖Λ_n^{1/2}(C − C′)‖_F ≤
(ν_n/ν₁)²‖C − C′‖_E, ‖·‖_E² := Σλ_mn²(·)². (4) Знаменатель: Λ_n^{1/2} ⪰ ν_n²I ⇒ σ_N(Λ_n^{1/2}C′) ≥ ν_n²σ_N(C′). (5) Отношение не зависит от n:
sin Θ ≤ ‖C − C′‖_E/(ν₁²σ_N(C′)); переход к физическим нормам — по формулам разд. 0. ∎
Множитель ν_n² сокращается — **константа гладкости оболочек не нужна**. Сравнение углов через L₂-углы дало бы множитель (1 + κ̄²/ν₁²) с неизвестной
гладкостью κ̄ точной оболочки; поэтому этот путь отвергнут.

## 5. Теорема о переносе [ВЫВОД ПРОЕКТА Q22-5]

**Утверждение (переформулировано по О-2).** Пусть w_s, w′_s — поля неусечённой (цель ω₀) и усечённой (цель ω_M) последовательностей,
E_s := ‖w_s − w′_s‖ — **фактическая** (неизвестная) ошибка, T ≥ ‖τ‖ — строгая граница (разд. 2), d′_s := w′_s − w′_{s−1}, R_s := (T² + ‖ω_M − w′_s‖²)^{1/2},
ν² := ν₁² для Y-полушага (s нечётно), κ₁² для X-полушага (s чётно). Определим **вычисляемую** последовательность оценок Ê_s:
- Ê₁ := T;
- для s ≥ 2, **если** Ê_{s−1} < D^{1/2}λ₁₁σ_N^{L₂}(w′_{s−1}) (проверяемое условие сохранения ранга),

$$\hat E_s:=\Bigl[\bigl(T+\hat\vartheta_sR_s\bigr)^2+\bigl(\hat E_{s-1}+\hat\vartheta_s\|d'_s\|\bigr)^2\Bigr]^{1/2},\qquad
\hat\vartheta_s:=\min\Bigl(1,\ \frac{\hat E_{s-1}}{D^{1/2}\nu^2\sigma_N^{L_2}(w'_{s-1})}\Bigr);$$

- при **первом** нарушении условия на полушаге s₀ вычисление оценки **прекращается**: Ê_s не определена (= ∞) для всех s ≥ s₀.

Тогда **E_s ≤ Ê_s для всех s, при которых Ê_s определена**. Все величины в правой части вычисляются по **одной** усечённой рекурсии (σ_N, d′_s,
‖ω_M − w′_s‖ — конечные суммы) и строгой границе T. Так поступает и код (`bound()` в `q022_transfer.py`, `q022_production.py`, `q022_table.py`).

*Монотонность правой части.* Обозначим F_s(e) := [(T + ϑ_s(e)R_s)² + (e + ϑ_s(e)‖d′_s‖)²]^{1/2}, ϑ_s(e) := min(1, e/(D^{1/2}ν²σ_N^{L₂}(w′_{s−1}))). ϑ_s(e) не убывает
по e ≥ 0, оба слагаемых под корнем не убывают, поэтому F_s не убывает. Если E_{s−1} ≤ Ê_{s−1} и условие выполнено для Ê_{s−1}, то оно выполнено и для
E_{s−1}, и (ниже, шаги 1–5) E_s ≤ F_s(E_{s−1}) ≤ F_s(Ê_{s−1}) = Ê_s. С E₁ ≤ T = Ê₁ по индукции получаем утверждение.

*Доказательство неравенства E_s ≤ F_s(E_{s−1})* при E_{s−1} < D^{1/2}λ₁₁σ_N^{L₂}(w′_{s−1}) (Y-полушаг s; X-полушаг — симметрично).
1. **Ранг.** ‖w_{s−1} − w′_{s−1}‖_{L₂-оп} ≤ ‖·‖_{L₂(Ω)} ≤ E_{s−1}/(D^{1/2}λ₁₁) < σ_N^{L₂}(w′_{s−1}) ⇒ по Вейлю [СТАНД.] σ_N(w_{s−1}) > 0: точное поле имеет ранг N,
   его x-оболочка U := U_{s−1} N-мерна, полушаг s точной последовательности определён однозначно (ВБ-14). U′ := U′_{s−1}.
2. **Разложение.** P := P_{M(U)}, P′ := P_{M(U′)}; w_s = Pω₀, w′_s = P′ω_M (ВБ-9, Q22-1). Тогда w_s − w′_s = P(ω₀ − w′_s) − (I − P)w′_s; слагаемые a-ортогональны
   (первое ∈ M(U), второе ∈ M(U)^⊥), поэтому E_s² = ‖P(ω₀ − w′_s)‖² + ‖(I − P)w′_s‖².
3. **Первое слагаемое.** ω₀ − w′_s = (I − P′)ω₀ + P′τ (так как P′ω₀ = P′ω_M + P′τ = w′_s + P′τ). ‖P(I − P′)ω₀‖ ≤ sin Θ·‖(I − P′)ω₀‖ ≤ sin Θ·‖ω₀ − w′_s‖ (наилучшее
   приближение в M(U′)); ‖ω₀ − w′_s‖² = ‖τ‖² + ‖ω_M − w′_s‖² ≤ R_s² (τ ⊥ S_M ⊗ S_M ∋ ω_M − w′_s). ‖PP′τ‖ ≤ ‖τ‖ ≤ T. Итого ≤ T + sin Θ·R_s.
4. **Второе слагаемое (ключевой шаг).** Включение w_{s−1} ∈ M(U) верно при **трёх предпосылках** (уточнено по О-3, рецензия `d73f497`, разд. 2.3):
   - (а) U — оболочка именно **заданного набора** X^{s−1} точной последовательности на полушаге s, а w_{s−1} = X^{s−1} ⊗ Y^{s−2} с Y^{s−2} ∈ V_b (ВБ-17, п. 3,
     при нечётном s; при чётном s — симметрично);
   - (б) dim U = N, т. е. x-оболочка поля w_{s−1} совпадает со span X^{s−1}; это выполняется только при rank w_{s−1} = N, которое обеспечивает шаг 1;
     без шага 1 включение может не выполняться, и угол (⋆) относился бы к другому подпространству;
   - (в) аналогично U′ = span X′^{s−1} = x-оболочка w′_{s−1} при σ_N(w′_{s−1}) > 0; тогда w′_{s−1}, w′_s, d′_s ∈ M(U′).

   При (а)–(в) (I − P)w_{s−1} = 0. Отсюда (I − P)w′_s = (I − P)d′_s + (I − P)(w′_{s−1} − w_{s−1}), и ‖(I − P)d′_s‖ ≤ sin Θ·‖d′_s‖ (d′_s ∈ M(U′)),
   ‖(I − P)(w′_{s−1} − w_{s−1})‖ ≤ E_{s−1} (ортогональный проектор). Итого ≤ E_{s−1} + sin Θ·‖d′_s‖.
5. **Угол.** sin Θ = sup_n sin Θ_{Λ_n}(U, U′) ≤ ϑ_s(E_{s−1}) по (⋆) (rank w_{s−1} ≤ N, rank w′_{s−1} = N) и sin Θ ≤ 1. ∎

**Почему не наивная оценка.** Прямое (P − P′)ω₀ ≤ sin Θ·‖ω₀‖ даёт E_s ≤ T + G_sE_{s−1}, G_s = ‖ω₀‖/(D^{1/2}ν²σ_N^{L₂}(w′_{s−1})) ≥ (λ₁₁/ν²)·σ₁^{L₂}(ω₀)/σ_N^{L₂}(w′_{s−1})
(λ₁₁ — сумма; ‖ω₀‖ ≥ D^{1/2}λ₁₁‖ω₀‖_{L₂} ≥ D^{1/2}λ₁₁σ₁^{L₂}(ω₀)), т. е. усиление
~1/ρ_N ≈ 10³ (N = 2), 10⁴–10⁵ (N = 3) за полушаг [НАБЛЮДЕНИЕ по значениям ρ_N рецензии `e6c351f`, разд. 11]. Шаг 4 заменяет его множителем 1 и
поправкой ϑ_s‖d′_s‖: ошибка предыдущего поля переносится **без** усиления 1/ρ_N.

## 6. Дополнительные следствия [ВЫВОД ПРОЕКТА Q22-6]

1. **Точечные меры.** Для v ∈ H_T и точки x₀ ∈ Ω̄: |v(x₀)| ≤ Γ(x₀)‖v‖, Γ(x₀)² = Σ_{m,n}φ_mn(x₀)²/(D(ab/4)λ_mn²) ≤ Γ*² := Σ_{m,n}1/(D(ab/4)λ_mn²) < ∞
   (Коши–Буняковский по Парсевалю). Хвост вне блока ≤ M строго: 1/λ_mn² ≤ a²b²/(4π⁴m²n²) (AM–GM: λ_mn ≥ 2π²mn/(ab)), Σ_{нечёт m > M}m⁻² ≤ 1/(2M) при нечётном M.
   **Суммирование по нечётным модам (З-3):** для Γ* оно основано на том, что разность полей содержит только нечётные моды — по симметрии полей при q = const
   и старте нечётными синусами (ВБ-22, п. 6); для Γ(c) это не нужно, так как φ_mn(c) = 0 при чётных m или n. Поэтому
   |w_s(c) − w′_s(c)| ≤ Γ(c)E_s ≤ Γ(c)Ê_s и max|w_s − w′_s| ≤ Γ*Ê_s.
2. **Энергетические меры.** |err_abs(w_s) − err_abs(w′_s)| ≤ E_s ≤ Ê_s (неравенство треугольника; err_abs по MATH_SPEC Б.13); для e_rel = err_abs²/‖ω₀‖²
   относительная ошибка ≤ 2q_s + q_s², q_s := Ê_s/err_abs(w′_s).
3. **Оценка строго возрастает; о фактической ошибке это ничего не говорит (исправлено по О-4).** По определению Ê_s ≥ (T² + Ê_{s−1}²)^{1/2} > Ê_{s−1}:
   **оценка** Ê_s строго возрастает по s при любом M. Кроме того, вклад ϑ̂_sR_s не исчезает: R_s ≥ ‖ω₀ − w′_s‖ ≥ d_N ≥ D^{1/2}λ₁₁δ_N > 0 (ВБ-19). Поэтому
   оценка этого типа сжатия не выражает. О **фактической** ошибке E_s из Q22-5 ничего, кроме E_s ≤ Ê_s, не следует; наблюдение 7.4 показывает
   E_s ≈ (0,96…0,99)‖τ‖ без роста. (В редакции `bd13cc5` здесь ошибочно стояло «E_s ≥ E_{s−1}».)
4. **N = 1.** σ₁^{L₂}(w′) = ‖w′‖_{L₂}; поправка g_s := (R_s + ‖d′_s‖)/(D^{1/2}ν²σ_N^{L₂}) мала (ошибка метода и шаги малы относительно поля), рост оценки —
   почти линейный по s.

## 8. Препятствие к строгой оценке без накопления (OPEN)

1. **Множитель ≥ 1 в оценке.** В доказательстве Q22-5 ошибка предыдущего поля входит через ‖(I − P)(w′_{s−1} − w_{s−1})‖ ≤ E_{s−1} — это лучшая **общая** оценка для
   ортогонального проектора. Реальная ошибка в значительной части лежит в M(U) и «пересчитывается» полушагом (отсюда наблюдаемое отсутствие роста),
   но для этого нужна информация о **направлении** ошибки относительно M(U), а не только о её норме.
2. **Поправка g_s при N ≥ 2.** ϑ_s содержит 1/σ_N(w′_{s−1}) — чувствительность N-мерной оболочки поля ранга N (Ведин; неулучшаема в общем виде). Она умножается
   на R_s ≥ d_N > 0 (Q22-6, п. 3) и на ‖d′_s‖; при ρ_N ≈ 10⁻³ (N = 2) и 10⁻⁵ (N = 3) получаем g_s ~ 1…7·10⁵ — экспоненциальный рост **оценки** Π(1 + g_s).
3. **Что потребовалось бы для строгой оценки без накопления.** (а) Оценка производной отображения «оболочка → оболочка» (Грассманиан, Q22-3) в окрестности
   вычисленной траектории вместе с липшицевостью этой производной — схема типа Ньютона — Канторовича с интервальной арифметикой (машинное доказательство);
   принципиально возможно для конечных N = 2–3, но не выполнено. (б) Структурная оценка через пучок t²a + 2tβ + γ (оболочка следующего полушага определяется
   полюсами и вычетами этой рациональной функции от t = ν_n²) — не выведена.
4. **[ГИПОТЕЗА Г-1]** Последовательность КК-МВИ нерастягивающая по цели в H_T: ‖w_s(ω) − w_s(ω′)‖ ≤ ‖ω − ω′‖ для всех s при общем старте. Подтверждается 7.4
   (отношение ≤ 0,99) и очевидна при s = 1 (линейная проекция). Не доказана; для общих нелинейных чередующихся проекций неверна без дополнительных условий.
   **Не используется** как основание статусов.
