## 3. Э-1: независимый вывод разложения

Обозначения ST 1.1 (все объекты — точные рационалы сохранённых double):

- w̃_p = ÛṼ_prevᵀ, w̃_s = ÛV̂ᵀ;
- ŵ = fl(XYᵀ);
- e′ = ŵ_p − w̃_p, e = ŵ_s − w̃_s;
- d = ŵ_p − ŵ_s, d̃ = w̃_p − w̃_s;
- d̂ = fl(d), δd = d̂ − d.

**Шаг 1.** l_h(v) = a_h(ω, v), где ω — минимизатор Π_h^C. Тогда
Π(v) − Π(w) = a_h(w, v − w) + ½‖v − w‖²_a − a_h(ω, v − w), то есть f(v, w) = a_h(w − ω, v − w) — как в RO ВОК-6.

**Шаг 2.** По ВОК-2 f(w̃_p, w̃_s) = Π(w̃_p) − Π(w̃_s) − ½‖d̃‖²_a = −γ_s. Знак согласован с AU: на строках с путём B проверяется
Q_b − (P_b,p − P_b,s) = γ (AU 398), и в Q3 Е-1 это выполнено 984/984.

**Шаг 3.** (ΔP̂ − Q̂) = [P̂_p − Π(ŵ_p)] − [P̂_s − Π(ŵ_s)] + f(ŵ_p, ŵ_s) + ½‖d‖²_a − ½‖d̂‖²_a − [Q̂ − ½‖d̂‖²_a].

Здесь использованы только тождество f(ŵ_p, ŵ_s) = Π(ŵ_p) − Π(ŵ_s) − ½‖d‖²_a и прибавление-вычитание ½‖d̂‖²_a. Отсюда:

- при d = d̂ − δd: ½‖d‖² − ½‖d̂‖² = −a_h(d̂, δd) + ½‖δd‖²_a = E^(3);
- f(ŵ_p, ŵ_s) − f(w̃_p, w̃_s) = a_h(w̃_s + e − ω, d) − a_h(w̃_s − ω, d̃) = a_h(e, d) + a_h(w̃_s − ω, d − d̃), где d − d̃ = e′ − e.

Получаем E_s = (ΔP̂ − Q̂) + γ_s = E^(1) + E^(2) + E^(3) + E^(4), а при точной заключительной арифметике AU E^(6) = 0. **PROVEN.**
Знаки, коэффициенты ½ и ориентация полушагов совпадают с ST.

**П. 2–5 задания:**

- **w̃ и ŵ различаются.** Точное произведение входит только через γ_s и E^(1). Энергии, Q и все мажоранты сборки берутся по
  вычисленным ŵ и d̂.
- **Переход к разности уже округлённых полей** точен: d − d̃ = e′ − e.
- **Член второго порядка.** RO ВОК-6 содержит a_h(e, e′ − e), а в Э-1 его нет: a_h(d̃, e) + a_h(e, e′ − e) = a_h(d̃ + e′ − e, e) =
  a_h(d, e). Член поглощён тем, что первое слагаемое записано через d, а не через d̃. Это тождество, а не отбрасывание.
- **Округление вычитания d̂** учтено дважды и без потерь: точным членом E^(3) и заменой ‖d‖_a ≤ ‖d̂‖_a + ‖δd‖_a в E^(1).

**Это именно E_s аудита.** AU 411–414 вычисляет num = |(frac(P̂_p) − frac(P̂_s)) − frac(Q̂) + γ| с точным γ пути B1 (AU 381), то
есть ровно |E_s|. «Часть формирования» f(ŵ) + γ (AU 415–417, f(ŵ) — по точной d) — это E^(1). «Часть сборки» — это
E^(2) + E^(3) + E^(4).

**А. Финальная арифметика.** В AU 411–414 P̂_p, P̂_s и Q̂ — значения double, а разность ΔP̂ − Q̂, числитель и тест (`k_interval`)
вычисляются в `Fraction`. Значит, E^(6) = 0 на этом пути. ST описывает именно этот объект и явно **не** приписывает
double-контроллеру отсутствие финального округления: для него ST даёт |r − (ΔP̂ − Q̂)| ≤ u(1+u)|ΔP̂| + u|ΔP̂ − Q̂|. Эту формулу
я вывел заново, она верна. Область применения ограничена (ST 8.1). Оценка величины этого члена в ST ошибочна (Н-1).

**Б. Переполнение.** Л-0 — не вывод «из конечности ответа» вообще. Это доказанное свойство конкретного набора операций (разд. 4.2):
у них нет операции, которая вернула бы ±∞/NaN к конечному значению, и нет нулевых множителей. Для пути с другими операциями —
сравнениями, min/max, делением на величину, которая может стать ∞, — Л-0 не переносится.

**В. BLAS (П-4′).** На этой платформе `numpy.matmul` для `X @ Y.T` вызывает dgemm библиотеки scipy-openblas 0.3.34 (DYNAMIC_ARCH,
ядра Haswell с FMA). При внутренней размерности N ≤ 3 граница γ_N|X||Y|ᵀ верна при любом порядке суммирования, с FMA и без:
каждое произведение проходит не более N округлений. Она перестаёт быть верной при пониженной точности накопления или
нестандартных алгоритмах. Поэтому П-4′ — свойство сборки библиотеки, а не следствие кода.

- Проверка Q3 Е-2 (984/984) относится к **текущим полям R-AC контроллера Q3**. Это другие массивы. Она **не** даёт основания для
  полей B-C кампании EQ и для предыдущего поля в новом базисе Û·C′ᵀ: это поле не совпадает с массивом ŵ шага s − 1 из Q3. ST
  (П-4′, У-1) говорит это прямо.
- Лемма Л-8 использует не свойство библиотеки, а неравенство |e| ≤ γ_N|X||Y|ᵀ (точнее, ‖e‖_a ≤ ε_a^C). Его точная проверка
  a posteriori на тех же массивах **заменяет** П-4′ для проверенных строк — независимо от BLAS, FMA, порядка и потоков (Н-5).

**Г. Underflow, FTZ, DAZ.** Для теоремы нужно:

1. сложения и вычитания с субнормальным результатом выполняются точно — постепенная потеря значимости, без FTZ;
2. субнормальные операнды не обнуляются (без DAZ);
3. для × и ÷ с ненулевыми операндами **точный** результат нормален.

Тогда модель П-1 верна с |δ| ≤ u. П-3′(в) в формулировке ST («результат по модулю ≥ 2⁻¹⁰²²») допускает пограничный случай
с |δ| = u/(1−u) > u (Н-2). П-3′(б) при (а) и (в) избыточно (Н-3).

**Отказ от сертификата при нарушении** — по RO 0.4, уточнение З-3: строка получает статус UNRESOLVED/NOT_APPLICABLE для
сертификата, а не FAIL теста. Абсолютный член потери значимости в ST не выведен, поэтому подставлять его без вывода нельзя.

**Историческое и повторное вычисление.** Проба FTZ/DAZ после кампании не проверяет условия исторического расчёта (ST разд. 10,
п. 1 это признаёт). Разрыв закрывает не проба, а **привязка**:
