## 2. Определения, зафиксированные до кампании

- **Ошибки** — в 2-норме набора и в K-норме (поле: ‖·‖_a = h_s^{1/2}‖·‖_K, П-S1); относительные — с сертифицированными границами ‖x*‖:
  - **полная** — s − x*, где s — решение B-C, x* — точное решение **исходной точной системы** K x = b;
  - вспомогательное разложение s − x* = (s − x_c_sym) + (x_c_sym − x*) — разд. 2.1.
- **Три системы не смешиваются** (*исправлено по И-1*):
  - **K** — исходная точная система, коэффициенты точные (`exact_coefficients`);
  - **K̂_FULL** — система, которую фактически решает B-C: вычисленные binary64-коэффициенты Â, B̂, Ĉ, F̂ **целиком**, в том числе
    несимметричные B̂ (и Ĉ у OLD, CONTROL); B-C решает модальные блоки по полной матрице (LU);
  - **K̂_SYM** — вспомогательная симметризованная система с **точными симметричными частями** (M̂ + M̂ᵀ)/2 вычисленных коэффициентов
    и тем же F̂. Это симметричная часть K̂_FULL, а не K̂_FULL.
- **Интервалы** — [d − b, d + b], где d — точно вычисленная разность, b — граница эталона.
- **Бюджет 1/100** (D-049.6, п. 4) — **для каждого** сравнения и **каждой** нормы отдельно: 100·b ≤ гарантированная нижняя граница
  разности. Иначе это сравнение — UNRESOLVED.
- **NEW против OLD:**
  - BETTER — интервал NEW целиком ниже интервала OLD;
  - WORSE — выше;
  - EQUAL — решения побитово равны;
  - OVERLAP — не решено.
- **Точность эталонов:** лестница 40/80/160 цифр эталонного аудита.

### 2.1. Вспомогательное разложение и смысл его частей (*исправлено по И-1*)

**Определение.** **x_c_sym** — точное решение вспомогательной симметризованной системы K̂_SYM. Это **не** точное решение полной
несимметричной системы K̂_FULL, используемой B-C. x_c_sym получено сертифицированно: Decimal-уточнение по точной невязке K̂_SYM, λ_low Q1b
для K̂_SYM.

$$x_{BC}-x^*=\underbrace{(x_{BC}-x_{c\_sym})}_{\text{смешанная доля}}+\underbrace{(x_{c\_sym}-x^*)}_{\text{сборка, симметричная часть}}.$$

Тождество точное: оно верно для любого промежуточного вектора.

- **x_c_sym − x\*** — ошибка, внесённая **симметричными частями** округлённых коэффициентов.
- **x_BC − x_c_sym — смешанная доля.** Это не «чистая модальная ошибка». Она содержит:
  - собственно ошибку модального решения B-C относительно K̂_FULL (μ_k, DST, ёмкость);
  - влияние **антисимметричных частей** вычисленных B̂, Ĉ, то есть округления **сборки** (несимметричные Грамовы суммы), а не модального
    алгоритма.

В `rows.csv`, `summary.json` и инструменте эта доля называется `modal` (`*_modal_*`, `budget_*_modal_*`). **Имена столбцов не меняются;
в этом отчёте `modal` всюду означает смешанную долю x_BC − x_c_sym.**

**Трёхчленное разложение Reviewer** (`ae4d083`, разд. 3.3; собственный расчёт рецензента в 5 точках, здесь не повторялся):

$$x_{BC}-x^*=(x_{BC}-x^*_{FULL})_{\text{модальная}}+(x^*_{FULL}-x_{c\_sym})_{\text{антисимметричная часть сборки}}+(x_{c\_sym}-x^*)_{\text{симметричная часть сборки}}.$$

Вывод Reviewer:
- **В OLD** антисимметричная составляющая может доминировать в прежней «модальной доле». Например, в точке P2 (1024 × 512, N = 2, Y)
  смешанная доля OLD ≈ **4,5·10⁻¹⁰** (набор), а собственно модальная ошибка относительно K̂_FULL — **4,4·10⁻¹⁴**. На крупных сетках
  смешанная доля OLD — в основном ошибка сборки Ĉ_OLD шаблоном D4 в double, а не модальное решение.
- **В NEW** Ĉ симметрична, асимметрия B̂ ~10⁻¹⁵; влияние антисимметричной части значительно меньше (≤ ~10⁻¹⁵), и смешанная доля NEW
  практически совпадает с собственно модальной ошибкой (в пределах ~5 % в поле в проверенных точках).
- **Опубликованные числа полной ошибки** OLD/NEW/CONTROL, их сертификаты и бюджеты 1/100 от выбора разложения **не зависят** и не меняются.

## 4. Исправление инструмента после первого прогона (раскрытие)

**Что обнаружено.** Первый прогон (`1b4261f`) дал противоречие. Ошибка «сборки» NEW доходила до 5,2·10⁻¹¹, а полная ошибка NEW была
≤ 3,8·10⁻¹⁴: решение B-C оказалось ближе к x*, чем к «своей» системе.

**Причина.** B̂ прототипа не строго симметрична (асимметрия ~10⁻¹⁴). Ленточная сборка SPD-системы (как и лента Q1b) берёт для блока узла
один треугольник коэффициентной матрицы, а для соседних узлов — оба. Из несимметричного B̂ получалась «перемешанная» система. Её решение
сдвинуто: 1,1·10⁻¹⁴ при 64 × 64, но лишь 2,6·10⁻¹⁶ при симметричной части B̂ (проверено отдельно).

**Исправление** (`b16398c`).
- Вспомогательная система строится по **точным симметричным частям** (M̂ + M̂ᵀ)/2 — это K̂_SYM, а не K̂_FULL (разд. 2.1).
- Влияние антисимметричной части — B-C видит её через LU полных модальных блоков — попадает в **смешанную долю** x_BC − x_c_sym, а не в
  чистую модальную ошибку (*уточнено по И-1*).
- Добавлен тест.

**Что не затронуто:** полные ошибки относительно точной системы, неравенство С-3⁺, выборка, критерии и правило бюджета. Изменилось только
вспомогательное разложение. *Уточнено по Н-4:* файлы первого прогона не сохранены — они перезаписаны повторным прогоном. Совпадение
итоговых счётчиков NEW/OLD и бюджетов видно только по выведенной в консоль сводке первого прогона. По коду полные ошибки от исправления не
зависят.

1. **Теорема С-3⁺** — PROVEN при П-1…П-5 и [СТАНД.]-оценке скалярного произведения. Подсчёт k = m + 13 — вывод QA по этому коду; нужна

   сетки и решатель Builder не переносится.
3. **N ≥ 2** — RESEARCH_ONLY / PROVISIONAL / NOT_QUALIFIED. Сертификаты относятся к решённому набору после QR.

   практически равна собственно модальной ошибке. Её разложение на μ_k, DST и ёмкость не исследовалось. Сборка B не менялась: влияние
