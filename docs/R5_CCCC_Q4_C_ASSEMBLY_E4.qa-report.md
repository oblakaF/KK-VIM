## 4. Исправление инструмента после первого прогона (раскрытие)

**Что обнаружено.** Первый прогон (`1b4261f`) дал противоречие. Ошибка «сборки» NEW доходила до 5,2·10⁻¹¹, а полная ошибка NEW была
≤ 3,8·10⁻¹⁴: решение B-C оказалось ближе к x*, чем к «своей» системе.

**Причина.** B̂ прототипа не строго симметрична (асимметрия ~10⁻¹⁴). Ленточная сборка SPD-системы (как и лента Q1b) берёт для блока узла
один треугольник коэффициентной матрицы, а для соседних узлов — оба. Из несимметричного B̂ получалась «перемешанная» система. Её решение
сдвинуто: 1,1·10⁻¹⁴ при 64 × 64, но лишь 2,6·10⁻¹⁶ при симметричной части B̂ (проверено отдельно).

**Исправление** (`b16398c`).
- Система с binary64-коэффициентами строится по **точным симметричным частям** (M̂ + M̂ᵀ)/2.
- Антисимметричная часть — B-C видит её через LU полных модальных блоков — относится к модальной части.
- Добавлен тест.

**Что не затронуто:** полные ошибки относительно точной системы, неравенство С-3⁺, выборка, критерии и правило бюджета. Итоговые счётчики
до и после исправления совпали. Изменилось только разложение.

5. **Разложение «сборка / модальная часть»** определено через симметричные части округлённых коэффициентов (разд. 4).
6. **Независимость исполнителей ограничена:** Literature, Reviewer и QA — исполнители одного типа.

## 10. Рекомендация

Вариант C-3⁺ **готов к отдельному решению владельца** как кандидат сборки C:
- неравенство С-3⁺ выполнено 476/476 при проверенных предпосылках;
- Ĉ SPD и симметрична во всех точках;
- на выборке он снимает доминирующую ошибку сборки (набор — в ~10⁵ раз при n = 512) и не меняет обусловленность модальных блоков;
- второй путь CONTROL даёт тот же уровень.

Перед решением рекомендуется адресная сверка Reviewer:
1. подсчёт k = m + 13 по коду `c3plus` и проверки П-3;
2. исправление разд. 4 — симметризация системы с округлёнными коэффициентами;
3. 2–3 случая WORSE (пары 160 × 32 в поле).
