## 1. Постановка: прямоугольник a × b

### 1.1. Что принято (MATH_SPEC, часть A)

| Элемент | Формулировка | Основание |
|---|---|---|
| Область | Ω̄ = [0, a] × [0, b], начало в углу, центр (a/2, b/2) | MATH_SPEC 1.1 |
| Уравнение | ΔΔw = q/D, q = const ≠ 0 | [АВТОР L-107, с. 99, (103), (104)]; MATH_SPEC 1.4 |
| SSSS | w = w_xx = 0 при x = 0, a; w = w_yy = 0 при y = 0, b | [АВТОР L-107, с. 124, (c); с. 100, (110), (111)] |
| D | Et³/[12(1 − ν²)] | [АВТОР L-107, с. 16, (3)] |
| Отношение сторон | r = b/a; опорная длина — a (сторона вдоль x) | MATH_SPEC 2.5 (В-12) |
| Безразмерные величины | x̄ = x/a, ȳ = y/b, w̄ = wD/(qa⁴) | MATH_SPEC 2.5 |
| Масштабирование | w⁽ˢ⁾ = (qa⁴/D)·w̄⁽ˢ⁾(x̄, ȳ; r); w̄⁽ˢ⁾ зависит от x̄, ȳ, r, s и не зависит от q, D, E, t, ν | MATH_SPEC 2.5, В-12 (вывод проведён для a × b) |
| Ряд Навье = ω₀ | В-27 выведен для a × b; ∬ω₀ = (64qab/(π⁸D))Σ 1/[m²n²(m²/a² + n²/b²)²] | MATH_SPEC 2.6, п. 6 |

### 1.2. Отношение сторон и соглашение источников

- В L-107 для прямоугольника a — **меньшая** сторона: «Мы полагаем, что b ≥ a, как на рис. 62» [АВТОР L-107, с. 136, сноска 2]; таблица 8 —
  b/a = 1,0 … ∞ (с. 143). MATH_SPEC 9.3 это отмечает.
- В KK-VIM a — сторона вдоль x, на которой задана X⁰ (D-030); r может быть и меньше 1.
- **[ВЫВОД ПРОЕКТА ЧВ-R1] Перестановка осей.** Пусть σ(x, y) = (y, x). Уравнение ΔΔw = q/D, условия SSSS и функционал Π (MATH_SPEC 1.5, 2.2)
  инвариантны относительно σ с заменой a ↔ b. Определения полушагов (MATH_SPEC 4.3, 4.4) переходят друг в друга: Y-полушаг с заданным X на
  a × b — это X-полушаг с заданным Y на b × a. Коэффициенты A, B, C, F — одни и те же интегралы. Следовательно:
  - последовательность КК-МВИ со стартом по **y** (Y⁰ = sin(πy/b)) на пластине a × b совпадает, после σ, с последовательностью со стартом
    по **x** (D-030) на пластине b × a: w_{a×b, старт y}⁽ˢ⁾ = w_{b×a, старт x}⁽ˢ⁾ ∘ σ при всех s;
  - выбор стартовой переменной при фиксированном соглашении D-030 равносилен выбору r или 1/r;
  - пересчёт безразмерного прогиба: w̄ (опорная длина a) = r⁴·w̄′ (опорная длина b), где w̄′ = wD/(qb⁴);
  - счётчики s и k = ⌊s/2⌋ при σ сохраняются; меняются местами только метки Y/X полушагов (полушаг s на a × b со стартом по y —
    X-полушаг, на b × a со стартом по x — Y-полушаг). Порядок D-030 по отношению к пластине b × a не меняется (Н-6).
  Подтверждено независимой рецензией (разд. 2: перестановка, эквивалентность стартов при каждом s, нормировка r⁴; численно до 10⁻¹⁷
  относительно). [SCRATCH] Центр Навье r = 0,5 равен центру r = 2, умноженному на r⁴, до 15 знаков.
- **Диапазон (Р-1, принято):** 0,2 ≤ r ≤ 5; контрольный набор — разд. 6.1.
- **Опорная длина (Р-3, принято):** a — по MATH_SPEC 2.5 (w̄ = wD/(qa⁴)) при всех r. Для сравнения с L-107 (a — меньшая сторона) при r < 1
  значение пересчитывается через перестановку сторон по ЧВ-R1: пластина a × b, r < 1, сопоставляется пластине b × a с отношением 1/r > 1,
  а w̄ = r⁴·w̄′.

  В диапазоне r ≤ 5 (α ≤ 7,9) переполнения нет.
- **Сетки и критерии** — семейства разд. 3.3, max(n_x, n_y) ≤ 640 для квалификации (Р-8). Применимость критериев А-4 (NUMERICAL_SPEC 14, 18.1)
  к каждому r проверяется и фиксируется до сравнений (Р-8; погранслой ширины ~a/π у краёв y = 0, b при r ≫ 1).
- Это контроль **первого полушага** (MATH_SPEC 9.3); не заменяет эталон Навье и проверку последующих полушагов.
- Для старта по y (ЧВ-R1) — та же формула с a ↔ b: α′ = πa/(2b).
