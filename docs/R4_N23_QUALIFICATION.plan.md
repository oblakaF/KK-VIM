## 1. Объекты сравнения

| Обозначение | Что это | Чем получено в кампании |
|---|---|---|
| w_s | точная **неусечённая** непрерывная последовательность КК-МВИ (цель ω₀) — объект квалификации; не вычисляется | — |
| w′_s | точная **усечённая** последовательность, нечётные индексы ≤ M = 4001 (2001 мода), цель ω_M (Q22-1) | интервально (arb) и в 60 знаках (mpmath) — инструменты QA |

## 3. Меры ошибки (как в группе B; на неусечённый метод — через N23)

| Мера | Измеряемая величина (группа B, M = 4001) | Связь с неусечённым методом |
|---|---|---|
| err_abs | err_meas = (‖w′ − ω₀‖²_блок + ½·хвост ω₀)^{1/2} — `err2_direct` | \|err(w_s) − err(w′_s)\| ≤ E_s ≤ Ê′_s (Q22-6, п. 2; N23-6) |
| e_rel | err_meas²/‖ω₀‖² | относительное изменение ≤ 2q + q², q = Ê′_s/err (Q22-6, п. 2) |
| δ_c | (w′(c) − ω₀(c))/ω₀(c), ω₀(c) — Леви (140) | \|w_s(c) − w′_s(c)\| ≤ Γ(c)·Ê′_s (Q22-6, п. 1) |
| E_∞ (выборка 65 × 65) | max\|w′ − ω₀\|/max\|ω₀\| по узлам | max\|w_s − w′_s\| ≤ Γ*·Ê′_s, Γ* = Γ(c) при нечётных модах (Q22-6, п. 1, З-3) |
| L₂ | `L2_rel` группы B | оценка ‖·‖_{L₂} ≤ ‖·‖_{H_T}/(D^{1/2}λ₁₁) существует, но **бюджет измерения L₂ в группе B не определён** → UNRESOLVED (причина R-BUD) |

Односторонняя мера N23-7 (только энергия): err_abs(N, s) ≤ U_s, U_s = min_{s₁ ≤ s}[(err_M(s₁)² + T²)^{1/2} + Ê′_{s₁}]; err_M(s) = ‖w′_s − ω_M‖.
Включение N23-8: d_N ≤ err_abs(N, s) ≤ err(N, 2)^{up} при s ≥ 2 — приводится справочно (ширина 8…75 %).

## 4. Состав бюджета ячейки (все части — в одной относительной норме измеряемой величины)

| № | Часть | Как вычисляется | Характер |
|---|---|---|---|
| Б1 | перенос усечения Ê′_s (N23-6) | рекурсия N23-6 по входам T, σ_N^{L₂}(w′_{s−1}), ‖d′_s‖, R_s = (T² + err_M(s)²)^{1/2}; в double — **в коде группы B** на массивах группы B; в arb — верхний конец шара | строгая формула; число — см. Б2 |
| Б2 | округление входов оценки | ρ_s = max(0, Ê′_s^{arb,up} − Ê′_s^{dbl}); в правило входит B_tr := max(Ê′^{dbl}, Ê′^{arb,up}) | интервальная оболочка (предпосылка — корректность arb) + 60-значная диагностика mpmath |
| Б3 | бюджет измерения группы B | строгое + модель группы B **в тех же ячейках**: e_rel — D_strict + D_model (к err²); err_abs — 1 − (1 − β_D)^{1/2}; δ_c — c_strict + c_model; E_∞ — inf_strict + inf_model; Π(ω₀) — tail + 24u для e_rel | строгое + модель первого порядка (как в группе B) |
| Б4 | округление массивов рекурсии в измеряемой величине | \|err_M^{dbl} − err_M^{arb}\| и \|w′^{dbl}(c) − w′^{arb}(c)\|; для E_∞ не вычисляется — предпосылка группы B (диагностика 40 знаков Reviewer) | интервальная оболочка |

Отношения (знаменатель — нижняя граница измеряемой величины с учётом Б3):

- err_abs: R = β_err + (B_tr + Б4)/(err_meas·(1 − β_err));
- e_rel: R = β_D + β_Π + 2q + q², q = (B_tr + Б4)/(err_meas·(1 − β_err));
- δ_c: R = β_c + (Γ(c)^{up}·B_tr + Б4_c)/(\|ω₀(c)δ_c\|·(1 − β_c));
- E_∞: R = β_∞ + Γ(c)^{up}·B_tr/(max\|ω₀\|·E_∞·(1 − β_∞));
- односторонняя (N23-7): err_abs — R_U = (U_s^{up} − err_meas)/err_meas + β_err; e_rel — R_U² = (U_s^{up,2} − err_meas²)/err_meas² + β_D + β_Π.
  Нижняя сторона вне двусторонней области не утверждается (max(d_N^{low}, err_meas − B_tr) — справочно).

Диагностики группы B (удвоение M, МНК) в бюджет не входят и приводятся отдельно, как в группе B.

## 6. Высокоточная проверка и округление

Три арифметических пути для **одной и той же** усечённой задачи (r, N, M = 4001, s ≤ 40):

1. **double, данные группы B** — диагностическое расширение `scripts/r4_group_b_study.py`, включаемое только явно (`--n23-transfer`):
   σ_N, ‖d′_s‖, err_M, Ê′_s, U_s, Γ(c), бюджеты Б3 и отношения R по массивам `continuous_sequence` группы B.
   Прежнее поведение скрипта без флага не меняется (регрессия разд. 10).
2. **arb (python-flint, шаровая арифметика, 1024 бита)** — независимый код QA `scripts/r4_n23_qualification.py` (не импортирует `kkvim` и
   `kkvim_reference`). Поля — через матрицы Грама факторов; смена базиса набора на точно представимую обратимую матрицу (поля не меняются,
   ВБ-16); σ_N — нижняя граница через положительную определённость Lᵀ·G_y·L − t·I (Холецкий в шарах); ‖ω_M‖², Γ(c)², T, λ₁₁ — в шарах.
   Результат — оболочки входов и верхние границы Ê′_s, U_s.
3. **mpmath, 60 знаков** — отдельная реализация (другая библиотека) тех же величин — диагностика.

Требования (задание, не допуски сравнения):
- контрольные значения печатаются с ≥ 40 значащими знаками; относительный радиус шара arb для них ≤ 10⁻⁴⁰ (иначе ячейка — R-RND);
- значение mpmath должно лежать в шаре arb, расширенном на 10⁻⁴⁰ отн.; несовпадение — дефект инструмента, разбирается, а не маскируется;
- double против arb — это **бюджет** Б2/Б4, а не допуск.

Строгость: шаровая арифметика даёт оболочку при предпосылке корректности arb (уровень В). Это **не** выдаётся за машинное доказательство
сверх этой предпосылки; совпадение double и высокой точности само по себе — диагностика.

**Печать границ:** верхние границы округляются наружу вверх, нижние — вниз; значения, округлённые к ближайшему, строгими границами
не называются.

## 9. Критерии результата ячейки

- **PASS (кандидат численной квалификации)**, если одновременно: применима проверенная оценка (ячейка сертифицирована N23-4; мера
  охвачена разд. 3); входы воспроизводимо вычислены тремя путями; Б2 учтён (оболочка arb); R ≤ 1/100; нет неучтённого источника
  ошибки, необходимого для сравнения.
- **UNRESOLVED** с кодом причины: R-TR — перенос не укладывается; R-BUD — бюджет неизвестен; R-RND — округление входов не ограничено;
  R-MEAS — бюджет измерения > 1/100; R-ASSUME — нужна недоказанная предпосылка; R-UNDEF — оценка для меры не определена.
- PASS здесь — **кандидат** для решения владельца; `status_cont_*` и другие статусы не меняются (D-048.10).
