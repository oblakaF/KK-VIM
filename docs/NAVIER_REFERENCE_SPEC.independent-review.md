## 4. Оценки остатка — PASS, замечание З-3

ВЫВОД РЕЦЕНЗЕНТА — проверка 8.2 по шагам:
- модуль члена ≤ 1/[mn(m² + n²)²] ≤ 1/(4m³n³), так как (m² + n²)² ≥ 4m²n² — верно;
- остаток квадратного усечения ≤ сумма по {m > M} плюс сумма по {n > M} ≤ 2·λ₃·S/4 = λ₃S/2,
  S = Σ_{m>M, нечёт} m⁻³ — верно (двойной учёт области m, n > M допустим для верхней границы);
- S ≤ ½∫_M^∞ t⁻³ dt = 1/(4M²) — верно для убывающей функции при шаге 2 по нечётным;
- итог (16/π⁶)·λ₃/(8M²) qa⁴/D равномерно по (x, y) — верно; λ₃ = 7ζ(3)/8 = 1,05180 — верно;
- числа: (16/π⁶)·λ₃/8 = 0,0166426·1,0518/8 = 0,0021881; при M = 101 — 2,14·10⁻⁷, при M = 201 —
  5,42·10⁻⁸ qa⁴/D — совпадает со спецификацией.

Проверка 8.3: член M_x по модулю ≤ (m² + νn²)/[mn(m² + n²)²] ≤ 1/[mn(m² + n²)] при 0 ≤ ν ≤ 1 ≤ 1/(2m²n²);
остаток ≤ λ₂·Σ_{m>M}m⁻² ≤ λ₂/(2M); λ₂ = π²/8; итог (16/π⁴)·π²/(16M) = 1/(π²M) ≈ 0,1013/M qa². При
M = 201 — 5,0·10⁻⁴ qa². Совпадает. **Обе оценки верны и консервативны.**

**З-3.** Вывод 8.3 «для моментов строгая оценка непрактична» относится к выбранной мажоранте, а не
к задаче. Мажоранта 1/(2m²n²) сильно завышает члены при m ≪ n. Более точная мажоранта (ВЫВОД
РЕЦЕНЗЕНТА, требует проверки QA):

- для фиксированного n: Σ_m 1/[m(m² + n²)] ≤ Σ_{m≤n} 1/(mn²) + Σ_{m>n} 1/m³ ≤ (ln n + 1,5)/n²;
- остаток ≤ 2·Σ_{n>M, нечёт} (ln n + 1,5)/n³ ≤ ∫_M^∞ (ln t + 1,5)/t³ dt = (ln M + 2)/(2M²);
- с множителем 16/π⁴ = 0,16426: |M − M_M| ≤ 0,0821·(ln M + 2)/M² qa², т. е. O(ln M / M²), а не O(1/M).

При таком виде строгая граница ε_M = 10⁻⁴·0,0479 = 4,8·10⁻⁶ qa² достигается при M порядка 4·10²
(ручная оценка, не расчёт), а не порядка 2·10⁴ по оценке 8.3. Аналогично для прогиба: остаток ≤
(16/π⁶)·[(ln M + 1,25)/(4M⁴) + 1/(16M⁴)] = O(ln M / M⁴). Рекомендация: либо добавить эти уточнённые
границы (после проверки QA), либо смягчить формулировку 8.3 — «для **выбранной** мажоранты строгая
оценка моментов непрактична».

- даёт значения w и моментов с точностью, намного превышающей 3 значащие цифры таблиц;

- является **независимой формой решения** той же краевой задачи (не тем же рядом), поэтому ошибки
  реализации двух форм независимы. Общие входные данные (q, D, a, b, ν) при этом не проверяются.

Рекомендация: добавить проверку П-12 — «совпадение w, M_x, M_y по Навье (при M уровня 8.6) и по формулам
§ 30 в точках средней линии y = b/2 (в координатах Навье)». Ограничения: формулы (139), (i), (l) сначала
