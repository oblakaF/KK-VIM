## А. Шаг 0 раздела 12 (D-039): энергетические измерения до сравнений с эталонами

### А.1. Что и как измерено

- **Скрипт:** `scripts/r3_solver_step0.py`; результаты — `docs/results/r3/solver/step0/` (`step0_energy.csv`, `step0_runs.csv`,
  `step0_r1_regression.csv`, `metadata.json` с SHA исходного кода и состоянием `dirty` до генерации, версиями Python/NumPy/SciPy,
  сетками и параметрами). Принятые данные Р-7 (`docs/results/r3/r7/`) только читаются.
- **Пластина и прогоны:** 1 × r, q = D = 1 (пластина заместителя Р-7), остановка с параметрами по умолчанию (tol_∞ = 10⁻¹⁰,
  tol_E = 10⁻⁸, s_min = 3, s_max = 100) — `kkvim.rectangle_run.run_rectangle_until_stopped`. Десять r; все уровни выбранных цепочек
  семейств I и II разд. 6.3, включая диагностические уровни с min < 20.
- **Независимый расчёт энергетических величин.** Для каждого s ≥ 2 QA вычисляет по формулам R3_NUMERICAL_SPEC 8.1
  (= NUMERICAL_SPEC 10.2–10.4) Q_s, ΔP_s, γ_s, R(w⁽ˢ⁻¹⁾), R(w⁽ˢ⁾), R_f, τ_s, τ_R, m_s, m_up, g_allow, E1, E2 и разрешимость
  **собственной реализацией**: двумерная сборка Δ_h = L_x + L_y, суммы `math.fsum`, γ_s из одномерной невязки ρ = F_h1 − KŶ
  с коэффициентами A_h…F_h, пересчитанными QA из заданного множителя (разд. 3.3), и разности множителей d_f = f_{s−2} − Ŷ.
  От решателя берутся только множители X, Y, вычисленный множитель до нормировки и сетки. `kkvim.energy`, `EnergyCheck`
  и `halfstep_report()` источником ожидаемых значений не служат; значения решателя сопоставлены с QA только после расчёта (А.5).
- **Обязательная область** (разд. 8.2–8.3; D-039; при r = 1 — D-032, п. 8): s = 2 — каждая квалификационная сетка;
  s = 3 — уровни таблицы 8.3. Таблица 8.3 закодирована в скрипте и тестом сверена с категориями `MANDATORY_CANDIDATE` в
  `margins.csv` (и с n ≤ 160 при r = 1).
- **Правило вердикта.** Обязательная строка — PASS, если тест разрешён (Q_s ≥ 10τ_s, т. е. m_s ≥ 1), выполнены E1 и E2,
  |γ_s| ≤ g_allow и |Q_s − Q_sur|/Q_sur ≤ e_sur (модель заместителя, Р-7, разд. 7, п. 7); иначе — **блокер** затронутого случая.
  Вне обязательной области — PASS/FAIL при разрешимости, иначе UNRESOLVED (не FAIL).
