## 2. Математическая проверка сертификата

### 2.1. Собственный вывод

Пусть K = Kᵀ ≻ 0, Kx* = b, r = b − Kx̂_ref (вычислен точно), 0 < λ_low ≤ λ_min(K).

1. x̂_ref − x* = x̂_ref − K⁻¹b = −K⁻¹(b − Kx̂_ref) = −K⁻¹r.
2. ‖x̂_ref − x*‖₂ ≤ ‖K⁻¹‖₂‖r‖₂ = ‖r‖₂/λ_min ≤ ‖r‖₂/λ_low.
3. ‖x̂_ref − x*‖²_K = (K⁻¹r)ᵀK(K⁻¹r) = rᵀK⁻¹r ≤ ‖r‖²₂/λ_min, отсюда ‖x̂_ref − x*‖_K ≤ ‖r‖₂/λ_low^{1/2}.
4. Поле решённого набора: по П-S1 (NS 4.3) a_h(ŨXᵀ, ŨXᵀ) = h_s vec(X)ᵀK vec(X), поэтому ‖Ũ(V̂ − V*)ᵀ‖_a = h_s^{1/2}‖x̂ − x*‖_K. Перестановка «по членам» ↔ «по узлам» — ортогональная, нормы не меняются.
5. Для измеряемого вектора x̂_BC: d = ‖x̂_BC − x̂_ref‖ точно, и по неравенству треугольника истинная ошибка лежит в [d − δ_ref, d + δ_ref] в каждой из двух норм.

Формулы QA (разд. 3 отчёта; код `analyse_point`) совпадают с выводом. **PROVEN.**

### 2.3. Решение в повышенной точности (`dec_cholesky`, `dec_solve`, `refine`)

- **Сборка.** Точная рациональная лента.
- **Множитель.** Ленточный Холецкий записей ленты, округлённых до p цифр (`ctx.divide`) — только **предобуславливатель**. Точный оператор он не подменяет: невязка каждого шага считается по точной ленте (`residual`), а поправка x + dx накапливается как точное рациональное число.
- **Остановка и отказ.** r = 0; ‖r‖∞ не уменьшилась в 10 раз; или 6 шагов. При неположительном опорном элементе — отказ на этом p и переход к следующему p.
- **Правило точности.** 40 → 80 → 160, переход — при отказе разложения или невыполнении бюджета в одной из норм; после 160 — UNRESOLVED. Правило зафиксировано до кампании и только повышает точность эталона; измерение B-C от него не зависит. Подгонкой оно не является. В кампании p = 40 в 476/476.
- **Сходимость.** `refine_converged` = 476/476; ‖r‖∞ падает с ~10⁻³² до ~10⁻²²² (QA).
- **Повторяемость.** Это не только совпадение готовых CSV: независимая сборка и иной решатель рецензента дают те же интервалы ошибки B-C во всех напечатанных знаках (разд. 4).

### 7.2. Разложение ошибки (три основные точки и две дополнительные)

Используются три решения:

- x*_dbl — решение системы с **double-коэффициентами B-C** (`bc_coefficients`, взяты точно) при точных шаблонах D4, L и точном h_s, определённое явно. Модальная часть B-C (μ_k в double, DST, ёмкость S с h\*\*4/(2D)·A⁻¹) — это **алгоритм решения**, она в x*_dbl не входит;
