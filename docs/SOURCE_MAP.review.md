## 5. Индекс k

### 5.1. Что установлено по первоисточникам

- **P81, Definition 1 (с. 367):** один шаг — вычисление одного набора функций по другому, т. е. **один координатный полушаг**.
  Верхний индекс набора равен числу шагов, выполненных для его получения: u⁰ (0), v¹ (1), u² (2), v³ (3). Неравенства (7), (8) на с. 368

- **P81, формула обрыва (с. 367):** ω_Nᵏ = Σ u_i^{k−1}v_iᵏ — авторы записывают только случай обрыва после набора v

### 6.2. Когда сильная и слабая формы Галёркина эквивалентны (одномерная задача)

Слабая задача: найти Y ∈ V_b = W₂²(0, b) ∩ W̊₂¹(0, b), для которого
A∫Y″Ỹ″ + 2B∫Y′Ỹ′ + C∫YỸ = F∫Ỹ для всех Ỹ ∈ V_b,
где A = ∫X², B = ∫X′², C = ∫X″², F = ∫qX/D.

Сильная задача: AY⁗ + 2(∫XX″)Y″ + (∫XX⁗)Y = F, Y = Y″ = 0 — форма разд. 6 SOURCE_MAP.

Эквивалентны при одновременном выполнении условий:
1. X ∈ W₂²(0, a) ∩ W̊₂¹(0, a), X ≢ 0, т. е. A > 0 — для корректности слабой задачи;
2. **коэффициенты совпадают:** ∫XX″ = −B, ∫XX⁗ = C. Для этого нужны X ∈ W₂⁴ (или C⁴), X(0) = X(a) = 0 и X′X″ = 0 на концах
   (∫XX⁗ = [XX‴ − X′X″] + ∫X″²). Это выполнено для SSSS (X″ = 0) и для CCCC (X′ = 0). Если заданная функция лишь из W₂², сильная форма
   с ∫XX⁗ не определена; тогда используются только коэффициенты слабой формы (−B, C) — [ВЫБОР] NUMERICAL_SPEC (Q-011);
3. q ∈ L₂ (для R2: q = const).

При этих условиях слабое решение принадлежит C^∞[0, b]: ОДУ с постоянными коэффициентами и постоянной правой частью. Оно удовлетворяет
сильной задаче с Y = Y″ = 0; обратно, классическое решение — слабое. **Разд. 9 SOURCE_MAP верен.**

**Двумерная задача (вне части A по существу).** При равномерной q точное решение SSSS **не принадлежит C⁴(Ω̄)**. Положим v = Δw. По (111)
v = 0 на ∂Ω, Δv = q/D. Если бы v ∈ C²(Ω̄), то в угловой точке v_xx = v_yy = 0, так как v ≡ 0 вдоль обеих сторон, и Δv = 0 ≠ q/D.
Следовательно, ω₀ ∉ D(T) при D(T) ⊂ C⁴(Ω̄), и ω₀ — обобщённое решение в H_T. Это подтверждает вывод разд. 9 SOURCE_MAP: проекционные
свойства КК-МВИ не должны требовать ω₀ ∈ D(T), и не требуют. Рекомендуется записать этот факт в MATH_SPEC (Н-6).

### 6.3. Положительная определённость и коэрцитивность (П-3) — через интеграл определителя гессиана

Пусть D(T) = {w ∈ C⁴(Ω̄): w = ∂²w/∂n² = 0 на ∂Ω}, Ω = (0, a) × (0, b), T = DΔ².

1. **Тождество.** w_xx w_yy − w_xy² = ∂_x(w_x w_yy) − ∂_y(w_x w_xy). Проверка: члены w_x w_xyy сокращаются. По формуле Гаусса–Остроградского
   ∬(w_xx w_yy − w_xy²) = ∮(w_x w_yy n_x − w_x w_xy n_y) ds.
   - На сторонах x = const: w ≡ 0 вдоль стороны ⇒ w_yy = 0.
   - На сторонах y = const: w ≡ 0 ⇒ w_x = 0.

   Интеграл равен нулю **для любой w ∈ C³(Ω̄), w = 0 на ∂Ω прямоугольника**; условие на вторые производные здесь не нужно. Следствие:
   для w, v ∈ D(T) член с (1 − ν) в (b), (h) L-107 исчезает **при любом ν**, а не только для произведений (разд. 3 SOURCE_MAP —
   частный случай): I(w) = ½D‖Δw‖² − (q, w).
2. **Симметрия.** Для w, v ∈ D(T): (Tw, v) = D∬ΔwΔv + D∮(v∂_nΔw − Δw∂_nv) ds. На ∂Ω v = 0, а Δw = w_nn + w_ττ = 0 (w_nn = 0 по ГУ,
   w_ττ = 0 вдоль стороны). Итого (Tw, v) = D(Δw, Δv) = (w, Tv).
3. **Положительная определённость** (в смысле (Tw, w) ≥ γ²‖w‖²_{L₂}). Пусть c_mn — коэффициенты w по φ_mn = sin(mπx/a)sin(nπy/b).
   По формуле Грина (w = φ_mn = 0 на ∂Ω) коэффициенты Δw равны −λ_mn c_mn, где λ_mn = π²(m²/a² + n²/b²). По Парсевалю
   ‖Δw‖² = Σλ_mn²c_mn²·ab/4 ≥ λ₁₁²‖w‖². Отсюда (Tw, w) ≥ Dλ₁₁²‖w‖², λ₁₁ = π²(1/a² + 1/b²).
4. **Коэрцитивность в W₂².** По п. 1 |w|²_{W₂²} = ‖w_xx‖² + 2‖w_xy‖² + ‖w_yy‖² = ‖Δw‖². Далее ‖∇w‖² = −(w, Δw) ≤ λ₁₁⁻¹‖Δw‖²
   и ‖w‖² ≤ λ₁₁⁻²‖Δw‖². Итого ‖w‖²_{W₂²} ≤ (1 + λ₁₁⁻¹ + λ₁₁⁻²)‖Δw‖² на D(T): энергетическая норма эквивалентна норме W₂².
5. **Одномерная коэрцитивность** — закрывает Б-3 и замкнутость M. При фиксированной X ≢ 0 из разд. 6.1:
   a(XỸ, XỸ) ≥ D‖X‖²‖Ỹ″‖² ≥ D‖X‖²(1 + (b/π)² + (b/π)⁴)⁻¹‖Ỹ‖²_{W₂²(0,b)} для Ỹ ∈ V_b.
   Неравенство Виртингера: Ỹ′ имеет нулевое среднее, а Ỹ = 0 на концах. Значит, одномерная задача однозначно разрешима
   (Лакс–Мильграм), и M = {XỸ: Ỹ ∈ V_b} — **замкнутое** подпространство H_T. Теорема 1 P81 использует проекцию на M₁¹ как на подпространство.

**Чего достаточно для части A.** Теореме 1 P81 нужны только п. 2, 3 на D(T), обобщённое решение ω₀ ∈ H_T
([v, ω₀] = (g, v) — существует по Риссу, так как |(g, v)| ≤ ‖g‖γ⁻¹‖v‖_{H_T}), п. 5 и принадлежность приближений D(T) (разд. 6.2).
H_T можно определить абстрактно как пополнение D(T) по энергетической норме, как в P81. Отождествление H_T = W₂² ∩ W̊₂¹ (П-3 в формулировке
SOURCE_MAP) для R2 **не обязательно**. Его строгое доказательство требует плотности D(T) в W₂² ∩ W̊₂¹ и распространения п. 1 на W₂² ∩ W̊₂¹;
это стандартный факт для выпуклых многоугольников, но в библиотеке проекта источника нет. Рекомендация: MATH_SPEC часть A строится
на п. 2–5 (Н-5).
