## 3. Уточнённые оценки остатка — PASS

Квадрат a = b. Члены рядов (131) и раздела 5 при a = b: для w — множитель qa⁴/D, для M_x, M_y — qa².
Обозначение: суммы только по нечётным индексам.

### 3.1. Прогиб, O(ln M/M⁴) (спецификация 8.2)

ПРОВЕРКА по шагам:
1. |член| ≤ 1/[mn(m² + n²)²] (|sin| ≤ 1) — верно.
2. Остаток квадратного усечения ≤ Σ_{n>M}Σ_m + Σ_{m>M}Σ_n; по симметрии m ↔ n обе суммы равны, итого
   ≤ 2Σ_{n>M} (1/n)·S(n), S(n) = Σ_m 1/[m(m² + n²)²]. Двойной учёт угла m, n > M допустим — верно.
3. S(n): при m ≤ n (m² + n²)² ≥ n⁴, Σ_{m≤n, нечёт} 1/m ≤ 1 + ½ ln n ≤ ln n + 1; при m > n (m² + n²)² ≥ m⁴,
   Σ_{m>n, нечёт} m⁻⁵ ≤ ½∫_n^∞ t⁻⁵dt = 1/(8n⁴) ≤ 1/(4n⁴). Итого S(n) ≤ (ln n + 1,25)/n⁴ — верно (с запасом).
4. g(t) = (ln t + 1,25)/t⁵: g′(t) = (1 − 5 ln t − 6,25)/t⁶ < 0 при t ≥ 1 — убывает. Для убывающей g и шага 2:
   Σ_{n>M, нечёт} g(n) ≤ ½∫_M^∞ g(t)dt. Множитель 2 из п. 2 сокращается с ½ — верно.
5. ∫_M^∞ ln t·t⁻⁵dt = ln M/(4M⁴) + 1/(16M⁴); ∫_M^∞ 1,25·t⁻⁵dt = 1,25/(4M⁴). Сумма
   (ln M + 1,25)/(4M⁴) + 1/(16M⁴) — **совпадает** с формулой 8.2.

Итог: |w − w_M| ≤ (16qa⁴/π⁶D)·[(ln M + 1,25)/(4M⁴) + 1/(16M⁴)], равномерно по (x, y). Граница верна.

### 3.2. Моменты, O(ln M/M²) (спецификация 8.3)

ПРОВЕРКА по шагам:
1. При a = b член M_x: (16qa²/π⁴)·(m² + νn²)S_mn/[mn(m² + n²)²]. При 0 ≤ ν ≤ 1 (m² + νn²) ≤ m² + n², откуда
   |член| ≤ 1/[mn(m² + n²)]; для M_y — так же. Верно (выполняется и при |ν| ≤ 1).
2. Для фиксированного n: m ≤ n — ≤ 1/(mn²), Σ ≤ (ln n + 1)/n²; m > n — ≤ m⁻³, Σ ≤ ½∫_n^∞ t⁻³dt = 1/(4n²) ≤
   1/(2n²). Итого ≤ (ln n + 1,5)/n² — верно (с запасом).
3. g(t) = (ln t + 1,5)/t³: g′(t) = (1 − 3 ln t − 4,5)/t⁴ < 0 при t ≥ 1 — убывает; остаток ≤
   2·½∫_M^∞ g(t)dt.
4. ∫_M^∞ ln t·t⁻³dt = ln M/(2M²) + 1/(4M²); ∫_M^∞ 1,5·t⁻³dt = 0,75/M². Сумма (ln M + 2)/(2M²) — совпадает.
5. 16/π⁴ = 16/97,4091 = 0,164256; ½ этого — 0,082128 ≈ 0,0821 — совпадает.

Итог: |M − M_M| ≤ 0,0821·(ln M + 2)/M² qa², равномерно по (x, y), для M_x и M_y. Граница верна.
