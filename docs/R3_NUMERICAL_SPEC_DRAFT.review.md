## 2. ЧВ-R1: перестановка осей, два старта, нормировка r⁴

**Подтверждено.**
- σ(x, y) = (y, x) переводит ΔΔw = q/D, условия SSSS и функционал Π пластины a × b в те же объекты пластины b × a. Y-полушаг с заданным X
  на a × b — это X-полушаг с заданным Y на b × a; коэффициенты A, B, C, F — те же интегралы (MATH_SPEC 4.2–4.4).
- Поэтому старт по y на a × b тождествен старту по x на b × a: w_{a×b, y}⁽ˢ⁾(x, y) = w_{b×a, x}⁽ˢ⁾(y, x) при всех s. Счётчики s и k сохраняются,
  меняются только метки Y/X полушагов.
- Нормировка: w̄ (опорная длина a) = wD/(qa⁴) = (b/a)⁴·wD/(qb⁴) = r⁴w̄′.
- Численно: центр(1/r) = r⁻⁴·центр(r) по двум разным однократным рядам Леви (вдоль a и вдоль b). Для r = 1,5; 2; 4; 5 — до 10⁻¹⁷
  относительно, т. е. на уровне усечения ряда (≤ 4·10⁻²² абсолютно).

Уточнение (Н-6): при переходе к b × a меняется направление первого полушага, но не порядок полушагов D-030 по отношению к пластине b × a.

## 6. ЧВ-R3: округление и ε_floor для прямоугольника (дополнение, п. 1)

**Вывод подтверждён в той же модели, что и в R2.** Модель: ошибка не больше u|w| в узле, т. е. ‖δw‖_h ≤ u‖w‖_h. Тогда
‖δw‖_{a_h} ≤ λ_max(−Δ_h)‖δw‖_h с λ_max < 4/h_x² + 4/h_y², и ‖w‖_{a_h} ≥ (μ₁ˣ + μ₁ʸ)‖w‖_h. Отсюда
ε ≲ 4u(n_x²/a² + n_y²/b²)/(π²(1/a² + 1/b²)) ≤ 4u(max(n_x, n_y)/π)².

- В знаменателе использовано μ₁ ≈ π²/ℓ². Точное μ₁ = (4/h²)sin²(π/(2n)) меньше на ≤ 0,4 % при n ≥ 20; это покрывается множителем запаса 10
  в ε_floor = 10u(max(n_x, n_y)/π)² (Н-3).
- Для семейства (i) n_x = n_y неравенство обращается в равенство: формула R2 точна в своей модели.
- Для семейства (ii) h_x = h_y, n_y = r·n_x формула R2 завышает пол в (1 + r²)/2 раз — при r = 5 в 13 раз. Это консервативно для оценки
  пола, но затрагивает правило конфигурации 11.2 (см. Б-2).
