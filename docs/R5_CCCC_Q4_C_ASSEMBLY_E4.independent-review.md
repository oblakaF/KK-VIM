## 2. A — теорема C-3⁺ и код QA

### 2.1. Реализация (`c3plus`, строки 135–149)

- **Шаблон.** Ŷ₃ = `_exact_stencil_rounded(G, Z3)`: точная рациональная сумма g_{i−1} − 2gᵢ + g_{i+1} (нули вне сетки), одно округление `float(Fraction)` (корректное). Для Z₅ (CONTROL) угловая диагональ 7 вводится через `end_diag` — верно.
- **Остальная часть.** ĥ = l/n; `h2 = h*h`; `X = Y3/h2`; `CL = h*(X.T@X)`; `h3 = h2*h`; `s = 2.0/h3`; `E = s*(outer(g1,g1) + outer(gm,gm))`; `C = CL + E`.
- **Соответствие формуле.** Это C = h(LG)ᵀ(LG) + (2/h³)(g₁g₁ᵀ + g_mg_mᵀ), тождество которой с hGᵀD4G доказано и проверено (рецензия `31f921a`, 2.1).
- **Независимая реализация рецензента** даёт **побитово** тот же Ĉ NEW в 5/5 проверенных точках.

## 3. Б и В — асимметрия B̂ и разложение

### 3.1. Как B-C использует B̂, Ĉ (`r5_cccc_bc.solve_bc`)

- `DM = D*(mu²·A + 2mu·B + C)` — **полные** матрицы.
- `np.linalg.solve(DM, …)` (LU) и `Minv` — полные, несимметричные блоки.
- `np.linalg.cholesky(DM)` — только диагностика положительности; NumPy использует нижний треугольник.
- Ёмкость: Ginv = h⁴/(2D)·A⁻¹ ⊗ I.

Значит, B-C приближает решение **несимметричной** системы

K̂_FULL = D[Â⊗D4 − 2B̂⊗L + Ĉ⊗I], b̂ = F̂⊗𝟏

с точными шаблонами и точным h_s. Модальное представление — K₀ с блоками M_k и поправкой Вудбери для углов E₂. Асимметрия на проверенных точках:
- B̂ — до 3,8·10⁻¹⁵ отн.;
- Ĉ OLD — до 1,9·10⁻⁹ отн.;
- Ĉ NEW — 0 (симметрична).

### 3.2. Что считает QA после `b16398c`

`frac_coef` строит систему по симметричным частям (M̂ + M̂ᵀ)/2 — **K̂_SYM**. Это симметричная часть K̂_FULL, так как (M⊗S)ᵀ = Mᵀ⊗S для симметричных D4, L.
- «Сборка» QA = x*_SYM − x*.
- «Модальная» = s − x*_SYM.
- Антисимметричная часть по тексту относится к «модальной» (docstring, отчёт, разд. 4).

**Вывод по пунктам Б.1–Б.7:**

1. B̂ и Ĉ в B-C используются **целиком** (3.1).
2. «Система с binary64-коэффициентами» QA ≠ системе, определённой вычисленными Â, B̂, Ĉ, F̂. Это K̂_SYM, а не K̂_FULL. Отчёт QA, разд. 2 («x*_c — точное решение системы с binary64-коэффициентами этого варианта») после исправления **неточен** (И-1).
3. Симметризация допустима как **выбранное диагностическое разложение**, но не обязательна. Точное решение K̂_FULL вычислимо и сертифицируемо: для любого x ‖K̂_FULL x‖‖x‖ ≥ xᵀK̂_FULL x = xᵀK̂_SYM x ≥ λ_low(SYM)‖x‖², поэтому ‖x − x*_FULL‖₂ ≤ ‖r_FULL‖₂/λ_low(SYM) (собственный вывод рецензента).
4. Антисимметричная часть — это **округление сборки** (несимметричный Грам Gᵀ(L̂G), Gᵀ(D̂4G)), а не модальный алгоритм. QA её не теряет: она входит в «модальную» долю, и это раскрыто в docstring и разд. 4. Но название «модальная (ошибка B-C относительно своих округлённых коэффициентов)» к ней не подходит.
5. Тождество s − x* = (s − x*_SYM) + (x*_SYM − x*) — **точное** при однозначно определённом x*_SYM. Оно верно для любого промежуточного вектора, так что вопрос только в смысле частей (п. 4).
6. Промежуточные решения сертифицированы. x*_SYM — Q1b λ_low и Decimal-уточнение. Граница в K-норме — b₂·√λ_max (Гершгорин): верно, так как ‖e‖_K ≤ √λ_max(K)‖e‖₂. Расстояния в K-норме вычисляются по точной K (`diff_interval` с невязками той же точной системы). Бюджет 1/100 — для каждой части и нормы отдельно: 476/476 × 12.
7. Исправление затронуло только `frac_coef`. Полная ошибка s − x*, выборка, бюджеты полных ошибок и классификация NEW/OLD от неё не зависят (по коду: `_errors` строит полные интервалы только по `ref`). Сличить счётчики до и после исправления нельзя: данных первого прогона нет. По коду их неизменность очевидна.
