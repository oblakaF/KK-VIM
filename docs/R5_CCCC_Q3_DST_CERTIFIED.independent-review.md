## 2. Математическая корректность (П1–П8)

**П1. Знакочередующийся ряд.** Если |t_k| не возрастает начиная с первого индекса хвоста, то хвост Σ_{k>K}(−1)^k t_k лежит между 0 и (−1)^{K+1}t_{K+1}, и сумма заключена между S_K и S_{K+1}.
- В коде нижняя граница берётся по S_нечётн, верхняя — по S_чётн, с K и K − 1 ≥ 1. Верно.
- **Направленность:** у положительных членов в нижней сумме берётся floor, у отрицательных — ceil (и наоборот для верхней). Рекуррентные границы членов t_{k+1}^lo = ⌊t_k^lo·A²/d⌋, t_{k+1}^hi = ⌈t_k^hi·A²/d⌉ монотонны по t_k. Верно.

**П2. π.**
- Тождество Мэчина π = 16 arctg(1/5) − 4 arctg(1/239) и тождество Эйлера π/4 = arctg(1/2) + arctg(1/3) — классические точные тождества.
- arctg(1/x) = Σ(−1)^k/((2k + 1)x^{2k+1}) при x ≥ 2 имеет строго убывающие члены.
- Комбинация: π_lo = 16a₅,lo − 4a₂₃₉,hi — коэффициент −4 меняет местами границы. Верно.
- Округление `>> 32` и `−((−hi) >> 32)` даёт floor и ceil. Верно.
- **Оракул:** интервалы π содержат π при bits = 1, 2, 4, 8, 16, 40, 64, 160, 300 по обоим путям. arctg(1/x) для x = 2, 3, 5, 239, 1000 при масштабах 3…200 бит — нарушений 0.

**П3. Приведение.**
- j = p mod 2q (Python: 0 ≤ j < 2q и для отрицательных p); sin(t + π) = −sin t; sin(π − t) = sin t. Тогда 0 ≤ j/q ≤ 1/2 — точно.
- j = 0 даёт 0, 2j = q даёт 1 — точно.
- **Оракул:** все p ∈ [−3q, 3q], q = 1…60, оба пути, bits = 4, 12, 40, 160 — 88 320 интервалов, нарушений 0. Знаки совпадают с sin(πp/q) во всех случаях. Специальные значения точны: sin(0), sin(π), sin(±π/2), sin(3π/2).

**П4. sin, cos на интервале.**
- **Тейлор sin при 0 ≤ x ≤ 2:** x²/((2k + 2)(2k + 3)) ≤ 4/6 < 1, убывание с k = 0.
- **cos:** x²/((2k + 1)(2k + 2)) ≤ 4/12 при k ≥ 1; первый член используется только в S₀, а брекет берётся при K − 1 ≥ 1. Верно.
- **Границы на [a, b]:**
  - sin вогнут и ≥ 0 на [0, π] ⊇ [0, 2], поэтому min ≥ max(0, min(sin a, sin b));
  - max = sin b, если b ≤ π/2 — доказано целым сравнением 2b ≤ π_lo; иначе max ≤ 1;
  - в пути B cos убывает на [0, π/2], проверка 2b ≤ π_lo обязательна (иначе ValueError).

  Верно.
- **Оракул:** 614 точечных вычислений sin и cos при bits = 3…160, включая A = 0, 1, x = 2, x ≈ π/2 и случайные точки в [0, 2] — нарушений 0.

**П5. √(2/n) = √(2n)/n.** r = isqrt(2n·4^W): r ≤ √(2n)2^W < r + 1, деление на n с floor/ceil; при r² = 2n·4^W — точно (n = 2, 8, 18, 32, 50, 128, 512, …). Оракул: n = 2…3000, bits = 8 и 160 — нарушений 0.

**П6. Ψ.** c, s ≥ 0, поэтому [c_lo s_lo, c_hi s_hi] содержит cs; floor/ceil к 2^−W; знак точен. Оракул: все элементы Ψ_ik при n = 2, 3, 4, 7, 16, 32, 64, 100 и bits = 12, 160 — нарушений 0. Ψ_ik = Ψ_ki — тождественно одинаковые интервалы.

**П7. DST.**
- x_k = X_k·2^E (`as_integer_ratio`, знаменатель — степень двойки) — точно.
- y_i ∈ [Σ min(L X, H X), Σ max(…)]·2^{E−W}: знак X_k выбирает границу. Это точная оболочка, поскольку члены независимы.
- **Оракул (DST в 120 знаках):** 42 вектора при n = 3…64 — нарушений 0. В их числе:
  - случайные;
  - отрицательные с порядками 10^{±300};
  - субнормальные ±5·10⁻³²⁴;
  - ψ₁ (y ≈ e₁, остальные ≈ 0 — сильное уничтожение);
  - знакопеременные единицы;
  - нулевой вектор;
  - e_m.

**П8. Сравнение.**
- e_i ∈ [ŷ_i − hi_i, ŷ_i − lo_i]; |e_i| ∈ [0 или min, max].
- 2-нормы: isqrt-границы точных целых.
- Отношения [lo₁/hi₂, hi₁/lo₂]; знаменатель, интервал которого содержит 0, даёт UNRESOLVED.
- Перевод в double — направленный.
- log₂n: 2^{b−1} ≤ n^K < 2^b ⇒ log₂n ∈ [(b − 1)/K, b/K].
- **Оракул:** абсолютная и относительная ошибка SciPy и отношение err/(u·log₂n·‖x‖) лежат в интервалах модуля на всех 42 векторах.

## 3. Реализация

- **Нормировка.** Оракул: SciPy DST-I `norm="ortho"` совпадает с √(2/n)Σ x_k sin(πik/n) при n = 3, 8, 33, разность 1,9·10⁻¹⁶…4,0·10⁻¹⁶, то есть округление. `bc.dst` — тот же вызов. Эталон относится к принятому преобразованию.
- **Независимость.**
  - В функциях эталона (`_arctan_inv`, `pi_bounds`, `_series_at`, `_sin_interval`, `_reduce`, `sin_pi_rational`, `sqrt2n_bounds`, `psi_table`, `certified_dst`, `boundary_psi`, `mu_bounds`, `orthogonality_check`) нет `math.sin`, `math.pi`, NumPy- и SciPy-источников значений (тест + чтение кода). Используются только `math.isqrt`, а также `math.floor` / `math.ceil` на рациональных числах — это точные операции.
  - `math.pi`, `np.sin` встречаются только в `double_boundary_diagnostics` (проверяемая double-формула) и в `compare` через проверяемый результат.
- **Граничные и особые входы.**

  | Вход | Поведение |
  |---|---|
  | нулевой вектор | точные нулевые интервалы; относительная ошибка, разрешение и c_DST-отношение — UNRESOLVED |
  | −x | точно отражённые интервалы |
  | float32, целые, NaN, ±∞, 2-D, пустой | `ValueError` |
  | субнормальные входы | интервалы верны; см. Н-1 |
- **Наружное округление.** Все переходы масштаба — floor для нижних границ и ceil для верхних (`>>`, `//`, `−(−a // b)`). Перевод в double: `_down` / `_up` с шагом `nextafter`. Печать — `decimal_up` / `decimal_down` модуля Q1b.
- **Величины Е-4** (оракул, n = 3, 4, 7, 16, 64):
  - ψ_k(1), ψ_k(m), ψ_k(1)², ψ_k(1)ψ_k(m), ψ_k(m)² и μ_k = (4/h²)sin²(kπ/(2n)) при h = l/n точно — нарушений 0;
  - ψ_k(m) = (−1)^{k+1}ψ_k(1) — точно.
- **Разложение ошибки double ψ_k(1).**
  - Тождество Ψ̂ − Ψ = (ĉ − c)sin t + ĉ(sin t̂ − sin t) + ĉ(ŝ − sin t̂) + (Ψ̂ − ĉŝ) верно алгебраически.
  - По оракулу каждая часть (нормировка, аргумент, sin) и полная ошибка, а также t̂ − t лежат в интервалах модуля.
  - Формула совпадает с `solve_bc`: `math.sqrt(2.0/n) * np.sin(k*math.pi/n)`.
- **Статусы и правило 1/100.** Случайный вектор n = 32, bits = 8…80:

  | bits | статус |
  |---|---|
  | 8…64 | UNRESOLVED |
  | 80 | RESOLVED |

  - Статус в каждом случае совпадает с заявленным правилом: ширина ≤ (1/100)·нижняя граница ошибки при ненулевой нижней границе.
  - Интервал ошибки при малой разрядности **содержит** интервал при 160 битах во всех случаях: ложного сертификата нет.
  - При bits = 60, 64 нижняя граница ошибки уже положительна, но правило не выполнено — UNRESOLVED.
- **Ресурсы.** (n − 1)² > `max_entries` (n = 1102 при умолчании 1100²) и `time_limit = 0` дают UNRESOLVED_RESOURCES; n = 1101 проходит.
- **Стоимость** (один вектор, Windows, без кэша таблицы):

  | n | таблица | DST |
  |---|---|---|
  | 128 | 0,001 с | 0,005 с |
  | 256 | 0,003 с | 0,021 с |
  | 512 | 0,006 с | 0,087 с |

  Согласуется с отчётом QA. Рост квадратичный.
