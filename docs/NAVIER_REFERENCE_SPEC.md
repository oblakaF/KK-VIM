## 1. Назначение независимого эталона

- Эталон Навье — **проверочная постановка SSSS** по D-024: аналитическое решение той же двумерной задачи
  Кирхгофа–Лява, с которым на этапе R2 сравнивается приближение КК-МВИ (N = 1, квадрат, SSSS; ROADMAP R2).
- По D-025 эталон служит двум разным целям, которые оформляются раздельно:
  - **верификация реализации КК-МВИ** — не служит: КК-МВИ при конечных N, k не обязан совпадать с точным
    решением (ВЫВОД ПРОЕКТА на основе D-025);
  - **исследование точности КК-МВИ** — эталон даёт «точное» значение двумерной задачи, относительно которого
    измеряется отличие приближения при данных N, k и сетке.
- Эталон должен быть **математически независим**: использует только формулы L-107 (раздел 4) и собственные
  преобразования проекта, не использует разностные схемы, интегрирование коэффициентов и иные элементы КК-МВИ.
- Эталон должен быть **программно независим** (D-015, D-028, AGENTS.md раздел 4): будущая реализация —
  в `src/kkvim_reference/`; импорты `kkvim_reference → kkvim` и `kkvim → kkvim_reference` запрещены.
  Эталон не вызывает решатель КК-МВИ ни прямо, ни косвенно.
- Собственная правильность эталона проверяется отдельно (раздел 9) до использования в R2.

## 3. Уравнение и граничные условия

**Жёсткость (НАПЕЧАТАНО, с. 16, ф-ла (3)):**

$$\frac{Eh^3}{12(1-\nu^2)} = D, \qquad (3)$$

названа «жесткостью пластинки при изгибе»; h — полная толщина (с. 15).

**Дифференциальное уравнение изогнутой поверхности (НАПЕЧАТАНО, с. 99, (103)–(105)):**

$$\frac{\partial^4 w}{\partial x^4} + 2\frac{\partial^4 w}{\partial x^2\,\partial y^2} + \frac{\partial^4 w}{\partial y^4} = \frac{q}{D}, \qquad (103)$$

$$\Delta\Delta w = \frac{q}{D}, \qquad (104) \qquad\qquad \Delta w = \frac{\partial^2 w}{\partial x^2} + \frac{\partial^2 w}{\partial y^2}. \qquad (105)$$

**Моменты (НАПЕЧАТАНО, с. 98, (101), (102)):**

$$M_x = -D\left(\frac{\partial^2 w}{\partial x^2} + \nu\frac{\partial^2 w}{\partial y^2}\right),\qquad M_y = -D\left(\frac{\partial^2 w}{\partial y^2} + \nu\frac{\partial^2 w}{\partial x^2}\right), \qquad (101)$$

$$M_{xy} = -M_{yx} = D(1-\nu)\frac{\partial^2 w}{\partial x\,\partial y}. \qquad (102)$$

**Граничные условия свободно опертого края (НАПЕЧАТАНО, с. 100, (110), (111)):** для края x = a

$$(w)_{x=a} = 0,\qquad \left(\frac{\partial^2 w}{\partial x^2} + \nu\frac{\partial^2 w}{\partial y^2}\right)_{x=a} = 0, \qquad (110)$$

что при w = 0 вдоль края равносильно

$$(w)_{x=a} = 0,\qquad (\Delta w)_{x=a} = 0, \qquad (111)$$

«не содержащим коэффициента Пуассона ν» (с. 100).

**SSSS для прямоугольника (НАПЕЧАТАНО, с. 124, (c)):**
(1) w = 0, (2) ∂²w/∂x² = 0 при x = 0 и x = a; (3) w = 0, (4) ∂²w/∂y² = 0 при y = 0 и y = b.

## 4. Двойной ряд Навье

**Общий случай (НАПЕЧАТАНО, § 28, с. 128–129):**

- нагрузка q = f(x, y) — (a), с. 128;
- разложение нагрузки:
  $$f(x,y) = \sum_{m=1}^{\infty}\sum_{n=1}^{\infty} a_{mn}\sin\frac{m\pi x}{a}\sin\frac{n\pi y}{b}; \qquad (128)$$
- коэффициенты:
  $$a_{m'n'} = \frac{4}{ab}\int_0^a\!\!\int_0^b f(x,y)\sin\frac{m'\pi x}{a}\sin\frac{n'\pi y}{b}\,dx\,dy; \qquad (129)$$
- прогиб:
  $$w = \frac{1}{\pi^4 D}\sum_{m=1}^{\infty}\sum_{n=1}^{\infty}\frac{a_{mn}}{\left(\frac{m^2}{a^2}+\frac{n^2}{b^2}\right)^2}\sin\frac{m\pi x}{a}\sin\frac{n\pi y}{b}. \qquad (130)$$

**Равномерная нагрузка f(x, y) = q₀ (НАПЕЧАТАНО, с. 129):**

$$a_{mn} = \frac{4q_0}{ab}\int_0^a\!\!\int_0^b \sin\frac{m\pi x}{a}\sin\frac{n\pi y}{b}\,dx\,dy = \frac{16q_0}{\pi^2 mn}, \qquad (c)$$

«где m и n — нечетные целые числа. Если m или n по отдельности или оба вместе числа четные, то a_mn
обращается в нуль» (с. 129).

## 5. Формулы прогиба и моментов

**Прогиб (НАПЕЧАТАНО, с. 129, (131)):**

$$w = \frac{16q_0}{\pi^6 D}\sum_{m=1}^{\infty}\sum_{n=1}^{\infty}\frac{\sin\frac{m\pi x}{a}\sin\frac{n\pi y}{b}}{mn\left(\frac{m^2}{a^2}+\frac{n^2}{b^2}\right)^2}, \qquad m = 1, 3, 5,\dots;\ n = 1, 3, 5,\dots \qquad (131)$$

**Максимальный прогиб (НАПЕЧАТАНО, с. 129–130, (132)).** «Под равномерной нагрузкой поверхность прогибов
получится симметричной относительно осей x = a/2 и y = b/2 … Максимальный прогиб пластинки получится
в центре и определится подстановкой x = a/2, y = b/2 в формулу (131)»:

$$w_{\max} = \frac{16q_0}{\pi^6 D}\sum_{m=1}^{\infty}\sum_{n=1}^{\infty}\frac{(-1)^{\frac{m+n}{2}-1}}{mn\left(\frac{m^2}{a^2}+\frac{n^2}{b^2}\right)^2}. \qquad (132)$$

Первый член для квадрата (НАПЕЧАТАНО, с. 130): w_max = 4q₀a⁴/(π⁶D) = 0,00416 q₀a⁴/D; при ν = 0,3
w_max = 0,0454 q₀a⁴/(Eh³); «Погрешность этого результата составляет около 2½% (см. табл. 8 на стр. 143)».

**Координаты максимума.** НАПЕЧАТАНО: центр (a/2, b/2) — по симметрии (с. 129–130). ВЫВОД ПРОЕКТА:
для проверки реализации положение максимума устанавливается не допущением, а сравнением значений в центре
с соседними точками сетки (раздел 9, П-5); сам максимум для эталона — значение (132).

**Моменты.** В L-107 ряды Навье для M_x, M_y при равномерной нагрузке **НЕ НАПЕЧАТАНЫ**. Напечатано
(с. 130): «Выражения для изгибающего и крутящего моментов могут быть получены из общего решения (131)
с помощью уравнений (101) и (102). Полученные при этом ряды сходятся не так быстро, как ряд (131)».

ВЫВОД ПРОЕКТА — почленное применение (101) к (131) (законно: ряд вторых производных сходится абсолютно,
раздел 8.3):

$$M_x = \frac{16q_0}{\pi^4}\sum_{m,n\ \text{нечёт}}\frac{\frac{m^2}{a^2}+\nu\frac{n^2}{b^2}}{mn\left(\frac{m^2}{a^2}+\frac{n^2}{b^2}\right)^2}\sin\frac{m\pi x}{a}\sin\frac{n\pi y}{b},$$

$$M_y = \frac{16q_0}{\pi^4}\sum_{m,n\ \text{нечёт}}\frac{\nu\frac{m^2}{a^2}+\frac{n^2}{b^2}}{mn\left(\frac{m^2}{a^2}+\frac{n^2}{b^2}\right)^2}\sin\frac{m\pi x}{a}\sin\frac{n\pi y}{b}.$$

Проверка структуры (ВЫВОД ПРОЕКТА): при одном члене m = n = 1 эти формулы совпадают со структурой
напечатанных выражений для синусоидальной нагрузки (f), с. 125, после замены q₀ → a₁₁ = 16q₀/π².

Для квадрата (ВЫВОД ПРОЕКТА): в центре по симметрии m ↔ n суммы при m² и n² равны, поэтому
M_x(центр) = M_y(центр) = (1 + ν)·C(a), где C не зависит от ν. Следовательно, коэффициент β = β₁ квадрата
пропорционален (1 + ν).

Знаки (НАПЕЧАТАНО, рис. 48, с. 97; рис. 63, с. 138): ось z и нагрузка — вниз; при q₀ > 0 прогиб w > 0;
в центре M_x, M_y > 0 (на рис. 63 — 0,0479qa²).

## 8. Усечение ряда и критерии сходимости

Всё в этом разделе — **ВЫВОД ПРОЕКТА**; требует проверки Reviewer и утверждения владельцем.

### 8.1. Индексы и пределы

- Присутствуют только нечётные m, n (с. 129). Чётные индексы не суммируются: они не нулевые малые,
  а точно нулевые.
- Квадратное усечение: m, n ∈ {1, 3, …, M}, M нечётно, одно и то же M для w, M_x, M_y.
- Последовательность уровней: M ∈ {1, 3, 9, 19, 39, 79, 159, 319, 639, 1279, …} — шаг по M примерно вдвое.
  Уровень M = 1 — контроль формулы (должно получиться 4/π⁶ = 0,00416 для квадрата, с. 130).
- Для квадратного усечения множество индексов симметрично по m ↔ n; на этом основаны проверки симметрии
  и ν-зависимости моментов центра (8.5, П-9). При несимметричном усечении они не гарантируются.

### 8.2. Строгая оценка остатка прогиба (квадрат)

Член ряда (131) по модулю не больше 1/(mn(m² + n²)²). Так как m² + n² ≥ 2mn, получаем
1/(mn(m² + n²)²) ≤ 1/(4m³n³). Остаток квадратного усечения — члены с m > M или n > M. Отсюда равномерно
по (x, y):

$$\left|w - w_M\right| \le \frac{16q a^4}{\pi^6 D}\cdot\frac{\lambda_3}{8M^2},\qquad \lambda_3=\sum_{n\ \text{нечёт}} n^{-3} = \tfrac{7}{8}\zeta(3) \approx 1{,}05180.$$

Здесь использовано Σ_{m>M, нечёт} m⁻³ ≤ ½∫_M^∞ t⁻³dt = 1/(4M²) (для убывающей f каждый член с шагом 2
не больше ½∫ по соседнему интервалу). Коэффициент (16/π⁶)·λ₃/8 = 0,0021881. Числа на уровнях 8.1:
M = 79 — ≤ 3,5·10⁻⁷ qa⁴/D; M = 159 — ≤ 8,7·10⁻⁸; M = 639 — ≤ 5,4·10⁻⁹; M = 1279 — ≤ 1,3·10⁻⁹ qa⁴/D.

**Это консервативная достаточная граница, а не реально необходимое число членов:** знакопеременность
в центре, |sin| < 1 и грубое неравенство (m² + n²)² ≥ 4m²n² не учтены.

**Порог для δ_w (разд. 8.6).** Условие 0,0021881/M² ≤ δ_w = 4,06·10⁻⁹ даёт M ≥ 734,1, то есть для нечётных M —
**M ≥ 735** (достаточно по этой оценке). В последовательности уровней 8.1 первый уровень, удовлетворяющий
условию, — **M = 1279**.

**Уточнённая граница прогиба (ВЫВОД ПРОЕКТА; предложена независимой рецензией, шаги проверены QA, требует
адресной перепроверки Reviewer).** Для фиксированного нечётного n:
Σ_m 1/(m(m² + n²)²) ≤ Σ_{m≤n} 1/(mn⁴) + Σ_{m>n} m⁻⁵ ≤ (ln n + 1)/n⁴ + 1/(4n⁴) = (ln n + 1,25)/n⁴;
умножение на 1/n и сумма по нечётным n > M для двух «полос» (m > M или n > M) с той же оценкой через интеграл
(функция (ln t + 1,25)/t⁵ убывает при t ≥ 1) дают

$$\left|w - w_M\right| \le \frac{16 q a^4}{\pi^6 D}\left[\frac{\ln M + 1{,}25}{4M^4} + \frac{1}{16M^4}\right] = O\!\left(\frac{\ln M}{M^4}\right).$$

По ней δ_w достигается при нечётном **M ≥ 49** (первый уровень 8.1 — M = 79). Пока Reviewer не подтвердит
эту границу, основанием выбора M остаётся консервативная оценка выше.

### 8.3. Строгая оценка остатка моментов (квадрат, 0 ≤ ν ≤ 1)

Член ряда M_x (или M_y) по модулю не больше (m² + n²)/(mn(m² + n²)²) = 1/(mn(m² + n²)) ≤ 1/(2m²n²). Отсюда

$$\left|M - M_M\right| \le \frac{16 q a^2}{\pi^4}\cdot\frac{\lambda_2}{2M},\qquad \lambda_2 = \sum_{n\ \text{нечёт}} n^{-2} = \frac{\pi^2}{8},$$

то есть ≤ (16qa²/π⁴)·π²/(16M) = 1/(π²M) ≈ 0,1013 qa²/M. Ряды моментов сходятся абсолютно; эта
**конкретная** мажоранта убывает лишь как 1/M (M = 1279 даёт ≤ 7,9·10⁻⁵ qa²; для δ_M = 4,79·10⁻⁶ qa² нужно
M ≥ 2,1·10⁴), потому что неравенство 1/(mn(m² + n²)) ≤ 1/(2m²n²) сильно завышает члены при m ≪ n.
Непрактична **выбранная мажоранта**, а не строгая оценка моментов вообще.

**Уточнённая граница моментов (ВЫВОД ПРОЕКТА; предложена независимой рецензией, шаги проверены QA, требует
адресной перепроверки Reviewer).** При 0 ≤ ν ≤ 1 член по модулю ≤ 1/(mn(m² + n²)). Для фиксированного n:
Σ_m 1/(m(m² + n²)) ≤ Σ_{m≤n} 1/(mn²) + Σ_{m>n} m⁻³ ≤ (ln n + 1)/n² + 1/(2n²) = (ln n + 1,5)/n²;
умножение на 1/n, сумма по нечётным n > M для двух «полос» и сравнение с интегралом (функция (ln t + 1,5)/t³
убывает при t ≥ 1; ∫_M^∞ (ln t + 1,5)t⁻³dt = (ln M + 2)/(2M²)) дают

$$\left|M - M_M\right| \le \frac{16 q a^2}{\pi^4}\cdot\frac{\ln M + 2}{2M^2} \approx 0{,}0821\,\frac{\ln M + 2}{M^2}\,qa^2 = O\!\left(\frac{\ln M}{M^2}\right).$$

По ней δ_M = 4,79·10⁻⁶ qa² достигается при нечётном **M ≥ 369** (первый уровень 8.1 — M = 639). До
подтверждения Reviewer эта граница — **предложение**, а не доказанное свойство спецификации; основанием
приёмки уровня M для моментов остаётся практический контроль 8.4 вместе с грубой оценкой выше.

### 8.4. Практический контроль сходимости (отдельно для w, M_x, M_y)

Для каждой величины Q ∈ {w, M_x, M_y} в каждой контрольной точке:

1. вычислить Q(M_j) на последовательных уровнях 8.1;
2. Δ_j = |Q(M_j) − Q(M_{j−1})| — **абсолютная** разность в единицах qa⁴/D (для w) или qa² (для моментов);
3. уровень принимается, если на трёх последних уровнях Δ убывает монотонно и Δ_j ≤ δ_Q/10, где δ_Q —
   абсолютный допуск точности эталона (8.6) в тех же единицах;
4. для w дополнительно обязательна строгая оценка 8.2 ≤ δ_w;
5. фиксируется отношение Δ_{j−1}/Δ_j. По грубым мажорантам ожидается рост с удвоением M не медленнее ~4
   для w (O(M⁻²)) и ~2 для моментов (O(M⁻¹)); по уточнённым — заметно быстрее. Это ориентир, а не критерий
   приёмки.

**Ограничения практического контроля:** малость Δ не доказывает малость остатка (медленно сходящийся или
знакопеременный ряд может иметь малые приращения при заметном остатке); именно поэтому для w требуется
строгая граница, а для моментов допуски выбираются с запасом.

### 8.5. Как отличить ошибку усечения от ошибки реализации

| Признак | Ошибка усечения | Ошибка реализации |
|---|---|---|
| Уровень M = 1 для квадрата | даёт ровно 4/π⁶ = 0,0041606 qa⁴/D (с. 130) | отличие при M = 1 (неверный коэффициент, π, знак) |
| Зависимость от M | монотонно убывающие Δ, порядок 8.4 | скачки, рост Δ, зависимость от чётности, ненулевой вклад чётных индексов |
| Предел при росте M | совпадение с 0,00406 в пределах τ_tab (8.6) | систематическое отличие, не убывающее с M |
