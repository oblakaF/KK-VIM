   Это не нормативная константа. P-2/P-3 в этом пути не проверяются (Н-3 `adf4877`).
6. **D2-9:** кандидат ≤ 4u для double-применения оператора не квалифицирован.
7. **Хенки–Инглис (A) и Ритц (B)** сохраняют ограничения точности и независимости (D-049.8, п. 2; аудит `5b384a1`):
   - A без строгой оценки ошибки — OBSERVATION / UNRESOLVED;
   - центр B — OBSERVATION; работа Ритца — односторонняя граница;
   - B независим по процедуре, но не по функционалу;
   - C — контрольные значения, не допуски; при r = 3, 5 — один источник L-058;
   - D2 независим по коду, но не по дискретизации (D1 = D2); e_D2 — оценка, а не строгий бюджет;
   - внешние данные D2 — UNVERIFIED_EXTERNAL_NUMERICAL_EVIDENCE до QA-C2 (D-049.0, п. 5).
8. **Независимость исполнителей при проверке DST-I ограничена.** Автор DST-I, Reviewer `9f30a5d` и Auditor `04cf548` — исполнитель
   одного типа (Claude). Это раскрыто в рецензии и аудите; совпадение логики уменьшено внешним оракулом `mpmath` вне git. Повторная
   проверка другим исполнителем — по решению владельца.
