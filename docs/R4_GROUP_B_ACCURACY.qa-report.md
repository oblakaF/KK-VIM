## 1. Три поля и разложение ошибки

| Обозначение | Что это | Чем вычислено |
|---|---|---|
| w_h^(N,s) | дискретная N-членная последовательность КК-МВИ (дискретизация проекта, уровень Б) | QA-контроль `r4_spectral_control`: тот же алгоритм, что `run_control`, но только со спектральными данными (совпадение с `run_control` — побитовое, `meta.json`) |
| w_cont^(N,s) | непрерывная N-членная последовательность КК-МВИ | матричная рекурсия Парсеваля (R4_NUMERICAL_SPEC 9.2); нечётные индексы ≤ 4001 по каждой оси (2001 мода) |
| ω₀ | точное решение пластины SSSS, q = const | Леви: центр — (140), поле — (139); энергия Π(ω₀) — `r4_energy_reference` |
| ω_h | точное решение полной двумерной дискретной задачи (без ограничения на N) | замкнутая спектральная форма `SpectralGrid.w_star` |

E_disc = w_h − w_cont (дискретизация КК-МВИ), E_method = w_cont − ω₀ (ошибка метода при тех же N и s),
E_total = w_h − ω₀ = E_disc + E_method. Отдельно от них ω_h − ω₀ — ошибка полной двумерной дискретизации.

- **ω_h − ω₀ ≠ E_disc:** это разные задачи (разд. 6.3).
- **Знаки** сохраняются: δ = (w − ω₀)/ω₀ в точке, с одним знаменателем ω₀ в этой точке.
- **Нормы не складываются** как равенство: в нормах возможна компенсация.

## 2. Энергетическая ошибка, бюджеты и два статуса

### 2.1. Определения и два пути вычисления

**Определения** (MATH_SPEC Б.13, В-23):
- err_abs² = ‖w_cont − ω₀‖²_{H_T} = 2[Π(w_cont) − Π(ω₀)];
- e_rel = err_abs²/‖ω₀‖²_{H_T} = [Π(w_cont) − Π(ω₀)]/[−Π(ω₀)] — **относительная квадратичная** ошибка;
- √e_rel = err_abs/‖ω₀‖_{H_T} — **относительная ошибка в энергетической норме**.

Предпосылки В-23 (q = const, SSSS, Π(ω₀) < 0) выполнены во всех расчётах. Ниже указываются обе величины, e_rel и √e_rel, без смешения.

**Путь E** — разность энергий Π(w_cont) − Π(ω₀).

**Путь D** — собственный вывод проекта, уровень Б:
- по В-9 ‖v‖_{H_T} = D^{1/2}‖Δv‖, по Парсевалю ‖v‖²_{H_T} = D(ab/4)π⁴ Σ λ_mn v_mn², где λ_mn = (m²/a² + n²/b²)²;
- применяется к v = w_cont − ω₀: сумма неотрицательных членов, без вычитания близких энергий.

**Пути D и E используют одни и те же массивы коэффициентов рекурсии.** Их согласие (`route_E_minus_D_over_budget_E` ≤ 0,07) проверяет только
вычисление нормы — отсутствие потери точности при вычитании энергий. Независимой квалификацией самой рекурсии оно **не является**.

**Усечённая рекурсия — собственный вывод.**
- При заданном наборе энергия полушага распадается по модам вычисляемой функции. Поэтому усечение по индексам ≤ M — точный полушаг задачи,
  ограниченной синусами с нечётными индексами ≤ M.
- Вычисленная w_cont — точная последовательность КК-МВИ этой **конечной спектральной задачи** и элемент H_T (подтверждено рецензией, разд. 3, ответ 1).
- Расстояние до **неусечённой** w_cont строгой оценкой при s ≥ 2 не ограничено (Q-022).

## 4. Энергетическая монотонность (ВБ-17) на вычисленной последовательности (T3)

Для точных полушагов ВБ-17 даёт:
- Π(w^(s)) ≤ Π(w^(s−1));
- err_abs(N, s) ≤ err_abs(N, s − 1);
- тождество Пифагора err²(s − 1) = err²(s) + ‖w_s − w_{s−1}‖²_{H_T}.

Усечённая рекурсия — точная последовательность конечной задачи (разд. 2.1), поэтому эти утверждения проверяемы на ней дословно.

**5.2. Объяснение и наблюдение — не доказательство.**
4. С s = 3 Y-полушаг использует новый смешанный набор X². Строки L получают ошибку, а общая энергетическая ошибка убывает (ВБ-17;

6. **Компенсация.** Вклады разных мод имеют разные знаки и могут компенсироваться. Универсального доминирования низких мод **нет**:

## 7. B-4: различимость ошибки метода и ошибки сетки (T6)

**Критерий различимости:** ошибка метода различима на сетке в данной мере, если |E_disc| ≤ |E_method|/100 в **той же** мере (принцип 1/100).
- Он применён к центру и к E_∞, где E_disc вычислена непосредственно.
- Требуемое n оценено по наблюдаемому закону h² с наилучшей сетки: n_f·(|E_disc(n_f)|/(0,01|E_method|))^{1/2}.
- Это исследовательская оценка, не требование.

| E_∞ (выборка 65², узлы сетки) | n ≈ 460–1560 | n ≈ 1500–5930 |

**Согласие e_rel,h с e_rel (1 %)** — отдельная диагностическая мера (И-4):

|---|---|---|
| \|e_rel,h − e_rel\|/e_rel ≤ 1 % | n ≈ 100–260 | n ≈ 190–520 |

- Эта величина показывает **согласие двух квадратичных энергетических ошибок**: дискретной (относительно ω_h) и непрерывной (относительно ω₀).
- Она **не равна** ‖w_h^(N,s) − w_cont^(N,s)‖_{H_T}.
- Она **не является** отношением нормы ошибки дискретизации к норме ошибки метода.
- Энергетическая норма E_disc **не вычислялась**, и энергетическая различимость в смысле критерия выше **не установлена**.
- Значения n ≈ 100–520 — только значения этой диагностической меры, а не нормативная энергетическая различимость.

**Сопоставление с оценкой задания** (N = 3, r = 1, центр, s = 10, n ≈ 1800):
- прямой расчёт на 1280 даёт |δ_c disc|/|δ_c method| = 1,9 % (при 640 — 7,6 %);
- по закону h² 1 % достигается при n ≈ 1760;
- оценка подтверждается по E_disc N-членного метода, а не по ω_h − ω₀;
- как правило D-048 она не вводится.

**Вывод B-4.**
