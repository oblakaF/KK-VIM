## 1. Три поля и разложение ошибки

| Обозначение | Что это | Чем вычислено |
|---|---|---|
| w_h^(N,s) | дискретная N-членная последовательность КК-МВИ (дискретизация проекта, уровень Б) | QA-контроль `r4_spectral_control`: тот же алгоритм, что `run_control`, но только со спектральными данными (совпадение с `run_control` — побитовое, `meta.json`) |
| w_cont^(N,s) | непрерывная N-членная последовательность КК-МВИ | матричная рекурсия Парсеваля (R4_NUMERICAL_SPEC 9.2), M = 4001 нечётных мод по каждой оси |
| ω₀ | точное решение пластины SSSS, q = const | Леви: центр — (140), поле — (139); энергия Π(ω₀) — `r4_energy_reference` |
| ω_h | точное решение полной двумерной дискретной задачи (без ограничения на N) | замкнутая спектральная форма `SpectralGrid.w_star` |

E_disc = w_h − w_cont (дискретизация КК-МВИ), E_method = w_cont − ω₀ (ошибка метода при тех же N и s),
E_total = w_h − ω₀ = E_disc + E_method. Отдельно от них ω_h − ω₀ — ошибка полной двумерной дискретизации.

- **ω_h − ω₀ ≠ E_disc:** это разные задачи, их совпадение не предполагается (разд. 6.3).
- **Знаки** сохраняются: δ = (w − ω₀)/ω₀ в точке, с одним знаменателем ω₀ в этой точке.
- **Нормы не складываются** как равенство: в нормах возможна компенсация.

**Правило 1/100 (D-046).** Бюджет эталонов не больше 1/100 измеряемой величины в той же относительной норме; иначе сравнение — UNRESOLVED.
Статусы RESOLVED / UNRESOLVED ниже означают только это.

## 2. Энергетическая ошибка: два способа вычисления и бюджеты эталонов

**Определения** (MATH_SPEC Б.13, В-23):
- err_abs² = ‖w_cont − ω₀‖²_{H_T} = 2[Π(w_cont) − Π(ω₀)];
- e_rel = err_abs²/‖ω₀‖²_{H_T} = [Π(w_cont) − Π(ω₀)]/[−Π(ω₀)].

Предпосылки В-23 (q = const, SSSS, Π(ω₀) < 0) выполнены во всех расчётах.

**Путь E — разность энергий.** Бюджет состоит из трёх частей, указанных отдельно:
- **Π(ω₀):**
  - строгий хвост (a⁴ + b⁴)π²/(80M⁵) при M = 4001;
  - счёт округления ≤ 24u (`r4_energy_reference`, предквалификация разд. 7);
  - итого ≈ 2,7·10⁻¹⁵ относительно.
- **Π(w_cont) — округление:** модель первого порядка ≤ 36u·S_abs, где S_abs — сумма модулей слагаемых (`energy_rounding_model`, MODEL).
  Фактическая ошибка по 40-значному пересчёту тех же массивов ≤ 7,7·10⁻¹⁶·|Π|, модель — 1,2·10⁻¹⁴ (T10).
- **Π(w_cont) — усечение рекурсии:** |Π_{M=4001} − Π_{M=8001}| — диагностика, не доказательство.

**Путь D — собственный вывод проекта (уровень Б).**
- По В-9 ‖v‖_{H_T} = D^{1/2}‖Δv‖. Для v = Σ v_mn sin(mπx/a) sin(nπy/b) по Парсевалю
  ‖v‖²_{H_T} = D(ab/4)π⁴ Σ λ_mn v_mn², где λ_mn = (m²/a² + n²/b²)².
- Применяется к v = w_cont − ω₀: это сумма **неотрицательных** членов, вычитания двух близких энергий нет.
- Вне вычисленного блока (m или n > M) w_cont коэффициентов не имеет. Часть ω₀ там строго ограничена хвостом энергии:
  (64q²ab/(π⁸D))·(a⁴ + b⁴)π²/(80M⁵).
- Бюджет пути D: этот хвост, модель округления разностей коэффициентов (`direct_rounding`) и удвоение M.

**Усечённая рекурсия как эталон — собственный вывод.**
- При заданном наборе энергия полушага распадается по модам вычисляемой функции, поэтому усечение по n ≤ M — точный полушаг
  задачи, ограниченной синусами ≤ M.
- Значит, w_cont с M модами — точная последовательность КК-МВИ этой ограниченной задачи и элемент H_T. Его Π и ‖·‖_{H_T} вычисляются без ошибки усечения.
- Расстояние до неусечённой w_cont — это усечение эталона. Оно оценивается удвоением M (диагностика). Перенос ошибок по s строго не оценён (Q-022).

## 4. Энергетическая монотонность (ВБ-17) на вычисленной последовательности (T3)

Для точных полушагов и выполненных предпосылок ВБ-17:
- Π(w^(s)) ≤ Π(w^(s−1));
- err_abs(N, s) ≤ err_abs(N, s − 1);
- выполняется тождество err²(s − 1) = err²(s) + ‖w_s − w_{s−1}‖²_{H_T} (теорема Пифагора, Б.12).

Усечённая рекурсия — точная последовательность КК-МВИ ограниченной задачи (разд. 2), поэтому эти утверждения проверяемы на ней дословно.

| Проверка (s = 2…40, N = 2, 3, все 10 r) | Результат |
|---|---|
| \|err²(s−1) − err²(s) − ‖Δw‖²\|/err² (дефект Пифагора) | ≤ 3,1·10⁻¹⁵ |
| min (err²(s−1) − err²(s))/err² | ≥ −3,0·10⁻¹⁵ (только на шагах, где Δw — шум) |
| нарушений монотонности сверх шума (шум поля ε_rec = 5,8·10⁻¹⁶ по T10; допуск 2ε_rec/√e_rel) | **0** из 780 шагов |
| последнее s, где ‖Δw‖/‖w‖ > 100·ε_rec | 12–13 (N = 2), 17–19 (N = 3) |
| ΔΠ_s < 0 по пути E (разность двух энергий в double) | до 16 шагов на (N, r) — все в пределах модели округления Π(w): 0 сверх модели |

**Вывод.** Энергетическая монотонность подтверждается численно как следствие вариационной постановки. Пока приращения поля различимы
(s ≲ 12–19), err_abs строго убывает, и тождество Пифагора выполнено до округления. Далее приращения неотличимы от шума, и монотонность
там численно не проверяема: это UNRESOLVED, а не нарушение.

Отрицательные ΔΠ по пути E — артефакт вычитания энергий: путь D их не даёт.

## 5. Почему ошибка центра может быть минимальной на s = 2 (T11)

Ошибка центра — один линейный функционал поля ошибки. Энергия убывает (разд. 4), но распределение ошибки по модам меняется.

Разложение δ_c по группам мод: x-моды L = {m ≤ 2N − 1} и H = {m > 2N − 1}, так же для y.

**Объяснение — собственный вывод проекта, уровень Б, проверяемый.**
1. При старте нечётными синусами w¹ = Σ_{m∈L} Σ_n w_mn φ_mn (ВБ-23). Поэтому Y¹_j пропорциональна строке m_j коэффициентов ω₀.
2. На s = 2 (X-полушаг) энергия ½‖X̃ ⊗ Y¹ − ω₀‖²_{H_T} в синусных коэффициентах диагональна (разд. 2) и распадается на независимые
   задачи по x-модам m: min Σ_n λ_mn(x̃_m · y¹_n − w_mn)².
3. Для m = m_j ∈ L строка w_{m_j,·} лежит в линейной оболочке {y¹} — минимум нулевой. Значит, **после s = 2 все строки m ≤ 2N − 1
   воспроизводятся точно** (численно: вклады LL, LH ~10⁻¹⁶). Ошибка остаётся только в высоких x-модах.
4. Начиная с s = 3, Y-полушаг использует новый смешанный набор X². Проекция уменьшает общую энергетическую ошибку
   (у N = 3: 3,38 → 2,47·10⁻⁸), но переносит часть ошибки (≈ 6 %, затем 11 %) в низкие моды LL.
5. В центре низкие моды весят больше всего (w_mn ~ 1/(mn(m² + n²)²) при единичных весах функционала), а в энергетической норме — меньше всего
   (вес λ_mn). Поэтому |δ_c| растёт при убывающей err_abs.

Следовательно, вывод «s = 2 лучше s = 10» по ошибке центра **неверен**: в энергетической норме s = 10 точнее (e_rel 2,40·10⁻⁸ против 3,38·10⁻⁸ при N = 3).
Немонотонность точечной ошибки — не нарушение ВБ-17 (R4_NUMERICAL_SPEC 9.4).

**Порядок.**
- Наблюдаемый порядок по сетке ≈ 2 на всех исследованных конфигурациях, в том числе при s ≥ 2. Все p ∈ [1,9; 2,1] — окно R2, используемое здесь
  только как исследовательский критерий асимптотичности.
- Это **наблюдение** на конечных цепочках. Общий второй порядок при s ≥ 2 **не доказан** (ЧВ4-7; D-046).

**Ричардсон** w_R = (4w_{2n} − w_n)/3 применён только к сеточной дискретизации при фиксированных N, s, r:
- на последней паре он уменьшает ошибку на 4–5 порядков (r = 1: с 7·10⁻⁸ до 10⁻¹²);
- прогноз E(4n) = E(2n)/4 подтверждён на следующей независимой сетке с точностью ≤ 1,6 %;
- оценка не строгая: остаток не обоснован;
- w_R эталоном не объявляется и к пределу по s или N не применяется.

### 6.3. Полная двумерная дискретная задача ω_h и ошибка дискретизации N-членного метода

| n (r = 1) | 40 | 80 | 160 | 320 | 640 | 1280 | 2560 |
|---|---|---|---|---|---|---|---|
| δ_c полной сетки (ω_h − ω₀) | −7,089·10⁻⁵ | −1,769·10⁻⁵ | −4,421·10⁻⁶ | −1,105·10⁻⁶ | **−2,762·10⁻⁷** | −6,906·10⁻⁸ | −1,727·10⁻⁸ |
| (Π_h(ω_h) − Π(ω₀))/\|Π(ω₀)\| | 1,04·10⁻³ | 2,60·10⁻⁴ | 6,49·10⁻⁵ | 1,62·10⁻⁵ | 4,05·10⁻⁶ | 1,01·10⁻⁶ | 2,53·10⁻⁷ |

Ориентир задания (−2,76·10⁻⁷ при n = 640, отношение ≈ 4 при удвоении) **воспроизведён**: −2,762·10⁻⁷, отношение 4,00.

**Это не ошибка дискретизации N-членного метода:**
- в центре при r = 1 δ_c disc близка к δ_c полной сетки, но отличается: на 13 % при s = 1, N = 2 (−3,135 против −2,762) и на 0,04–1 % при s ≥ 2;
- в точке (¼, ½) расхождение 19 % (N = 2);
- при r = 1/5 и 5 (семейство I) знаки обеих величин в центре положительны;
- оценивать E_disc по ω_h − ω₀ можно лишь как ориентир (R4_NUMERICAL_SPEC 9.4).

Различие дискретной Π_h и непрерывной Π оценено отдельно (строка выше): эти энергии не смешиваются. Энергетическая мера метода на сетке
e_rel,h = ‖w_h − ω_h‖²_h/‖ω_h‖²_h сравнивается с e_rel только как с пределом. Расхождение ведёт себя как h²: −0,25 при n = 40 и −9,4·10⁻⁴ при n = 640 (N = 3, s = 10).

## 7. B-4: различимость ошибки метода и ошибки сетки (T6)

**Критерий:** ошибка метода различима на сетке в данной мере, если |E_disc| ≤ |E_method|/100 в той же мере (принцип 1/100).
Требуемое n оценено по наблюдаемому закону h² с наилучшей сетки: n_f·(|E_disc(n_f)|/(0,01|E_method|))^{1/2}. Это **исследовательская оценка, не требование**.

| Мера | N = 2 (s = 2…10) | N = 3 (s = 2…10) |
|---|---|---|
| центр, r = 1 | n ≈ 550–760 | n ≈ 1760 (s = 10), ≈ 3660 (s = 2) |
| центр, r ∈ [1/3, 3] без 1 (сем. I) | n ≈ 575–1150 | n ≈ 1880–2100 (s = 10), 3760–9340 (s = 2) |

| E_∞ (выборка 65², узлы сетки) | n ≈ 460–1560 | n ≈ 1500–5930 |
| **энергия** (e_rel,h против e_rel) | n ≈ 100–260 | n ≈ 190–520 |

**Сопоставление с оценкой задания** (N = 3, r = 1, центр, s = 10, n ≈ 1800):
- прямой расчёт на 1280 даёт |δ_c disc|/|δ_c method| = 1,9 % (при 640 — 7,6 %);
- по закону h² 1 % достигается при n ≈ 1760;
- оценка задания подтверждается, но получена **по E_disc N-членного метода**, а не по ω_h − ω₀.

Как правило D-048 она не вводится.

**Главный вывод B-4.**
- Ошибку метода можно вычислять прямо из w_cont без сетки (разд. 3).
- Сетка нужна для дискретизационной составляющей фактического решателя.
- В энергетической норме эта составляющая различима уже на сетках 200–500. В точке центра при N = 3 нужны n ≳ 1800 (r = 1) и больше для r ≠ 1.

## 9. Ответы на вопросы задания

1. **Точность КК-МВИ в энергетической норме.** Относительная квадратичная ошибка e_rel = err_abs²/‖ω₀‖² (непрерывный метод):

   | N | r = 1, s = 1 | r = 1, s = 2 | r = 1, s ≥ 10 | диапазон по 10 r при s ≥ 10 |
   |---|---|---|---|---|
   | 2 | 3,0·10⁻⁴ | 1,1·10⁻⁶ | 1,05·10⁻⁶ | 3,3·10⁻⁷…1,05·10⁻⁶ |
   | 3 | 4,8·10⁻⁵ | 3,4·10⁻⁸ | 2,40·10⁻⁸ | 6,4·10⁻⁹…2,4·10⁻⁸ |

   Относительная энергетическая норма err_abs/‖ω₀‖ = √e_rel ≈ 1,0·10⁻³ (N = 2) и 1,5·10⁻⁴ (N = 3) при r = 1. Все значения RESOLVED.
2. **Энергетическая монотонность по s** подтверждается в пределах различимости. Нарушений сверх шума 0 на 780 шагах; тождество Пифагора — до 3·10⁻¹⁵.
   Дальше s ≈ 12–19 приращения неотличимы от шума: монотонность там UNRESOLVED (не нарушена).
3. **Минимум ошибки центра на s = 2.**
   - На s = 2 строки низких x-мод ω₀ воспроизводятся точно (собственный вывод, разд. 5).
   - С s = 3 энергетически оптимальная проекция переносит часть ошибки в низкие моды, которые доминируют в центре.
   - По энергии s = 10 точнее s = 2.
4. **Различимость ошибки метода.**
   - Непрерывная ошибка метода вычисляется без сетки (все RESOLVED).
   - На сетке энергетическая мера различима при n ≈ 100–520.
   - Центр при N = 3, r = 1, s = 10 — при n ≈ 1760 (оценка по h²; на 1280 — 1,9 %).
   - При r = 1/5, 5 и s = 2 центр практически неразличим.
5. **Порядок сеточной сходимости** — наблюдаемый p = 2,00 на последних парах всех цепочек (I и II), min 1,90 на грубых.
   Ричардсон согласован на следующей сетке (≤ 1,6 %). Доказательства второго порядка при s ≥ 2 нет.
6. **Где нужны более точные эталоны.**
   - В исследованной области (N = 2, 3, 10 r) используемые эталоны достаточны с запасом ≥ 2,5·10⁴ (центр), ≥ 3,7·10⁶ (E_∞) и ≥ 4·10⁵ (энергия, путь E).
   - Навье M = 2559 был бы недостаточен по энергии для N = 3 при r = 1/5, 5 (D-046) и по прогибу для N ≥ 3 (9.5.1).
   - Узкие места: высокоточная проверка рекурсии выполнена только при M ≤ 81; центр при N = 3, r = 1/5, s = 2 (δ_c ≈ −8,6·10⁻⁹) — бюджет 4·10⁻⁵, но мера вырождена.
7. **Сетки для будущей численной политики** — предложение, не норматив; D-048 — решение владельца:
   - энергетическая мера: n_x = n_y ≥ 320 (N = 2) и ≥ 640 (N = 3) — с запасом;
   - центр: N = 2 — ≥ 1280 при r ∈ [1/2, 2]; N = 3, s ≥ 10 — ≥ 1800–2100 при r ∈ [1/2, 2]; s = 2 — ≥ 3700–5900; для r = 1/3, 3, 1/5, 5 — больше;
   - вместо предельных сеток допустим Ричардсон по паре сеток при подтверждённом p и проверке на третьей сетке — тоже решение владельца.
8. **UNRESOLVED:**
   - монотонность при s ≳ 12–19 (неразличимые приращения);
   - центр N = 3, r = 1/5 и 5, s = 2 на любых практических сетках;
   - перенос ошибки рекурсии по s (Q-022);
   - сходимость полей при фиксированном N (Б.13, Q-025);
   - второй порядок при s ≥ 2 — только наблюдение;
   - строгий бюджет округления рекурсии при M = 4001 (проверена M ≤ 81).

## 10. Что не утверждается

- Наблюдаемая стабилизация при s ≈ 10–20 не доказывает сходимости полей при фиксированном N.
- Положительное расстояние до ω₀ (ВБ-19) согласуется с ненулевым пределом e_rel; численное значение d_N не вычислялось.
- Совпадение стабилизированных значений при r и 1/r — наблюдение, не теорема.
- p ≈ 2 — наблюдение; Ричардсон не обоснован строгим остатком.
- Рекурсия Парсеваля, энергетический эталон QA и Леви для R4 нормативно не приняты (D-046). Здесь они использованы как исследовательские эталоны с указанными бюджетами.
- Рекомендации по сеткам — предложение; правило n ≈ 1800 не вводится.
