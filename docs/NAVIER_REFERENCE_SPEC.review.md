## 2. Оценка остатка ряда прогиба

Проверено (ВЫВОД ПРОЕКТА):
- Шаги строгие: |член| ≤ a⁴/(mn(m² + n²)²) ≤ a⁴/(4m³n³), так как (m² + n²)² ≥ 4m²n²; хвост квадратного
  усечения покрывается суммой двух «полос» (m > M или n > M); Σ_{m > M, нечёт} m⁻³ ≤ ½∫_M^∞ t⁻³dt = 1/(4M²),
  поскольку для убывающей f каждый член f(m) ≤ ½∫_{m−2}^{m} f. Итог λ₃/(8M²) верен и равномерен по (x, y).
- Оценка **консервативна**: не учитывает знакопеременность в центре (−1)^{(m+n)/2−1} и |sin| < 1. Фактически
  центр сходится к 7 значащим цифрам уже при M = 39 (таблица выше), тогда как оценка гарантирует 10⁻⁶
  (относительно) лишь при M ≥ 734,1.
- Формулировку «M ≥ ≈ 734» (разд. 8.6) следует уточнить: для нечётных M порог — **M = 735**, и это
  **достаточное** по оценке значение, а не минимально необходимое (Н-2).
- Оценка для прогиба на моменты в спецификации **не переносится**: для моментов выведена отдельная оценка
  разд. 8.3, (16qa²/π⁴)·λ₂/(2M), с допущением 0 ≤ ν ≤ 1. Её шаги проверены: (m² + νn²) ≤ (m² + n²) при
  0 ≤ ν ≤ 1; 1/(mn(m² + n²)) ≤ 1/(2m²n²); Σ_{m > M, нечёт} m⁻² ≤ 1/(2M). Верна; при ν < 0 не применима —
  стоит указать явно (Н-3).
