## 5. Проверка компонентов и эталонные конструкции

Ожидания установлены до сравнений: точные факты арифметики и замкнутые формулы, выведенные вручную ниже.

**Единичное возмущение** w = e_{ij} во внутреннем узле, не соседнем с границей. Шаблон даёт 5 ненулевых значений t: в центре
−2/h_x² − 2/h_y², в соседях 1/h_x² (по x) и 1/h_y² (по y); все веса h_x h_y. Отсюда
‖w‖²_a = D h_x h_y[(2/h_x² + 2/h_y²)² + 2/h_x⁴ + 2/h_y⁴]. Для w ≥ 0 в одном узле A = |Δ||w| = |t|, поэтому S_q = S_2 = ‖w‖²_a/2;
S_l = ‖w‖²_h = h_x h_y. При w = −2: ‖·‖²_a в 4 раза больше, S_l в 2 раза, нагрузка меняет знак.

**Постоянное поле c.** По x: t_x(0) = t_x(n_x) = 2c/h_x² (вес h_x/2), t_x(1) = t_x(n_x − 1) = −c/h_x² (вес h_x), остальные 0 (при
n_x = 3 оба внутренних узла дают −c/h_x²). Тогда Σ_I W_x t_x² = 6c²/h_x³, Σ_{внутр.} W_x t_x = −2c/h_x, и
‖c‖²_a = D[6c²(n_y − 1)h_y/h_x³ + 6c²(n_x − 1)h_x/h_y³ + 8c²/(h_x h_y)]. Проверено на сетках 8×10, 3×3, 5×7.

**Прочие конструкции:**

- **нулевое поле** — B_E = 0 и E_s = 0 точно, все части 0, сертификат есть;
- **симметричное поле** w(i, j) = w(n_x − i, n_y − j) — все величины равны для отражённого поля;
- **антисимметричное по x поле** — нагрузка точно 0, Π = ‖w‖²_a/2;
- **тождество маршрутов** — Σ v·(ΔᵀWΔw) = a_h(v, w);
- **Л-6** и ‖w‖_a ≥ D^{1/2}μ_low‖w‖_h — на шуме, постоянном и «шахматном» полях;
- **почти компенсирующаяся разность** (сопряжённый фактор сдвинут на 1 ulp, ‖d̂‖²_h < 2⁻⁹⁰‖ŵ_s‖²_h) — сертификат, части Э-1 выполнены;
- **величины у границы нормальных** (факторы × 2⁻⁵⁰⁰) — квадраты шаблона уходят ниже 2⁻¹⁰²², П-3′(в) нарушена → UNRESOLVED;
- **направленные корни** — точные квадраты (lo = hi), иррациональные корни, 2⁻²⁰⁰⁰, 2²⁰⁰⁰ + 1; отрицательный аргумент — отказ;
- **направленное округление** — представимые значения, 2⁻¹⁰⁷⁴, ¾·2⁻¹⁰⁷⁴, 2¹⁰²⁴ (вверх +∞), середина между DBL_MAX и 2¹⁰²⁴;
- **нарушенные предпосылки, все — UNRESOLVED, ложного сертификата нет:**
  - D = 0, D = −1;
  - NaN во входе;
  - поле, не равное fl(XYᵀ) (У-1);
  - P̂, не равное значению пути (И-1);
  - d̂, не равное fl(ŵ_p − ŵ_s) (Л-2);
  - перебор углов, расходящийся с замкнутой формой (И-2);
  - дефектный целый корень (сертификация);
  - операции, сконструированные по битам: результат ровно 2⁻¹⁰²²; ноль без точного сокращения (имитация FTZ).

**Части Э-1 на каждой строке.**
- Вычисляются точно: E^(1) = a_h(e, d) + a_h(w̃_s, e′ − e) − l_h(e′ − e), без ω, по l_h = a_h(ω, ·); E^(2), E^(3), E^(4) — по ST 3.
- Проверяются: тождество E^(1) + E^(2) + E^(3) + E^(4) = E_s точно; |E^(k)| ≤ B_k для каждой части; ‖e‖_a ≤ ε_a^C(s), ‖e′‖_a ≤ ε_a^C(s−1); Л-6.

## 6. Отрицательные испытания и мутации

**Методика.**
- Каждая мутация — один текстовый дефект, исполняемый как отдельный объект модуля; файлы не меняются.
- Ожидание (вердикт на каждом входе, эффект, канал) задано в каталоге до запуска.
- Вердикт вычисляется только по значениям:
  - INAPPLICABLE — мутированная реализация на этом входе даёт те же компоненты;
  - DETECTED — эффект есть и сработал хотя бы один канал;
  - UNDETECTED — эффект есть, но не сработал ни один канал; это пробел, а не PASS.
- Каналы:
  - «сравнение» — первая расходящаяся компонента;
  - «неравенство» — |E_s| > B_E;
  - «части» — |E^(k)| > B_k;
  - «самопроверка» второго пути;
  - «аналитический эталон».
- Нулевая мутация N-01 (эквивалентная запись ½β²) обязана быть INAPPLICABLE, без срабатываний: так проверяется, что ни один канал
  не читает флаг мутации.

- **Аналог Г-5.** Для всех 11 мутаций основного пути неравенство |E_s| ≤ B_E мутированного пути **продолжает выполняться**: на этих
  контрольных входах |E_s|/B_E = 1,8·10⁻³…8,9·10⁻³. Поэтому само неравенство ни одну из них не видит. Все обнаружены сравнением с независимо вычисленной
  полной границей. У P-01 первая расходящаяся компонента — BE (B1 сам не менялся), заключение ERROR_UNSAFE.
- **Классификация заключений:**
  - ERROR_VALUE — математически другое значение без корней;
  - ERROR_UNSAFE — значение ниже точного значения формулы, то есть не верхняя граница. Решается уточнением интервала корней без допуска;
  - ERROR_NOT_DOCUMENTED — значение по-прежнему верхняя граница, но не то, что задаёт формула;
  - «допустимое отличие представления» — собственный B_E против B_E основного пути при совпадении всех подкоренных величин (разд. 7).
- **Находка первого прогона.** Вход «rect» был задан как 8×10 на 1 × 1,25, то есть h_x = h_y = 0,125. Поэтому P-05 и S-05 дали
  INAPPLICABLE против объявленного DETECTED. Механизм сработал правильно, ошибочным был выбор входа. Вход заменён на 8×10 на 1 × 1
  (h_x ≠ h_y); ожидания не менялись. Объявленный вход «square» по-прежнему показывает INAPPLICABLE.
- **Мутации тестов второго пути** (изолированная копия, scratch): 12 дефектов в реализации, 12/12 обнаружены тестами. Первая серия
  оставила 4 выживших — защитные проверки, которые не срабатывают на корректных данных:
  - сертификация корня;
  - строгий порог 2⁻¹⁰²²;
  - перебор углов;
  - ноль без сокращения.

  Добавлены адресные тесты на сконструированных операндах и подменённых процедурах; после этого все 12 обнаружены.
