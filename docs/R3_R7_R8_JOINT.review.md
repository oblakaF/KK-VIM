## 2. Математическая рецензия Р-7

### 2.1. Формулы Q_s, τ_s, E1, E2 [ПРОВЕРЕНО]

Формулы разд. 2 Р-7 совпадают с принятыми NUMERICAL_SPEC 4.1, 10.2–10.4 и с реализацией `kkvim.energy` (`check_pair`, `rounding_threshold`):
- Q_s = ½a_h(d, d) — двумерная сборка по полю d;
- R(w) = u(⌈log₂N⌉ + 16)Ŝ(w), N = (n_x − 1)(n_y − 1);
- R_f = 4u(max(n_x, n_y)/π)²‖w⁽ˢ⁾‖_{a_h}‖d‖_{a_h};
- τ_s = |γ_s| + 10[R(w⁽ˢ⁻¹⁾) + R(w⁽ˢ⁾) + R_f];
- E1: ΔP_s ≥ −τ_s; E2: |ΔP_s − Q_s| ≤ τ_s;
- разрешимость: Q_s ≥ 10τ_s.

Р-7 эти формулы не менял.

### 2.2. ЧВ-Р7-1: верхний запас при γ_s = 0 [ПРОВЕРЕНО]

Обозначим τ_R = 10[R + R + R_f]. Тогда τ_s = |γ_s| + τ_R ≥ τ_R, и m_s = Q_s/(10τ_s) ≤ Q_s/(10τ_R) = m_up. Неравенство
m_s ≥ 1 ⇔ Q_s ≥ 10|γ_s| + 10τ_R ⇔ |γ_s| ≤ Q_s/10 − τ_R = τ_R(m_up − 1) = g_allow. Вывод верен и строг.

Существенная оговорка, которую Р-7 соблюдает: m_up — верхняя граница **при тех же Q, R, R_f**. Q и R настоящего решателя R3 отличаются
от заместителя (разд. 3), поэтому m_up заместителя не является верхней границей запаса решателя.

### 2.3. ЧВ-Р7-2: масштабная инвариантность [ПРОВЕРЕНО]

При w = (qa⁴/D)w̄ и h ∝ a величины a_h(w, w) ~ D·a²·(qa²/D)², |q|Σh_xh_y|w| ~ q·a²·qa⁴/D и R_f ~ ‖w‖_a‖d‖_a однородны
степени q²a⁶/D. Поэтому m_s в точной арифметике зависит только от r, n_x, n_y, s. Это следует из ЧВ-14 (NUMERICAL_SPEC 9.3),
от E, t, ν величины зависят только через D. Вывод верен.

### 2.4. Три уровня величин: непрерывная рекурсия, заместитель, дискретный решатель

| Уровень | Что вычисляется | Источник в Р-7 | Ошибка относительно решателя |
|---|---|---|---|
| Непрерывная рекурсия | Q_cont = ½‖w_SA⁽ˢ⁻¹⁾ − w_SA⁽ˢ⁾‖² в непрерывной энергетической норме, по Парсевалю | `energy(s).change_norm2` | при r = 1, n = 20: +0,85 % (s = 2) |
| Дискретизированный заместитель | дискретная форма a_h и модель округления на **непрерывных** полях, взятых в узлах | `Q_sur`, R, R_f | при r = 1, n = 20: −3,0 % (s = 2), −1,4 % (s = 3) |
| Дискретный решатель | a_h на **дискретных** полях, γ_s по невязке одномерных систем | только r = 1 (код R2) | — |

Заместитель воспроизводит дискретизацию формы энергии, но не дискретизацию самого решения. При n = 20 его Q даже дальше от дискретного,
чем Q_cont, но запасы определяются им корректно: R и R_f заместителя совпадают с дискретными до 4·10⁻⁵ и 1,5 % соответственно
(разд. 3.1). При r ≠ 1 дискретного решателя нет, и разница «заместитель — решатель» не измерена. Р-7 это указывает явно (разд. 5, 8).

### 3.2. Погрешность заместителя и её зависимость от h

- При r = 1 погрешность заместителя убывает как O(n⁻²) — от 3,0 % при n = 20 до 3·10⁻⁵ при n = 640.
- Модель e_sur = C_s[(h_x/ℓ_min)² + (h_y/ℓ_min)²] — [ИНЖЕНЕРНЫЙ ВЫБОР]. При r = 1 она вдвое больше калибровочного закона; при r ≠ 1
  **не проверена**.
- Наблюдение рецензента: отношение Q_sur/Q_cont при n = 20 (семейство I) лежит в пределах −2,65…−4,06 % для s = 2 и −3,52…−5,44 % для s = 3
  при всех десяти r. Это подтверждает формулировку Р-7 «−2,7…−5,4 %».
- Это наблюдение не оценивает расстояние до **дискретного** решателя при r ≠ 1. Иллюстрация [ВЫВОД РЕЦЕНЗЕНТА, диагностика]: одномерная
  модельная задача первого полушага на (0, b) с коэффициентами G₁ квалифицированного эталона — плотная разностная система, а не решатель
  пластины и не результат квалификации. Её относительная ошибка множителя Y¹ при том же числе интервалов n_y:
  - при b = 0,2 — в ≈ 8 раз больше, чем при b = 1;
  - при b = 5 — в ≈ 17 раз больше (n = 20).

  Амплитуды ошибок решения при r ≠ 1 могут поэтому существенно отличаться от квадрата. Модель e_sur, масштабированная по ℓ_min, даёт
  такой же порядок роста (при r = 5, n = 20 e_sur в 13 раз больше, чем у квадрата), но это не калибровка.
- **Вывод.** Калибровка только при r = 1 достаточна для **предварительного** правила, но не для окончательного. Достаточна она потому,
  что во всех случаях MANDATORY_CANDIDATE m_low ≥ 4: чтобы обязательный случай стал неразрешимым (m < 1), ошибка заместителя должна
  составить более 75 % по Q (или более чем четырёхкратную по τ). Для O(h²)-ошибок при min(n) ≥ 20 это неправдоподобно,
  но не доказано (разд. 10, Н-4).

### 6.2. κ_s, размерность и ζ

- **κ_s = (C_s/A_s)^{1/4}** [ПРОВЕРЕНО]. Характеристическое уравнение A z² − 2B z + C = 0 при B² ≤ AC имеет комплексно-сопряжённые
  (или двойной) корни с |z|² = C/A, поэтому |λ| = (C/A)^{1/4}. Неравенство B² ≤ AC следует из Коши–Буняковского: B = ∫g′² = −∫gg″ ≤ √(AC)
  при g = 0 на концах. Численно оно выполнено при всех r и s ≤ 7. Значения κ₁…κ₃ и повтор κ₄…κ₇ совпадают с табл. 4.1 Р-8 до 4 знаков.
- **Размерность.** A = ∫g² ~ L, B ~ 1/L, C ~ 1/L³, отсюда κ ~ 1/L и ζ = κh безразмерна. Корректно.
- **ζ как мера наступления асимптотики** [ЭВРИСТИКА; дополнительное рассуждение рецензента — ВЫВОД РЕЦЕНЗЕНТА].
  - Дифференцирование уравнения полушага A f⁗ − 2B f″ + C f = const дважды даёт f⁽⁶⁾ = (2B/A)f⁽⁴⁾ − (C/A)f″,
    откуда |f⁽⁶⁾| ≤ 2κ²|f⁽⁴⁾| + κ⁴|f″|.
  - Отношение следующего члена разложения второй разности к главному, h²|f⁽⁶⁾|/(30|f⁽⁴⁾|), поэтому порядка (κh)²/15 с множителем O(1)
    (в предельных режимах — «балка» при κℓ ≪ 1 и погранслой при κℓ ≫ 1). Это подкрепляет довод разд. 4.1 Р-8.
  - Доказательством это не является: перенос ошибки через дискретную обратную задачу, ошибки коэффициентов на другой сетке
    и граничные члены (ЧВ-7) не учтены.
  - Одномерная модельная проверка (разд. 3.2) согласуется с этим: при b = 0,2 множитель Y¹ почти полиномиален, и наблюдаемый порядок равен
    1,993 уже на 4 → 8 интервалах. Мера ζ_A4 Р-8 с κ₁ = π/a, а не с π/b, для **наступления асимптотики** при r < 1 правдоподобна.
- **ζ не описывает константы ошибки.** Р-8 это признаёт (разд. 4.1, 7.5). Пример из одномерной модели: амплитуда ошибки Y¹ при b = 0,2
  в ≈ 8 раз больше, чем у квадрата при том же n_y. На критерии p и Ричардсона (относительные величины) это прямо не влияет, но они
  остаются эвристическим переносом.
- **Применение ζ к прямоугольникам.** ζ_A5 = max(πh_x/a, κ₁h_y, κ₂h_x, κ₃h_y) использует для каждого полушага шаг своего направления
  и учитывает фиксированный множитель X⁰. Это корректно. Возможный нижний предел π/ℓ на отрезке короткой стороны при контрольных r
  классов не меняет: при r < 1 κ₂ ≈ π/b, и этот член уже максимален.

### 6.4. Уровни с min(n) < 20 в Р-8 (Н-6)

| Риск избыточного UNRESOLVED | высокий (r = 5, 1/5; одна пара для r = 3, 1/3) | нет | нет |

Механизм ложного PASS: грубые пары хуже обнаруживают дефекты порядка O(h) и постоянные смещения относительно эталона. Чем мельче пара,
тем выше чувствительность. Поэтому любой вариант должен сохранять в обязательном наборе самые мелкие допустимые пары. P-B и P-C это
делают, а P для r = 5 и 1/5 не даёт пар вовсе.

## 8. Раздельные правила для p и Ричардсона

**Допуск уровня к проверке p и допуск пары к критерию Ричардсона — разные решения.** Расширенная область P-C на Ричардсона
**не переносится**.

**P-C / Richardson (проверено):** пара допускается к квалификационному критерию Ричардсона, только если её **грубый уровень** имеет
ζ ≤ ζ^{R2}(80). Тогда и мелкий уровень Q, поэтому допущенные пары — это ровно пары Q–Q. Отсюда:
- набор допущенных пар совпадает с парами Ричардсона правила P (Р-8, разд. 6), дополненными более мелкими парами Q–Q;
- обязательными по аналогии с D-032, п. 7, остаются две самые грубые пары Q–Q; более мелкие — необязательные (как 640 в R2) или диагностика;
- на допущенной паре действует существующее условие NUMERICAL_SPEC 12 и D-032: Ричардсон применяется только при наблюдаемом
  p ∈ [1,9; 2,1] на этой паре. Допуск ≤ 0,05 прежний; новых чисел нет.
