## 5. Независимость эталонов

- **D2:** независим по коду. Основная сборка — поузловая, с явным фиктивным узлом; кронекерова сборка и гессиан Π_h^C — только контрольные.
  По дискретизации не независим: D1 = D2, поэтому ошибку сетки проверяют только A и B.
- **B (Ритц):** независим от КК-МВИ по процедуре, но не по функционалу. При M = N по x совпадает с КК-МВИ(s = 1) по построению.
- **A (Хенки–Инглис):** методически независим. Строгой оценки ошибки нет.
- **C:** опубликованные значения с источником, страницей и шагом печати.
- **Импорты и данные:** в независимых эталонах нет импортов `kkvim`; данных Builder и результатов решателя CCCC нет.
