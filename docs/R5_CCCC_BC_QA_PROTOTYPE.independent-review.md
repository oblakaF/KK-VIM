## 1. Модальное решение и формула Вудбери (вопросы 1, 2)

| Элемент | Проверка | Итог |
|---|---|---|
| DST-I | `scipy.fft.dst(type=1, norm="ortho")` при длине m = n − 1 даёт √(2/(m + 1))·Σ sin(πik/(m + 1)) = ψₖ(i) = √(2/n) sin(kπi/n); Ψ симметрична и ортогональна (Ψ² = I) | **верно** |
| μₖ | (4/h²)sin²(kπ/(2n)), k = 1…n − 1, h = h_s; Lψₖ = −μₖψₖ | **верно** |
| Mₖ, знак | −2B ⊗ L = −2B ⊗ (−ΨΛΨᵀ) = 2B ⊗ ΨΛΨᵀ ⇒ 𝒦₀ = DΣMₖ ⊗ ψₖψₖᵀ, Mₖ = μₖ²A + 2μₖB + C | **верно** |
| x₀ | b = F ⊗ 𝟏 (сначала член): модально b̂ₖ,ᵢ = Fᵢ(Ψᵀ𝟏)ₖ; решение (DMₖ)x̂ₖ = b̂ₖ; обратное DST по каждому члену; `reshape` (N, m) → порядок «сначала член» | **верно** |
| Y₀ | Z = I_N ⊗ [e₁, e_m], столбец 2i + side = eᵢ ⊗ e_pos. 𝒦₀⁻¹(eᵢ ⊗ e_pos) = Σₖ(DMₖ)⁻¹eᵢ ⊗ ψₖψₖ(pos); в коде Vh[j, k] = (DMₖ)⁻¹_{ji}·ψₖ(pos), затем обратное DST | **верно** |
| G⁻¹ | (h_s⁴/(2D))A⁻¹ ⊗ I₂, индекс 2i + side совпадает с порядком столбцов Z | **верно** |
| S, c, x | S = G⁻¹ + Y₀[rows, :] = G⁻¹ + ZᵀY₀; c = S⁻¹Zᵀx₀; x = x₀ − Y₀c — формула Шермана–Моррисона–Вудбери | **верно** |
| Коэффициенты (шаблоны) | A = hGᵀG, B = −hGᵀ(LG), C = hGᵀ(D4G); строки D4 (7, −4, 1) при n ≥ 3; `HalfStep` запрещает n < 3 (И-4 Q1b) | **верно** |

Тест точной арифметики (`test_capacitance_decomposition_and_woodbury_are_exact`) доказывает тождества 𝒦^C = 𝒦₀ + ZGZᵀ и x₀ − Y₀S⁻¹Zᵀx₀ = (𝒦^C)⁻¹b точно на малых сетках. Моя плотная сборка 𝒦^C со своим D4 совпадает с решением прототипа до 2,7·10⁻¹⁴ отн. (Н-3; nₓ = 20, n_y = 30, N = 3, после QR).

## 2. Ёмкость S: путь (г) против модального пути (м) (вопрос 3)

Прототип формирует S **по пути (г)** — граничные строки вычисленного Y₀. Исправленный документ Literature (`fe5d60f`, ВОК-13, «Отдельный вклад ε_S») этот путь **не рекомендует**: ε_{ZY} ≤ ε_Y‖Y₀‖₂/‖ZᵀY₀‖₂, и отношение растёт с сеткой. Путь (м) — ZᵀY₀ = Σₖ(DMₖ)⁻¹ ⊗ zₖzₖᵀ — даёт ε_{ZY} ≤ 2N·maxₖεₖ (доказано при заданных εₖ).

Мой расчёт (Н-2): S по пути (г) прототипа и по пути (м) в double сравнены с модальной суммой в 40 знаках при тех же A, B, C. Сетка n_f = 32, N = 3 после QR (для N = 1 — то же по порядку).

| n_s | 16 | 64 | 256 | 1024 |
|---|---|---|---|---|
| ‖Y₀‖₂/‖ZᵀY₀‖₂ | 4,9 | 33 | 250 | 1980 |
| путь (г), ‖Ŝ − S‖/‖S‖ | 1,6·10⁻¹⁶ | 5,8·10⁻¹⁶ | 3,2·10⁻¹⁵ | 8,9·10⁻¹⁵ |
| путь (м), double | 1,2·10⁻¹⁶ | 1,3·10⁻¹⁶ | 8,0·10⁻¹⁶ | 2,1·10⁻¹⁵ |

**Вывод.**

1. На проверенных сетках путь (г) численно приемлем: ошибка S ~10⁻¹⁴, на порядки ниже худшей оценки u·log n·‖Y₀‖/‖ZᵀY₀‖. При cond(S) ≤ 5 он не делает решение B-C ненадёжным.
2. Но он в ~4 раза хуже пути (м) при n = 1024, разрыв растёт, и это **не тот путь**, который рекомендован для рабочего решателя.
3. Е-4 калибрует модель ВОК-13 с членом ε_S, а Е-6 журналирует cond(S). На пути (г) ε_S содержит множитель, которого на пути (м) нет. Измерения на (г) не переносятся на (м) без дополнительного предположения.
4. **Второй путь (м) нужен до Q3** (ПБ-2): включаемый параметром, с журналом обоих S и их разности. Путь (г) оставить как сравнительный.

## 3. QR, журнал обусловленности и неразличимый ранг (вопросы 4, 5)

- **QR с весом.** √h_f G = QR, Ũ = Q/√h_f ⇒ h_fŨᵀŨ = QᵀQ = I (R4 5.4). cond(A) до QR = cond(R)², так как A = h_fGᵀG = RᵀR. Точный дефект max\|h_fŨᵀŨ − I\| ≤ 5,0·10⁻¹⁶ (`chain.csv`). При N = 1 QR нет, cond(A) = 1. **Верно.**
- **Журнал NS 5.1.** cond(A) до и после QR и cond(S) записываются раздельно — как требует D-049.2, п. 4 (после ФА-1). **Верно.**
- **ε = 10⁻⁸, QR по запросу.**
  - cond(A) до QR = 7,2·10¹⁶ ~ 1/u — это случай NS 5.1, шаг 1: остановка до QR. Квалифицированного критерия численного ранга нет (D-049.5, D-049.6), и прототип останавливается только при **точной** потере ранга.
  - Мой расчёт (Н-5): синус наибольшего угла между span(Ũ) и span(G) после QR — **2,4·10⁻⁸**. QR действительно меняет оболочку, и результат относится к другой задаче.
  - **Допустимость.** Как изолированный исследовательский эксперимент — да: без вывода о точности для исходной оболочки и без включения в нормативные распределения Е-6. Отчёт QA (разд. 4, п. 2) это оговаривает. Но в `ill_conditioned.csv` и в журнале `run_halfstep` такая строка ничем не отличается от штатной (`status = INDEPENDENT_GIVEN_SET`, `qr = True`) — ПБ-4.
