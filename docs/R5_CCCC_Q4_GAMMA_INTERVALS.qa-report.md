## 3. Направленное округление и его доказательство

Для точного рационального x функция `directed` строит интервал так:
1. **Переполнение.** Если x > DBL_MAX, интервал [DBL_MAX, +∞]; если x < −DBL_MAX — [−∞, −DBL_MAX].
2. **Обычный случай.** Иначе f = float(x).
   - Если Fraction(f) = x — интервал [f, f].
   - Если Fraction(f) < x — интервал [f, nextafter(f, +∞)].
   - Иначе — [nextafter(f, −∞), f].

**Утверждение.** Результат — наименьший binary64-интервал, содержащий x.

**Доказательство.**
1. Если x — double, интервал вырожден.
2. Иначе x лежит строго между соседними double a < x < b.
3. f — одно из чисел a, b: для |x| ≤ DBL_MAX округление к ближайшему даёт соседний double, в том числе в субнормальной области.
4. Если f < x, то f = a и nextafter(f, +∞) = b. Если f > x, то f = b и nextafter(f, −∞) = a.
∎

**Проверяемость.** Корректность не принимается на веру. Каждый результат проверяется функцией `verify` **точными** сравнениями:
- Fraction(γ↓) ≤ x ≤ Fraction(γ↑);
- для x, не являющегося double, γ↓ и γ↑ — **соседние** double (nextafter(γ↓, +∞) = γ↑);
- для x — double — интервал вырожден.

При нарушении `directed` поднимает исключение, а не возвращает интервал. Поэтому ошибка округления `float()` не может пройти незамеченной.

**Γ_up.** Из γ↓ ≤ x ≤ γ↑ следует |x| ≤ max(|γ↓|, |γ↑|). Это тоже проверено точно для каждой строки.

**Независимая проверка в тестах.** Эталон «наибольший double ≤ x / наименьший ≥ x» строится двоичным поиском по упорядоченным битовым
образам double, без `float()`. С ним сверены:
- 19 заданных случаев: оба знака, ноль, «ничья» 1 + 2⁻⁵³ (округление к чётному), субнормальные значения, значения ниже наименьшего
  субнормального, окрестность DBL_MAX и переполнение;
- 3000 случайных рациональных чисел с порядками 2⁻¹¹⁰⁰…2¹⁰⁰⁰ обоих знаков.

Совпадение полное.

## 5. Ноль, субнормальные и нечисловые входы

В данных Q3 нулевых и субнормальных γ **нет**, поэтому эти случаи проверены тестами, а не данными:
- **Ноль:** x = 0 даёт [0.0, 0.0].
- **Ниже наименьшего субнормального:**
  - −2⁻¹¹⁰⁰ даёт [−5·10⁻³²⁴, −0.0];
  - +2⁻¹⁰⁸⁰ даёт [0.0, 5·10⁻³²⁴];
  - Γ_up = 5·10⁻³²⁴.
- **Субнормальная область** (3·2⁻¹⁰⁷⁵ и др.) — соседние субнормальные double.
- **Переполнение:** ±3·2¹⁰²³ даёт [DBL_MAX, +∞] и [−∞, −DBL_MAX].
- **Нечисловые входы:**
  - NaN или ±∞ в массиве — `gamma_b1` отказывает (ValueError). В кампании такая строка получила бы статус UNRESOLVED, интервал не строился
    бы. В данных Q3 таких строк нет.
  - Нецелое представление x (float вместо Fraction) отклоняется.
- **Неверные интервалы** (переставленные границы, несоседние double, NaN, невырожденный интервал для double) — `verify` их отклоняет.

   независимых реализаций, а не независимость исполнителей: исполнители одного типа (D-053.2, п. 6). QA-γ4 (другой исполнитель) не выполнялся.
