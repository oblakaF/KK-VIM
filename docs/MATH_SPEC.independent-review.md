## 2. Блокирующие замечания

### Б-1. Не доказано, что ряд Навье (131) — то же ω₀, что обобщённое решение в H_T

- **Где.** Разд. 7.4: В-27 — «Π(ω₀) = −½q∬ω₀ и по (131) L-107 ∬ω₀ = …», а также «точность определяется сравнением
  с независимым эталоном (Навье)». Разд. 9.3 — сравнение с «центром Навье».
- **Причина.**
  - В MATH_SPEC ω₀ определено абстрактно: элемент H_T из теоремы Рисса (В-10).
  - Классического решения в C⁴(Ω̄) нет (В-11). Значит, ссылка NAVIER_REFERENCE_SPEC на «решение той же краевой задачи»
    в классическом смысле не переносится на ω₀ автоматически.
  - На этом отождествлении держатся формула В-27 и смысл всего сравнения R2 «КК-МВИ ↔ Навье» (D-024, D-025).
    Отождествление не доказано и не помечено как допущение. По AGENTS.md (разд. 2) и постановке задачи такое
    отождествление не принимается.
- **Требуемое исправление.** Добавить короткий [ВЫВОД ПРОЕКТА] по следующей схеме; я её проверил.
  1. Частичные суммы w_M ряда (131) принадлежат D(T_SS): это конечные суммы синусов, на сторонах w = ∂ₙ²w = 0.
  2. Tw_M = q_M — частичная сумма разложения q по (128), (129), (c) L-107, потому что Δ²φ_mn = λ²_mn φ_mn и
     λ_mn² = π⁴(m²/a² + n²/b²)². При этом q_M → q в L₂ по полноте системы.
  3. ‖w_M − w_K‖²_{H_T} = (q_M − q_K, w_M − w_K). По В-7 отсюда ‖w_M − w_K‖_{H_T} ≤ ‖q_M − q_K‖/(D^{1/2}λ₁₁) → 0,
     то есть последовательность фундаментальна в H_T.
  4. Для её предела w* и любого v ∈ D(T_SS): [v, w*] = lim(v, q_M) = (v, q). По плотности это верно для всех v ∈ H_T,
     и по единственности (В-10) w* = ω₀.
  5. Ряд (131) сходится абсолютно и равномерно, а H_T ⊂ W₂²(Ω) ⊂ C(Ω̄) в размерности 2. Поэтому значения ω₀ в точках
     (центр, узлы сетки) равны сумме ряда.

  После этого В-27 и сравнения разд. 9.3 и R2 получают основание.

### Б-2. Общее условие допустимости начальной функции (разд. 4.6) не исключает вырождения алгоритма

- **Где.** Разд. 4.6: «Общее условие допустимости в части A: X⁰ ≢ 0, X⁰ ∈ C⁴[0, a] и удовлетворяет условиям задачи по x».

- **Причина.** Условие разд. 4.6 недостаточно для корректности самого алгоритма, а не только энергетического теста.
  - Контрпример: X⁰ = sin(2πx/a) удовлетворяет разд. 4.6, но F_{X⁰} = q∫X⁰ = 0.
  - Тогда ℓ_{X⁰} ≡ 0, по В-20 Y¹ ≡ 0 и w⁽¹⁾ = 0.
  - На X-полушаге s = 2 получается A_Y = B_Y = C_Y = 0 и F_Y = 0. Уравнение вырождается в 0 = 0, решение не единственно,
    В-20 неприменим (нужно A_Y > 0).
  - Невырожденность установлена только в В-25 и только как условие 3 теста (разд. 7.3). Индукция В-22 молча опирается
    на Y^{s−1} ≢ 0, то есть на В-25, а В-25 сам опирается на В-22 и В-24.

  «Допустимые начальные функции» — обязательный пункт части A по D-029.
- **Требуемое исправление.**
  1. В разд. 4.6 включить в общее условие допустимости невырожденность старта: (q, X⁰Ỹ) ≢ 0 на V_b, при q = const —
     ∫₀ᵃ X⁰ dx ≠ 0 (по существу F_{X⁰} ≠ 0).
  2. Оформить В-22 и В-25 как одну совместную индукцию по s. Утверждение: заданный множитель принадлежит C⁴ и ≢ 0,
     следовательно w⁽ˢ⁾ = P_{M_s}ω₀ и Π(w⁽ˢ⁾) ≤ Π(w⁽¹⁾) < 0, следовательно новый множитель ≢ 0.

  Для sin(πx/a) и sin²(πx/a) условие выполнено (F = 2qa/π и qa/2), поэтому на R2 исправление не влияет.
