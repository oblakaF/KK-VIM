### 1.1. Эталоны (RO 4.2; D-049.6, п. 4)

| Уровень | Где | Эталон | Ошибка эталона |
|---|---|---|---|
| **Точный** | N·(n_s − 1) ≤ 36 (`EXACT_LIMIT`) | x* = (𝒦^C)⁻¹(F ⊗ 𝟏) в рациональной арифметике по точной системе входных double (лента Q1b). Там же — точные компоненты B-C: 𝒦₀ = 𝒦^C − ZGZᵀ, x₀*, Y₀* = 𝒦₀⁻¹Z, S* = G⁻¹ + ZᵀY₀*, c*, M* = I − Y₀*S*⁻¹Zᵀ. Самопроверка: x₀* − Y₀*c* = x* **точно** | δ_ref = 0 |
| **Сертифицированный R-AC** | больше | R-AC с уточнением; сертификат Q1b: b_ref ≥ ‖x_ref − x*‖₂ (`error_bound`), b_ref,K = ‖r_ref‖₂/λ_low^{1/2} ≥ ‖x_ref − x*‖_K | b_ref, b_ref,K (строго) |

Сравнение двух double-реализаций в качестве эталона не используется.

### 1.2. Е-4 — что записывается (`e4_case`)

| Величина | Как | Статус |
|---|---|---|
| ошибка **набора коэффициентов** ‖x̂ − x*‖₂ (абс. и отн.) | точный уровень: точный интервал; R-AC: [d − b_ref, d + b_ref], d = ‖x̂ − x_ref‖₂ точно | строго (интервал) |
| невязка R-HP ‖r(x̂)‖₂ и η_QA | точная невязка исходного оператора с D4; корень — интервал | строго / наблюдение (η) |
| **граница ВОК-14 (б)**: r̄/(Dμ̲₁²λ̲), r̄/(D^{1/2}μ̲₁λ̲^{1/2}), для поля h_s^{1/2}·(…) | r̄ — точная невязка, корень вверх; μ̲₁ = 4/l_s² (sin x ≥ 2x/π), точно; λ̲ ≤ λ_min(A) — сертифицирована точным LDLᵀ матрицы A − λ̲I | CERTIFICATE при условиях 1–3, иначе UNRESOLVED |
| согласованность с ВОК-14 (а) | точно: ‖x̂ − x*‖ ≤ граница (точный уровень) или d − b_ref ≤ граница (R-AC) | должно выполняться; нарушение — дефект эталона или невязки |
| **бюджет 1/100** (набор и поле отдельно) | ошибка эталона ≤ измеренной/100 в той же норме, сравнение квадратов точно | SATISFIED / NOT_MET → сравнение UNRESOLVED / UNRESOLVED (нулевая ошибка, правило не определено) |
| **ошибка поля** ‖Ũ(V̂ − V*)ᵀ‖_a (абс. и отн.) | **отдельно от набора**: тождество ‖Ũ(V̂ − V*)ᵀ‖²_a = h_s‖x̂ − x*‖²_K (NS 4.3, П-S1), ‖δ‖²_K = −δᵀr(x̂) точно; на R-AC — интервал с b_ref,K | строго (интервал) |
| часть δS ошибки ε_S для путей (м) и (г) | ‖Ŝ − S*‖₂/‖S*‖₂ (Ŝ прототип отдаёт) | наблюдение относительно точного S* (только точный уровень) |
| ε₀, ε_Y, ε_S целиком, T₁…T₄ | точные эталоны готовы, но прототип B-C не отдаёт x̂₀, Ŷ₀, ĉ, Ĝ⁻¹ | **UNRESOLVED** (недостающий инструмент назван) |
| εₖ | нужны точные zₖ = (ψₖ(1), ψₖ(m)) — иррациональные синусы | **UNRESOLVED** (ОК-7) |

**Сертификат коэффициентов — не сертификат поля.**
- Энергетическая норма ошибки поля получена из точного тождества NS 4.3 для **решаемого** набора, а не переносом 2-нормы.
- Поле в max- и 2-норме не сертифицируется: нужны ‖G‖₂ и ошибка произведения.
- Ошибка образования поля (Е-2, составляющая (i)) сюда не входит.
- После QR все сертификаты относятся к span(Ũ), а не к исходному полю (`certificates_refer_to`).
