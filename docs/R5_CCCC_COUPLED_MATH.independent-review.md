## 3. Стартовый набор и точные дискретные коэффициенты

### 3.1. Вердикт по стартовому набору: **PASS**

X_i⁰ = sin²(iπx/a), i = 1…N (оболочка 𝒯_N, базис A):
- допустимость: C^∞, X = X′ = 0, симметрия;
- непрерывная независимость; вектор нагрузки ненулевой;
- точные Грамы; cond a = 1 + 2N;
- преемственность с N = 1 (В-32);
- вложенность по N.

Ещё:
- **Эквивалентность базисов A и B** доказана: одна оболочка, одна последовательность полей.
- 𝒫_N — действительно другое подпространство, с худшей обусловленностью и без преемственности с N = 1. Отказ от него обоснован не по ошибке — верно.
- Применимость при N = 2, 3 — да, при nₓ ≥ 2N + 1 для точных формул и при контроле ранга (разд. 4).
- **Ориентация.** Старт по x — соглашение MATH_SPEC. r ↔ 1/r — другая последовательность. Совпадение значений при s = 3…8 — наблюдение, а не совпадение пределов (Q-025). Ориентацию фиксировать в протоколе.

### 3.2. Вердикт по точным дискретным коэффициентам: **PASS**

Независимый вывод:
- (1 − cᵢ)/2, cᵢ(l) = cos(2iπl/n), — n-периодическое чётное продолжение, совпадающее с отражением w₋₁ = w₁ и при l = n. Поэтому Ł и L действуют как периодическая вторая разность: ŁUᵢ = (μᵢ/2)cᵢ, μᵢ = (4/h²)sin²(iπ/n).
- Трапеции с весом ½ дают сумму по периоду. Ортогональность Σcᵢcⱼ = (n/2)δᵢⱼ и Σcᵢ = 0 требует i ± j ≢ 0 (mod n), что выполнено при **2N < n**.
- Отсюда A = a(I/8 + 11ᵀ/4), B = (a/8)diag(μᵢ) (через Σ_{l=1}^{n−1}cⱼ = −1), C^C = (a/8)diag(μᵢ²), F = qa/2.

**Расчёт** (a = 1,3; (n, N) = (13, 3), (12, 3), (9, 2), (8, 2), (7, 3), (40, 3), (101, 2)): отклонение ≤ 5·10⁻¹². При 2N = n (n = 6, N = 3) формула C^C нарушается, независимость сохраняется. Порог независимости N ≤ ⌊n/2⌋ подтверждён при n = 6…9. Условие nₓ ≥ 2N для 𝒫_N доказано верно: многочлен степени ≤ 2N + 2 с 4 + nₓ − 1 нулями.

## 4. ОВ-C1 — полный ранг первого полушага

### 4.1. Доказательство рецензента для N = 2 (непрерывно) [ВЫВОД РЕЦЕНЗЕНТА; требует включения Literature и проверки]

По ВБC-18: L_iY_i = g, L_i = (D² − κᵢ²)², κᵢ = 2iπ/a, g = 4q/D − 2(Y₁⁗ + Y₂⁗), Yᵢ = Yᵢ′ = 0 на концах; Yᵢ ∈ C^∞[0, b] (ВБC-4). Пусть Y₁, Y₂ линейно зависимы.

1. **Y₂ ≡ 0.** Тогда g = L₂Y₂ = 0, и L₁Y₁ = 0 с защемлением. Так как ∫Y·L₁Y = ∫(Y″² + 2κ₁²Y′² + κ₁⁴Y²), получаем Y₁ = 0. Тогда g = 4q/D ≠ 0 — противоречие. Случай Y₁ ≡ 0 — симметрично.
2. **Y₁ = cY₂, c ≠ 0, Y₂ ≢ 0.**
   - Из L₁Y₁ = L₂Y₂: (cL₁ − L₂)Y₂ = 0. Оператор ненулевой (κ₁ ≠ κ₂), поэтому Y₂ — экспоненциальный многочлен с частотами из корней Q(ξ) = c(ξ² − κ₁²)² − (ξ² − κ₂²)².
   - Из g = L₂Y₂: (3 + 2c)Y₂⁗ − 2κ₂²Y₂″ + κ₂⁴Y₂ = 4q/D. Оператор с постоянными коэффициентами сохраняет частоты.
   - Если 0 не корень Q, левая часть не имеет компоненты нулевой частоты, а правая — ненулевая константа. Это противоречие: экспоненциальные многочлены с разными частотами линейно независимы на интервале.
   - Значит Q(0) = cκ₁⁴ − κ₂⁴ = 0, то есть **c = 16**. Тогда 16L₁ − L₂ = 15D⁴ − 24κ₁²D², и для защемлённой Y: ∫Y(15Y⁗ − 24κ₁²Y″) = 15‖Y″‖² + 24κ₁²‖Y′‖² > 0 при Y ≢ 0. Следовательно Y₂ = 0 — противоречие. ∎

**Итог:** при q = const ≠ 0, любых a, b и старте 𝒯₂ выполняется **rank w^{(1)} = 2** — без новых предположений.

### 4.2. Любое N — необходимое условие [ВЫВОД РЕЦЕНЗЕНТА]

Если Σdᵢ Yᵢ = 0, d ≠ 0, то по ВБC-18 P(D)g = 0.
- Если P(0) ≠ 0, у g нет компоненты нулевой частоты.
- У каждой Yⱼ = Gⱼg её тоже нет: частное решение имеет частоты корней P, ни один из которых не равен ±κⱼ (P(±κ_k) ≠ 0); однородная часть — частоты ±κⱼ ≠ 0.
- Тогда равенство g = 4q/D − 2ΣYⱼ⁗ даёт 4q/D = 0 — противоречие.

Следовательно, вырождение возможно только при P(0) = 0, то есть **Σᵢ dᵢ/i⁴ = 0**. При N = 2 это и дало c = 16. При N = 3 условие оставляет двумерное множество направлений d; противоречие с краевыми условиями не получено — **UNRESOLVED**.

### 4.3. Дискретно

- Дискретный аналог не доказан: D4 = (L − μ)² + E₂ — операторы Lᵢʰ не коммутируют, частотный довод не переносится.
- Расчёт рецензента (Π_h^C, полушаги с QR, s = 1…6): σ_N/σ₁ первого полушага при (24, 30, b/a = 1), (21, 35, 1,7), (40, 12, 0,3) — 2,6·10⁻³…3,7·10⁻³ (N = 2) и 4,1·10⁻⁵…8,2·10⁻⁵ (N = 3), далеко от уровня округления.
- Энергетическое тождество выполняется до ≤ 9·10⁻¹⁴ отн.
- Зазор до D1 стабилизируется на положительном уровне — к D1 последовательность не сходится. Это наблюдения.

### 4.4. Ответы на вопросы задания

1. **Без новых предположений:** N = 2 непрерывно — да (разд. 4.1). N = 3 непрерывно и любое N дискретно — пока нет. Нужное условие — исключение направлений d с Σdᵢ/i⁴ = 0 — UNRESOLVED.
2. **Достаточность обязательного контроля.** Для исследовательской реализации — да: диагностика ранга после первого и каждого последующего полушага с остановкой до QR — тот же принцип, что РВ4-2 для SSSS, где сохранение ранга при s ≥ 2 тоже не доказано (D-045). Численный критерий S-2 и защитные параметры для CCCC не переносятся из SSSS — их квалифицирует QA и утверждает владелец.
3. **Реализация при «полный ранг подтверждён численно»** корректна как исследовательская с маркировкой PROVISIONAL / NOT_QUALIFIED, по образцу исследовательского режима R4 (D-047, доп. 1; D-048.5).
4. **Реакция при утрате ранга:** остановка до QR без изменения N.
   - S-1 — только при доказанной зависимости: например, N > ⌊nₓ/2⌋ (ВБC-13, п. 4), или точно зависимый набор.
   - Иначе — статус защитной остановки (аналог PROVISIONAL_RANK_GUARD_STOP / PROVISIONAL_SET_GUARD_STOP); S-2 по неквалифицированному порогу не присваивается.
   - Понижение N, регуляризация и восстановление направлений не вводятся.
5. **Ограниченная приёмка без теоремы об априорном сохранении ранга** — да. Так же принята часть B для SSSS: ограничение D-045 «сохранение полного ранга при s ≥ 2 не доказано».

## 5. Сходимость и независимость

- Сходимость энергии, ограниченность и ‖w^{(s)} − w^{(s−1)}‖ → 0 доказаны (ВБC-9, ВБC-10) с оговоркой У-C2. Сходимость полей не утверждается — верно.
- Сходимость к D1 при фиксированном N не доказывается. Дискретно расстояние положительно при rank ω_h > N (ВБC-14, п. 2) — условие оговорено, что закрывает замечание У-R4 рецензии `4b18761`.
- **ВБC-11** остаётся условным. L-D, по оценке рецензента, следует из стандартных фактов: плотность C_c^∞ ⊗ C_c^∞ в C_c^∞(Ω) в C²-топологии, симметризация, ВБC-1, п. 4. Однако набросок не превращён в доказательство, и статус не повышается.
- **Сравнения с Ритцем (разд. 6 документа):**
  - совпадение x-оболочки старта с x-подпространством B при M = N верно;
  - сравнение s = 1 с B при M = N по x совпадало бы по построению — предупреждение верно. Проекция на 𝒯_N ⊗ V_b совпадает с проекцией на 𝒯_N ⊗ (симметричная часть V_b) в силу симметрии ω₀;
  - методы независимы по процедуре — верно.
- Аналог ВБ-19 для CCCC — НЕ УСТАНОВЛЕНО, основание приведено честно (разд. 7 документа).
