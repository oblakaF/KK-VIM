## 2. Что реализовано (`src/kkvim_reference/navier.py`)

В единицах qa⁴/D (прогиб), qa² (моменты), qa⁶/D (интеграл), s_m(x) = sin(mπx/a), s_n(y) = sin(nπy/b), m, n нечётные, квадратное усечение
m, n ≤ M:

$$\bar w=\frac{16}{\pi^6}\sum\frac{s_m s_n}{mn\,(m^2+n^2/r^2)^2},\quad
\bar M_x=\frac{16}{\pi^4}\sum\frac{(m^2+\nu n^2/r^2)\,s_m s_n}{mn\,(m^2+n^2/r^2)^2},\quad
\bar M_y=\frac{16}{\pi^4}\sum\frac{(\nu m^2+n^2/r^2)\,s_m s_n}{mn\,(m^2+n^2/r^2)^2},$$

$$J_M=\frac{64}{\pi^8}\,r\sum\frac{1}{m^2n^2(m^2+n^2/r^2)^2},\qquad I_M=\frac{qa^6}{D}J_M,\qquad \Pi_M=-\tfrac12 qI_M .$$

| Элемент API | Назначение |
|---|---|
| `NavierRectangle(a, b, q, D, nu)`, `from_material(...)` | пластина a × b; проверка 0,2 ≤ b/a ≤ 5; `r = b/a`; `swapped()` — пластина b × a (ЧВ-R1) |
| `at_points(x, y, *, M=2559, summation, diagnostics)` | w, M_x, M_y в точках 0 ≤ x ≤ a, 0 ≤ y ≤ b; векторизовано блоками по 2048 точек |
| `at_nodes(nx, ny, *, M=2559, ...)` | поля в узлах x_i = ia/n_x, y_j = jb/n_y; разделимое суммирование S_x C S_yᵀ, синусы — целочисленная редукция (И-11) |
| `NavierRectangleResult` | `w`, `Mx`, `My` и безразмерные `*_coef`; `w_tail_bound_coef` (ЧВ-R2), `w_error_bound_coef`, оценки округления |
| `NavierRectangleConvergence` | значения на уровнях 1, 3, …, 1279, 2559 и приращения Δ_j — **только диагностика, без правила приёмки** (δ_w(r) не введён, Р-5) |
| `deflection_integral(*, M=2559)` | `NavierIntegral`: J_M, I_M, Π_M, граница ЧВ-R2a, округление |
| `deflection_tail_bound_rect(M, r)` | ЧВ-R2: (16/π⁶)λ₃r²/(8M²) = 0,0021881·r²/M² |
| `deflection_integral_coef_rect(M, r)`, `deflection_integral_tail_bound_rect(M, r)` | J_M(r); ЧВ-R2a: 0 ≤ J − J_M ≤ r³/(18π⁴M³) |
| `M_R3 = 2559`, `NAVIER_LEVELS_R3`, `R3_RATIO_MIN = 0.2`, `R3_RATIO_MAX = 5.0` | уровень и диапазон R3 |

**Не реализовано:** M_xy, перерезывающие силы, уточнённые оценки O(ln M/M⁴) и оценки моментов для r ≠ 1 (Q-027), П-12 (Леви), П-13.

### 2.1. Диапазон r — ERROR_INPUT

Вне 0,2 ≤ b/a ≤ 5 конструктор и функции границ выдают `ValueError` с текстом `ERROR_INPUT` (Р-1, Р-5; черновик 6.1). Уровень 2559 вне
диапазона не квалифицирован (черновик 4.3: при r = 8 нужно M ≥ 3280).

**Допуск на представление входных чисел — 4u** (решение владельца от 2026-10-14; поправка QA). Точное отношение заданных float
(целочисленная арифметика через `float.as_integer_ratio`) проверяется условием

$$0{,}2\,(1-4u)\le b/a\le 5\,(1+4u),\qquad u=2^{-53}.$$

Это допуск только на двоичное представление входных чисел, а не расширение физической области R3. Следствия:
- a = 3, b = 0,6 **принимается**: float 0,6 меньше 3/5, точное отношение b/a = 0,2·(1 − u/3) — в пределах 4u;
- точные границы (a = 1, b = 5; a = 5, b = 1; a = 1, b = 0,2) принимаются;
- отклонения в пределах 4u принимаются: b = 5 + 1 ulp (+1,6u), 5 + 2 ulp (+3,2u), 0,2 − 1 ulp (−0,75u), 0,2 − 3 ulp (−3,25u);
- выход за 4u — `ERROR_INPUT`: b = 5 + 3 ulp (+4,8u), 0,2 − 4 ulp (−4,5u). Прежнее правило «любое превышение на 1 ulp — ERROR_INPUT»
  заменено этим.

Функции строгих границ (`deflection_tail_bound_rect`, `deflection_integral_coef_rect`, `deflection_integral_tail_bound_rect`) применяют
то же правило к своему входу r. Методы пластины проверяют отношение один раз в конструкторе и не проверяют повторно округлённое
r = fl(b/a): иначе у края допуска возможен ложный отказ уже принятой пластины. Пример: a = 0,7, b = 0,13999999999999993 — точное
отношение 0,2·(1 − 3,93u) принимается, а fl(b/a) = 0,2·(1 − 4,5u).

### 2.2. Совместимость с R2

- `NavierPlate` (квадрат), `M_R2 = 1279`, `NAVIER_LEVELS`, `DELTA_W`, `DELTA_M`, `select_level`, правило практического контроля 8.4 и
  все публичные функции R2 сохранены. `NavierPlate` по-прежнему отвергает b ≠ a: этого требуют тест R2
  `tests/reference/test_navier.py::test_invalid_plate` и тест QA `tests/cross/test_navier_a10a.py::test_invalid_plate`. Поэтому прямоугольник —
  отдельный класс `NavierRectangle` на общих внутренних функциях.
- Внутренние функции обобщены параметром r; при r = 1 выполняются те же операции с плавающей точкой, что и раньше. Проверено побитно:
  снимок 196 массивов R2 (точки и узлы, оба порядка суммирования, уровни 1, 9, 159, 1279, интеграл, границы, три набора a, q, D, ν)
  до и после изменения совпадает бит в бит.
- `NavierRectangle` при a = b даёт значения `NavierPlate` бит в бит (при одинаковом M); интеграл при r = 1 считается прежней точной
  целочисленной формой.
- `NavierConvergence` (квадрат) сохраняет правило приёмки 8.4; общая часть вынесена в базовый класс без изменения полей и методов.

### 2.3. Округление

Модель первого порядка R2 (`_rounding_bound`) с двумя дополнительными округлениями на член для n²/r²; интеграл прямоугольника —
24u относительно J_M (модель: 6 округлений на член, fsum, множитель (64/π⁸)·r; запас 2). Это оценка, а не доказанная граница
([СТАНД.], как в R2).

### 2.4. Производительность

Сеточные поля — матричные произведения S_x C S_yᵀ (как в R2); точки — блоками по 2048 с таблицами синусов один раз на блок; наивного
двойного цикла по гармоникам для каждой точки нет. Центр с диагностикой 11 уровней при M = 2559 — ≈ 0,08 с; J_M при M = 2559 — ≈ 0,05 с;
сетка 16 × 32 при M = 2559 — ≈ 0,12 с (Windows, Python 3.13).
