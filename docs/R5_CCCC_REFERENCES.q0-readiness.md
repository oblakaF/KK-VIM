**Вывод QA системы (11)–(13)** (уровень Б; это проверка транскрипции, а не новая формула):
- φₘ(ξ) = 1 − cos 2mπξ, отсюда ∫₀¹φₘφₚ = 1 + δₘₚ/2, ∫₀¹φₘ″φₚ″ = 8π⁴m⁴δₘₚ, ∫₀¹φₘ″φₚ = −2π²m²δₘₚ.
- Подстановка в (7) даёт (D/a⁴)·4π⁴·K·w = q·e*:
  - диагональ 4π⁴[m² + (a/b)²n²]²;
  - связь при одинаковом m — 8π⁴m⁴ = 4π⁴·2m⁴;
  - связь при одинаковом n — 4π⁴·2(an/b)⁴.
- Совпадает с (11)–(13).

**Строгое одностороннее свойство B** (стандартный факт метода Ритца, уровень Б):
- при точном интегрировании Π(w_M) = −½(q, w_M) ≥ Π(ω₀) = −½(q, ω₀);
- значит, работа нагрузки ∬q w_M **не превосходит** точную и не убывает при вложенных базисах.

Это строгая **нижняя** граница работы, но не оценка прогиба центра и не двусторонняя оценка.

**Пределы независимости B (D-049.8, п. 2):**
- независим от КК-МВИ по процедуре, но не по функционалу;
- при M = N по x и первом полушаге совпадает с КК-МВИ (s = 1) по построению, поэтому сравнения — только при M → ∞ по обеим переменным
  (D-049.3, п. 4; QA-M9).
