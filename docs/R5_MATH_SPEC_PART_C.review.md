## 3. ВБ-19 и ОВ-PC1…ОВ-PC3 (п. 6 задания)

**Собственная проверка Reviewer: что именно не переносится в ВБ-19.**

Шаги 1–3 и 5 доказательства ВБ-19 переносятся на CCCC без изменений:

- п. 1: вложение J: H_T → L₂ с той же константой. Для v ∈ W̊₂²(Ω) ⊂ W₂² ∩ W̊₂¹ выполнено ‖Δv‖ ≥ λ₁₁‖v‖, λ₁₁ = π²(1/a² + 1/b²) — первое собственное значение лапласиана Дирихле;
- пп. 2, 3, 5 — рассуждения только в L₂(Ω).

Не переносится только п. 4 — **бесконечный** ранг ω₀ через ряд Навье. Поэтому для CCCC:

**d_N > 0 ⇐ rank K_{ω₀} > N**, и достаточно конечного ранга, большего N. Бесконечный ранг (ОВ-C2) — более сильное, чем нужно, условие.

| № | Формулировка в C.11.1 | Логическая оценка | Нужен ли отдельный номер |
|---|---|---|---|
| ОВ-PC1 | «Выполнение ВБ-20 требует d_{N−1} > 0, **то есть ОВ-C2**» | Неточно. d_{N−1} > 0 следует уже из rank K_{ω₀} ≥ N, а это строго слабее бесконечного ранга. Отождествление с ОВ-C2 неверно в сторону «⇔» | Как отдельный вопрос оправдан только в уточнённой форме: «rank K_{ω₀} ≥ N для N = 2, 3 (достаточно для d_{N−1} > 0 по пп. 1–3, 5 ВБ-19)». Иначе — подпункт ОВ-C2 (РЧ-4) |
| ОВ-PC2 | гладкость, D(T_CC), ранг — только при q = const | Это граница области (C.1, MATH_SPEC 1.6), а не открытый вопрос | Не нужен: оставить как ограничение области в C.1 |
| ОВ-PC3 | N ≥ 4 не исследован | Тоже граница области (C.1: «N ≥ 4 не рассматривается»). Формулировка «ВБC-20, п. 1 верен, но не исследован» внутренне неясна: п. 1 доказан для любого N | Не нужен: ограничение области и ссылка на ROADMAP (N = 4–6) |

Строку 4 таблицы ВБC-10 и C.10.2 («ВБ-19 опирается на бесконечный ранг ω₀») уточнить так же: при фиксированном N нужен rank K_{ω₀} > N (РЧ-4).
