### 0.3. Границы R2 (без расширения)

**Входит:**
- линейная теория Кирхгофа–Лява;
- однородная изотропная квадратная пластина a × a, полная толщина t;
- SSSS;
- нагрузка q = const;
- N = 1, КК-МВИ Кириченко–Крысько, X⁰(x) = sin(πx/a);
- полушаги Y¹, X², Y³, X⁴, …;
- счётчики s, k (D-030).

**Не входит:**
- CCCC, прямоугольник a ≠ b, N ≥ 2;
- фон Карман, пластичность, Биргер, FGM, Мори–Танака и другие нелинейные или неоднородные модели;
- сетка по толщине;
- двумерный МКР и МКЭ (это будущие независимые сравнения).

Подмена КК-МВИ другим методом не допускается.

Разностная сетка — инструмент дискретизации одномерных задач (D-008), а не часть математического определения КК-МВИ.

**Единое определение коэффициентов (Д-3, п. 1).** Для заданного множителя f на (0, ℓ), f ≢ 0:

$$A=\int_0^\ell f^2,\qquad B=\int_0^\ell (f')^2>0,\qquad C=\int_0^\ell (f'')^2,\qquad F=q\int_0^\ell f .$$

B > 0, потому что f(0) = f(ℓ) = 0 и f ≢ 0. Иначе f′ ≡ 0, f = const = 0.
В форме P81 используется ∫ff″ = −B (MATH_SPEC, разд. 5.3: внеинтегральный член [ff′]₀^ℓ = 0). Знаки согласованы: −2B f″ в уравнении соответствует члену +2∫ff″·(·)″ формы P81.

## 3. Сетки (Д-1)

### 3.1. Одномерная сетка G(ℓ, n) — общая структура для X и Y

| Элемент | Определение |
|---|---|
| Число интервалов | n ≥ n_min = 4 (разд. 3.3); узлов n + 1 |
| Шаг | h = ℓ/n |
| Узлы | ξ_i = i·h, i = 0, …, n (вычислять как i·ℓ/n, а не накоплением) |
| Внутренние узлы | I = {1, …, n − 1}; сеточная функция задаётся вектором f ∈ ℝ^{n−1} |
| Главное условие | f₀ = f_n = 0 — **точно**, не неизвестные (входит в пространство V_h) |
| Скалярное произведение | ⟨u, v⟩ = h Σ_{i=1}^{n−1} u_i v_i — правило трапеций; концевые слагаемые равны нулю, так как u₀ = u_n = 0 |
| Первая разность (на полуцелых точках) | (D⁺f)_{i+½} = (f_{i+1} − f_i)/h, i = 0, …, n − 1 |
| Вторая разность | (Lf)_i = (f_{i−1} − 2f_i + f_{i+1})/h², i ∈ I, с f₀ = f_n = 0 — [ОПУБЛ. L-107 (g)] |
| Естественное условие f″ = 0 | (Lf)₀ = (Lf)_n := 0. При f₀ = 0 это равносильно фиктивной точке f₋₁ = −f₁ — [ОПУБЛ. L-107, с. 400]; L(Lf) берётся с этими нулевыми значениями |
| Четвёртая разность | L²f = L(Lf) (ЧВ-2) |

**Дискретные пространства:** V_h^x = ℝ^{n_x−1} (G(a, n_x)), V_h^y = ℝ^{n_y−1} (G(b, n_y)), V_h = V_h^x ⊗ V_h^y — сеточные функции
на внутренних узлах тензорной сетки, равные нулю на её границе.

### 3.2. Тензорная сетка и поле результата

- n_x и n_y задаются пользователем **независимо**: 11 × 11, 41 × 81, 121 × 121 узлов и т. п. (n ≥ 4).
- Поле полушага s вычисляется **только** в узлах тензорного произведения: w_ij = X_i Y_j. Отдельной сетки результата нет.
- Научные сравнения (Леви, полуаналитический эталон, Навье) — только в этих узлах.
- **Контрольная точка (x*, y*)** является узлом, только если x* = i·a/n_x и y* = j·b/n_y при целых i, j.
  - Проверка — точной целочисленной арифметикой: x*/a задаётся рациональным числом, например «½», «¼».
  - Иначе выдаётся «точка не является узлом сетки». Ни ближайший узел, ни интерполированное значение за узловое не выдаются.
  - Центр — узел, только если n_x и n_y чётны; четверти — если они делятся на 4.
- Интерполяция допускается только для графики и маркируется в результатах как неузловая визуализация.
- Для тестов симметрии квадрата и перестановки x ↔ y — **n_x = n_y**.
- При n_x ≠ n_y Y-полушаг использует G(b, n_y), а коэффициенты A_h, B_h, C_h, F_h — G(a, n_x); X-полушаг — наоборот.

### 3.3. Минимальное число интервалов [ВЫВОД ПРОЕКТА ЧВ-0; И-1]

- **Математически достаточно n ≥ 2:**
  - V_h ≠ {0};
  - a_h положительно определена (ЧВ-3);
  - F_h(X⁰) = q·h·ctg(π/(2n)) > 0 (ЧВ-6);
  - для нормированного множителя A_h ≥ h > 0 (разд. 9).
- **В программе n_min = 4 [И-1].**
  - При n ≥ 4 матрица одномерной задачи содержит обе граничные строки, изменённые отражением, и хотя бы одну строку (i = 2) с полным
    пятиточечным шаблоном без фиктивных узлов. Все типы строк схемы присутствуют.
  - При n = 2, 3 все строки граничные.
  - Нечётные n допустимы (центр тогда не узел).
- Асимптотический режим для проверки порядка начинается с n = 20 (разд. 3.4). Малые n в обычных расчётах дают грубый результат,
  но не запрещаются.

### 3.4. Вложенные последовательности для проверки порядка

- **Основная:** n_x = n_y ∈ {20, 40, 80, 160, 320}.
  - Последовательность вложенная: узлы сетки n — подмножество узлов сетки 2n (индекс i ↦ 2i).
  - Центр (½, ½) и четверти (¼, ¼), (¼, ½), (½, ¼), (¾, ¾) — узлы всех уровней.
- **Дополнительные уровни:** 640, 1280 и более — если на этом уровне выполнены допуски на округление (А-1а, А-6, А-8).

## 4. Дискретный функционал Π_h

### 4.1. Определение [ВЫВОД ПРОЕКТА ЧВ-3]

Для w ∈ V_h (нули на границе тензорной сетки):

$$(\Delta_h w)_{ij}=(L_xw)_{ij}+(L_yw)_{ij},\qquad (i,j)\ \text{внутренние};\qquad (\Delta_h w)=0\ \text{в граничных узлах};$$

$$a_h(w,v)=D\sum_{i=1}^{n_x-1}\sum_{j=1}^{n_y-1}h_xh_y(\Delta_hw)_{ij}(\Delta_hv)_{ij},\qquad l_h(w)=q\sum_{i,j}h_xh_y\,w_{ij},\qquad \Pi_h(w)=\tfrac12a_h(w,w)-l_h(w).$$

- Квадратура — тензорное правило трапеций. Граничные узлы дают нулевой вклад: w = 0, и (Δ_h w) = 0 по естественному условию (разд. 3.1).
- Это дискретный аналог принятой ν-свободной формы a(w, v) = D∬ΔwΔv (MATH_SPEC, разд. 2.2).

**Положительная определённость.**
- −L — симметричная положительно определённая матрица с собственными значениями μ_k = (4/h²)sin²(kπ/(2n)), k = 1, …, n − 1 [СТАНД.].
- Δ_h = L_x ⊗ I + I ⊗ L_y имеет собственные значения −(μ_k^x + μ_l^y).
- Поэтому a_h(w, w) ≥ D(μ₁^x + μ₁^y)²‖w‖²_h > 0 при w ≠ 0, где ‖w‖²_h = Σh_xh_y w²_ij.
- Так как sin θ ≥ 2θ/π, μ₁ ≥ 4/ℓ².
- Отсюда существует единственный минимизатор ω_h ∈ V_h функционала Π_h. Он нужен только в доказательствах; **в R2 не вычисляется** (это был бы двумерный МКР).

**Дискретная Лемма 1 и ν [ЧВ-3].**
- Пусть (D⁺_xD⁺_y w) — смешанная разность в центрах ячеек; w = 0 на границе.
- По ЧВ-1, применённому сначала по x (L_y w = 0 в граничных по x узлах), затем по y:
  $$\sum_{ij}h_xh_y(L_xw)_{ij}(L_yw)_{ij}=\sum_{\text{ячейки}}h_xh_y\bigl(D^+_xD^+_yw\bigr)^2 .$$
- Следовательно, дискретная форма с ν,
  D Σ h²[(L_xw)² + (L_yw)² + 2νL_xwL_yw] + 2D(1 − ν)Σ_яч h²(D⁺_xD⁺_yw)²,
  **тождественно равна** a_h(w, w) при любом ν.
- Дискретный прогиб от ν не зависит, ν входит только через D. [SCRATCH] Тождество проверено на случайной сеточной функции: разность — 0 в арифметике с плавающей точкой.

### 4.2. Суммирование по частям [СТАНД.; ЧВ-1]

**Утверждение.** Для u, v ∈ ℝ^{n+1} с u₀ = u_n = v₀ = v_n = 0 и ⟨·,·⟩ из разд. 3.1:

$$\langle u,Lv\rangle=\langle Lu,v\rangle=-\sum_{i=0}^{n-1}h\,(D^+u)_{i+\frac12}(D^+v)_{i+\frac12},\qquad \langle u,-Lu\rangle=\sum_{i=0}^{n-1}h\,(D^+u)^2_{i+\frac12}.$$

*Доказательство.*
1. Запишем Σ_{i=1}^{n−1}u_i(v_{i+1} − 2v_i + v_{i−1}) = Σ_{i=1}^{n−1}u_i(v_{i+1} − v_i) − Σ_{i=1}^{n−1}u_i(v_i − v_{i−1}).
2. В первой сумме добавим слагаемое i = 0: оно равно нулю, так как u₀ = 0.
3. Во второй сумме сдвинем индекс: Σ_{i=0}^{n−2}u_{i+1}(v_{i+1} − v_i). Добавим i = n − 1: оно равно нулю, так как u_n = 0.
4. Разность сумм равна Σ_{i=0}^{n−1}(u_i − u_{i+1})(v_{i+1} − v_i). Деление на h² и умножение на h дают формулу. ∎

**Условия тождества** (Д-1, п. 2):
- нулевые значения обеих функций на концах — главное условие;
- **равные** веса h во внутренних узлах;
- произвольный вес концевых узлов, так как там стоят нули.

При других весах (например, Симпсона) или при ином концевом операторе L тождество «сумма квадратов первых разностей = −⟨u, Lu⟩» **не выполняется**, и автоматически отождествлять их нельзя. В схеме R2 условия выполнены.

**Следствие.** ⟨Lu, Lv⟩ = ⟨u, L²v⟩: L симметричен относительно ⟨·,·⟩. Это дискретный аналог ∫ff⁗ = ∫(f″)² (MATH_SPEC, разд. 5.3, п. 3).

   Вывод:
   - (Δ_hw, Δ_hv) = ⟨LX, LX⟩⟨Y, Ỹ⟩ + ⟨X, LX⟩(⟨Y, LỸ⟩ + ⟨LY, Ỹ⟩) + ⟨X, X⟩⟨LY, LỸ⟩;

   Стационарность Π_h на M_s^h даёт систему. Это дословно разностное уравнение опубликованной схемы (разд. 2.3), применённой к сильной форме, с коэффициентами, вычисленными сеточными суммами.
   [SCRATCH] Сужение a_h и l_h на M_s^h совпало с h_y ỸᵀKY и h_yF_h1ᵀỸ до 4·10⁻¹⁵.
4. **A_h, B_h, C_h, F_h** — разд. 7.
5. **Порядок точности** — O(h_x² + h_y²) (ЧВ-7, ЧВ-8).
6. **Граничная аппроксимация.**
   - Главное условие Y₀ = Y_{n_y} = 0 — точно.
   - Естественное условие Y″ = 0 — через (L_yY)₀ = (L_yY)_{n_y} := 0, т. е. нечётное отражение.

### 5.4. Порядок точности одномерной задачи [ВЫВОД ПРОЕКТА ЧВ-7]

**Утверждение.** Пусть A > 0, B ≥ 0, C ≥ 0, D > 0 и f ∈ C⁶[0, ℓ] решает D(Af⁗ − 2Bf″ + Cf) = g, f = f″ = 0 на концах.
Пусть f_h решает K f_h = g|_I с теми же A, B, C. Тогда для e = f_h − f|_I:

$$\|e\|_{h}\le C_1h^2,\qquad \|Le\|_h\le C_2h^2,\qquad \max_i|e_i|\le \sqrt{\ell}\,(\|e\|_h\|Le\|_h)^{1/2}\le C_3h^2,$$

где C₁–C₃ зависят от ℓ, A, B, C и ‖f⁽⁴⁾‖_∞, ‖f⁽⁶⁾‖_∞. Константы явно не оцениваются.

*Доказательство.*
1. Положим z = f″. Тогда z(0) = z(ℓ) = 0, так как f″ = 0 на концах.
2. По формуле Тейлора [СТАНД.]: δ := L(f|_I) − z|_I удовлетворяет |δ_i| ≤ h²‖f⁽⁴⁾‖/12; τ := L(z|_I) − z″|_I удовлетворяет |τ_i| ≤ h²‖f⁽⁶⁾‖/12.
   Значения z на концах равны нулю, что совпадает с концевыми нулями оператора L.
3. L²f = L(z + δ) = Lz + Lδ, где δ продолжено нулём на концы (как в L). Отсюда
   K f|_I − g = D[A Lδ + Aτ − 2Bδ].
4. Получаем e = −K⁻¹DA Lδ − K⁻¹D(Aτ − 2Bδ). Операторы — функции симметричной L. Для собственных значений −μ_k:
   - ‖K⁻¹DAL‖₂ = max_k Aμ_k/(Aμ_k² + 2Bμ_k + C) ≤ 1/μ₁;
   - ‖K⁻¹D‖₂ ≤ 1/(Aμ₁²).
   Значит, ‖e‖_h ≤ ‖δ‖_h/μ₁ + (A‖τ‖_h + 2B‖δ‖_h)/(Aμ₁²) = O(h²).
5. Аналогично ‖K⁻¹DAL²‖₂ ≤ 1 и ‖K⁻¹DL‖₂ ≤ 1/(Aμ₁), откуда ‖Le‖_h = O(h²).
6. Дискретное неравенство Соболева: |e_i| ≤ Σ_{k<i}h|D⁺e| ≤ √ℓ(Σh(D⁺e)²)^{1/2} = √ℓ(−⟨e, Le⟩)^{1/2} (ЧВ-1). ∎

**Почему порядок сохраняется у границ.**
- Локальная невязка в строке 1 равна (Lδ)₁ ≈ −f⁗(0)/12 = O(1), если f⁗(0) ≠ 0 — а это так у Y-полушагов: AY⁗(0) = F/D.
- Она имеет вид L·δ с δ = O(h²), а K⁻¹L ограничен равномерно по h.
- Опубликованного доказательства этого факта в библиотеке нет (разд. 2.3). [SCRATCH] Подтверждено тестом с f⁗ = 1 на концах: порядок 2,00.

### 5.5. Порядок при фиксированном s [ВЫВОД ПРОЕКТА ЧВ-8, набросок индукции]

**Утверждение.** При q = const и фиксированном s имеем max_ij|w_h^{(s)} − w^{(s)}(x_i, y_j)| = O(h_x² + h_y²). Здесь w^{(s)} — непрерывное приближение MATH_SPEC.

*Шаги индукции:*
1. Непрерывные множители принадлежат C^∞ и удовлетворяют f = f″ = 0 (В-22). Применимы ЧВ-7 и формулы Тейлора.
2. **Согласованность квадратур** для гладкого множителя X с X = X″ = 0 на концах, по узловым значениям [СТАНД.]:
   - A_h — правило трапеций для X²; (X²)′ = 0 на концах, ошибка O(h⁴);
   - B_h — сумма h(D⁺X)² = h·[X′(ξ_{i+½}) + O(h²)]², правило средних, O(h²);
   - C_h — трапеции для (LX)² = (X″ + O(h²))²; на концах LX = 0 = X″, O(h²);
   - F_h — трапеции для X, O(h²).
3. **Устойчивость коэффициентов к возмущению множителя.** Пусть ‖X_h − X|‖_h + ‖L(X_h − X|)‖_h = O(h²) (это даёт ЧВ-7 для предыдущего полушага).

## 8. Решение линейных систем

### 8.1. Алгоритм [ВЫВОД ПРОЕКТА ЧВ-9; И-6]

Многочлен A r² − 2B r + C имеет корни r₁,₂ = (B ± √(B² − AC))/A. Квадратный корень берётся комплексным:
- при B² ≤ AC — комплексно-сопряжённые корни, или двойной вещественный корень при B² = AC;
- при B² > AC (возможно только в одномерных тестах) — вещественные корни, оба ≥ 0.

Re r₁,₂ ≥ 0 всегда (A > 0, B ≥ 0, C ≥ 0). Тогда

$$K=D\,A\,(L-r_1I)(L-r_2I)\quad(\text{множители коммутируют}),$$

и K Y = g решается двумя трёхдиагональными задачами Дирихле:

$$(L-r_1I)Z=g/(DA),\qquad (L-r_2I)Y=Z,\qquad Y:=\operatorname{Re}Y .$$

- Это последовательное решение двух уравнений второго порядка с нулевыми концевыми значениями — по идее L-107 (i), (n) [ОПУБЛ.].
  Для шага КК-МВИ сдвиги r₁,₂ комплексные — расширение проекта.
- При B² ≤ AC: Z = (L − r₂)Y, где Y вещественна. Теоретически Im Y = 0; вычисленная мнимая часть — мера округления.
- **Устойчивость каждого множителя:** матрица −L + r нормальна, ее собственные значения μ_k + r, |μ_k + r| ≥ μ₁ + Re r ≥ μ₁ > 0. Тогда ‖(−L + r)⁻¹‖₂ ≤ 1/μ₁ ≤ ℓ²/4.
  Число обусловленности множителя ≤ (μ_{n−1} + |r|)/μ₁ ≈ (2n/π)² + |r|/μ₁ — квадратный корень из cond(K).
- Диагональное преобладание: |2/h² + r| ≥ 2/h² — нестрогое во внутренних строках, строгое в крайних при Re r > 0 или по неприводимости.
  Поэтому метод прогонки (LU без выбора ведущего элемента) применим [СТАНД.]. Допускается ленточный LU с выбором ведущего (LAPACK gbsv через SciPy) [И-6].
- **Почти кратные корни** (B² ≈ AC) факторизацию не портят: каждый множитель обусловлен независимо от r₁ − r₂.
  [SCRATCH] Ошибка ~3·10⁻¹² при C = 1,001·π⁴, n = 640.
- Сборка пятидиагональной матрицы с разложением Холецкого **не используется** для решения: потеря точности, разд. 3.5.

### 8.2. Невязка (без сборки матрицы)

Невязка: r = g − D[A·L(LY) − 2B·LY + C·Y]. L применяется с концевыми нулями.

Нормированная обратная ошибка:

$$\eta=\frac{\|r\|_\infty}{D\,(16A/h^4+8B/h^2+C)\,\|Y\|_\infty+\|g\|_\infty}$$

(16A/h⁴ + 8B/h² + C — оценка ‖K‖_∞/D: сумма модулей элементов строки).

### 8.3. Правило контроля [И-7]

1. Если η ≤ η_max = 10⁻¹² и ‖Im Y‖_∞ ≤ 10⁻¹²‖Y‖_∞ — принято.
2. Иначе — один шаг итерационного уточнения: решить K δ = r тем же алгоритмом, Y ← Y + δ, пересчитать η.
3. Если условие не выполнено — выход с ошибкой **ERROR_LINEAR_SOLVE**. Результаты предыдущих полушагов сохраняются.
4. Нечисловые значения (NaN, ±∞) — **ERROR_NONFINITE**.

[SCRATCH] η ≈ 10⁻¹⁶ на всех сетках.

## 9. Нормировка и масштабирование

### 9.1. Нормировка множителей [И-4]

После полушага s вычисленный множитель f (Y при нечётном s, X при чётном) и заданный множитель g преобразуются так:

$$c=\sigma\,\|f\|_\infty,\quad \sigma=\operatorname{sign}\langle f,\mathbf 1\rangle;\qquad f\leftarrow f/c,\qquad g\leftarrow g\cdot c .$$

- Поле w^{(s)} = g ⊗ f не меняется: в точной арифметике — точно, с округлением — на ≤ 2u относительно в каждом узле.
- Заданный множитель следующего полушага имеет ‖·‖_∞ = 1 и ⟨·, 1⟩ > 0. Значит, A_h ≥ h > 0, F_h ≠ 0 (ЧВ-13) — диагностика вырождения упрощается.
- Нормировка выполняется **до** формирования и сохранения w^{(s)} и Π_h(w^{(s)}). Сохранённое поле w^{(s)} = g_норм ⊗ f_норм лежит в M_{s+1}^h с тем же массивом заданного множителя (условие ЧВ-11).
- Влияние на коэффициенты: A, B, C → c²·, F → c·. Нормировочно-инвариантные величины:
  β = B/A, γ = C/A, χ = F²/A (последнее уточнение владельца, п. 3). χ = 2φ²/ℓ, где φ = F√(ℓ/(2A)); знак F фиксирован правилом σ.
- Критерии остановки и сравнения используют **только поле w** и Π_h (MATH_SPEC, разд. 3), а не изменения множителей.

### 9.2. Масштабы

- Расчёт ведётся в размерных величинах пользователя (D-009): a, t, E, ν, q, D = Et³/[12(1 − ν²)].
- Нормированный заданный множитель безразмерен. Вычисленный множитель несёт размерность прогиба, ~qa⁴/D.
- Число обусловленности K от масштабов не зависит: K = DA_h × (функция от L, β, γ).
- Переполнение исключено для физически разумных данных. Входные данные проверяются [И-5]: a, t, E конечны и > 0; q конечна и ≠ 0; |ν| < 1 (условие D > 0, MATH_SPEC В-1). Других ограничений на ν R2 не вводит.
- Безразмерный выход: w̄ = wD/(qa⁴) (MATH_SPEC, разд. 2.5), x̄ = x/a, ȳ = y/b. Для q = 0 — ошибка ввода ERROR_INPUT (R2: q ≠ 0).

### 9.3. Масштабные свойства дискретной схемы [ВЫВОД ПРОЕКТА ЧВ-14]

При h = a/n все операторы однородны:
- L ~ a⁻², A_h ~ a, B_h ~ a⁻¹, C_h ~ a⁻³, F_h ~ qa;
- K ~ D·a·a⁻⁴, решение ~ qa⁴/D.

Отсюда для схемы **точно** (в точной арифметике) w_h(λq) = λw_h(q), w_h·D инвариантно, w̄_h(i, j) не зависит от a, E, t, ν при тех же n_x, n_y.
Это аналог В-12 для схемы. Тест А-9 проверяет реализацию.

## 10. Энергетический тест (Q-021)

### 10.1. Свойства точных дискретных полушагов [ВЫВОД ПРОЕКТА ЧВ-10, ЧВ-11]

**ЧВ-10 (дискретная проекционность).** Пусть w^{(s)} ∈ M_s^h — точное решение системы полушага s. Тогда a_h(w^{(s)}, v) = l_h(v) для всех v ∈ M_s^h,
т. е. w^{(s)} — a_h-ортогональная проекция ω_h на M_s^h. Для любого v ∈ M_s^h:

$$\Pi_h(v)-\Pi_h(w^{(s)})=\tfrac12\|v-w^{(s)}\|_{a_h}^2 .$$

*Доказательство.* Π_h(v) − Π_h(w) = ½a_h(v − w, v − w) + [a_h(w, v − w) − l_h(v − w)]. Скобка равна нулю, так как v − w ∈ M_s^h. ∎
Пространство M_s^h конечномерно, поэтому замкнуто; регулярность множителей не требуется.

**ЧВ-11 (энергетическое тождество, s ≥ 2).** Условия:
1. s ≥ 2;
2. w^{(s−1)} ∈ M_s^h. Это выполнено по построению: при нечётном s w^{(s−1)} = X^{s−1} ⊗ Y^{s−2} ∈ {X^{s−1} ⊗ Ỹ}, при чётном — симметрично. Используется тот же сохранённый массив заданного множителя (разд. 9.1);
3. на всех полушагах одна и та же положительно определённая форма a_h и одна l_h: одни n_x, n_y, a, D, q, без смены сетки в ходе расчёта;
4. точная минимизация на M_s^h.

Тогда

$$\Pi_h(w^{(s-1)})-\Pi_h(w^{(s)})=\tfrac12\|w^{(s)}-w^{(s-1)}\|_{a_h}^2\ \ge 0 .$$

При s = 1 предыдущего поля нет: w⁰ в алгоритме отсутствует. **Первое сравнение — пара (w¹, w²).** Сравнение Y¹ с нулевым полем тестом последовательности не является и не выполняется.

**ЧВ-12.** Для точного w^{(s)}: a_h(w^{(s)}, w^{(s)}) = l_h(w^{(s)}), то есть Π_h(w^{(s)}) = −½‖w^{(s)}‖²_{a_h} = −½ l_h(w^{(s)}). Получается из ЧВ-10 при v = 0 ∈ M_s^h.

**ЧВ-13 (невырожденность и ограниченность).**
- F_h(X⁰) = q h ctg(π/(2n_x)) ≠ 0 ⇒ Y¹ ≠ 0 ⇒ Π_h(w¹) < 0.
- По ЧВ-11 Π_h(w^{(s)}) ≤ Π_h(w¹) < 0, откуда w^{(s)} ≠ 0. Оба множителя ненулевые, A_h > 0 на каждом следующем полушаге.
- По ЧВ-12 ‖w^{(s)}‖_{a_h} не убывает по s. F_h на каждом шаге ≠ 0: l_h(w^{(s)}) = q⟨X, 1⟩⟨Y, 1⟩ = ‖w^{(s)}‖² > 0.
- Σ_{s≥2}‖w^{(s)} − w^{(s−1)}‖²_{a_h} ≤ 2(Π_h(w¹) − Π_h(ω_h)) < ∞. Поэтому изменения стремятся к нулю.
  **Сходимость последовательности w^{(s)} этим не доказывается** (как и в MATH_SPEC, разд. 7.4).
- Это дискретный аналог В-22/В-25. Доказательство проще, так как пространство конечномерно.

Q-021 — собственный тест проекта. С утверждением авторов P82 о монотонности (Q-019) он не смешивается и на него не ссылается.

### 10.2. Приближённое решение систем [ВЫВОД ПРОЕКТА ЧВ-15]

Пусть Ŷ — вычисленное решение, ρ = g − KŶ — его невязка, d_f = f_{s−2} − Ŷ — разность одномерных векторов, d = w^{(s−1)} − ŵ^{(s)} = g_норм ⊗ d_f.
Аналогично ЧВ-10 (тождество алгебраическое, верно для любого Ŷ):

$$\Delta\Pi_s:=\Pi_h(w^{(s-1)})-\Pi_h(\hat w^{(s)})=\tfrac12\|d\|_{a_h}^2-\gamma_s,\qquad \gamma_s:=h\,\rho^{\mathsf T}d_f,$$

$$|\gamma_s|\le\|\hat w^{(s)}-w^{(s)}_*\|_{a_h}\,\|d\|_{a_h},$$

где w_*^{(s)} — точное решение системы.

- Дефект тождества линеен по ошибке решения, а точная убыль квадратична по ‖d‖.
- При ‖d‖_{a_h} ≫ ‖ŵ − w_*‖_{a_h} тест информативен. При ‖d‖ сравнимом с ошибкой решения — нет.
- Следующий полушаг использует сохранённое ŵ^{(s)}. Условие «предыдущее поле лежит в подпространстве» сохраняется и при неточном решении.

### 10.3. Округление при вычислении Π_h [И-8, первая модель округления]

Энергии вычисляются **двумерной** сборкой по определению разд. 4.1. Это путь, независимый от одномерных матриц, поэтому тест проверяет и согласованность сборки.

Обозначим:

$$(|\Delta|_hw)_{ij}=\frac{|w_{i-1,j}|+2|w_{ij}|+|w_{i+1,j}|}{h_x^2}+\frac{|w_{i,j-1}|+2|w_{ij}|+|w_{i,j+1}|}{h_y^2},\qquad \hat S(w)=D\sum h_xh_y\,|\Delta_hw|\,(|\Delta|_hw)+|q|\sum h_xh_y|w| ,$$

$$R(w)=u\,(\lceil\log_2N\rceil+16)\,\hat S(w),\qquad N=(n_x-1)(n_y-1).$$

Обоснование первого порядка:
- ошибка шаблона ≤ ~5u(|Δ|_h w);
- квадрат — ≲ 11u|Δw|(|Δ|w);
- попарное суммирование — u⌈log₂N⌉Σ|слагаемых|.

Это **модель**, а не строгая граница. Она консервативна за счёт множителя 10 ниже.

Ошибка формирования поля w_ij = fl(X_iY_j) (≤ u|w|) даёт член R_f = 4u(max(n_x, n_y)/π)²‖w^{(s)}‖_{a_h}‖d‖_{a_h}.

### 10.4. Порог и правило применения [И-9]

Для каждого s ≥ 2 вычисляются:
- P_s = Π_h(w^{(s)}), ΔP_s = P_{s−1} − P_s;
- Q_s = ½a_h(d_s, d_s) — двумерная сборка по полю d_s = w^{(s−1)} − w^{(s)};
- γ_s (одномерно).

Порог:

$$\tau_s=|\gamma_s|+10\,[R(w^{(s-1)})+R(w^{(s)})+R_f] .$$

- **E1 (невозрастание):** ΔP_s ≥ −τ_s.
- **E2 (тождество):** |ΔP_s − Q_s| ≤ τ_s.
- **Разрешимость теста:** тест «разрешён», если Q_s ≥ 10τ_s.
  - Если не разрешён — статус **UNRESOLVED**: изменение энергии ниже уровня округления. Это не FAIL и не PASS.
  - Обязательного PASS/FAIL вне этой области нет.
- **Статусы:** s = 1 — NOT_APPLICABLE; s ≥ 2 — PASS / FAIL / UNRESOLVED.
- FAIL разрешённого теста — признак дефекта реализации: несогласованная сборка, неверное подпространство, счётчики, нормировка.
  Выход ERROR_ENERGY_TEST, если FAIL по E1.
- Допуск по прогибу и допуск по энергии механически не отождествляются: τ_s строится из невязки, γ_s и модели округления. Коэффициентов между ними не постулируется.
- Квадратичный характер убыли: при относительном изменении поля ε тест разрешим, пока ε² ≳ 10τ/|P| ~ u·n². [SCRATCH] Разрешены s = 2, 3, 4 при n = 160; ΔP − Q ≈ 10⁻¹⁹ при τ ~ 10⁻¹³.
- **Обязательные условия применения в R2:** тест должен быть разрешён при s = 2 на всех сетках проверки и при s = 3 на сетках n ≤ 320. Иначе тест считается **не выполненным** — с объяснением, а не FAIL.

## 11. Остановка итераций (Q-009) [И-10]

### 11.1. Величины (полное поле, s ≥ 2)

- ε_s^∞ = max_ij|w^{(s)} − w^{(s−1)}| / max_ij|w^{(s)}|.
- ε_s^E = ‖w^{(s)} − w^{(s−1)}‖_{a_h} / ‖w^{(s)}‖_{a_h}. Вычисляется по разностному полю, без вычитания энергий.
- ε_s^{L2} = ‖w^{(s)} − w^{(s−1)}‖_h / ‖w^{(s)}‖_h — диагностика.
- θ_s = ε_s^E / ε_{s−1}^E — наблюдаемое отношение последовательных изменений (s ≥ 3).
- Энергетический тест — разд. 10, где применим.

### 11.2. Параметры по умолчанию

| Параметр | Значение | Основание |
|---|---|---|
| tol_∞ | 10⁻¹⁰ | на 3–4 порядка ниже ошибки дискретизации на n = 640 ([SCRATCH] ~3·10⁻⁷); выше пола округления ~10⁻¹⁴ |
| tol_E | 10⁻⁸ | пол округления ε^E ≈ 10u(n/π)² ([SCRATCH] 1,5·10⁻¹² при n = 320; 7·10⁻¹² при n = 640) |
| s_min | 3 | хотя бы одно обновление Y после X |
| s_max | 100 | [SCRATCH] сходимость к tol за s ≈ 6; запас |
| строгий режим (чувствительность) | tol_∞/100, tol_E/100 | разд. 11.4 |

Если tol_E < 10·ε_floor, где ε_floor = 10u(max(n_x, n_y)/π)², — ошибка конфигурации ERROR_INPUT. Требование машинной точности не ставится.

### 11.3. Алгоритм

1. После каждого полушага s ≥ 2 вычислить величины 11.1 и энергетический тест.
2. **CONVERGED** при s ≥ s_min, если для s − 1 и s одновременно ε^∞ ≤ tol_∞ и ε^E ≤ tol_E.
3. **STAGNATED**, если 10 полушагов подряд θ_s ≥ 0,9 при ε_s^E > tol_E. Расчёт останавливается, результаты сохраняются, статус «не сошлось».
4. **MAX_HALF_STEPS**, если s = s_max без выполнения п. 2.
5. **Ошибочные выходы:** ERROR_LINEAR_SOLVE, ERROR_NONFINITE, ERROR_DEGENERATE (F_h = 0, A_h ≤ 0 или Π_h(w^{(s)}) ≥ 0), ERROR_ENERGY_TEST (FAIL E1 разрешённого теста), ERROR_INPUT.
6. **Диагностика хвоста:**
   - T_s = ε_s^E·θ̄/(1 − θ̄), где θ̄ — медиана θ последних трёх полушагов, если θ̄ < 1;
   - отмечается как «оценка при предположении сжатия»;
   - условие сжатия **не доказано**, поэтому T_s — не гарантия.
   - Малое ε_s само по себе не доказывает сходимость последовательности (ЧВ-13).

### 11.4. Проверка чувствительности к остановке

Повторить расчёт в строгом режиме и определить:
- S_stop(n) = max_ij|w_строгий − w_обычный| / max|w|;
- E_disc(n) = max по общим узлам |w_n − w_{2n}| / max|w| (для старшего уровня — пара (n/2, n)).

Требование (А-11): S_stop ≤ 0,01·E_disc. Только тогда остановка не искажает исследования сходимости по сетке.

### 11.5. Что сохраняется после каждого полушага

- s, k, тип полушага (Y/X), направление и сетка;
- A_h, B_h, C_h, F_h — до нормировки и после нормировки предыдущего шага (с указанием), а также β, γ, χ;
- нормировочный множитель c;
- нормированные множители X и Y (узловые векторы);
- ‖ρ‖_∞, η, флаг уточнения, ‖Im Y‖/‖Y‖;
- P_s = Π_h, ‖w‖_{a_h}, ε^∞, ε^E, ε^{L2}, θ_s;
- ΔP_s, Q_s, γ_s, τ_s, статус энергетического теста;
- w̄ в контрольных точках (или «точка не является узлом сетки»);
- статус выхода.

Входные данные (a, t, E, ν, q, n_x, n_y, параметры остановки) и версии пакетов сохраняются вместе с результатом (G5).

| Источник | Как измеряется | Чем не является |

## 12. Сеточная сходимость и экстраполяция

- **Наблюдаемый порядок по эталону:** p_n = log₂(E(n)/E(2n)), где E — ошибка относительно Леви (s = 1) или полуаналитического эталона (s = 1, 2, 3). Значения берутся в общих узлах.
- **Самосходимость** (если эталона нет): p_n = log₂(|w_n − w_{2n}|/|w_{2n} − w_{4n}|) в общих узлах.
- При втором порядке отношение E(n)/E(2n) → 4 **асимптотически**. Ровно 4 на всех сетках не требуется: допуски — разд. 18.
- **Экстраполяция Ричардсона:** w_RE(n, 2n) = (4w_{2n} − w_n)/3 в узлах сетки n.
  - Выполняется **при фиксированном s**. Результат называется «экстраполированное значение при фиксированном s».
  - Либо выполняется после проверки чувствительности 11.4 и тогда называется «экстраполированное значение при остановке по критерию (tol)».
  - Доказанным пределом КК-МВИ по s оно не называется.
  - Ричардсон применяется только при наблюдаемом p ∈ [1,9; 2,1] на этой паре.

## 13. Тест одномерного решателя (manufactured solution)

Это тест одномерного численного решателя, а не физический режим продукта. Решатель получает произвольную правую часть g (вектор).

### 13.1. T-1D-1: синус

- **Точная функция:** f(y) = sin(κy), κ = π/ℓ. f = f″ = 0 на концах. Все чётные производные на концах равны нулю, нечётное продолжение гладкое.
- **Коэффициенты:** (A, B, C) ∈ {(1, 0, 0), (1, 3, 5), (0,5, π²/2, π⁴/2)}; D = 1; ℓ ∈ {1, 2,5}.
- **Правая часть:** g = D(Aκ⁴ + 2Bκ² + C)sin(κy).
- **Точное дискретное решение [ЧВ-16]:** sin(κy_i) — собственный вектор L. Поэтому
  f_h = ρ_h sin(κy), ρ_h = (Aκ⁴ + 2Bκ² + C)/(Aμ₁² + 2Bμ₁ + C).
- **Ошибка:** e_∞ = max|f_h − f| / max|f|.
- Ожидается **ровно** e_∞ = |1 − ρ_h| = O(h²) с главным членом, который вычисляется явно.
- Тест проверяет сборку оператора; на граничную обработку он слабый (нечётное продолжение гладкое).

### 13.2. T-1D-2: многочлен с f⁗ ≠ 0 на концах

- **Точная функция:** f(y) = (y⁴ − 2ℓy³ + ℓ³y)/24. Проверка: f(0) = f(ℓ) = 0, f″ = (y² − ℓy)/2 обращается в нуль на концах, f⁗ ≡ 1.
- **Правая часть:** g = D[A − 2B(y² − ℓy)/2 + C f(y)].
- **Коэффициенты:** (1, 0, 0) и (1, 3, 5); ℓ = 1; D = 1.

## 15. Полуаналитический контроль последовательности КК-МВИ при N = 1

Назначение — **независимая от МКР проверка реализации полушагов** s = 1, 2, 3, … Это не решение полной двумерной задачи и не замена
основного МКР-решателя (D-008). Модуль — `kkvim_reference` (разд. 19).

### 15.1. Решение одномерного полушага синусным рядом [ВЫВОД ПРОЕКТА ЧВ-17]

Задача: D(A f⁗ − 2B f″ + C f) = F, f(0) = f(ℓ) = f″(0) = f″(ℓ) = 0. Здесь A > 0, B ≥ 0, C ≥ 0, F = const — коэффициенты из заданного множителя (разд. 1).

$$f(\xi)=\sum_{m\ \text{нечёт}}c_m\sin\lambda_m\xi,\qquad \lambda_m=\frac{m\pi}{\ell},\qquad c_m=\frac{4F}{D\,m\pi\,(A\lambda_m^4+2B\lambda_m^2+C)};\qquad c_m=0\ \text{при чётных}\ m .$$

*Вывод.*
- Подставим Ỹ = sin λ_mξ в слабую форму MATH_SPEC, разд. 4.3.
- Синусы ортогональны в L₂(0, ℓ), их производные — тоже, поэтому a(f, sin λ_m) = D(Aλ_m⁴ + 2Bλ_m² + C)(ℓ/2)c_m.
- Правая часть: F∫₀^ℓ sin λ_mξ dξ = F(1 − (−1)^m)ℓ/(mπ), то есть 2Fℓ/(mπ) при нечётном m и 0 при чётном.
- Приравнивая, получаем c_m.

*Применимость.*
- |c_m| = O(m⁻⁵), Σλ_m⁴c_m² < ∞, поэтому ряд сходится в W₂²(0, ℓ) к функции из V_ℓ.
- Ряд удовлетворяет слабой форме на каждом sin λ_m. По плотности синусных сумм в V_ℓ (MATH_SPEC, разд. 6.4, п. 1) — на всём V_ℓ.
- По единственности (В-20) это и есть решение полушага.
- Условия f = 0 выполняются почленно; f″ = 0 — как естественное условие (В-21).

**Область применения (Д-3, п. 5):** только постановка R2 — q = const, постоянные коэффициенты, SSSS, N = 1.
Для нелинейных, неоднородных задач, других краевых условий и N ≥ 2 метод **не** объявляется применимым.

### 15.2. Коэффициенты следующего полушага по ортогональности [ЧВ-18]

Для f = Σ c_m sin λ_mξ на (0, ℓ) (сумма по нечётным m; при W₂²-сходимости допустимо почленное интегрирование):

$$A'=\int_0^\ell f^2=\frac\ell2\sum c_m^2,\qquad B'=\int_0^\ell(f')^2=\frac\ell2\sum\lambda_m^2c_m^2,\qquad C'=\int_0^\ell(f'')^2=\frac\ell2\sum\lambda_m^4c_m^2,$$

$$F'=q\int_0^\ell f=q\sum c_m\frac{2\ell}{m\pi}=2q\sum\frac{c_m}{\lambda_m}\quad(m\ \text{нечёт}).$$

*Доказательство.*
- ∫₀^ℓ sin λ_m sin λ_k = (ℓ/2)δ_mk и ∫₀^ℓ cos λ_m cos λ_k = (ℓ/2)δ_mk при m, k ≥ 1 [СТАНД.].
- f′ = Σλ_mc_m cos λ_m, f″ = −Σλ_m²c_m sin λ_m; ряды сходятся в L₂, так как Σλ_m⁴c_m² < ∞. Это равенство Парсеваля.
- ∫₀^ℓ sin λ_m = 2ℓ/(mπ) при нечётном m.

B′ > 0, так как c₁ ≠ 0 при F ≠ 0. Пространственной квадратуры нет.

### 15.3. Скалярная рекурсия [ЧВ-19]

Обозначим G_s = (A, B, C, F)_s — коэффициенты, по которым решается полушаг s (из заданного множителя полушага s); ℓ_s — длина отрезка неизвестного
множителя (b при нечётном s, a при чётном), λ_m = mπ/ℓ_s, P_m = Aλ_m⁴ + 2Bλ_m² + C, κ_s = 4F/(Dπ). Тогда c_m = κ_s/(mP_m), и

$$G_{s+1}=\Bigl(\tfrac{\ell_s}{2}\kappa_s^2S_0,\ \tfrac{\ell_s}{2}\kappa_s^2S_2,\ \tfrac{\ell_s}{2}\kappa_s^2S_4,\ q\,\tfrac{2\ell_s}{\pi}\kappa_s\,T\Bigr),\qquad S_k=\sum_{m\ \text{нечёт}}\frac{\lambda_m^k}{m^2P_m^2},\quad T=\sum_{m\ \text{нечёт}}\frac1{m^2P_m}.$$

- Начало: G₁ = (a/2, π²/(2a), π⁴/(2a³), 2qa/π) (MATH_SPEC, разд. 5.1).
- Все слагаемые сумм **одного знака**: P_m > 0, а знак c_m — знак F. Вычитаний нет.

**Что хранится:** G₁, …, G_s (по четыре числа на полушаг) и ℓ_s.
- Множитель, вычисленный на полушаге j, восстанавливается формулой c_m(G_j) в любой точке.
- Поле w^{(s)} = X^{s−1} ⊗ Y^{s} (s нечётно) или X^{s} ⊗ Y^{s−1} (s чётно). Нужны множители полушагов s и s − 1 (для s = 1 — X⁰ = sin(πx/a)).
- **Узловые значения [И-11]:** f(ξ_i) = Σ c_m sin(mπ i/n) в узлах ξ_i = iℓ/n.
  - Аргумент приводится в целых числах: r = (m·i) mod 2n, sin(mπi/n) = sin(πr/n). Больших аргументов тригонометрических функций нет.
  - Значения sin(πr/n), r = 0, …, 2n − 1, вычисляются один раз. Погрешность каждого ≤ ~u (по свойству библиотечной функции sin) [ИСТОЧНИК НЕ ПОДТВЕРЖДЁН — разд. 2.4, п. 3].
- **Суммирование [И-15]:**
  - коэффициенты A′, B′, C′, F′ — суммы одного знака, вычисляются компенсированным суммированием с корректным округлением (`math.fsum`);
  - узловые суммы рядов (знакопеременные) — `math.fsum` либо попарное суммирование, начиная с малых членов.
  - Ошибки суммирования оцениваются отдельно от хвостов усечения (разд. 15.5).

**Нормировка (Д-3, п. 2).**
- Замена множителя f → κf переводит G_{s+1} → (κ²A, κ²B, κ²C, κF), решение следующего полушага — в c/κ. Поле не меняется (В-13).
- Для устойчивости масштабов допускается каноническая нормировка: после вычисления c — c ← c/‖c‖₂ (то есть A′ = ℓ/2), знак — F′ > 0. Скалярный множитель поля σ_s хранится отдельно: w = σ_s X̂ ⊗ Ŷ.
- Сравнения с МКР — по полному полю w (непосредственно) и по инвариантам β = B/A, γ = C/A, χ = F²/A. Они от нормировки не зависят. Можно сравнивать и сами A, B, C, F, но только при одной явно заданной нормировке в обоих вычислениях (например, max-норма заданного множителя = 1, ⟨·,1⟩ > 0). Отличие отдельных A, B, C, F, вызванное только разной нормировкой, ошибкой реализации не считается.

### 15.4. Аналитические оценки усечения (Д-3, п. 3) [ЧВ-20]

M — **наибольший сохранённый нечётный индекс** (число членов — (M + 1)/2).

1. Так как B, C ≥ 0, P_m ≥ Aλ_m⁴ = Aπ⁴m⁴/ℓ⁴. Отсюда
   $$|c_m|\le\frac{K}{m^5},\qquad K=\frac{4|F|\ell^4}{D\,A\,\pi^5}.$$
2. Для p > 1 и нечётного M: Σ_{m нечёт, m>M} m^{−p} ≤ ½∫_M^∞ t^{−p}dt = 1/(2(p − 1)M^{p−1}).
   Каждый член m^{−p} ≤ ½∫_{m−2}^{m}t^{−p}dt, так как t^{−p} убывает; объединение отрезков покрывает [M, ∞).
3. Остатки (f_M — усечённая сумма; A_M и т. д. — коэффициенты по усечённому ряду):

| Величина | Остаток (точные входные G) |
|---|---|
| f(ξ), равномерно | \|f − f_M\| ≤ K/(8M⁴) |
| A | 0 ≤ A − A_M ≤ (ℓ/2)K²/(18M⁹) |
| B | 0 ≤ B − B_M ≤ (ℓ/2)K²(π/ℓ)²/(14M⁷) |
| C | 0 ≤ C − C_M ≤ (ℓ/2)K²(π/ℓ)⁴/(10M⁵) |
| F | \|F − F_M\| ≤ \|q\|(2ℓ/π)K/(10M⁵) |

4. **Выбор M [И-12].** Наименьшее нечётное M, при котором:
   - все остатки разд. 15.4, п. 3, отнесённые к значениям по усечённому ряду (|f|_max, A_M, B_M, C_M, |F_M|), ≤ ε_rel = 10⁻¹⁴;
   - абсолютный остаток f ≤ ε_abs = 10⁻¹⁴·|f_M|_max.

   M вычисляется по формулам из K, а не фиксируется. Ориентир: K/|c₁| = P₁/(Aλ₁⁴) ≤ 4 при s = 1 на квадрате; для C нужно M⁵ ≳ 10¹⁵, т. е. M ~ 10³.

### 15.5. Накопление ошибки по полушагам (Д-3, п. 4) [ЧВ-21]

Различаются:
- (а) усечение ряда полушага при точных входных G — разд. 15.4;
- (б) ошибка входных G от предыдущих полушагов;
- (в) её перенос и усиление рекурсией;
- (г) округление.

**Правило переноса (первый порядок, строгое при знакопостоянных слагаемых).**
- Пусть относительные ошибки входа: ρ_F = |δF|/|F|, ρ_P = max(|δA|/A, |δB|/B, |δC|/C).
- Так как P_m — сумма неотрицательных слагаемых, |δP_m|/P_m ≤ ρ_P. Тогда |δc_m|/|c_m| ≤ ρ_F + ρ_P + O(ρ²) для каждого m.
- Все суммы S_k, T знакопостоянны. Поэтому относительная ошибка A′, B′, C′ ≤ 2(ρ_F + ρ_P), F′ ≤ ρ_F + ρ_P (с O(ρ²)).
- Для ρ_s := max относительной ошибки компонент G_s:
  $$\rho_{s+1}\le 4\rho_s+\tau_{s+1}+O(\rho_s^2),\qquad \rho_s\le\sum_{j\le s}4^{\,s-j}\tau_j ,$$
  где τ_j — относительный остаток (а) плюс округление (г). Округление: суммы положительных членов по `math.fsum`, ≤ ~12u на полушаг.
- Поле: относительная (к Σ|c_m|) ошибка значений ≤ ρ_F + ρ_P + K/(8M⁴Σ|c_m|) + округление.

**Раздельный учёт вкладов (отчёт эталона по каждому s):**

| Вклад | Оценка | Статус |
|---|---|---|
| (а) хвост ряда при точных входных G | формулы разд. 15.4 | строгая аналитическая оценка (ЧВ-20) |
| (б)+(в) входные G и их перенос рекурсией | ρ_s ≤ Σ4^{s−j}τ_j | строгая в первом порядке (ЧВ-21) |
| (г1) вычисление sin(πr/n) | ≤ ~u на значение; вклад в поле ≤ ~uΣ\|c_m\| | [ИСТОЧНИК НЕ ПОДТВЕРЖДЁН] (свойство библиотеки) |
| (г2) суммирование | fsum: корректно округлённый результат (≤ u относительно суммы); попарное: ≲ u⌈log₂M⌉Σ\|слагаемых\| | [ИСТОЧНИК НЕ ПОДТВЕРЖДЁН] (разд. 2.4, п. 3) |
| (г3) вычисление c_m, P_m | ≤ ~8u относительно на член (операции над положительными числами) | [СТАНД.] модель первого порядка |

**Гарантия.** Для s ≤ 3 при τ_j ≤ 10⁻¹⁴ получаем ρ₃ ≤ 21·10⁻¹⁴ ≈ 2·10⁻¹³. Этого достаточно для требования δ_SA ≤ 10⁻¹² (разд. 15.7).
Для больших s граница 4^s·τ пессимистична. Строгий перенос сохраняется, но может не дать нужной точности. Тогда дополнительно выполняется практический контроль: удвоение M и сравнение. Он **не является** доказательством точности (Д-3, п. 4).

### 15.6. Почти кратные характеристические корни (Д-2, п. 7)

- Характеристическое уравнение однородной задачи: Ak⁴ − 2Bk² + C = 0, k² = (B ± i√(AC − B²))/A.
- По Коши–Буняковскому B² = (∫ff″)² ≤ ∫f²·∫(f″)² = AC. Равенство — только если f″ = −κ²f, т. е. f — синусный режим. Это так при s = 1: X⁰ = sin, корень двойной, решение содержит ch и y·sh (В-29).
- При s ≥ 2 множитель близок к sin(πξ/ℓ). [SCRATCH] В пределе α₃/α₁ ≈ 0,0134; отсюда (AC − B²)/(AC) ≈ 10⁻², разность корней ~10 %.
- В экспоненциальном или гиперболическом базисе при AC − B² → 0 базисные функции e^{k₁ξ}, e^{k₂ξ} почти линейно зависимы. Коэффициенты решения содержат множители ~1/(k₁ − k₂) с взаимным уничтожением, и при сильном сближении корней теряются значащие цифры. Нужен отдельный предельный случай.
- **Синусное представление** этой проблемы не имеет:
  - c_m — частное положительных величин, формула не зависит от разности корней;
  - B² = AC (s = 1) обрабатывается той же формулой.
- **Остаются ограничения:**
  - алгебраическая сходимость |c_m| = O(m⁻⁵): нужны M ~ 10³ членов, что дёшево;
  - ряды f‴, f⁗ не сходятся равномерно к значениям на концах: f⁗(0) ≠ 0, это эффект Гиббса. Они не используются;
  - применимость только в постановке R2.
- Экспоненциальный, гиперболический или тригонометрический базис **не требуется**.
- В основном МКР-решателе аналог проблемы снят факторизацией (разд. 8.1).

## 17. Исследование точности (группа B; без PASS/FAIL, D-025)

Для s ∈ {1, 2, 3, 4} и для остановки по критерию; сетки — разд. 3.4.

| Показатель | Формула | Назначение |
|---|---|---|
| Центр | δ_c = (w̄_h^{(s)}(½, ½) − w̄_N(½, ½))/w̄_N(½, ½) | отличие от Навье в центре |
| Поле, максимум | E_∞^N = max_ij\|w̄_h − w̄_N\| / max_ij\|w̄_N\| | по узлам |
| Поле, L₂ | E_2^N = (Σω_ij(w̄_h − w̄_N)²)^{1/2}/(Σω_ij w̄_N²)^{1/2}, ω — веса трапеций | по узлам |
| Четверти | то же в (¼, ¼), (¼, ½), (½, ¼) | форма поля |
| Энергетическая ошибка | e_s^{(h)} = (Π_h(w_h^{(s)}) − Π(ω₀))/\|Π(ω₀)\| | мера MATH_SPEC, 7.4 |
| Непрерывное отличие N = 1 | δ_c^SA = (w_SA^{(s)} − w_N)/w_N в центре; E_∞ по узлам | без ошибки дискретизации |
| Разложение | w_h^{(s)} − w_N = (w_h^{(s)} − w_SA^{(s)}) + (w_SA^{(s)} − w_N) | отделение МКР от приближения N = 1 (D-016) |
| Асимметрия x ↔ y | A_sym(s) = max\|w_ij − w_ji\| / max\|w\|, n_x = n_y | наблюдение (разд. 18, А-8) |

**Замечания.**
- e_s^{(h)} смешивает непрерывную энергию Π(ω₀) и дискретную Π_h. Её отличие от непрерывной e_s — O(h²) и может иметь любой знак: Π_h не ограничен снизу величиной Π(ω₀).
  Поэтому e_s^{(h)} даётся на всех сетках вместе с экстраполяцией при фиксированном s. Непрерывная e_s вычисляется для полуаналитической последовательности: Π(w_SA^{(s)}) = −½q∫X∫Y (В-23) — без сетки.
- Универсального порога («КК-МВИ обязан совпасть с Навье лучше 1 %») нет. Отличие — результат исследования.
- [SCRATCH, не результат R2] центр N = 1 после остановки ≈ 0,004058181 против Навье 0,004062353 (−0,10 %); e ≈ 2·10⁻⁴.
  Энергетическая ошибка N = 1 не стремится к нулю (MATH_SPEC, 7.4).
- Точность эталона Навье должна быть ≤ 1/10 (предпочтительно 1/100) наименьшего измеряемого отличия. При δ_w = 4,06·10⁻⁹ и отличии ~4·10⁻⁶ (SCRATCH) это 1/1000. Подтверждается фактическими значениями R2.
