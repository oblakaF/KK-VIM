## 2. Точное тождество и обозначения

### 2.1. Определение γ_s (RO, ВОК-2; уровень Б)

Пусть заданы три сохранённых double-массива: Û, Ṽ_prev (второй множитель предыдущего поля в том же базисе Û) и V̂ (любое вычисленное
решение полушага). Пусть w̃⁽ˢ⁻¹⁾ := ÛṼ_prevᵀ, w̃⁽ˢ⁾ := ÛV̂ᵀ и d̃ := w̃⁽ˢ⁻¹⁾ − w̃⁽ˢ⁾ — точные произведения. Определим

$$\rho:=b-\mathcal K^C v,\qquad \Delta:=\mathrm{vec}(\tilde V_{\rm prev}-\hat V),\qquad \gamma_s:=h_s\,\rho^{\mathsf T}\Delta .$$

Тогда (ВОК-2):

$$\Pi_h^C(\tilde w^{(s-1)})-\Pi_h^C(\tilde w^{(s)})=\tfrac12\|\tilde d\|_a^2-\gamma_s .$$

**Статус: PROVEN** (RO, ВОК-2; на данных Q3 — 984/984 точно, Q3 4.1).

### 2.2. Что входит в γ_s и при каких предпосылках

- **Точные объекты.** h_f, h_s — вещественные частные **сохранённых** double-значений l_f, l_s и целых n_f, n_s. Задача определяется
  сохранёнными double: например, сторона 0,2 означает fl(0,2). A, B, C, F, 𝒦^C — точные функции Û. ρ и Δ — точные функции сохранённых
  массивов. Ошибки самих факторов в тождество не входят (ВОК-2, «Свойства»).
- **Зависимости:**
  - γ_s билинейна по (ρ, Δ);
  - ρ линейна по V̂ и зависит от Û через A, B, C (квадратично) и F (линейно);
  - Δ — разность двух сохранённых массивов.
- **Предпосылка тождества.** P_{s−1} вычисляется по **тем же** массивам (Û, Ṽ_prev), что используются на полушаге s (ВОК-2). При s = 1
  w⁽⁰⁾ = 0, то есть Ṽ_prev = 0 и Δ = −v.
- **Точная дискретная величина и её вычисление в double — разные объекты.** γ_s — точное число, определённое сохранёнными массивами.
  γ̂_s — результат конкретного пути double (разд. 3). Тождество 2.1 относится только к γ_s.

### 2.3. Собственные следствия (уровень Б)

**Г-1. Второй точный путь вычисления.** Из 2.1:

$$\gamma_s=\tfrac12\|\tilde d\|_a^2-\bigl[\Pi_h^C(\tilde w^{(s-1)})-\Pi_h^C(\tilde w^{(s)})\bigr].$$

Правая часть вычисляется через энергию по определению NS 2.2, без системы полушага. **PROVEN** (перестановка членов 2.1). Этим тождеством
γ_s независимо пересчитал Reviewer (RV 2.2: 11 полушагов, совпадение с точным γ QA до 9·10⁻¹⁷ отн.). Энергию Reviewer вычислял не по
определению NS 2.2, а через гессиан hₓh_y·D·𝒜 13-точечного шаблона (Предложение D) — уточнение по рецензии Q4, Н-2.

**Г-2. Оценка |γ_s| через ошибку решения.** Пусть v* — точное решение 𝒦^C v* = b (существует при независимом Û, NS 4.6), w* := ÛV*ᵀ.

$$|\gamma_s|\le\|w^*-\tilde w^{(s)}\|_a\,\|\tilde d\|_a .$$

*Вывод.* ρ = 𝒦^C(v* − v), поэтому γ_s = h_s(v* − v)ᵀ𝒦^CΔ. Неравенство Коши–Буняковского в скалярном произведении 𝒦^C даёт
|γ_s| ≤ h_s‖v* − v‖_{𝒦^C}‖Δ‖_{𝒦^C}. По П-S1 h_s‖x‖²_{𝒦^C} = ‖Û mat(x)ᵀ‖²_a. ∎

**PROVEN.** Если ‖w* − w̃⁽ˢ⁾‖_a ограничена сертификатом ВОК-14 (б) (в Q3 — сертификат Q1b для 476/476 полушагов Е-4), правая часть даёт
строгую верхнюю оценку |γ_s|, не требующую вычислять γ_s. Насколько она точна, не исследовано (**UNRESOLVED**, разд. 5).

## 3. Модель вычисления γ̂_s

### 3.1. Путь double в эталонах QA (уровень В; SEQ, HS)

Путь кампании Q3 (`r5_cccc_sequence._energy`):

1. Â, B̂, Ĉ, F̂ — `coefficients`:
   - ĥ_f = fl(l_f/n_f);
   - Â = ĥ_f(ÛᵀÛ);
   - B̂ = −ĥ_f(Ûᵀ(L̂_fÛ)), где L̂_f = tridiag(1, −2, 1)/ĥ_f\*\*2;
   - Ĉ = ĥ_f(Ûᵀ(D̂4_fÛ)), где D̂4_f = L̂_f·L̂_f + (2/ĥ_f\*\*4) в двух углах;
   - F̂ = (q ĥ_f)·ΣÛ.
2. K̂ = D[kron(Â, D̂4_s) − 2·kron(B̂, L̂_s) + kron(Ĉ, I)] — плотная матрица (`coefficient_system`).
3. ρ̂ = fl(b̂ − fl(K̂v)).
4. Δ̂ = fl(Ṽ_prev − V̂).
5. t̂ = fl(ρ̂ᵀΔ̂).
6. γ̂ = fl(ĥ_s·t̂), где ĥ_s = fl(l_s/n_s).

### 3.2. Источники ошибки γ̂_s (разделение по заданию)

| Источник | Где | Порядок величины |
|---|---|---|
| ошибки входных вычисленных данных: Â, B̂, Ĉ, F̂, ĥ | шаг 1 | относительно **мажорант** Грама G (3.3), а не \|A\|, \|B\|, \|C\| |
| сборка оператора K̂ | шаг 2 | несколько u на элемент, относительно мажоранты 𝓜 |
| умножение оператора на вектор | шаг 3 | γ_p\|K̂\|\|v\|, p — число ненулевых в строке |
| сборка невязки и сокращение близких слагаемых | шаг 3 | b и K̂v почти равны: при уточнённом решении ρ на порядки меньше ошибок пп. 1–3 |
| разность полей | шаг 4 | u\|Δ\| |
| скалярное произведение | шаг 5 | γ_M\|ρ̂\|ᵀ\|Δ̂\| |
| масштаб h_s | шаг 6 | 2u |

**Механизм шума (MODEL).** Точное ρ уточнённого решения ничтожно, а абсолютная ошибка ρ̂ имеет порядок u·(𝓜|v|). Поэтому ρ̂ состоит
почти целиком из ошибки, и γ̂ = h_s ρ̂ᵀΔ̂ — проекция этой ошибки на Δ. Отсюда |γ̂ − γ|/|γ̂| ≈ 1. Это **наблюдение** Q3 (4.1:
0,98…1,02 в 984/984; RV 2.2), согласующееся с механизмом; механизм — MODEL.

### 3.3. Мажоранты (вычислимы по сохранённым массивам)

Модули операторов |L|, |D4| — поэлементные модули коэффициентов шаблона:

- |L| = tridiag(1, 2, 1)/h²;
- |D4| — пятидиагональная (1, 4, 6, 4, 1)/h⁴, в углах 7/h⁴.

$$G_A:=h_f|\hat U|^{\mathsf T}|\hat U|,\quad G_B:=h_f|\hat U|^{\mathsf T}|L_f|\,|\hat U|,\quad G_C:=h_f|\hat U|^{\mathsf T}|D4_f|\,|\hat U|,\quad G_F:=|q|\,h_f|\hat U|^{\mathsf T}\mathbf 1,$$

$$\mathcal M:=D\bigl(G_A\otimes|D4_s|+2G_B\otimes|L_s|+G_C\otimes I_m\bigr).$$

По неравенству треугольника |A| ≤ G_A, |B| ≤ G_B, |C| ≤ G_C, |F| ≤ G_F и |𝒦^C| ≤ 𝓜 поэлементно — **PROVEN**.

После QR внедиагональные элементы A малы, а G_A — нет. Для гладкого Û G_C ≫ |C|: сокращение в D4_fÛ. Поэтому ошибки Грама нужно
мерить относительно G, а не относительно |A|, |B|, |C|. Форма оценки RV 2.3 (а) с |𝒦^C| и |F| вместо 𝓜 и G_F строгой границей не
является.

## 4. Выводы и оценки ошибок

### 4.1. Путь A: строгая граница B_γ (собственный вывод; уровень В)

**Предпосылки.**

- П-1…П-5 (RO 0.4). FMA допускается: это одна операция с одним округлением.
- **П-γ1 (пути коэффициентов).** Существуют целые k_A, k_B, k_C, k_F, k_K такие, что поэлементно:
  - |Â − A| ≤ γ_{k_A}G_A;
  - |B̂ − B| ≤ γ_{k_B}G_B;
  - |Ĉ − C| ≤ γ_{k_C}G_C;
  - |F̂ − F| ≤ γ_{k_F}G_F;
  - |K̂ − 𝒦^C| ≤ γ_{k_K}𝓜.

  Они следуют из оценки скалярного произведения [СТАНД.] и правила (1 + γ_a)(1 + γ_b) ≤ 1 + γ_{a+b} [СТАНД.], если k подсчитаны вдоль
  фактического пути (4.2).
- **П-γ2 (умножение на вектор).** Каждая строка fl(K̂v) — сумма не более p ненулевых произведений, в любом порядке. Нулевые слагаемые
  точны.
- **П-γ3.** Ни в одной промежуточной величине нет переполнения и субнормальных значений. Иначе к оценке добавляется абсолютный член или
  она не действует (RO 0.4, уточнение по З-3).

**Лемма Γ-A (невязка).**

$$|\hat\rho-\rho|\le\bar r:=\frac{u}{1-u}|\hat\rho|+\gamma_{k_F}\,(G_F\otimes\mathbf 1_m)+\gamma_{k_K+p}\,\mathcal M|v| .$$

*Доказательство.*

1. K̂ = 𝒦^C + δK, |δK| ≤ γ_{k_K}𝓜; отсюда |K̂| ≤ (1 + γ_{k_K})𝓜 (3.3).
2. По П-γ2 fl(K̂v) = K̂v + e₁, |e₁| ≤ γ_p|K̂||v| ≤ γ_p(1 + γ_{k_K})𝓜|v|.
3. b̂ = b + δb, |δb| ≤ γ_{k_F}(G_F⊗𝟏).
4. ρ̂ = (b̂ − fl(K̂v))(1 + δ), |δ| ≤ u. Тогда точно ρ̂ − ρ = ρ̂δ/(1 + δ) + δb − δK v − e₁.
5. Оценка по модулю и γ_{k_K} + γ_p(1 + γ_{k_K}) ≤ γ_{k_K+p}. ∎

**Теорема Γ-A (вычисленное γ̂).** При тех же предпосылках, если Δ̂ = fl(Ṽ_prev − V̂) поэлементно, t̂ = fl(ρ̂ᵀΔ̂) в любом порядке,
ĥ_s = fl(l_s/n_s), γ̂ = fl(ĥ_s t̂), то

$$|\hat\gamma_s-\gamma_s|\le B_\gamma:=\frac{\hat h_s}{1-u}\Bigl[\frac{\bar r^{\mathsf T}|\hat\Delta|}{1-u}+\Bigl(\frac{u}{1-u}+\gamma_M+\gamma_2(1+\gamma_M)\Bigr)|\hat\rho|^{\mathsf T}|\hat\Delta|\Bigr],$$

и, следовательно, **|γ_s| ≤ |γ̂_s| + B_γ**.

*Доказательство.*

1. Δ̂ = Δ(1 + δ′) поэлементно, поэтому |Δ| ≤ |Δ̂|/(1 − u) и |Δ̂ − Δ| ≤ u|Δ̂|/(1 − u).
2. |t̂ − ρ̂ᵀΔ̂| ≤ γ_M|ρ̂|ᵀ|Δ̂| [СТАНД.], отсюда |t̂| ≤ (1 + γ_M)|ρ̂|ᵀ|Δ̂|.
3. h_s t̂ − γ_s = h_s[(ρ̂ − ρ)ᵀΔ + ρ̂ᵀ(Δ̂ − Δ) + (t̂ − ρ̂ᵀΔ̂)] — точно.
4. γ̂ = h_s(1 + δ_h)(1 + δ₂)t̂, поэтому |γ̂ − h_s t̂| ≤ γ₂h_s|t̂|.
5. Сложить, подставить лемму и h_s ≤ ĥ_s/(1 − u). Последнее неравенство — неравенство треугольника. ∎

**Статус.**

- Неравенство — **PROVEN** при П-1…П-5, П-γ1…П-γ3 и [СТАНД.]-лемме. Отбрасывания второго порядка нет.
- Для **конкретного кода** оно действует, только если значения k проверены по этому коду (QA-γ2). До проверки — **UNRESOLVED** для этого
  кода.
- **Вычислительным сертификатом** B_γ становится, только если сама граница вычислена с округлением вверх (или увеличена на
  1/(1 − γ_c) — все её слагаемые неотрицательны) и П-γ3 проверена во время счёта, как в ВОК-14 (б). Иначе значение B_γ — **MODEL**.

**Главный член.** B_γ ≈ ĥ_s[γ_{k_F}(G_F⊗𝟏)ᵀ|Δ̂| + γ_{k_K+p}(𝓜|v|)ᵀ|Δ̂|]. Член с |ρ̂|ᵀ|Δ̂| второго порядка, так как |ρ̂| ~ u𝓜|v|, но в
строгой границе сохранён.

### 4.2. Подсчёт k для пути QA (по коду HS; требует независимой сверки)

Подсчёт Literature по тексту `coefficients` и `coefficient_system`. Это **не** VERIFIED до QA-γ2.

| Величина | Операции | k |
|---|---|---|
| ĥ_f, ĥ_s | одно деление | 1 |
| элементы L̂ | ĥ\*\*2 (pow от ĥ), деление | 4 |
| элементы D̂4 | L̂·L̂ (произведения и сумма ≤ 3 слагаемых); углы + 2/ĥ\*\*4 | ≤ 12 |
| Â | скалярное произведение длины n_f − 1, умножение на ĥ_f | n_f + 1 |
| B̂ | L̂_fÛ (3 ненулевых), скалярное произведение, умножение на ĥ_f | n_f + 8 |
| Ĉ | D̂4_fÛ (5 ненулевых), скалярное произведение, умножение на ĥ_f | n_f + 18 |
| F̂ | сумма n_f − 1 слагаемых, (q ĥ_f)·сумма | n_f + 1 |
| K̂ | наибольший из членов (Ĉ⊗I: k_C), два сложения, умножение на D | k_K = n_f + 21 |
| fl(K̂v) | не более 5N ненулевых в строке | p = 5N |

Итого k_K + p = n_f + 21 + 5N, k_F = n_f + 1, M = N(n_s − 1).

**Предпосылка о `pow`** (рецензия Q4, Н-1). Счёт «ĥ\*\*2 — одна операция» в строке L̂ и аналогичный счёт для 2/ĥ\*\*4 в строке D̂4
верны **при корректно округлённом `pow`** (ошибка ≤ u на операцию). При принятой в проекте более слабой предпосылке «`pow` в пределах

### 4.4. Масштаб B_γ относительно членов τ_s^C (MODEL)

Оценки качественные, не границы:

1. **Отношение к Q.** B_γ/Q ≈ 2γ_{k}(𝓜|v|)ᵀ|Δ| / (h_s·ΔᵀK̂Δ·…). Для гладкого Δ это ~ u·n_f·Λ_h²·‖V̂‖/‖Δ‖ (Λ_h — RO, ВОК-5).
   Асимптотически ∝ n⁵, и множитель ‖V̂‖/‖Δ‖ растёт с s. SCRATCH 4.3 даёт ~n^4,4 при Ṽ_prev = 0.
2. **Отношение к R^C.** R^C/Q ~ u(⌈log₂ M⌉ + c_R)·Λ_h·‖w‖²_a/‖d‖²_a (ВОК-3, ВОК-8). Отсюда B_γ/R^C ~ (n_f/c_R)·Λ_h·‖d‖_a/‖w‖_a.
   - При s = 1 (‖d‖ ≈ ‖w‖) на рабочих сетках это **10³–10⁵**.
   - Фактическая ошибка в Q3 достигает 158·R (Q3 4.1), а B_γ завышает её в 10²–10⁴ раз (4.3). Это согласуется с оценкой.
3. **Следствия для пути A.** При τ = |γ̂| + B_γ + K_E[…] член B_γ при s = 1, 2 на крупных сетках будет больше K_E[…] на несколько
   порядков. Тогда:
   - **мощность проверки** падает: дефект реализации меньше B_γ не обнаруживается;
   - **разрешимость** Q̂ ≥ K_Eτ сужается: при малых Δ (s ≥ 2) B_γ/Q растёт.

   Насколько — **UNRESOLVED** до QA-γ1.

### 4.5. Путь B: γ_s в повышенной точности

**B1 — точное вычисление по сохранённым массивам (эталоны QA).**

- **Что вычисляется точно.**
  - Û, V̂, Ṽ_prev как точные рациональные значения сохранённых double (`Fraction(float(x))`);
  - h_f, h_s = Fraction(l)/n;
  - A, B, C, F — точно (`exact_coefficients`);
  - ρ — R-HP (`residual_exact`);
  - Δ — точная разность;
  - γ_s = h_sρᵀΔ — точное рациональное число.
- **Сертификат.** Не нужен: число точно. При переводе в double нужен интервал [γ↓, γ↑] с направленным округлением; округление к
  ближайшему даёт ошибку ≤ u/2 отн.
- **Статус значения — PROVEN** (точная арифметика), если реализация верна.
- **Статус реализации — VERIFIED:**
  - R-HP входит в принятые эталоны Q1 (D-051.1);
  - на данных Q3 точное тождество 2.1 замыкается 984/984. P и Q вычисляются по определению NS 2.2, а γ — по системе полушага NS 4.2,
    то есть разными формулами. Совпадение точное, не приближённое;
  - Reviewer независимо пересчитал γ путём Г-1 (RV 2.2, 11 полушагов).

  Независимость исполнителей ограничена (D-053.2, п. 6).
- **Уже сделано.** Для всей выборки Q3 точное γ есть в данных (столбец `j_gamma_exact`; Q3 4.1; RV 2.3 (б)). Пересчитывать не нужно,
  кроме интервала [γ↓, γ↑] (QA-γ3).
- **Ограничения.**
  - Стоимость: рациональная арифметика; в Q3 последовательность 512 × 1024 с точной энергией — 53 мин.
  - Это инструмент эталона и квалификации, а не рабочий путь решателя.
  - Для будущей квалификации решателя B1 применим к **сохранённым** массивам решателя: R-HP принимает double. Изменять эталон для этого
    не нужно.

**B2 — повышенная точность без точности (например, double-double; инструмента нет).**

- **Что должно вычисляться в повышенной точности.**
  - Не только ρ, но и **A, B, C, F, h** — заново по сохранённому Û.
  - Если подставить двойные Â, B̂, Ĉ, то результат сходится к γ для оператора K̂, а не 𝒦^C. Ошибка порядка ĥ_sγ_{k_K}(𝓜|v|)ᵀ|Δ|
    останется. Это аналог вывода Q2 о различии V2 и V4 (D-052).
- **Представление данных.** Сохранённые double точно представимы в повышенном формате, поэтому преобразование входов ошибки не вносит.
- **Сертификат.** Теорема Γ-A с u, заменённой на u_p арифметики повышенной точности, при условии, что для её операций доказана модель
  |fl_p(a∘b) − a∘b| ≤ u_p|a∘b| (ОК-7 RO). Граница B_γ^(p) ≈ (u_p/u)·B_γ пренебрежимо мала.
- **Статус.**
  - Метод — PROVEN при доказанной модели арифметики p.
  - Реализации нет, поэтому сейчас **UNRESOLVED**.
  - Без доказанной модели (например, произвольная точность без анализа ошибок) результат — только OBSERVATION.

### 5.2. Почему двойной путь не может быть существенно точнее B_γ (MODEL)

Ошибка ρ̂ поэлементно ограничена только величинами вида u(𝓜|v|)ᵢ. Для γ̂ = h_sρ̂ᵀΔ̂ худший случай — ошибки, согласованные по знаку с Δ.
Такой вектор ошибок допустим стандартной моделью округления. Поэтому оценка, использующая только эту модель и покомпонентные сведения, не
может быть меньше B_γ больше чем на множитель, связанный с k.

Альтернатива Г-2 через ‖w* − w̃‖_a тоже требует строгой оценки ‖ρ‖. В double она ограничена той же величиной r̄. Уменьшить неопределённость
можно только более точным вычислением ρ, то есть путём B. Довод качественный — **MODEL**.

### 5.3. Связь с K_E (D-053.4, п. 1)

Разделение объектов:

| Объект | Что это | Статус |
|---|---|---|
| Энергетическое тождество | 2.1: ΔΠ = ½‖d̃‖²_a − γ_s | PROVEN |
| Ошибка численного вычисления проверки | ΔP̂ − Q̂ = −γ_s + E_s, E_s = (часть формирования) + (часть сборки) (ВОК-6, ВОК-8; Q3 4.1) | разложение PROVEN; R^C, R_Q^C, R_f^C — MODEL (в R_f^C доказаны только оценки ε_a^C при ВОК-4; ВОК-8) |
| Ошибка вычисления γ | γ̂ − γ, разд. 4 | путь A — PROVEN при предпосылках; путь B1 — 0 |
| Модель порога τ_s^C | τ = Γ_up + K_E·R_Σ, R_Σ := R^C(ŵ⁽ˢ⁻¹⁾) + R^C(ŵ⁽ˢ⁾) + R_Q^C + R_f^C | MODEL; ОК-1 (строгая мажоранта E_s) — UNRESOLVED |
| Разрешимость E1/E2 | Q̂_s ≥ K_E·τ_s | зависит от Γ_up (4.4) и R_Σ |
| Достаточность выборки Q3 | 984 полушага, 123 последовательности | OBSERVATION для распределений; обоснование K_E — решение владельца |

**Предлагаемая структура** (собственный вывод; изменяет форму кандидата ВОК-8, поэтому требует решения владельца, В-2).

1. В τ_s^C заменить |γ̂_s| строгой верхней оценкой Γ_up ≥ |γ_s|:
   - путь A: Γ_up = |γ̂_s| + B_γ;
   - путь B1/B2: Γ_up = max(|γ↓|, |γ↑|).
2. Тогда |ΔP̂ − Q̂| ≤ |γ_s| + |E_s| ≤ Γ_up + |E_s|. Ложного FAIL по E2 (и по E1, так как Q̂ ≥ 0) нет, если |E_s| ≤ K_E·R_Σ. Значит, K_E
   должен покрывать **только** E_s. Ошибка вычисления γ покрывается Γ_up и в K_E не входит. **PROVEN** — алгебра неравенств при данной
   форме теста.
3. **Калибровочная статистика**, согласованная с этой формой:

   $$m_s^*:=\frac{|\hat{\Delta P}_s-\hat Q_s+\gamma_s|}{R_\Sigma}=\frac{|E_s|}{R_\Sigma}\quad(\gamma_s\ \text{точное, путь B1}).$$

   Она консервативна: (|ΔP̂ − Q̂| − Γ_up)₊/R_Σ ≤ m*_s. На Q3:
   - max m*_s = 5,6·10⁻⁴ (Q3 4.1; RV 2.2);
   - max (|ΔP̂ − Q̂| − |γ̂|)₊/R_Σ = 5,0·10⁻⁴ (RV 2.3).

   **OBSERVATION**; значения K_E не дают.

**Чего не хватает для определения K_E (UNRESOLVED с указанием шага):**

1. Решение владельца о пути получения Γ_up (В-1) и о форме теста (В-2).
2. При пути A — QA-γ1: B_γ на данных Q3 и разрешимость с Γ_up = |γ̂| + B_γ.
3. **Зависимость от пути вычислений.** R^C, R_Q^C и c_R = 22 относятся к пути double Г-4 эталона QA. Для пути решателя Builder их нужно
   пересчитать по его коду или доказать независимость от пути. Иначе K_E, найденный на Г-4, не переносится.
4. **Строгость.** ОК-1 открыт: τ_s^C остаётся MODEL при любом K_E. Выборочный максимум m*_s не доказывает sup m*_s. K_E — инженерный
   запас и решение владельца, фиксируемое до сравнений с Builder (D-025, D-053.5).

   себе больше; путь B1 его учитывает точно. Распределение E_s от решателя почти не зависит (E_s определяется полями) — это MODEL, его
   нужно подтвердить на данных решателя.
6. **Разрешимость.** В Q3 она ограничена членами R_Σ при убывающем Q (Q3 4.1, наблюдение 2; RV 2.4). При пути B1 Γ_up её не меняет
   (OBSERVATION: тот же счёт с |γ̂|, |γ| и без γ). При пути A — UNRESOLVED.
