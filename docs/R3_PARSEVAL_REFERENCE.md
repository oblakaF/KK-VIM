## 1. Математическая постановка

Прямоугольная пластина Кирхгофа–Лява a × b, SSSS, q = const ≠ 0, D > 0, N = 1, 0,2 ≤ r = b/a ≤ 5 (Р-1). Оси и центр — MATH_SPEC.md, 1.1;
опорная длина a (Р-3).

- **Старт (D-030):** X⁰(x) = sin(πx/a) на (0, a); G₁ = (a/2, π²/(2a), π⁴/(2a³), 2qa/π) (MATH_SPEC.md, 5.1).
- **Чередование (MATH_SPEC.md, 4.3–4.5; черновик R3, 2.1, 3.1):**

| s | k = ⌊s/2⌋ | полушаг | решается на | по коэффициентам | из множителя (на его отрезке) | поле |
|---|---|---|---|---|---|---|
| 1 | 0 | Y | (0, b), ℓ₁ = b | G₁ | X⁰ на a | X⁰Y¹ |
| 2 | 1 | X | (0, a), ℓ₂ = a | G₂ | Y¹ на b | X²Y¹ |
| 3 | 1 | Y | (0, b), ℓ₃ = b | G₃ | X² на a | X²Y³ |
| 4 | 2 | X | (0, a), ℓ₄ = a | G₄ | Y³ на b | X⁴Y³ |
| нечётное | (s − 1)/2 | Y | ℓ_s = b | G_s | X^{s−1} на a | X^{s−1}Y^s |
| чётное | s/2 | X | ℓ_s = a | G_s | Y^{s−1} на b | X^sY^{s−1} |

- **Полушаг s (ЧВ-17, NUMERICAL_SPEC.md, 15.1)** на ℓ = ℓ_s: f(ξ) = Σ_{m нечёт} c_m sin λ_mξ, λ_m = mπ/ℓ_s,
  c_m = 4F/[Dmπ(Aλ_m⁴ + 2Bλ_m² + C)], (A, B, C, F) = G_s.
- **Коэффициенты следующего полушага (ЧВ-18, 15.2)** — с физической длиной **полученного** множителя, т. е. той же ℓ_s:
  A′ = (ℓ_s/2)Σc_m², B′ = (ℓ_s/2)Σλ_m²c_m², C′ = (ℓ_s/2)Σλ_m⁴c_m², F′ = 2qΣc_m/λ_m. Длина нового искомого множителя — ℓ_{s+1}
  (другая сторона); длина множителя, из которого считаются G_{s+1}, — ℓ_s.
- **Хвосты и выбор M (ЧВ-20, И-12, 15.4)** — с ℓ_s: K = 4|F|ℓ_s⁴/(DAπ⁵), остатки f, A, B, C, F по 15.4, п. 3; M выбирается автоматически
  для каждого полушага. **M = 2559 относится к Навье и для Парсеваля не устанавливается.** Ориентир черновика (Е-8) подтверждён:
  при s = 1 K/|c₁| = (1 + r²)², M ≈ 2669 (r = 1), 4259 (r = 2), 10123 (r = 5).
- **Перенос ошибок (ЧВ-21, 15.5)** — без изменений: величины относительные и от ℓ не зависят.
- **Поля** — в узлах x_i = ia/n_x, y_j = jb/n_y с целочисленной редукцией аргумента (И-11); в произвольных точках — суммы ряда.
- **Непрерывная энергия (MATH_SPEC.md, В-23; NUMERICAL_SPEC.md, 17):** I_s = I_X I_Y; Π_s = −qI_s/2;
  Π_full = D(C_X A_Y + 2B_X B_Y + A_X C_Y)/2 − qI_X I_Y, где A_X, B_X, C_X, I_X — на (0, a), A_Y, B_Y, C_Y, I_Y — на (0, b)
  (∬(X″Y + XY″)² = C_X A_Y + 2B_X B_Y + A_X C_Y, так как ∫XX″ = −B_X). ‖w_s − w_{s−1}‖² — по разности сменённого множителя на ℓ_s.
- **Второй старт (ЧВ-R1, Р-2):** старт по y на a × b ≡ старт по x на b × a; `swapped()`.

## 5. Ограничения применимости

- Только SSSS, q = const, N = 1, 0,2 ≤ b/a ≤ 5 (Р-1); вне диапазона — `ValueError: ERROR_INPUT`. Квадрат — R2 без изменений.
- Бюджет переноса ошибок — первого порядка и растёт ~4ˢ (Q-022); при s = 7 — ~6·10⁻¹¹, при s = 10 — ~4·10⁻⁹; начиная с s = 24 (все
  контрольные r) перенос перестаёт быть оценкой: `valid = False`, ошибки — `inf`, значения при этом вычисляются. Значения ниже бюджета не
  являются строго установленными.
- Бюджет учитывает модель округления первого порядка ([СТАНД.]; точность библиотечного sin — [ИСТОЧНИК НЕ ПОДТВЕРЖДЁН], 15.5); это оценка,
  а не доказанная граница всех ошибок floating-point.
- `field_at_points` вне узлов несёт дополнительное округление аргумента ≈ πuΣm|c_m| на множитель; точная целочисленная редукция — только
  в узлах.
- Стабилизация по s и совпадение двух стартов — наблюдения, не доказательства предела (MATH_SPEC.md, 7.4; Q-025).
- Это не решение двумерной задачи; эталон двумерной задачи — Навье.
