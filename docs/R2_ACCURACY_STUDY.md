# R2, группа B: исследование точности КК-МВИ при N = 1 относительно решения Навье

**Статус:** результаты исследования QA (2026-10-13, редакция 2 — с расширенной полуаналитической последовательностью),
подготовлены к независимой научной рецензии. Не приняты. Группа B не имеет критерия PASS/FAIL по величине отличия от Навье
(D-025; NUMERICAL_SPEC.md, разд. 17, 18.2): отличия измерены и объяснены, а не подогнаны.

**Цели:** G3.1, G4. **Основания:** D-016, D-024, D-025, D-030, D-032–D-034; MATH_SPEC.md, часть A (разд. 7; В-23, В-24, В-27);
NUMERICAL_SPEC.md, разд. 3.4, 11.4, 12, 15–18; NAVIER_REFERENCE_SPEC.md.

**Источник чисел.** Все численные таблицы этого отчёта — блоки между маркерами `<!-- AUTO:… -->`; их формирует
`scripts/r2_accuracy_study.py` только из CSV-файлов каталога [`results/r2/`](results/r2/) (тест
`tests/cross/test_r2_accuracy_study.py` сверяет блоки с CSV). В тексте численные результаты вручную не повторяются.

## 1. Постановка и метод

- **Задача.** Линейная квадратная пластина Кирхгофа–Лява, все края свободно оперты (SSSS), равномерная нагрузка; безразмерный
  случай a = D = q = 1, поэтому w = w̄ = wD/(qa⁴), энергия — в единицах q²a⁶/D.
- **Приближение.** КК-МВИ при N = 1 (`kkvim`): X⁰ = sin(πx/a), полушаги Y¹, X², Y³, … по МКР (NUMERICAL_SPEC.md, разд. 5), нормировка
  И-4, автоматическая остановка (разд. 11; А-11). Счётчики s и k = ⌊s/2⌋ — D-030. Состояния исследования: s = 1, 2, 3, 4 и фактический
  полушаг остановки контроллера на каждой сетке (не навязывается).
- **Эталон Навье.** Ряд (131) L-107 (`kkvim_reference.navier`), M = 1279, непосредственно в узлах каждой сетки, без интерполяции;
  квалифицирован по прогибу (А-10а, D-034).
- **Полуаналитическая последовательность (SA)** (`kkvim_reference.parseval_recursion`, расширенная редакция): непрерывные полушаги
  синусными рядами и Парсевалем (разд. 15), без пространственной сеточной аппроксимации, для всех исследуемых состояний, включая s = 4
  и полушаг остановки. Это независимое вычисление со своей погрешностью усечения и накопления (бюджеты — разд. 7.1); пределом
  последовательности при s → ∞ оно не является.
- **Метрики** (разд. 17): δ_c — подписанное относительное отличие в центре; E_∞ = max|w_h − w_N| / max|w_N|; E_2 — относительная
  L₂-норма с двумерными весами трапеций; четверти (¼, ¼), (¼, ½), (½, ¼); положение максимального |w_h − w_N|; энергетическая мера
  e = (Π − Π_N)/|Π_N|; асимметрия A_sym = max|w − wᵀ|/max|w|. Все сравнения — в одинаковых узлах.
- **Сеточная сходимость** (разд. 12): E_disc = max по общим узлам |w_n − w_2n| / max|w_n| (знаменатель — max поля грубой сетки пары);
  наблюдаемый порядок p — по SA для всех состояний (дополнительно — по самосходимости, `grid_convergence.csv`); экстраполяция Ричардсона
  w_RE = (4w_2n − w_n)/3 в узлах сетки n — только при p ∈ [1,9; 2,1]. Экстраполяция — значение при фиксированном s или «при остановке
  по критерию», а не доказанный предел при h → 0 или s → ∞.

## 7. Энергетические меры

### 7.1. Расширенная полуаналитическая последовательность: квалификация QA

Расширение Reference (`a50f332`) независимо проверено QA:
- для s ≤ 3 коэффициенты, ряды, бюджеты и поля побитово совпадают с прежней реализацией;
- для s = 1…10 чередование Y/X и счётчики k = ⌊s/2⌋ верны;
- при `m_scale = 2` вся рекурсия пересчитывается с удвоенным M на каждом полушаге, начиная с s = 1 (в двойной точности G_s при малых s
  совпадают побитово — добавленные члены ниже округления; различия появляются позже и остаются в пределах бюджета);
- инварианты B/A, C/A, F²/A и поля не зависят от нормировки X⁰; поля масштабируются как qa⁴/D, энергия — как q²a⁶/D; знак q сохраняется;
- взаимных импортов `kkvim` и `kkvim_reference` нет;
- собственная 30-значная рекурсия QA (вне репозитория) на s = 4, 7, 10 совпала с Reference на уровне округления двойной точности
  и подтвердила В-24 на s = 2…4.

**Пояснение к таблице.** Столбец «Π_{s−1} − Π_s (вычитанием)» при s ≥ 5 ниже разрешения float64 (порядка u·|Π|): это шум округления,

и вычисленных коэффициентов, особенно при s = 9–10. Изменения, отмеченные как неустановленные, нельзя интерпретировать как достоверные
изменения непрерывной последовательности.

- Бюджеты растут примерно как 4ˢ (разд. 15.5) и остаются валидными до s = 10; требование δ_SA ≤ 10⁻¹² (разд. 15.7) обеспечено бюджетом
  для полей до s = 4, для инвариантов до s = 3; далее бюджет больше 10⁻¹², но на много порядков меньше измеряемых отличий от Навье и ошибок МКР. Фактическое расхождение
  с независимыми рекурсиями QA — на уровне округления: бюджеты очень пессимистичны.
- **Изменение энергии.** При s ≥ 5 вычитание Π_{s−1} − Π_s двух близких чисел даёт только шум округления (~u·|Π|), тогда как
  ½‖w_s − w_{s−1}‖²_{H_T}, найденная по разностному множителю без вычитания, продолжает убывать; при s = 2…4 обе величины совпадают
  (тождество В-24).
- **Поздние полушаги.** Начиная с s = 7 относительное изменение ‖Δw‖/‖w‖ меньше границы его собственной численной ошибки: такие
  изменения **не** считаются установленными изменениями точной непрерывной последовательности. Удвоение M — практическая диагностика,
  а не доказательство точности.

**Ограничения и неопределённости:**

- Только квадрат SSSS, равномерная нагрузка, N = 1 и только прогиб; моменты не квалифицированы как эталон (D-034).
- Экстраполяция Ричардсона опирается на эмпирическое выполнение порядка 2 (D-032); асимптотическое разложение ошибки не доказано.
- SA — независимое вычисление без пространственной сетки, но с усечением рядов и накоплением ошибки; бюджет растёт как 4ˢ и превышает 10⁻¹²
  (разд. 15.7) для полей при s > 4, для инвариантов при s > 3; изменения при s ≥ 7 меньше бюджета и не считаются установленными.
- Тождество Π(w_SA) = −½q∬w_SA использовано для проекционных полушагов (В-23); Π_N — приближение Π(ω₀) с доказанной границей остатка
  (разд. 16); утверждение о равенстве Π_M непрерывной энергии усечённого поля Навье Reviewer не принимал.
- Положение максимума |w_h − w_N| указано в узлах сетки; между узлами оно не уточнялось.
