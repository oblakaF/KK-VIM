# R2, группа B: исследование точности КК-МВИ при N = 1 относительно решения Навье

**Статус:** результаты исследования QA (2026-10-13), подготовлены к независимой научной рецензии. Не приняты.
Группа B не имеет критерия PASS/FAIL по величине отличия от Навье (D-025; NUMERICAL_SPEC.md, разд. 17, 18.2):
отличия измерены и объяснены, а не подогнаны.

**Цели:** G3.1, G4. **Основания:** D-016, D-024, D-025, D-030, D-032–D-034; MATH_SPEC.md, часть A (разд. 7.4, 9; В-23, В-27);
NUMERICAL_SPEC.md, разд. 3.4, 11.4, 12, 15–18; NAVIER_REFERENCE_SPEC.md.

## 1. Постановка и метод

- **Задача.** Линейная квадратная пластина Кирхгофа–Лява, все края свободно оперты (SSSS), равномерная нагрузка; безразмерный
  случай a = D = q = 1, поэтому w = w̄ = wD/(qa⁴), энергия — в единицах q²a⁶/D.
- **Приближение.** КК-МВИ при N = 1 (`kkvim`): X⁰ = sin(πx/a), полушаги Y¹, X², Y³, … по МКР с одномерными задачами (NUMERICAL_SPEC.md,
  разд. 5), нормировка И-4, автоматическая остановка (разд. 11; квалифицирована А-11). Счётчики s и k = ⌊s/2⌋ — D-030.
- **Эталон.** Ряд Навье (131) L-107 (`kkvim_reference.navier`), M = 1279, вычисляется непосредственно в узлах каждой сетки МКР,
  без интерполяции. Квалифицирован по прогибу (А-10а, D-034).
- **Полуаналитическая последовательность** (`kkvim_reference.parseval_recursion`): непрерывные полушаги s = 1, 2, 3 синусными
  рядами и Парсевалем (разд. 15), без сетки. Используется для разделения ошибок (D-016) и непрерывной энергетической меры.
- **Метрики** (разд. 17): δ_c — подписанное относительное отличие в центре; E_∞ = max|w_h − w_N| / max|w_N|; E_2 — относительная
  L₂-норма с двумерными весами трапеций; четверти (¼, ¼), (¼, ½), (½, ¼); положение максимального |w_h − w_N|; энергетическая мера
  e = (Π − Π_N)/|Π_N|; асимметрия A_sym = max|w − wᵀ|/max|w|. Все сравнения — в одинаковых узлах.
- **Сеточная сходимость** (разд. 12): E_disc = max по общим узлам |w_n − w_2n| / max|w_n| (знаменатель — max поля грубой сетки пары);
  наблюдаемый порядок p по эталону SA (s ≤ 3) или по самосходимости на тройке (n, 2n, 4n) (s = 4 и остановка); экстраполяция Ричардсона
  w_RE = (4w_2n − w_n)/3 в узлах сетки n — только при p ∈ [1,9; 2,1]. Экстраполяция — значение при фиксированном s
  (или «при остановке по критерию»), а не доказанный предел при h → 0 или s → ∞.

## 7. Энергетические меры

**Π_N** — энергия непрерывного эталона, приближённая усечённым рядом (M = 1279; Π(ω₀) ≤ Π_N ≤ Π(ω₀) + 1,363·10⁻¹³).
**Π_h** — дискретная энергия Π_h(w_h) (разд. 4.1). Мера e_h = (Π_h − Π_N)/|Π_N| смешивает дискретный и непрерывный функционалы,
может иметь любой знак и **не** является непрерывной энергетической ошибкой (разд. 17, замечания).

интегралы множителей — из их синусных рядов (∫sin(mπξ) = 2/(mπ) при нечётном m), без квадратуры:

- Непрерывная составляющая w_SA − w_N от сетки не зависит; она включает ограничение N = 1 **и** незавершённость последовательности

- В центре знаки составляющих при s ≥ 2 совпадают (обе отрицательны): дискретизация не компенсирует, а немного увеличивает отличие.
- Для s = 4 и остановки точного полуаналитического поля нет; оценка вклада дискретизации — по Ричардсону (w_h − w_RE) и непрерывного —
