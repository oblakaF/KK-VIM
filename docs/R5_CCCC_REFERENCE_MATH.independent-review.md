### 5.4. Рекомендация владельцу (не утверждение)

Рекомендуется принять для КК-МВИ CCCC функционал **Π_h^C**:
- вес ½ в граничных узлах (правило трапеций);
- граничная вторая разность через чётный фиктивный узел (Łf)₀ = 2f₁/h²;
- нагрузка по внутренним узлам.

Основания:
1. Его гессиан тождественно равен классической 13-точечной схеме D2 (доказано). Поэтому полную дискретную задачу D1 можно проверять отдельным поузловым кодом QA.
2. Граничное замыкание аппроксимирует ∂w/∂n = 0 со вторым порядком; локальная невязка O(h⁻¹) — только в первом ряду узлов.
3. Наблюдаемый глобальный второй порядок: 1D — точно h²/48, 2D — 1,998. Вариант с весом 1 даёт первый порядок.
4. Симметрия и положительная определённость; матрицы полушагов сохраняют структуру R4 с заменой L² → D4.

Остаточные ограничения:
- (а) глобальный второй порядок D2 и структура разложения ошибки не доказаны (угловая особенность ρ^{γ₁+1}); Ричардсон не обоснован (ОВ-М9);
- (б) при выборе Π_h^C задача D2 совпадает с D1 и **не проверяет** ошибку сетки независимо — её проверяют только A и B;
- (в) **инженерное следствие, не отмеченное в документе:** D4 = L² + поправка ранга 2 **не диагонализуется DST-I**. Модальный алгоритм R4 (ЧФ-3, вариант B, РВ4-5) на CCCC напрямую не переносится. Нужно отдельное решение: блочная ленточная система, поправка Шермана–Моррисона–Вудбери к модальному решению или иное — по отдельной спецификации;
- (г) выбор — решение владельца (Q-010, ОВ-М11).
