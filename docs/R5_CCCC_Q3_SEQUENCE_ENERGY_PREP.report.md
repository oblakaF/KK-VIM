## 2. Последовательность (Г-1): порядок одного полушага

1. **Заданный набор и спутник.** Заданный набор G — множитель фиксированного направления; спутник C — другой множитель предыдущего поля:
   w̃⁽ˢ⁻¹⁾ = G Cᵀ в ориентации x-первым. При s = 1 C = 0, w⁽⁰⁾ = 0.
2. **Точный ранг G.** Точная зависимость — остановка.
3. **Решение и сертификат.** R-AC с уточнением, сертификат Q1b; набор V̂ решаемого направления.
4. **Энергия** (точно): тождество ВОК-2, вычисленная проверка и её разложение, модельные члены.
5. **Преобразование:**
   - **N = 1** (И-4, NS 4.4): c = σ‖f‖∞, σ = sign⟨f, 𝟏⟩; f ← f/c, g ← g·c. Если f = 0 — остановка ZERO_FIELD.
   - **N ≥ 2, QR** (R4 5.4.1, NS 5.1):
     - тонкие QR √h_g G = Q_G R_G и √h_s V̂ = Q_V R_V; SVD матрицы R_G R_Vᵀ даёт ρ̂_N, κ_rep; вычисляется σ_N(R_V D_c);
     - точная зависимость V̂ (exact rank < N) — остановка S-1 (D-049.5, п. 2);
     - иначе — решение о ранге UNRESOLVED, исследовательский QR: V̂ ← Q_V/√h_s, G ← G R_Vᵀ (поле сохраняется);
     - cond(A) до QR = cond(R_V)², после QR — по новому набору;
     - энергия после преобразования — `P_after_transform_minus_before`.

     Библиотечные эвристики ранга (`matrix_rank`, пороги SVD) не используются: ранг — только точный.
   - **N ≥ 2 без QR:** только диагностика (аналог BC-6).
6. **Переход к следующему полушагу:** вычисленный набор становится заданным, прежний заданный — спутником.

Условие ВОК-2 «P_{s−1} по тем же массивам, что на полушаге s» выполнено: w̃⁽ˢ⁻¹⁾ строится из преобразованных массивов.

## 3. Г-4: R^C и c_R — разбор цепочки операций

Путь double (`pi_double`) с фиксированным порядком: слагаемые формируются поузлово, затем одна попарная сумма всех
M = (nₓ + 1)(n_y + 1) + (nₓ − 1)(n_y − 1) слагаемых.

| Операция | Множители (1 + δ) | Класс |
|---|---|---|
| значение шаблона Łw: числитель — 2 сложения | 2 | доказано при П-1…П-5 (относительно \|Ł\|\|w\|) |
| h_d = fl(l/n), входит в квадрате | 2 | доказано (возмущение точного h) |
| h_d**2 через `pow` | 2 | **допущение**: pow с целым показателем ошибается ≤ 1 ulp (не гарантировано IEEE; как в Q1b, Р-2) |
| деление | 1 | доказано |
| сумма Łₓw + Ł_yw | 1 | доказано; итого c_Δ = 8 |
| квадрат t·t | 2c_Δ + 1 = 17 (первый порядок, относительно \|Δw\|(\|Δ\|w)) | **модель первого порядка** (отброшен член второго порядка) |
| (D/2)·w_I·w_J (веса — h или h/2, деление на 2 точно) | 4; умножение на t²: +1 | доказано; итого 22 на квадратичное слагаемое |
| нагрузка −(q hₓh_y)w | 5 | доказано |
| попарная сумма M слагаемых | глубина ⌈log₂M⌉ — **по построению** `pairwise_sum` (явное двоичное дерево; сложение с добавленным нулём точно) | доказано |

Итог: R^C(w) = u(⌈log₂M⌉ + c_R)·Ŝ^C(w) с **c_R = 22 для этого пути**.
- Это подсчёт для модели первого порядка; ВОК-3 так и определяет c_R: «подсчёт по коду».
- Не доказано, что R^C мажорирует фактическую ошибку: член второго порядка отброшен.
- Для другого пути (Builder, иное суммирование, `numpy.sum` с блочным попарным суммированием, глубина которого зависит от реализации)
  счёт другой.

| Что | Статус |
|---|---|
| поэлементные множители и глубина суммы этого пути | ограничено доказательно при П-1…П-5 (кроме pow — допущение) |
| R^C, R_Q^C как мажоранта ошибки сборки | МОДЕЛЬ (первый порядок) |
| запас K_E против модельности | требует экспериментального множителя (Е-1) |
| c_R для пути Builder, K_E, ε_floor^C, правило конфигурации | UNRESOLVED, решение владельца после Q3 |

**Разложение дефекта (точное).** Для вычисленной проверки ΔP̂ − Q̂ (числа double, взятые точно):
- ΔP̂ − Q̂ = (−γ_s) + [f(ŵ⁽ˢ⁻¹⁾, ŵ⁽ˢ⁾) − f(w̃⁽ˢ⁻¹⁾, w̃⁽ˢ⁾)] + [(ΔP̂ − Q̂) − f(ŵ⁽ˢ⁻¹⁾, ŵ⁽ˢ⁾)];
- слагаемые: решение полушага (ВОК-2), образование поля, вычисление энергии;
- f(v, w) = Π(v) − Π(w) − ½‖v − w‖²_a — точно; f(w̃) = −γ_s проверяется точно.

Каждая часть — точное рациональное число; в журнале оно округлено к ближайшему (OBSERVATION). Ошибки решения, образования и сборки
разделены.
