# R4 — интеграционная QA-проверка связанного решателя N = 2–3 в `main` и группы B

Цели: G2, G3.3, G4. Роль: QA.
Это проверка реализации в объединённом дереве; **не** нормативная приёмка решателя и **не** научная приёмка R4.
Все результаты исследовательского режима — PROVISIONAL / NOT_QUALIFIED (D-047, дополнение 1).

**Вердикт: PASS_WITH_NOTES.**
- Дефектов не обнаружено.
- Фактический `run_coupled` совпадает с независимым QA-контролем на уровне округления и с сохранёнными таблицами группы B в пределах точности их записи.
- Замечания неблокирующие (разд. 4).

**Выборка:**
- N = 2, 3; r = 1/5, 1, 5;
- семейство I: n = 40, 80, 160;
- семейство II: (n_x, n_y) = (40, 200) при r = 5;
- s = 1, 2, 3, 10 (для каждого s отдельный прогон с `half_steps = s`; последовательность детерминирована);
- dense против FFT: N = 3, r = 1, n = 80.

**Сравниваются только дискретные величины одной сетки:** w_h, Π_h, δ_c полн. = (w_h − ω₀)/ω₀ в центре, E_∞ полн.
Дискретное поле не отождествляется с неусечённым непрерывным решением. Ошибки метода, дискретизации и полной сетки разделены в отчёте группы B
и здесь не пересчитывались.

**Допуски — существующие, зафиксированы до проверки:**
- поле и сингулярные числа — модель первого порядка `_model` и неравенство Вейля из `tests/cross/test_r4_controller_comparison.py`;
- сохранение поля при QR — оценка оттуда же;
- сравнение с CSV — точность записи (7 значащих цифр, 5·10⁻⁷ отн.) плюс та же модель.

Новых порогов нет.

## 4. Замечания (неблокирующие)

1. Защиты K_RESEARCH проверены только подстановкой K в тесте. Естественного срабатывания на N = 2–3 не найдено (как в разд. 6.3 сравнения контроллера).
2. Высокоточные тесты (`mpmath`) в обязательном CI пропускаются по замыслу; они выполнялись во временной среде QA и рецензентом.
3. Сравнение с таблицами группы B ограничено точностью их записи (7 значащих цифр). Более тонкое совпадение подтверждается прямым сравнением с QA-контролем (≤ 6,9·10⁻¹⁵).
4. Docstring модуля сравнения контроллера уточнён: модуль теперь выполняется в обычном CI.
