### 3.1. Принятая основа [ПРИНЯТО MS-C C.8]

Обозначения MS-C C.0.5: в операторах D = d/dy; жёсткость D стоит множителем (4q/D). Различаются по контексту.

- ВБC-18: L_iY_i = g, L_i = (D² − κ_i²)², κ_i = 2iπ/a, g = 4q/D − 2Σ_jY_j⁗; Y_i = Y_i′ = 0 при y = 0, b. Если Σd_iY_i ≡ 0, d ≠ 0, то
  P_d(D)g = 0, где P_d(ξ) = Σ_i d_iΠ_{j≠i}(ξ² − κ_j²)² ≢ 0.
- ВБC-19: N = 2 — ДОКАЗАНО. ВБC-20, п. 1: вырождение ⇒ Σd_i/i⁴ = 0 — ДОКАЗАНО (необходимое условие). ВБC-20, п. 2: N = 3 — UNRESOLVED.
- Препятствие ВБC-20 для N = 3: одного уравнения P_d(D)g = 0 мало. На плоскости Σd_i/i⁴ = 0 оно оставляет двумерное множество d, а
  резонансные корни ±κ_k допускают составляющие p(y)e^{±κ_ky}.

### 3.2. РН-1: алгебраический критерий [ВЫВОД ПРОЕКТА РН-1]

**Утверждение.** Пусть выполнены условия ВБC-18: непрерывная задача CCCC, q = const ≠ 0, D > 0, a, b > 0, старт 𝒯_N, первый полушаг
точный. Положим L_j(ξ) = (ξ² − κ_j²)² и

$$\chi_N(\xi)=\prod_{j=1}^N L_j(\xi)+2\xi^4\sum_{i=1}^N\prod_{j\ne i}L_j(\xi).\qquad(\text{РН-1.1})$$

Если для каждого вещественного d ≠ 0 с Σ_i d_i/i⁴ = 0 многочлены P_d и χ_N не имеют общего комплексного корня, то **rank w⁽¹⁾ = N**.

**Доказательство.**

1. Заданный набор 𝒯_N независим (ВБC-17), поэтому rank w⁽¹⁾ = dim span(Y₁, …, Y_N) (ВБ-2). По ВБC-4, п. 1, Y_i ∈ C^∞[0, b]. Значит,
   операторы с постоянными коэффициентами применяются классически.
2. **Уравнение связи для g.** Положим S = Σ_jY_j. Так как L_iY_i = g и операторы коммутируют,
   Π_jL_j(D)·S = Σ_i Π_{j≠i}L_j(D)·(L_iY_i) = Σ_iΠ_{j≠i}L_j(D)g. По определению g имеем D⁴S = (4q/D − g)/2. Применим D⁴ к предыдущему
   равенству и используем Π_jL_j(D)c = (Π_jκ_j⁴)c для постоянной c:

   $$\chi_N(D)\,g=\Bigl(\prod_j\kappa_j^4\Bigr)\frac{4q}{D}.\qquad(\text{РН-1.2})$$

   Это новое по сравнению с ВБC-18…ВБC-20 соотношение. Его роль: g лежит в конечномерном пространстве решений ОДУ χ_N(D)g = const.
3. **Частное решение.** χ_N(0) = Π_jκ_j⁴ ≠ 0, поэтому g₀ := 4q/D удовлетворяет (РН-1.2). Разность g₁ := g − g₀ удовлетворяет
   χ_N(D)g₁ = 0.
4. **Случай Σd_i/i⁴ ≠ 0.** P_d(0) = (Π_jκ_j⁴)Σ_id_i/κ_i⁴ ≠ 0 (ВБC-20, п. 1, шаг 2). Тогда P_d(D)g₁ = −P_d(0)g₀ — ненулевая постоянная.
   Но g₁ ∈ ker χ_N(D), а это пространство инвариантно относительно P_d(D). Ненулевая постоянная c в нём не лежит:
   χ_N(D)c = χ_N(0)c ≠ 0. Противоречие. Это второе доказательство ВБC-20, п. 1.
5. **Случай Σd_i/i⁴ = 0.** Тогда P_d(0) = 0, и g₁ ∈ ker P_d(D) ∩ ker χ_N(D). По тождеству Безу G = AP_d + Bχ_N, G = НОД(P_d, χ_N) над ℂ[ξ],
   поэтому G(D)g₁ = 0. По условию G = 1, значит g₁ = 0 и g ≡ 4q/D.
6. **Противоречие с защемлением.** При g ≡ 4q/D имеем D⁴S = 0 и L_iY_i = 4q/D. Отсюда Y_i = 4q/(Dκ_i⁴) + H_i, где
   H_i ∈ ker L_i(D) = span{e^{±κ_iy}, ye^{±κ_iy}}. Каждое ker L_i(D) инвариантно относительно D⁴. Показатели ±κ_i различны при разных i и
   не равны нулю. Экспоненциальные многочлены с различными показателями линейно независимы, поэтому из ΣD⁴H_i = D⁴S = 0 следует
   D⁴H_i = 0 при каждом i. На ker L_i(D) оператор D⁴ обратим (собственное значение κ_i⁴ ≠ 0 на каждом корневом подпространстве), поэтому
   H_i = 0. Тогда Y_i ≡ 4q/(Dκ_i⁴) ≠ 0, что противоречит Y_i(0) = 0.
7. **Вещественность d.** Y_i вещественны. Комплексная зависимость даёт вещественную: Re d или Im d. Поэтому достаточно вещественных
   d ≠ 0. ∎

**Замечания.**

- χ_N(ξ) = det(diag(L_i(ξ)) + 2ξ⁴𝟏𝟏ᵀ) по лемме об определителе. Это характеристический многочлен полной системы (Ф-4C) для 𝒯_N.
- **Резонанс устраняется автоматически.** χ_N(±κ_k) = 2κ_k⁴Π_{j≠k}(κ_k² − κ_j²)² ≠ 0: в сумме остаётся только слагаемое i = k. Поэтому
  резонансные корни ±κ_k многочлена P_d (возможные при d_k = 0, ВБC-20, шаг 3) никогда не являются общими корнями. Именно они мешали
  ВБC-20 при N = 3.
- **Масштаб.** При t = ξ²/κ², κ = 2π/a: L_i = κ⁴(t − i²)², χ_N = κ^{4N}c_N(t), P_d = κ^{4(N−1)}p_d(t). Общие корни по ξ и по t
  соответствуют друг другу. Условие РН-1 **не зависит ни от a, ни от b**: b в доказательство не входит.
- **Требования.** Используется структура 𝒯_N (ВБC-17): a^X ∝ I + 2·𝟏𝟏ᵀ, β^X и γ^X диагональны; q = const. Для другого старта или для
  s ≥ 2 скалярного распада на L_i нет (разд. 3.5).

## 4. Дискретный ранг и накопление ошибки (п. 6 задания)

### 4.1. Структура полушага [ПРИНЯТО MS-C ВБC-12…ВБC-14; NS 4.2–4.3]

𝒦^C = D[A ⊗ D4_y − 2B ⊗ L_y + C^C ⊗ I], A = hₓUᵀU, B = −hₓUᵀLₓU, C^C = hₓUᵀD4ₓU, F = q·hₓUᵀ𝟏. 𝒦^C ≻ 0 ⇔ U независим. D4 = L² + E₂,
E₂ = (2/h⁴)(e₁e₁ᵀ + e_{n−1}e_{n−1}ᵀ). При 2N < nₓ коэффициенты 𝒯_N известны точно (ВБC-13, п. 3).

### 4.2. Стартовый набор и дискретный первый полушаг

- **Точный 𝒯_N на сетке** независим ⇔ N ≤ ⌊nₓ/2⌋ (ВБC-13, п. 4) [ПРИНЯТО D-049.3, п. 3].
- **Сохранённый старт** `hs.start_set` = fl(sin(fl(iπl/n))²) отличается от точного. [НАБЛЮДЕНИЕ, эта платформа: NumPy 2.5.4]
  - на всех nₓ сеток D1 (N ≤ 3) 9295 из 12066 элементов (77,0 %) не равны правильно округлённому sin²;
  - max|T̂ − T*| = 1,77·10⁻¹⁵ = 15,9u;
  - 30 точных нулей sin²(kπ) = 0 (i·l ≡ 0 mod n) хранятся ненулевыми, ~10⁻³².

  Точный ранг сохранённого старта вычисляется (O1); связь с точным 𝒯_N — через РН-5.
- **Дискретный полный ранг w⁽¹⁾ — UNRESOLVED** (ВБC-20, п. 3). Причина: операторы L_i^h = (L − μ_i)² + E₂ не коммутируют.
  **Направление (не результат):** на симметричном подпространстве (РН-3) E₂ — ранга 1: E₂|_Sym = (1/h⁴)ffᵀ, f = e₁ + e_{n−1}. Тогда
  (L_i^h)⁻¹ = R_i − R_iffᵀR_i/(h⁴ + fᵀR_if) с коммутирующими R_i = (L − μ_i)⁻². Отсюда (L − μ_i)²V_i = g − τ_if со скалярами τ_i —
  дискретный аналог «L_iY_i = g плюс краевые условия». Довести до аналога РН-1 не удалось: [НЕ УСТАНОВЛЕНО]. Пока остаётся
  посеточная сертификация (РН-5).

### 4.3. РН-3: лемма симметрии [ВЫВОД ПРОЕКТА РН-3]

**Утверждение.** Пусть U ∈ ℝ^{(nₓ−1)×N} — любой независимый набор (симметрии от U не требуется). J_y — отражение l ↦ n_y − l на
внутренних узлах. Тогда решение V Y-полушага (ЧФ-C1) удовлетворяет J_yV = V. Значит, rank V ≤ min(N, ⌊n_y/2⌋). Для X-полушага —
то же с ⌊nₓ/2⌋. На точной дискретной последовательности со стартом 𝒯_N rank w⁽ˢ⁾ ≤ min(N, ⌊nₓ/2⌋, ⌊n_y/2⌋) при всех s ≥ 1.

**Область** [РЕЦ, разд. 3]: равномерная сетка, защемление на обоих концах решаемого направления, q = const, U независим. Утверждение
относится к **точному** решению полушага (O3, на любом входе) и к точной последовательности (O4-h). На вычисленные binary64-наборы (O1)
оно **не переносится**: округление может нарушить симметрию (следствие 2).

**Доказательство.** J_yL_yJ_y = L_y. Граничные строки D4 симметричны, поэтому J_yE₂J_y = E₂ и J_yD4_yJ_y = D4_y. J_y𝟏 = 𝟏. Отсюда
(I⊗J_y)𝒦^C(I⊗J_y) = 𝒦^C и (I⊗J_y)(F⊗𝟏) = F⊗𝟏. Решение единственно (𝒦^C ≻ 0, ВБC-13, п. 2), поэтому (I⊗J_y)vec V = vec V.
Симметричные векторы на узлах 1…n − 1 определяются первыми ⌊n/2⌋ значениями. Для последовательности: при s ≥ 2 оба множителя поля —
решённые наборы соседних полушагов, оба симметричны; при s = 1 rank ≤ rank 𝒯_N ≤ ⌊nₓ/2⌋ и rank V¹ ≤ ⌊n_y/2⌋. ∎

**Следствия.**

1. **Доказанная зависимость для S-1** (D-049.5, п. 2): при N > ⌊n_y/2⌋ точное w⁽¹⁾ имеет ранг < N. Это условие на конфигурацию,
   аналог ВБC-13, п. 4 для решаемого направления. Его можно проверить до первого полушага. В D1 нарушений нет: min⌊n_y/2⌋ = 3 у (14, 6)
   при N = 3 — равенство.
2. **Отрицательный пример O1 ↔ O4-h** (исправлено по РЕЦ, Ф-1). Четыре уровня утверждения разделены.
   - **(а) Теорема** [РН-3, PROVEN]. При N > ⌊n_y/2⌋ точное w⁽¹⁾ имеет ранг ≤ ⌊n_y/2⌋. Для N = 3 на сетках (14, 4), (12, 4), (16, 4),
     (14, 5), (13, 4), (10, 4) точный ранг ≤ 2. Это свойство точного решения полушага (O3) и точной последовательности (O4-h), а не

   - **(б) Наблюдения конкретных запусков** [НАБЛЮДЕНИЕ; сетки вне D1; 1 × 1, D = q = 1, первый полушаг Y].

### 4.4. РН-4: блок D (14, 6), N = 3 — точная сходимость [ВЫВОД ПРОЕКТА РН-4]

потеря ранга.

### 4.6. РН-5: сертификат O4-h на первом полушаге [ВЫВОД ПРОЕКТА РН-5]

На s = 1 точное подпространство 𝒰₁* = 𝒯_N известно в замкнутой форме. Положим:

- Ũ — сохранённый заданный набор после QR прототипа;
- R := (T*ᵀT*)⁻¹T*ᵀŨ (N × N, с интервальными оболочками sin²), U′ := T*R ∈ 𝒯_N, E := Ũ − U′;
- A′ = RᵀA(T*)R, B′ = RᵀB(T*)R, C′ = RᵀC(T*)R, F′ = RᵀF(T*). При 2N < nₓ A(T*), B(T*), C(T*), F(T*) известны из ВБC-13, п. 3 — это
  независимая проверка оболочек;
- δA = A(Ũ) − A′ и т. д. — точная рациональная часть минус оболочка;
- δ𝒦 = D[δA ⊗ D4 − 2δB ⊗ L + δC ⊗ I], ‖δ𝒦‖₂ ≤ D(‖δA‖₂·16/h⁴ + 2‖δB‖₂·4/h² + ‖δC‖₂) (RO ВОК-1).

Если λ_low(𝒦(Ũ)) > ‖δ𝒦‖₂, то для решений x* = vec V* (система Ũ) и x′ (система U′):

$$\|x'-x^*\|_2\le\frac{\|\delta F\otimes\mathbf 1\|_2+\|\delta\mathcal K\|_2\|x^*\|_2}{\lambda_{\mathrm{low}}(\mathcal K(\tilde U))-\|\delta\mathcal K\|_2},\qquad
w_h^{(1)}-W_1^*=-E\,V'^{\mathsf T}+\tilde U\,(V'-V^*)^{\mathsf T}.$$

Это стандартное возмущение линейной системы. Член E·V′ᵀ — следствие тождества U′V′ᵀ = ŨV′ᵀ − EV′ᵀ. Во взвешенной 2-норме, как RKR 4.1:
‖(w_h⁽¹⁾ − W₁*)_w‖₂ ≤ ‖E_w‖₂‖V′_w‖₂ + ‖Ũ_w‖₂√h_y‖x′ − x*‖₂, а ‖(ŵ₁ − W₁*)_w‖₂ ≤ ‖Ũ_w‖₂√h_y·b с границей BR. Вейль даёт сертификат
rank w_h⁽¹⁾ = N при σ_N(ŵ_{1,w}) больше суммы этих двух величин. Все величины — точные или направленные оценки по сохранённым массивам.

**Порядок величины** (оценка, на сетках D1 не вычислялась). |E| ~ 16u (разд. 4.2). 𝒦 ⪰ D(C ⊗ I), поскольку A ⊗ D4 ⪰ 0 и
−2B ⊗ L ⪰ 0. Поэтому λ_low(𝒦) ≥ Dλ_min(C) ≥ D(μ₁ˣ)² (RO ВОК-1) при h-ортонормированном Ũ. Грубая мажоранта через ‖δC‖₂ ≤ 2hₓ‖Ũ‖₂‖D4ₓ‖₂‖E‖₂
даёт ‖δ𝒦‖₂/λ_low ~ 10⁻⁶ при nₓ ≤ 200 (блоки B, C). Это против ρ̂₃ ≥ 1,1·10⁻⁵ на D0: запас лишь ~5.

Точное значение много меньше. Справедливо ŨᵀD4ₓE = (D4ₓŨ)ᵀE: гладкий D4ₓŨ ≈ Ũ·diag(μ²) почти ортогонален высокочастотному шуму E.
Поэтому в РН-5 δA, δB, δC вычисляются **точно**, а не мажорируются через ‖D4‖. На малых сетках (разд. 4.8, s = 1) распространённая часть
p₁ — (1,5…2,1)·10⁻¹⁵ относительно [НАБЛЮДЕНИЕ]. Вывод: **O4-h при
s = 1 сертифицируема существующими средствами** — оболочки sin², точные коэффициенты, λ_low и BR. Новой математики сверх РН-5 не нужно.

### 4.7. Перенос ошибки полушага на последовательность [ВЫВОД ПРОЕКТА РН-6…РН-9]

**РН-6 (возмущение проекции).** Пусть M, M′ — замкнутые подпространства гильбертова пространства, P, P′ — ортопроекторы, ω — элемент.
Тогда

$$\|P'\omega-P\omega\|\le\operatorname{dist}(P\omega,M')+\|\omega-P\omega\|\;\delta(M',M),\qquad \delta(M',M):=\sup_{m'\in M',\|m'\|=1}\operatorname{dist}(m',M).$$

*Доказательство.* Пусть w = Pω и r = ω − w ⊥ M. Тогда P′ω − w = (P′w − w) + P′r, ‖P′w − w‖ = dist(w, M′) и
‖P′r‖ = sup_{m′∈M′,‖m′‖=1}[r, m′] = sup[r, m′ − Pm′] ≤ ‖r‖δ(M′, M). ∎

**РН-7 (угол оболочек столбцов).** Пусть A, B — вещественные матрицы одного размера точного ранга N. Тогда
sup_{x∈colsp A, ‖x‖=1} dist(x, colsp B) ≤ ‖A − B‖₂/σ_N(A). То же верно в метрике M ≻ 0 при замене A, B на M^{1/2}A, M^{1/2}B.

*Доказательство.* Пусть P_B^⊥ — ортопроектор на (colsp B)^⊥. Тогда P_B^⊥A = P_B^⊥(A − B). Для единичного x = Az с z в строчном
пространстве A ‖z‖ ≤ 1/σ_N(A), поэтому ‖P_B^⊥x‖ ≤ ‖A − B‖₂/σ_N(A). ∎ (Аналог оценки Ведина в R4NS 5.2.1 (6), доказан здесь
элементарно.)

**РН-8 (тождество и множитель Z_s).** **Предпосылки** (записаны явно по РЕЦ, Ф-6; доказательство не меняется):

- (Р1) rank w_h⁽ˢ⁻¹⁾ = N — поле точной последовательности на полушаге s − 1 имеет полный ранг. Тогда 𝒰*_s = colsp w_h⁽ˢ⁻¹⁾ —
  N-мерное заданное подпространство точной последовательности на полушаге s;
- (Р2) rank Ŵ_{s−1} = N — точное произведение сохранённых факторов предыдущего поля имеет полный ранг. Тогда colsp Ŵ_{s−1} = 𝒰̂_s —
  N-мерное заданное подпространство вычисленной траектории;
- (Р3) для оценки нормы ниже: X_k ≻ 0 (D4ₓ, −Lₓ, I и их аналоги по y положительно определены); M ≻ 0 — метрика угла θ_M.

При нарушении (Р1) или (Р2) 𝒰*_s ≠ colsp w_h⁽ˢ⁻¹⁾ или colsp Ŵ_{s−1} ≠ 𝒰̂_s, и тождество к паре (𝒰*_s, 𝒰̂_s) не применяется.
(Р1) даёт сертификат ранга O4-h шага s − 1: РН-5 при s − 1 = 1; РН-9 с критерием Вейля ниже при s − 1 ≥ 2. (Р2) проверяется точно по
сохранённым массивам (O1, РТ-1). Без этих проверок РН-8 и РН-9 на полушаге s не используются.

Пусть Π — любой проектор на 𝒰*_s = colsp w_h⁽ˢ⁻¹⁾, Z_s := Ŵ_{s−1}⁺W*_s. Тогда

$$(I-\Pi)\,W_s^*=(I-\Pi)\,(\hat W_{s-1}-w_h^{(s-1)})\,Z_s .$$

*Доказательство.* Столбцы W*_s лежат в 𝒰̂_s = colsp Ŵ_{s−1}, поэтому W*_s = Ŵ_{s−1}Ŵ_{s−1}⁺W*_s. Кроме того,
(I − Π)w_h⁽ˢ⁻¹⁾ = 0. ∎

Для матриц T (по x) и Z (по y) в a-норме

$$\|TFZ\|_a\le\max_{k}\bigl(\|T\|_{X_k}\,c_{Z,Y_k}\bigr)\,\|F\|_a,\quad (X_k,Y_k)\in\{(D4_x,I),(-L_x,-L_y),(I,D4_y)\},$$

где ‖T‖_X := ‖X^{1/2}TX^{−1/2}‖₂ и c_{Z,Y} := ‖Y^{−1/2}ZY^{1/2}‖₂. *Доказательство:* a_h(F) = Dhₓh_y[tr(FᵀD4ₓF) + 2tr(Fᵀ(−Lₓ)F(−L_y)) +
tr(FᵀFD4_y)]; каждое слагаемое оценивается отдельно, поскольку tr(XZYZᵀ) ≤ c²tr(XY) при ZYZᵀ ⪯ c²Y и X ⪰ 0. ∎

Для неизвестного Π берётся проектор на 𝒰*_s вдоль ker P̂, где P̂ — M-ортопроектор на 𝒰̂_s. Он существует при θ_M < π/2, где θ_M —
наибольший главный угол между 𝒰*_s и 𝒰̂_s в метрике M. Тогда Π = ΠP̂, P̂ = P̂Π, Π − P̂ = (I − P̂)ΠP̂ и ‖Π − P̂‖_M ≤ tan θ_M: для
x ∈ 𝒰̂_s элемент Πx ∈ 𝒰*_s имеет 𝒰̂-составляющую x. В других метриках
‖Π − P̂‖_X ≤ κ(X, M)^{1/2} tan θ_M, где κ(X, M) = λ_max(M⁻¹X)λ_max(X⁻¹M). Угол θ_M ограничен по РН-7 через Ŵ_{s−1} и
e_{s−1} + q_{s−1}.

**РН-9 (рекурсивная апостериорная граница).** При s ≥ 2, предпосылках (Р1)–(Р3) РН-8 на полушаге s и θ̄_M < π/2

$$e_s\le b_s+C_s\,(e_{s-1}+q_{s-1})+\bar r_s\,\bar\delta_s,\qquad C_s=\max_k\bigl(\|I-\hat P\|_{X_k}+\|\Pi-\hat P\|_{X_k}\bigr)c_{Z_s,Y_k},$$

где r̄_s ≥ ‖ω_h − W*_s‖_a — сертифицированная граница и δ̄_s := max_k‖I − P̂‖_{X_k}‖Π − P̂‖_{X_k} ≥ δ_a(M*_s, M̂_s). Нормы
‖Π − P̂‖_X берутся по оценке выше через θ̄_M. Сертификат ранга O4-h на полушаге s: σ_N(ŵ_{s,w}) > e_s/(Dλ_low(𝒜))^{1/2}, где
λ_min(𝒜) ≥ (μ₁ˣ + μ₁ʸ)² (RO ВОК-1), а a_h(F) ≥ Dhₓh_yλ_min(𝒜)‖F‖²_F.

*Доказательство.* e_s ≤ b_s + p_s, p_s = ‖W*_s − w_h⁽ˢ⁾‖_a. По РН-6 с M = M̂_s, M′ = M*_s
p_s ≤ dist_a(W*_s, M*_s) + ‖ω_h − W*_s‖_aδ_a(M*_s, M̂_s). ΠW*_s ∈ M*_s, поэтому dist ≤ ‖(I − Π)W*_s‖_a. По РН-8 и оценке нормы
это ≤ C_s‖Ŵ_{s−1} − w_h⁽ˢ⁻¹⁾‖_a ≤ C_s(q_{s−1} + e_{s−1}). Для δ_a: (I − P̂)m = (I − P̂)(Π − P̂)m при m ∈ M*_s. Вейль:
‖F‖_{2,w} ≤ ‖F‖_a/(Dλ_min(𝒜))^{1/2}. ∎

## 5. Защитная остановка до QR (п. 7 задания)

### 5.1. Нормативная база и противоречие

[ПРИНЯТО] D-049.5, п. 1: «при потере или неразличимости ранга — остановка **до QR**, без понижения N, регуляризации и восстановления
направлений». П. 2: S-1 — только при доказанной зависимости; иначе статус защитной остановки; S-2 по неквалифицированному порогу не
присваивается. MS-C C.11.2, пп. 1–3: то же со ссылкой на R4NS 5.4.1, 5.5. R4NS 5.2 п. 9: **«численно неразличимый ранг: ρ̂_N ≤ ε/(1 − ε)
… либо бюджет ε не установлен»**. Объект ε — поле точной **последовательности** W* (R4NS 5.2 п. 6), то есть O4-h. D-054.5: O4 —
UNRESOLVED; K, c_d, c_rank, τ_set, δ_f не утверждены.

**Буквальное следствие.** Пока бюджет ε для O4-h не установлен, ранг при N = 2, 3 формально «численно неразличим» на каждом полушаге.
Значит, требуется остановка до QR после первого решённого полушага.

**Фактическое поведение принятых инструментов.**

| Инструмент | Решение | Поведение при N ≥ 2 | Место |
|---|---|---|---|
| SEQ (`r5_cccc_sequence`) | D-051.1 — технически принят как исследовательский QA-инструмент | QR продолжается: «RESEARCH_ONLY: QR without an approved rank criterion»; остановка только при точной зависимости сохранённого набора | docstring, стр. 24–27, 133, 170–179 |
| ОП-8 | D-055.1 — ACCEPTED_LIMITED_RESEARCH_QA_TOOL | то же: `rank_decision = UNRESOLVED`, QR продолжается | docstring, стр. 25–27; стр. 460 |
| данные Q3, PR #41, PR #42 (N = 2, 3, s = 2…8) | D-053 (Q3), D-054 | получены цепочками с продолжением QR | RK 3; Q3 |
| PROT, разд. 3, блок D | D-055.2 — APPROVED_PROTOCOL | «Ранг диагностируется на каждом полушаге (D-049.5, п. 1). При неразличимости ранга — защитная остановка до QR» | PROT, стр. 141–144 |

**Расхождение.** Принятые решения D-051.1, D-053, D-055.1 приняли инструменты и данные, которые продолжают QR при неустановленной
различимости. D-049.5 вместе с MS-C C.11.2 и R4NS 5.2 п. 9 этого не допускает. D-055.2 утвердил протокол с требованием остановки. Это не
математическая ошибка. Literature предлагала рассматривать его как **неоднозначность объекта применения D-049.5**:

- (а) D-049.5 относится к исследовательскому режиму **реализации метода**, а QA-эталонные цепочки идут с маркировкой RESEARCH_ONLY;
- (б) D-049.5 относится ко всем расчётам N = 2–3, включая траектории QA кампании D1.

**Вывод рецензии** [РЕЦ, разд. 6]. Для D1 это **не противоречие решений, а невыполненное требование.** Сама D-049.5 и есть
исследовательский режим N = 2–3, в котором QR при неразличимом ранге запрещён. Протокол D1 (D-055.2, разд. 3, блок D) требует остановки
однозначно, а D-055.1 принял ОП-8 с явно перечисленными ограничениями. По R4NS 5.2 п. 9 («либо бюджет ε не установлен») ранг при N = 2, 3
сейчас **неразличим**. Поэтому до рангового сертификата для D1 буквально применяется **вариант В** — защитная остановка до QR (разд. 5.4).
Это сохранение действующей политики, а не новая ранговая норма. Неоднозначность (а)/(б) реальна **только для статуса прежних данных**
Q3 и PR #41–#42 при N ≥ 2, s ≥ 2. Они и так RESEARCH_ONLY, и уточнение формулировки их статус не меняет. Этот документ решения не
принимает.

**Почему расхождение не формальность** (разд. 4.3, следствие 2; исправлено по РЕЦ, Ф-1). Срабатывание остановки SEQ и ОП-8 по точной
зависимости сохранённого набора зависит от округлений решателя: на сетках разд. 4.3 SEQ всегда остановился по S-1, ОП-8 — на четырёх
сетках из шести, а на (12, 4) и (10, 4) ОП-8 получил набор точного ранга 3 и продолжил QR. Гарантии срабатывания нет. Продолжение QR на
численно зависимом наборе создаёт направление из шума, то есть неявный вариант C R4NS 5.5 — подмену подпространства. На D0 запасы
велики: ρ̂₃ ≥ 1,1·10⁻⁵ против уровня QR ~10⁻¹⁶·κ. Но это наблюдение, а не гарантия.
