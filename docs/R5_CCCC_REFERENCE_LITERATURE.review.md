**Тип документа.** Литературный обзор и рекомендация для решения владельца. Это не спецификация и не решение.

**Целевая задача.** Изгиб изотропной пластины Кирхгофа–Лява D∇⁴w = q на прямоугольнике под равномерной нагрузкой.
Все края защемлены (CCCC): w = 0 и ∂w/∂n = 0. Нужен эталон, который для CCCC играет ту же роль, что ряд Навье
для SSSS.

**Нормировка в документе.** α = w(центр)·D/(q·ℓ⁴), где ℓ — **полная** длина короткой стороны, r = длинная/короткая ≥ 1.

## 4. Формулы и численные данные по источникам

### 4.1. Хенки–Инглис: Meleshko & Gomilko (P5, P4) и Batista (L-058)

Пластина |x| ≤ a, |y| ≤ b, то есть a и b — **полустороны**.

- **P5 (3.1), с. 810 (сверено с изображением).** Исправленная форма Хенки–Инглиса (сноска на с. 810 отмечает
  опечатку в P4 (3.19)). Для w:

  w = (p₀/(8D))(a² − x²)(b² − y²) − b Σₘ (−1)ᵐ (Xₘ/αₘ) H(y, αₘ, b) cos αₘx + a Σₗ (−1)ˡ (Yₗ/βₗ) H(x, βₗ, a) cos βₗy,

  где αₘ = (2m − 1)π/(2a), βₗ = (2l − 1)π/(2b).
  `[MG2004, ур. (3.1), с. 810] references/Поиск статей/meleshko2004.pdf`

  В оригинале формула записана совместно для w и функции тока Ψ: множитель p₀/(8D) стоит только при полиноме,
  а свободные члены (3.3) не содержат p₀/D. Следовательно, в (3.1)–(3.3) либо неявно принято p₀/(8D) = 1,
  либо коэффициенты Xₘ, Yₗ отнесены к p₀/(8D). Авторы этого явно не оговаривают. Размерный множитель
  при рядах нужно установить при сверке Reviewer (ОВ-13). Сравнение с L-058 (26)–(27), где множитель q/D
  стоит явно, — один из способов это сделать.

- **P5 (3.2), с. 810.** H(z, λ, h) = h·tanh(λh)·cosh(λz)/cosh(λh) − z·sinh(λz)/cosh(λh).
- **P5 (3.3), с. 811 (сверено с изображением).** Fₘ = −b/(aαₘ²), Hₗ = a/(bβₗ²). Это свободные члены системы (1.1)
  для задачи (2.1)–(2.2).
- **P4 (2.1), с. 2142.** Система (1.1):

  Xₘ·b·Δ(αₘb) = Σₗ Yₗ·4αₘ²βₗ/(βₗ² + αₘ²)² + Fₘ, и симметричное уравнение для Yₗ,

  где Δ(ξ) = tanh ξ + ξ/cosh²ξ.
- **P5 (3.7), с. 811 (сверено с изображением).**

  (1/(h·Δ(λh))) · Σᵢ 4λ²δᵢ/(δᵢ² + λ²)² < 0.77 < 1, δᵢ = (2i − 1)π/(2h).

  Из этого следует полная регулярность системы (1.1). По Канторовичу–Крылову (1964, с. 28) при ограниченных Fₘ, Hₗ
  существует **единственное ограниченное** решение. Его можно найти последовательными приближениями из любого
  ограниченного начального значения (P5, с. 811).
- **P5 (3.8), с. 811.** Неограниченные решения (1.9) дают нулевой вклад в w. Поэтому физическое поле единственно.
- **P5 (3.13)–(3.14), с. 813.** xₘ = Re(E·m^(−ζ₁)) + O(m⁻³) с ζ₁ ≈ 2.74 + 1.12i. Это корень, отвечающий угловой
  особенности. Неизвестные убывают алгебраически; именно поэтому ряды для моментов на краю сходятся медленно.
- **L-058 (24)–(28), с. 12 (сверено с изображением).**
  - w₀ = q(x² − a²)(y² − b²)/(8D) — (24);
  - Cₙ = −Dₙ tanh βₙa, Aₙ = −Bₙ tanh αₙb — (25);
  - система (26)–(27), «equivalent to the system obtained by Hencky»;
  - замена Bₙ′ = aαₙBₙ/b, Dₙ′ = −bβₙDₙ/a — (28) — делает систему полностью регулярной.

  Batista приводит те же утверждения о регулярности, что P5, но без доказательства, со ссылками на [6] и [12].
- **P4, разд. 3(a), с. 2149–2152.**
  - Форма Коялович–Бубнова (3.9)/(3.16).
  - Свойство E = 0 (3.21).
  - Перерезывающие силы в углах равны нулю (3.24).
  - G = 12 для квадрата (точно) и G = 17.972 для b = 2a.

  Численные прогибы в P4 не приводятся, P4 отсылает к L-046.
- **P3 (Davis), с. 410–411 (с. 410 сверена с изображением).**
  - Система (1.1) имеет однородное решение Xₘ = αₘ, Yₗ = βₗ. Оно неограничено.
  - Сопряжённая однородная система имеет решение Uₘ = Vₗ = 1. Отсюда условие разрешимости (1.4):
    Σ(Fₘ + Hₘ) = 0. Оно необходимо при сходимости ΣXₘ и ΣYₗ.
  - Для пластины условие выполнено (MG (3.21)).
  - В форме Коялович–Бубнова есть ограниченное однородное решение Xₙ = Yₖ = 1, поэтому G неопределима без
    дополнительного условия.
  - Ответ P5: для формы Хенки (полная регулярность) выбор ограниченного решения однозначен.

  **Вывод для R5.** Форма Хенки–Инглиса не имеет проблемы неединственности, если искать ограниченное решение.
  Форма Коялович–Бубнова требует дополнительного условия на G или B₀ (P5 (3.23)–(3.24), с. 815).

## 6. Оценка методов

### 6.1. Хенки–Инглис (P5 (3.1)–(3.3), P4 (2.1); L-058 (24)–(28))

**Точное представление.** Ряд (3.1) — точное представление решения при точном решении бесконечной системы (1.1).

- Уравнение D∇⁴w = q и условие w = 0 на контуре выполняются тождественно (P5, с. 811).
- Условие ∂w/∂n = 0 сводится к системе (1.1).
- Ряды непрерывны вплоть до границы и почленно дифференцируемы внутри (P5, с. 811).

**Приближение.** Конечное приближение строится редукцией системы к N + K уравнениям; её сходимость
к ограниченному решению следует из полной регулярности (Канторович–Крылов, по P5).

**Собственный вывод (уровень Б, требует проверки Reviewer).**

1. Подставим t = λh, gᵢ = δᵢh = (2i − 1)π/2 в (3.7). Множители h сокращаются, и левая часть принимает вид
   f(t) = Σᵢ 4t²gᵢ/(gᵢ² + t²)² / Δ(t). Она зависит только от t.
2. Если, как утверждают P5 и Абрамян (1957), неравенство (3.7) выполнено при всех t > 0, оценка 0.77 равномерна
   по отношению сторон r.
3. После деления строк на диагональ система имеет вид (I − K)z = f с ‖K‖∞ ≤ ρ < 0.77.
4. Отсюда ‖(I − K)⁻¹‖∞ ≤ 1/(1 − ρ) и κ∞(I − K) ≤ (1 + ρ)/(1 − ρ) < 7.7.
5. Конечная секция K_N имеет построчные суммы не больше, чем K. Поэтому та же оценка верна для любой редукции.
6. **Оговорка.** Сопряжённая однородная система имеет решение Uₘ = Vₗ = 1 (P3, с. 410, сверено с изображением).
   - Значит, взвешенные суммы по столбцам внедиагональной части стремятся к диагонали. Ограниченности в нормах 1
     и 2 нет.
   - Оценка обусловленности п. 4 верна **только в ∞-норме**. κ₁ и κ₂ конечных секций могут расти с N.
   - Анализ погрешности эталона A следует вести в ∞-норме.

Источник утверждения «при всех t > 0» (Abramian 1957; Meleshko & Gomilko 1994) в библиотеке отсутствует (ОВ-2).

**Сильные стороны:**

- полное поле;
- доказанные существование и единственность ограниченного решения;
- известная асимптотика неизвестных (3.13)–(3.14), которую можно использовать для ускорения («improved reduction»,
  L-046 с. 39);
- обусловленность, ограниченная в ∞-норме;
- любое r;
- метод не использует вариационный шаг и разделение переменных с чередованием, поэтому структурно независим от КК-МВИ;
- есть независимые реализации в литературе (P7 «Hencky», L-058, L-046).

**Слабые стороны:**

- в источниках нет явной оценки остатка редукции;
- из-за угловой особенности (ζ₁) неизвестные убывают алгебраически, поэтому моменты на краю сходятся медленно
  (у L-058 до 1201 членов);
- энергию нужно выводить самостоятельно (замкнутые интегралы от H по z).

4. Альтернатива — двусторонние лимитанты Кояловича (L-046, табл. 1, с. 38). Их применимость требует

### 6.3. Taylor–Govindjee, метод Ритца (P7)

**Представление.** Двумерный базис, в котором заложены все граничные условия. Неизвестные находятся из
энергетического функционала. Бесконечной системы суперпозиции нет, гиперболических функций нет.

**Независимость.**

- От Хенки независим по представлению, способу выполнения ГУ и алгебре.
- От КК-МВИ независим по структуре: фиксированный тензорный базис, итераций с чередованием нет.
- Функционал энергии тот же, что лежит в основе вариационных методов. Если дискретизация КК-МВИ в R5 будет
  использовать тот же тригонометрический базис, независимость частичная (ОВ-10).

**Сходимость.**

- Энергия по Ритцу сходится монотонно (общая теория метода Ритца; в P7 не формулируется).
- Для значения в точке оценки нет.
- Сходимость алгебраическая: для 10 знаков w(центр) нужно M ≥ 800 (P7, табл. I); моменты на краю при M = 2000
  ещё не сошлись (P7, с. 5–6).
- Обусловленность после масштабирования около 4.

**Точность 10⁻⁸ или 10⁻¹⁰** для значения в точке не обоснована. Обосновать её можно было бы только через
двусторонние энергетические оценки (P6 ссылается на Diaz & Greenberg 1948; этой работы в библиотеке нет) и перенос
оценки энергии на точку. Пути такого переноса в источниках нет.

### 6.4. Остальные методы

- **Morley (P6).** Экономное представление (корни Папковича–Фадля) и полное поле. Доказательства сходимости нет,
  приведено только два приближения, есть комплексная алгебра. Подходит только как исторический и качественный
  контроль (3 знака).
- **Li et al. (P1).** Независим от КК-МВИ, но по-видимому принадлежит семейству суперпозиции (разд. 4.4).
  Сходимость медленная и немонотонная, опубликовано 3 знака, доказательств нет. Как эталон не рекомендуется.
- **An–Gu–Su (P8).** Это полудискретный метод: разложение по фиксированному базису по одной переменной и численное
  решение системы ОДУ по другой. По структуре он совпадает с проекционным шагом метода Канторовича. Поэтому его
  независимость от КК-МВИ **сомнительна** (собственная оценка; родство с методом Канторовича по D-045/D-046
  требует проверки по публикациям). Кроме того, значения немонотонны по N, а при c = 1.2 расходятся с P7.
  Не рекомендуется ни как эталон A, ни как B.
- **Bhaskar–Sivaram (P2).** CCCC не рассматривает.
- **Коялович–Бубнов (P4, P5).** Это эквивалентная альтернатива Хенки внутри того же семейства, а не независимый
  метод. Её достоинство — точное значение G = 12 для квадрата (P4, Гринченко–Улитко) как внутренняя проверка.
  Неединственность снимается дополнительным условием.

## 7. Рекомендация

- **Эталон A — основной аналитический эталон полного поля:** суперпозиция Хенки–Инглиса по P5 (3.1)–(3.3),

  - Использовать для w в центре и энергии (работы), но не для моментов на краю.
  - При выборе дискретизации КК-МВИ проверить, что B не использует тот же базис (ОВ-10).
- **Эталон C — опубликованные значения:**
  - P7, табл. I–II: r = 1; 1.2–2.0; 20. Прогибы, моменты, работа.
  - L-058, табл. 5a–5b: r = 1; 1.5; 2; 3; 4; 5; 10. Прогибы, моменты в центре и на краях, перерезывающие силы.

  двумерной МКР- или МКЭ-проверки для изотропной пластины Кирхгофа.

  для бигармонического оператора с законтурными узлами. Одномерный МКР внутри ВИМ эталоном D не является (AGENTS.md, разд. 4).
