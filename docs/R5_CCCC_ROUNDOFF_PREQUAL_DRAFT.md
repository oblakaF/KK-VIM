## 1. Общая спектральная лемма для Π_h^C

### ВОК-1. Границы спектра D4 и 𝒜

**Утверждение.** Для любых nₓ, n_y ≥ 2:

1. λ_max(D4) ≤ ‖D4‖∞ ≤ 16/h⁴, λ_min(D4) ≥ μ₁²;
2. (μ₁ˣ + μ₁ʸ)² ≤ λ_min(𝒜) ≤ λ_max(𝒜) ≤ (4/hₓ² + 4/h_y²)²;
3. max_i Σ_j |𝒜_ij| ≤ (4/hₓ² + 4/h_y²)²;
4. следовательно, для v ∈ V_h:
   $$D^{1/2}(\mu_1^x+\mu_1^y)\,\|v\|_h\le\|v\|_a\le D^{1/2}\Bigl(\frac4{h_x^2}+\frac4{h_y^2}\Bigr)\|v\|_h .$$

**Доказательство.**

1. D4 симметрична. Модули строк: граничная — 7 + 4 + 1 = 12, вторая — 4 + 6 + 4 + 1 = 15, внутренние — 1 + 4 + 6 + 4 + 1 = 16 (в единицах
   h⁻⁴; при малых n строки укорочены и суммы меньше). По Гершгорину λ_max(D4) ≤ 16/h⁴. D4 = L² + E₂, E₂ ⪰ 0, поэтому
   λ_min(D4) ≥ λ_min(L²) = μ₁².
2. −L ≻ 0 с собственными значениями μ_k ∈ (0, 4/h²), поэтому Lₓ ⊗ L_y = (−Lₓ) ⊗ (−L_y) ≻ 0 и
   μ₁ˣμ₁ʸ ≤ λ(Lₓ ⊗ L_y) < 16/(hₓ²h_y²). Для суммы симметричных матриц λ_max(ΣXᵢ) ≤ Σλ_max(Xᵢ), λ_min(ΣXᵢ) ≥ Σλ_min(Xᵢ). Отсюда
   λ_max(𝒜) ≤ 16/hₓ⁴ + 32/(hₓ²h_y²) + 16/h_y⁴ = (4/hₓ² + 4/h_y²)² и λ_min(𝒜) ≥ (μ₁ˣ)² + 2μ₁ˣμ₁ʸ + (μ₁ʸ)².
3. Модуль строки суммы не больше суммы модулей строк слагаемых: ≤ 16/hₓ⁴ + 2·4·4/(hₓ²h_y²) + 16/h_y⁴.
4. ‖v‖_a² = D hₓh_y vᵀ𝒜v и п. 2. ∎

### ВОК-2. Тождество при неточном решении полушага

**Утверждение.** Пусть Û — сохранённый (после QR — преобразованный) массив заданного набора, Ṽ_prev — сохранённый массив второго
множителя предыдущего поля, V̂ — любое вычисленное решение (ЧФ-C1), ρ := F ⊗ 𝟏 − 𝒦^C vec(V̂), Δ := Ṽ_prev − V̂, d̃ := ÛΔᵀ,
w̃⁽ˢ⁻¹⁾ := ÛṼ_prevᵀ, w̃⁽ˢ⁾ := ÛV̂ᵀ (точные произведения сохранённых массивов). Тогда в точной арифметике

$$\Pi_h^C(\tilde w^{(s-1)})-\Pi_h^C(\tilde w^{(s)})=\tfrac12\|\tilde d\|_a^2-\gamma_s,\qquad \gamma_s:=h_y\sum_{i=1}^{N}\rho_i^{\mathsf T}\Delta_i .$$

**Доказательство.** Π_h^C(v) − Π_h^C(w) = ½a_h(v − w, v − w) + [a_h(w, v − w) − l_h(v − w)]. При v − w = ÛΔᵀ:
a_h(ÛV̂ᵀ, ÛΔᵀ) = h_y vec(V̂)ᵀ𝒦^C vec(Δ) (NS 4.3, П-S1: a_h^C(UṼᵀ, UṼᵀ) = h_y vec(Ṽ)ᵀ𝒦^C vec(Ṽ), билинейная форма — поляризацией);
l_h(ÛΔᵀ) = q hₓh_y 𝟏ᵀÛΔᵀ𝟏 = h_y Σᵢ(q hₓÛᵢᵀ𝟏)(Δᵢᵀ𝟏) = h_y (F ⊗ 𝟏)ᵀvec(Δ) (F = q hₓÛᵀ𝟏). Скобка равна −h_y ρᵀvec(Δ). ∎

**Свойства.** Тождество верно при любой точности Û, Ṽ_prev, V̂ (как R4 6.3, п. 2): неточность решения учтена γ_s, ошибки факторов в
тождество не входят. Условие — P_{s−1} вычисляется по **тем же** массивам, что используются на полушаге s.

**Уровень:** Б. **Статус:** ДОКАЗАНО (перенос ЧВ4-14, п. 3, на Π_h^C; оператор входит только через a_h и 𝒦^C).

### ВОК-3. Путь вычисления и модель округления сборки R^C(w)

**Путь [ИНЖ; фиксируется до Q3].** Π_h^C вычисляется **по определению NS 2.2**: Δ_h^C = Łₓ ⊗ E_y + Eₓ ⊗ Ł_y во всех узлах 0…nₓ × 0…n_y
(включая граничные строки Ł с (Łf)₀ = 2f₁/h²), веса W = diag(h/2, h, …, h, h/2). Альтернативный путь (D hₓh_y wᵀ𝒜w/2 по 13-точечному
шаблону) алгебраически равен (Предложение D), но округляется иначе. Модель относится к выбранному пути.

**Мажоранта.** Для поля w:

- (|Δ|^C w)ᵢⱼ := (|Ł|ₓ|w|)ᵢⱼ + (|Ł|_y|w|)ᵢⱼ, где |Ł| — шаблон Ł с модулями коэффициентов:
  (|Ł|f)ᵢ = (|f_{i−1}| + 2|fᵢ| + |f_{i+1}|)/h² при 0 < i < n; (|Ł|f)₀ = 2|f₁|/h², (|Ł|f)_n = 2|f_{n−1}|/h²;

$$\hat S^C(w):=\frac D2\sum_{i,j=0}^{n_x,n_y}(W_x\otimes W_y)_{ij}\,|(\Delta_h^Cw)_{ij}|\,(|\Delta|^Cw)_{ij}+|q|\,h_xh_y\sum_{\text{внутр.}}|w_{ij}|,$$

$$R^C(w):=u\,\bigl(\lceil\log_2 M\rceil+c_R\bigr)\,\hat S^C(w),\qquad M=(n_x+1)(n_y+1)+(n_x-1)(n_y-1).$$

**Вывод (первый порядок).** Как И-8 R2 (NUMERICAL_SPEC 10.3), по слагаемым:

- ошибка значения шаблона в узле ≤ c_Δ u(|Δ|^Cw). Во внутренней строке — сумма до пяти слагаемых с делением на h² (как R2). В граничной
  строке — одно умножение 2·(1/h²)·f₁; множитель 2 и веса ½ точны в двоичной арифметике (П-1…П-3), поэтому c_Δ граничной строки не
  больше, чем внутренней;
- квадрат значения, умножение на вес и D/2 — ≲ c_sq u|Δw|(|Δ|w);
- попарное или иное суммирование M слагаемых — u⌈log₂M⌉Σ|слагаемых| (попарное) или до uM (последовательное).

c_R := c_Δ + c_sq зависит от **порядка операций реализации**. В R2 для SSSS c_R = 16 (5 + 11) при попарном суммировании. Для CCCC число
операций на слагаемое не больше, чем в R2, поэтому c_R = 16 — **кандидат по аналогии с R2** *(уточнено по Р-1 `f4a4cb9`)*, а не
выведенная оценка. Значение c_R — подсчёт операций по коду QA (или Builder) до Q3; при иной организации вычислений (иное суммирование,
иная предварительная нормировка) оно иное.

**Уровень:** В (модель реализации). **Статус:** МОДЕЛЬ (как И-8 R2); c_R — подсчёт по коду до Q3; правильность модели — ЭКСПЕРИМЕНТ (Q3, Е-1).

### ВОК-5. Энергетическая норма ошибки образования

**Утверждение.** При ВОК-4

$$\|e^{(j)}\|_a\le\varepsilon_a^C(j):=\gamma_N\,\kappa_W^{(j)}\,D^{1/2}\Bigl(\frac4{h_x^2}+\frac4{h_y^2}\Bigr)\|\hat w^{(j)}\|_h\le\gamma_N\,\kappa_W^{(j)}\,\Lambda_h\,\|\hat w^{(j)}\|_a,\qquad

### ВОК-10. Спектральная локализация ёмкости S

**Утверждение.** Пусть A ≻ 0, B, C ⪰ 0 (выполнено для независимого набора, NS 4.2). Тогда

$$\frac1D\,A^{-1}\otimes\Bigl(\frac{h_y^4}2I_2+\varrho^2T_0\Bigr)\ \preceq\ S\ \preceq\ \frac1D\,A^{-1}\otimes\Bigl(\frac{h_y^4}2I_2+T_0\Bigr),\qquad
T_0:=P^{\mathsf T}(L_y^2)^{-1}P=h_y^4\begin{pmatrix}\frac{(n-1)(2n-1)}{6n}&\frac{n^2-1}{6n}\\[2pt]\frac{n^2-1}{6n}&\frac{(n-1)(2n-1)}{6n}\end{pmatrix},$$

n := n_y. Собственные значения T₀: λ_max = h_y⁴(n − 1)/2, λ_min = h_y⁴(n − 1)(n − 2)/(6n). Следовательно,

$$\operatorname{cond}(S)\le\operatorname{cond}(A)\cdot\mathcal C_S(n,\varrho),\qquad
\mathcal C_S(n,\varrho):=\frac{n}{1+\varrho^2\,(n-1)(n-2)/(3n)}\ \le n,\qquad \lim_{n\to\infty}\mathcal C_S=\frac3{\varrho^2}.$$

**Доказательство.**

1. **Модальная форма.** Zᵀ𝒦₀⁻¹Z = Σₖ (DMₖ)⁻¹ ⊗ zₖzₖᵀ (подстановка 𝒦₀⁻¹ = D⁻¹Σₖ Mₖ⁻¹ ⊗ ψₖψₖᵀ); G⁻¹ = (h_y⁴/(2D))A⁻¹ ⊗ I₂.
2. **Верхняя граница Mₖ⁻¹.** B, C ⪰ 0, μₖ > 0 ⇒ Mₖ ⪰ μₖ²A ⇒ Mₖ⁻¹ ⪯ A⁻¹/μₖ².
3. **Нижняя граница Mₖ⁻¹.** По определению β_U, χ_U: B ⪯ β_U A, C ⪯ χ_U A. Тогда Mₖ ⪯ (μₖ² + 2μₖβ_U + χ_U)A ⪯ (μₖ + ϑ_U)²A, так как
   (μ + β + √γ)² ≥ μ² + 2μβ + γ. Функция μ ↦ μ/(μ + ϑ) возрастает, μₖ ≥ μ₁, поэтому Mₖ⁻¹ ⪰ A⁻¹/(μₖ + ϑ)² ⪰ ϱ²A⁻¹/μₖ².
4. **Сумма.** Кронекерово произведение двух положительно полуопределённых матриц положительно полуопределено, поэтому порядок Лёвнера
   сохраняется: Σₖ X ⊗ zₖzₖᵀ/μₖ² = X ⊗ T₀, где T₀ = Σₖ zₖzₖᵀ/μₖ² = Pᵀ(Σψₖψₖᵀ/μₖ²)P = Pᵀ(L²)⁻¹P. Отсюда двусторонняя оценка.
5. **T₀ явно.** (−L)⁻¹ = h²K, K_ij = min(i, j)(n − max(i, j))/n. (L²)⁻¹ = h⁴K²; T₀₁₁ = h⁴Σⱼ K₁ⱼ² = h⁴Σⱼ((n − j)/n)² = h⁴(n − 1)(2n − 1)/(6n);
   T₀₁₂ = h⁴Σⱼ K₁ⱼK_{j,n−1} = h⁴Σⱼ j(n − j)/n² = h⁴(n² − 1)/(6n); по симметрии T₀₂₂ = T₀₁₁. Собственные значения — T₀₁₁ ± T₀₁₂.
6. **Число обусловленности.** Для X ⪰ 0: λ(A⁻¹ ⊗ X) = {λᵢ(A⁻¹)λⱼ(X)}. Поэтому λ_min(S) ≥ λ_min(A⁻¹)(h⁴/2 + ϱ²λ_min(T₀))/D,
   λ_max(S) ≤ λ_max(A⁻¹)(h⁴/2 + λ_max(T₀))/D; отношение даёт cond(A)·[n/2]/[1/2 + ϱ²(n − 1)(n − 2)/(6n)]. ∎

### ВОК-14. A posteriori оценка ошибки решения и поля

*Исправлено по З-3 (`f4a4cb9`): разведены (а) математическое неравенство и (б) вычислительный сертификат.*

**(а) Математическое неравенство.** Пусть x — точное решение (ЧФ-C1), x̂ — любое приближение, r := b − 𝒦^C x̂ — **точная** невязка,
μ₁ и λ_min(A) — **точные** значения. Тогда

$$\|\hat x-x\|_{\mathcal K^C}\le\frac{\|r\|_2}{D^{1/2}\mu_1\,\lambda_{\min}(A)^{1/2}},\qquad
\|\hat x-x\|_2\le\frac{\|r\|_2}{D\mu_1^2\lambda_{\min}(A)},\qquad
\|\hat U(\hat V-V)^{\mathsf T}\|_a=h_y^{1/2}\|\hat x-x\|_{\mathcal K^C}.$$

**Доказательство.** ‖x̂ − x‖²_{𝒦^C} = rᵀ𝒦^{C,−1}r ≤ ‖r‖²/λ_min(𝒦^C); ‖x̂ − x‖ ≤ ‖𝒦^{C,−1}‖‖r‖; ВОК-11, п. 2. Равенство для поля — NS 4.3
(П-S1). ∎

**(б) Вычислительный сертификат.** Вычисленное значение правой части (а) является **гарантированной** верхней границей, только если
выполнены все три условия:

1. **Невязка:** использована доказанная верхняя оценка r̄ ≥ ‖r‖₂. Например: r вычислена точно (рационально) или в повышенной точности с
   доказанной оценкой её ошибки, а сама норма вычислена с округлением вверх (направленное округление или интервальная арифметика).
2. **μ₁:** использована доказанная положительная нижняя оценка μ̲₁ ≤ μ₁. Например, μ₁ = (4/h_y²)sin²(π/(2n_y)) ≥ 4/b²
   (sin x ≥ 2x/π при 0 ≤ x ≤ π/2), вычисленная с округлением вниз; или интервальное значение sin. Вычисленное в двойной точности
   (4/h²)sin²(·) таким оценкой не является.
3. **λ_min(A):** использована доказанная положительная нижняя оценка λ̲ ≤ λ_min(A). Например, сертифицированная инерция A − λ̲I
   (разложение Холецкого с учётом ошибки) или точное A в рациональной арифметике. После QR λ_min(A) ≈ 1, но не ровно 1, и значение
   «1» без оценки не допускается.

Тогда r̄/(D^{1/2}μ̲₁λ̲^{1/2}) и r̄/(Dμ̲₁²λ̲), вычисленные с округлением вверх, — сертификаты для двух неравенств (а). В строгом пути
переполнение и потеря значимости обрабатываются явно: результат, обратившийся в 0 или ∞ из-за переполнения или потери значимости, —
**не** сертификат (см. 0.4).

**Если хотя бы одно условие не выполнено**, вычисленная величина — **оценка** (МОДЕЛЬ) или UNRESOLVED, а не сертификат.

как на исправленный путь Q1b, в этой базе нет. Ссылка на них — после их появления в `main`; до этого условия 1–3 для B-C выполняются

**Связь с η_N^C.** Знаменатель η_N^C (NS 5) — мажоранта ‖|F ⊗ 𝟏| + |𝒦^C||vec V̂|‖∞ по модулям коэффициентов, поэтому η_N^C — нормированная
обратная ошибка. Вычисленная в двойной точности невязка сама содержит шум ~ u на этом масштабе: η ~ u означает «невязка на уровне
округления», а не малую прямую ошибку. Прямая ошибка ≤ κ∞(𝒦^C)·(обратная ошибка) [СТАНД.] — оценка грубая (κ∞ растёт как ~(2n/π)⁴).
Поэтому для Q3 оценка прямой ошибки — по ВОК-14 с невязкой в повышенной точности (R-HP плана), а не по η в двойной точности.

**Уровень:** Б (оценка) / В (вычисление). **Статус:** (а) — ДОКАЗАНО при точных r, μ₁, λ_min(A); (б) — сертификат только при условиях
1–3, иначе — оценка (МОДЕЛЬ) или UNRESOLVED.

### 3.3. Ошибка восстановления поля

Поле полушага ŵ = fl(ÛV̂ᵀ), V̂ = обратное DST от модальных коэффициентов. Составляющие:

1. ошибка решения x̂ − x — ВОК-14 (a posteriori) или ВОК-13 (модель);
2. обратное DST — c_DST u log₂n·‖x̂‖ (УСЛОВНО, 3.2) — уже входит в ε_mod, если x̂ берётся после обратного DST;

### 4.1. Условия и рамки

- Q3 выполняется **на QA-эталонах** (PL Q1: R-H, R-AC с уточнением, R-HP, D1 = D2), не на решателе Builder (PL §4.7, §7).

- **Основная выборка — по PL §2.2 и BC-2** *(исправлено по З-4)*: N = 1, 2, 3; r ∈ {1, 2, 3, 5} и перестановки 1/2, 1/3, 1/5; пары
  (nₓ, n_y) = (40, 64), (64, 40), (47, 53), (160, 32), (32, 160); цепочка n = 32…512 с ограничениями BC-2 по r (r ≤ 2 — до n_y = 512,
  r = 5 — до 256); оба направления полушага; s = 1…8 на последовательностях эталона; старт 𝒯_N (D-049.3).

  выборки помечаются OBSERVATION и не входят в обоснование кандидатов без отдельного решения владельца.
