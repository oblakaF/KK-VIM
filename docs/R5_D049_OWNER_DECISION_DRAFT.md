> #### D-049.1. Дискретная основа CCCC (Р-1)

> #### D-049.2. Решатель полушага (Р-2)
>
> 1. Основной путь решения полушага CCCC — **B-C**: DST-I на 𝒦₀ и поправка Шермана–Моррисона–Вудбери ранга 2N (NS 5).
> 2. **A-C** (блочно-пятидиагональная система, половина ширины ленты 3N − 1) — только **независимый контроль** той же системы, с
>    итеративным уточнением по исходному оператору с D4. Без уточнения при больших n эталоном не считается.
> 3. Порядок полушага — NS 5.1: диагностика ранга → допустимая нормировка/QR → диагностика обусловленности → решение B-C → невязка
>    исходной системы.
> 4. В журнал на каждом полушаге записываются три величины с разными ролями (NS 5.1; АП-4):
>    - cond(A) **до** QR = cond(R)² — величина, которую ограничивает условие У-R5;
>    - cond(A) **после** QR — контроль QR;
>    - cond(S).
>
>    При N = 1 QR нет, cond(A) = 1, записывается cond(S).
> 5. Пороги cond(A) до QR, cond(S), η_max^C и действие при их превышении устанавливаются отдельным решением после квалификации QA
>    (NS QA-C7; PL §2, §4) и до сравнений. Числа D-048 не переносятся.
>
> #### D-049.3. Старт и ориентация N = 2–3 (Р-3)
>
> 1. Стартовое подпространство — 𝒯_N = span{sin²(iπx/a), i = 1…N}, N = 2, 3; вычислительный базис sin²(iπx/a).
>    - При N = 1 это принятый старт sin²(πx/a) (MATH_SPEC 10, В-32).
>    - Базис sin(πx/a)·sin((2i − 1)πx/a) задаёт то же подпространство (CM ВБC-15).
> 2. Первый полушаг — по y при заданных функциях от x (ориентация x). Перестановка r ↔ 1/r даёт другую последовательность (Q-025).
>    Ориентация записывается в протокол каждого расчёта.
> 3. Доказанные дискретные условия:
>    - независимость набора ⇔ N ≤ ⌊nₓ/2⌋ (CM ВБC-13, п. 4);
>    - точные формулы коэффициентов — при 2N < nₓ (там же, п. 3).
>
>    nₓ ≥ 8N — инженерное предложение, не принятое требование.
> 4. x-оболочка 𝒯_N совпадает с одномерным базисом эталона B. Поэтому сравнения с B ведутся только при M → ∞ по обеим переменным
>    (CM разд. 6; QA-M9).
