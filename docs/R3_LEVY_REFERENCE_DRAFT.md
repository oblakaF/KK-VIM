## 2. Соглашения о координатах и ориентации

### 2.1. Система Леви внутри эталона [ИНЖЕНЕРНЫЙ ВЫБОР по заданию; соглашение сноски 2, с. 136]

Ряд всегда суммируется при **a_L = min(a, b)**, **b_L = max(a, b)**, **r_L = b_L/a_L ∈ [1, 5]**. Если исходная пластина имеет b < a,
координаты переставляются: (x_L, y_L) = (y, x). Поперечная координата Леви η_L = y_L − b_L/2 (система рис. 62); в формулах (139) a, b, x, y
читаются как a_L, b_L, x_L, η_L.

### 2.2. Возврат в исходную систему

- Вход и выход функций поля — **исходные** координаты 0 ≤ x ≤ a, 0 ≤ y ≤ b (начало в углу, MATH_SPEC.md, 1.1).
- Физический прогиб не зависит от ориентации: w_{a×b}(x, y) = w_{b×a}(y, x) (ЧВ-R1). В коде обе пластины приводятся к одной и той же
  системе Леви, поэтому равенство выполняется **побитно** при r ≠ 1 (тест `test_permutation_of_sides_is_exact`).
- Безразмерные величины — с опорной длиной **исходной** стороны a (Р-3): w̄ = wD/(qa⁴). Ряд даёт значение в единицах q·a_L⁴/D;
  перевод: w̄ = (a_L/a)⁴·w̄_L. При b ≥ a множитель равен 1, при b < a — r⁴ (r = b/a). Функция `levy_centre_wbar(r)` возвращает w̄
  в исходной нормировке; `levy_alpha_141(r_L)` — коэффициент α (141) в нормировке L-107 (a_L — меньшая сторона). Их нельзя путать:
  при r = 1/2 α(2) = 0,0101287, а w̄ = 2⁻⁴·α(2) = 6,33041·10⁻⁴.
- Все оценки (разд. 5, 6) сначала получены в единицах q·a_L⁴/D. Функции `levy_field_bounds`, `levy_centre_bounds` возвращают их
  в единицах результата (физический прогиб), т. е. уже умноженными на |q|·a_L⁴/D.

### 2.3. Единая симметричная проверка диапазона — D-038 (принято)

**Научная область** остаётся 0,2 ≤ b/a ≤ 5 (D-036). Для представления входных чисел D-038 устанавливает единый

$$\max(a,b)\le 5(1+4u)\min(a,b),\qquad u=2^{-53}.$$

## 3. Устойчивые формы [ВЫВОД ПРОЕКТА ЧВ-Л1]

### 3.1. Переменная расстояния до края

Пусть t = 2η_L/b_L ∈ [−1, 1]. Тогда 2α_m y/b = α_m t (по (h): 2α_m η/b = mπη/a — тождество, отмеченное в рецензии, разд. 1).
Скобка (139) чётна по t, и она записывается через **s = 1 − |t| ∈ [0, 1]**: s = 0 на краях η_L = ±b_L/2, s = 1 на средней линии.
В коде s = 2·min(y_L, b_L − y_L)/b_L. Разность b_L − y_L при y_L ≥ b_L/2 точна (лемма Стербенца), так что s получается одним округлением
**без вычитания 1 − |t|**, которое у края потеряло бы значащие цифры.

Аналогично sin(mπx_L/a_L) = sin(mπx̃/a_L), x̃ = min(x_L, a_L − x_L), для нечётного m (sin(mπ − θ) = sin θ). Поэтому на краях x_L = 0, a_L
аргумент равен ровно 0, а аргумент синуса не превосходит mπ/2.

### 3.2. Скобка (139) без ch α и sh α больших аргументов

Обозначим z = α s, g = e^{−2α}, E = e^{−α(2−s)}. Используя ch(α|t|)/ch α = (e^{−αs} + E)/(1 + g), |t| sh(α|t|)/ch α = (1 − s)(e^{−αs} − E)/(1 + g),
th α = (1 − g)/(1 + g), α th α = α − 2αg/(1 + g):

1. (α th α + 2)(e^{−αs} + E) − α(1 − s)(e^{−αs} − E) = e^{−αs}[2 + αs − 2αg/(1 + g)] + E[2 + α(1 + th α − s)];
2. 1 + th α = 2/(1 + g); отсюда
   (1 + g)T = 1 + g − e^{−αs}(1 + αs/2) + αg e^{−αs}/(1 + g) − E[1 + α/(1 + g) − αs/2];
3. подставляя g = E·e^{−αs}, g − E = −E(1 − e^{−αs}), αg e^{−αs} − αE = −αE(1 − e^{−2αs}), получаем

$$(1+g)\,T=\underbrace{\bigl[-\mathrm{expm1}(-z)-\tfrac z2e^{-z}\bigr]}_{f(z)\ \ge\ 0}+E\Bigl[\mathrm{expm1}(-z)+\frac{\alpha\,\mathrm{expm1}(-2z)}{1+g}+\frac z2\Bigr].$$

Свойства:
- все показатели ≤ 0 — переполнения нет при любых α (при r_L = 5 и M = 1131 α_max ≈ 8,9·10³);
- при s = 0 (край) обе части равны **ровно** 0 в арифметике с плавающей точкой (expm1(0) = 0) — прогиб на краях η_L = ±b_L/2 ровно 0;
- f(z) = (1 − e^{−z}) − (z/2)e^{−z}, и e^z − 1 ≥ z ⇒ (1 − e^{−z}) ≥ z e^{−z}: вычитаемое не больше половины уменьшаемого, поэтому
  относительная обусловленность разности ≤ 3 — вычитание доброкачественное **доказуемо**;
- во второй скобке отрицательная часть N = (1 − e^{−z}) + α(1 − e^{−2z})/(1 + g) ≥ z·th α ≥ 0,917z (при α ≥ π/2) больше 1,83·(z/2),
  поэтому и там обусловленность ≤ 3,4 (доказуемо по монотонности (1 − e^{−2z})/z);
- обусловленность суммы f + E[…] доказательства не имеет. [НАБЛЮДЕНИЕ] Она ≤ 2,84 на сетке α ∈ [π/2, 700], s ∈ [10⁻³⁰⁰, 1]
  и при 2·10⁵ случайных точках.

Сверка с 80- и 360-значной десятичной арифметикой по исходной форме (139) [НАБЛЮДЕНИЕ, scratch]: относительная ошибка устойчивой формы
≤ 3,92u при всех проверенных α ∈ [π/2, 700] и s ∈ [10⁻³⁰⁰, 1]. Исходная форма с cosh/sinh имеет **абсолютную** ошибку ≈ 2u(α + 2)
и у края (T ≈ αs/2) теряет около lg(1/s) знаков; при α ≳ 710 она переполняется.

### 3.3. Коэффициент P_m

P_m = (α th α + 2)/(2 ch α) = (α th α + 2)·e^{−α}/(1 + g), th α = −expm1(−2α)/(1 + g). Без ch α, без переполнения.

### 5.2. Хвост поля по (139), включая окрестности краёв [ВЫВОД ПРОЕКТА ЧВ-Л3, ЧВ-Л4]

**ЧВ-Л3 (лемма).** Для любого α > 0 и t ∈ [−1, 1]: 0 ≤ T(t) ≤ 1 − P, T(±1) = 0, T убывает по |t|.
Доказательство. T = 1 − K, K(t) = [(α th α + 2) ch(αt) − αt sh(αt)]/(2 ch α); K чётна, K(0) = P > 0,
K(1) = (α th α + 2 − α th α)/2 = 1. При t ∈ (0, 1]: K′(t) = α·h(t)/(2 ch α), h(t) = (α th α + 1) sh(αt) − αt ch(αt), h(0) = 0,
h′(t) = α² u(t), u(t) = th α·ch(αt) − t sh(αt), u(1) = th α ch α − sh α = 0. Далее u′(t) = sh(αt)·β(t), β(t) = α th α − 1 − αt·cth(αt);
функция x cth x строго возрастает при x > 0, поэтому β строго убывает, и β(1) = α th α − 1 − α cth α < 0. Значит, u′ меняет знак не более
одного раза (с + на −) и на конечном участке u убывает к u(1) = 0. При этом u(0) = th α > 0. Если u′ первоначально положительна, то u возрастает от положительного u(0), а затем убывает к u(1) = 0; если u′ отрицательна с начала, то убывает от u(0) > 0 к нулю. В обоих случаях u > 0 на [0, 1), h′ > 0, h > 0 на (0, 1], K′ > 0 на (0, 1].
Следовательно, K строго возрастает от P до 1, что и требовалось. ∎

**ЧВ-Л4 (равномерная граница).** По лемме и |sin| ≤ 1, в каждой точке **замкнутой** пластины:

$$|w-w_M|\le\frac{4}{\pi^5}\sum_{m\ge M+2,\ \text{нечёт}}m^{-5}\le\frac{4}{\pi^5}\cdot\frac{1}{8M^4}=\frac{1{,}6339\cdot10^{-3}}{M^4}\quad(qa_L^4/D),$$

так как m⁻⁵ ≤ ½∫_{m−2}^{m}x⁻⁵dx и Σ ≤ ½∫_M^∞x⁻⁵dx = 1/(8M⁴). Граница **не зависит от r_L** и от точки. Функция `levy_field_tail_bound(M)`.
Уточнение множителем (1 − P_{M+2}) возможно, но не используется. Сходимость (139) равномерная и абсолютная (M-признак Вейерштрасса).

синус-ряда w по x на линии η). На любой внутренней линии T_m → 1 при m → ∞, поэтому коэффициенты убывают как m⁻⁵. Так ведёт себя синус-ряд
полоски (c), чья 4-я производная после нечётного продолжения разрывна. [НАБЛЮДЕНИЕ, scratch; в тесте `test_field_convergence_within_uniform_bound` — та же проверка на сетке 81×81 с M_ref = 2263]:
max по сетке 401×401 |w_M − w_{4001}| / граница = 0,03; 0,24; 0,58; 0,74; 0,81; 0,86; 0,88 при M = 1, 3, 9, 19, 39, 79, 159 — одинаково
при r_L = 1 и 5. Граница достигается с точностью до множителя ≈ 0,9, а максимум лежит **у краёв x_L = 0, a_L** (x ≈ 0,4/M), а не у краёв η_L.

**Окрестность краёв η_L = ±b_L/2.** Здесь поправочные члены компенсируют полосковую часть: T_m(s) ≈ αs/2 → 0 при s → 0, и каждый член
(139) мал. Оценка ЧВ-Л4 действует и здесь (равномерна), но **не** даёт экспоненциального убывания. [НАБЛЮДЕНИЕ]: при r_L = 2, x = a/4
хвост (M = 159) равен 8,8·10⁻¹⁴ при y = 0,1 и 2,1·10⁻¹⁴ при y = 0,001, т. е. одного порядка с внутренними точками.

### 5.3. Хвост (j)

(j) — это (139) в центре. Её хвост ограничен той же ЧВ-Л4: (4/π⁵)/(8M⁴). [НАБЛЮДЕНИЕ]: фактически он знакопеременен и ≈ (4/π⁵)(M+2)⁻⁵.

### 5.4. Почему экспоненциальная оценка центра не переносится на поле

(140) экспоненциальна потому, что полоска 5/384 вычтена **в замкнутом виде**, а остаётся ряд с P_m ~ e^{−α_m}. В (139) полоска представлена
своим синус-рядом (m⁻⁵). Если и для поля выделить полоску по (c), то поправка K_m(η) = 1 − T_m ≤ min(1, (α_m + 2)e^{−α_m s})
(из ch(α|t|)/ch α ≤ 2e^{−αs}). Хвост станет экспоненциальным при **фиксированном** s > 0, но у краёв (s → 0) снова ~ Σ m⁻⁵, и укороченный
ряд перестанет обращаться в 0 на краях η_L = ±b_L/2: остаток равен хвосту полоски. Указанное равномерное ограничение хвоста имеет порядок O(M⁻⁴). Предположение, что на всём поле никакая из этих форм не даёт лучшего **равномерного порядка**, — асимптотический довод с численными наблюдениями, а **не доказанная нижняя оценка** (Н-3 Аудитора); для корректности ЧВ-Л4 это не требуется. Тест при M ≥ 9 фиксирует фактическую погрешность поля > 100·граница центра.

### 5.5. Выбор числа гармоник [ИНЖЕНЕРНЫЙ ВЫБОР, зафиксирован до любых сравнений]

  погрешность. Относительно центра это ≤ 2,5·10⁻¹³ (w̄_c,L ≥ 4,06·10⁻³ при r_L ∈ [1, 5]). M = 2559 Навье **не используется**. Уровень

## 6. Ошибки округления — **модель, не строгая граница**

### 6.1. Поле (139)

Модель первого порядка (`levy_field_bounds(...).rounding_model`), коэффициенты в единицах u = 2⁻⁵³:
- член m⁻⁵T_m sin: скобка 4 (наблюдаемый максимум 3,92); α_m = m(πr_L/2) — 3 округления при |∂lnT/∂lnα| ≤ 2,1 [НАБЛЮДЕНИЕ]: 7;
  s — 1 округление при |∂lnT/∂ln s| ≤ 1: 1; m⁻⁵ (int/int, корректное округление): 1; два произведения: 2; библиотечный sin: 1 — **итого 16u**
  относительно члена;
- аргумент mθ (θ = πx̃/a_L, относительная ошибка ≤ 4u) даёт абсолютную добавку ≤ 4mθu ≤ 2πmu;
- **суммирование** K членов в любом порядке (numpy, BLAS-произведение для сетки): ≤ (K − 1)u·Σ|членов| — стандартная граница рекурсивного
  суммирования; здесь она доминирует;
- масштаб 4q a_L⁴/(π⁵D): 6u; общий запас ×2.

Итог: R(M) = 2u·(4/π⁵)·[(16 + 6 + K − 1)·Σ_{m≤M} m⁻⁵ + 2π Σ_{m≤M} m⁻⁴] в единицах q a_L⁴/D: M = 1 — 8,2·10⁻¹⁷; M = 159 — 3,1·10⁻¹⁶;
M = 1131 — **1,7·10⁻¹⁵**; M = 2559 — 3,8·10⁻¹⁵.

Почему это модель: точность библиотечных exp, expm1, sin (обычно < 1 ulp) не гарантирована стандартом; коэффициенты чувствительности
и максимум ошибки скобки получены численно; ошибки второго порядка не учтены. Строгой границы округления нет — **UNRESOLVED** (как и для
R_M Навье, D-037, п. 3).

### 6.2. Центр (140), (j)

Суммы берутся `math.fsum` (точное суммирование с одним округлением). Модель: ошибка P_m ≈ (15 + 3α_m)u·P_m относительно; для (140) —
плюс 2·(5/384)u; запас ×2. При r_L = 1 и M = 17 модель — 4,5·10⁻¹⁷ (≈ 1·10⁻¹⁴ относительно). Вычитание 5/384 − поправка обусловлено ≤ 3,2
(при r_L = 1; рецензия, разд. 6).

### 6.3. Наблюдения согласованности [НАБЛЮДЕНИЕ]

- (139) в центре при том же M, что (j), — расхождение ≤ модели округления;
- (j) − (140): −1,7·10⁻¹⁸ … 0 при всех r_L из контрольного набора (M_j = 1131);
- сетка (матричное произведение) против поточечного суммирования: ≤ 7·10⁻¹⁸ (r_L = 2).
