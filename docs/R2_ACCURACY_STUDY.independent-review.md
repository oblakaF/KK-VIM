## 4. Проверка методов исследования

### 4.1. Прогиб

- **Формулы метрик** (`delta_centre`, `error_inf`, `error_l2` с двумерными весами трапеций, `max_abs_difference`) соответствуют
  NUMERICAL_SPEC, разд. 17; четверти берутся только в узлах (n кратно 4). Подтверждено собственным расчётом (3.3).
- **Четверти** (n = 320, остановка): (¼, ¼) −6,875·10⁻⁴; (¼, ½) и (½, ¼) +8,065·10⁻⁴ — совпадают. Картина знаков разности
  (центр и диагонали занижены, средние линии завышены) подтверждена и для непрерывной SA − Навье на плотной сетке.
- **Положение максимума.** При s ≥ 2 максимум |w − w_N| лежит у углов на диагоналях. Между узлами (плотная сетка 401 × 401, SA − Навье,
  s = 7) он находится при x/a = y/a ≈ 0,1325 (и симметрично); E_∞ на плотной сетке = 1,45098·10⁻³ против 1,45074·10⁻³ в узлах n = 320.
  Наблюдение «≈ 0,13» корректно. Причинных утверждений (кручение, угловые реакции, моменты) отчёт не делает — это правильно: без
  отдельного анализа они не обоснованы.
- **По полушагам:** s = 1 завышает центр (+1,157 %, максимум на средней линии x/a ≈ 0,153); s = 2 уменьшает отличие примерно на порядок;
  при s ≥ 3 изменения ≪ отличия от Навье.

### 4.2. Сеточная сходимость

- E_disc = max по общим узлам |w_n − w_2n| / max|w_n| — нормирование на грубую сетку пары; оно отличается от нормирования на тонкую сетку
  на ~10⁻⁵ относительно и на выводы не влияет (ответ на вопрос QA 3: корректно).
- Наблюдаемый порядок по SA: 1,9988…2,0006 для всех состояний и пар (80, 160), (160, 320), (320, 640) — в окне [1,9; 2,1].
- Ричардсон применён только при p в окне и для одинакового s на обеих сетках (s = 7 при остановке на всех сетках). Экстраполяция
  согласуется с SA: 1,5·10⁻¹⁰ в центре на паре (160, 320), 9,6·10⁻¹² на (320, 640). Отчёт называет её «экстраполированным значением при
  фиксированном s / при остановке по критерию», а не пределом при h → 0 или s → ∞ (разд. 1, 6) — соответствует разд. 12 и D-032, п. 7.

### 4.3. Разделение источников ошибок

- Разложение w_h − w_N = (w_h − w_SA) + (w_SA − w_N) — алгебраическое тождество в узлах; его научный смысл определяется точностью w_SA.
- n = 320, остановка: дискретная составляющая **1,078·10⁻⁶**, непрерывная **1,451·10⁻³**, отношение **≈ 1346** (в отчёте 1,35·10³);
  n = 640: 2,69·10⁻⁷ и 1,451·10⁻³. Для s = 1…4 значения также подтверждены.
- **Достаточность бюджета SA.** Строгий бюджет поля SA при s = 7 — 5,6·10⁻¹¹ (s = 4 — 8,9·10⁻¹³) относительно max|w| — в 2·10⁴ раз меньше
  дискретной составляющей на n = 320 и в 5·10³ раз — на n = 640. Фактическая ошибка Reference по моей 40-значной сверке ≤ 6,4·10⁻¹⁶.
  Разделение строгое. Исключение — сравнение Ричардсона с SA на паре (320, 640): 9,6·10⁻¹² меньше формального бюджета при s = 7; в отчёт эта
  пара не выносится (Н-10).
- Отчёт (разд. 8) прямо говорит, что непрерывная составляющая включает ограничение N = 1 **и** незавершённость последовательности при
  конечном s, и не называет её чистой ошибкой предела N = 1. В выводах разд. 10 это соблюдено не полностью — Б-1.

## 6. Проверка энергетических результатов

### 6.1. Две формы энергии

- Π_s = −½q·I_X·I_Y и Π_full = ½D(C_X A_Y + 2B_X B_Y + A_X C_Y) − q·I_X·I_Y. Вывод: для SSSS интеграл определителя гессиана равен нулю
  (MATH_SPEC 2.2), поэтому ½D∬(Δw)² = ½D(C_X A_Y + 2B_X B_Y + A_X C_Y), так как ∫XX″ = −B_X.
- Совпадение форм — следствие равенства a(w_s, w_s) = ℓ(w_s) для решения Галёркина. Для **усечённого** ряда оно точное: синусы
  диагонализируют одномерную форму полушага при постоянных коэффициентах, поэтому усечённый ряд — точное решение Галёркина на
  X ⊗ span{sin λ_m y, m ≤ M} при вычисленных G. Проверено: 40 знаков — |Π_full − Π_s| ≤ 2·10⁻⁴²; float (CSV) — ≤ 2,5·10⁻¹⁶ отн.
- По тому же аргументу (двойные синусы — собственные функции бигармонического оператора при SSSS) Π_M = −½q·I_M — точная энергия
  усечённого поля Навье, и Π(ω₀) ≤ Π_M ≤ Π(ω₀) + ½(J − J_M). Оговорку отчёта («равенство Π_M непрерывной энергии усечённого поля Reviewer не
  принимал», разд. 10) эта рецензия снимает (Н-8).

### 6.2. Тождество В-24 для усечённых рядов

Π_{s−1} − Π_s = ½‖w_s − w_{s−1}‖²_{H_T} выполняется **точно** (в точной арифметике) при одновременном выполнении условий:
1. каждый полушаг — точная проекция на своё (усечённое) подпространство: синусный ряд при G, вычисленных по **тем же** усечённым
   коэффициентам заданного множителя (так и сделано);
2. **вложенность усечений по каждой переменной:** w_{s−1} ∈ M_s^{trunc}, т. е. множитель полушага s − 2 лежит в span{sin λ_m, m ≤ M_s}:
   M_{s−2} ≤ M_s (для s = 2 — X⁰ = sin ∈ span). В Reference M = 2669, затем 2673 — условие выполнено;
3. функционал, нагрузка и граничные условия одни и те же на всех полушагах.

При нарушении п. 2 тождество не выполняется: появляется слагаемое −ℓ от хвоста старого множителя вне нового подпространства
(контрпример 3.2: −7,1·10⁻¹¹ и −1,0·10⁻⁶). Тождество подтверждает структуру проекционной минимизации усечённой последовательности,
но **не** говорит о близости к бесконечному непрерывному решению и не доказывает сходимость по s (MATH_SPEC 7.4).

### 6.3. Энергетическая ошибка

- **Подтверждено собственным расчётом** (точная Π(ω₀), 3.1): e_SA = 4,87335·10⁻³ (s = 1); 1,519974·10⁻⁴ (s = 2); 1,519159·10⁻⁴ (s = 3);
  1,5191589524·10⁻⁴ (s = 4…10; от s = 4 к s = 7 e меняется на 2,6·10⁻¹² относительно, далее — меньше 10⁻¹⁹). Значения QA (4,8734·10⁻³; 1,51997·10⁻⁴; 1,51916·10⁻⁴;
  1,51916·10⁻⁴ ± 2,1·10⁻¹⁰) совпадают. Неопределённость QA определяется границей усечения Π_N; она односторонняя (Π_N ≥ Π(ω₀)).
- **Интерпретация.** Так как Π(ω₀) = −½‖ω₀‖²_{H_T} и Π(w) − Π(ω₀) = ½‖w − ω₀‖²_{H_T} (В-23), √e = ‖w_s − ω₀‖_{H_T}/‖ω₀‖_{H_T} =
  **1,2325 %** при s ≥ 3 (6,98 % при s = 1). Это корректно для непрерывной SA-последовательности, не для сеточной w_h (e_h смешивает Π_h и
  Π(ω₀), разд. 7.2 отчёта это оговаривает).
- **Ограничения интерпретации.** Для SSSS ‖w‖²_{H_T} = D∬(Δw)² = D∬(w_xx² + 2w_xy² + w_yy²), т. е. 1,23 % — среднеквадратичная по пластине
  относительная ошибка всего тензора кривизн, включая кручение. Это не оценка изгибающих моментов или напряжений в точке; моменты как эталон
  не квалифицированы (D-034). Прогиб в точке энергетическая норма прямо не оценивает: фактическая ошибка прогиба (E_∞ = 0,145 %) на порядок
  меньше 1,23 %.
