## 2. А. Корректность точного эталона

### 2.1. Путь γ̂ в рабочем решателе

Подтверждено по коду:

| Шаг | Место |
|---|---|
| ρ̂ = F ⊗ 𝟏 − 𝒦 vec(V̂) | `coupled.py:309-311` |
| действие 𝒦: `D * (l2V @ A.T − 2.0 * (lV @ B.T) + V @ C.T)`, где `l2V` — `fourth_difference` = L(L·) с нулевыми концами | `coupled.py:306`, `grid.py:90-92` |
| γ̂ = `solve_grid.h * float(np.sum(rho * (companion_prev − received)))` | `coupled_energy.py` (`pair_energy`) |
| τ = \|γ̂\| + 10(R_prev + R + R_f), затем E1, E2, правило Q ≥ 10τ | там же |

Это та же схема, что в CCCC Q3: невязка почти точного решения в double и её скалярное произведение на гладкую разность. Форма τ, E1, E2 и разрешимости совпадает с D-048.1 и R4_NUMERICAL_SPEC 6.3, п. 7.

### 2.2. Шесть пунктов задания

1. **Перенос binary64 без округления.** `dyadic` использует `as_integer_ratio` и общий двоичный порядок, то есть перевод точен по построению. Выборочная проверка обратимости — 3 элемента на столбец. Шаги h берутся как binary64-значения реализации, `Fraction(grid.h)`. **PASS.**
2. **Сборка оператора, невязки и γ_HP** (`exact_coefficients`, `exact_gamma`) соответствует определениям:
   - A = h⟨U, U⟩; B = h Σ(D⁺U)² по n интервалам с концами (= `forward_difference`); C = h Σ(LU)² с нулевыми концами; F = q h ΣU;
   - L² = d2(d2(·)) с нулевыми концами (= `fourth_difference`); знак −2B; множитель D;
   - γ_HP = h_s Σ ρᵢᵀdᵢ, где h_s — шаг решаемой x-сетки (R4_NUMERICAL_SPEC 6.2, п. 3).

   **PASS.**
3. **Согласованность с R4.**
   - s = 2 — X-полушаг: заданный набор Y после QR, w^(s−1) = prev_X Yᵀ, w^(s) = X Yᵀ. На месте проверено `prev_Y` = `Y` побитово.
   - SSSS: нулевые граничные значения и нулевые концы для L.
   - Нормировка a = 1, b = r, D = q = 1; параметры `run_coupled` как в B5/К-3.
   - Энергия реализации (`energy.discrete_energy`): a_h = D hₓh_y Σ_внутр (Lₓw + L_yw)², l_h = q hₓh_y Σ_внутр w. С ней согласованы и разделимая форма QA, и двумерная сборка рецензента (разд. 3).

   **PASS.**
4. **Тождество не тавтологично.** γ_HP считается по невязке (`exact_gamma`). ΔP̃ и Q̃ считаются разделимой формой энергии точных произведений (`exact_energy`), без A, B, C, F и 𝒦. Ни одна сторона не определяется через другую. Общими остаются вспомогательные `d2` и `dot` — QA это раскрывает (разд. 2.3). Рецензент закрывает этот остаток полностью раздельным путём (разд. 3). **PASS.**
5. **Разделение ошибок при сравнении с γ_double.**
   - Часть коэффициентов: γ с binary64-коэффициентами, вычисленный точно, минус γ_HP.
   - Часть вычисления 𝒦V̂ в double: доля по медиане 0,9989.
   - Ошибка решения полушага — само γ_HP ≠ 0; в тождество она входит точно.
   - Сравнение «заменено только γ» корректно: `rest = FACTOR_10 * (R_prev + R + R_f)` в том же порядке, что в `pair_energy`. Проверка `|γ̂| + rest = τ` выполнена побитово 72/72.

   **PASS.**
6. **Область точности.** «Ошибка эталона = 0» относится к конечной дискретной задаче с зафиксированными binary64-массивами и шагами реализации, а не к непрерывному решению и не к задаче с шагом a/n в точной арифметике. QA это оговаривает (разд. 2.3). **PASS.**
