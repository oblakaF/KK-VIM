## 2. Единая постановка трёх задач

**[ВЫВОД ПРОЕКТА N23-1] Сведение к взвешенной низкоранговой чередующейся проекции.** Пусть 𝒲 — пространство матриц коэффициентов
V = (V_mn) со скалярным произведением

$$\langle V,W\rangle:=c_0\sum_{m,n}(\alpha_m+\beta_n)^2V_{mn}W_{mn},\qquad \alpha_m,\beta_n>0,$$

с целью Ω ∈ 𝒲 и функционалом Π(V) = ½‖V − Ω‖² − ½‖Ω‖². Для подпространства U коэффициентов по x и подпространства V по y положим
𝓜(U) := {W: столбцы W ∈ U} и 𝓝(V) := {W: строки W ∈ V}. Y-полушаг: W_s = P_{𝓜(col W_{s−1})}Ω; X-полушаг: W_s = P_{𝓝(row W_{s−1})}Ω.
Старт: первый Y-полушаг использует заданное подпространство U₀ = span{e_{m_1}, …, e_{m_N}}, m_i = 2i − 1, т. е. W_1 = P_{𝓜(U₀)}Ω.

## 3. Q-020: сохранение ранга при s ≥ 2

### 3.1. Первые два полушага в замкнутой форме

**[ВЫВОД ПРОЕКТА N23-2] Ошибка второго полушага.** Пусть L := {1, 3, …, 2N − 1}. В любой из задач (а)–(в) при нечётном синусном старте:
1. W_1 состоит из строк m ∈ L матрицы Ω, остальные строки нулевые;
2. W_2 строится построчно: строка m — Λ_m-ортогональная проекция строки m матрицы Ω на V₁ := span{строки m_j матрицы Ω, j = 1…N},
   где Λ_m := diag_n(c₀(α_m + β_n)²);
3. справедливо равенство

$$\mathrm{err}(N,2)^2=\|W_2-\Omega\|^2=c_0\sum_{m\notin L}\ \min_{t\in\mathbb R^N}\ \sum_n(\alpha_m+\beta_n)^2\Bigl(\Omega_{mn}-\sum_{j=1}^{N}t_j\Omega_{m_jn}\Bigr)^2,$$

   и **любой** набор t = t^{(m)} даёт верхнюю оценку.

*Доказательство.*
1. Вес диагонален в базисе e_m ⊗ e_n, поэтому проекция на 𝓜(span{e_m: m ∈ L}) сохраняет строки m ∈ L и обнуляет остальные. Это п. 1;
   непрерывный случай — ВБ-23, п. 3(а); дискретный — ЧВ4-9.
2. rank W_1 = N: для (а) — ВБ-22, п. 5; для (в) — ЧВ4-9 при n_x, n_y ≥ 2N. Значит, row W_1 = V₁ и dim V₁ = N.
3. 𝓝(V₁) распадается по строкам: строка m ∈ V₁ независимо от других, а вес блочно-диагонален по m. Поэтому проекция — построчная (п. 2,
   Q22-3 для X-полушага).
4. Для m ∈ L строка лежит в V₁, остаток нулевой. Для чётных m строка Ω нулевая.
5. Минимум не больше значения при любом t. ∎

### 3.2. Нижняя граница расстояния до полей ранга ≤ k

**[ВЫВОД ПРОЕКТА N23-3] Три хвоста Мирского.** Для любой задачи (а)–(в) и любого k ≥ 0

$$d_k^2:=\inf_{\operatorname{rank}W\le k}\|W-\Omega\|^2\ \ge\ c_0\bigl[\tau_k(A\Omega)^2+2\,\tau_k(A^{1/2}\Omega B^{1/2})^2+\tau_k(\Omega B)^2\bigr],\qquad
\tau_k(X)^2:=\sum_{j>k}\sigma_j(X)^2,$$

где A = diag(α_m), B = diag(β_n). Правую часть можно ещё уменьшить, заменив каждую матрицу её подматрицей (любые строки и столбцы).

*Доказательство.*
1. **Точное разложение.** (α + β)² = α² + 2αβ + β² даёт ‖X‖² = c₀[‖AX‖²_F + 2‖A^{1/2}XB^{1/2}‖²_F + ‖XB‖²_F]. Для (а) это ‖v_xx‖² + 2‖v_xy‖² + ‖v_yy‖²
   в L₂ (при SSSS ∫(Δv)² = ∫(v_xx² + 2v_xy² + v_yy²)). Каждое слагаемое конечно, так как не превосходит ‖X‖²/c₀; матрицы — операторы
   Гильберта–Шмидта.
2. **Ранг.** При rank W ≤ k ранги AW, A^{1/2}WB^{1/2} и WB тоже не больше k.
3. **Мирский через Вейля.** Для операторов Гильберта–Шмидта X, Y с rank Y ≤ k: σ_{k+i}(X) ≤ σ_i(X − Y) + σ_{k+1}(Y) = σ_i(X − Y) [СТАНД.]. Отсюда
   ‖X − Y‖²_F ≥ τ_k(X)².
4. **Нижняя граница суммы.** Инфимум суммы не меньше суммы инфимумов.
5. **Подматрицы.** σ_j(PXQ) ≤ σ_j(X) для координатных проекторов P, Q [СТАНД.]; поэтому τ_k подматрицы не больше τ_k матрицы. ∎

ВБ-19 даёт d_k ≥ D^{1/2}λ₁₁δ_k (L₂-расстояние, Eckart–Young там не используется). N23-3 работает непосредственно в энергетической норме,
поэтому оценка точнее. Обе оценки — нижние.

## 4. Q-022: перенос ошибки усечения по полушагам

### 4.1. Уточнённый угол оболочек

**[ВЫВОД ПРОЕКТА N23-5] Уточнение (⋆) Q22-4.** При условиях Q22-4 (rank w ≤ N, rank w′ = N) для всех n

$$\sin\Theta_{\Lambda_n}(U,U')\ \le\ \frac{\|w-w'\|_{H_T}}{D^{1/2}\,\lambda_{11}\,\sigma_N^{L_2}(w')},\qquad \lambda_{11}=\kappa_1^2+\nu_1^2 ,\qquad(\star')$$

и то же для X-полушага. По сравнению с (⋆) знаменатель увеличен в λ₁₁/ν₁² = 1 + (b/a)² раз для Y-полушага и в λ₁₁/κ₁² = 1 + (a/b)² раз для
X-полушага.

*Доказательство.* Пусть X := C − C′, ‖X‖²_E := Σλ_mk²X_mk², Λ_n^{1/2} = diag_m(κ_m² + ν_n²).
1. **Числитель.** ‖Λ_n^{1/2}X‖²_F = Σ_{m,k}(κ_m² + ν_n²)²X_mk². Для всех m, k ≥ 1:
   - если ν_n ≥ ν_k, то функция x ↦ (x + ν_n²)/(x + ν_k²) убывает при x ≥ 0, и
     (κ_m² + ν_n²)/(κ_m² + ν_k²) ≤ (κ₁² + ν_n²)/(κ₁² + ν_k²) ≤ (κ₁² + ν_n²)/λ₁₁;
   - если ν_n < ν_k, то отношение меньше 1 ≤ (κ₁² + ν_n²)/λ₁₁.

   Отсюда ‖Λ_n^{1/2}X‖_F ≤ ((κ₁² + ν_n²)/λ₁₁)·‖X‖_E.
2. **Знаменатель.** Λ_n^{1/2} ⪰ (κ₁² + ν_n²)I, поэтому σ_N(Λ_n^{1/2}C′) ≥ (κ₁² + ν_n²)σ_N(C′) [СТАНД.].
3. **Ведин** (элементарная форма Q22-4, п. 2): sinΘ_{Λ_n} ≤ ‖Λ_n^{1/2}X‖₂/σ_N(Λ_n^{1/2}C′) ≤ ‖X‖_E/(λ₁₁σ_N(C′)). Множитель κ₁² + ν_n² сокращается, оценка
   равномерна по n.
4. **Физические нормы** — по Q22, разд. 0. X-полушаг — симметрично: блоки по m, Λ^x_m = diag_n(κ_m² + ν_n²). ∎

Стресс-тест (scratch, вне git; случайные поля ранга N = 1…3, r ∈ {1/5, 1/2, 1, 2, 5}, 299 случаев с оценкой < 1): наибольшее отношение
«точный sup_n угла / (⋆′)» — 0,922. Нарушений нет. Это OBSERVATION.

### 4.2. Оценка переноса без обрыва

**[ВЫВОД ПРОЕКТА N23-6] Q22-5 с (⋆′) на сертифицированных ячейках.** Пусть (r, N) сертифицирована N23-4 для задач (а) и (б). Определим

$$\hat E'_1:=T,\qquad \hat E'_s:=\Bigl[\bigl(T+\hat\vartheta'_sR_s\bigr)^2+\bigl(\hat E'_{s-1}+\hat\vartheta'_s\|d'_s\|\bigr)^2\Bigr]^{1/2},\qquad
\hat\vartheta'_s:=\min\Bigl(1,\frac{\hat E'_{s-1}}{D^{1/2}\lambda_{11}\sigma_N^{L_2}(w'_{s-1})}\Bigr)$$

без условия обрыва (обозначения Q22-5). Тогда E_s ≤ Ê′_s при всех s ≥ 1.

*Доказательство.* Шаги 2–4 доказательства Q22-5 — без изменений.
- Шаг 1 (ранг точного поля через Вейля) больше не нужен: rank w_{s−1} = N при всех s по N23-4 (а). Поэтому предпосылка (б) шага 4 выполнена
  на всех полушагах.
- Предпосылка (в): rank w′_{s−1} = N по N23-4 (б).
- Шаг 5: (⋆′) вместо (⋆), и sinΘ ≤ 1.
- Монотонность F_s и индукция — как в Q22-5: ϑ′_s(e) не убывает по e. ∎

### 4.3. Монотонная верхняя оценка — без накопления

**[ВЫВОД ПРОЕКТА N23-7] Неусечённая ошибка сверху.** На сертифицированных ячейках для всех s ≥ s₁ ≥ 1

$$\mathrm{err}_{\mathrm{abs}}(N,s)\ \le\ U_s:=\min_{1\le s_1\le s}\Bigl[\bigl(\mathrm{err}_M(s_1)^2+T^2\bigr)^{1/2}+\hat E'_{s_1}\Bigr],\qquad
\mathrm{err}_M(s):=\|w'_s-\omega_M\|_{H_T}.$$

U_s не возрастает по s. Для s₁ = 2 то же верно и без Ê′: err_abs(N, s) ≤ err(N, 2)^{up} — полностью сертифицированная граница N23-2.

*Доказательство.*
1. err_abs(N, s) ≤ err_abs(N, s₁) по ВБ-17 для неусечённой последовательности.
2. err_abs(N, s₁) ≤ ‖w′_{s₁} − ω₀‖ + E_{s₁} — неравенство треугольника.
3. ‖w′_{s₁} − ω₀‖² = ‖w′_{s₁} − ω_M‖² + ‖τ‖², так как τ ⊥ S_M ⊗ S_M ∋ w′_{s₁} − ω_M (Q22-5, шаг 3).
4. ‖τ‖ ≤ T, E_{s₁} ≤ Ê′_{s₁} (N23-6). ∎

**Почему здесь нет накопления.** Оценка Ê′ растёт по s (Q22-6, п. 3). Но в U_s можно взять **ранний** s₁, где Ê′ ещё мал, и перенести его
на все поздние s монотонностью ВБ-17. Фактической ошибки переноса E_s это не оценивает. Оценивается сама энергетическая ошибка
неусечённого метода, и только сверху.

### 4.4. Двусторонняя оценка при всех s ≥ 2

$$d_N\ \le\ \mathrm{err}_{\mathrm{abs}}(N,s)\ \le\ \mathrm{err}(N,2)^{\mathrm{up}},\qquad

## 5. Q-025: сходимость при фиксированном N

### 5.1. Теорема для конечномерных задач

**[ВЫВОД ПРОЕКТА N23-9] Сходимость полей.** Пусть задача (б) (любое нечётное M ≥ 23) или (в) сертифицирована N23-4. Предполагается [СТАНД.-Л].
Тогда последовательность полей W_s сходится, а предел W_* обладает свойствами:
- rank W_* = N, dist(W_*, 𝓡_{N−1}) ≥ (1 − μ)(D^{low}_{N−1})^{1/2};
- W_* — критическая точка Π на многообразии 𝓜_N матриц ранга ровно N;
- W_* — неподвижная точка обоих полушагов: W_* = P_{𝓜(col W_*)}Ω = P_{𝓝(row W_*)}Ω;
- Σ_s‖W_s − W_{s−1}‖ < ∞ (конечная длина).

*Доказательство.* Пространство конечномерно. Обозначим ω_min, ω_max наименьший и наибольший вес c₀(α + β)², κ := (ω_max/ω_min)^{1/2},
e₂ := err(N, 2), η := (1 − μ)(D^{low}_{N−1})^{1/2}.

1. **(H1) Убыль.** f(W_{s−1}) − f(W_s) = ½‖W_s − W_{s−1}‖² — ВБ-17, ЧВ4-14 и разд. 2.
2. **Компакт.** 𝒮 := {W: rank W ≤ N, ‖W − Ω‖ ≤ e₂, dist(W, 𝓡_{N−1}) ≥ η} замкнуто и ограничено, значит компактно. Все его точки имеют ранг ровно N.
   По N23-4, п. 2 и ВБ-17 W_s ∈ 𝒮 при s ≥ 2. Для W ∈ 𝒮: η ≤ dist(W, 𝓡_{N−1}) ≤ ω_max^{1/2}·dist_F(W, 𝓡_{N−1}) = ω_max^{1/2}σ_N(W), т. е.
   σ_N(W) ≥ σ_* := η/ω_max^{1/2}.
3. **(H2) Градиент через шаг.** Пусть s ≥ 3 нечётно (Y-полушаг; чётное — симметрично), G := W_s − Ω, U := col W_s = col W_{s−1}, V_s := row W_s.
   Градиент Π на 𝓜_N — grad f(W_s) = P_T G, где T = 𝓜(U) + 𝓝(V_s) — касательное пространство.
   - (а) Для Z ∈ T положим B := (I − P^E_U)Z, где P^E_U — евклидов проектор столбцов. Тогда B ∈ 𝓝(V_s): для Z = X₁Yᵀ + XY₁ᵀ имеем
     B = (I − P_U)X₁Yᵀ. Также Z − B ∈ 𝓜(U) и ‖B‖ ≤ κ‖Z‖.
   - (б) G ⊥ 𝓜(U) — условие проекции. Поэтому ⟨G, Z⟩ = ⟨P_{𝓝(V_s)}G, B⟩ и ‖grad f(W_s)‖ ≤ κ‖P_{𝓝(V_s)}G‖.
   - (в) W_{s−1} — результат X-полушага, row W_{s−1} =: V_{s−1}, поэтому P_{𝓝(V_{s−1})}(W_{s−1} − Ω) = 0. Отсюда
     P_{𝓝(V_s)}G = P_{𝓝(V_s)}(W_s − W_{s−1}) + (P_{𝓝(V_s)} − P_{𝓝(V_{s−1})})(W_{s−1} − Ω).
   - (г) P_{𝓝(V)} действует построчно: строка m переходит в свою Λ_m-ортогональную проекцию на V. Отсюда
     ‖P_{𝓝(V)} − P_{𝓝(V′)}‖ = max_m sinΘ_E(Λ_m^{1/2}V, Λ_m^{1/2}V′) ≤ κ·sinΘ_E(V, V′). Здесь использовано sinΘ(AV, AV′) ≤ κ(A)sinΘ(V, V′):
     для единичного x′ = Av′ ∈ AV′ верно ‖v′‖ ≤ ‖A⁻¹‖ и dist(x′, AV) ≤ ‖A‖·dist(v′, V) ≤ ‖A‖sinΘ‖v′‖.
   - (д) По элементарной форме Ведина: sinΘ_E(V_s, V_{s−1}) ≤ ‖W_s − W_{s−1}‖₂/σ_N(W_{s−1}) ≤ ‖W_s − W_{s−1}‖/(ω_min^{1/2}σ_*).

   Итого ‖grad f(W_s)‖ ≤ b‖W_s − W_{s−1}‖, b := κ(1 + κ²e₂/η) < ∞.
4. **[СТАНД.-Л].** 𝓜_N — вещественно-аналитическое вложенное подмногообразие, f|𝓜_N аналитична. Для любой W* ∈ 𝓜_N найдутся
   окрестность 𝒰, C > 0 и θ ∈ [½, 1), такие что |f(W) − f(W*)|^θ ≤ C‖grad f(W)‖ на 𝒰 ∩ 𝓜_N. Через аналитическую карту это сводится
   к неравенству в ℝ^d; нормы градиента в карте и римановой метрике эквивалентны на компактной окрестности.
5. **Конечная длина.**
   - Пусть W* — предельная точка (W_s); она существует по компактности 𝒮 и лежит в 𝒮 ⊂ 𝓜_N. f_s := f(W_s) ↓ f* = f(W*).
   - Если f_s = f* при некотором s, то по (H1) все последующие шаги нулевые.
   - Иначе положим φ(t) := Ct^{1−θ}/(1 − θ). При W_s ∈ 𝒰, по вогнутости φ, (H1) и (H2):
     φ(f_s − f*) − φ(f_{s+1} − f*) ≥ C(f_s − f*)^{−θ}·½‖ΔW_{s+1}‖² ≥ ‖ΔW_{s+1}‖²/(2b‖ΔW_s‖).
   - Отсюда 2‖ΔW_{s+1}‖ ≤ ‖ΔW_s‖ + 2b[φ(f_s − f*) − φ(f_{s+1} − f*)] (2√(xy) ≤ x + y).
   - Суммирование от s₀ даёт Σ_{s>s₀}‖ΔW_s‖ ≤ ‖ΔW_{s₀}‖ + 2bφ(f_{s₀} − f*).
   - **Удержание в окрестности.** Пусть B(W*, ε) ∩ 𝓜_N ⊂ 𝒰. Выберем s₀ из подпоследовательности, сходящейся к W*, так, чтобы
     ‖W_{s₀} − W*‖ + ‖ΔW_{s₀}‖ + 2bφ(f_{s₀} − f*) < ε; это возможно, так как ‖ΔW_s‖ → 0 (ВБ-18, п. 2) и f_s → f*. По индукции все W_s при s ≥ s₀
     остаются в B(W*, ε).
   - Значит, (W_s) фундаментальна и W_s → W*.
6. **Предел.** ‖grad f(W_s)‖ ≤ b‖ΔW_s‖ → 0, а градиент непрерывен на 𝓜_N, поэтому grad f(W*) = 0. Так как T_{W*} ⊇ 𝓜(col W*), остаток W* − Ω
   ортогонален 𝓜(col W*), и W* = P_{𝓜(col W*)}Ω. Аналогично для 𝓝. ∎

**Статус:** PROVEN при допущении [СТАНД.-Л]; без него — UNRESOLVED. Скорость сходимости не устанавливается: показатель θ неизвестен.
Наблюдаемое геометрическое убывание приращений (группа B, разд. 4) остаётся OBSERVATION.

### 5.2. Что следует без [СТАНД.-Л]

- **Стабилизация конечного поля в точной арифметике — PROVEN без допущений.** Σ‖ΔW‖² < ∞ (ВБ-18, п. 2), в конечной размерности все нормы
  эквивалентны. Поэтому любой положительный порог изменения поля (например, ε^∞ ≤ tol_∞, ε^E ≤ tol_E D-048.3) рано или поздно выполняется.
  Это **не** означает близости к пределу: выполнение критерия при конечном s расстояние до W* не ограничивает.
- PROVISIONAL_FIELD_STABILIZED вычисленной последовательности (D-048.4) остаётся наблюдением о вычисленных полях: δ_f — NOT_QUALIFIED.

### 5.3. Неусечённая непрерывная задача — UNRESOLVED

Точная причина: N23-9 существенно конечномерна.
- ω_max = ∞ (вес (κ_m² + ν_n²)² не ограничен), поэтому κ = ∞ и константа b из (H2) не существует.
- Неравенство Лоясевича в бесконечной размерности в общем случае неверно. Понадобилось бы неравенство типа Лоясевича–Саймона для
  функционала на многообразии полей ранга N в H_T (фредгольмовость гессиана) — не исследовалось.
- Известно только: ограниченность, Σ‖Δw‖² < ∞, слабо сходящиеся подпоследовательности (ВБ-18), равномерная граница ранга (N23-4) и
  включение N23-8.

Единственность предела и независимость от старта (r ↔ 1/r) — UNRESOLVED для всех трёх задач. N23-9 не исключает разных критических
точек для разных стартов.

## 10. Воспроизведение

Скрипты `scripts/r4_n23/` (README там же) не импортируют `kkvim` и `kkvim_reference` и **не зависят от рабочего решателя**:

Окружение: Python 3.14.8, NumPy 2.5.4, mpmath 1.4.1 (только временно, `uv run --with mpmath`), Windows 10.
