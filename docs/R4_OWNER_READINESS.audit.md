### 5.3. Энергетический сертификат

- **d_{N−1}** = min_{Z ∈ 𝓡_{N−1}} ‖Z − ω_h‖_{a_h} — расстояние в энергетической норме дискретной задачи до множества полей ранга ≤ N − 1
  (рецензия, разд. 3.1). **D^low_{N−1}** ≤ d²_{N−1} — по N23-3; в CSV `D_low_N1_lo` > 0 во всех 132 ячейках; `dlow_sqrt_lo`² ≤ `D_low_N1_lo`
  во всех строках (направленная печать согласована).
- **Верхняя граница** ‖W̃ − ω_h‖_{a_h} (`energy_err_up`) — тождество Галёркина, шары arb, все моды. Норма и задача на обеих сторонах одни
  (b = float(r), точные h = a/n).
- **Положительность запасов.** Во всех 2702 строках s ≥ 2: `energy_rank_certified` = True, `energy_err_up` < `dlow_sqrt_lo`, запас > 0;
  запас, пересчитанный из напечатанных концов, не больше напечатанного (печать вниз).
- **Направления.** `energy_err_up` — вверх, `dlow_sqrt_lo` и `energy_margin` — вниз (рецензия, М-2; аудит — согласованность выше).
- **Без универсальных c_d и δ_f.** Формула сертификата не использует ни c_d, ни δ_f, ни W*. Но для применения **внутри** решателя нужна

  Это ограничение отражено верно; новой квалификации решателю отчёты не приписывают.
