## 3. Энергетический вывод (разд. 6.3)

### 3.1. Ошибка формирования поля (п. 3)

|e_ij| ≤ γ_N·S_ij, S = |U||V|ᵀ, γ_N = Nu/(1 − Nu) — стандартная оценка скалярного произведения длины N. Она верна при **любом** порядке суммирования
(дерево глубины ≤ N − 1 плюс умножение; блочные и многопоточные редукции BLAS; FMA — не хуже; расширенные аккумуляторы — не хуже).
**Необходимые предпосылки** (в тексте не все названы — НА-5): модель IEEE fl(a ∘ b) = (a ∘ b)(1 + δ), |δ| ≤ u, округление к ближайшему; нет переполнения;
нет потери значимости (при субнормальных числах добавляется абсолютный член ≲ N·2⁻¹⁰⁷⁴; при режимах FTZ/DAZ модель не гарантирована); классический
алгоритм произведения без быстрых схем типа Штрассена/Винограда, для которых поэлементная оценка неверна; Nu < 1. Для полей R4 (|w| ~ 10⁻³…10⁻²)
поправки потери значимости пренебрежимы, но предпосылки нужно записать.

### 3.2. κ_W и κ_rep (п. 3; табл. 5.7) — НА-1

κ_W := ‖S‖_h/‖ŵ‖_h (знаменатель — **округлённое** поле), κ_rep := ‖U_w‖‖V_w‖/‖W_w‖ (знаменатель — **точное** произведение сохранённых факторов W = w̃).
Доказательство черновика (‖S‖_F ≤ ‖U‖_F‖V‖_F ≤ N‖U‖₂‖V‖₂, ‖W‖_F ≥ ‖W‖₂) даёт **κ̃_W := ‖S‖_h/‖w̃‖_h ≤ N·κ_rep — строго**, но не κ_W ≤ N·κ_rep: при
‖ŵ‖_h < ‖w̃‖_h неравенство может нарушаться на величину O(γ_N·Nκ_rep). **В записанном виде утверждение строго неверно.**

**Строгая формула (дополнение задания) — подтверждена.** ‖ŵ‖_h ≥ ‖w̃‖_h − ‖e‖_h и ‖e‖_h ≤ γ_N‖S‖_h (поэлементно ⇒ по норме). Отсюда
κ_W ≤ κ̃_W/(1 − γ_Nκ̃_W). Функция x/(1 − γx) возрастает при γx < 1, поэтому при **γ_N·N·κ_rep < 1**

$$\kappa_W\le\frac{N\,\kappa_{\mathrm{rep}}}{1-\gamma_N N\kappa_{\mathrm{rep}}} .$$

Формула устраняет расхождение знаменателей: оба отношения сводятся к w̃. При γ_N·N·κ_rep ≥ 1 оценка неприменима и не объявляется применимой.
Уточнение: при ортонормированном (в весе) факторе ‖U_w‖_F = √N и ‖W_w‖_F = ‖V_w‖_F, поэтому κ̃_W ≤ √N, т. е. κ_W ≤ √N/(1 − γ_N√N) — в √N раз лучше,
чем «N(1 + O(u))» в тексте. [SCRATCH] На заместителе (N = 2, 3; QR заданного набора) κ_W = 1,0007–1,0008.
**Минимальная правка (НА-1):** заменить «Строго κ_W ≤ N·κ_rep» на «строго κ̃_W := ‖S‖_h/‖w̃‖_h ≤ Nκ_rep и κ_W ≤ Nκ_rep/(1 − γ_NNκ_rep) при γ_NNκ_rep < 1;
при ортонормированном факторе κ_W ≤ √N/(1 − γ_N√N)». То же — в п. 8 разд. 6.3 и в табл. 5.7. Модель Literature этим не меняется.
Дефект появился в исправлениях (новый текст).
