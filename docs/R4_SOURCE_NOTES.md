## 1. Назначение документа и область R4

Документ устанавливает по первоисточникам авторский алгоритм КК-МВИ для N-го приближения

$$w_N(x,y)=\sum_{i=1}^{N}X_i(x)\,Y_i(y),$$

чтобы подготовить часть B `MATH_SPEC.md` (D-029): связанную систему полушага (D-004, Q-007) и требования к начальному набору (Q-020).
Цель — основание **одного общего алгоритма для произвольного N ≥ 2**, а не отдельных алгоритмов для N = 2, 3, …

Область R4 (ROADMAP): линейная пластина Кирхгофа–Лява, SSSS, q = const; N = 2–3 — квалификация, N = 4–6 — исследование.

## 4. Авторская процедура решения для N ≥ 2

### 4.1. Что установлено по тексту [АВТОР]

1. **N-е приближение.** w_N = Σ_{i=1}^{N} X_iY_i (Т-1, Т-7, Т-18); N — число членов (Definition 2), что совпадает с D-003.
2. **Что задано в начале полушага.** Набор N функций одной переменной (Т-3: «A certain system of N functions of one of the variables is given»;
   Т-19: «задавая первоначальную систему из N функций … по любой из переменных»). Начало «по любой из переменных» — как при N = 1.
3. **Что определяется полушагом.** Набор N функций другой переменной: v₁¹, …, v_N¹ (Т-3), ψ₁¹, …, ψ_N¹ (Т-19); затем u₁², …, u_N² и т. д.
4. **Как образуется система.** «a system of N functions v₁¹(y), …, v_N¹(y) is determined from the first N equations of the system (3)» (Т-3) — N уравнений
   ∫_X(Tω_N − g)u_i dx = 0, i = 1, …, N; P82: одно операторное уравнение (3) с проекцией P₁ на подпространство M₁ᴺ всех сумм Σφ_i⁰ψ_i, где **каждая** ψ_i
   пробегает всё пространство (Т-19); P80: «N неизвестных функций ω_j(x₁) находят из следующей системы уравнений (10)», l = 1, …, N (Т-28).
5. **Определение шага.** «The process of computing one system of functions from another given system is called one VIM step» (Т-4): один шаг — вычисление
   **всей системы** N функций, а не одной функции.
6. **Переход Y → X.** Найденные функции «are substituted into the remaining N equations of the system (3), a new set of functions of the variable x is determined»
   (Т-3); P82: «Затем определяется новая система функций — φ₁²(x), …, φ_N²(x)» из (4) с проекцией на M₂ᴺ (Т-20).
7. **Следующая итерация.** Новый набор становится заданным: «then this set is used to obtain new functions of y, v₁³(y), …» (Т-3); P82: P₃, M₃ᴺ «структура которого
   подобна M₁ᴺ и M₂ᴺ, и т. д.» (Т-20).
8. **Завершение.** Процесс «обрывается» на k-м шаге: ω_Nᵏ = Σu_i^{k−1}v_iᵏ (Т-5); w_N^{n,k+1} = Σφᵏψ_i^{k+1} [sic] (Т-20). **Критерия завершения итераций авторы
   не дают** — [НЕ УСТАНОВЛЕНО]. В экспериментах P82 последовательности w₁^{n,k} приводятся до совпадения четырёх знаков (с. 80), но правило остановки не сформулировано.

### 4.2. Одновременно или последовательно — ответ по тексту

**Ответ.** [ВЫВОД ПРОЕКТА; подтверждён рецензией, разд. 4] **Все N функций полушага определяются одновременно (совместно) — как решение одной
связанной системы, или, что то же, одной проекции на M_sᴺ.** Слово «одновременно» авторы не печатают (Н-9); это прямое следствие напечатанных
формулировок и проекционной постановки.

**[АВТОР] Напечатанные основания:**

- P81, с. 367 (Т-3): «a system of N functions … is determined from the first N equations of the system (3)» — система функций из системы уравнений;
- P81, с. 367 (Т-4): шаг — вычисление «one system of functions from another given system»;
- P81, с. 369 (Т-12): ω_N¹ = P_Nω₀ — ортогональная проекция на M_N¹ = {Σu_i⁰(x)v_i(y)}, где «for every i the function v_i(y) runs through the entire space»;
- P82, с. 78–79, (3), (4) (Т-19, Т-20): одно уравнение с проекцией P₁ (P₂) на M₁ᴺ (M₂ᴺ), в котором все ψ_i (все φ_i) варьируются;
- P82, с. 79 (Т-22): w_N^{n,1} — минимум по **всему** M₁ᴺ;
- P80, с. 2188 (Т-28, Т-29): N неизвестных ω_j находятся из системы (10), эквивалентной проекции на M_N.

**[ВЫВОД ПРОЕКТА] Почему это следствие:** (а) каждое уравнение системы содержит все неизвестные одного направления (ВР4-1); (б) результат полушага
определён как проекция на всё M_sᴺ; (в) последовательное определение членов (каждая функция из своего уравнения при уже найденных остальных)
в общем случае всей системе не удовлетворяет (рецензия, разд. 4).

**Последовательного определения по отдельным членам (поочерёдное вычисление u_i, v_i при фиксированных остальных; последовательное добавление членов /
поправок) в проверенных текстах P80, P81, P82 и P81-S, с. 54–57, нет.** Других вариантов процедуры не найдено.

[ВЫВОД ПРОЕКТА ВР4-1] **Почему систему нельзя прочитать как N независимых задач.** Подставим в первые N уравнений (3) ω_N = Σ_j u_j v_j с заданными u_j = u_j^{s−1}
(они же — веса u_i в этих уравнениях, Т-3):

$$\sum_{j=1}^{N}\int_X u_i(x)\,T\bigl(u_j(x)\,v_j(y)\bigr)\,dx=\int_X g\,u_i(x)\,dx,\qquad i=1,\dots,N.$$

Уравнение с номером i содержит **все** неизвестные v_j; индексы i и j связаны через интегралы по заданной переменной от произведений u_i на T(u_j ·).
Каждое уравнение можно решить относительно «своей» v_i независимо от остальных, только если перекрёстные члены (i ≠ j) обращаются в нуль; в общем
случае это не так. Шаги (уточнено по Н-4): подстановка (2) в (3); линейность T; сначала применяется T = DΔ²: T(u_jv_j) = D(u_j⁗v_j + 2u_j″v_j″ + u_jv_j⁗);
после этого функции y и их производные выносятся из интегралов по x, а связь неизвестных сохраняется через матрицы коэффициентов — для SSSS
a_ij = ∫u_iu_j, β_ij = ∫u_i′u_j′, γ_ij = ∫u_i″u_j″ (рецензия, разд. 4). Система выше не меняется. Полный вид для T = DΔ² и пространства SSSS — часть B
(не выполняется здесь).

[ВЫВОД ПРОЕКТА ВР4-2] **Связь системы (3) с проекцией при N ≥ 2** (уточнено по Н-5).
- [АВТОР P81, с. 367] Для N = 1 эквивалентность «(6) ⇔ первое уравнение (4) при u⁰v* ∈ D(T)» напечатана.
- [АВТОР P81, с. 368–369] Для первого шага при любом N напечатано утверждение без выкладки: «It can be shown by arguments analogous to those in Theorem 1
  that every ω_N¹ is a projection of element ω₀ into the subspace M_N¹» (Т-12). [АВТОР P80, с. 2188] Для s = 1 эквивалентность системы (10) и проекции
  на M_N напечатана — для нелинейной задачи в W̊₂ᵐ (Т-29).
- [ВЫВОД ПРОЕКТА] Эквивалентность интегральной системы (3) и проекционной формы при N ≥ 2 в P81 не выписана. Условие проекции
  [Σu_jv_j* − ω₀, u_iṽ]_{H_T} = 0 ∀ṽ, i = 1, …, N, при Σu_jv_j* ∈ D(T) сводится к ∫_X(Tω_N − g)u_i dx = 0 — первым N уравнениям (3) (проверено рецензией, ВР4-2).
- Условия, которые предстоит строго оформить в части B (SSSS, s ≥ 2; аналог MATH_SPEC.md, 4.3, 6.4 для N = 1): принадлежность Σu_iv_i* к D(T),
  тестовые функции u_iṽ (i = 1, …, N, ṽ ∈ V) из H_T, замкнутость M_sᴺ (ВР4-5).

**Согласие с D-004.** [ВЫВОД] Связанное решение всего семейства на каждом полушаге (D-004) совпадает с напечатанной процедурой P81/P82; D-004 при этом остаётся

## 6. Неоднозначность представления GL(N)

### 6.1. Что есть у авторов

[АВТОР] Неоднозначность представления, нормировка, ортогонализация и линейная независимость координатных функций в P80, P81, P82 (и P81-S, с. 54–57)
**не рассматриваются**. Единственное утверждение о единственности — P81, Теорема 2: «for sufficiently large N the VIM yields a unique approximate solution ω_N»
(Т-11); что именно единственно (поле или функции u_i, v_i) и почему нужно «sufficiently large N», не пояснено; доказательство отослано к теореме 16.2 [3],
которой в библиотеке нет — [НЕ УСТАНОВЛЕНО]. В P80 в аналогичной теореме сказано «хотя бы одно решение» (Т-29), т. е. для нелинейной задачи единственность
не утверждается. Существование минимума в P82 — через слабую полунепрерывность нормы (Т-22); единственность там не обсуждается.

### 6.2. Наблюдение проекта

[ВЫВОД ПРОЕКТА ВР4-4] **Подпространство полушага зависит только от линейной оболочки заданного набора.** Пусть U = (u₁, …, u_N) — заданный набор, V — пространство
функций другой переменной, M(U) = {Σ_i u_i v_i: v_i ∈ V}. Для любой матрицы A ∈ ℝ^{N×N}

$$\sum_{i}(UA)_i\,v_i=\sum_{j}u_j\Bigl(\sum_i A_{ji}v_i\Bigr),$$

поэтому M(UA) ⊆ M(U); при обратимой A отображение (v_i) ↦ (Σ_iA_{ji}v_i) — биекция Vᴺ → Vᴺ, и M(UA) = M(U). Следовательно, M(U) = span(U) ⊗ V (алгебраическое
тензорное произведение конечномерной оболочки на V) и проекция поля на M(U) от выбора базиса оболочки не зависит. Если w = Σu_iv_i = Σ(UA)_iṽ_i, то при
линейно независимых u_i ṽ = A⁻¹v; новый набор переходит в набор той же линейной оболочки. Отсюда по индукции: **при сохранении размерности N оболочек на всех
полушагах последовательность полей {w⁽ˢ⁾} зависит только от span(X₁⁰, …, X_N⁰)**. Это обобщение В-13 (N = 1, A = c) и аналог преобразования
X → XA, Y → YA^{−T} для строк координатных функций. Утверждение — проекта, а не авторов.

[ВЫВОД ПРОЕКТА ВР4-5] **Единственность и обусловленность полушага.** Поле — проекция на замкнутое подпространство — единственно при любом наборе
(если M(U) замкнуто). Функции v_i единственны тогда и только тогда, когда отображение (v_i) ↦ Σu_iv_i инъективно, т. е. когда u₁, …, u_N линейно независимы.
Для SSSS (тождество части A, MATH_SPEC.md, 2.2) a(w, w) = D‖Δw‖² ≥ D‖∂²w/∂y²‖², и при w = Σu_iṽ_i

$$\Bigl\|\sum_i u_i\,\tilde v_i''\Bigr\|^2_{L_2(\Omega)}=\sum_{i,j}G_{ij}\int\tilde v_i''\tilde v_j''\,dy\ \ge\ \lambda_{\min}(G)\sum_i\|\tilde v_i''\|^2,\qquad G_{ij}=\int u_iu_j\,dx.$$

Предварительный вывод (полностью — часть B; уточнено по Н-6): при λ_min(G) > 0, т. е. при невырожденной матрице Грама заданного набора, оценка выше
даёт **нижнюю оценку** постоянной коэрцитивности системы полушага на Vᴺ: не меньше Dλ_min(G)·c, где c > 0 от набора не зависит (неравенство Виртингера
по y, как в части A). λ_min(G) зависит от масштаба выбранных функций набора (при U → cU умножается на c²); полная обусловленность системы полушага
одной λ_min(G) не определяется. Из той же оценки (ограниченность снизу отображения Vᴺ → H_T) при невырожденном наборе следует замкнутость M_sᴺ в H_T;
строгий вывод оформляется в части B `MATH_SPEC.md`. Численные критерии обусловленности здесь не вводятся. **Риск:** если функции набора становятся почти линейно зависимыми, λ_min(G) → 0, система полушага
плохо обусловлена; отдельные Y_i могут быть велики и взаимно компенсироваться при нормальном поле. Правило И-4 (N = 1) на этот случай автоматически не переносится.

### 6.3. Вырождение представления в допустимом наборе

[ВЫВОД ПРОЕКТА ВР4-6] **Пример (SSSS, q = const > 0, N = 2).** X₁⁰ = sin(πx/a), X₂⁰ = sin(2πx/a): обе функции из V_a, удовлетворяют X = X″ = 0, линейно независимы
и являются компонентами базисной системы sin(mπx/a)sin(nπy/b) — т. е. удовлетворяют аналогу (для SSSS) предпосылок п. 3 P82 «по переменной x» (сам п. 3 P82 сформулирован для W̊₂², защемление). Для T = DΔ² синусы — собственные
функции: (X_j⁰)⁗ = (jπ/a)⁴X_j⁰, (X_j⁰)″ = −(jπ/a)²X_j⁰, ∫₀ᵃX_i⁰X_j⁰dx = (a/2)δ_ij. Поэтому перекрёстные члены ВР4-1 исчезают и система распадается:

$$D\frac a2\Bigl[Y_j''''-2\Bigl(\frac{j\pi}{a}\Bigr)^2Y_j''+\Bigl(\frac{j\pi}{a}\Bigr)^4Y_j\Bigr]=q\int_0^aX_j^0dx,\qquad Y_j=Y_j''=0\ \text{при}\ y=0,b.$$

∫₀ᵃ sin(2πx/a)dx = 0, и по однозначной разрешимости одномерной задачи (часть A, разд. 6) Y₂¹ ≡ 0. На s = 2 набор (Y₁¹, 0) линейно зависим: матрица Грама вырождена,
X₂² не определяется, а напечатанная процедура (Т-3, Т-20) не говорит, какую функцию взять; от этого выбора зависит M₃ᴺ. Поле w⁽²⁾ (проекция) определено однозначно, но
фактически это приближение N = 1. Вывод: **допустимость каждой функции и предпосылки теорем авторов не исключают вырождения набора на последующих полушагах**;
условие невырожденности при N ≥ 2 должно формулироваться для набора в целом и проверяться на каждом полушаге — предмет части B. Конкретного правила здесь не предлагается.
(Н-7) Невырожденность определяется линейной оболочкой всего набора (ВР4-4): покомпонентное условие ∫X_i⁰ ≠ 0 для каждой функции (аналог условия 3
MATH_SPEC.md, 4.6) сохранения ранга набора после полушага не гарантирует — например, набор (sin(πx/a), sin(πx/a) + sin(2πx/a)) имеет ту же оболочку
и даёт тот же вырожденный Y-набор (рецензия, разд. 5). Подробный разбор — часть B.

[ИНЖЕНЕРНЫЙ ВЫБОР — не принят] Возможные направления на будущее (без выбора): диагностика λ_min(G) или числа обусловленности матрицы Грама на каждом полушаге;
правило нормировки/ортогонализации набора между полушагами — допустимо по ВР4-4, если оно сохраняет линейную оболочку. Выбор — только в будущей численной
спецификации после части B.

### 11.3. Ответы на вопросы задачи по поздним работам

1. **Системы при N = 2, 3, произвольном N.** Произвольное N — только в общем виде (L-104 (93); L-005 (73); L-006 (24), (27)); явная система N = 2 —

   (L-005 (70), L-006 (29)) и, в L-098, предварительное понижение порядка. Последовательного определения по членам нет.
3. **Ортогонализация, нормировка, контроль независимости, обусловленность** — в работах школы **не обнаружены**. Критерии остановки поздних работ

5. **Численные эксперименты с несколькими членами** — VIM 2 только для нелинейных задач (L-109, L-006, L-089, L-111, L-113); для линейной SSSS — нет.

6. **Отмечаемые преимущества и ограничения.** Преимущества: не нужна заранее система аппроксимирующих функций, начальные функции могут не удовлетворять

   KVM 1 в L-110 (не объяснено).
7. **Прямые ссылки на исследования, посвящённые N ≥ 2** — в проверенных работах не найдены; «VIM in the second approximation [37]» в L-109 ссылается
   на L-104, где N ≥ 2 не исследуется.
