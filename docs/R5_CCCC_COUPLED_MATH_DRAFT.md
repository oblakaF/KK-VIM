## 2. Непрерывная связанная постановка

### ВБC-1. Тензорная лемма для W̊₂²

**Утверждение.** Для u, ũ ∈ V_a и v, ṽ ∈ V_b:

1. u ⊗ v ∈ W̊₂²(Ω) = H_T (CCCC);
2. справедлива формула

$$[u\otimes v,\tilde u\otimes\tilde v]_{H_T}=D\bigl[(u'',\tilde u'')(v,\tilde v)+2(u',\tilde u')(v',\tilde v')+(u,\tilde u)(v'',\tilde v'')\bigr];\qquad(\text{Ф-1C})$$

3. (q, u ⊗ v) = q(∫u)(∫v) при q = const;
4. ‖u ⊗ v‖_{H_T} ≤ 2D^{1/2}‖u‖_{W₂²}‖v‖_{W₂²}.

**Условия.** CCCC: H_T = W̊₂²(Ω) с [w, z]_{H_T} = D(Δw, Δz) [ПРИНЯТО MATH_SPEC 10, В-31: интеграл определителя гессиана исчезает на W̊₂²(Ω),
Π(w) = ½D‖Δw‖² − (q, w)].

**Доказательство.**

1. **Гладкие множители.** Для u, ũ ∈ C_c^∞(0, a) и v, ṽ ∈ C_c^∞(0, b) произведения лежат в C_c^∞(Ω). Тогда Δ(uv) = u″v + uv″, и

   ∬Δ(uv)Δ(ũṽ) = (u″, ũ″)(v, ṽ) + (u″, ũ)(v, ṽ″) + (u, ũ″)(v″, ṽ) + (u, ũ)(v″, ṽ″).

   Интегрирование по частям (функции и производные равны нулю на концах) даёт (u″, ũ) = −(u′, ũ′), (v, ṽ″) = −(v′, ṽ′) и т. д.;
   два средних слагаемых равны (u′, ũ′)(v′, ṽ′). Это (Ф-1C).
2. **Предел.**
   - Пусть uₙ → u в W₂²(0, a), uₙ ∈ C_c^∞ (определение V_a), и vₙ → v аналогично.
   - По (Ф-1C) для гладких множителей ‖f ⊗ g‖²_{H_T} = D[‖f″‖²‖g‖² + 2‖f′‖²‖g′‖² + ‖f‖²‖g″‖²] ≤ 4D‖f‖²_{W₂²}‖g‖²_{W₂²}.
   - Отсюда (uₙ ⊗ vₙ) фундаментальна в H_T: оценка разности — как в шаге 2 ВБ-1.
   - Предел z ∈ W̊₂²(Ω), так как пространство замкнуто. Кроме того, uₙvₙ → uv в L₂(Ω), значит z = uv.
3. **Продолжение формулы.** Обе части (Ф-1C) непрерывны по W₂²-нормам множителей.
4. **Пп. 3, 4** — непосредственно. ∎

**Отличие от ВБ-1.** Синусные ряды и D(T_SS) не используются: достаточно определения W̊₂² как замыкания C_c^∞.

**Для реализации.** Коэффициенты полушага — интегралы одномерных функций (ВБC-3).

**Ограничения.** Только q = const в п. 3. Для q ∈ L₂ — как в Б.3, «нагрузка общего вида».

### ВБC-2. Низкоранговое представление и энергия

**Утверждение.**

1. Поле N-го приближения w_N = U ⊗ Y = Σᵢ₌₁ᴺ uᵢ(x)vᵢ(y), uᵢ ∈ V_a, vᵢ ∈ V_b [АВТОР P81, с. 366, (2); с. 367, Definition 2].
2. w_N ∈ H_T (ВБC-1).
3. Π(w_N) = ½‖w_N‖²_{H_T} − (q, w_N), где

$$\|U\otimes Y\|^2_{H_T}=D\sum_{i,j}\bigl[(u_i'',u_j'')(Y_i,Y_j)+2(u_i',u_j')(Y_i',Y_j')+(u_i,u_j)(Y_i'',Y_j'')\bigr].$$

**Доказательство** — билинейность и ВБC-1.

**Ограничение.** Множество 𝓡_N полей ранга ≤ N — не подпространство (как в Б.2).

### ВБC-3. Подпространства полушагов и слабые формы

**Утверждение.** Для заданного набора U ∈ V_aᴺ подпространство Y-полушага — M(U) := {U ⊗ Ỹ : Ỹ ∈ V_bᴺ}.

Коэффициенты (интегралы по x):

- aˣᵢⱼ = (Xᵢ, Xⱼ);
- βˣᵢⱼ = (Xᵢ′, Xⱼ′);
- γˣᵢⱼ = (Xᵢ″, Xⱼ″);
- Fˣᵢ = q∫Xᵢ.

**Слабая форма:** найти Y ∈ V_bᴺ такой, что для всех Ỹ ∈ V_bᴺ

$$b_U(Y,\tilde Y):=D\!\int_0^b\!\bigl[\tilde Y''^{\mathsf T}a^XY''+2\tilde Y'^{\mathsf T}\beta^XY'+\tilde Y^{\mathsf T}\gamma^XY\bigr]dy=\int_0^b\tilde Y^{\mathsf T}F^X\,dy=:\ell_U(\tilde Y).\qquad(\text{Ф-2C})$$

X-полушаг: M(Y) := {X̃ ⊗ Y : X̃ ∈ V_aᴺ}, коэффициенты aʸ, βʸ, γʸ, Fʸ по y, форма c_Y на V_aᴺ (Ф-3C).

**Доказательство.**

- По (Ф-1C) [U ⊗ Y, U ⊗ Ỹ]_{H_T} = b_U(Y, Ỹ) и (q, U ⊗ Ỹ) = ℓ_U(Ỹ).
- Функционал полушага 𝒥_U(Ỹ) = Π(U ⊗ Ỹ) = ½b_U(Ỹ, Ỹ) − ℓ_U(Ỹ).
- Форма b_U симметрична (матрицы Грама симметричны). Поэтому (Ф-2C) — условие стационарности 𝒥_U.
- Вывод X-полушага — тем же путём с ролями x ↔ y, а не переносом (ср. ВБ-4).

**Отличие от SSSS.** Только пространство: V_b = W̊₂²(0, b) вместо W₂² ∩ W̊₂¹. Формулы коэффициентов те же.

**Для реализации.** Одна связанная система на N функций, все функции полушага определяются совместно (D-044).

### ВБC-4. Сильные формы и граничные условия

**Утверждение.** Пусть U линейно независим (aˣ невырождена, ВБC-7), q = const, Y решает (Ф-2C). Тогда:

1. Y ∈ C^∞[0, b]ᴺ и

$$D\bigl[a^XY''''-2\beta^XY''+\gamma^XY\bigr]=F^X,\quad 0<y<b;\qquad Y_j(0)=Y_j(b)=0,\quad Y_j'(0)=Y_j'(b)=0 .\qquad(\text{Ф-4C})$$

2. **Оба** краевых условия главные: они входят в V_b. **Естественных условий нет.**
3. Обратно, Y ∈ W₂⁴(0, b)ᴺ с (Ф-4C) и Y = Y′ = 0 на концах решает (Ф-2C).

Для X-полушага — то же: X = X′ = 0 при x = 0, a (Ф-5C).

**Доказательство.**

- **п. 1, внутренняя регулярность.** Пробные функции eᵢφ, φ ∈ C_c^∞(0, b) ⊂ V_b. Повторяется рассуждение ВБ-5, п. 1: aˣY⁗ = F/D + 2βˣY″ − γˣY в 𝒟′,
  затем бутстрэп W₂ᵏ. Используются только внутренние пробные функции и обратимость aˣ.
- **Краевые условия.** Входят в определение V_b. Совпадает с одномерными условиями В-33 [ПРИНЯТО MATH_SPEC 10].
- **п. 3.** Для Y ∈ W₂⁴ и Ỹ ∈ V_bᴺ:

  b_U(Y, Ỹ) − ℓ_U(Ỹ) = ∫Ỹᵀ(D[aˣY⁗ − 2βˣY″ + γˣY] − Fˣ) + D[Ỹ′ᵀaˣY″ − Ỹᵀ(aˣY‴ − 2βˣY′)]₀ᵇ.

  Внеинтегральные члены равны нулю, так как Ỹ = Ỹ′ = 0 на концах. ∎

**Отличие от SSSS (ВБ-5, ВБ-7).** В SSSS граничный член D[Ỹ′ᵀaY″] не исчезал и давал естественное условие aˣY″ = 0. В CCCC он
исчезает из-за Ỹ′ = 0, и **векторной связи следов через aˣ нет**.

**Для реализации.** В дискретной схеме не нужно реализовывать естественное условие. Оба условия задаются пространством сеточных
функций: w = 0 в узлах, ∂w/∂n = 0 через фиктивное отражение (ВБC-12).

### ВБC-5. Форма P81

**Утверждение.** Если Xᵢ ∈ C⁴[0, a] и Xᵢ = Xᵢ′ = 0 на концах, то:

- ∫XᵢXⱼ″ = −βˣᵢⱼ;
- ∫XᵢXⱼ⁗ = [XᵢXⱼ‴ − Xᵢ′Xⱼ″]₀ᵃ + γˣᵢⱼ = γˣᵢⱼ.

Следовательно, (Ф-4C) — первые N уравнений (3) P81: ∫₀ᵃXᵢ(Tw − q)dx = 0 [АВТОР P81, с. 367, (3)].

**Доказательство** — интегрирование по частям: оба внеинтегральных члена обнуляются условием Xᵢ = Xᵢ′ = 0. ∎

**Ограничение.** Только для гладких наборов (C⁴). Для W₂² используются коэффициенты слабой формы.

### ВБC-6. Эквивалентность проекционной постановке

**Утверждение.** Пусть U ∈ V_aᴺ и M(U) замкнуто (ВБC-7, п. 6). Для w ∈ M(U) равносильны:

1. w = U ⊗ Y, где Y решает (Ф-2C);
2. Π(w) = min_{M(U)} Π;
3. w = P_{M(U)}ω₀ (ортогональная проекция в H_T);
4. [w − ω₀, m]_{H_T} = 0 для всех m ∈ M(U).

Если, кроме того, w ∈ D(T_CC) (MATH_SPEC 1.4), то 1–4 равносильны также
5. ∫₀ᵃ(Tw − q)Xᵢ dx = 0 для всех y, i.

Пункт 5 выполняется, например, когда U ⊂ C⁴ с X = X′ = 0, U независим и Y ∈ C^∞ по ВБC-4.

**Доказательство.**

1. **1 ⇔ 4.** [m, ω₀] = (q, m) для m ∈ H_T — определение ω₀ по Риссу [ПРИНЯТО MATH_SPEC 10]. Поэтому b_U(Y, Ỹ) − ℓ_U(Ỹ) = [U ⊗ Y − ω₀, U ⊗ Ỹ].
2. **4 ⇔ 3** — определение проекции.
3. **3 ⇔ 2:** Π(v) = ½‖v − ω₀‖² − ½‖ω₀‖² (ВБC-9, п. 1).
4. **4 ⇔ 5.** Для w ∈ D(T_CC) и m ∈ W̊₂²(Ω) формула Грина даёт [w, m] = (Tw, m): граничные члены содержат m и ∂ₙm, равные нулю
   [ПРИНЯТО MATH_SPEC 10, «Симметрия»]. Далее — как в ВБ-9, п. 4⇔5.
5. **Поле в D(T_CC).** w = ΣXᵢYᵢ; на x = 0: w = ΣXᵢ(0)Yᵢ = 0, wₓ = ΣXᵢ′(0)Yᵢ = 0; аналогично на остальных сторонах. ∎

**Отличие от SSSS.** В SSSS для п. 5 требовалось дополнительное условие X″ = 0 на концах заданного набора (Б.5, «двумерные условия
SSSS»). В CCCC заданный набор из V_a ∩ C⁴ сразу даёт полные условия CCCC поля.

**Для реализации.** Полушаг — проекция ω₀ на M(U); дискретно — точный минимум Π_h^C на M_h(U) (ВБC-13).

### ВБC-7. Матрицы Грама, разрешимость, замкнутость, вырожденный набор

**Утверждение.** Для U ∈ V_aᴺ:

1. aˣ, βˣ, γˣ симметричны и неотрицательно определены. **Каждая** из них положительно определена ⇔ U линейно независим.
2. При независимом U форма b_U ограничена: |b_U| ≤ D(‖a‖₂ + 2‖β‖₂ + ‖γ‖₂)‖Y‖‖Ỹ‖.
3. ℓ_U ограничен.
4. Коэрцитивность:

   b_U(Ỹ, Ỹ) ≥ Dλ_min(aˣ)Σ‖Ỹᵢ″‖² ≥ Dλ_min(aˣ)/(1 + (b/π)² + (b/π)⁴)·‖Ỹ‖²_{V_bᴺ}.
5. Решение (Ф-2C) существует и единственно (Рисс).
6. M(U) замкнуто, а L_U: Ỹ ↦ U ⊗ Ỹ — изоморфизм V_bᴺ на M(U).
7. **Зависимый U** (dim span U = r < N):
   - M(U) = span(U) ⊗ V_b = M(U_r) замкнуто;
   - поле P_{M(U)}ω₀ единственно;
   - набор Y не единствен: Y + cψ для Σcᵢuᵢ = 0, ψ ∈ V_b.

**Доказательство.**

1. **п. 1.** cᵀac = ‖Σcᵢuᵢ‖², cᵀβc = ‖(Σcᵢuᵢ)′‖², cᵀγc = ‖(Σcᵢuᵢ)″‖².
   - Если (Σcᵢuᵢ)′ = 0, функция постоянна и равна нулю на концах.
   - Если (Σcᵢuᵢ)″ = 0, функция линейна и равна нулю на обоих концах.

   Обе импликации верны для V_a ⊂ W̊₂¹.
2. **п. 4.** Неравенства:
   - ‖Ỹ‖ ≤ (b/π)‖Ỹ′‖ — Ỹ = 0 на концах;
   - ‖Ỹ′‖ ≤ (b/π)‖Ỹ″‖ — ∫Ỹ′ = Ỹ(b) − Ỹ(0) = 0, неравенство Виртингера для функций с нулевым средним.

   Те же неравенства использованы для CCCC в MATH_SPEC 10. Слагаемые с β, γ неотрицательны.
3. **Пп. 2, 3, 5–7** — дословно ВБ-13: используются только гильбертовость V_bᴺ, пп. 1 и 4 и билинейность (Ф-1C). ∎

**Разделение (по требованию задания):**

| Объект | Когда единствен |

| Поле полушага | всегда (п. 5, 7) |
| Набор координатных функций | только при независимом **заданном** наборе (п. 5) |
| Линейная зависимость заданного набора | не меняет поле, разрушает единственность набора (п. 7) |

GL(N)-инвариантность — ВБC-9, п. 4.

**Для реализации.** Матрица полушага ≻ 0 ⇔ заданный набор независим (дискретный аналог — ВБC-13).

### ВБC-8. Индукция гладкости и проекционности

### ВБC-16. Полиномиальное семейство и эквивалентное ему

### ВБC-18. Связанная система первого полушага для 𝒯_N и частичный результат о ранге

**Утверждение.** При X⁰ = (A₁…A_N), κᵢ = 2iπ/a система (Ф-4C) первого полушага — это

### ВБC-19. Полный ранг первого непрерывного полушага при N = 2

**Утверждение.** rank w⁽¹⁾ = 2.

**Условия:**

- q = const ≠ 0, D > 0;
- любые a, b > 0;

- Lᵢ Yᵢ = g, Lᵢ = (D² − κᵢ²)², D = d/dy;
- g = 4q/D − 2(Y₁⁗ + Y₂⁗);
- Yᵢ = Yᵢ′ = 0 при y = 0, b;

Заданный набор независим (ВБC-17), поэтому по ВБ-2 rank w⁽¹⁾ = dim span(Y₁, Y₂). Пусть Y₁, Y₂ линейно зависимы. Возможны три
исчерпывающих случая.

1. **Y₂ ≡ 0.**
   - Тогда g = L₂Y₂ ≡ 0 и L₁Y₁ = 0 с защемлением.
   - Интегрирование по частям даёт ∫Y₁L₁Y₁ = ‖Y₁″‖² + 2κ₁²‖Y₁′‖² + κ₁⁴‖Y₁‖²; граничные члены равны нулю при Y = Y′ = 0. Отсюда Y₁ ≡ 0.

2. **Y₁ ≡ 0** — симметрично (L₂ вместо L₁).
3. **Y₂ ≢ 0, Y₁ = cY₂, c ≠ 0.** Если d₁Y₁ + d₂Y₂ = 0 с d ≠ 0 и Y₂ ≢ 0, то d₁ ≠ 0 и c = −d₂/d₁.

     - Значит, Y₂ — экспоненциальный многочлен Σₖpₖ(y)e^{ξₖy} по корням ξₖ многочлена Q. Это общее решение ОДУ с постоянными

     - Функции y^m e^{ξy} с различными (m, ξ) линейно независимы на любом интервале.
     - Если Q(0) ≠ 0, ни один ξₖ не равен 0. Тогда левая часть не содержит компоненты с показателем 0, а правая — ненулевая постоянная,
       то есть компонента с показателем 0. Противоречие.
     - Вырождение R при c = −3/2 на рассуждение не влияет.
   - **(в)** Следовательно, Q(0) = cκ₁⁴ − κ₂⁴ = 0, то есть c = (κ₂/κ₁)⁴ = **16**.

4. **Показатели Yⱼ.** Yⱼ — гладкое решение LⱼYⱼ = g, Lⱼ = (D² − κⱼ²)², с защемлением. Поэтому Yⱼ — экспоненциальный многочлен:
   частное решение плюс однородная часть.

## 4. Рекомендуемый стартовый набор N = 2–3

**Рекомендация [ВЫВОД + ИНЖ; окончательно — решение владельца]:**

**Научное обоснование:**

1. **Преемственность с частью A.** При N = 1 это принятый старт sin²(πx/a) (MATH_SPEC 10, В-32). Наборы вложены по N, поэтому монотонность
   первого полушага по N гарантирована (ВБC-9, п. 3).
2. **Допустимость:** C^∞, X = X′ = 0, симметрия относительно a/2.
3. **Нагрузка:** F ≠ 0. Ненулевые нагрузки поддерживает **оболочка**, а не отдельные функции.
4. **Явные коэффициенты** (ВБC-17). Непрерывный Грам хорошо обусловлен: cond a = 5 и 7, в отличие от 𝒫_N.

6. **Согласованность при N → ∞:** одномерная полнота доказана; двумерная — условно (ВБC-11).

**Почему не 𝒫_N** (а не «потому что хуже ошибка»):

- нарушена преемственность с принятым N = 1;
- cond a растёт до 2,9·10³ (P) или 625 (Q) уже при N = 3.

до показанных знаков. Выбор старта по минимальной ошибке относительно опубликованного решения не производится.

- Для 𝒯_N Холецкий-QR устойчив: ‖QᵀAQ − I‖ ≤ 5·10⁻¹⁶ [SCRATCH].
- Потеря ранга — S-1/S-2 до QR и до следующего полушага (R4 5.4.1; РВ4-2 по структуре, пороги не переносятся).
