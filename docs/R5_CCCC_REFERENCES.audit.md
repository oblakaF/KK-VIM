## 3. Собственные проверки аудитора

### 3.1. Независимый оператор D2 и точное дискретное решение

- Оператор: δₓ⁴ + 2δₓ²δᵧ² + δᵧ⁴ сдвигами двумерного массива с фиктивными узлами w₋₁ = w₁, w_{n+1} = w_{n−1} и нулями на границе.
  Арифметика целочисленная: x = X/2⁴²⁰, масштабы — точные рациональные, общий знаменатель.
- Собственная матрица (одномерные L и D4 с угловым элементом 7, кронекерова сборка) и собственный LU — только для поправок.
- Уточнение по точной невязке до поправки < 2⁻³⁵⁰: x\* известно с точностью ~10⁻⁴⁰ отн.
- Объём: все 28 точек `d2_external.csv` (r = 1, 2, 3 при n = 32…256; r = 5 при n = 32…256), 1 477 452 неизвестных.

(l_x, l_y, n_x, n_y, D, q) = (0,37; 1,13; 60; 180; 2,5; 0,7), (1,13; 0,37; 300; 40; 1; 1), (3; 1; 96; 32; 2,5; 0,7):

### 3.3. Логика остановки (п. 5)

- Во всех 31 случае уточнение сходится за 1–2 шага (контракция cond·u ≪ 1). Затем поправка падает до уровня ошибки представления, x + dx
  округляется обратно в x, и следующая поправка ей равна. Остановка срабатывает по `size >= previous` (равенство).
- Поэтому e_D2 — ошибка округления самого x, а не остаток итерации. Она практически равна фактической ошибке, но в части случаев меньше её
  на ~10⁻¹⁰ отн. (А-1).
- Стагнация при расходимости: поправка растёт, остановка на втором шаге, e_D2 — большая поправка; e_D2/α > 10⁻¹³ даёт UNRESOLVED.
  Безопасно. При медленной сходимости и `max_refine = 5` последняя поправка завышает остаток в 1/ρ раз. Тоже безопасно.

### 3.4. A и B

- **Ритц.** Интегралы Грама φₘ = 1 − cos 2mπξ: ∫φφ = 1 + δ/2, ∫φ″φ = −2π²m²δ, ∫φ″φ″ = 8π⁴m⁴δ. Матрица /(4π⁴) = P7 (11)–(12),
  правая часть q·a⁴/(4π⁴D), центр 4Σ_{нечётные} w_mn, работа ab·Σw_mn. SMW (14)–(17) по коду верно. Перестановка (a, b, M, N) ↔ (b, a, N, M):
  α — 1,9·10⁻¹⁵ и 5·10⁻¹⁶ отн.
- **Хенки–Инглис.** Проверены вывод работы (2P/9)a³b³ + 2bΣXₘI_H/αₘ² − 2aΣYₗI_H/βₗ², I_H = 2 tanh(λh)/λ² − 2h·sech²(λh)/λ, центр (с b², a²),
  наклон ∂_yH(b) = −Δ(λb) и знаки свободных членов (A-2).
- **Страницы.** L-120, отчёт с. 6 (PDF с. 9), отрисована аудитором: табл. I (w, E, κ при M = 200…2000, опечатка 3.981200775) и табл. II
  совпадают с `r5_cccc_tables.py`. L-058, с. 13, табл. 5a (r = 1…10) — совпадает.
- **Ритц, табл. I.** E при M = 1800 = 3,89120077453 — на 0,031 последнего знака выше границы округления; это единственное несовпадение,
