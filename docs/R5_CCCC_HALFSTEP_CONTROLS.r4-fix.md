## 1. Относительные границы (Р-4)

Модуль `src/kkvim_reference/r5_cccc_halfstep.py`, функции `norm_lower`, `relative_bounds`, класс `RelativeBounds`.

**Определения:**
- ŝ — вычисленный набор (вектор double), s* — точное решение точной системы.
- b = `error_bound(...)` ≥ ‖ŝ − s*‖₂ — сертифицированная абсолютная граница (рецензия `4f92c82`, разд. 1–2, 4).
- L = `norm_lower(ŝ)`. Сумма квадратов ‖ŝ‖₂² = P/Q считается точно (Fraction от каждого double). Затем
  L = isqrt(PQ·4⁶⁴)/(Q·2⁶⁴) ≤ √(PQ·4⁶⁴)/(Q·2⁶⁴) = ‖ŝ‖₂. Для ŝ = 0 L = 0. Нечисловые и бесконечные элементы дают `ValueError`.

| Величина | Условие | Обоснование | Иначе |
|---|---|---|---|
| `to_computed` = ↑(b/L) ≥ ‖ŝ − s*‖₂/‖ŝ‖₂ | L > 0 | ‖ŝ − s*‖₂ ≤ b и ‖ŝ‖₂ ≥ L > 0 | `None` (UNRESOLVED) |
| `to_exact` = ↑(b/(L − b)) ≥ ‖ŝ − s*‖₂/‖s*‖₂ | L > b | ‖s*‖₂ ≥ ‖ŝ‖₂ − ‖ŝ − s*‖₂ ≥ L − b > 0 | `None` (UNRESOLVED) |

- ↑ — перевод точного рационального частного в double вверх (`_float_up`, принят Reviewer `4f92c82`, разд. 1).
- Если b = inf (конечной границы нет), обе величины — `None`.
- Проверки выполняются в точной арифметике: L > 0, L > b, B = Fraction(b).
- Произвольные числа вместо UNRESOLVED не подставляются.

**Трассируемость** (AGENTS.md, разд. 2):
1. Формулы: абсолютная граница — рецензия `4f92c82`, разд. 4; неравенство треугольника для ‖s*‖₂.
2. Уровень Б: собственный вывод QA. Методом автора это не является.
3. Решения: D-049.2 (контроль R-HP); выбор варианта 2 — владелец, текущее задание.
4. Проверка: точные тесты против s*, решённого рационально (разд. 5).
5. Ограничения: граница относится к набору S, а не к полю W.
