### 2.2. ПБ-2: два пути формирования S

**Формула (м).** ZᵀY₀ = Σₖ (DMₖ)⁻¹ ⊗ zₖzₖᵀ, где zₖ = (ψₖ(1), ψₖ(m)).
- Индекс строки S равен 2i + s (член i, сторона s). Это согласовано с `boundary_rows` (i·m + q, q ∈ {0, m − 1}) и с G⁻¹ = (h⁴/2D)·A⁻¹ ⊗ I₂.
- `einsum("kij,ks,kt->isjt")` с `reshape(2N, 2N)` даёт строку i·2 + s и столбец j·2 + t. Индексация верна.
- **Знак.** ψₖ(m) = √(2/n)·sin(k(n − 1)π/n) = √(2/n)·sin(kπ − kπ/n) = (−1)^{k+1}ψₖ(1). В коде `np.where(k % 2 == 1, 1, −1)` даёт +1 при нечётном k, то есть совпадает.

**Независимая проверка.** Я построил S заново: модальная сумма в 40 знаках по собственной формуле (mpmath) на тех же A, B, C.

**‖M‖₂: собственный вывод QA** (address-fix, разд. 2; docstring `m_norm`). Сверено по шагам.

1. M = I − WZᵀ, где W = Y₀S⁻¹. Обозначим 𝒮 := span[Z, W].
   - M переводит 𝒮 в 𝒮.
   - На 𝒞 := 𝒮^⊥ имеем Zᵀv = 0, поэтому Mv = v.
   - Значит, в ортогональном разложении ℝⁿ = 𝒮 ⊕ 𝒞 оператор M блочно-диагонален, и ‖M‖₂ = max(‖M|_𝒮‖₂, 1) при 𝒞 ≠ {0}. Это ВОК-12, п. 4.
2. Хаусхолдеров QR матрицы [Z, W] (n × 4N, без решения о ранге) даёт Q с ортонормированными столбцами и [Z, W] = QR. Поэтому 𝒮′ := span Q ⊇ 𝒮 **при любом ранге**.
   - Добавочное подпространство 𝒮′ ⊖ 𝒮 лежит в 𝒞, где M = I.
   - Значит, M переводит 𝒮′ в 𝒮′ и ‖QᵀMQ‖₂ = ‖M|_𝒮′‖₂ = max(‖M|_𝒮‖₂, 1 — если 𝒮′ ≠ 𝒮).
   - При n > 4N имеем dim 𝒮′ ≤ 4N < n, поэтому 𝒞 ≠ {0}, и ‖M‖₂ = max(1, ‖QᵀMQ‖₂).
   - Вывод верен.
3. QᵀMQ = I − (QᵀW)(ZᵀQ), где ZᵀQ = Q[rows, :], поскольку Z[rows[j], j] = 1. Плотная ветвь: `M[:, rows] −= W`, то есть столбец rows[j] матрицы WZᵀ равен W[:, j]. Обе формулы верны.
4. Граница ветвей `n <= 2k` при k = 2N означает n ≤ 4N, то есть m ≤ 4 (n_s ≤ 5). Поэтому пограничные случаи n_y ≤ 3 ВОК-12 (`f62cd79`) всегда считаются плотно.
