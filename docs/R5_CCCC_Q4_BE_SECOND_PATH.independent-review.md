## 2. Математическая трассировка

### 2.1. Оператор, веса, формы, нагрузка, остаток

| Элемент | Формула (ST / docstring EN = NS 2.2) | Место в BE2 | Независимая проверка |

| a_h, ‖·‖_a, ‖·‖_h | a_h(v, w) = D(Δv)ᵀW(Δw); ‖w‖²_h = h_xh_yΣw² | `field_quantities`, `bilinear` | точно |
| l_h, Π_h^C | l_h(w) = q h_xh_yΣw; Π = a_h(w, w)/2 − l_h(w) | `field_quantities`, `load_of` | точно; q < 0 и q = 0 проверены |
| S_q, S_l, S₂ | (D/2)ΣW\|t\|A; \|q\|h_xh_yΣ\|w\|; (D/2)ΣWA² (ST 4) | `field_quantities` | точно |
| остаток B_ω | ‖DAŵ_s − q𝟏‖_h, A = ΔᵀWΔ/(h_xh_y) | `residual_h2` (транспонированная матрица) | точно равен остатку через мой плотный гессиан: r = (Hŵ − q h_xh_y𝟏)/(h_xh_y) |

**Масштаб остатка.** a_h(v, w) = vᵀHw, H = DΔᵀWΔ = D h_xh_y A. В скалярном произведении ⟨·,·⟩_h представитель градиента Π —
r = DAw − q𝟏. Отсюда ‖w − ω‖²_a = ⟨r, w − ω⟩_h ≤ ‖r‖_h‖w − ω‖_h ≤ ‖r‖_h‖w − ω‖_a/(D^{1/2}μ_low). Значит,
‖w − ω‖_a ≤ ‖r‖_h/(D^{1/2}μ_low) — ровно форма BE2 и EN `b_omega`. Это **собственный вывод рецензии** для проверки
масштаба. Неравенство ‖v‖_a ≥ D^{1/2}μ_low‖v‖_h — RO ВОК-1, п. 4; я его заново не доказывал. Санитарная проверка в double
на 6 сетках: λ_min(A)/μ_low² ≥ 10,1. Дополнительно, прямо с точным ω: ‖w̃_s − ω‖_a/B_ω = 0,04…0,23.

**Вывод c_q, ν (Л-5), сделанный мной заново.** T̂ − T = (D/2)W[(φ̃ − 1)t̂² + (t̂² − t²)], |φ̃ − 1| ≤ ψ, |t̂ − t| ≤ η_tA. Подставим
t̂² ≤ t² + 2η_t|t|A + η_t²A², |t̂² − t²| ≤ η_tA(2|t| + η_tA) и t² ≤ |t|A. Получится
|T̂ − T| ≤ (D/2)W[(ψ + 2(1+ψ)η_t)|t|A + (1+ψ)η_t²A²], то есть c_q и ν ST 4. Сборка B_P через Л-3 даёт
(1+γ_L)(c_qS_q + νS₂ + c_lS_l) + γ_L(S_q + S_l) = κ_PS_q + κ_LS_l + (1+γ_L)νS₂ — ровно `BP` в BE2.

**Направления (ST 5.4).** B_E — сумма произведений неотрицательных величин. Корни в числителях (√D, ‖S‖_h, ‖d̂‖_h,
‖d̂‖_a, остаток) берутся сверху. √D в знаменателе B_ω берётся снизу (`r(…, numerator=False)`). Нижняя сборка
(`lower=True`) делает всё наоборот. Ни один корень не стоит со знаком минус. Проверено:

- на 6 сетках третьей реализации нижняя сборка ≤ значение с точными корнями (`decimal`, запас 10⁻¹⁴⁰) ≤ верхняя;
- для каждой из B1…B4 верхняя граница не меньше значения с точными корнями;
- B2 и B4 корней не содержат и совпадают с моим пересчётом точно в дробях.

`sqrt_bounds` сертифицирует каждую пару возведением в квадрат. Случайная проверка 20 000 значений от 2⁻¹¹⁰⁰ до 2¹¹⁰⁰ против
`decimal`: 0 нарушений; ширина ≤ 2⁻⁹³·hi.

**binary64 → рациональное, округление в double.**
- `exact` (через `math.frexp`) совпала с `Fraction(float)` на 5000 случайных битовых шаблонах, включая субнормальные; ±∞ и NaN —
  отказ.
- `round_up` и `round_down` совпали с независимым правилом (`Fraction.__float__` и один шаг `nextafter`) на 20 000 случаях:
  субнормальная область, переполнение, оба знака.
- Переполнение вверх даёт +∞, а B_E = +∞ — отказ (ST 5.4, п. 4).

**Повторение G-4 (И-1, П-3′(в), П-2).** `replicate_g4` повторяет EN операция в операцию:

- (P_{i−1} − 2P_i) + P_{i+1}, затем ÷ `hx**2` (Python `pow`);
- граничные строки 2P₁/c;
- t = L_x + L_y;
- ((D/2)·outer(w_x, w_y))·(t·t);
- ((q·h_x)·h_y)·w;
- конкатенация квадратичных членов всех узлов и −нагрузки;
- то же дерево `pairwise_sum` с дополнением нулём.

Каждое × и ÷ классифицируется по битам: результат с ненулевыми операндами должен строго превышать 2⁻¹⁰²². Каждое + и −
даёт ноль только при точном сокращении. Привязка побитовая: к EN на тех же массивах и к переданным P̂, Q̂. Значит, проверки
операций относятся к тому самому значению, которое ограничивает B_E.

### 2.4. Точное E_s и разложение Э-1

E_s в BE2 = (P̂_p − P̂_s − Q̂) − f(w̃_p, w̃_s), где f(v, w) = Π(v) − Π(w) − ½‖v − w‖²_a на точных полях произведений. Это
определение ST 1.1 с ВОК-2 (f(w̃_p, w̃_s) = −γ_s). Инструменты γ не используются.

Независимо я вычислил γ_s **через точный минимизатор ω** в форме ВОК-6: −a_h(w̃_s − ω, w̃_p − w̃_s). Это другая формула и
другой код. E_s совпало точно на 6 сетках, E^(1) с явным ω — тоже точно.

Части Э-1: E^(2) и E^(4) — по определению; E^(3) = −a_h(d̂, δd) + ½‖δd‖²_a с δd = d̂ − d. В E^(1) замена
a_h(w̃_s − ω, x) = a_h(w̃_s, x) − l_h(x) верна, потому что ω — минимизатор. Тождество E^(1) + … + E^(4) = E_s проверяется точно и
выполняется на всех строках, проверенных мной (6 + 4 + 288).

Результаты трассировки совпали на 3.13.15 и 3.14.8.

**Чем пути действительно различаются:**
- **binary64 → рациональное:** BE2 — `frexp`; QA-EB — битовые шаблоны и целые с общей степенью двойки.
- **оператор:** BE2 — разреженная матрица «узлы × внутренние узлы» в `Fraction`; QA-EB — целочисленные сдвиги массивов.
- **остаток B_ω:** BE2 — ΔᵀWΔ; QA-EB — 13-точечный D4 ⊗ I + 2L ⊗ L + I ⊗ D4.
- **корни:** BE2 — пара целых корней k = 96 с сертификацией квадратом; QA-EB — `isqrt(PQ·4⁸⁰)`.
- **предпосылки:** BE2 — своё повторение G-4 с битовой классификацией; QA-EB — `OpLog` + `replicate_energy`.

**Сравнение не является двумя вызовами одной функции.**

**Общее по необходимости** (это не независимые доказательства):
- теорема Э-2 и её вывод;
