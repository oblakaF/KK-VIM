## 2. Собственные расчёты QA

**Независимая высокоточная цепочка** (mpmath 1.4.1, 50 знаков; одноразовый расчёт вне git). Синусный ряд модуля и код `kkvim_reference`
в ней не используются:
- s = 1 — замкнутая форма В-29 с α = πb/(2a), Y¹ на (0, b);
- s ≥ 2 — замкнутое решение ОДУ полушага D(Af⁗ − 2Bf″ + Cf) = F на (0, ℓ_s), f = f″ = 0 на концах, через комплексные корни
  k² = (B + i√(AC − B²))/A: f = F/(DC) + 2 Re(K ch(k(ξ − ℓ_s/2))), постоянная K — из двух условий на краю;
- G_{s+1} = (∫f², ∫f′², ∫f″², q∫f) по собственной длине множителя ℓ_s — квадратурой mpmath;
- поле w_s = X·Y, энергия Π_s = −qI_XI_Y/2.

Значения при s = 1…5 для пластин (1; 0,2), (3; 1), (1; 1,4), (1; 2), (2; 1), (1; 5) встроены в тест QA как константы с 22 знаками.

**Остальные собственные проверки:**
- правило И-12 — по формулам хвостов 15.4 (собственный код);
- s = 1 против В-29 в повышенной точности и сама формула В-29 в double;
- диагностики против эталона Навье (`NavierRectangle`, M = 2559);
- побитная регрессия R2 против модуля `origin/main`.

## 4. Особый случай r = 0,2: s = 1 против В-29 в повышенной точности

Узлы сетки 9 × 21 (n_x = 8, n_y = 20); эталон — В-29 в mpmath (50 знаков).

| Величина | r = 0,2 | максимум по остальным r |
|---|---|---|
| Реализация: max\|w − w_mp\| / max\|w\| | **1,7·10⁻¹⁶** | 4,7·10⁻¹⁶ |
| Бюджет `field_error` (s = 1) | 2,0·10⁻¹⁴ | 2,5·10⁻¹⁴ |
| Модель округления значений ROUND_VALUES·Σ\|c_m\| (относительно max\|Y\|) | 5,4·10⁻¹⁵ | 8,1·10⁻¹⁵ |
| Формула В-29 в double: max\|err\| / max\|Y\| | **8,2·10⁻¹⁴** | 1,9·10⁻¹⁴ (r = 1/3) |
| Формула В-29 в double, центр | 2,4·10⁻¹⁴ относительно | — |
| Отношение ошибки В-29 в double к модели автора (32u·Σ\|слагаемых\|) | 0,021 | ≤ 0,069 |

Центр при r = 0,2: w̄ = 2,45178392177077166197…·10⁻⁵ (mpmath); реализация 2,451783921770772·10⁻⁵.

**Вывод.**
- Реализация при r = 0,2 точна до ~u: фактическая ошибка в 120 раз меньше бюджета и в 30 раз меньше модели округления.
- Значение 8,2·10⁻¹⁴ в таблице автора (разд. 3) — ошибка **замкнутой формулы** В-29 в double, а не реализации. При α = π/10 величина
  1 − P = 1,876·10⁻³, и вычитание 1 − P·ch(…) теряет около трёх знаков.
- Модель автора для этой формулы консервативна: фактическая ошибка ≤ 0,07 допуска при всех r. Допуск не ослаблялся.

## 6. Неблокирующие замечания

- **Н-1.** Флаг `valid = True` сохраняется при s = 22–23, хотя бюджет поля уже 0,1–0,94, то есть неинформативен. Пользователям бюджета
  следует смотреть на величину `field_error`, а не только на `valid`. Это особенность документированной оценки ~4ˢ (Q-022), а не ошибка.
- **Н-2.** В документе автора (разд. 3, задание 1) относительная разность 8,2·10⁻¹⁴ при r = 0,2 стоит в столбце «s = 1 против В-29».
  Её стоит пояснить как ошибку замкнутой формулы в double (разд. 4 этого отчёта).
- **Н-3.** Docstring `centre_value` говорит «w_s(a/2, a/2)», а для прямоугольника узел i = j = 1 сетки 2 × 2 — это (a/2, b/2).
  Вычисление верное, устарел только текст.
- **Н-4.** Модуль выбирает M консервативно: в оценке f_max берётся нижняя граница (|c₁| − |c₃|). Иногда критерию 15.4 удовлетворяло бы и
  M − 2. Это допустимо и согласуется с И-12.
