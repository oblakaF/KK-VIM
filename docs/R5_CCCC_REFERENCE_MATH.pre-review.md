### 1.1. P4 — Meleshko & Gomilko 1997

**(1.1)–(1.4), с. 2140.** Общая бесконечная система X_n = Σ_k a_k^{(n)} Y_k + b_n, Y_k = Σ_n c_n^{(k)} X_n + d_k
с **положительными** элементами a, c. Определения:

- система **регулярна**, если φ_n = 1 − Σ_k a_k^{(n)} > 0 и ψ_k = 1 − Σ_n c_n^{(k)} > 0 (1.3);
- система **вполне регулярна**, если φ_n ≥ θ и ψ_k ≥ θ при θ > 0 (1.4).

Конечная система (1.2) — «метод редукции» (Riesz 1913).
`[MG1997, ур. (1.1)–(1.4), с. 2140] references/Поиск статей/meleshko1997.pdf`

**(1.5)–(1.8), с. 2141–2142.**

- Условия на свободные члены: |b_n| ≤ C_rφ_n (1.5) или ограниченность (1.6).
- По Канторовичу–Крылову (1958, гл. 1) редукция сходится к **главному** решению.
- Лимитанты Кояловича (1.7):
  - V_n = (b_n + Σ_{k≤K} a_k^{(n)} Y_k)/(φ_n + Σ_{k≤K} a_k^{(n)}), n > N;
  - аналогично W_k.

  Теорема (1.8): если H и h — соответственно больше и меньше всех V_n, W_k, то **все** неизвестные с номерами > N, > K
  лежат в [h, H]. Условия теоремы: регулярная система и **положительные** свободные члены (с. 2141).
- Сноска на с. 2141: опечатка в ур. (53) Канторовича–Крылова (1958, с. 40).

**(2.1)–(2.2), с. 2142–2143.** Система для функций, чётных по x и y:

Y_l\,a\,\Delta(\beta_l a)=\sum_{m=1}^{\infty}X_m\frac{4\beta_l^2\alpha_m}{(\alpha_m^2+\beta_l^2)^2}+H_l .$$

## 2. Размерности, знаки и множитель p₀/(8D) [ВЫВОД]

### 2.1. Представление и тождественно выполняемые условия

Берём P5 (3.1) с явным множителем P = p₀/D только при полиноме (как напечатано) и неизвестными Xₘ, Yₗ, несущими размерность:

$$w=\frac P8(a^2-x^2)(b^2-y^2)-b\sum_m(-1)^m\frac{X_m}{\alpha_m}H(y,\alpha_m,b)\cos\alpha_m x+a\sum_l(-1)^l\frac{Y_l}{\beta_l}H(x,\beta_l,a)\cos\beta_l y .\qquad(\text{A-1})$$

1. **Уравнение.** В (a² − x²)(b² − y²) бигармонический оператор отличен от нуля только на слагаемом x²y²:
   ∇⁴(x²y²) = 2∂²ₓ∂²ᵧ(x²y²) = 8. Поэтому ∇⁴[(P/8)(a² − x²)(b² − y²)] = P = p₀/D.
   Функции cosh(λz)cos(λs) и z·sinh(λz)cos(λs) бигармоничны. Следовательно, D∇⁴w = p₀ почленно — внутри области,
   где ряды можно дифференцировать (P5, с. 811).
2. **w = 0 на контуре.**

## 3. Полная регулярность и обусловленность (ОВ-2)

### 3.1. Масштабированная форма [ВЫВОД]

Разделим каждую строку (A-2) на её диагональ: dₘ = bΔ(αₘb) и d̂ₗ = aΔ(βₗa). Получим z = Kz + f̃ с z = (X, Y) и

$$K_{m,l}^{XY}=\frac{4\alpha_m^2\beta_l}{(\alpha_m^2+\beta_l^2)^2\,b\,\Delta(\alpha_m b)}\ge0,\qquad
K_{l,m}^{YX}=\frac{4\alpha_m\beta_l^2}{(\alpha_m^2+\beta_l^2)^2\,a\,\Delta(\beta_l a)}\ge0,\qquad K^{XX}=K^{YY}=0 .$$

**K ≥ 0 поэлементно.** Отсюда (I − K)⁻¹ = ΣKᵏ ≥ 0 при ‖K‖∞ < 1 (разд. 3.5).

### 3.2. Лемма R1: строчные суммы зависят только от одного параметра [ВЫВОД]

Строка m блока X имеет сумму ρₘ = (1/(bΔ(λb)))·Σₗ 4λ²βₗ/(βₗ² + λ²)² при λ = αₘ. Положим t = λb и gₗ = βₗb = (2l − 1)π/2:

$$\rho_m=f(t):=\frac{1}{\Delta(t)}\sum_{i=1}^{\infty}\frac{4t^2g_i}{(g_i^2+t^2)^2},\qquad t=\alpha_m b .$$

Множители b сокращаются: Σ 4λ²βₗ/(βₗ² + λ²)² = **b**·Σ 4t²gᵢ/(gᵢ² + t²)² (размерность длины, ср. P4 (2.7): Rₘ ≈ 2b/π),
а делитель bΔ(t) снимает этот множитель b. Для строки блока Y — та же функция f при t = βₗa. *(У-1: в редакции `321432d`
промежуточный множитель был ошибочно записан как 1/b; итоговая f(t) не менялась.)*

**Следствия.**

- Это левая часть P5 (3.7) и P4 (2.9) в переменной t.
- Отношение сторон r определяет только **набор** точек tₘ = (2m − 1)πb/(2a), в которых берётся f.
- Если sup_{t>0} f(t) = ρ < 1, оценка **равномерна по r**.

**Ответ на вопрос задания «равномерна ли граница 0,77 по r»:** да — при условии, что неравенство (3.7) верно при всех t > 0.

### 3.3. Лемма R2: f — взвешенное среднее [ВЫВОД]

По разд. 2.5, п. 2, Σᵢ 4t gᵢ²/(gᵢ² + t²)² = Δ(t). Поэтому

f(t) = Σᵢ wᵢ(t/gᵢ), wᵢ = 4t gᵢ²/((gᵢ² + t²)²Δ(t)) > 0, Σwᵢ = 1.

Это объясняет, почему f < 1 не очевидно: f — среднее отношений t/gᵢ, а их значения бывают больше 1.

### 3.5. Обусловленность [ВЫВОД]

Пусть ρ := sup f < 1. Тогда:

- ‖K‖∞ ≤ ρ;
- ‖I − K‖∞ ≤ 1 + ρ;
- (I − K)⁻¹ = ΣKᵏ (ряд Неймана в ℓ∞), ‖(I − K)⁻¹‖∞ ≤ 1/(1 − ρ);
- **κ∞(I − K) ≤ (1 + ρ)/(1 − ρ).**

| ρ | κ∞ | Статус |
|---|---|---|
| 0,77 (P5) | < 1,77/0,23 = **7,70** | при условии (3.7) |
| 0,7081 (SCRATCH) | 5,85 | не доказано |

**Ограничение (подтверждено).** Сопряжённая система имеет ограниченное положительное решение U = V = 1 (разд. 2.5, п. 2).
Значит, для вектора диагоналей d = (dₘ, d̂ₗ) выполнено Kᵀd = d.

- Спектральный радиус Kᵀ на ограниченных последовательностях **не меньше 1**, так как Kᵀd = d при d > 0. Отсюда

### 3.6. Существование, единственность, сходимость редукции [ВЫВОД, элементарно в ℓ∞]

При ρ < 1 и ограниченном f̃:

1. Отображение z ↦ Kz + f̃ — сжатие в ℓ∞. Поэтому ограниченное решение z* единственно, ‖z*‖∞ ≤ ‖f̃‖∞/(1 − ρ), и

$$\|P_Nz^*-z_N\|_\infty\le\frac{1}{1-\rho}\ \sup_{i\le N}\ \sum_{j>N}K_{ij}\,|z^*_j| .\qquad(\text{E-1})$$

### 9.3. D2: 13-точечная схема с фиктивными узлами [ВЫВОД, стандартная конструкция]

**Во внутренних узлах:**

(δ⁴ₓ + 2δ²ₓδ²ᵧ + δ⁴ᵧ)w_{ij} = q/D.

Здесь δ⁴ — пятиточечный шаблон (1, −4, 6, −4, 1)/h⁴, а δ²ₓδ²ᵧ — девятиточечное произведение вторых разностей.

**Защемление:**

- w = 0 в граничных узлах;
- ∂w/∂n = 0 центральной разностью (w₁ − w₋₁)/(2h) = 0, то есть **фиктивный узел w₋₁,ⱼ = w₁,ⱼ** (чётное отражение) и
  аналогично на всех сторонах.

Фиктивные узлы нужны только в δ⁴: δ²ₓδ²ᵧ в узле, соседнем с краем, использует лишь граничные узлы, где w = 0.

**Матричная форма:**

### 9.4. D1: полная дискретная вариационная задача

Дискретизация КК-МВИ для CCCC в проекте **ещё не определена**: MATH_SPEC, таблица разд. 10, «одномерные разностные условия
защемления — R5»; Q-010. Поэтому D1 определяется **условно**, относительно функционала, который будет принят для КК-МВИ.

**Предлагаемый кандидат [ВЫВОД; предложение, не решение].** Аналог функционала R2–R4 (R4_NUMERICAL_SPEC 2.1):

$$\Pi_h^{C}(w)=\frac D2\sum_{i=0}^{n_x}\sum_{j=0}^{n_y}\omega_i\omega_j\,h_xh_y\bigl(\Delta_h^{C}w\bigr)_{ij}^2-q\sum_{\text{внутр.}}h_xh_y\,w_{ij},$$

где:

- ω = ½ в граничных узлах и 1 во внутренних (правило трапеций);
- Δ_h^C = Ł_x ⊗ E_y + E_x ⊗ Ł_y;
- E — вложение внутренних значений с нулями на границе;
- **Ł** — вторая разность, продолженная на граничные узлы через фиктивный узел: (Łf)₀ = 2f₁/h², (Łf)_n = 2f_{n−1}/h²,
  во внутренних узлах (Łf)ᵢ = (f_{i−1} − 2fᵢ + f_{i+1})/h².

Отличие от SSSS: там (Lf)₀ = 0 (R4_NUMERICAL_SPEC 2.3), здесь (Łf)₀ = 2f₁/h² ≈ f″(0) + O(h).

**Предложение D [ВЫВОД, доказано].** Гессиан Π_h^C равен D·hₓh_y·𝒜_{D2}.

*Доказательство.*

1. (Ł ⊗ E)ᵀ(W ⊗ W)(Ł ⊗ E) = (ŁᵀWŁ) ⊗ (EᵀWE).
2. EᵀWE = h·I.
3. ŁᵀWŁ = h·L² + (h/2)·(2/h²)²(e₁e₁ᵀ + e_{n−1}e_{n−1}ᵀ) = h·D4.
4. Перекрёстный член: (Ł ⊗ E)ᵀW(E ⊗ Ł) = (ŁᵀWE) ⊗ (EᵀWŁ) = (hL) ⊗ (hL), так как граничные строки Ł умножаются на нулевые
   граничные строки E. В сумме с транспонированным он даёт 2hₓh_y·Lₓ ⊗ L_y.
5. Линейная часть: ∇l_h = q·hₓh_y·𝟏. ∎

[SCRATCH П-9: ‖Hess − 𝒜_{D2}‖/‖𝒜_{D2}‖ = 1,6·10⁻¹⁶.]

**Следствия:**

1. **D1 = D2 тогда и только тогда, когда** квадратичная форма и линейная часть принятого функционала КК-МВИ на той же
   сетке совпадают (с точностью до общего множителя) с D·hₓh_y·𝒜_{D2} и q·hₓh_y·𝟏.

   **Π_h^C — достаточная реализация** этого условия: вес ½ в граничных узлах и фиктивная вторая разность 2f₁/h².
   Другие эквивалентные квадратичные формы возможны. Пример Reviewer: вес 1 вместе с граничной разностью √2·f₁/h² даёт
   тот же гессиан (У-2).

   При весе 1 **и сохранении граничной разности 2f₁/h²** одномерная граничная строка становится (9, −4, 1)/h⁴, и D1 ≠ D2
   [SCRATCH П-9]. При односторонних разностях или других квадратурах D1 нужно строить отдельно как минимизатор принятого
   функционала.
2. **Матрицы полушагов КК-МВИ при выборе Π_h^C** (аналог ЧФ-1 R4_NUMERICAL_SPEC 2.3, вывод тем же путём):

   K^C_{ij} = D[A_{ij}·D4_y − 2B_{ij}·L_y + C^C_{ij}·I], A_{ij} = ⟨U_i, U_j⟩, B_{ij} = −⟨U_i, LU_j⟩, **C^C_{ij} = h·U_iᵀD4·U_j**.

   собственные векторы L не являются собственными векторами D4. Модальный решатель R4 (R4_NUMERICAL_SPEC 3.2, вариант B,

   - блочная ленточная или разреженная система;
   - поправка Шермана–Моррисона–Вудбери к модальному решению.
3. **Если Π_h^C будет принят:**
   - КК-МВИ минус D1 — ошибка низкорангового представления на фиксированной сетке;
   - D1 минус A — ошибка сетки.

   D2 при этом совпадает с D1 и **не даёт независимой проверки ошибки сетки** этой дискретизации. Независимо её проверяет
   только A (и B). Чтобы независимо проверить и саму двумерную реализацию, D2 строится QA отдельным кодом поузловой сборки,

**Условия, при которых D1 — полный дискретный эталон КК-МВИ:**

- (а) один функционал на всех полушагах;
- (б) полушаг — точная минимизация на M_h(U) (R4_NUMERICAL_SPEC 2.6);
- (в) одинаковые сетка, веса и коэффициенты A, B, C^C, F;

Тогда D1 — единственный минимизатор Π_h^C на V_h, а итерации КК-МВИ — проекции на подпространства V_h. Энергетическое тождество

### 9.9. Сетки для будущей квалификации (предложение для QA) [ИНЖ]

**Сетки по короткой стороне:** n ∈ {32, 48, 64, 96, 128, 192, 256}; для r ≤ 2 дополнительно n = 384, 512.

- Последовательность с чередующимися отношениями 1,5 и 4/3 даёт ≥ 5 точек на каждом из двух вложенных удвоений
  (32→64→128→256 и 48→96→192). Это позволяет:
  - оценить наблюдаемый порядок по тройкам (h, h/2, h/4) независимо на двух сериях;
  - подогнать разложение по нескольким показателям, например {2, 3, 4} против {2, 4, 6}, и проверить устойчивость коэффициентов;
  - применить обобщённый Ричардсон только с показателями, подтверждёнными наблюдением.
- Критерии сравнения и допуски фиксируются **до** итогового сравнения (D-025, AGENTS.md разд. 4) — отдельным решением,
  а не этим документом.

**Объём** (неизвестные (n − 1)(rn − 1)):

| n | r = 1 | r = 2 | r = 3 | r = 5 |
|---|---|---|---|---|
| 128 | 16 129 | 32 385 | 48 641 | 81 153 |
| 256 | 65 025 | 130 305 | 195 585 | 326 145 |
| 512 | 261 121 | 522 753 | — | (1 307 649 — не предлагается) |

**Стоимость [ИНЖ, оценка порядка].**

- Матрица SPD, 13 ненулей в строке. Разреженный Холецкий с упорядочением nested dissection: заполнение ~ N log N.
- Ленточный Холецкий с лентой 2(n − 1) по короткой стороне: память ~ 8N·2n байт.
  - Для r = 5, n = 256: ≈ 1,3 ГБ, ~10¹¹ флопов.
  - Для r = 5, n = 512: ≈ 11 ГБ — поэтому не предлагается.
- Итерационные методы для бигармонической матрицы (cond ~ h⁻⁴) без предобуславливания не рекомендуются: точность
  10⁻¹⁰ и лучше требует прямого решателя или многосеточного предобуславливания [ИНЖ].
- Ошибка округления растёт как cond·u ~ (n⁴)·10⁻¹⁶. При n = 512 это до ~10⁻⁵ относительно в худшем случае. Поэтому для
  верхних сеток QA оценивает фактическую ошибку решения, например повторным решением с итеративным уточнением.
