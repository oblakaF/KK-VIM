## 3. Вердикт по полушагам

1. **Коэффициенты и множители.** A = h_xUᵀU, B = −h_xUᵀL_xU, C^C = h_xUᵀD4_xU, F = q h_xUᵀ𝟏 — верно.
   - C^C = (ŁU)ᵀW(ŁU)/h ⪰ 0.
   - C^C − C_{L²} = (2/h_x³)(u₁u₁ᵀ + u_{n−1}u_{n−1}ᵀ): проверено при N = 1, nₓ = 10 — 36,47 = 36,47.
2. **ЧФ-C1 из энергии.** Рецензент построил 𝒦^C ограничением своего гессиана Π_h^C на M_h(U):
   - 𝒦^C = (1/h_y)·(U ⊗ I)ᵀ·Hess·(U ⊗ I), нумерация «член — узел»;
   - нагрузка — (1/h_y)(U ⊗ I)ᵀ q h_xh_y 𝟏.

   Совпадение с D[A⊗D4_y − 2B⊗L_y + C^C⊗I] и F⊗𝟏 — ≤ 2,4·10⁻¹⁶ на трёх сетках с hₓ ≠ h_y и a ≠ b: (10, 14, a = 1, b = 1,7, N = 3); (8, 12, 0,6, 1,3, N = 2); (12, 7, 2,0, 0,9, N = 1). Порядок кронекеровых множителей (член первым), множители D, h_y и q верны. X-полушаг — симметрично.
3. **N = 1.** K = D[A_hD4 − 2B_hL + C^C_hI]. Числа 4.4 воспроизведены: A_h = 0,3750, B_h = 4,7746, C^C_h = 182,37, F_h = 0,5000 при nₓ = 10. Непрерывные коэффициенты и ОДУ совпадают с MATH_SPEC 10 (В-34).
4. **Разрешимость и SPD.** Перенос ЧВ4-5 верен в общем виде: vec(Ṽ)ᵀ𝒦^C vec(Ṽ) = a_h^C(UṼᵀ, UṼᵀ)/h_y, a_h^C ≻ 0 на V_h, UṼᵀ = 0 ⇔ Ṽ = 0 при независимых столбцах U. Доказательство опирается только на SPD конечномерной энергии и вид M_h — **общее утверждение**. ОВ-S1 в дискретной части можно закрыть.
5. **Энергетическое тождество.** ЧВ4-14 для Π_h^C — общий факт ортогональной проекции в конечномерном пространстве со SPD-формой (точный минимум на M_h, w^{(s−1)} ∈ M_h, SPD) — **верно**. Не перенесены и требуют отдельного доказательства для CCCC:
   - непрерывная теория N ≥ 2 (часть B);
   - допустимый старт;
   - дискретная независимость стартового набора (аналоги ЧВ4-8, ЧВ4-9);

## 4. Вердикт по A-C и B-C

### 4.1. Алгебра

**B-C.**
- 𝒦^C = 𝒦₀ + Z(DA ⊗ (2/h⁴)I₂)Zᵀ, где 𝒦₀ = D[A⊗L² − 2B⊗L + C^C⊗I] и Z = I_N ⊗ [e₁, e_{n−1}].
- 𝒦₀ уже содержит C^C, поэтому поправка равна только D·A ⊗ E₂ — ранга 2N при A ≻ 0 (численно: ранг 2, 4, 6 при N = 1, 2, 3).
- 𝒦₀ диагонализуется DST-I: M_k = μ_k²A + 2μ_kB + C^C ≻ 0.
- Формула Шермана–Моррисона–Вудбери x = x₀ − Y₀S⁻¹Zᵀx₀, S = G⁻¹ + ZᵀY₀ верна; S ≻ 0 и симметрична.
- Все множители D и h на месте: G = DA ⊗ (2/h⁴)I₂, G⁻¹ = (DA)⁻¹ ⊗ (h⁴/2)I₂.
- Совпадение с прямым решением ≤ 6·10⁻¹⁶ на трёх прямоугольных сетках — алгебраическая проверка, не квалификация.
- **N = 1:** 𝒦₀ = DA(L − r₁)(L − r₂) по R2 ЧВ-9 с C → C^C. Для sin² B² − AC < 0, корни комплексно-сопряжённые — этот случай в NUMERICAL_SPEC 8.1 предусмотрен. Затем поправка ранга 2 и S размера 2 × 2. Верно.

**A-C.** SPD блочно-пятидиагональная система (У-R1); Холецкий применим при независимых U; стоимость O(nN³). Верно.

### 4.2. Точность при росте n (наблюдение рецензента, не квалификация)

Эталон — решение, уточнённое итерациями с невязкой исходного оператора (D4 со строкой (7, −4, 1)) в 40 знаках (mpmath). Заданный набор — (1 − cos 2iπx/a)/2, i ≤ N, после QR; b = 1,7, h_y = b/n, nₓ = 64. Относительная ∞-ошибка:

|---|---|---|---|

| 128 | 3·10⁻¹⁶ / 4·10⁻¹⁶ / 6·10⁻¹⁶ | 5·10⁻¹¹ / 9·10⁻¹¹ / 8·10⁻¹¹ | 1,0 / 2,56 / 4,05 |
| 512 | 1,2·10⁻¹⁵ / 1,0·10⁻¹⁵ / 1,0·10⁻¹⁵ | 1,3·10⁻⁸ / 2,0·10⁻⁸ / 2,0·10⁻⁸ | 1,0 / 2,57 / 4,12 |
| 1024 | 1,1·10⁻¹⁵ / 2,5·10⁻¹⁵ / 1,5·10⁻¹⁵ | 4,9·10⁻⁸ / 1,5·10⁻⁷ / 1,5·10⁻⁷ | 1,0 / 2,57 / 4,12 |

- A-C теряет точность как cond(𝒦^C)·u ~ (2n/π)⁴u — тот же эффект, что R2 И-6 (NUMERICAL_SPEC 3.5).
- B-C в этих тестах точен до ~10⁻¹⁵, cond S ограничена по n.
- **Уязвимость B-C** при почти зависимом наборе без QR (n = 256, N = 3): cond A = 1,1·10⁵ / 1,1·10⁹ ⇒ cond S = 4,8·10⁴ / 4,7·10⁸, ошибка поля 9·10⁻¹³ / 9·10⁻⁹. Отсюда условие У-R5.

**Вердикт.**
- **B-C — PASS как основной путь.** Алгебра доказана. Наблюдаемая устойчивость хорошая при условии хорошо обусловленного заданного набора (после QR). Квалификация — QA.
- **A-C — PASS только как контроль.** Либо малые и средние n, либо с итеративным уточнением по исходному оператору. Основным путём A-C не рекомендуется (опыт R2 И-6 и измерение выше).

### 4.3. Проверки QA, необходимые до принятия РВ5-2

1. B-C против эталона с уточнённой невязкой на цепочке n до наибольшей сетки R5. Условия: hₓ ≠ h_y, N = 1–3, все контрольные r, оба направления полушага.
2. Журнал cond(A) и cond(S) на каждом полушаге; поведение при плохо обусловленном наборе (инъекция, как в R4) — подтверждение порядка «диагностика → QR».
3. Невязка η_N^C по исходному оператору с D4 без модального преобразования (У-R2); проверка формулы нормировки.
4. Модель округления быстрого DST для 𝒦₀ (аналог QA-δ2 R4) — не переносится автоматически.
5. A-C как независимая проверка той же системы — с итеративным уточнением. Для QA-C6 при больших n сравнение с A-C без уточнения неинформативно: A-C даёт ошибку до 10⁻⁷ при n = 1024.
6. N = 1: путь R2-факторизации с C^C и поправкой ранга 2 сравнить с модальным B-C (DST) и с эталоном.

Чего не хватает до приёмки:
1. Решения владельца по Π_h^C (Б-5) и по способу решения (Б-3/РВ5-2).
2. Численной политики CCCC N = 1 (Б-4): пороги остановки, η_max, энергетический тест. Пороги R2/D-048 для SSSS не переносятся автоматически — решение, проект это соблюдает.
3. **Явной записи представления и нормировки множителя N = 1 между полушагами.** Аналог И-4 R2/R3 в проекте прямо не назван — достаточно ссылки «как R2 И-4» или отдельного решения.
4. Аналитический контроль первого полушага (ОВ-S6) желателен, но не обязателен для приёмки.

Реализацию R5 по ROADMAP формально ограничивает Б-1 (R4 не принят). Приёмку спецификации N = 1 это не блокирует.
