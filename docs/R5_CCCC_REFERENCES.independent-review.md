## 1. Ответы на обязательные вопросы

### 1.1. D2: последняя поправка уточнения — граница или оценка; бюджет 1/100

**Что делает код** (`r5_cccc_d2.py`, `solve`):

- x₀ = LU⁻¹f;
- затем до пяти шагов: r = f − 𝒜x в double-double по точному оператору, dx = LU⁻¹r, x ← x + dx;
- остановка, когда max|dx| перестаёт убывать;
- e_D2 = max|dx| последнего шага.

**Мой независимый пересчёт** (`refcheck.py`, Н-1): своя сборка Z = D4ₓ ⊗ I + 2Lₓ ⊗ L_y + I ⊗ D4_y в целых числах, невязка в `fractions`, шесть шагов.

| Точка | α (моё) против α_ref QA | Поправки / α по шагам | Оценка ошибки итогового x / α |
|---|---|---|---|
| r = 1, n = 32 | совпадают побитово | 4,9·10⁻¹³; затем **8,5·10⁻¹⁷ на каждом шаге** | 8,5·10⁻¹⁷ |
| r = 1, n = 48 | побитово | 1,7·10⁻¹²; затем 8,5·10⁻¹⁷ | 8,5·10⁻¹⁷ |
| r = 2, n = 32 | побитово | 8,8·10⁻¹³; затем 8,3·10⁻¹⁷ | 8,3·10⁻¹⁷ |

**Вывод.**

1. После первого шага поправка **не убывает**, а остаётся постоянной на уровне 8,5·10⁻¹⁷·α < u·α. Это ошибка представления: x* не представимо в double, |dx| < ½ ulp, и x + dx округляется обратно в тот же x.
   - Поэтому e_D2 — точная по порядку **оценка остаточной ошибки** на уровне округления хранения, а не результат сходящегося процесса.
   - QA правильно называет e_D2 «оценкой, не строгой границей».
2. **Верхней границей e_D2 становится только при доказанном сжатии уточнения.** Пусть F — оператор ошибки решения факторизацией. При ‖F‖ ≤ ½ выполнено ‖x* − x̂‖∞ ≤ 2·e_D2 + O(u)‖x̂‖∞.
   - Граница ‖F‖ ≲ c_LU·cond(𝒜)·u правдоподобна: cond(𝒜)·u ≤ 3·10⁻⁷ при n ≤ 256, PL §1.4.
   - Но c_LU (рост в SuperLU с частичным выбором) не оценён, поэтому граница не доказана.
3. **Бюджет 1/100 для сравнения дискретных решений.**
   - Для α и **max-нормы узлового поля относительно α** (центр — максимум прогиба) правило применимо: эталон D1 = D2 и сравниваемое поле КК-МВИ — величины одной дискретной задачи, норма одна.
   - Минимальная измеримая ошибка ~10⁻¹⁴ отн. на много порядков ниже ожидаемых разностей КК-МВИ − D1 (низкоранговая ошибка ~10⁻⁸ и выше).
   - **Для энергетических величин бюджет не установлен:** Π_h^C, ½‖w − ω_h^C‖²_{a_h} — проверки BC-11, BC-12, ST-10. Ошибка эталона в норме a_h не следует из max-нормы без множителя ~(λ_max(𝒜)·hₓh_y·D·число узлов)^{1/2}, а сравнение квадрата расстояния чувствительно к ней линейно. До отдельного вывода — UNRESOLVED.
   - Это нужно записать (ЭР-3).

- **Свойство верно в точной арифметике.** Базис (1 − cos 2πmξ)(1 − cos 2πnη) лежит в W̊₂²(Ω), интегралы Грама точные. Решение Ритца w_M — энергетическая проекция ω₀ на подпространство, поэтому q·W_M = (q, w_M) = [w_M, ω₀] = ‖w_M‖²_{H_T} ≤ ‖ω₀‖²_{H_T} = q·W. Для вложенных базисов W_M не убывает.
- Тест вложенности (`test_ritz.py`, 4u·W) и перекрёстный тест A ≥ B при M = 120 (`test_cross`, 64u) корректны: запас там ≫ округления.
- **С учётом численных ошибок неравенство для вычисленных чисел — наблюдение, а не строгая проверка.**
  - В `compare.csv` (M до 2000) запас (W_A − W_B)/W_A = 1,0·10⁻¹⁰ (r = 1; 1,2), 8,4·10⁻¹⁰ (r = 2), 7,3·10⁻¹⁰ (r = 3), 6,7·10⁻¹⁰ (r = 5).

### 1.8. Отклонение: double-double вместо рациональной арифметики (разд. 7.1)

- **Где действует.** Во всех точках внешних данных и последовательностей hₓ = h_y = 1/n (короткая сторона 1). Масштаб n⁴ — точное целое (n ≤ 512 ⇒ n⁴ < 2⁵³), его округления нет вовсе. Отклонение касается только недиадических проверок (D2-7, D2-12, ℓ = 3).
- **Величина влияния.**
  - Масштабы трёх слагаемых, округлённые до double-double, возмущают оператор на |δ| ≲ 10⁻³². Если все масштабы округлены одинаково, это скалярное возмущение и решение меняется на ~10⁻³² отн.
  - При разных округлениях трёх масштабов — не больше cond(𝒜)·10⁻³² ≤ 10⁻²² (оценка QA).
  - В обоих случаях это на шесть и более порядков ниже u.
  - Невязка double-double совпадает с точной рациональной (тест D2-9); моя рациональная невязка даёт побитово тот же α (Н-1).
- **Вывод.** На достоверность утверждений о точности отклонение **не влияет**. Его нужно зафиксировать в плане QA при следующей правке (ЭР-6).
