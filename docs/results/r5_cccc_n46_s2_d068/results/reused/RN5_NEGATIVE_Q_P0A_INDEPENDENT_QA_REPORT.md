## Математика
- **Тождество.** F_i = q·h·Σ_l T_li, и h·Σ_{l=1}^{n−1} sin²(πil/n) = a/2 точно при n ∤ i (сумма корней из единицы равна 0; i ≤ N < n/2). Значит F\* = q·a/2.
- **Граница.** F_c − F\* = q·h·Σ_l(Tc − T\*)_li, откуда |F_c − F\*| ≤ |q|·h·m·ρ.
- **Почему старая формула неверна.** При q < 0 правая часть q·h·m·ρ < 0, а левая |·| ≥ 0. Поэтому старая проверка отклоняла каждый случай с q < 0 безусловно.
