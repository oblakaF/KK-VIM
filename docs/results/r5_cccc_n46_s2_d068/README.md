## Перенос в репозиторий (что изменено относительно файлов QA)

Только три вида преобразований, для каждого файла указанных в `REPACKAGING.csv`:

1. `eol` — окончания строк CRLF заменены на LF (так Git хранит текстовые файлы; при `core.autocrlf=true` рабочая копия снова покажет CRLF).
2. `path` — абсолютные пути локальных рабочих деревьев заменены метками `<QA_WORKTREE>` (worktree QA) и `<BUILDER_WORKTREE>` (worktree Builder). Скрипты с такими метками перед повторным запуском нужно настроить на свой клон; это ограничение отмечено и в отчёте QA (разд. 11).
3. `name` — `*.log` переименованы в `*.log.txt` (`*.log` исключены `.gitignore`); `MANIFEST.sha256` QA сохранён как `MANIFEST.qa_original.sha256`.

Других изменений нет. Исходные SHA256 из `MANIFEST.qa_original.sha256` относятся к байтам файлов QA до переноса; для 11 файлов без преобразований они совпадают с `MANIFEST.sha256`.

**Проверка хэшей.** `MANIFEST.sha256` вычислен по содержимому, записанному в Git (LF). Проверять на рабочей копии с LF (например, Linux или `core.autocrlf=false`): `cd docs/results/r5_cccc_n46_s2_d068 && sha256sum -c MANIFEST.sha256`; либо по объектам Git: `git show <коммит>:docs/results/r5_cccc_n46_s2_d068/<файл> | sha256sum`.

## Ограничения

- Независимость QA ограничена: исполнитель того же типа, одна платформа; эталон — тот же принятый дискретный оператор D2, поэтому проверяется реализация дискретной задачи, а не точность континуальной модели (QA_REPORT, разд. 11).
- Расхождение порядка 1e-6 с полным D2 объяснено QA как разница аппроксимации ранга N и полного двумерного решения; происхождение числа ≈1,1e-6 из прежних материалов не установлено (разд. 6).
- Неблокирующие наблюдения QA: в случае C (N = 6, a = 5, b = 1, 32×13) рабочий RN-5 консервативно отказывает (`RN5_UNRESOLVED`), хотя независимая RN-5 сертифицирует с запасом 1,03; при отказе RT-7 в `factors.csv` нет поэлементной пометки s = 2 (разд. 7, 13).
- Скрипты рассчитаны на расположение файлов в клоне QA (`scratch/d068_final`, `scratch/d068_s2`, `scratch/rn5_n46`, `scratch/rn5_negq`); без этих каталогов повторный запуск невозможен.
