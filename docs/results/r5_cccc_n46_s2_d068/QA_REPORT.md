## 3. Критерий (зафиксирован до сравнения, прежний)
- **Строгая граница:** ‖X̂ − X\*‖_F ≤ ‖ρ‖₂ / λ_low(K). Здесь K = PᵀAP, f = (q/D)Pᵀ1, P = I⊗G2.
  - Невязка ρ = KX̂ − f вычисляется **точно**, в дробях.
  - λ_low(K) ≥ (μx² + μy²)·Gersh_low(G2ᵀG2) — доказано.
- **PASS:** B_rel = граница / ‖X̂‖ ≤ 2·κ_up·n·u, где κ_up = Gersh_up(K)/λ_low(K) — **доказанная** верхняя оценка.
  - Эвристическая κ (по `eigvalsh`) только сообщается и ничего не решает.
- **Основание.** Критерий взят без изменений из QA R5-CCCC-N46-S2-D068-INDEPENDENT. Задание того QA требовало «границу ошибки зафиксировать до сравнения». Новых допусков нет; пороги N2–3 не переносятся.
- **Эталон для сравнения поля.** X_ref = X̂ − K_float⁻¹ρ — одно уточнение по точной невязке. Его погрешность доказана: ‖X_ref − X\*‖ ≤ ‖ρ_ref‖/λ_low.

## 6. Расхождение ≈1,1e-6 (случай B)
- **Происхождение числа.** Записи о нём в доступных материалах Builder и QA я не нашёл, поэтому само число не воспроизведено.
- **Решение X-системы.** Рабочий X совпадает с точным решением проецированной системы на фактическом G2 с доказанной относительной ошибкой поля около 3e-10 (δ_rel к уточнённому эталону 4,5e-15). Значит, на уровне 1e-6 это **не** ошибка решения X-системы и **не** обусловленность: κ_up = 6,3e4, κ·u ≈ 1e-11.
- **Отличие от полного D2.** От полного двумерного решения D2 (`kkvim_reference.r5_cccc_d2.solve`, собственная оценка ошибки 1e-20) рабочее поле отличается на δ_rel = 3,0e-6 (B), 7,2e-6 (D_N4), 2,4e-8 (D_N5). Это **другая задача**: поле ранга N после двух полушагов не равно решению на полном пространстве.
- **Подтверждение точным тождеством.** Π(w2) − Π(u) = ½c(w2 − u)ᵀA(w2 − u) + c(w2 − u)ᵀr_u:
  - для B энергетический член 1,2148e-11 совпадает с ΔΠ;
  - член невязки D2 равен −5e-24.
- **Вывод.** Расхождение порядка 1e-6 — разница аппроксимации ранга N (s = 2) и полного двумерного решения. Это не дефект реализации и не дефект эталона. Утверждения о сходимости из этого не следует.

## 11. Ограничения независимости
- **Тип исполнителя и платформа.** Исполнитель того же типа; одна платформа: Windows 10, Python 3.14.8, NumPy 2.5.4, SciPy 1.18.1.

- **Провенанс числа ≈1,1e-6** не установлен.
- **Пути в скриптах.** Скрипты используют пути внутри QA-клона: `s2_independent_check.py` — константы QA/BUILDER; остальные — относительно своего каталога. Для воспроизведения в другом клоне нужно поправить константы путей.
