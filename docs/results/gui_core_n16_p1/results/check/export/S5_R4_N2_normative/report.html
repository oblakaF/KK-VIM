7. Ограничения применимости

  • Реализация D-048 — ACCEPTED_LIMITED_ENGINEERING (D-049.7) в области D-047, D-048; результат — не сходимость (D-048.4, D-056.8). Каждый результат — PROVISIONAL / NOT_QUALIFIED.
  • NOT_QUALIFIED: c_d, c_rank, τ_set, c_DST, накопленная δ_f, константа QR, нормативный S-2, K_E; K_RESEARCH — временная защита (D-048.5, D-056.8).
  • При s → ∞ — не доказанная сходимость; единственность предела и независимость от старта не утверждаются (D-056.8; Q-020, Q-022, Q-025).
  • Линейная прямоугольная пластина Кирхгофа–Лява, однородный изотропный материал, SSSS, q = const, 0,2 ≤ b/a ≤ 5.
  • CCCC, другие закрепления и нагрузки, моменты и напряжения здесь не считаются.
  • Успешный запуск, стабилизация итераций и научная приёмка — разные статусы (AGENTS.md, разд. 4).
  • Теории Тимошенко и Редди в этой версии недоступны.
  • Результат — значения в узлах сетки n_x × n_y; максимальный |w| найден по узлам, а не между ними.
  • Моменты, напряжения и сравнение с эталонами в этой версии не выводятся.
  • Масштаб прогиба на 3D-виде увеличен только для изображения; все числа отчёта и файлов — без увеличения.
