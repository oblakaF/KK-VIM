Отчёт строго различает четыре объекта (docstring инструмента, O1–O4).

|---|---|---|

## 4. Точный ранг

### 4.1. O1: сохранённые факторы и W̃ (PROVEN, точная арифметика)

Алгоритм (собственный):
- двоично-рациональные значения → одна целочисленная матрица с общим показателем;
- безделительное исключение Bareiss, каждое деление проверено на точность;
- **свидетельство полного ранга** — номера строк ненулевого N × N минора. Его определитель вычислен двумя точными путями: целочисленным и формулой Лейбница над `Fraction` сохранённых double. Значения совпали и не равны 0;
- **свидетельство зависимости** — целочисленный вектор z с M z = 0, проверенный на всех строках.

| | AC | BC |
|---|---|---|
| rank Û = N (минор-свидетельство) | 656/656 | 656/656 |
| rank V̂ = N (минор-свидетельство) | 656/656 | 656/656 |
| вторая реализация (`r5_cccc_halfstep.exact_rank`) совпала | 1312/1312 | |
| rank W̃ = N; второй путь rank(G_U G_V) = N; det(G_U G_V) > 0 | 656/656 | 656/656 |
| минор W̃[I_U, I_V] из точных произведений = det Û_I · det V̂_J | 656/656 | 656/656 |
| после QR: rank V_n = rank G_n = rank W̃_n = N | 656/656 | 656/656 |

**Вывод (PROVEN):** поле, определённое сохранёнными binary64-факторами, имеет точный ранг N на всех 1312 полях — до и после QR. Свидетельства (`*_rank_certificate`) записаны в `rows.csv` и проверяются пересчётом минора по NPZ.

**Это не ранг O3 и O4.**

### 4.2. O3: точное решение дискретного полушага (CERTIFIED при принятых сертификатах)

- σ_N(W*_w) ≥ σ_N(W̃_w) − ‖Û_w‖₂·√h_s·b. Здесь b — **принятая** граница ‖x̂ − x*‖₂:
  - для AC — `j_set_bound_2` Q3;
  - для BC — `bc_set_bound_2_up` PR #41.

  Границы прочитаны, а не пересчитаны.
- Все величины — в точной арифметике с направленными границами.

| | AC | BC |
|---|---|---|
| rank W* = N сертифицирован | **656/656** | **656/656** |
| ε_step = ‖Û_w‖√h_s·b/σ₁(W̃_w), макс. | 2,3·10⁻⁷ | 1,7·10⁻⁶ |
| мин. ρ(W̃)·σ₁/(‖Û_w‖√h_s·b) (запас) | 106 (N = 3, s = 1) | **15,2** (1x0.5:1024x512, N = 3, s = 1) |

- **Что это означает:** точное решение каждой дискретной системы полушага, построенной на **сохранённом** заданном наборе, имеет ранг N.
- **Чего это не означает:** что ранг N имеет точная последовательность КК-МВИ (O4). Сохранённый Û отличается от набора точной последовательности на накопленную ошибку предыдущих полушагов, и её граница не выведена.
- Запас у BC меньше, чем у AC, потому что сертифицированные границы B-C (PR #41) шире границ уточнённого R-AC. Это свойство **границ**, а не обязательно фактической ошибки (PR #39: фактическая относительная ошибка набора B-C ≤ 5,2·10⁻¹¹).

  *Ред. Integrator (Н-1, Н-3; рецензия `bf9dcf8`, разд. 4.2, 8):*
  - *запасы 15,159 (BC) и 106,17 (AC) — отношение ρ(W̃) к **использованной сертифицированной границе** ошибки Q1b, а не к измеренной
    фактической ошибке; их уровень зависит от выбора λ_low в Q1b. Reviewer подтвердил сертификат альтернативной сертифицированной оценкой
    (собственные невязка и λ_low): CERTIFIED 1312/1312, минимальные запасы — **9,42** (BC) и **84,6** (AC). Данные QA этим не заменяются;*
  - *значение 5,2·10⁻¹¹ из PR #39 — максимум группы «пары, s = 2…8», а не всей выборки PR #39; уточнение ссылки и нормы — разд. 7, п. 3.*

### 4.3. O2: точный ранг матрицы fl(ÛV̂ᵀ) (PROVEN, малые сетки)

- Сформированная в double матрица поля на 160 + 160 малых полях имеет точный ранг **16…46, всегда > N** (320/320). Перекрёстная проверка: ранг по модулю 2⁶¹ − 1 не выше точного.
- Ранг равен min(число различных строк, число различных столбцов) в 312/320 случаях. Точная симметрия задачи дублирует строки и столбцы; в остальных 8 ранг ровно на 1 ниже этого минимума (OBSERVATION).
- σ_{N+1}/σ₁ сформированного поля (путь P3) ≤ 2,2·10⁻¹⁶, т. е. на уровне округления (OBSERVATION).
- **Следствие:** «точный ранг записанного в binary64 поля» без указания объекта бессмыслен. Ранг N имеет только произведение факторов (O1). Матрица O2 из-за округления имеет полный точный ранг по модулю симметрии.

### 5.3. Ошибка диагностики относительно точного ρ_N(W̃)

ρ(W̃) вычислено с сертификатом (относительная ширина ≤ 2⁻⁷²). Относительно W̃ ошибка факторов δ_f по определению равна 0. Поэтому расхождение ρ̂ − ρ(W̃) — чистая диагностическая часть (д) R4 5.2 п. 6.

| Путь | max |ρ̂ − ρ|/ρ, s ≥ 2 | max, s = 1 |
|---|---|---|
| P1 (numpy QR + SVD, путь Q3) | 9,9·10⁻¹⁶ | 3,3·10⁻¹³ |
| P2 (scipy geqp3 + gesvd) | 1,1·10⁻¹⁵ | 4,6·10⁻¹³ |
| P3 (SVD явного поля, малые сетки) | 1,4·10⁻¹³ | 2,6·10⁻¹³ |
| P1 против P2 | ≤ 9,7·10⁻¹⁶ | ≤ 1,4·10⁻¹³ |

- **Наблюдаемая константа** c_d,obs = |ρ̂ − ρ(W̃)|/(u·κ̂_rep):
  - вычисленные поля: медиана ≈ 8·10⁻⁴, максимум **0,171** (BC 1x0.2:160x32, N = 2, s = 1);
  - контроли: максимум **1,85** (F5, a = 1, N = 2, κ_rep = 1,4; абсолютная ошибка 2,9·10⁻¹⁶ при ρ = 0,84).
- Модель (д) R4 «|ρ̂ − ρ| ≲ c_d·u·κ_rep» на этих данных **не опровергнута**. Строгая константа c_d не установлена (стандартные оценки обратной устойчивости QR/SVD без источника в библиотеке проекта; ОК-5).
- cond(A) до QR (P1) против точного cond(A_V): относительная ошибка ≤ 1,5·10⁻¹⁵ (s ≥ 2), ≤ 6,5·10⁻¹³ (s = 1).

## 7. Пригодность формы ρ_N > K·u·κ_rep (PL §4.5) — OBSERVATION, K не выбирается

| Класс | Число | t = ρ̂_N/(u·κ̂_rep) |
|---|---|---|
| вычисленные поля AC | 656 | 9,6·10¹⁰…4,1·10¹³ |
| вычисленные поля BC | 656 | 9,9·10¹⁰…4,1·10¹³ |
| контроли, мат. вырожденные | 42 | 4,4·10⁻⁸…**0,70** |

| контроли, мат. полноранговые | 52 | 1,1·10⁻⁶…5,4·10¹⁵ |

1. **На этих данных** вычисленные поля отделены от математически вырожденных контролей разрывом **≈ 11,1 порядка** (мин. 9,6·10¹⁰ против макс. 0,70). Любое K из этого промежутка разделило бы **эти два множества**. Это наблюдение, а не квалификация K.
2. **Форма не отделяет математически полный ранг от вырожденного**, если σ_N ниже уровня различимости: 9 полноранговых контролей имеют t ≤ max t вырожденных. Это совпадает с R4 5.2 п. 9. Такой ранг — «численно неразличимый», и он не объявляется ни потерянным, ни установленным.
3. **Главное ограничение формы — отсутствие δ_f.**
   - Для вычисленных полей определяющая погрешность — ошибка факторов. Её сертифицированная граница только для **текущего** полушага: ε_step до 2,3·10⁻⁷ (AC) и 1,7·10⁻⁶ (BC).

     - *«на 9–10 порядков» — сравнение с u·κ_rep **сертифицированной границы** ε_step ошибки текущего полушага, а не измеренной
       фактической ошибки;*
     - *наблюдение Reviewer о фактической ошибке. По PR #39 (`docs/R5_CCCC_Q4_BC_REFERENCE_AUDIT.qa-report.md`) фактическая

       и численного решения. Она не является ни
       чистой модальной ошибкой, ни оценкой накопленной ошибки собственной последовательности B-C (δ_f, составляющая (г) рецензии, разд. 7).
