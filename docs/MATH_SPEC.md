### 2.2. Исчезновение интеграла определителя гессиана и упрощение энергии

**[ВЫВОД ПРОЕКТА В-4] Лемма 1.** Пусть Ω — прямоугольник, w ∈ C³(Ω̄) и **след w на ∂Ω равен нулю**. Тогда

$$\iint_\Omega\bigl(w_{xx}w_{yy}-w_{xy}^2\bigr)\,dx\,dy=0.$$

*Доказательство.* w_xx w_yy − w_xy² = ∂ₓ(wₓw_yy) − ∂_y(wₓw_xy): ∂ₓ(wₓw_yy) = w_xx w_yy + wₓw_xyy, ∂_y(wₓw_xy) = w_xy² + wₓw_xyy. Поле
(wₓw_yy, −wₓw_xy) ∈ C¹(Ω̄); по формуле Гаусса–Остроградского интеграл равен ∮(wₓw_yy nₓ − wₓw_xy n_y) ds. На x = 0, a (n_y = 0): w ≡ 0 вдоль
стороны ⇒ касательная вторая производная w_yy = 0. На y = 0, b (nₓ = 0): w ≡ 0 вдоль стороны ⇒ касательная производная wₓ = 0. Углы — мера нуль. ∎

**Предпосылки и границы применимости Леммы 1:**
- нужны: прямолинейные стороны (касательные производные вдоль стороны — производные по x или y), w ∈ C³(Ω̄), w = 0 на ∂Ω; условия на ∂ₙw или ∂ₙ²w
  **не нужны** — лемма одинаково верна для D(T_SS) и D(T_CC);
- **продолжение по непрерывности:** функционал w ↦ ∬(w_xx w_yy − w_xy²) непрерывен в W₂²(Ω), поэтому равенство сохраняется на замыкании D(T_SS)
  в W₂²(Ω), т. е. на H_T (разд. 2.4); для CCCC — на W̊₂²(Ω) (разд. 10);
- **не утверждается** для всего W₂² ∩ W̊₂¹ без доказательства плотности D(T_SS) в нём (разд. 2.4);
- для функций, не обращающихся в нуль на ∂Ω (например, свободные края), лемма неверна — вне части A.

**[ВЫВОД ПРОЕКТА В-5] Лемма 1′ (произведения).** Если w = X₁(x)Y₁(y), v = X₂(x)Y₂(y), X_j ∈ W₂²(0, a), Y_j ∈ W₂²(0, b), X_j(0) = X_j(a) = 0,
Y_j(0) = Y_j(b) = 0 (следы на концах), то b(w, v) := ∬(w_xx v_yy + w_yy v_xx − 2w_xy v_xy) = 0. *Доказательство:* ∫X₁″X₂ = −∫X₁′X₂′ и
∫Y₁Y₂″ = −∫Y₁′Y₂′ (внеинтегральные члены — нули следов), поэтому ∬w_xx v_yy = ∫X₁′X₂′∫Y₁′Y₂′ = ∬w_xy v_xy; так же ∬w_yy v_xx = ∬w_xy v_xy. ∎
Для двойного синусного ряда — [АВТОР L-107, с. 381]. Для пространства из Леммы 1 симметричная форма b(w, v) обращается в нуль по поляризации:
b(w, v) = ½[b(w + v, w + v) − b(w, w) − b(v, v)], b(w, w) = 2∬(w_xx w_yy − w_xy²) = 0.

**Следствие (упрощение энергии).** Для w, v ∈ H_T (в том числе D(T_SS)) и для произведений Леммы 1′

$$a(w,v)=D\iint_\Omega\Delta w\,\Delta v\,dx\,dy,\qquad I(w)=\Pi(w):=\tfrac12a(w,w)-(q,w).$$

ν в a(·,·) не входит; ν входит только в моменты (разд. 8).

### 2.3. Симметрия, положительная определённость, коэрцитивность — раздельно

**[ВЫВОД ПРОЕКТА В-6] Симметрия.** Для w, v ∈ D(T_SS) по формуле Грина (Tw, v) = D∬ΔwΔv + D∮(v∂ₙΔw − Δw∂ₙv) ds. На ∂Ω v = 0, а
Δw = w_nn + w_ττ = 0 (w_nn = 0 по условию, w_ττ = 0 вдоль стороны). Итого (Tw, v) = a(w, v) = (w, Tv).

**[ВЫВОД ПРОЕКТА В-7] Положительная определённость — оценка в L₂.** φ_mn = sin(mπx/a)sin(nπy/b), ‖φ_mn‖² = ab/4; {φ_mn} ортогональна и полна в L₂(Ω) —
стандартный факт анализа (произведение полных систем sin(mπx/a) в L₂(0, a) и sin(nπy/b) в L₂(0, b)); L-107 (128) [с. 128] это разложение лишь
использует, но не доказывает (Н-2). Для w ∈ D(T_SS), c_mn = (4/ab)(w, φ_mn): (Δw, φ_mn) = (w, Δφ_mn) — внеинтегральный член
∮(φ_mn∂ₙw − w∂ₙφ_mn) ds = 0 при w = φ_mn = 0 на ∂Ω; Δφ_mn = −λ_mn φ_mn, λ_mn = π²(m²/a² + n²/b²). По Парсевалю

$$\|\Delta w\|^2=\frac{ab}4\sum_{m,n}\lambda_{mn}^2c_{mn}^2\ \ge\ \lambda_{11}^2\|w\|^2,\qquad (Tw,w)=D\|\Delta w\|^2\ge D\lambda_{11}^2\|w\|^2,\quad \lambda_{11}=\pi^2\Bigl(\frac1{a^2}+\frac1{b^2}\Bigr).$$

Это условие Теоремы 1 P81 («let operator T be positive definite» [АВТОР P81, с. 367]). Для SSSS у авторов утверждения нет — вывод проекта.

**[ВЫВОД ПРОЕКТА В-8] Коэрцитивность — оценка в W₂²(Ω).** Норма: ‖w‖²_{W₂²(Ω)} := ‖w‖² + ‖∇w‖² + |w|²_{W₂²},
|w|²_{W₂²} := ‖w_xx‖² + 2‖w_xy‖² + ‖w_yy‖² — смешанная производная учитывается **дважды**; в норме P81 (с. 368) суммирование по мультииндексам,
и константы там иные. На D(T_SS) по Лемме 1 |w|²_{W₂²} = ‖w_xx‖² + 2‖w_xy‖² + ‖w_yy‖² = ‖Δw‖²; далее
‖∇w‖² = −(w, Δw) ≤ ‖w‖‖Δw‖ ≤ λ₁₁⁻¹‖Δw‖², ‖w‖² ≤ λ₁₁⁻²‖Δw‖². Итого

$$\|\Delta w\|^2\ \le\ \|w\|^2_{W_2^2(\Omega)}\ \le\ \bigl(1+\lambda_{11}^{-1}+\lambda_{11}^{-2}\bigr)\|\Delta w\|^2,\qquad a(w,w)\ \ge\ \frac{D}{1+\lambda_{11}^{-1}+\lambda_{11}^{-2}}\|w\|^2_{W_2^2(\Omega)} .$$

Положительная определённость (В-7) — нижняя оценка в L₂; коэрцитивность (В-8) — в W₂²; это разные свойства. Двумерная коэрцитивность для части A
нужна только для вложения H_T ⊂ W₂² (разд. 2.4); разрешимость одномерных задач опирается на одномерную коэрцитивность (разд. 6.2).

### 2.4. Энергетическое пространство, вложения, существование и единственность

**[ВЫВОД ПРОЕКТА В-9] H_T и вложения (R-3).** H_T — пополнение D(T_SS) по ‖w‖_{H_T} = a(w, w)^{1/2} = D^{1/2}‖Δw‖ (как в P81 [АВТОР P81, с. 367:
«the energy space of operator T»]); [·,·]_{H_T} — продолжение a(·,·).
- **Вложение в L₂:** по В-7 ‖w‖ ≤ (D^{1/2}λ₁₁)⁻¹‖w‖_{H_T} на D(T); фундаментальная в H_T последовательность фундаментальна в L₂, отображение J: H_T → L₂(Ω)
  непрерывно. **Инъективность:** если w_n → w в H_T и w_n → 0 в L₂, то для любой φ ∈ D(T) [w, φ]_{H_T} = lim(w_n, Tφ) = 0; D(T) плотно в H_T ⇒ w = 0.
- **Вложение в W₂²:** по В-8 H_T непрерывно и инъективно отождествляется с замыканием D(T_SS) в W₂²(Ω); оно лежит в W₂²(Ω) ∩ W̊₂¹(Ω) (следы
  непрерывны в W₂²).
- **Не утверждается:** H_T = W₂²(Ω) ∩ W̊₂¹(Ω). Для этого нужна плотность D(T_SS) в W₂² ∩ W̊₂¹; источника в библиотеке нет; для части A не требуется.

**[ВЫВОД ПРОЕКТА В-10] Ограниченность функционала, существование и единственность.** |(q, v)| ≤ ‖q‖‖v‖ ≤ ‖q‖(D^{1/2}λ₁₁)⁻¹‖v‖_{H_T} — функционал
ограничен на H_T (используется вложение в L₂). Форма [·,·]_{H_T} — скалярное произведение H_T (ограничена и коэрцитивна с константой 1).
По теореме Рисса (частный случай Лакса–Мильграма) существует единственное ω₀ ∈ H_T: [v, ω₀]_{H_T} = (q, v) для всех v ∈ H_T — обобщённое решение
(образец определения — [АВТОР P80, с. 2186, (3)] для первой краевой задачи). ω₀ — единственный минимум Π на H_T; Π(ω₀) = −½‖ω₀‖²_{H_T} = −½(q, ω₀).

**[ВЫВОД ПРОЕКТА В-11] ω₀ ∉ C⁴(Ω̄) при q = const ≠ 0.** Шаг 1 (Н-3): если обобщённое ω₀ ∈ C⁴(Ω̄), то по формуле Грина в [v, ω₀] = (q, v):
пробные v ∈ C_c^∞(Ω) дают DΔ²ω₀ = q в Ω; затем пробные v ∈ D(T_SS) с произвольной ∂ₙv на стороне дают Δω₀ = 0 на сторонах, т. е. ω₀ — классическое
решение. Шаг 2:
для классического решения v = Δω₀ = 0 на ∂Ω (111) и Δv = q/D. В угловой точке v ≡ 0 вдоль обеих
сторон ⇒ v_xx = v_yy = 0 ⇒ Δv = 0 ≠ q/D. Значит, ω₀ — только обобщённое решение; проекционные свойства КК-МВИ (разд. 6) ω₀ ∈ D(T) не требуют.
Область (Н-3): достаточно, чтобы q была непрерывна в угловой точке и q(угол) ≠ 0; речь идёт о гладкости **вплоть до границы**, а не внутри Ω. Для CCCC
утверждение не делается.

### 2.5. Безразмерные величины (D-009)

[ВЫВОД ПРОЕКТА В-12] (равномерная q = const, разд. 1.6) Опорная длина — a; отношение сторон r = b/a; для q ≠ 0

$$\bar x=\frac xa,\quad \bar y=\frac yb,\quad \bar w=\frac{wD}{qa^4},\quad \bar M_x=\frac{M_x}{qa^2},\quad \bar M_y=\frac{M_y}{qa^2}\ \ \Bigl(\bar M_{xy}=\frac{M_{xy}}{qa^2}\Bigr).$$

- Согласовано с NAVIER_REFERENCE_SPEC.md, разд. 6: w̄ = wD/(qa⁴), w_max = α qa⁴/D (L-107, (141)), (M_x)_max = β qa² (L-107, с. 138, (o)); x̄ = x/a, ȳ = y/b.

  (Â = ∫₀¹X̂², B̂ = ∫₀¹X̂′², Ĉ = ∫₀¹X̂″², F̂ = ∫₀¹X̂ — интегралы по x̄), d/dy = (1/b)d/dȳ; умножая сильную форму 4.3 на a³/D:

### 2.6. Ряд Навье — это обобщённое решение ω₀ (Б-1)

[АВТОР L-107, с. 129, (131)] прогиб при равномерной нагрузке:
w = (16q/(π⁶D)) Σ_{m, n нечёт} sin(mπx/a)sin(nπy/b)/[mn(m²/a² + n²/b²)²]; коэффициенты нагрузки a_mn = 16q/(π²mn) [(c), с. 129] в разложении (128).

**[ВЫВОД ПРОЕКТА В-27] Совпадение ряда (131) с ω₀ (q = const).** Классического решения в C⁴(Ω̄) нет (В-11), поэтому отождествление требует
отдельного доказательства в слабой постановке; C⁴-регулярность ω₀ **не утверждается**. Пусть w_M — квадратная частичная сумма (131) (m, n ≤ M,
нечётные), q_M — частичная сумма (128) с теми же индексами.
1. **w_M ∈ D(T_SS):** конечная сумма функций φ_mn ∈ C^∞(Ω̄), каждая из которых удовлетворяет w = ∂ₙ²w = 0 на сторонах.
2. **Tw_M = q_M:** Δ²φ_mn = λ_mn²φ_mn, λ_mn² = π⁴(m²/a² + n²/b²)², поэтому коэффициент Tw_M при φ_mn равен D·λ_mn²·16q/(π⁶Dmn(m²/a² + n²/b²)²) =
   16q/(π²mn) = a_mn. По полноте {φ_mn} в L₂(Ω) (В-7) q_M → q в L₂.
3. **Фундаментальность в H_T:** ‖w_M − w_K‖²_{H_T} = (T(w_M − w_K), w_M − w_K) = (q_M − q_K, w_M − w_K) ≤ ‖q_M − q_K‖·(D^{1/2}λ₁₁)⁻¹‖w_M − w_K‖_{H_T}
   (вложение В-9), откуда ‖w_M − w_K‖_{H_T} ≤ ‖q_M − q_K‖/(D^{1/2}λ₁₁) → 0. Пусть w* — предел в H_T.
4. **Слабое уравнение и единственность:** для v ∈ D(T_SS) [v, w*]_{H_T} = lim[v, w_M] = lim(v, Tw_M) = lim(v, q_M) = (v, q) (симметрия В-6). Обе части
   непрерывны по v в H_T (В-10), D(T_SS) плотно в H_T, поэтому [v, w*] = (q, v) для всех v ∈ H_T. По единственности (В-10) **w* = ω₀**.
5. **Значения в точках:** H_T непрерывно вкладывается в W₂²(Ω) (В-9), а W₂²(Ω) ⊂ C(Ω̄) для прямоугольника (теорема вложения Соболева в размерности 2 —
   стандартный факт анализа; в библиотеке не цитируется). Поэтому w_M → ω₀ равномерно на Ω̄. Ряд (131) сходится абсолютно и равномерно (мажоранта
   Σ1/[mn(m²/a² + n²/b²)²] ≤ (a²b²/4)Σ1/(m³n³) < ∞), и значения непрерывного представителя ω₀ в любой точке (центр, узлы сетки) равны сумме ряда (131).
6. **Следствия:** коэффициенты ω₀ по φ_mn в L₂ — коэффициенты ряда (131); (q, ω₀) = lim(q, w_M), т. е. ∬ω₀ = (64qab/(π⁸D))Σ_{m,n нечёт}1/[m²n²(m²/a² + n²/b²)²]
   (∬φ_mn = 4ab/(π²mn) при нечётных m, n); Π(ω₀) = −½(q, ω₀) (В-10).

Отсюда сравнение КК-МВИ с эталоном Навье (D-024, D-025; NAVIER_REFERENCE_SPEC.md) — сравнение с тем же ω₀, относительно которого доказаны проекционность
и энергетическое тождество (разд. 6, 7). Мера точности на этой основе — разд. 7.4.

## 3. Разделённое представление и масштабная неоднозначность

[АВТОР P81, с. 366, (2); с. 367, Definition 2]: ω_N = Σ_{i=1}^{N} u_i(x)v_i(y); первое приближение ω₁ = u(x)v(y). Для части A

Следствия (Н-5): (а) нормировка множителя **в любой момент** между полушагами не меняет последовательности полей {w⁽ˢ⁾}, поэтому её правило можно
выбрать в NUMERICAL_SPEC.md без ограничений со стороны математики; (б) зависимость масштабов множителей от X⁰ точная: при X⁰ → cX⁰ все Y^{2k+1} → Y^{2k+1}/c,

**Корректные величины для контроля** (все инвариантны):
- поле w⁽ˢ⁾ и его значения в точках; ε_s = ‖w⁽ˢ⁾ − w⁽ˢ⁻¹⁾‖ в выбранной норме поля (L₂, максимум по точкам, энергетическая ‖·‖_{H_T}) и относительная

### 4.1. Порядок полушагов и счётчики

[АВТОР P81, с. 367]: задана система функций одной переменной u⁰(x); из первых уравнений (3) находится v¹(y), затем u²(x), затем v³(y) «and so on»;

### 4.2. Коэффициенты и их зависимость от a, b

Для заданного X ∈ V_a, X ≢ 0, и для заданного Y ∈ V_b, Y ≢ 0:

$$A_X=\int_0^aX^2dx,\ \ B_X=\int_0^a(X')^2dx,\ \ C_X=\int_0^a(X'')^2dx,\ \ F_X=\int_0^a qX\,dx;$$
$$A_Y=\int_0^bY^2dy,\ \ B_Y=\int_0^b(Y')^2dy,\ \ C_Y=\int_0^b(Y'')^2dy,\ \ F_Y=\int_0^b qY\,dy.$$

Коэффициенты Y-полушага — интегралы по (0, a), а его пространство и граничные условия — на (0, b); у X-полушага наоборот. При q = const
F_X = q∫X, F_Y = q∫Y; при q ∈ L₂ правая часть — ∬qXỸ (∬qX̃Y).

### 4.3. Y-полушаг (s нечётно; задан X = X^{s−1})

M_s = {X(x)Ỹ(y): Ỹ ∈ V_b}.

**Слабая (проекционная) форма** [ВЫВОД ПРОЕКТА В-15]: найти Y ∈ V_b, для которой

$$a_X(Y,\tilde Y):=D\Bigl[A_X\!\int_0^b\!Y''\tilde Y''dy+2B_X\!\int_0^b\!Y'\tilde Y'dy+C_X\!\int_0^b\!Y\tilde Y\,dy\Bigr]=F_X\!\int_0^b\!\tilde Y\,dy=:\ell_X(\tilde Y)\qquad\forall\tilde Y\in V_b.$$

*Вывод.* По Лемме 1′ a(XY, XỸ) = D∬(X″Y + XY″)(X″Ỹ + XỸ″) = D[A_X∫Y″Ỹ″ + ∫XX″(∫YỸ″ + ∫Y″Ỹ) + C_X∫YỸ]; ∫XX″ = −B_X, ∫YỸ″ = ∫Y″Ỹ = −∫Y′Ỹ′;
(q, XỸ) = F_X∫Ỹ. Это первое уравнение (4) P81 в форме (6) [АВТОР P81, с. 367] и уравнение (3) P82 с проекцией P₁ на M_s [АВТОР P82, с. 78].

**Сильная форма** [ВЫВОД ПРОЕКТА В-16]:

$$D\bigl[A_X\,Y''''-2B_X\,Y''+C_X\,Y\bigr]=F_X,\quad 0<y<b;\qquad Y(0)=Y(b)=0,\quad Y''(0)=Y''(b)=0.$$

Форма P81 с коэффициентами ∫XX″, ∫XX⁗ (SOURCE_MAP.md, разд. 6) совпадает с ней при условиях разд. 5.3.

**Приближение после полушага:** w⁽ˢ⁾ = X^{s−1}(x)Y^{s}(y).

### 4.4. X-полушаг (s чётно; задан Y = Y^{s−1})

M_s = {X̃(x)Y(y): X̃ ∈ V_a}. Слабая форма: найти X ∈ V_a,

$$D\Bigl[A_Y\!\int_0^a\!X''\tilde X''dx+2B_Y\!\int_0^a\!X'\tilde X'dx+C_Y\!\int_0^a\!X\tilde X\,dx\Bigr]=F_Y\!\int_0^a\!\tilde X\,dx\qquad\forall\tilde X\in V_a;$$

сильная форма: D[A_Y X⁗ − 2B_Y X″ + C_Y X] = F_Y, 0 < x < a; X(0) = X(a) = 0, X″(0) = X″(a) = 0. Второе уравнение (4) P81, (4) P82.
**Приближение:** w⁽ˢ⁾ = X^{s}(x)Y^{s−1}(y).

### 4.5. Полный цикл и состояния приближения

| s | k_пр | полушаг | задано | вычислено | w⁽ˢ⁾ |
|---|---|---|---|---|---|
| 1 | 0 | Y | X⁰ | Y¹ | X⁰Y¹ — метод Канторовича–Власова [АВТОР P82, с. 80] |
| 2 | 1 | X | Y¹ | X² | X²Y¹ |
| 3 | 1 | Y | X² | Y³ | X²Y³ |
| 4 | 2 | X | Y³ | X⁴ | X⁴Y³ |
| нечётное | (s − 1)/2 | Y | X^{s−1} | Y^{s} | X^{s−1}Y^{s} |
| чётное | s/2 | X | Y^{s−1} | X^{s} | X^{s}Y^{s−1} |

Полный цикл с номером k_пр ≥ 1 — полушаги s = 2k_пр − 1 (Y) и s = 2k_пр (X); результат «после k_пр циклов» — w⁽²ᵏ⁾; состояние s = 1 обозначается
s = 1, k_пр = 0. Индексы публикаций — только через s (разд. 0.3). Критерии остановки — NUMERICAL_SPEC.md (Q-009), по величинам разд. 3.

### 4.6. Допустимые начальные функции

SSSS: X⁰(x) = sin(πx/a) (разд. 5.1). CCCC: X⁰(x) = sin²(πx/a) (разд. 10). X⁰ сама приближением не является.

**Общее условие допустимости в части A (Б-2)** — все три требования обязательны:
1. X⁰ ∈ C⁴[0, a] и удовлетворяет условиям задачи по x: X⁰ = X⁰″ = 0 (SSSS) или X⁰ = X⁰′ = 0 (CCCC) при x = 0, a (предпосылка разд. 6.4);
2. X⁰ ≢ 0;
3. **невырожденность старта:** правая часть первого полушага не равна тождественно нулю: ∬q X⁰Ỹ dx dy ≢ 0 на V_b, т. е. ∫₀ᵃq(x, ·)X⁰(x)dx ≢ 0;
   **при ненулевой постоянной нагрузке q = const ≠ 0 —**

$$\int_0^a X^0(x)\,dx\ne0 .$$

[ВЫВОД ПРОЕКТА, к В-17, В-32] Проверка: sin(πx/a) — ∫₀ᵃ = 2a/π ≠ 0 (F = 2qa/π); sin²(πx/a) — ∫₀ᵃ = a/2 ≠ 0 (F = qa/2). Без условия 3 алгоритм может
выродиться: например, X⁰ = sin(2πx/a) удовлетворяет 1–2, но ∫X⁰ = 0, тогда Y¹ ≡ 0, w⁽¹⁾ = 0, и на s = 2 A_Y = 0 — одномерная задача некорректна (рецензия, Б-2).
Требование авторов — [АВТОР P82, с. 78] «∀i φ_i⁰(x) ∈ W̊₂²(x)» (для защемления) и [АВТОР P81, с. 367] u⁰(x) ∈ H_T(x); условие 3 у авторов не сформулировано
— это вывод проекта.

## 5. SSSS: допустимость, условия f = 0, f″ = 0, формы и их эквивалентность

### 5.1. Допустимость X⁰ = sin(πx/a)

[ВЫВОД ПРОЕКТА В-17] X⁰ ∈ C^∞[0, a]; X⁰(0) = X⁰(a) = 0; X⁰″ = −(π/a)²X⁰ ⇒ X⁰″(0) = X⁰″(a) = 0; X⁰ ∈ V_a, X⁰ ≢ 0. Требование P82 «∈ W̊₂²(x)» относится

$$A=\frac a2,\qquad B=\frac{\pi^2}{2a},\qquad C=\frac{\pi^4}{2a^3},\qquad F=\frac{2qa}{\pi}.$$

### 5.2. Одномерные условия f = 0, f″ = 0

[ВЫВОД ПРОЕКТА В-18] Из двумерных условий SSSS (разд. 1.4) при заданном множителе X ≢ 0:
- край y = 0, b: w = XY = 0 ⇒ **Y = 0**; ∂²w/∂y² = XY″ = 0 ⇒ **Y″ = 0**. По (110): w_yy + νw_xx = XY″ + νX″Y = XY″ при Y = 0 — тот же результат, без ν;
- край x = 0, a: w = 0 и w_xx = X″Y = 0 выполняются за счёт заданного X (X = X″ = 0 на концах) — при любом Y.

Для X-полушага симметрично: **X = 0, X″ = 0** при x = 0, a. Согласуется с Remark 4 P81 («in the first step we obtain a system of functions satisfying
the boundary conditions with respect to one of the variables» [АВТОР P81, с. 369]). f = 0 — **главное** условие (входит в V_b, V_a); f″ = 0 —
**естественное** (разд. 6.3).

### 5.3. Условия эквивалентности сильной и слабой форм

[ВЫВОД ПРОЕКТА В-19] Для Y-полушага слабая форма 4.3 и сильная форма 4.3 эквивалентны при:
1. X ∈ V_a, X ≢ 0 (A_X > 0);
2. q ∈ L₂ (R2: q = const);
3. для записи коэффициентов в форме P81 (∫XX″, ∫XX⁗): X ∈ C⁴[0, a] (или W₂⁴) и X′X″ = 0 на концах, так как ∫XX⁗ = [XX‴ − X′X″]₀ᵃ + ∫(X″)². Для SSSS
   выполнено (X″ = 0). Если X лишь из W₂², ∫XX⁗ не определён, используются A, B, C слабой формы — [ИНЖЕНЕРНЫЙ ВЫБОР] NUMERICAL_SPEC.md (Q-011).

При условиях 1–2 слабое решение **Y ∈ W₂⁴(0, b)** удовлетворяет сильной задаче почти всюду и условиям Y = Y″ = 0; **при q = const —
Y ∈ C^∞[0, b]** и сильная задача выполняется классически (Б-3). Обратно, классическое решение — слабое (разд. 6.3).

## 6. Строгое обоснование одномерных задач (SSSS)

### 6.1. Исключение интеграла определителя гессиана

Лемма 1 (В-4) — для C³(Ω̄) с нулевым следом на ∂Ω и её продолжение на H_T; Лемма 1′ (В-5) — для произведений с множителями W₂², равными нулю на
концах. Одномерная форма a_X (разд. 4.3) получена по Лемме 1′ и от Леммы 1 не зависит.

### 6.2. Ограниченность, коэрцитивность, Лакс–Мильграм

[ВЫВОД ПРОЕКТА В-20] Пусть X ∈ V_a, X ≢ 0.
1. **V_b — гильбертово пространство:** замкнутое подпространство W₂²(0, b) (следы Ỹ(0), Ỹ(b) непрерывны на W₂²).
2. **Ограниченность формы (R-3):** |a_X(Y, Ỹ)| ≤ D·max(A_X, 2B_X, C_X)(‖Y″‖‖Ỹ″‖ + ‖Y′‖‖Ỹ′‖ + ‖Y‖‖Ỹ‖) ≤ D·max(A_X, 2B_X, C_X)‖Y‖_{W₂²}‖Ỹ‖_{W₂²}
   (неравенство Коши–Буняковского дважды).
3. **Ограниченность функционала (R-3):** |ℓ_X(Ỹ)| = |F_X∫Ỹ| ≤ |F_X|b^{1/2}‖Ỹ‖ ≤ |F_X|b^{1/2}‖Ỹ‖_{W₂²}; при q ∈ L₂ — |∬qXỸ| ≤ ‖q‖_{L₂(Ω)}‖X‖‖Ỹ‖.
4. **Коэрцитивность:** для Ỹ ∈ V_b по неравенству Виртингера ‖Ỹ‖ ≤ (b/π)‖Ỹ′‖ (Ỹ = 0 на концах) и ‖Ỹ′‖ ≤ (b/π)‖Ỹ″‖ (∫₀ᵇỸ′dy = Ỹ(b) − Ỹ(0) = 0), откуда

$$a_X(\tilde Y,\tilde Y)\ \ge\ DA_X\|\tilde Y''\|^2\ \ge\ \frac{DA_X}{1+(b/\pi)^2+(b/\pi)^4}\,\|\tilde Y\|^2_{W_2^2(0,b)} .$$

5. **Существование и единственность:** по теореме Лакса–Мильграма (форма симметрична — достаточна теорема Рисса) существует единственное Y ∈ V_b,
   решающее слабую задачу; ‖Y‖_{W₂²} ≤ (1 + (b/π)² + (b/π)⁴)|F_X|b^{1/2}/(DA_X). Этим для N = 1 обосновывается допущение P81 «which we assume to be
   solvable» [АВТОР P81, с. 367, Remark 1].

Различие свойств: положительная определённость T (В-7) — оценка в L₂ на D(T), условие Теоремы 1 P81; коэрцитивность (п. 4) — оценка в W₂²(0, b) на V_b;
существование и единственность — следствие п. 1–4. Одной положительности a_X(Ỹ, Ỹ) > 0 при Ỹ ≢ 0 для бесконечномерного V_b недостаточно. Для X-полушага —
то же с заменой b → a, V_b → V_a, X → Y.

### 6.3. Регулярность одномерного решения и естественное условие

[ВЫВОД ПРОЕКТА В-21] Для Ỹ ∈ C_c^∞(0, b) слабая форма даёт A_X Y⁗ − 2B_X Y″ + C_X Y = F_X(y)/D в смысле распределений (при q ∈ L₂(Ω)
F_X(y) = ∫₀ᵃq(x, y)X(x)dx ∈ L₂(0, b)); отсюда Y⁗ ∈ L₂, **Y ∈ W₂⁴(0, b) ⊂ C³[0, b] — при q ∈ L₂**. **При q = const** правая часть постоянна, и по индукции
Y ∈ C^∞[0, b] (Б-3). Интегрируя по частям при произвольной Ỹ ∈ V_b: a_X(Y, Ỹ) − ℓ_X(Ỹ) = DA_X[Y″Ỹ′]₀ᵇ = 0. Значения
Ỹ′(0), Ỹ′(b) в V_b произвольны, поэтому Y″(0) = Y″(b) = 0. Обратно, классическое решение сильной задачи удовлетворяет слабой форме.

### 6.4. Регулярность координатного множителя, плотность, замкнутость подпространства (R-2)

**Предпосылка полушага s.** Заданный множитель — X^{s−1} ∈ C⁴[0, a] с X = X″ = 0 при x = 0, a (для X-полушага — Y^{s−1} ∈ C⁴[0, b] с Y = Y″ = 0
при y = 0, b) — и **≢ 0**.

**Лемма о полушаге** (п. 1–4 ниже): если предпосылка полушага s выполнена, то верны п. 1–4; в частности w⁽ˢ⁾ = P_{M_s}ω₀ ∈ D(T_SS) при q = const.

[ВЫВОД ПРОЕКТА В-22] **Совместная индукция (Б-2): гладкость, проекционность, невырожденность и энергия.** Пусть q = const ≠ 0 (R2, R3; D-005) и X⁰
допустима по разд. 4.6 (условия 1–3). Утверждение P(s), s ≥ 1: *предпосылка полушага s выполнена*.
- **База P(1):** X⁰ ∈ C⁴ с условиями задачи и X⁰ ≢ 0 (4.6, условия 1–2).
- **Шаг P(s) ⇒ P(s + 1):**
  1. A > 0, одномерная задача полушага s однозначно разрешима (В-20);
  2. вычисленный множитель принадлежит C^∞ и удовлетворяет условиям задачи на своём отрезке (В-21 при q = const; главное условие — из V, естественное —
     из 6.3);
  3. по Лемме о полушаге w⁽ˢ⁾ = P_{M_s}ω₀ ∈ D(T_SS);
  4. энергия: Π(w⁽¹⁾) = −½‖w⁽¹⁾‖²_{H_T} (В-23), и w⁽¹⁾ ≢ 0 — по 4.6, условие 3: ℓ_{X⁰} ≢ 0, поэтому Y¹ ≢ 0 (иначе a_{X⁰}(Y¹, ·) ≡ 0 = ℓ_{X⁰}), а X⁰ ≢ 0;
     значит Π(w⁽¹⁾) < 0. При s ≥ 2 по В-24, применённому к полушагам 2, …, s (каждый из них удовлетворяет предпосылке по P(2), …, P(s)),
     Π(w⁽ˢ⁾) ≤ Π(w⁽ˢ⁻¹⁾) ≤ … ≤ Π(w⁽¹⁾) < 0;
  5. отсюда w⁽ˢ⁾ ≢ 0; так как w⁽ˢ⁾ — произведение заданного и вычисленного множителей, **вычисленный множитель ≢ 0**. Он и есть заданный множитель
     полушага s + 1, что вместе с п. 2 даёт P(s + 1).
- Знакопостоянство множителей нигде не используется и не утверждается.

**При q ∈ L₂** вычисленный множитель лишь из W₂⁴ ⊂ C³; предпосылка на s ≥ 2 не доказана, и п. 2–4 Леммы для s ≥ 2 не утверждаются (Б-3). Для s = 1 заданный
множитель X⁰ гладкий при любой q, поэтому при q ∈ L₂(Ω) и условиях 1–2 разд. 4.6 верны п. 1–3 для M₁ и проекционность w⁽¹⁾ = P_{M₁}ω₀ (первая часть п. 4);
при этом Y¹ ∈ W₂⁴(0, b). Утверждения w⁽¹⁾ ∈ D(T_SS) и совпадение с уравнением (4) P81 в классическом смысле (последняя фраза п. 4) при q ∈ L₂ **не доказаны**

Пункты Леммы о полушаге:
1. **Плотность.** Для Ỹ ∈ V_b частичные суммы Ỹ_n = Σ_{j≤n} d_j sin(jπy/b), d_j = (2/b)(Ỹ, sin(jπy/b)), сходятся к Ỹ в W₂²(0, b): (Ỹ″, sin(jπy/b)) =

## 7. Энергетический тест Q-021

### 7.1. Утверждение авторов

[АВТОР P81, с. 367, Теорема 1] «If T is a positive definite operator with domain of definition D(T) ⊂ H_T, then the sequence of elements
α_k = ‖ω₁ᵏ(x, y) − ω₀)‖_{H_T} [sic] is monotonically decreasing»; доказательство — проекции (7), (8) [с. 368]; k_P81 = s. Формулировка P82 (норма W̊₂²,
положительная определённость в L₂ [АВТОР P82, с. 79]) с P81 без доказательства не взаимозаменяема (SOURCE_MAP.md, разд. 10); спецификация
опирается на P81.

### 7.2. Вывод проекта

**[ВЫВОД ПРОЕКТА В-23] Тождество.** Для w ∈ H_T: ‖w − ω₀‖²_{H_T} = 2Π(w) + ‖ω₀‖²_{H_T}, Π(w) = ½[w, w] − (q, w) (так как [w, ω₀] = (q, w)); для w ∈ H_T
Π совпадает с I (h) L-107 (разд. 2.2). Для точного полушага w⁽ˢ⁾ = P_{M_s}ω₀: [w⁽ˢ⁾, w⁽ˢ⁾] = [w⁽ˢ⁾, ω₀] = (q, w⁽ˢ⁾), поэтому Π(w⁽ˢ⁾) = −½(q, w⁽ˢ⁾); при
q = const > 0 невозрастание Π равносильно неубыванию ∬w⁽ˢ⁾dx dy.

**[ВЫВОД ПРОЕКТА В-24] Когда точная минимизация гарантирует невозрастание.** w⁽ˢ⁾ — единственный минимум Π на M_s (6.4.4); при s ≥ 2 предыдущее приближение
лежит в M_s: для нечётного s w⁽ˢ⁻¹⁾ = X^{s−1}Y^{s−2} ∈ {X^{s−1}Ỹ}, для чётного w⁽ˢ⁻¹⁾ = X^{s−2}Y^{s−1} ∈ {X̃Y^{s−1}} (ср. вывод (8) из (7) P81, с. 368). Поэтому

$$\Pi(w^{(s)})\le\Pi(w^{(s-1)}),\qquad \Pi(w^{(s-1)})-\Pi(w^{(s)})=\tfrac12\|w^{(s-1)}-w^{(s)}\|^2_{H_T}\qquad(s\ge2).$$

Неравенство и тождество убыли относятся **только к точной минимизации** на M_s (q = const, разд. 1.6); для приближённых полушагов — разд. 7.4.

**Почему неравенство нестрогое:** при точной минимизации равенство ⇔ w⁽ˢ⁾ = w⁽ˢ⁻¹⁾ (единственность минимума). Тогда заданный множитель следующего полушага совпадает с тем,
по которому было получено w⁽ˢ⁻¹⁾, и все последующие приближения совпадают (неподвижная точка). Строгое убывание ⇔ w⁽ˢ⁾ ≠ w⁽ˢ⁻¹⁾; заранее оно не гарантировано.

**[ВЫВОД ПРОЕКТА В-25] Невырожденность сомножителей** — п. 4–5 совместной индукции В-22 (Б-2). Π(w⁽¹⁾) = −½‖w⁽¹⁾‖²_{H_T} < 0, если правая часть первого
полушага ненулевая: в общем виде ∫₀ᵃq(x, ·)X⁰(x)dx ≢ 0; при q = const ≠ 0 — ∫₀ᵃX⁰dx ≠ 0 (разд. 4.6, условие 3; sin(πx/a): 2a/π; sin²(πx/a): a/2). Тогда
Π(w⁽ˢ⁾) ≤ Π(w⁽¹⁾) < 0 для всех s, w⁽ˢ⁾ ≢ 0, оба множителя ненулевые, A > 0 на каждом следующем полушаге. Доказательство не отделено от индукции В-22:
невырожденность полушага s + 1 использует проекционность и энергию полушагов 1, …, s и наоборот. Знакопостоянство X^{s}, Y^{s} не доказывается и не нужно.

**[ВЫВОД ПРОЕКТА В-26] Сравнение с одночленом** (Лемма P81 [АВТОР P81, с. 368]): c·sin(πx/a)sin(πy/b) ∈ M₁, поэтому Π(w⁽ˢ⁾) ≤ min_c Π(c sin(πx/a)sin(πy/b))
при s ≥ 1. Базисность системы синусов для этого не нужна.

### 7.3. Условия применимости теста (достаточные условия теоремы В-24)

Заголовок означает условия, при которых тест применяется; математически это достаточные условия (Н-9). Тест Π(w⁽ˢ⁺¹⁾) ≤ Π(w⁽ˢ⁾) применяется только
при одновременном выполнении:
1. T симметричен и положительно определён на D(T) (В-6, В-7); **q = const ≠ 0 (R2, R3; D-005)** — область доказательства гладкости последовательных
   множителей и проекционности s ≥ 2 (разд. 1.6, Б-3);
2. **допустимость:** X⁰ ∈ C⁴[0, a], X⁰ = X⁰″ = 0 на концах (SSSS), X⁰ ≢ 0; тогда по совместной индукции В-22 все последовательные приближения допустимы —
   w⁽ˢ⁾ ∈ D(T_SS);
3. **невырожденность старта:** ∫₀ᵃX⁰dx ≠ 0 (разд. 4.6, условие 3; В-22, В-25);
4. каждый полушаг решён **точно** в непрерывной постановке (w⁽ˢ⁾ = P_{M_s}ω₀);
5. w⁽ˢ⁾ ∈ M_{s+1} по построению;
6. на всех полушагах один и тот же функционал Π (те же T, q, граничные условия);
7. **начало теста:** сравниваются w⁽ˢ⁾ и w⁽ˢ⁺¹⁾ при s ≥ 1, т. е. первое сравнение — Π(w⁽²⁾) ≤ Π(w⁽¹⁾); X⁰ сама приближением не является
   (для s = 1 верно лишь Π(w⁽¹⁾) ≤ Π(0) = 0, так как 0 ∈ M₁); неравенство нестрогое (В-24).

Для SSSS с X⁰ = sin(πx/a) условия 1–7 выполнены. Для CCCC с sin²(πx/a) — разд. 10; для CCCC с sin(πx/a) не выполнено условие 2 (разд. 10).

### 7.4. Ограничения

- Тест относится к полю w = XY и функционалу Π(w) (разд. 3), а не к множителям.
- **Приближённое численное решение требует отдельного контроля** (Н-10). В-24 опирается на точную минимизацию на M_s. Неравенство
  Π(w_h⁽ˢ⁾) ≥ Π(w⁽ˢ⁾) верно лишь, если w_h⁽ˢ⁾ ∈ M_s — т. е. заданный множитель точный, а сеточное решение продолжено до функции из V_b (V_a). Если заданный
  множитель сам получен приближённо, w_h⁽ˢ⁾ лежит в другом подпространстве, и сравнение с w⁽ˢ⁾ не обосновано. Сеточная функция без восстановления
  (продолжения) значения Π не имеет; вычисленная квадратурой энергия — лишь оценка Π. Монотонность дискретной последовательности автоматически не следует.
  Дискретный аналог теста, способ восстановления и допуски — только по NUMERICAL_SPEC.md [ИНЖЕНЕРНЫЙ ВЫБОР].
- **Уменьшение энергии не доказывает точности относительно двумерного эталона.** ‖w⁽ˢ⁾ − ω₀‖²_{H_T} = 2(Π(w⁽ˢ⁾) − Π(ω₀)) убывает. Для квадрата SSSS
  его предел **строго положителен** (Н-11; к В-24, требует проверки): по В-27 коэффициенты ω₀ по φ_mn пропорциональны c_mn = 1/[mn(m² + n²)²], и
  c₁₁c₃₃ = (1/4)(1/2916) = 8,57·10⁻⁵ ≠ c₁₃c₃₁ = (1/300)² = 1,11·10⁻⁵, т. е. матрица коэффициентов не ранга 1, и ω₀ не является произведением X(x)Y(y)
  функций из L₂. Если бы ‖w⁽ˢ⁾ − ω₀‖_{H_T} → 0, то коэффициенты произведений w⁽ˢ⁾ (матрицы ранга 1) сходились бы к коэффициентам ω₀ (вложение в L₂, В-9);
  все миноры 2 × 2 в пределе нулевые, т. е. ω₀ было бы произведением — противоречие. Сходимость ряда Σ‖w⁽ˢ⁻¹⁾ − w⁽ˢ⁾‖²_{H_T} ≤ 2(Π(w⁽¹⁾) − Π(ω₀))
  не доказывает сходимости последовательности w⁽ˢ⁾ и не даёт её предела. Энергетическая норма не оценивает непосредственно прогиб в точке. Точность
  определяется сравнением с независимым эталоном — рядом Навье, который по В-27 совпадает с ω₀ (D-024, D-025; NUMERICAL_SPEC.md, Q-012). Возможная мера
  [ИНЖЕНЕРНЫЙ ВЫБОР для NUMERICAL_SPEC]: относительная энергетическая ошибка e_s = ‖w⁽ˢ⁾ − ω₀‖²_{H_T}/‖ω₀‖²_{H_T} = (Π(w⁽ˢ⁾) − Π(ω₀))/|Π(ω₀)|, где
  Π(ω₀) = −½q∬ω₀ и ∬ω₀ — по В-27, п. 6.
- Сходимость при N → ∞ (Теорема 2 P81, п. 3 P82) — часть B.

### 8.2. Моменты

[АВТОР L-107, с. 98, (101), (102)]:

$$M_x=-D\Bigl(\frac{\partial^2w}{\partial x^2}+\nu\frac{\partial^2w}{\partial y^2}\Bigr),\qquad M_y=-D\Bigl(\frac{\partial^2w}{\partial y^2}+\nu\frac{\partial^2w}{\partial x^2}\Bigr),\qquad M_{xy}=-M_{yx}=D(1-\nu)\frac{\partial^2w}{\partial x\,\partial y}.$$

Проверено по изображению с. 98; положительные направления — рис. 48, а [АВТОР L-107, с. 97]; M_yx = −M_xy «вследствие того, что τ_xy = τ_yx» (с. 98).
Соглашение о знаке крутящего момента (Н-7): M_nt = −∫τ_nt z dz [АВТОР L-107, с. 53, (40)]; «Знаки M_n и M_nt выбраны таким образом, что если пользоваться

M_nt = D(1 − ν)∂²w/∂n∂t [АВТОР L-107, с. 55, (43)]. Поэтому M_yx = −M_xy — следствие этого векторного соглашения (для грани с нормалью y направление t = −x),
а не изменение физической величины. Для будущего вычисления напряжений (R6): из (42), (43) τ_xy = −12M_xy z/t³ [ВЫВОД ПРОЕКТА, не используется в части A].
[ИНЖЕНЕРНЫЙ ВЫБОР, рекомендация рецензии Н-7] выдавать только M_xy по (102) с пометкой «соглашение L-107»; при сравнении с источниками, где принято
тензорное соглашение M_xy = M_yx, выполнять пересчёт знака.

[ВЫВОД ПРОЕКТА В-28] Для w = X(x)Y(y):

$$M_x=-D\bigl(X''Y+\nu XY''\bigr),\qquad M_y=-D\bigl(XY''+\nu X''Y\bigr),\qquad M_{xy}=D(1-\nu)X'Y'.$$

## 9. Аналитический контроль первого полушага по Леви (SSSS, s = 1)

### 9.1. Первая гармоника решения Леви

[ВЫВОД ПРОЕКТА В-29] При X⁰ = sin(πx/a) (X⁰″ = −(π/a)²X⁰, X⁰⁗ = (π/a)⁴X⁰; коэффициенты 5.1) Y-полушаг s = 1 после деления на DA = Da/2:

$$Y''''-2\Bigl(\frac{\pi}{a}\Bigr)^2Y''+\Bigl(\frac{\pi}{a}\Bigr)^4Y=\frac{4q}{\pi D},\qquad Y(0)=Y(b)=0,\ \ Y''(0)=Y''(b)=0.$$

Решение: η = y − b/2 = y_c, κ = π/a, α = κb/2 = πb/(2a), C₀ = 4qa⁴/(π⁵D). Частное решение C₀ (κ⁴C₀ = 4q/(πD)); чётная по η однородная часть
P ch(κη) + Q κη sh(κη), (κη sh κη)″ = κ²(2 ch κη + κη sh κη). Условия при η = ±b/2: C₀ + P ch α + Q α sh α = 0; κ²[P ch α + Q(2 ch α + α sh α)] = 0.
Вычитая: C₀ − 2Q ch α = 0 ⇒ Q = C₀/(2 ch α), P = −C₀(α th α + 2)/(2 ch α):

$$Y^1(y)=\frac{4qa^4}{\pi^5D}\Bigl[1-\frac{\alpha\,\mathrm{th}\,\alpha+2}{2\,\mathrm{ch}\,\alpha}\,\mathrm{ch}\frac{\pi y_c}{a}+\frac{1}{2\,\mathrm{ch}\,\alpha}\,\frac{\pi y_c}{a}\,\mathrm{sh}\frac{\pi y_c}{a}\Bigr],\qquad y_c=y-\frac b2 .$$

Сравнение с [АВТОР L-107, с. 136, (139)] при m = 1 (α₁ = πb/(2a) по (h), с. 135; в (139) y = y_Л — от средней линии, разд. 1.1; 2α₁y_Л/b = πy_Л/a):
слагаемые совпадают. По однозначной разрешимости (6.2) w⁽¹⁾ = X⁰Y¹ — **точно член m = 1 решения Леви при любом b/a**. Независимое пояснение
в слабой форме (ω₀ ∉ C⁴, поэтому без проекции уравнения (103)): φ_mn ∈ D(T_SS) взаимно ортогональны в H_T, так как [φ_mn, φ_kl] = (Tφ_mn, φ_kl) =
Dλ_mn²(φ_mn, φ_kl); они полны в H_T: если [w, φ_mn] = (Jw, Tφ_mn) = Dλ_mn²(Jw, φ_mn) = 0 при всех m, n, то Jw = 0 (полнота в L₂) и w = 0 (инъективность J, В-9).
Для m ≠ 1 [φ_mn, X⁰Ỹ] = Dλ_mn²(φ_mn, X⁰Ỹ) = 0 (ортогональность sin(mπx/a) и sin(πx/a)), т. е. φ_mn ⊥ M₁; для m = 1 φ_1n ∈ M₁. Поэтому P_{M₁}ω₀ =
Σ_n c_1n φ_1n — гармоника m = 1. Основное доказательство (явное решение плюс единственность) от пояснения не зависит.
[sic] при цитировании: L-107, с. 134, (d) — «m⁴π⁴/a² Y_m» при «m⁴π⁴/a⁴ Y_m» в строке выше.

требует только X, Y = 0 на концах, а X′X″ = 0 на концах при X′ = 0) и одномерные условия В-33. Для X⁰ = sin²(πx/a) = (1 − cos(2πx/a))/2:
X⁰′ = (π/a)sin(2πx/a), X⁰″ = 2(π/a)²cos(2πx/a); A = ∫X⁰² = 3a/8, B = ∫X⁰′² = π²/(2a), C = ∫X⁰″² = 2π⁴/a³, F = q∫X⁰ = qa/2 (q = const). Проверено рецензией
(её В-33, квадратурой при a = 1: 0,375; 4,9348; 194,818; 0,5);

$$D\Bigl[\frac{3a}{8}Y''''-\frac{\pi^2}{a}Y''+\frac{2\pi^4}{a^3}Y\Bigr]=\frac{qa}{2},\qquad Y(0)=Y(b)=0,\ \ Y'(0)=Y'(b)=0.$$

**Энергетический тест** — условия 7.3 с заменой в условии 2 на X⁰ = X⁰′ = 0.

**Не входит:** неподтверждённый исторический численный алгоритм P81/P82 — одномерные условия и разностные шаблоны авторов не напечатаны (Q-008 — CCCC, Q-010);
опубликованные числа P82 случая II — физически нелинейная задача с индексами n, k (Q-015, Q-016); CCCC с sin(πx/a) — не выполняет условия допустимости
(sin′ ≠ 0 на краях), это Q-017 и R5. Аналитического контроля первого полушага, подобного разд. 9, для CCCC не выводится.

## 11. Математические препятствия

Действительных математических препятствий для части A (N = 1, SSSS, квадрат и прямоугольник) **не выявлено**. Ограничения, которые не являются пробелами,
