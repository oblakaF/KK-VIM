## 1. Доказательство интервальных границ

Каждая эталонная величина — интервал [lo, hi] целых чисел в масштабе 2^−W (W = `bits`, по умолчанию 160), который **содержит** точное значение. Вывод собственный, уровень В; классические факты названы. Этот же текст — в docstring модуля.

| Шаг | Утверждение | Обоснование |
|---|---|---|
| (П1) | Знакочередующийся ряд Σ(−1)^k t_k с t₀ ≥ t₁ ≥ … ≥ 0, t_k → 0: S₁ ≤ S₃ ≤ … ≤ сумма ≤ … ≤ S₂ ≤ S₀ | классический признак Лейбница; достаточно убывания с первого индекса хвоста |
| (П2) | π ∈ [π_lo, π_hi] | тождество Мэчина π = 16 arctg(1/5) − 4 arctg(1/239) (точное); arctg(1/x) = Σ(−1)^k/((2k + 1)x^{2k+1}) при x ≥ 2 — члены строго убывают, (П1). Каждый член ограничен целыми floor/ceil в масштабе 2^−(W+32); нижняя граница частичной суммы берёт нижние границы положительных и верхние — отрицательных членов. π_lo = 16·a₅,lo − 4·a₂₃₉,hi, π_hi = 16·a₅,hi − 4·a₂₃₉,lo, затем floor/ceil к 2^−W. **Второй независимый путь** (тесты): формула Эйлера π/4 = arctg(1/2) + arctg(1/3) |
| (П3) | Точное приведение угла | sin(πp/q): j = p mod 2q; при j ≥ q знак −1 и j ← j − q; при 2j > q j ← q − j. Тогда 0 ≤ j/q ≤ 1/2 — **точно** в целых. j = 0 даёт 0 точно, 2j = q даёт 1 точно. Иначе t = πj/q ∈ [π_lo·j/q, π_hi·j/q] (округление наружу). Ошибка аргумента — только от интервала π; приведение её не увеличивает |
| (П4) | sin на [a, b], 0 ≤ a ≤ b ≤ 2 | ряд Тейлора: отношение соседних членов x²/((2k + 2)(2k + 3)) ≤ 4/6 < 1, поэтому (П1) работает на каждом конце; границы членов — направленные целые. sin вогнут и ≥ 0 на [0, π] ⇒ min ≥ max(0, min(sin a, sin b)); sin возрастает на [0, π/2] ⇒ max = sin b при b ≤ π_lo/2 (точное целочисленное сравнение), иначе max ≤ 1. **Второй путь** (тесты): sin t = cos(π/2 − t), cos убывает на [0, π/2], ряд cos — (П1) при убывании членов с k = 1 (|x| ≤ 2) |
| (П5) | √(2/n) ∈ [c_lo, c_hi] | √(2/n) = √(2n)/n; r = isqrt(2n·4^W): r ≤ √(2n)·2^W < r + 1 (точно при r² = 2n·4^W, например n = 32, 128, 512); деление на n с floor/ceil |
| (П6) | Ψ_ik = знак·c·s | c, s ≥ 0: произведения нижних и верхних границ, floor/ceil к 2^−W, содержат c·s; знак точен (П3) |
| (П7) | DST точных binary64-входов | x_k = X_k·2^E (X_k — целые, точно). y_i = Σ_k Ψ_ik x_k ∈ [Σ_k min(L_ik X_k, H_ik X_k), Σ_k max(…)]·2^{E−W}: каждый член независимо в своём интервале, знак X_k выбирает границу. Все суммы — точные целые |
| (П8) | Нормы и отношения | квадраты точных целых, корни через isqrt с направленным округлением, отношения [lo₁/hi₂, hi₁/lo₂]; если интервал знаменателя содержит 0 — UNRESOLVED. Перевод в double — направленный (`_down`, `_up`), печать — `decimal_up` / `decimal_down` |

**Ширина и строгость.**
- Число членов рядов и разрядность меняют только **ширину** интервала, а не включение. Ширина записывается с каждым результатом.
- Отдельно учитываются:
  - **ошибка аргумента синуса** — от интервала π, для эталона; поле `sin_width_max` таблицы;
  - **ошибка множителя нормировки** — ширина интервала √(2/n), поле `sqrt_width`.
- Для double-формулы ψ_k(1) из `r5_cccc_bc.solve_bc` ошибка раскладывается **точно**: нормировка, аргумент, вычисление sin, округление произведения (разд. 2).

**Источники эталона.** `math.sin`, `math.pi`, NumPy, SciPy и `mpmath` как источник эталонных значений не используются; это проверяет тест по исходному коду функций. NumPy и SciPy встречаются только в проверяемом пути и в диагностике double-формулы.

## 2. Инструмент (`src/kkvim_reference/r5_cccc_dst_cert.py`)

| Функция | Что даёт |
|---|---|
| `pi_bounds(bits, route)` | целочисленный интервал π: `"machin"` (эталон), `"euler"` (второй путь) |
| `sin_pi_rational(p, q, bits, route)` | (знак, lo, hi) для sin(πp/q): `"A"` (Мэчин + Тейлор sin), `"B"` (Эйлер + Тейлор cos дополнительного угла) |
| `sqrt2n_bounds(n, bits)` | интервал √(2/n) |
| `psi_table(n, bits)` | интервалы \|Ψ\| по приведённому индексу j = 0…⌊n/2⌋, с кэшем: из (n − 1)² элементов вычисляется только ⌊n/2⌋ + 1 различных синусов; `entry(i, k)` — интервал Ψ_ik со знаком |
| `certified_dst(x, bits, max_entries, time_limit)` | интервалы y = Ψx для конечного float64-вектора длины n − 1 (П7). Сверх `max_entries` = (n − 1)² (по умолчанию 1100²) или `time_limit` — **UNRESOLVED_RESOURCES**, точность не снижается |
| `compare(y_hat, ref, x, budget)` | ошибка проверяемого результата: поэлементные интервалы, абсолютная и относительная 2-норма, ширина эталона. **Правило разрешения**: ширина ≤ 1/100 нижней границы измеренной ошибки (форма D-049.6, п. 4) — RESOLVED, иначе UNRESOLVED с указанием причины. Нулевой результат, ошибка, не отделённая от 0, и x = 0 — UNRESOLVED. Отношение err/(u·log₂n·‖x‖₂) формы RO 3.2 — OBSERVATION, log₂n — целочисленные рациональные границы |
| `boundary_psi(n, bits)` | ψ_k(1), ψ_k(m) и произведения zₖzₖᵀ (ψ_k(1)², ψ_k(1)ψ_k(m), ψ_k(m)²) для модального пути S (Е-4) |
| `mu_bounds(n, l, bits)` | μ_k = (4/h²)sin²(kπ/(2n)) при точном h = l/n из double l |
| `double_boundary_diagnostics(n, bits)` | ошибка double-формулы `math.sqrt(2.0/n) * np.sin(k*math.pi/n)` (как в `solve_bc`), точно разложенная на (ĉ − c)sin t, ĉ(sin t̂ − sin t), ĉ(ŝ − sin t̂), округление произведения; t̂ — double-аргумент, его ошибка t̂ − t — интервалом |
| `orthogonality_check(n, bits)` | интервальная проверка ΨΨ = I |

**Входы:**
- только конечные float64-векторы длины n − 1, n ≥ 2;
- float32, целые, NaN, ±∞, 2-D и пустые массивы отклоняются с `ValueError`.

**Стоимость** (Windows, Python 3.14.8):

| n | таблица Ψ | DST одного вектора |
|---|---|---|
| 512 | 0,006 с | ≈ 0,09 с |
| 1024 | 0,012 с | 0,37 с |
| 2048 | 0,023 с | 1,47 с |

- n = 1024 и 2048 — одиночный замер стоимости, не выборка.
- Рост DST квадратичный: (n − 1)² целочисленных умножений. Число вычисляемых синусов линейно: ⌊n/2⌋ + 1.
- При n = 2048 лимит по умолчанию (1100²) даёт UNRESOLVED_RESOURCES; его можно поднять параметром.

**Подтверждённые размеры:** n = 3, 4, 7, 16, 32, 64, 128, 256, 512 (пилот). 1024, 2048 — замер стоимости.
