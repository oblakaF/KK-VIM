## Вердикт: **NOT_QUALIFIED**

Обоснованных **априорных** верхних бюджетов, применимых рабочим решателем во всей области D-048, для обеих составляющих
ε = c_d·u·κ_rep + δ_f **нет**. Не хватает трёх оценок: строгой константы c_d (QR/SVD), строгой модели ошибки быстрого DST `scipy.fft` и
строгой оценки переноса накопленной ошибки по полушагам. Поэтому c_d, c_rank, τ_set как нормативные кандидаты **не выводятся**.

При этом получен результат, которого раньше не было: для **всех записанных прогонов** области D-048 (132 ячейки × до 100 полушагов,
13 200 полей; плюс контроль `dense`) накопленная δ_f и полная ошибка диагностики **сертифицированы апостериорно** строгими оболочками
(шаровая арифметика arb). Максимум δ_f = **1,39·10⁻¹³**, ε_cert ≤ **1,38·10⁻¹³** при ρ̂_N ≥ **2,19·10⁻⁶**; достаточное условие
ρ̂_N > ε/(1 − ε) выполнено в каждом поле с запасом ≥ **1,04·10⁸**. Это сертификат конкретных массивов на этой платформе, а не бюджет
решателя (разд. 9).

Ранг N23-4 на вычисленные поля автоматически не переносится. Отдельно проверен энергетический маршрут (разд. 6.4): он сертифицирует
полный ранг **сохранённых** полей при s ≥ 2 во всех 132 ячейках без δ_f и c_d; это собственный вывод QA, требующий проверки Reviewer.

## 6. Ранг: различение потери ранга и неразличимости

### 6.1. Критерий ρ̂_N > ε/(1 − ε)

Применён только с **доказанным для этого прогона** ε_cert(s) = max_k|σ̂_k − σ_k(W*_w)|/σ₁(W*_w) (верхний конец оболочки):
13 200/13 200 полей `fft` и все поля `dense` — «различим в этом прогоне». Это не делает ε бюджетом решателя (разд. 9).
Наблюдаемый ε_obs = c_d,obs·u·κ_rep + δ_f ≈ 8·10⁻¹⁶ + 1,4·10⁻¹³; модельный член c_d·u·κ_rep на два порядка меньше δ_f.

### 6.2. Г-3: точная потеря ранга против численной неразличимости (n = 40, 160)

| полный ранг, 2⁻⁴⁵ | N | 2,0·10⁻¹⁴ > 0 | 2,0·10⁻¹⁴ | **стоп** | различим (ε_cert = 6,7·10⁻¹⁷) |
| полный ранг, 2⁻⁵⁵, 2⁻⁷⁰ | N | 2,0·10⁻¹⁷; 6,0·10⁻²² > 0 | те же | стоп | **не различим** |

- полный ранг 2⁻⁵⁵, 2⁻⁷⁰ доказан, но по нормовому критерию **численно неразличим** — это S-2-ситуация, а не потеря ранга;
- K_RESEARCH останавливает и точную потерю ранга, и различимый случай 2⁻⁴⁵ — защита консервативна, она не критерий S-1/S-2;
- нормовый критерий тоже консервативен: при 2⁻⁷⁰ вычисленное ρ̂ совпадает со строгим до 9 знаков, но ε_cert (по σ₁) ~10⁻¹⁶ его закрывает.

### 6.3. Г-1: граничные сетки

- N = 3, n_y или n_x = 5 < 2N: S-1 (`STOPPED_RANK_LOSS_PROVEN`) до первого полушага — 6/6.
- N = 2, n = 3: `ERROR_INPUT` (правило сетки R2, N_MIN = 4, срабатывает раньше проверки ранга). S-1 при N = 2 поэтому недостижима;
  дефектом это не считается, но в формулировке «S-1 при n < 2N» подразумевается n ≥ 4.
- n = 2N, 2N + 1: нечётных мод ровно N, поэтому W*(1) = ω_h; полный ранг доказан строго (σ_N > 0), защиты пройдены,
  стабилизация при s = 3; δ_f ≤ 7,8·10⁻¹⁶.

### 6.4. Энергетический маршрут (диагностика QA)

Если ‖w − ω_h‖_{a_h} < d_{N−1}, то rank w = N (определение d_{N−1}); d²_{N−1} ≥ D^{low}_{N−1} (лемма N23-3, своя реализация QA `_d_lower`
на ω_h задачи с binary64-входами). Применено к точному произведению **сохранённых** массивов W̃(s):
- при **s ≥ 2 сертифицировано во всех 13 068 полях** 132 ячеек; min запас (√D^{low} − ‖W̃ − ω_h‖)/√D^{low} = 0,741;
- при s = 1 не сертифицируется (ошибка первого полушага больше d_{N−1}; ранг s = 1 доказан ЧВ4-9);
- строгая нижняя граница ρ_N(W̃), выводимая отсюда через Λ_h, слабая (≥ 5,1·10⁻¹⁰), но положительная.

Маршрут не использует ни δ_f, ни c_d; ему нужны строгая оценка энергии хранимого поля и офлайн-сертификат D^{low} ячейки. Вывод
тривиален, но это собственный вывод QA: до проверки Reviewer и решения владельца он критерием решателя не является.
