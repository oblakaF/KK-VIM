**Наблюдение 1 — ошибка вычисления γ̂.**
- m_s > 1 в 116 полушагах (91 при s = 1, 25 при s = 2), все на крупных сетках. Во всех 116 числитель **целиком** равен ошибке вычисления γ̂ − γ: отношение 1,0000.
- Вычисленное γ̂ = h_s(F ⊗ 𝟏 − K ŝ)ᵀΔ в double для уточнённого решения — **чистый шум**: |γ̂ − γ|/|γ̂| = 0,98…1,02 во всех 984 случаях. Точное γ ничтожно: |γ|/Q ≤ 3·10⁻².
- Части «сборка» и «формирование» (точные) малы против своих моделей:
  - |часть сборки|/R^C ≤ 6,0·10⁻⁴;
  - |часть формирования|/R_f^C ≤ 8,0·10⁻⁵.
- **Следствие для модели ВОК-8.** Кандидат τ_s^C = |γ̂| + K_E[…] не содержит члена погрешности γ̂, а она в выборке доминирует числитель m_s при s = 1, 2. Это **OBSERVATION**, а не опровержение модели. ВОК-8 помечает «вычисленное γ̂_s — МОДЕЛЬ» и не даёт для него оценки.

## 8. Неразрешённые вопросы и блокеры

Блокеров для передачи данных на проверку нет. Открытые вопросы (не решаются QA без нового задания):
