2. **Различимость.** μ_k = (4/h²)sin²(kπ/(2n)) строго возрастает по k ∈ [1, n − 1] (kπ/(2n) ∈ (0, π/2)) ⇒ t_k попарно различны и > 0, λ_i попарно различны и > 0.
3. **Сведение.** Так как ψ_k ортонормированы, rank(V¹) = rank [V̂_ik] = rank [K(t_k, λ_i)]_{i ≤ N, k нечёт} (умножение на невырожденные diag(F), diag(c_k)).
   Нечётных k ∈ [1, n_y − 1] ровно ⌊n_y/2⌋.
4. **Лемма (обобщённый Декарт).** f(z) = Σ_{j=1}^{N}a_je^{−zτ_j} при различных τ_j и не всех нулевых a_j имеет не более N − 1 нулей на ℝ.
   Индукция по N: N = 1 — нулей нет; f·e^{zτ₁} = a₁ + Σ_{j≥2}a_je^{−z(τ_j−τ₁)}, производная — сумма N − 1 экспонент; по Ролле число нулей f не больше
   (число нулей производной) + 1 ≤ N − 1. Следствие: det[e^{−z_kτ_j}]_{j,k ≤ N} ≠ 0 при различных z_k и различных τ_j, а при упорядоченных
   τ₁ < … < τ_N и z₁ < … < z_N имеет **постоянный знак** ε(τ) (непрерывная ненулевая функция на связном множестве {z₁ < … < z_N}).
5. **Строгая полная положительность ядра (с точностью до знака).** K(t, λ) = ∫₀^∞ z e^{−zt}e^{−zλ}dz (t + λ > 0). По тождеству Андреева (непрерывная формула
   Коши–Бине: разложение обоих определителей и мультилинейность)
   det[K(t_i, λ_j)]_{i,j ≤ N} = ∫_{0<z₁<…<z_N} det[e^{−z_kt_i}]·det[e^{−z_kλ_j}]·Π_k z_k dz_k.
   При упорядоченных t, λ подынтегральное выражение имеет постоянный знак ε(t)ε(λ) и отлично от нуля на множестве положительной меры
   (непрерывно, z_k > 0); интеграл сходится (t_i, λ_j > 0). Значит det ≠ 0; при t, λ, упорядоченных одинаково, ε(t)ε(λ) = +1 и det > 0
   (знаки двух экспоненциальных определителей совпадают, так как это одна и та же функция ε). **Любая квадратная подматрица** [K(t_k, λ_i)] с различными
   t_k и различными λ_i невырождена. Интегральное представление само по себе этого не даёт — нужны п. 4 (знакопостоянство) и тождество Андреева.
6. **Достаточность.** При ⌊n_y/2⌋ ≥ N выберем N нечётных k: подматрица N × N невырождена ⇒ rank V¹ = N. U = X⁰ инъективна (n_x ≥ 2N) ⇒ rank W¹ = rank V¹ = N (ЧВ4-11).
7. **Необходимость.** n_y: V_i ∈ span{ψ_k: k нечётно} размерности ⌊n_y/2⌋ ⇒ rank W¹ ≤ ⌊n_y/2⌋ < N при n_y ≤ 2N − 1. n_x: при n_x ≤ 2N − 1 rank W¹ ≤ rank X⁰ < N (ЧВ4-8). ∎
