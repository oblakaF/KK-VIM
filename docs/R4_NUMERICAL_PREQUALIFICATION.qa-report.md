# R4 — численная предквалификация N = 2–3: доказательная основа для D-048

Цели: G2, G3.3, G4. Роль: QA. База: `main` @ `ebd29154c248a68a998f386977c88febff7ee3ad`.
**Критерии зафиксированы до расчётов**: `docs/R4_NUMERICAL_PREQUALIFICATION.plan.md`, отдельный коммит `7748877`. Результаты получены после него
без изменения критериев; отклонений от плана нет.

Это исследовательский отчёт QA для решения владельца, **не** нормативное решение. DECISIONS, спецификации, нормативы и код Builder не менялись.
Все результаты исследовательского режима — PROVISIONAL / NOT_QUALIFIED (D-047, дополнение 1). Конечная дискретная задача не смешивается с
неусечённым непрерывным методом; **Q-022 и Q-025 открыты**.

## Итог

- **Дефектов фактического решателя не найдено.** Все заранее заданные критерии B1–B9 выполнены.
- **Одно замечание к реализации.** Плотная Ψ Builder вычисляет sin(ikπ/n) без целочисленного приведения аргумента. При n = 1280 ошибка
  преобразования на отдельных входах достигает ~1,7·10³·u‖x‖ против ≤ 1,9·u‖x‖ у быстрого DST (разд. 3, B3). Основной путь `fft` это не затрагивает.
- **Можно предложить владельцу уже сейчас** (`PROPOSAL_LIMITED`, разд. 4):
  - область энергетического теста;
  - η_max;
  - параметры остановки R2 с полом ε_floor^(N);
  - исследовательскую защиту ранга как временный рабочий критерий;
  - кандидатные допуски А4-3 и А4-12;
  - эталоны для конечной задачи.
- **Не квалифицируются** — причины в разд. 5:
  - строгие c_d, c_rank, τ_set;
  - накопленная δ_f;
  - c_DST быстрого DST;
  - константа QR;
  - классы ζ^(N);
  - второй порядок при s ≥ 2;
  - всё, что касается неусечённого непрерывного метода при s ≥ 2.

## 4. Предложения для D-048 (что владелец может решить уже сейчас)

Каждое предложение ограничено **N = 2–3, 10 контрольными r, семейством I n ≤ 1280 и верхними уровнями семейства II** (где не указано иное).
Все результаты исследовательского режима остаются PROVISIONAL / NOT_QUALIFIED, пока владелец не примет решение.

1. **Энергетический тест.**
   - Сохранить форму R2: τ_s^(N), множитель 10, E1/E2.
   - s = 2 — обязательная область на n ≥ 160 (основание — резерв D-039, B5).
   - s ≥ 3 — необязательная (UNRESOLVED допустим).
   - Множитель 10 остаётся неквалифицированным числом, но менять его оснований нет.
2. **η_max = 10⁻¹²** (R2) как контроль реализации; запас 2,8·10³.
3. **Остановка.**
   - Перенести tol_∞ = 10⁻¹⁰, tol_E = 10⁻⁸, s_min = 3, s_max = 100.
   - Ввести правило конфигурации tol_E ≥ 10·ε_floor^(N), ε_floor^(N) = 10u(max n/π)²·√N/(1 − γ_N√N). Проверено при n ≤ 640, при n ≤ 1280 — по формуле.
   - Требуется реализация статуса CONVERGED (Builder) с пояснением, что это стабилизация, а не сходимость к ω₀.
4. **Ранг.**

5. **Допуски А4:** утвердить кандидаты А4-3 (10⁻¹³) и А4-12 (10⁻¹² / 10⁻¹¹); остальные — по таблице разд. 3.
