### 2.1. Q22-1

Энергетическое скалярное произведение диагонально в синусном базисе. Поэтому Y-полушаг с N-мерной оболочкой U распадается по столбцам n в Λ_n-ортогональные проекции.
- При U ⊂ S_M и цели ω_M столбцы n > M дают нулевые проекции.
- Для n ≤ M проекция совпадает с вычисляемой рекурсией: Грам по m ≤ M точен, правая часть X̂ᵀΛ_nω_M,·n = (16q/(π²Dn))Σ_{m≤M}x_m/m.
- Выход снова лежит в S_M; по индукции с общего старта ⊂ S_M утверждение доказано.
- Ортонормирование (QR) оболочку и поле не меняет (ВБ-16).

Вывод обобщает утверждение, проверенное в `b0c208d` (разд. 3, ответ 1). Он верен для **любой** цели в H_T, а не только для навье-цели.

### 2.2. Q22-4, оценка (⋆)

Проверено построчно.
1. Λ_n^{1/2} = diag_m(κ_m² + ν_n²) — изометрия ℓ²(Λ_n) → ℓ².
2. «Ведин» при rank C ≤ N сводится к элементарной оценке: P_⊥A = 0 ⇒ ‖P_⊥U′‖ = ‖P_⊥(A′ − A)V′Σ′⁻¹‖ ≤ ‖A − A′‖₂/σ_N(A′). Знаменатель — σ_N **сравниваемого** поля C′, а не точного: это правильно.
3. Поэлементно κ_m² + ν_n² ≤ (ν_n/ν₁)²(κ_m² + ν_k²) при всех k: оба слагаемых сравниваются через ν_n ≥ ν₁ и ν_k ≥ ν₁. Отсюда ‖Λ_n^{1/2}(C − C′)‖_F ≤ (ν_n/ν₁)²‖C − C′‖_E.
4. Λ_n^{1/2} ⪰ ν_n²I ⇒ σ_N(Λ_n^{1/2}C′) ≥ ν_n²σ_N(C′). Множитель ν_n² сокращается, оценка равномерна по n.
5. Переход к физическим нормам верен: ‖·‖_{H_T} = (Dab/4)^{1/2}‖·‖_E, σ^{L₂} = (√(ab)/2)σ(C) (проверено отдельно по ортонормированным базисам √(2/a)s_m, √(2/b)s_n).

**Компактные операторы.** C — оператор Гильберта–Шмидта (Σc² < ∞). Для w ∈ H_T оператор Λ_n^{1/2}C тоже Гильберта–Шмидта: его квадрат нормы ≤ (ν_n/ν₁)⁴Σλc² < ∞.
- Элементарная оценка п. 2 требует только ограниченности и конечного ранга C′ = N; она верна в гильбертовом пространстве.
- Неравенство Вейля |σ_k(A) − σ_k(B)| ≤ ‖A − B‖ для компактных операторов следует из минимаксной характеристики.
- Применение корректно.

Если rank C < N, левая часть (⋆) равна 1. Неравенство всё равно верно: ‖C − C′‖₂ ≥ σ_N(C′).

### 2.3. Q22-5

Проверены все шаги.
- **Шаг 1.** ‖·‖_оп ≤ ‖·‖_{L₂(Ω)} ≤ ‖·‖_{H_T}/(D^{1/2}λ₁₁), где λ₁₁ — **сумма** π²(1/a² + 1/b²) (В-9). Вейль ⇒ σ_N(w_{s−1}) > 0, rank w_{s−1} = N, полушаг s определён однозначно (ВБ-14).
- **Шаг 2.** w_s − w′_s = P(ω₀ − w′_s) − (I − P)w′_s; слагаемые a-ортогональны. Верно.
- **Шаг 3.** ω₀ − w′_s = (I − P′)ω₀ + P′τ. Использованы ‖P(I − P′)‖ = sin Θ (равные конечные размерности блоков) и ‖(I − P′)ω₀‖ ≤ ‖ω₀ − w′_s‖ (наилучшее приближение). Также ‖ω₀ − w′_s‖² = ‖τ‖² + ‖ω_M − w′_s‖², поскольку τ ⊥ S_M ⊗ S_M ∋ ω_M − w′_s. Верно. Замечание: P′τ ≠ 0 (столбцы n > M), но использована только оценка ‖P′τ‖ ≤ T, она верна.
- **Шаг 4 (ключевой).** w_{s−1} ∈ M(U) **верно**, но при условиях, которые в тексте не перечислены (О-3):
  - (а) U — оболочка именно заданного набора X^{s−1} точной последовательности, а w_{s−1} = X^{s−1} ⊗ Y^{s−2} с Y^{s−2} ∈ V_b. Это ВБ-17, п. 3, при нечётном s; при чётном s симметрично;
  - (б) dim U = N, то есть x-оболочка поля w_{s−1} совпадает со span X^{s−1}. Это выполняется только при rank w_{s−1} = N, а его обеспечивает шаг 1. Без шага 1 включение может не выполняться, и угол (⋆) относился бы к другому подпространству;
  - (в) аналогично U′ = span X′^{s−1} = x-оболочка w′_{s−1} при σ_N(w′_{s−1}) > 0; тогда w′_{s−1}, w′_s, d′_s ∈ M(U′).

  Далее ‖(I − P)d′_s‖ = ‖(I − P)P′d′_s‖ ≤ sin Θ‖d′_s‖ и ‖(I − P)(w′_{s−1} − w_{s−1})‖ ≤ E_{s−1}. Верно.
- **Шаг 5.** (⋆) применима: rank w_{s−1} ≤ N, rank w′_{s−1} = N. Для X-полушага (y-оболочки, блоки по m, κ₁) — симметрично. Верно.
- **E₁ ≤ T.** Общий старт ⊂ S_M ⇒ P = P′, w₁ − w′₁ = Pτ. Верно.

**Применимость на каждом полушаге (О-2).** Условие и правая часть записаны через неизвестную E_{s−1}. Корректное применение — через вычисленную верхнюю оценку Ê_{s−1}:
- правая часть монотонно не убывает по E_{s−1}, ϑ_s тоже;
- если условие выполнено для Ê_{s−1}, оно выполнено и для E_{s−1};
- после первого нарушения условия оценка прекращается на всех последующих шагах.

Код (`bound()`, `q022_table.py`, `q022_production.py`) делает именно так. В теореме это нужно сформулировать явно. Других недостающих условий сохранения ранга нет: шаг 1 даёт полный ранг точного поля на каждом полушаге, где условие выполнено.

**Независимая попытка опровержения** (собственный код рецензента; модули Literature не использованы):
- цели — случайные гладкие поля в H_T (с навье-частью и без), старты — случайные наборы в S_M;
- r ∈ {1/5, 1/2, 1, 2, 5}, N = 1–3;
- полушаги — прямой взвешенный МНК по цели, а не формула нагрузки.

Результат:
- (⋆): 619 проверок, **0 нарушений**, наибольшее отношение угол/оценка — 0,944 (оценка близка к точной);
- рекуррентность Q22-5: 257 полушагов, **0 нарушений**, наибольшее E_true/Ê — 0,27.

Это не доказательство, но ни одного контрпримера к выводам нет.

### 2.5. Коллизия λ_mn и λ₁₁ (О-1)

В документе λ_mn := (κ_m² + ν_n²)² (квадрат суммы), а λ₁₁ := π²(1/a² + 1/b²) (сумма). В принятом MATH_SPEC (стр. 211, 846) λ_mn = π²(m²/a² + n²/b²) — сумма. Таким образом документ переопределяет принятое обозначение, и внутри документа λ₁₁ ≠ λ_mn|_{m=n=1}.

Влияет ли это на выводы:
- **по существу — нет.** Все места, где стоит λ₁₁ (шаг 1 Q22-5, условие применимости, Q22-6 п. 3 через ВБ-19, оценка G_s в разд. 5), требуют именно суммы, то есть собственного значения −Δ. Код использует сумму (`lam11 = π²(1/a² + 1/b²)`);
- **риск реальный.** Если взять λ₁₁ по определению λ_mn документа, условие ранга ослабнет в (κ₁² + ν₁²) раз (≈ 19,7 при a = b = 1) и станет неконсервативным: оценка «разрешит» шаги, где полный ранг точного поля не гарантирован.

Перед любой реализацией QA обозначение нужно развести, например Λ_mn := (κ_m² + ν_n²)² и λ₁₁ := κ₁² + ν₁² как в MATH_SPEC.
