## 1. PRE_D1_RANK — отдельный крупный пункт

### 1.1. Формулировка

Можно ли в кампании D1 при N = 2, 3 выполнять QR и следующие полушаги, если ранг траектории не сертифицирован? Если нельзя — как
останавливать и как маркировать.

### 1.2. Что установлено (ИС, разд. 2, 5.1)

- D-049.5, п. 1 с MS-C C.11.2 и R4NS 5.2 п. 9: при неустановленном бюджете ε ранг «численно неразличим», остановка до QR.
- Принятые QA-инструменты SEQ (D-051.1) и ОП-8 (D-055.1) при N ≥ 2 продолжают QR с меткой RESEARCH_ONLY. Данные Q3 и PR #41–#42 получены
  так же и приняты D-053, D-054 как исследовательская база.
- PROT (D-055.2), разд. 3, блок D требует защитную остановку до QR при неразличимости.
- **Это неоднозначность объекта D-049.5** (ВП-1). Прочтения:
  - (а) D-049.5 относится к режиму реализации метода, а QA-цепочки RESEARCH_ONLY допустимы;
  - (б) D-049.5 относится ко всем расчётам N = 2–3, включая D1.
- O1 PROVEN, O3 CERTIFIED (D0, 1312/1312), O4 UNRESOLVED (D-054.5).
- **Новое (ИС):**
  - непрерывный ранг s = 1 при N = 3 — вывод РН-2, к рецензии;
  - O4-h при s = 1 сертифицируема (РН-5);
  - для s ≥ 2 есть рекурсивная апостериорная граница (РН-9), замыкание которой UNRESOLVED;
  - на малых сетках фактический перенос сжимающий (наблюдение);
  - контрпример (14, 4), N = 3: остановка ОП-8 по точной зависимости сохранённого набора доказанную потерю ранга не обнаруживает.

  s ≥ 2 получены без защиты D-049.5. Их статус RESEARCH_ONLY не меняется. При (а) — изменить формулировку PROT, разд. 3 (блок D).
- **Решение 4.** Имя статуса траектории при защитной остановке (D-049.5, п. 2), например `STOPPED_RANK_GUARD_UNCERTIFIED`. S-2 не
  вводится.
- **Решение 5.** Конфигурационное правило S-1 по РН-3 (N > ⌊n_s/2⌋ в решаемом направлении). Это доказанная зависимость, D-049.5, п. 2;
  в D1 не срабатывает.

**Чего не делать:** принимать Д без пересмотра D-049.5; назначать K, c_d, c_rank, τ_set; квалифицировать N ≥ 2.
