## 2. Дискретизация связанных систем

### 2.1. Дискретное подпространство полушага и функционал [ПРИНЯТО NUMERICAL_SPEC 4.1, ЧВ-3, ЧВ-10]

Π_h(w) = ½a_h(w, w) − l_h(w), a_h(w, v) = DΣ_{ij}h_xh_y(Δ_hw)_{ij}(Δ_hv)_{ij}, Δ_h = L_x ⊗ I + I ⊗ L_y, l_h(w) = qΣh_xh_yw_{ij}; a_h симметрична
и положительно определена на V_h = V_h^x ⊗ V_h^y. Функционал, сетки и операторы — те же, что в R2/R3; для N ≥ 2 меняется только
подпространство полушага:

$$M_h(U):=\Bigl\{\sum_{j=1}^{N}U_j\otimes\tilde V_j:\ \tilde V_j\in V_h^y\Bigr\}=\operatorname{span}(U)\otimes V_h^y\quad(\text{Y-полушаг}),\qquad
M_h(V):=V_h^x\otimes\operatorname{span}(V)\quad(\text{X-полушаг}).$$

### 2.2. Проверка L² = L·L и суммирования по частям [ВЫВОД ПРОЕКТА ЧВ4-1]

1. **L² — квадрат L.** В R2 оператор четвёртой разности **определён** как L(Lf) с концевыми нулями (Lf)₀ = (Lf)_n = 0 [ПРИНЯТО NUMERICAL_SPEC 3.1,
   ЧВ-2]. Пятиточечный шаблон (1, −4, 6, −4, 1)/h⁴ с f₀ = f_n = 0 и антисимметричным отражением f₋₁ = −f₁, f_{n+1} = −f_{n−1} даёт граничные строки
   (5, −4, 1)/h⁴ и (1, −4, 5)/h⁴ и совпадает с L·L, где L — матрица (n − 1) × (n − 1) второй разности с условиями Дирихле [ПРИНЯТО ЧВ-2; реализация SSSS
   R2/R3]. Значит, **L² = L·L точно** как произведение матриц на внутренних узлах; собственные векторы L² — те же ψ_k, собственные значения — μ_k².
   [SCRATCH] max|L·L − шаблон|·h⁴ ≤ 7,3·10⁻¹⁶ (n = 4, 5, 20); |Lψ_k + μ_kψ_k| ≤ 2,3·10⁻¹³ (n = 12, ℓ = 1,7).
2. **Применимость синус-преобразования.** −L = ΨΛΨᵀ, Ψ = [ψ₁ … ψ_{n−1}] ортогональна, Λ = diag(μ_k) [ПРИНЯТО NUMERICAL_SPEC 4.1 — спектр
   трёхдиагональной матрицы Тёплица]. Ψ — матрица дискретного синус-преобразования типа I (с нормировкой √(2/n)); Ψᵀ = Ψ⁻¹ = Ψ.
3. **Поляризованное суммирование по частям.** Для u, v с нулевыми концами ⟨u, Lv⟩ = ⟨Lu, v⟩ = −ΣhD⁺uD⁺v [ПРИНЯТО ЧВ-1]. Отсюда для набора U:

$$A_{ij}:=\langle U_i,U_j\rangle,\qquad B_{ij}:=\sum_{l=0}^{n-1}h\,(D^+U_i)_{l+\frac12}(D^+U_j)_{l+\frac12}=-\langle U_i,LU_j\rangle=-\langle LU_i,U_j\rangle,\qquad
C_{ij}:=\langle LU_i,LU_j\rangle=\langle U_i,L^2U_j\rangle,\qquad F_i:=q\langle U_i,\mathbf 1\rangle .$$

   A, B, C — симметричные неотрицательно определённые матрицы N × N (матрицы Грама в ⟨·,·⟩: ξᵀAξ = ‖Uξ‖², ξᵀBξ = ΣhD⁺(Uξ)², ξᵀCξ = ‖L(Uξ)‖²).
   Условия тождеств — те же, что в R2: нулевые концы и равные веса h во внутренних узлах [ПРИНЯТО NUMERICAL_SPEC 4.2]. Смешение квадратур
   запрещено [ПРИНЯТО NUMERICAL_SPEC 7.3].

### 2.3. Дискретная связанная система Y-полушага [ВЫВОД ПРОЕКТА ЧВ4-2]

Задан набор U = X^{s−1} на G(a, n_x) (s нечётно); неизвестный набор V = Y^{s} на G(b, n_y). Для w = Σ_jU_j ⊗ V_j и v = Σ_iU_i ⊗ Ṽ_i:
- Δ_h(U_j ⊗ V_j) = (L_xU_j) ⊗ V_j + U_j ⊗ (L_yV_j); на граничных узлах Δ_h := 0 — согласовано с концевыми нулями L [ПРИНЯТО NUMERICAL_SPEC 4.1];
- для тензорных произведений (f ⊗ g, f′ ⊗ g′)_h = ⟨f, f′⟩_x⟨g, g′⟩_y;
- поэтому

$$\bigl(\Delta_h(U_j\otimes V_j),\Delta_h(U_i\otimes\tilde V_i)\bigr)_h=\langle L_xU_j,L_xU_i\rangle\langle V_j,\tilde V_i\rangle+\langle L_xU_j,U_i\rangle\langle V_j,L_y\tilde V_i\rangle
+\langle U_j,L_xU_i\rangle\langle L_yV_j,\tilde V_i\rangle+\langle U_j,U_i\rangle\langle L_yV_j,L_y\tilde V_i\rangle$$

$$=C_{ij}\langle V_j,\tilde V_i\rangle-2B_{ij}\langle L_yV_j,\tilde V_i\rangle+A_{ij}\langle L_y^2V_j,\tilde V_i\rangle
=h_y\,\tilde V_i^{\mathsf T}\bigl[A_{ij}L_y^2-2B_{ij}L_y+C_{ij}I\bigr]V_j$$

  (использованы ⟨L_xU_j, U_i⟩ = −B_{ij}, симметрия B, ⟨V_j, L_yṼ_i⟩ = ⟨L_yV_j, Ṽ_i⟩, ⟨L_yV_j, L_yṼ_i⟩ = ⟨L_y²V_j, Ṽ_i⟩);
- l_h(U_i ⊗ Ṽ_i) = qΣh_xh_yU_{li}Ṽ_{ki} = h_yF_i𝟏ᵀṼ_i.

Итого a_h(w, v) = h_yΣ_{ij}Ṽ_iᵀK_{ij}V_j, l_h(v) = h_yΣ_iF_i𝟏ᵀṼ_i, и стационарность Π_h на M_h(U) (множитель h_y сокращается) даёт **одну блочную
систему**:

$$\sum_{j=1}^{N}K^X_{ij}V_j=F^X_i\,\mathbf 1,\quad i=1,\dots,N;\qquad K^X_{ij}=D\bigl[A^X_{ij}L_y^2-2B^X_{ij}L_y+C^X_{ij}I\bigr];\qquad
\mathcal K^X=D\bigl[A^X\otimes L_y^2-2B^X\otimes L_y+C^X\otimes I\bigr],\quad \mathcal K^X\,\mathrm{vec}(V)=F^X\otimes\mathbf 1 .\qquad(\text{ЧФ-1})$$

(vec(V) — столбцы V один за другим; в ⊗ первым множителем стоит индекс члена.)

**Соглашение об обозначениях (НБ-1).** Верхний индекс у A, B, C, F, K и 𝒦 указывает **источник коэффициентов** — набор, по которому вычислены
сеточные суммы, — а **не** решаемое направление (как a^X, a^Y в MATH_SPEC Б.3–Б.4): A^X_{ij} = ⟨U_i, U_j⟩_x и т. д. для U = X^{s−1} (формулы разд. 2.2 на
G(a, n_x)). Поэтому **𝒦^X — матрица Y-полушага** на сетке y, размер N(n_y − 1); **𝒦^Y — матрица X-полушага** на сетке x, размер N(n_x − 1) (разд. 2.4).
Там, где направление ясно из контекста (разд. 3, 5), индекс опускается: A, B, C, F, 𝒦 — коэффициенты из **заданного** набора текущего полушага.

**Проверки.**

### 2.4. Дискретная связанная система X-полушага [ВЫВОД ПРОЕКТА ЧВ4-3]

Задан набор V = Y^{s−1} на G(b, n_y) (s чётно); неизвестный набор U = X^{s} на G(a, n_x). Тем же выводом с заменой ролей:

$$A^Y_{ij}=\langle V_i,V_j\rangle_y,\quad B^Y_{ij}=-\langle V_i,L_yV_j\rangle_y,\quad C^Y_{ij}=\langle L_yV_i,L_yV_j\rangle_y,\quad F^Y_i=q\langle V_i,\mathbf 1\rangle_y;$$

$$\sum_{j}K^Y_{ij}U_j:=\sum_{j}D\bigl[A^Y_{ij}L_x^2-2B^Y_{ij}L_x+C^Y_{ij}I\bigr]U_j=F^Y_i\,\mathbf 1\quad\text{на }G(a,n_x);\qquad
\mathcal K^Y=D\bigl[A^Y\otimes L_x^2-2B^Y\otimes L_x+C^Y\otimes I\bigr].\qquad(\text{ЧФ-2})$$

- коэффициенты — сеточные суммы **по y** на G(b, n_y) с шагом h_y; операторы и неизвестные — **по x** на G(a, n_x); сокращаемый множитель — h_x;
- при n_x ≠ n_y каждая сумма берётся на сетке своей функции, каждый оператор — на сетке неизвестного набора [ПРИНЯТО NUMERICAL_SPEC 3.2;
  R3_NUMERICAL_SPEC 3.3]; размеры (верхний индекс — источник коэффициентов, разд. 2.3): 𝒦^Y ∈ ℝ^{N(n_x−1)×N(n_x−1)} (X-полушаг),
  𝒦^X ∈ ℝ^{N(n_y−1)×N(n_y−1)} (Y-полушаг);
- одна функция-решатель для обоих направлений, как в R2 [ПРИНЯТО NUMERICAL_SPEC 5.3].

### 2.6. Разрешимость дискретного полушага [ВЫВОД ПРОЕКТА ЧВ4-5]

Пусть U ∈ ℝ^{(n_x−1)×N} — заданный набор, Ṽ ∈ ℝ^{(n_y−1)×N}.
1. **Связь с энергией:** h_y·vec(Ṽ)ᵀ𝒦vec(Ṽ) = a_h(UṼᵀ, UṼᵀ) (ЧВ4-2 при v = w).
2. **Норма поля:** ‖UṼᵀ‖²_h = Σ_{ij}A_{ij}⟨Ṽ_i, Ṽ_j⟩_y ≥ λ_min(A)Σ_i‖Ṽ_i‖²_y.
3. **Положительная определённость.** a_h(w, w) ≥ D(μ₁ˣ + μ₁ʸ)²‖w‖²_h [ПРИНЯТО NUMERICAL_SPEC 4.1]. Если столбцы U линейно независимы
   (A ≻ 0), то 𝒦 ≻ 0 и система (ЧФ-1) имеет единственное решение. Обратно, если U зависим (Uξ = 0, ξ ≠ 0), то Ṽ = ξ ⊗ g даёт UṼᵀ = 0 и 𝒦 вырождена.
   Итак, **𝒦 ≻ 0 ⇔ столбцы U линейно независимы в ℝ^{n_x−1}**; необходимо N ≤ n_x − 1.
4. **Существование и единственность.** Пространство конечномерно; при 𝒦 ≻ 0 решение единственно; оно — единственный минимум Π_h на M_h(U)
   и a_h-ортогональная проекция ω_h на M_h(U) [ПРИНЯТО ЧВ-10 — доказательство не зависит от N].
5. **Вырожденный набор.** Ядро 𝒦 = {Ṽ: UṼᵀ = 0}; правая часть F ⊗ 𝟏 ортогональна ядру (l_h(UṼᵀ) = 0 для таких Ṽ), поэтому система совместна,

## 3. Решение блочной системы

### 3.1. Вариант A — непосредственная блочная система

Сборка 𝒦 (размер N(n − 1)) и одно решение. При нумерации «узел — член» 𝒦 = D[L² ⊗ A − 2L ⊗ B + I ⊗ C] — блочно-пятидиагональная матрица
с блоками N × N, ширина ленты ≈ 2N. Решение — ленточное разложение (Холецкого или LU) за O(nN³) операций, память O(nN²).
- **Устойчивость:** cond(𝒦) ≍ (μ_{n−1}/μ₁)²·(множитель представления) ~ (2n/π)⁴·κ_A (разд. 3.2); для N = 1 R2 установил, что сборка пятидиагональной
  матрицы с Холецким теряет точность (4·10⁻⁹ при n = 320, 5·10⁻⁶ при n = 1280) и отказался от неё [ПРИНЯТО NUMERICAL_SPEC 3.5, 8.1, И-6]. Для N ≥ 2
  ожидается та же потеря, умноженная на обусловленность представления. Матричного аналога факторизации R2 (K = DA(L − r₁)(L − r₂)) для некоммутирующих
  A, B, C нет без дополнительных построений (квадратичная матричная задача на собственные значения) [НЕ УСТАНОВЛЕНО].

### 3.2. Вариант B — модальная диагонализация по собственным векторам L [ВЫВОД ПРОЕКТА ЧВ4-6]

Так как L_y = −ΨΛΨᵀ и L_y² = ΨΛ²Ψᵀ (ЧВ4-1), то

$$\mathcal K=D\sum_{k=1}^{n_y-1}M_k\otimes\psi_k\psi_k^{\mathsf T},\qquad M_k:=\mu_k^2A+2\mu_kB+C,$$

т. е. в координатах V̂_{jk} = ψ_kᵀV_j система (ЧФ-1) **алгебраически эквивалентна** n_y − 1 независимым системам размера N × N:

$$D\,M_k\,\hat V_{\cdot k}=F\,(\psi_k^{\mathsf T}\mathbf 1),\qquad k=1,\dots,n_y-1;\qquad V_j=\sum_k\hat V_{jk}\psi_k .\qquad(\text{ЧФ-3})$$

*Вывод.* (ψ_kᵀ ⊗ …): A_{ij}L_y² − 2B_{ij}L_y + C_{ij}I = Σ_k(A_{ij}μ_k² + 2B_{ij}μ_k + C_{ij})ψ_kψ_kᵀ — знак «+2μB» из −2B·(−μ). Дополнительной аппроксимации нет.
- **Правая часть:** ψ_kᵀ𝟏 = √(2/n)Σ_{i=1}^{n−1}sin(kπi/n) = √(2/n)·ctg(kπ/(2n)) при нечётном k и 0 при чётном [СТАНД.; та же сумма, что в ЧВ-6 R2].
  Поэтому V̂_{·k} = 0 для чётных k: решение содержит только нечётные дискретные моды.
- **Положительная определённость M_k:** μ_k > 0, A ≻ 0, B, C ⪰ 0 ⇒ M_k ⪰ μ_k²A ≻ 0. Спектр 𝒦 — объединение спектров DM_k, поэтому
  λ_min(𝒦) ≥ Dμ₁²λ_min(A), λ_max(𝒦) ≤ D(μ_{n−1}²‖A‖ + 2μ_{n−1}‖B‖ + ‖C‖).
- **Обусловленность по модам:** cond(M_k) ≤ (μ_k²‖A‖ + 2μ_k‖B‖ + ‖C‖)/(μ_k²λ_min(A)); при больших μ_k → cond(A). В модальном решении сеточный множитель
  (μ_{n−1}/μ₁)² **не входит** в решаемые системы — каждая мода решается отдельно; он проявляется только в масштабах мод.
- [SCRATCH] Решение (ЧФ-3) совпало с решением собранной системы (ЧФ-1) до 9,9·10⁻¹⁵ относительно (N = 3, n = 10, случайные A, B, C ≻ 0); для чётных k
  |ψ_kᵀ𝟏| ≤ 2,2·10⁻¹⁶.

и не отдельное решение владельца. Прежнее достаточное условие ⌊n_y/2⌋ ≥ 2N − 1 (n_y ≥ 4N − 2; числитель степени ≤ 2N − 2 с 2N − 1 нулями) верно, но
заменено необходимым и достаточным.

1. **Общее ограничение размерности (q = const, любой старт, любое s, точная арифметика, равномерные сетки R2/R3).** Правая часть полушага — F ⊗ 𝟏, и
   ψ_kᵀ𝟏 = 0 для чётных k (разд. 3.2); при независимом заданном наборе M_k ≻ 0, поэтому V̂_{·k} = 0 для всех чётных k (при зависимом наборе — для решения
   с нулевыми чётными модами; поле от выбора решения не зависит, ЧВ4-5, п. 5). Нечётные ψ_k симметричны относительно середины отрезка
   (sin(kπ(n − i)/n) = (−1)^{k+1}sin(kπi/n)) и образуют базис пространства **симметричных** сеточных функций на внутренних узлах, размерности ⌊n/2⌋.
   Значит, после Y-полушага все V_j симметричны по y и **rank W ≤ ⌊n_y/2⌋**, после X-полушага — **rank W ≤ ⌊n_x/2⌋**. Полный ранг N после обоих полушагов
   возможен только при **n_x ≥ 2N и n_y ≥ 2N** (⌊n/2⌋ ≥ N ⇔ n ≥ 2N) — сильнее прежнего «N ≤ min(n_x − 1, n_y − 1)».
2. **Теорема (Reviewer).** Пусть q = const ≠ 0, X_i⁰ = s_{2i−1}, s = 1, точное решение дискретной системы. Тогда **rank W¹ = min(N, ⌊n_y/2⌋) при n_x ≥ 2N**,
   и, следовательно, **rank W¹ = N ⇔ n_x ≥ 2N и n_y ≥ 2N.**
   *Схема доказательства (полностью — рецензия, разд. 7, пп. 1–7).*
   - **Ненулевые коэффициенты нагрузки и формула решения.** При n_x ≥ 2N матрицы диагональны (ЧВ4-8), F_i = qh_x ctg(m_iπ/(2n_x)) > 0, и по (ЧФ-3)
     V̂_ik = F_i·c_k·K(t_k, λ_i)/(D·a/2), K(t, λ) = (t + λ)⁻², t_k = μ_k^y, λ_i = μ^x_{2i−1}, c_k = ψ_kᵀ𝟏 ≠ 0 ⇔ k нечётно. t_k и λ_i попарно различны и положительны
     (μ строго возрастает по k ∈ [1, n − 1]).
   - **Сведение.** rank V¹ = rank[K(t_k, λ_i)]_{i ≤ N, k нечётно} (умножение на невырожденные diag(F), diag(c_k)); нечётных k ∈ [1, n_y − 1] ровно ⌊n_y/2⌋.
   - **Обобщённое правило Декарта.** Σ_{j=1}^{N}a_je^{−zτ_j} при различных τ_j и не всех нулевых a_j имеет не более N − 1 нулей на ℝ (индукция и Ролль);
     отсюда det[e^{−z_kτ_j}] ≠ 0 и имеет постоянный знак при упорядоченных τ и z.
   - **Тождество Андреева.** K(t, λ) = ∫₀^∞ z e^{−zt}e^{−zλ}dz, и det[K(t_i, λ_j)] = ∫_{0<z₁<…<z_N}det[e^{−z_kt_i}]·det[e^{−z_kλ_j}]·Π_kz_kdz_k; подынтегральное
     выражение знакопостоянно и не равно нулю на множестве положительной меры ⇒ **матрица ядра 1/(t + λ)² невырождена** для любых различных t_k и
     различных λ_i (любая квадратная подматрица).
   - **Достаточность:** при ⌊n_y/2⌋ ≥ N выбираются N нечётных k ⇒ rank V¹ = N, и rank W¹ = rank V¹ (ЧВ4-11, X⁰ инъективна). **Необходимость:** п. 1
     (⌊n_y/2⌋ < N при n_y ≤ 2N − 1) и ЧВ4-8 (n_x ≤ 2N − 1).
   [SCRATCH рецензии, `decimal`, 70 знаков] rank V¹ = N − 1 при n_y = 2N − 1 и N при n_y = 2N, 2N + 1, 4N − 2 для N = 2, 3, 6. [SCRATCH, `scratch/r4fix/`, double]

3. **Следствие для сеток:** математический минимум полного ранга s = 1 — **n_x, n_y ≥ 2N** (N = 6 — 12). Прежняя неопределённость «N = 6, n_y = 20 (< 22)»

## 5. Ранг, обусловленность и представление

### 5.1. Что различается [ПРИНЯТО MATH_SPEC Б.10, ВБ-14]

(а) независимость **заданного** набора; (б) независимость **полученного** набора; (в) **ранг поля**; (г) **единственность следующего полушага**.
Дискретный аналог ВБ-14 [ВЫВОД ПРОЕКТА ЧВ4-11]: если столбцы заданного набора U независимы, то rank(UVᵀ) = rank(V) (UVᵀz = 0 ⇔ Vᵀz = 0, так как U
инъективна; матричная форма ВБ-2). Значит, (б) ⇔ (в) rank W = N ⇔ (г) — следующий полушаг однозначен (ЧВ4-5, п. 3).

### 5.2. Диагностика ранга поля ρ_N [ВЫВОД ПРОЕКТА ЧВ4-12]

**Определение.** W_w := diag(√ω_x)·W·diag(√ω_y), ω — веса ⟨·,·⟩ на внутренних узлах. В схеме R2/R3 все внутренние веса равны h, поэтому
W_w = √(h_xh_y)·W, и

$$\rho_N:=\frac{\sigma_N(W_w)}{\sigma_1(W_w)}=\frac{\sigma_N(W)}{\sigma_1(W)}\qquad(\sigma_1>0).$$

σ_k(W_w) — сингулярные числа оператора дискретного поля L₂-типа, дискретный аналог K_f (ВБ-2, ВБ-19).

**Свойства (точная арифметика).**
1. **Инвариантность GL(N):** U → UT, V → VT^{−T} не меняют W ⇒ ρ_N тот же. [SCRATCH] |Δρ| ≤ 3,3·10⁻¹⁶ (случайные T).
2. **Инвариантность масштаба:** W → cW (c ≠ 0) ⇒ ρ_N тот же.
3. **Связь с точным рангом:** rank W = N ⇔ σ_N > 0 ⇔ ρ_N > 0.
4. **Вычисление без формирования W:** U = Q_UR_U, V = Q_VR_V (тонкие QR, (n − 1) × N) ⇒ W = Q_U(R_UR_Vᵀ)Q_Vᵀ, σ_k(W) = σ_k(R_UR_Vᵀ) — SVD матрицы N × N;
   стоимость O(nN²). [SCRATCH] совпадение с полным SVD W до 5,6·10⁻¹⁷.

**Округление: пол различимости ρ_floor [ВЫВОД ПРОЕКТА ЧВ4-12, пп. 5–9; исправлено по Б-1 рецензии `e6c351f`].** Прежняя модель
«‖E‖₂ ~ c(n, N)·u·‖W‖₂, ρ_N ниже ~c(n, N)·u неотличим от нуля» **снята**: при вычислении через факторы обратные ошибки QR относятся к ‖U‖, ‖V‖,
а не к ‖W‖, и к ним добавляется прямая ошибка самих факторов.

5. **Множитель представления.** Весовые факторы U_w := √h_x·U, V_w := √h_y·V (равные веса R2/R3), W_w = U_wV_wᵀ;

$$\kappa_{\mathrm{rep}}:=\frac{\|U_w\|_2\,\|V_w\|_2}{\|W_w\|_2}\ \Bigl(=\frac{\|U\|_2\|V\|_2}{\|W\|_2}\ \text{при равных весах}\Bigr).$$

   Свойства (точная арифметика; доказательство в одну строку каждое):
   (а) 1 ≤ κ_rep ≤ min(cond₂(U_w), cond₂(V_w)): ‖U_wV_wᵀ‖₂ ≤ ‖U_w‖₂‖V_w‖₂ и ‖U_wV_wᵀ‖₂ ≥ σ_N(U_w)‖V_w‖₂ при инъективной U_w;
   (б) κ_rep **зависит от представления** (не GL(N)-инвариант); его минимум по GL(N) равен 1 и достигается, когда один из факторов имеет
   ортонормированные (в весе) столбцы: при U_wᵀU_w = I ‖W_w‖₂ = ‖V_w‖₂ и κ_rep = 1;
   (в) вычисляется по тем же QR за O(N³) дополнительно: ‖U_w‖₂ = ‖R_U‖₂, ‖V_w‖₂ = ‖R_V‖₂, ‖W_w‖₂ = σ₁(R_UR_Vᵀ).
   При старте нечётными синусами (ЧВ4-8) столбцы X⁰ ортогональны и равны по норме, поэтому на s = 1 κ_rep = 1 точно.
6. **Разложение ошибки.** Пусть W* — поле точной (в точной арифметике) дискретной последовательности КК-МВИ на той же сетке, Ŵ = ÛV̂ᵀ — точное
   произведение сохранённых факторов, σ̂_k — вычисленные сингулярные числа. Для любых возмущений факторов
   δW = δU·Vᵀ + U·δVᵀ + δU·δVᵀ (тождество). Отсюда два вклада:
   - **(д) диагностика (QR, произведение R_UR_Vᵀ, SVD).** Хаусхолдеров QR обратно устойчив по столбцам: U_w + ΔU = Q̃_UR̂_U, ‖Δu_j‖₂ ≤ c₁u‖u_j‖₂
     (Q̃_U точно ортонормирована); произведение — с ошибкой ≤ γ_N|R̂_U||R̂_V|ᵀ; SVD матрицы N × N обратно устойчиво [СТАНД.; источник в библиотеке
     проекта — нет, как NUMERICAL_SPEC 2.4]. Поэтому σ̂_k — точные сингулярные числа Ŵ_w + δW_d, где δW_d = ΔU·V_wᵀ + U_w·ΔVᵀ + ΔU·ΔVᵀ + Q̃_UEQ̃_Vᵀ и
     ‖δW_d‖₂ ≤ c_d(n, N)·u·‖U_w‖₂‖V_w‖₂ + O(u²) = c_d·u·κ_rep·‖W_w‖₂ + O(u²);
   - **(ф) прямая ошибка факторов.** δW_f := Ŵ − W* (полевая величина, от представления не зависит); δ_f := ‖δW_{f,w}‖₂/‖W*_w‖₂. Для любой пары
     представлений Û = U*T + δU, V̂ = V*T^{−T} + δV:

$$\delta_f\le\kappa_{\mathrm{rep}}\,(\varepsilon_U+\varepsilon_V+\varepsilon_U\varepsilon_V),\qquad \varepsilon_U=\frac{\|\delta U_w\|_2}{\|U_w\|_2},\ \ \varepsilon_V=\frac{\|\delta V_w\|_2}{\|V_w\|_2}.$$

     δ_f включает ошибки решения текущего полушага, сборки коэффициентов, DST, хранения массивов и **перенос ошибок предыдущих полушагов**.
     **Условия использования κ_rep (НА-2).** Мажоранта δ_f строга, если κ_rep, ε_U, ε_V взяты для **точного** представления (U*T, V*T^{−T}, W*).
     Вычисляемое в решателе κ_rep относится к **сохранённым** факторам (Û, V̂, Ŵ) и совпадает с точным только в первом порядке:
     κ_rep(Û, V̂) = κ_rep(U*T, V*T^{−T})·(1 + O(ε_U + ε_V + δ_f)). В оценке (д) используется κ_rep сохранённых массивов — там оно стоит по определению
     (обратные ошибки QR/SVD относятся именно к ним).
7. **Оценка ρ_N (Вейль).** |σ̂_k − σ_k(W*_w)| ≤ ‖δW_d‖₂ + ‖δW_{f,w}‖₂ ≤ ε·σ₁(W*_w), ε := c_d·u·κ_rep + δ_f (первый порядок). Тогда при ε < 1

$$|\hat\rho_N-\rho_N(W^*)|\le\frac{\varepsilon\,(1+\rho_N)}{1-\varepsilon}\le\frac{2\varepsilon}{1-\varepsilon},\qquad
\rho_{\mathrm{floor}}:=c_d(n,N)\,u\,\kappa_{\mathrm{rep}}+\delta_f\quad(\text{первый порядок}).$$

   **Строгое достаточное условие полного ранга (НА-2).** Если rank W* < N, то σ_N(W*) = 0, и по Вейлю σ̂_N ≤ ε·σ₁(W*), σ̂₁ ≥ (1 − ε)σ₁(W*), откуда
   ρ̂_N ≤ ε/(1 − ε). Следовательно, **если ε — доказанная верхняя оценка** относительной ошибки (в смысле этого пункта) и ε < 1:

$$\hat\rho_N>\frac{\varepsilon}{1-\varepsilon}\ \Longrightarrow\ \sigma_N(W^*)>0\ \ (\operatorname{rank}W^*=N).$$

   Различаются три уровня: (1) **точное условие** — при достоверном бюджете ε (c_d и δ_f известны как верхние оценки); (2) **модель первого порядка** —
   ε ≈ c_d·u·κ_rep + δ_f с оценёнными, но не доказанными величинами; (3) **нормативный критерий рабочего решателя** — **NOT_QUALIFIED** (c_d, δ_f, запас
   c_rank — QA и решение владельца). Пока c_d или δ_f неизвестны, ранг **не объявляется сертифицированным**.

   **Что доказано, что — модель.** Строго: тождество для δW, оценки κ_rep (п. 5), мажоранта δ_f через ε_U, ε_V (для точного представления),
   неравенство Вейля, оценка ρ̂_N и достаточное условие ρ̂_N > ε/(1 − ε).
   Стандартные (без источника в библиотеке проекта): обратная устойчивость QR и SVD; константа c_d(n, N) — полином умеренной степени, **не оценена**
   (UNRESOLVED; произвольный коэффициент не вводится). **Модель первого порядка:** отбрасывание членов O(u²), O(δ_f·u) и запись ρ_floor как
   «c_d·u·κ_rep + δ_f». δ_f в рабочем решателе **не известна** как число (п. 9).
8. **Контрпример (рецензия `e6c351f`, разд. 8, `a7_rho.py`).** Поле **точного** ранга 2, записанное тремя членами через плотное плохо обусловленное
   T ∈ GL(3): κ_rep = 1; 4·10²; 2,8·10⁵; 9,1·10⁸ ⇒ вычисленное ρ₃ = 9·10⁻¹⁷; 1,7·10⁻¹⁴; 5,7·10⁻¹²; **5,7·10⁻⁹**; ортогонализация уже вычисленных факторов
   уровень не снижает (3,8·10⁻⁹). [SCRATCH, `scratch/r4fix/`] Независимое повторение: κ_rep = 1,0; 36; 6,8·10³; 8,1·10⁵; 1,0·10⁸ ⇒ ρ̂₃/(u·κ_rep) = 0,43;
   0,16; 0,48; 0,20; 0,07; QR сохранённых факторов даёт κ_rep = 1, а ρ̂₃ остаётся 4,4·10⁻¹⁰. Объяснение: информация теряется уже при хранении
   факторов (это часть δ_f ~ κ_rep·u), а последующий QR уменьшает только диагностическую часть c_d·u·κ_rep. **Вывод:** малое положительное ρ̂_N
   **не доказывает** полного математического ранга, если погрешность факторов имеет тот же порядок; кандидат порога «c(n, N)·u» без κ_rep и δ_f
   точную потерю ранга не обнаружит.
9. **Три случая (различаются; не смешиваются).**
   - **Точная потеря ранга** σ_N(W*) = 0 — устанавливается **доказательством** (априорные условия: n_x < 2N — ЧВ4-8; n_y < 2N — ЧВ4-9; построенные
     тесты с известной зависимостью). Численно она совместима с ρ̂_N ≤ ε/(1 − ε), но численно не доказывается.
   - **Численно неразличимый ранг:** ρ̂_N ≤ ε/(1 − ε) (в модели первого порядка — ρ̂_N ≲ ρ_floor), либо бюджет ε не установлен — по вычисленным
     данным нельзя решить, rank W* = N или < N. **Не отождествляется** с математически недостаточным рангом.

     c_d и δ_f действительно мажорируют ошибки. Пока δ_f не оценена (разд. 5.2.1), этот вывод условен и ранг не сертифицирован.

### 5.4. Нормировка, ортогонализация и GL(N) [ВЫВОД ПРОЕКТА ЧВ4-13; ПРИНЯТО ВБ-16]

**Допустимость.** Дискретный аналог ВБ-16: M_h(UT) = M_h(U) для T ∈ GL(N) (span не меняется), поэтому проекция Π_h на подпространство — то же поле;

**Предпосылка (Б-1):** R невырождена **численно**, т. е. набор надёжно различим как набор полного ранга (разд. 5.4.1). QR численно вырожденного

### 5.6. ВБ-20 и рабочая диагностика [ПРИНЯТО ВБ-20; ПРЕДЛОЖЕНИЕ о роли]

- Условие err_abs(N, s₀) < d_{N−1} — доказанное **достаточное** условие сохранения ранга (ВБ-20). Его проверка требует (а) оценки err_abs относительно ω₀ —
  только с независимым эталоном; (б) **гарантированной нижней** оценки d_{N−1} ≥ D^{1/2}λ₁₁δ_{N−1} (ВБ-19), где δ_{N−1} — L₂-расстояние до полей ранга ≤ N − 1.
- Конечное спектральное усечение даёт **оценку**, а не сертифицированную границу непрерывной задачи; сертификация требует строгой оценки хвоста — UNRESOLVED.
- Поэтому ВБ-20 — **диагностическая проверка групп A/B**, но **не** рабочий критерий: основной решатель не зависит от эталона Навье и обнаруживает потерю
  ранга непосредственно (ρ_N, разд. 5.2).
- Внешние спектральные эксперименты, указывающие на выполнение условия при s₀ = 2 для отдельных N и r, — **неподтверждённое исследовательское
  наблюдение**, не доказательство и не квалификационный PASS.

### 6.2. Дискретное тождество [ВЫВОД ПРОЕКТА ЧВ4-14]

1. **Минимум одного и того же Π_h.** Решение (ЧФ-1) — точный минимум **того же** Π_h (одни n_x, n_y, a, b, D, q, одна квадратура) на M_h(U) (ЧВ4-2, ЧВ4-5).
   Это верно и после ортогонализации (разд. 5.4): подпространство то же.
2. **Тождество.** w⁽ˢ⁻¹⁾ ∈ M_h(заданный набор полушага s) по построению (при нечётном s w⁽ˢ⁻¹⁾ = X^{s−1}(Y^{s−2})ᵀ, заданный набор — X^{s−1}; при ортогонализации —
   через преобразованный V_prev, разд. 5.4). По ЧВ-10 (не зависит от N): Π_h(w⁽ˢ⁻¹⁾) − Π_h(w⁽ˢ⁾) = ½‖w⁽ˢ⁻¹⁾ − w⁽ˢ⁾‖²_{a_h} ≥ 0. Инвариантно относительно
   представления.
3. **Неточное решение (обобщение ЧВ-15).** Пусть V̂ — вычисленное решение, ρ := F ⊗ 𝟏 − 𝒦vec(V̂) (блоки ρ_i), d_i := V_{prev,i} − V̂_i, d := U(V_prev − V̂)ᵀ. Тогда
   (алгебраически, при любом V̂)

$$\Delta P_s:=\Pi_h(w^{(s-1)})-\Pi_h(\hat w^{(s)})=\tfrac12\|d\|^2_{a_h}-\gamma_s,\qquad \gamma_s=h\sum_{i=1}^{N}\rho_i^{\mathsf T}d_i ,$$

   h — шаг сетки решаемого полушага. *Доказательство:* Π_h(v) − Π_h(ŵ) = ½a_h(v − ŵ, v − ŵ) + [a_h(ŵ, v − ŵ) − l_h(v − ŵ)], v − ŵ = d ∈ M_h(U); скобка
   = −hΣ_id_iᵀρ_i (ЧВ4-2). При N = 1 — ЧВ-15 R2.

### 6.3. Округление энергетического теста при N ≥ 2 [ВЫВОД ПРОЕКТА ЧВ4-15; модель первого порядка; исправлено по НБ-3]

Прежний кандидат R_f^{(N)} = R_f·max(1, κ_W) (κ_W по максимуму) **снят**: в нём не было множителя γ_N и нормовой формы. Ниже — анализ первого порядка
по образцу NUMERICAL_SPEC 10.3 (И-8). Пути вычисления — как в R2: P_{s−1}, P_s — двумерной сборкой по сформированным полям ŵ^{(s−1)}, ŵ^{(s)};
Q_s — двумерной сборкой по разности сформированных полей; γ_s — по невязке.

1. **Сборка Π_h.** Модель R(w) (NUMERICAL_SPEC 10.3) определена по полю и переносится без изменений [ПРИНЯТО И-8].
2. **Ошибки уже вычисленных факторов в тест не входят.** Тождество ЧВ4-14, п. 3, верно для **точных произведений** сохранённых массивов
   w̃^{(s−1)} = ÛṼ_prevᵀ, w̃^{(s)} = ÛV̂ᵀ при любой точности Û, V̂, V_prev: w̃^{(s−1)} ∈ M_h(Û) по построению, неточность решения учтена γ_s. Условие:
   P_{s−1} вычисляется по **тем же** (после QR — преобразованным, разд. 5.4) массивам, что используются на полушаге s. Прямые ошибки факторов
   (δ_f, разд. 5.2) влияют на точность поля, но не на корректность теста.
3. **Образование поля.** ŵ_ij = fl(Σ_{k=1}^{N}U_ikV_jk). Для скалярного произведения длины N при **любом** порядке суммирования (в том числе блочные и
   многопоточные редукции BLAS, FMA, расширенные аккумуляторы) [СТАНД.; источника в библиотеке нет] — **при предпосылках (НА-5):** (1) стандартная
   модель IEEE 754 fl(a ∘ b) = (a ∘ b)(1 + δ), |δ| ≤ u, округление к ближайшему; (2) нет переполнения; (3) нет потери значимости — при субнормальных
   промежуточных значениях добавляется абсолютный член ≲ N·2⁻¹⁰⁷⁴, а при режимах FTZ/DAZ (сброс субнормальных в ноль) модель **не гарантирована**;
   (4) классическое вычисление скалярных произведений, без быстрых схем умножения (Штрассен, Виноград и т. п.), для которых поэлементная оценка неверна;
   (5) Nu < 1. Для полей R4 (|w| ~ 10⁻³…10⁻² в единицах qa⁴/D) поправка (3) пренебрежима, но предпосылки входят в условия применения:

$$|e_{ij}|:=|\hat w_{ij}-\tilde w_{ij}|\le\gamma_N\,S_{ij},\qquad S:=|U|\,|V|^{\mathsf T},\qquad \gamma_N=\frac{Nu}{1-Nu}\quad(Nu<1).$$

   Попарное суммирование даёт γ_{⌈log₂N⌉+1}, но только при фиксированном собственном порядке операций (D-025) — здесь не предполагается.

   **Взаимное уничтожение слагаемых (исправлено по НА-1).** Различаются два множителя с разными знаменателями:

$$\tilde\kappa_W:=\frac{\|S\|_h}{\|\tilde w\|_h}\ (\text{точное произведение сохранённых факторов}),\qquad

## 8. Независимая верификация — принципы

- **Группа A** — правильность реализации численного алгоритма; **группа B** — точность КК-МВИ относительно точного решения; не смешиваются (D-025).
- Независимый эталон не вызывает основной решатель (AGENTS.md, разд. 4; D-028); сравнение реализации с самой собой — не эталон.
- Допуски фиксируются **до** сравнений; допуски R2/R3 на N ≥ 2 **не копируются** без обоснования; где бюджет эталона > 1/100 наименьшей измеряемой
  ошибки — UNRESOLVED по образцу РВ-3 (D-040). Распространение правила 1/100 на R4 — [ПРИНЯТО D-046] как принцип измеримости; численные эталоны R4 этим нормативно не квалифицированы (NOT_QUALIFIED).
- Бюджет эталона — фактическая оценка его ошибки (строгая часть + модель округления); **нормативный допуск квалификации** (например, δ_w = 10⁻⁶w̄_c
  Навье, D-037) бюджетом не является. Бюджеты прогиба и энергии разделены (разд. 9.5).

### 9.1. Эталон s = 1 по Леви — ориентация [ПРИНЯТО R3_NUMERICAL_SPEC 9.2]

Существующий `levy_series_w` строит ряд вдоль **короткой** стороны; при r < 1 его члены — старт по y, а не по x (R3, табл. «В»). Поэтому **существующий

**Один математический эталон — два способа вычисления** [поправка С-2, редакция 2026-10-16; рецензия `3aaca8e`, разд. 2, 2.1, 8]. Тождество ЧВ4-16 сохраняется:
первый N-членный полушаг (старт нечётными синусами по x) = x-ориентированная частичная сумма Леви по m ∈ {1, 3, …, 2N − 1} = m-усечённая сумма Навье

Навье c_mn (ряд сходится равномерно, c_mn ~ n⁻⁵); Reviewer подтвердил тождество численно — расхождение ≤ 4,3·10⁻¹⁵ от max|w| при всех проверенных r,
в том числе r < 1 (`3aaca8e`, разд. 2). Ниже — **эквивалентные способы вычисления одного и того же эталона**, а не изменение авторского КК-МВИ

#### 9.5.2. Энергия Π(ω₀) — отдельно от прогиба

e_rel(N, s) и err_abs требуют Π(ω₀) = −½qJ. Бюджет энергии **не следует** из бюджета прогиба: хвост ЧВ-R2a при M = 2559 — 3,40·10⁻¹⁴ qa⁶/D
(2,0·10⁻¹¹ относительно при r = 1; 1,3·10⁻¹⁰ при r = 1/5). **При r = 1** по правилу 1/100 этого достаточно для N ≤ 3 (e_rel = 2,4·10⁻⁸ при N = 3 ⇒ отношение
8·10⁻⁴) и **недостаточно для N ≥ 4** (отношения 0,02; 0,3; 3,8 при N = 4, 5, 6).

**Уточнение области (поправка С-1, редакция 2026-10-16; рецензия `3aaca8e`, разд. 6.2).** Прежняя формулировка «достаточно для N ≤ 3» получена **при r = 1** и на все
допустимые отношения сторон **не распространяется**. По независимой проверке Reviewer (хвост ЧВ-R2a относительно 40-значного |Π₀|; e_rel — по непрерывной
последовательности QA, M = 2001, NOT_QUALIFIED; s = 2 и стабилизированное s = 12) правило 1/100 для энергии Навье M = 2559:
- **N = 2** — выполнено на **всех десяти** проверенных r (отношение ≤ 3,8·10⁻⁴);
- **N = 3** — выполнено на **восьми из десяти** проверенных r (r ∈ [1/3, 3], отношение ≤ 4,7·10⁻³, запас ≥ 2);
- **N = 3, r = 1/5 и 5** — **нарушено** для некоторых s: при стабилизированном s — для обоих r (2,0·10⁻²), при s = 2 — для r = 5 (1,6·10⁻²);
- **N ≥ 4** — недостаточно (см. выше).

Эти результаты относятся **к проверенным точкам** (десять контрольных r, указанные s) и **не доказывают** пригодность целого интервала отношений сторон.
Правило 1/100 не меняется; бюджет эталона прогиба (разд. 9.5.1) бюджетом энергии **не подменяется**.

**Отдельный QA-эталон Π(ω₀)** (`r4_energy_reference`: J = (64qab/(π⁸D))·S, строгий хвост 0 ≤ S − S_M ≤ (a⁴ + b⁴)π²/(80M⁵) при нечётном M, оценка

исследования** (рецензия `3aaca8e` — REVIEW_READY_TO_USE_FOR_COMPARISON, с редакционным Р-1), но **нормативно не принят** (NOT_QUALIFIED, D-046, РВ4-8).

Варианты для энергетической части [ПРЕДЛОЖЕНИЕ — ТРЕБУЕТ РЕШЕНИЯ ВЛАДЕЛЬЦА; РВ4-8]:
