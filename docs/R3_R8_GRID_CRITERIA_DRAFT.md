## 3. Формулы и количество допустимых пар семейства II

**[ВЫВОД ПРОЕКТА] Общая формула.** Пусть r = p/q, НОД(p, q) = 1. Из n_y/n_x = p/q следует n_x = qt, n_y = pt для целого t ≥ 1.
Требуется 4 | qt и 4 | pt. Так как p и q взаимно просты, хотя бы одно из них нечётно; для нечётного множителя 4 | (нечётное)·t ⇔ 4 | t.
Значит, t = 4k, и обратно, при t = 4k обе компоненты кратны 4. Итог:

$$(n_x,n_y)=(4qk,\;4pk),\qquad k=1,\dots,k_{\max},\qquad k_{\max}=\Bigl\lfloor\frac{640}{4\max(p,q)}\Bigr\rfloor=\Bigl\lfloor\frac{160}{\max(p,q)}\Bigr\rfloor .$$

- Минимальная пара — (4q, 4p). Число допустимых пар равно k_max.
- Вложенные последовательности с удвоением — это цепочки k = k₀, 2k₀, 4k₀, … ≤ k_max с нечётным k₀.
  Число цепочек равно ⌈k_max/2⌉; длина цепочки с началом k₀ — ⌊log₂(k_max/k₀)⌋ + 1 уровней. Каждая допустимая пара входит ровно в одну цепочку.
- Проверено перебором в точных дробях (scratch, вне git): для каждого r число пар совпадает с k_max, минимальная пара — (4q, 4p);
  для каждой пары a/n_x = b/n_y точно; обе компоненты кратны 4; max ≤ 640.

|---|---|---|---|---|---|---|
| 1/5 | (20,4) | (20k, 4k) | 32 | 32 | 16 | 6 уровней: k = 1…32 |
| 1/3 | (12,4) | (12k, 4k) | 53 | 53 | 27 | 6: k = 1…32 |

## 4. Вложенные квалификационные последовательности

### 4.1. Мера разрешения, не опирающаяся на дискретный решатель

**[ВЫВОД ПРОЕКТА] Масштаб полушага.** Полушаг s решает одномерное уравнение D(A f⁗ − 2B f″ + C f) = F с постоянными коэффициентами
G_s = (A, B, C, F) (MATH_SPEC 4.3–4.4). Его однородные решения — e^{λξ} с λ² = z, A z² − 2B z + C = 0. В КК-МВИ B² ≤ AC (NUMERICAL_SPEC 8.1),
поэтому корни z₁, z₂ комплексно сопряжены (или совпадают) и |z₁| = |z₂| = √(C/A). Следовательно, модуль характеристических показателей равен

$$\kappa_s=(C_s/A_s)^{1/4}.$$

1/κ_s — длина, на которой меняются однородные (погранслойные) части решения. Из В-29: при s = 1 κ₁ = π/a точно (C/A = (π/a)⁴).

**[ИНЖЕНЕРНЫЙ ВЫБОР] Безразмерное разрешение уровня** — для каждой проверки своё:
- А-4 (только s = 1): ζ_A4 = (π/a)·max(h_x, h_y). Множитель X⁰ имеет масштаб π/a; Y¹ — κ₁ = π/a.
- А-5 (s = 1, 2, 3): ζ_A5 = max(πh_x/a, κ₁h_y, κ₂h_x, κ₃h_y). Нечётные s решаются по y, чётные — по x.

**[ЭВРИСТИКА] Почему именно ζ.** В разложении второй разности L f = f″ + h²f⁗/12 + h⁴f⁽⁶⁾/360 + … отношение следующего члена к главному
для функции с показателем κ имеет порядок (κh)²/30. Поэтому отклонение наблюдаемого порядка p от 2 и отношение Ричардсона должны
масштабироваться примерно как ζ². Данные R2 этому согласуются [ИЗ R2, STATUS, А-4а, А-4б]:
- p − 2 = 0,0019 на (80,80) → (160,160) и 0,0005 на (160,160) → (320,320) — отношение 3,8;
- отношение Ричардсона в центре 1,8·10⁻³ и 4,4·10⁻⁴ — отношение 4,1.

Асимптотическое разложение ошибки не доказано (NUMERICAL_SPEC 5.5; D-032, п. 7), поэтому ζ — эвристика, а не теорема. Она
сопоставляет только скорость наступления асимптотического режима. Константы ошибки (амплитуда вклада погранслоя в max-норму)
ею не учитываются.

### 4.2. Классы уровней [ИНЖЕНЕРНЫЙ ВЫБОР; пороги — только величины R2]

Для проверки c ∈ {А-4, А-5} уровень относится к одному из классов:

### 4.3. Выбор цепочки семейства II [ИНЖЕНЕРНЫЙ ВЫБОР]

## 5. Пары для порядка p

**[ИНЖЕНЕРНЫЙ ВЫБОР] Правило P (строгое, рекомендуемое).**
- Критерий p ∈ [1,9; 2,1] переносится из R2 **только** на пары, оба уровня которых — Q для данной проверки.
- Берутся две самые грубые Q-пары выбранной цепочки: (L, 2L) и (2L, 4L), где L — первый Q-уровень. Так при r = 1 получаются пары R2.
- Если Q-уровней меньше трёх, используются имеющиеся Q-пары: это ограничение. Если Q-пар нет, критерий **UNRESOLVED** для этого r
  и семейства, а p вычисляется только как диагностика.
- **Монотонность** (R2: «e_c убывает с n = 20») требуется на всех A- и Q-уровнях цепочки.
- G-уровни — только диагностика, без PASS/FAIL.

Порядок вычисляется по эталону: А-4 — против Леви (s = 1), А-5 — против полуаналитического эталона (s = 1, 2, 3); p = log₂(E(L)/E(2L))
в общих узлах (NUMERICAL_SPEC 12). Для p достаточно двух уровней пары. Тройка (L, 2L, 4L) даёт две независимые оценки p.

| r | семейство | А-4: пары p (правило P) | А-5 (и А-5в): пары p (правило P) | монотонность А-5 (A ∪ Q) |

## 6. Пары для Ричардсона

**[ИНЖЕНЕРНЫЙ ВЫБОР]** Критерии А-4б и А-5б (|w_RE − w_ex| ≤ 0,05·|w_2n − w_ex|, центр и поле) применяются только на парах правила P
(разд. 5, только Q-пары). Как в R2 (NUMERICAL_SPEC 12), критерий применяется к паре, только если на ней наблюдаемый p ∈ [1,9; 2,1].
- w_RE(L, 2L) = (4w_{2L} − w_L)/3 в узлах сетки L — общих узлах вложенной пары; при удвоении обеих компонент узлы сетки L — это
  узлы (2i, 2j) сетки 2L.
- Экстраполяция выполняется при фиксированном s и не называется пределом КК-МВИ по s (NUMERICAL_SPEC 12).
- Пары Ричардсона совпадают с парами p правила P (табл. разд. 5). Для r = 5 (оба семейства), r = 1/5 (А-5) — **UNRESOLVED**:
  Q-пар нет. Для r = 3 и для r = 1/3 (А-5) — одна пара.
- А-2б (одномерный решатель) от r не зависит: пары n = 80 → 160, 160 → 320 одномерной сетки сохраняются.
- В правиле P-B Ричардсон не применяется (разд. 5).

Использование уровня 640 в критериальных парах (например, (320,320) → (640,640) при r = 7/5, 3/2, 2) допустимо:
- А-1а, А-6, А-8 квалифицированы до n = 640 (R2; Е-3 черновика R3);
- ошибка дискретизации на этих уровнях (ζ ≥ ζ^{R2}(640)) по эвристике разд. 4.1 не меньше, чем у R2 при n = 640 (8·10⁻⁷ по E_disc), что
  на 5 порядков выше уровня округления А-1а (3,5·10⁻¹²);
- D-032, п. 7 делает 640 необязательной, но не запрещает.

## 7. Анализ пограничных слоёв

### 7.1. Аналитически обоснованное

- **Порядок O(h_x² + h_y²)** для каждого фиксированного s доказан при любых a, b, т. е. при любом r (ЧВ-7, ЧВ-8a, ЧВ-8;
  NUMERICAL_SPEC 5.4–5.5). При s = 1 доказательство полное без h₀ (Ã = A точно). Константы зависят от ‖f⁽⁴⁾‖, ‖f⁽⁶⁾‖ множителей и
  потому от κ_s. Асимптотическое разложение e = c_x h_x² + c_y h_y² + O(h⁴) **не доказано** — ни для квадрата, ни для прямоугольника.
  Переход к нему — эмпирическая предпосылка Ричардсона (D-032, п. 7).
- **Первый полушаг (В-29).** Y¹ = C₀[1 − P ch(κη) + Q κη sh(κη)], κ = π/a, η = y − b/2, α = κb/2 = πr/2.
  - **r > 1.** Однородная часть Y¹ сосредоточена у краёв y = 0, b: относительный вклад ~ e^{−κd} на расстоянии d от края. Это
    погранслой ширины ~a/π = a_L/π, а середина пластины близка к полоске. В семействе I на ширину a/π приходится n/(πr) шагов по y,
    в семействе II — n_x/π. Для сравнения, R2: n/π шагов (25,5 при n = 80; 6,4 при n = 20).
  - **r < 1.** κb = πr ≤ π·2/3, однородная часть плавная на всём (0, b), погранслоя по y нет. Множитель X⁰ = sin(πx/a) точен в узлах,
    ошибки сеточных коэффициентов O(h_x²) с явной константой (ЧВ-6, NUMERICAL_SPEC 5.5).
- **ЧВ-R1** (перестановка осей): расчёт a × b со стартом по x и r < 1 эквивалентен расчёту b × a со стартом по y. Отсюда симметрия
  таблиц разд. 4 для r и 1/r в классах А-5. Для А-4 симметрии нет: первый полушаг при r < 1 плавный.

### 7.2. Предварительные результаты непрерывной рекурсии

[НЕПРЕРЫВНАЯ РЕКУРСИЯ; не дискретный решатель]
- **r ≥ 1.** Нечётные полушаги (по y) имеют κ ≈ π/a (3,143…3,154) при всех r: погранслой ширины ~a_L/π у краёв y = 0, b.
  Чётные полушаги (по x) плавнее: κ₂ = 1,02…3,15 убывает с ростом r.
- **r < 1.** Чётные полушаги (по x, длинная сторона) имеют κ₂ ≈ π/b = π/a_L: погранслой ширины ~a_L/π у краёв x = 0, a — с s = 2,
  а не с s = 1. Нечётные полушаги — κ₃ ≈ 3,19…5,09 при r = 2/3…1/5.
- **Итог.** Ширина слоя ~a_L/π (короткая сторона/π) в обоих случаях. Слой лежит вдоль длинной стороны у коротких краёв. Его разрешает
  шаг **по длинной стороне**: N_L = a_L/h_long. В семействе I N_L = n/max(r, 1/r), в семействе II N_L = min(n_x, n_y).
- **Семейство I против II.** В семействе I при r_L = max(r, 1/r) > 1 шаг вдоль длинной стороны в r_L раз крупнее шага вдоль короткой.
  Короткое направление переразрешено, длинное недоразрешено: ζ_A5 ≈ π·r_L/n. В семействе II шаги равны, и ζ_A5 ≈ π/min(n_x, n_y). Но при
  max ≤ 640 короткая сторона получает ≤ 640/r_L интервалов. Поэтому для r_L = 5 **ни одно** семейство не достигает разрешения Q
  на двух уровнях подряд: лучший уровень — n = 640 (I) или (128,640) (II), ζ/ζ^{R2}(80) = 0,62.

### 7.3. Особые случаи

- **r = 3 и r = 1/3.** Q-уровней — два: (320,320), (640,640) в I; (96,288), (192,576) в II (и переставленные для 1/3). Одна Q-пара.
  Уровни A (80, 160 в I) дают монотонность и p по правилу P-B.
- **r = 5 и r = 1/5.** Один Q-уровень. Правило P: p и Ричардсон для А-5 — UNRESOLVED в обоих семействах. Для А-4 — UNRESOLVED
  при r = 5 и полная тройка при r = 1/5 (первый полушаг плавный). Уровни (16,80), (8,40), (4,20) и 20, 40, 80 семейства I — грубые (G):
  ζ_A5/ζ_A5^{R2}(20) ≥ 1,24. Их нельзя использовать для наблюдения асимптотического порядка.
- **r = 7/5.** Семейство II — цепочка (20,28) → … → (320,448). Q-тройка (80,112) → (160,224) → (320,448) соответствует R2 по
  разрешению (0,998). Семейство I требует n ≥ 112 для Q: тройка 160 → 320 → 640. (20,20) при r = 7/5 — G. Это отдельный диагностический
  контроль (Р-1) только в части эталонов (П-12); для группы A r = 7/5 — обычное контрольное r.

### 7.4. Будущая проверка основным дискретным решателем

- Все уровни выбранных цепочек (включая A и G) вычисляются и публикуются: E, p на каждой паре, отношения Ричардсона.
- PASS/FAIL — только по правилам разд. 5–6. Наблюдения на A- и G-уровнях последовательности не меняют.
- Если на Q-паре p вне [1,9; 2,1]: FAIL, и ищется причина по NUMERICAL_SPEC 3.5 (асимптотика, реализация, эталон, остановка).
  Допуск задним числом не меняется, сетки не переназначаются (D-025).
- Если наблюдаемая монотонность нарушена на A-уровне — FAIL по правилу монотонности; G-уровни не оцениваются.

### 7.5. UNRESOLVED

- Достаточность разрешения Q для r ≠ 1 — эвристика ζ, а не доказательство. Константа ошибки может зависеть от r иначе, чем ζ
  (например, через вклад погранслоя в max-норму поля).
- r = 5, 1/5 (А-5) и r = 5 (А-4): в пределах 640 асимптотический режим в смысле R2 (класс Q на двух уровнях подряд) не достигается ни
  в одном семействе. Обосновать применимость p и Ричардсона правилом P нельзя.
- r = 3, 1/3: только одна Q-пара; две независимые оценки p в смысле R2 недоступны.
- Разложение ошибки с членами нечётной степени h у границы (локальная невязка O(1) в строках 1, n − 1; ЧВ-7) не исследовано и для R2.

## 10. Ограничения и UNRESOLVED

1. **Мера ζ — эвристика.** Классы Q/A/G опираются на модуль характеристических показателей одномерных задач (точный) и на гипотезу,
   что асимптотический режим определяется ζ так же, как в R2 (не доказано; асимптотическое разложение ошибки не доказано и для R2).
2. **r = 5:** p и Ричардсон для А-4 и А-5 — **UNRESOLVED** по правилу P в обоих семействах. В пределах 640 есть только один Q-уровень.
3. **r = 1/5:** А-5 — UNRESOLVED (один Q-уровень). А-4 — полная тройка.
4. **r = 3, 1/3:** одна Q-пара (А-5; для r = 3 также А-4): меньше трёх Q-уровней. Записано как ограничение без изменения предела
   и критериев.
5. **Правило P-B** (разд. 5) — только предложение; его эвристическая основа — перенос констант квадрата.
6. **А-7** открыт до результата Р-7.
7. **А-1а, А-3, А-10б** требуют дополнительной квалификации в новой области (разд. 8).
8. Значения κ_s получены квалифицированным эталоном непрерывной рекурсии (QA `a636baf`), но сами по себе независимо не проверены
   как «мера разрешения». Их роль — классификация уровней, а не PASS/FAIL.
9. Вклад погранслоя в константу ошибки при r ≠ 1 (а не только в скорость наступления асимптотики) не оценён.
