## 2. Собственный вывод двумерного спектрального контроля

1. **Сетка и спектр** [ПРИНЯТО NUMERICAL_SPEC 3.1; R4_NUMERICAL_SPEC 2.2]. На G(ℓ, n) оператор L с f₀ = f_n = 0 симметричен; Ψ_ik = √(2/n)sin(πik/n)
   симметрична и ортогональна, −L = Ψ diag(μ) Ψ, μ_k = (4/h²)sin²(kπ/(2n)). Проверено тестом (n = 4, 13, 40).
2. **Поле в коэффициентах.** Для поля W на внутренних узлах Ŵ := Ψ_x W Ψ_y. Так как Δ_h W = L_x W + W L_y, имеем
   Δ_h W = −Ψ_x(diag(μ^x)Ŵ + Ŵ diag(μ^y))Ψ_y, и по ортогональности Ψ
   a_h(w, w) = D h_x h_y Σ_kl λ_kl Ŵ_kl², **λ_kl = (μ^x_k + μ^y_l)²**; l_h(w) = q h_x h_y c^xᵀŴc^y, c := Ψ1.
3. **Квадратичная форма относительно минимума.** С Ŵ*_kl := q c^x_k c^y_l/(D λ_kl) (коэффициенты дискретного минимизатора ω_h) проверяется
   раскрытием квадрата: Π_h(w) = ½D h_x h_y Σ λ_kl (Ŵ_kl − Ŵ*_kl)² − ½D h_x h_y Σ λ_kl Ŵ*_kl².
4. **Y-полушаг.** При заданном наборе U (узловые значения, столбцы — функции) W = UVᵀ, Ŵ = Û V̂ᵀ с Û = Ψ_xU, V̂ = Ψ_yV. Функционал распадается по
   y-модам l: для строки v_l = V̂_{l,·}
   min_v Σ_k λ_kl (Û_{k,·}·v − Ŵ*_kl)² — взвешенная линейная задача наименьших квадратов с матрицей diag(√λ_{·l})Û, решаемая Householder QR
   (без нормальных уравнений). X-полушаг — то же с заменой x ↔ y. Поле полушага — a_h-ортогональная проекция ω_h на M_h(U), других предположений нет.
5. **Независимость от представления.** Минимум зависит только от span(U); поэтому заданный набор может быть заменён ортонормированным базисом
   своей оболочки (поле в точной арифметике то же). Контроль по умолчанию так и делает; режим без ортонормирования оставлен для проверок
   инвариантности. Регуляризации нет: численно зависимый набор виден по большому cond и не исправляется.
6. **s = 1, нечётные синусы.** Столбцы X⁰ — собственные векторы L_x: Û = √(n_x/2)·(e_{m_1}, …, e_{m_N}), задача каждой моды диагональна, и
   W¹ = Ψ_x P Ŵ* Ψ_y, где P оставляет x-моды m = 1, 3, …, 2N − 1 (замкнутая форма; совпадение с МНК-путём ≤ 10⁻¹³).
7. **Отдельные узловые проверки** (путь энергии R2, без спектра): Π_h по двумерной сборке Δ_h; стационарность Π_h на M_h(заданного набора)
   через Δ_hᵀΔ_hW, отнесённая к масштабу округления с абсолютным шаблоном |Δ_h|²|W|; дискретное тождество ЧВ4-14
   Π_h(w⁽ˢ⁻¹⁾) − Π_h(w⁽ˢ⁾) = ½‖w⁽ˢ⁾ − w⁽ˢ⁻¹⁾‖²_{a_h}.

Это та же дискретная задача, а не другой метод: на каждом полушаге все N функций определяются совместно (одна задача на M_h(U)); замена
КК-МВИ иным способом приближения не производится.

## 4. QA-δ2: DST-I

**Определение.** `scipy.fft.dst(x, type=1, norm="ortho")` для вектора длины n − 1 равен Ψx (проверено при n = 4…640, все входы).
