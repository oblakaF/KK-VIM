## 2. ‖M‖₂ без плотной матрицы и без решения о ранге (ПБ-3)

M = I − WZᵀ, W = Y₀S⁻¹ (ВОК-12, п. 1); n = N·m.

1. **n ≤ 4N** (m ≤ 4, то есть n_s ≤ 5, включая пограничные n_s = 3): M формируется плотно (не больше 12 × 12), ‖M‖₂ — по SVD. Выбор
   ветви ВОК-12, п. 4 не нужен. Здесь же случаи n_y ≤ 3, где оценка ‖M‖₂ ≥ 1 не гарантирована (`f62cd79`).
2. **n > 4N.** Q — ортонормированный базис столбцов [Z, W] (n × 4N, хаусхолдеров QR **без** решения о ранге). Тогда 𝒮′ := span Q ⊇
   𝒮 := span[Z, W] при **любом** ранге [Z, W], и dim 𝒮′ ≤ 4N < n.
   - По ВОК-12, п. 4: M = M|_𝒮 ⊕ I_𝒞, 𝒞 = 𝒮^⊥ ≠ {0}.
   - 𝒮′ = 𝒮 ⊕ (𝒮′ ⊖ 𝒮), и 𝒮′ ⊖ 𝒮 ⊂ 𝒞. Значит, QᵀMQ — это M|_𝒮 и, возможно, единичный блок.
   - Поэтому ‖M‖₂ = max(1, ‖Qᵀ(I − WZᵀ)Q‖₂) в точной арифметике, независимо от численного ранга. Собственный вывод QA, уровень Б, из
     доказательства ВОК-12, п. 4.
   - Вычисление: Qᵀ(I − WZᵀ)Q = I − (QᵀW)(Q[rows, :]); плотная n × n матрица не строится.
3. **Статус значения.** Ветвь не зависит от численного решения о ранге, поэтому требование «при недостоверном ранге не выдавать
   результат как гарантию» выполняется тем, что такое решение не требуется. Вычисленное ‖M‖₂ остаётся значением в double
   (OBSERVATION), а не гарантией.
4. **Сверка с документом Literature.** Совпадает с его SCRATCH: (N, n_y) = (1, 3) 0,922; (2, 3) 0,991; (1, 4) 1,035; (3, 5) 1,107;
   n_y = 31 — 10,4; 127 — 86,7.
