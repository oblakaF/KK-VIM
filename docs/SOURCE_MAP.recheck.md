### 1.1. Б-3 по пунктам задания

- **Положительная определённость не подменяет коэрцитивность.** Разд. 6, «Три разных свойства»: (Tw, w) ≥ Dλ₁₁²‖w‖²_{L₂} на D(T) — условие
  Теоремы 1 P81; коэрцитивность на V_b — отдельная оценка в норме W₂²(0, b); прямо сказано, что одной положительности для бесконечномерного
  V_b недостаточно. **PASS.**
- **Применимость теоремы Лакса–Мильграма.** Предпосылки:
  - V_b — гильбертово пространство (замкнутое подпространство W₂²(0, b));
  - форма коэрцитивна (доказано) и ограничена;
  - функционал ∫qXỸ ограничен.

  Ограниченность заявлена, но не выписана (R-3). Она элементарна:
  - |a(XY, XỸ)| ≤ D·max(A, 2B, C)‖Y‖_{W₂²}‖Ỹ‖_{W₂²};
  - |F∫Ỹ| ≤ |F|b^{1/2}‖Ỹ‖_{L₂}.

  Форма симметрична, поэтому достаточна и теорема Рисса. **PASS** при условии R-3 в MATH_SPEC.
- **Достаточность предпосылок для однозначной разрешимости одномерной задачи:** X ∈ W₂² ∩ W̊₂¹, X ≢ 0, q ∈ L₂ — достаточны. **PASS.**
- **Замкнутость M в H_T и вложение M ⊂ H_T.** Рассуждение «XỸ ∈ H_T как предел элементов D(T)» требует, чтобы XỸ_n ∈ D(T). Для этого X ∈ C⁴[0, a]
  с X = X″ = 0 на концах и плотность гладких Ỹ с Ỹ″ = 0 в V_b (например, частичных сумм ряда по sin(nπy/b)). Для всех приближений части A
  (X⁰ = sin, далее X^s ∈ C^∞ с условиями SSSS) это выполнено. Однако в разд. 6 предпосылка 1 допускает X лишь из W₂² (R-2). Неблокирующее:
  на выводы части A не влияет.
