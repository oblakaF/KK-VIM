## 2. Замечания

### Н-1 (исправление моей рекомендации Р-3; до выполнения Е-2)

**Где:** Е-2, «Уточнено по Р-3: T — перестановка столбцов (или смена знаков)… Измеренное ε^E — пол образования и сборки без ошибки решения».

**Проблема.** Сложение и умножение в IEEE 754 коммутативны, а смена знака точна. Поэтому:

- при **N = 1** поля совпадают тривиально;
- при **N = 2** перестановка двух слагаемых (a + b = b + a) даёт **побитово то же** поле при последовательном суммировании. Мой расчёт (Н-2): разность 0;
- при **N = 3** различаются только перестановки, меняющие порядок сложения первой пары: разность ~2·10⁻¹⁶;
- смена знаков даёт поле с точно противоположным знаком — ноль информации.

Ненулевая разность при N = 2 в BLAS (2,2·10⁻¹⁶) — артефакт конкретного ядра, а не мера пола.

Итак, приём Е-2 с перестановкой **не измеряет пол образования при N ≤ 2** и лишь частично измеряет его при N = 3. Буквально выполненный Е-2 дал бы для N = 1, 2 «пол = 0», и это было бы ложным выводом.

**Минимальная правка.** Измерять ошибку образования **непосредственно**: e = ŵ − w̃, где w̃ = ÛV̂ᵀ вычислено по тем же сохранённым массивам в повышенной точности (double-double или `fractions`). Это прямо мажорируется ВОК-4/ВОК-5, и приём GL(N) не нужен. Приём GL(N) с T общего вида оставить вспомогательным, с явным вычитанием ошибки преобразования ~cond(T)·u.

### Н-2 (уточнение, не блокирует)

**Где:** ВОК-13, «Отдельный вклад ε_S»: «ε_fS — округление их сложения (≤ u поэлементно)».

Поэлементная оценка u\|Ŝ\| в 2-норме даёт ‖δ‖₂ ≤ u‖\|Ŝ\|‖₂ ≤ u‖Ŝ‖_F ≤ u(2N)^{1/2}‖Ŝ‖₂. В формулу для ε_S нужно подставлять ε_fS ≤ (2N)^{1/2}u(1 + O(u)), а не u. Порядок величины не меняется.

### Н-3 (сведения)

ВОК-14, «Реализация»: в `main` @ `d315e24` функций `error_bound` и `certify_lambda_min` действительно нет. Они есть в ветках QA Q1b (`aed5ba4`, `9d2e487`; адресная сверка `4f92c82`) и ждут интеграции. Формулировка документа верна; ссылку обновить после интеграции Q1b.
