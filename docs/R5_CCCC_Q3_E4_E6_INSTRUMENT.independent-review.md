## 2. A. Точный эталон

- 𝒦^C = D[A ⊗ D4_s − 2B ⊗ L_s + C ⊗ I] и 𝒦₀ с L_s² вместо D4_s;
- G = D A ⊗ (2/h_s⁴)I₂, Z — граничные строки.

Проверено на 6 системах: Y и X, N = 1–3, с QR и без, D = 1,7, q = 0,3, сетки от 5 × 3 до 10 × 9 и 9 × 12.

## 3. B. Ошибка B-C

**Раздельные нормы.**
- Ошибка набора ‖x̂ − x*‖₂ — интервал корня точного квадрата.
- Ошибка поля ‖Ũ(V̂ − V*)ᵀ‖_a = (h_s δᵀ𝒦^Cδ)^{1/2}, δ = x̂ − x*.
- Это две разные величины, перенос одной на другую не выполняется.

**Тождество NS 4.3 — независимо.** Поле ошибки Ũ·δVᵀ я построил точно и вычислил его a_h по **определению Π_h^C** (E-2 `energy_sq`: граничные строки Ł, веса трапеций). Получилось ‖·‖²_a = h_s δᵀ𝒦^Cδ **точно** в 5 из 5 случаев (Y и X, N = 1–3).

**Невязка R-HP и знак.** `residual_exact` = b − 𝒦^C x̂ — совпадает с моей. Отсюда 𝒦^Cδ = −r и δᵀ𝒦^Cδ = −δᵀr точно, как в модуле. На сертифицированном уровне 𝒦^C(x̂ − x_ac) = r_ac − r — верно.

**Направленность интервалов.**
- **Точный уровень:** [⌊√·⌋, ⌈√·⌉] от точных квадратов (относительная ширина ≤ 2⁻⁶⁴), затем `_down` / `_up`. Мои точные значения ошибки набора, ошибки поля и ‖r‖₂ лежат внутри журнальных интервалов во всех 6 пересчитанных строках (разд. 6).
- **Сертифицированный уровень:**
  - набор: [d − b_ref, d + b_ref], нижний конец не меньше 0;
  - поле: [h^{1/2}‖δ‖_K − h̄^{1/2}b_ref,K, …];
  - корни направлены, b_ref,K = ‖r_ac‖₂/λ_low^{1/2} ≥ ‖x_ac − x*‖_K, поскольку ‖e‖²_K = r_acᵀ𝒦⁻¹r_ac ≤ ‖r_ac‖²/λ_min(𝒦) и λ_low ≤ λ_min(𝒦) по сертификату Q1b.

  Верно.

**ВОК-14 (б) — условия 1–3.**
1. **Невязка.** r̄ = ⌈√‖r‖²⌉ из точной невязки — выполнено.
2. **μ₁.** μ̲₁ = 4/l_s² — точное рациональное. Доказательство: sin x ≥ 2x/π, поэтому sin(π/(2n)) ≥ 1/n и μ₁ = (4/h²)sin²(π/(2n)) ≥ 4/(n²h²) = 4/l_s². Это доказательство, а не double-значение — выполнено.
3. **λ_min(A).** λ̲ — double-кандидат, его допустимость доказывается **точным** LDLᵀ матрицы A − λ̲I. Я проверил независимо (миноры Сильвестра A − λ̲I > 0) в 6 из 6 случаев; λ̲/λ_min(A) = 0,999999 — выполнено.

Сами границы вычисляются в рациональных числах и переводятся вверх. Нуль возникает только при точной нулевой невязке (q = 0), а не из-за потери значимости.

Независимость λ_min(𝒦^C) ≥ Dμ₁²λ_min(A) от B, C ⪰ 0 (ВОК-11, п. 2) обеспечена: B = −hŨᵀLŨ ⪰ 0, C = hŨᵀD4Ũ ⪰ 0.

**Поле.**
- Сертификат поля дан только в ‖·‖_a и только через точное тождество NS 4.3 (`vok14_field_a_bound_up` = h̄_s^{1/2}·b₁₄,K) для **решаемого** набора.
- Поле в max- и 2-норме не сертифицируется, ошибка образования (Е-2, (i)) не включена, `certificates_refer_to` указывает span Ũ.

Переноса сертификата набора на поле нет.

## 5. D. Е-6

**Множители.** ρ₀, κ̄_c, cond(S) и ‖M‖₂ взяты из журнала `r5_cccc_bc` (принят в `5bcc09d`). β_U = λ_max(A⁻¹B), χ_U = λ_max(A⁻¹C), ϑ_U, ϱ = μ₁/(μ₁ + ϑ_U) соответствуют RO 0.2. Мой пересчёт по точным компонентам (разд. 6) совпадает с журналом:

| Набор | Наибольшее относительное расхождение |
|---|---|
| хорошо обусловленные наборы | ≤ 3,3·10⁻⁷ (печать CSV `.6e`) |
| почти зависимый набор без QR | 4,2·10⁻⁴ — по max cond(Mₖ) ~2,7·10¹²; это double-вычисление собственных значений, наблюдение |

Значения `*_exactref` отличаются от моих не более чем на 5,6·10⁻⁵ (‖M‖₂ при cond(S) = 5·10¹²), в остальных случаях — не более чем на 2,5·10⁻⁷.

**Границы ВОК-10, 11, 12** в модуле совпадают с моими: 𝒞_S(n, ϱ) с n = n_s; cond(A)/ϱ²; (λ_max(𝒦₀)/(Dμ₁²λ_min(A)))^{1/2}, λ_max(𝒦₀) = D·maxₖλ_max(Mₖ). Расхождение не больше 3·10⁻⁴, на почти зависимом наборе.

Предпосылки ВОК-10…ВОК-12 (A ≻ 0, B, C ⪰ 0) выполнены для независимого набора. При отсутствии решения ставится NOT_APPLICABLE. Нижняя граница ‖M‖₂ ≥ 1 применяется только при n_s ≥ 4 — соответствует исправленной ВОК-12.

**Правило размерности ‖M‖₂.**
- N·m ≤ 4N — плотно; иначе — подпространство с max(1, ·). Это принятое правило ПБ-3 (`5bcc09d`) и тест QA.
- Мой скан n_s = 3…6, N = 1–3, l_y = 0,05…20: n_s = 3 — min 0,8185 (нижняя граница неприменима, помечено); n_s ≥ 4 — ≥ 1 в журнале.

**ИИ-1 — дефект.** `e6_case` сравнивает `log["M_norm_2"] >= 1` строго в double. В плотной ветви (n_s = 4, 5) max(1, ·) не применяется, а значение ‖M‖₂ = 1 **достигается**: при ‖M|_𝒮‖₂ < 1 единица идёт из 𝒞 = 𝒮^⊥ ≠ {0}. SVD в double возвращает 1 − 2u, и проверка доказанного неравенства получает «VIOLATED (double): check code».

**Контрпример** (воспроизводится, 5 случаев из моего скана):

```
q.e6_case(hs.HalfStep(1.0, 10, 1000.0, 4, "Y", hs.start_set(10, 1)), qr=False)
  -> M_norm_2 = 0.9999999999999998, vok12_check = 'VIOLATED (double): check code'
```

Те же результаты:
- при qr = True;
- при l_y = 3000;
- при N = 2, l_y = 300 с QR (0,9999999999999999).

По ВОК-12, п. 3, при n_s = 4 имеем ‖M‖₂ ≥ 1 точно: нарушения нет, это ошибка округления SVD. RO, таблица 4.3а: «ВОК-10, ВОК-11, ВОК-14 — теоремы… не должны нарушаться **в пределах ошибки вычисления**». Нарушение означает дефект кода или эталона. Ложный «VIOLATED» при Q3 приводил бы к поиску несуществующего дефекта.

На сетках выборки Q3 (n_y ≥ 32) ветвь подпространства с max(1, ·) этого не допускает. Но инструмент принимает любые n_s ≥ 3, и тесты и пилот работают на малых сетках.

**Требуется:**
- сравнивать double-значения доказанных неравенств с **явным** допуском на ошибку вычисления;
  - например, для нижней границы — статус «HOLDS within rounding», если 1 − ‖M‖₂ ≤ c·n·u (c и n названы);
  - либо при n_s ≤ 5 использовать точное значение ‖M‖₂ точного уровня;
- результат вне допуска — VIOLATED, внутри — не VIOLATED;
- тот же принцип записать для верхних границ ВОК-10…ВОК-12 (там запас велик, но правило должно быть единым);
- тест на контрпримере.

**Статусы:**
- N ≥ 2 — RESEARCH_ONLY (с QR и без) и PROVISIONAL / NOT_QUALIFIED (D-049.5);
- N = 1 не помечается;
- ε₀, ε_Y, ε_S, T₁…T₄ — UNRESOLVED с названным недостающим инструментом (B-C не отдаёт x̂₀, Ŷ₀, ĉ; ОК-7);
- εₖ — UNRESOLVED (синусы);
- ВОК-13 — МОДЕЛЬ.

Double-вычисление границ ВОК-10…ВОК-12 обозначено как «double evaluation», а не как сертификат (отчёт, разд. 6). Верно, за исключением ИИ-1.
