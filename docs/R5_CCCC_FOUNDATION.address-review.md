### 2.1. ВБC-20 при dₖ = 0 и кратности выше двух; пример d = (0, 9, −64)

**Постановка.** P(ξ) = Σᵢdᵢ·Πⱼ≠ᵢ(ξ² − κⱼ²)², κᵢ = iκ, κ = 2π/a. При dₖ = 0 каждое слагаемое с i ≠ k содержит (ξ² − κₖ²)². Поэтому кратность ±κₖ **не меньше двух**, но может быть больше: P = (ξ² − κₖ²)²·P̃ₖ, и P̃ₖ(±κₖ) может обращаться в нуль.

**Пример N = 3, d = (0, 9, −64)** [собственный расчёт, Н-1, точная символьная арифметика]:

- P(ξ) = +5(ξ² − κ²)³(59κ² − 11ξ²): корни ±κ₁ — **тройные**. Согласованность: P(0) = 5·(−κ²)³·59κ² = −295κ⁸.
  (SymPy выдаёт эквивалентную запись −5(κ − ξ)³(κ + ξ)³(59κ² − 11ξ²), так как (κ − ξ)³(κ + ξ)³ = −(ξ² − κ²)³.)
- Причина: P̃₁(κ₁) = 9(κ₁² − κ₃²)² − 64(κ₁² − κ₂²)² = κ⁴(9·64 − 64·9) = 0.
- Аналогично тройные корни дают d = (9, 0, −25) (в ±κ₂) и d = (64, −25, 0) (в ±κ₃). Кратность 4 при N = 3 невозможна: из P̃₁(1) = P̃₁′(1) = 0 по t = ξ²/κ² следует d = 0 (аналогично для k = 2, 3).
- Σdᵢ/i⁴ = 9/16 − 64/81 = −295/1296 ≠ 0; P(0) = −295κ⁸ ≠ 0.

**Что меняет кратность 3 в доказательстве.**

1. g ∈ ker P(D) содержит компоненты (α + βy + γy²)e^{±κ₁y}, а не только (α + βy)e^{±κ₁y}, как сказано в шаге 3.
2. Y₁ с L₁ = (D − κ₁)²(D + κ₁)²: L₁(p(y)e^{κ₁y}) = e^{κ₁y}·D²(D + 2κ₁)²p. Оператор (D + 2κ₁)² обратим на многочленах, а D² повышает степень прообраза на 2.
   - Поэтому для любой степени m правой части y^m e^{κ₁y} частное решение имеет вид p̃(y)e^{κ₁y}, deg p̃ = m + 2. Проверено символьно для m = 0…3 (Н-1).
   - Для y²e^{κ₁y}: p̃ = (3/(16κ⁴))y² − (1/(12κ³))y³ + (1/(48κ²))y⁴.
3. Показатель сохраняется: ±κ₁ ≠ 0. Все показатели g + 2ΣYⱼ⁗ лежат в {корни P} ∪ {±κⱼ} ∌ 0, так как P(0) ≠ 0.
4. Противоречие с 4q/D ≠ 0 следует из линейной независимости y^m e^{ξy}. Ни точная кратность, ни степень многочленов в нём не участвуют.

**Вывод.** Доказательство необходимого условия Σdᵢ/i⁴ = 0 **сохраняется без предположения о точной кратности**:

- шаг 4 (`4660c28`) уже сформулирован для произвольной степени (deg p̃ ≤ deg p + 2);
- резонанс возможен только при dⱼ = 0, так как P(±κⱼ) = dⱼΠᵢ≠ⱼ(κⱼ² − κᵢ²)²;
- доказательство использует только показатели.

Пример d = (0, 9, −64) теоремой и исключается: Σdᵢ/i⁴ ≠ 0, поэтому такое d не может быть направлением вырождения.

**АП-1 (CM ВБC-20, шаг 3, и разд. 14; обязательная правка до включения в MATH_SPEC, результат не меняется).**
