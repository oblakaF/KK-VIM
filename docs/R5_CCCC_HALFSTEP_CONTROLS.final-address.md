## 2. И-2 — `certify_lambda_min()` (стр. 299–349): PASS

**Доказательство (проверено самостоятельно).**
1. M = K − tI, t = Fraction(float(τ)) — точная рациональная матрица.
2. R̂ — верхнетреугольная, диагональ R̂ᵢᵢ = √s > 0. Ветки `s <= 0` и `rii <= 0` дают `None`. Значит, R̂ невырождена и R̂ᵀR̂ ≻ 0.
3. E = R̂ᵀR̂ − M вычисляется точно: элементы Decimal переводятся в Fraction без потерь.
4. По неравенству Вейля λ_min(M) ≥ λ_min(R̂ᵀR̂) − ‖E‖₂ > −‖E‖₂. Для симметричной E ‖E‖₂ = ρ(E) ≤ ‖E‖∞.
5. λ_min(K) > t − ‖E‖∞ = low. Затем `_float_down(low)`; при low ≤ 0, нуле или субнормальном double — `None`.

Выводы верны. Строгое неравенство обеспечено п. 2.
