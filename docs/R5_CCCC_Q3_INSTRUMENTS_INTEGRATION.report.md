## 6. Неблокирующие ограничения Н-1…Н-6 (рецензия `adf4877`, разд. 7)

Н-1…Н-6 зафиксированы как **неблокирующие ограничения** включённой редакции. В интеграционной ветке код их не исправляет, нового
цикла QA не создаётся.

| № | Ограничение | Действует для |
|---|---|---|
| Н-1 | В double И-4 и QR меняют поле: до 4,3·10⁻¹⁶ относительно, в узле. Изменение записывается как OBSERVATION (`P_after_transform_minus_before`). Поле сохраняется только в точной арифметике; формулировку отчёта QA «поле сохраняется» читать так | Г-1, журнал |
| Н-2 | Знак И-4 при ⟨f, 𝟏⟩ = 0 берётся по соглашению σ(0) = +1: NS 4.4 его не определяет, используется сумма в double. При q = 0 и N = 2 статус «S-1, computed set exactly dependent» формально верен, но причина — нулевая нагрузка, а не ZERO_FIELD | Г-1, И-4 |
| Н-3 | **P-2/P-3 (нет переполнения и субнормальных значений) в пути double не проверяются.** Экстремальные масштабы (lₓ = 10⁻¹⁶⁰ или 10¹⁶⁰) дают необработанный `OverflowError`. Для них путь не сертифицирован, и c_R = 22 к ним не относится | Г-4: `pi_double`, `q_double`, `Grid` |
| Н-4 | **Путь B_ω (б) строг лишь при ВОК-4** (П-1…П-5), так как ε_a^C — оценка ВОК-5. Путь (а) строг безусловно | Г-4: `b_omega` |
| Н-5 | Критерий PL «применение оператора ≤ 4u·норма» для double тестом не проверяется: тест точный. Наблюдение Reviewer — ≤ 1,0 на 4 сетках | D2-9 |
| Н-6 | **Печатный CSV — не точный рациональный журнал.** Части разложения дефекта печатаются с 7 знаками. При взаимном уничтожении частей (s = 8, 𝒯₃, Y, 10 × 9) разложение по напечатанным числам не воспроизводится: относительное расхождение 0,24. Само разложение в коде точное | пилот, `sequence.csv` |

Сопутствующее ограничение рецензии (разд. 8): **c_R = 22 — условная модель первого порядка для данного пути double** при П-1…П-5
и предпосылке о `pow` (≤ 1 ulp — только наблюдение на этой платформе). Это не нормативная константа.
