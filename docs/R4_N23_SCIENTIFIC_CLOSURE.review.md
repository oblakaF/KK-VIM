### 3.3. N23-3: нижняя граница d_k

1. **Разложение и ранг.**
   - (α + β)² = α² + 2αβ + β² даёт точное разложение ‖X‖².
   - При rank W ≤ k ранги AW, A^{1/2}WB^{1/2} и WB не превышают k.
2. **Мирский через Вейля.** σ_{k+i}(X) ≤ σ_i(X − Y) + σ_{k+1}(Y) = σ_i(X − Y), поэтому ‖X − Y‖²_F ≥ Σ_{j>k}σ_j(X)². Неравенство Вейля для компактных операторов —
   [СТАНД.]. Теорема Эккарта–Янга, которую ВБ-19 оговорённо не использует, здесь тоже не нужна.
3. **Нижняя граница суммы.** Инфимум суммы не меньше суммы инфимумов.
4. **Подматрицы.** σ_j(PXQ) ≤ σ_j(X) для координатных проекторов, поэтому хвост подматрицы — нижняя граница хвоста оператора. Направление верное.
5. **Задача (а).**
   - AΩ, A^{1/2}ΩB^{1/2} и ΩB — операторы Гильберта–Шмидта: каждый квадрат нормы не больше ‖Ω‖²/c₀.
   - Инфимум по полям 𝓡_k ⊂ {rank ≤ k, конечная энергия} не меньше инфимума по большему множеству. Граница верна и для d_k ВБ-19/ВБ-20.

**Проверка корректности сертификата (построчно):**

1. **Включение точных значений.**
   - π — `iv.pi`; r — точная рациональная `ivq`; все операции цели, весов, невязок и хвостов выполняются в `iv` при 256 битах.
   - Пробный t из double превращается в точный `iv.mpf`: допустим любой t (N23-2).
   - Верхняя сторона — `hi(E2)`, нижняя — `lo(dN1)`. Направления верные.
2. **Собственные числа.**
   - λ_j(S) > t подтверждается, если у S − tI не меньше j положительных пивотов, причём ни один интервал пивота не содержит нуль.
   - LDLᵀ без перестановок: каждый вычисленный интервал содержит точное дополнение Шура точной S. Используются только элементы нижнего
     треугольника столбца p, которые на шаге p не меняются; симметричная копия корректна.
   - Закон инерции Сильвестра даёт знаки собственных чисел.
   - Ориентир t = λ_j^{mid}(1 − 2⁻⁴⁰) берётся из нестрогого `mp.eigsy`. Если он завышен, проверка не проходит, и цикл останавливается:
     граница остаётся верной, так как остальные λ_j ≥ 0.
3. **Отличие доказательных величин от обычного double.**
   - μ и d_N^{low}/err₂^{up} получаются в `mp` с округлением к ближайшему из интервальных концов, а не в `iv`.
   - При запасе μ ≤ 0,265 < 1 и относительной ошибке ~10⁻⁷⁷ это на вывод не влияет (Н-1).
   - Печатные значения таблиц округлены к ближайшему, а не направленно (Н-1).
4. **Крайние случаи.** r = 1/5 и r = 5 при N = 2 и 3 сертифицированы: μ ≤ 0,0795; 0,2650; 0,0700; 0,2009. Наихудший случай — r = 1/5, N = 3.

разд. 5: тот же результат получен без mpmath.

## 6. Ошибка и её перенос: N23-5…N23-8

### 6.1. N23-5: (⋆′)

1. **Числитель.**
   - При ν_n ≥ ν_k функция x ↦ (x + ν_n²)/(x + ν_k²) не возрастает, а κ_m² ≥ κ₁², поэтому отношение (κ_m² + ν_n²)/(κ_m² + ν_k²) ≤ (κ₁² + ν_n²)/(κ₁² + ν_k²) ≤ (κ₁² + ν_n²)/λ₁₁.
   - При ν_n < ν_k отношение < 1 ≤ (κ₁² + ν_n²)/λ₁₁.
   - Поэлементно (κ_m² + ν_n²)²X_mk² ≤ ((κ₁² + ν_n²)/λ₁₁)²λ_mk²X_mk². Верно.
2. **Знаменатель.** Λ_n^{1/2} ⪰ (κ₁² + ν_n²)I ⇒ σ_N(Λ_n^{1/2}C′) ≥ (κ₁² + ν_n²)σ_N(C′). Множитель сокращается.
3. **Итог.** Элементарная форма Ведина (проверена в `d73f497`) и ‖·‖₂ ≤ ‖·‖_F дают (⋆′). Замена ν₁² на λ₁₁ законна.

## 7. N23-9: сходимость при фиксированном N

**Используемая теорема** — градиентное неравенство Лоясевича. Пусть f вещественно-аналитична в открытом множестве ℝ^d и x* — любая точка.
Тогда найдутся окрестность 𝒰 точки x*, C > 0 и θ ∈ [½, 1), такие что |f(x) − f(x*)|^θ ≤ C|∇f(x)| на 𝒰. Источника в библиотеке нет.

**Предпосылки проверены:**

1. **Многообразие.** 𝓜_N — матрицы ранга ровно N — вещественно-аналитическое вложенное подмногообразие. Явная карта: после перестановки
   строк и столбцов W* = [A B; C D] с обратимым A размером N × N, и окрестность W* в 𝓜_N — {[A B; C CA⁻¹B]}. Это аналитическая параметризация
   по (A, B, C), так что утверждение элементарно.
2. **Функционал.** f = Π|𝓜_N — многочлен в карте.
3. **Градиент.** Риманова норма градиента и норма градиента в карте эквивалентны на компактной окрестности, как и сказано в документе.
4. **Ключевая предпосылка: предельная точка лежит в 𝓜_N.** 𝓜_N не замкнуто, поэтому она не очевидна. Обеспечивается компактом 𝒮 ⊂ 𝓜_N.
   - 𝒮 замкнуто и ограничено, а при конечной размерности (б) и (в) компактно.
   - W_s ∈ 𝒮 при s ≥ 2 — по N23-4, п. 2 и ВБ-17.
   - Значит, W* ∈ 𝒮 и rank W* = N.
5. **(H1).** Тождество убыли ВБ-17, ЧВ4-14.
6. **(H2) по шагам** (Y-полушаг s ≥ 3; чётный — симметрично):
   - (а) T = 𝓜(U) + 𝓝(V_s) — касательное пространство; B = (I − P^E_U)Z ∈ 𝓝(V_s); ‖B‖ ≤ κ‖Z‖ через ω_min, ω_max. Верно.
   - (б) G ⊥ 𝓜(U) по условию проекции, поэтому ‖grad f‖ ≤ κ‖P_{𝓝(V_s)}G‖. Верно.
   - (в) col W_s = col W_{s−1} и row W_{s−1} = V_{s−2}, так как ранги равны N. Отсюда P_{𝓝(V_{s−1})}(W_{s−1} − Ω) = 0. Верно.
   - (г) ‖P_{𝓝(V)} − P_{𝓝(V′)}‖ = max_m sinΘ_{Λ_m} (построчное действие, равные размерности); sinΘ(AV, AV′) ≤ κ(A)sinΘ(V, V′). Доказательство верно.
   - (д) Элементарная форма Ведина для пространств строк; ‖·‖₂ ≤ ‖·‖_F ≤ ω_min^{−1/2}‖·‖; σ_N(W_{s−1}) ≥ σ_* при s − 1 ≥ 2.
   - Константа: b = κ(1 + κ²e₂/η), так как ω_min^{1/2}σ_* = η/κ. Пересчитана.
7. **Конечная длина.**
   - Рассуждение типа Аттуша–Болта–Свайтера: убыль f_s − f_{s+1} = ½‖ΔW_{s+1}‖², градиент в W_s ≤ b‖ΔW_s‖.
   - Оценка 2‖ΔW_{s+1}‖ ≤ ‖ΔW_s‖ + 2b[φ_s − φ_{s+1}] и её суммирование в Σ_{s>s₀}‖ΔW_s‖ ≤ ‖ΔW_{s₀}‖ + 2bφ(f_{s₀} − f*) проверены по индексам.
8. **Удержание в окрестности.** Индукция по S: шаги s₀…S лежат в B(W*, ε), поэтому сумма шагов ограничена и W_{S+1} ∈ B(W*, ε). Выбор s₀ возможен,
   так как ‖ΔW_s‖ → 0 (ВБ-18, п. 2) и f_s → f*. Случай f_s = f* разобран. Верно.
9. **Предел.** grad f(W*) = 0 по непрерывности P_T на 𝓜_N. T ⊇ 𝓜(col W*) и T ⊇ 𝓝(row W*), поэтому W* — неподвижная точка обоих полушагов.

**Четыре утверждения, которые нельзя смешивать:**

| Утверждение | (б), (в) | (а) |
|---|---|---|
| сходимость энергии f_s ↓ f* | PROVEN (ВБ-18, п. 2), без [СТАНД.-Л] | PROVEN |
| ‖W_s − W_{s−1}‖ → 0 | PROVEN (ВБ-18, п. 2) | PROVEN |
| сходимость самих полей W_s → W* и конечная длина Σ‖ΔW_s‖ < ∞ | **CONDITIONAL** — при [СТАНД.-Л] | **UNRESOLVED** (κ = ∞, неравенство Лоясевича в бесконечной размерности в общем случае неверно) |
| скорость, единственность W*, независимость от старта | UNRESOLVED | UNRESOLVED |

**Смысл фразы «рано или поздно стабилизируется»** (разд. 5.2 документа):

- Для любого положительного порога найдётся s, начиная с которого изменение поля на двух соседних полушагах ниже порога: ‖ΔW_s‖ → 0,
  а в конечной размерности все нормы эквивалентны.
- Это **не** сходимость и **не** оценка расстояния до предела. Документ формулирует это верно (Н-5 — необязательное дополнение).

**Классификация N23-9:**

- это **условная теорема**, а не безусловное доказательство;
- она относится **только к конечномерным задачам** (б), (в) и только к сертифицированным ячейкам;
- математически она верна; единственное условие — допустимость классической теоремы Лоясевича как основания (Б-3 документа, решение владельца);
- на неусечённую задачу (а) она **не** переносится.

Признание теоремы владельцем проверку её предпосылок не заменяет. Предпосылки проверены выше; принятие источника — отдельное решение.
