    - модель e_sur в этой геометрии откалибрована практически на границе;
    - её нельзя распространять за пределы проверенной области (r < 0,2, другие семейства сеток, s ≥ 4);
    - при любом будущем расширении проверку заместителя нужно повторять на решателе.
  - На вердикт А-7 это не влияет: он основан на **измеренных** m_s (в этих случаях ≥ 90,9), а не на заместителе.
- **Н-2.** Включение (160,160) при r = 7/5 в обязательную область s = 3 решено по заместителю с запасом 0,7 % (m_low ≈ 4,027 против 4).
  Это инженерный порог отбора, а не критерий: фактический m_s = 4,029 ≥ 1 — PASS. Действий не требуется.
- **Н-3.** А-3: наибольшее отклонение 5,76·10⁻¹⁴ (n_x = 640) растёт примерно линейно по n_x. Запас до 10⁻¹³ около 1,7 — допуск выполнен
  в квалифицированной области n ≤ 640 (Р-8). За её пределы результат не переносить.
- **Н-4.** Linux-повтор полного расчёта — сообщение без сохранённых доказательств (разд. 4). Если владелец хочет учитывать его как
  подтверждение воспроизводимости, достаточно сохранить его metadata/логи. Это не условие приёмки.
- **Н-5.** Хэши входных CSV записаны по сырым байтам рабочей копии (CRLF на Windows), хэши скриптов — по LF-блобам.

    зафиксированного файла).
  - Косметическое замечание к происхождению; на данные не влияет.
- **Н-6.** Дублирование цикла остановки в `rectangle_run.py` и `controller.py` — архитектурное ограничение (В.3 отчёта QA).
  Численных последствий нет: побитовая регрессия и независимое воспроизведение правил остановки защищают текущую версию.
- **Н-7.** Неравные сетки (сгущение одной оси): до насыщения встречаются p ≠ 2 (например, 2,54 при r = 1/5, ось x). Вероятная причина —
  взаимная компенсация вкладов c_x h_x² и c_y h_y² разных знаков; она не исследовалась. По спецификации это наблюдение без допуска

- **Н-8.** `sys.path.insert` в тестах Builder (В.4 отчёта QA) — без влияния на результаты.
- **Н-9.** Перенос по ζ — эвристика (D-039). При r = 5 Ричардсон UNRESOLVED по правилу, хотя диагностические отношения ≈ 10⁻⁴. Правило
  закреплено заранее и правильно не изменено задним числом (D-025). Наблюдение говорит лишь о консервативности эвристики на этих данных.

## 6. Что не утверждается

Сходимость КК-МВИ при s → ∞, независимость предела от старта, единственность предела (Q-025); асимптотическое разложение ошибки;
достаточность переноса по ζ вне проверенных сеток; моменты и напряжения R3 (D-034, Q-027); CCCC, N ≥ 2. Энергетические запасы и модель
e_sur подтверждены только на выбранных цепочках I/II.

## 7. Заключение для владельца
