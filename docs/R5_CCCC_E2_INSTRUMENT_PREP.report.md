**Корни и деления.**
- Квадраты норм — точные рациональные числа.
- Корень оценивается снизу и сверху через `isqrt` (точность 2⁻⁶⁴ отн.), затем переводится в double направленно (`_float_down`, `_float_up` модуля Q1b).
- Отношения вычисляются интервалами: [нижняя/верхняя, верхняя/нижняя].
- При нулевом знаменателе (нулевое поле) — `UNRESOLVED`, без подстановки числа.

**Что инструмент не утверждает:**
- значения ‖·‖_a и отношений в double строгими не объявляются;
- строгими являются точные сравнения (ВОК-1, ВОК-4, ВОК-5) и интервалы.

**Перестановка столбцов** (п. 6 задания, Н-1). Функция `swap_difference` — только вспомогательная, `measure` её не вызывает (это
проверяется тестом). Причина: при N = 1, а также при N = 2 с последовательным суммированием, поля с переставленными столбцами
совпадают побитово, и перестановка дала бы ложный ноль. Вспомогательный приём GL(N) с T общего вида не реализован: методика
называет его дополнительным, прямое измерение он не заменяет.
