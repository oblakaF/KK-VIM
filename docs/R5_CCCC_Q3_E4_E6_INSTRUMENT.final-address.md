## 3. ИИ-1а — дефект (п. 5, 6)

`lower_bound_one(m_norm, n_s)` при n_s ≥ 4 и m_norm < 1 **безусловно** возвращает:

```
HOLDS (exact witness: M e_k = e_k ... so ||M||_2 >= 1 exactly; the SVD value is below 1 by {1 - m_norm}: SVD rounding)
```

**Воспроизведение:**

```
q.lower_bound_one(0.5, 4)    -> 'HOLDS (exact witness ... below 1 by 5.0e-01: SVD rounding)'
q.lower_bound_one(1e-9, 5)   -> 'HOLDS (exact witness ...'
# подмена r5_cccc_bc.m_norm -> (0.5, "dense"), e6_case(HalfStep(1.0, 10, 1.0, 4, "Y", start_set(10, 2)), qr=True):
vok12_check = 'HOLDS (double evaluation); lower bound 1: HOLDS (exact witness ...'   vok12_lower_svd_deficit = 0.5
```

**Почему это дефект.**
- Свидетель доказывает **теорему** (‖M‖₂ ≥ 1 для оператора и для сформированной M̂). Он не доказывает, что вычисленное значение 0,5 получено округлением SVD.
- Дефицит 0,5 означает, что программа вычислила ‖M‖₂ неверно: дефект SVD-вызова, формирования M̂, ветви `m_norm` или передачи значения. Это ровно то, что проверка double-значений должна выявлять.
- Строгой оценки ошибки SVD в инструменте нет. QA сам это признаёт в `numeric_check`.
- Значит, приписать дефицит округлению можно не больше, чем назвать его нарушением. Для верхних границ ВОК-10…ВОК-12 QA выбрал UNRESOLVED_ROUNDING; для нижней выбран HOLDS — правило не едино.
- Сводная `vok12_check` начинается с «HOLDS» (`test_ir1_svd_below_one_…` это и требует). Автоматический разбор журнала не увидит проблему: остаётся только числовое поле `vok12_lower_svd_deficit`.

**Минимальное исправление** (без нового допуска):
- при n_s ≥ 4 и m_norm < 1:
  - `vok12_theorem` / `vok12_lower` — «PROVEN by the exact witness» (утверждение);
  - **проверка** double-значения — тем же `numeric_check(m_norm, 1, ">=")`, то есть UNRESOLVED_ROUNDING с `gap_rel` = 1 − m_norm, без слов «SVD rounding» как установленной причины;
- в `vok12_check` нижняя граница при m_norm < 1 не должна давать префикс «HOLDS»;
- тест: подмена `m_norm` на 0,5 → проверка UNRESOLVED_ROUNDING, разрыв 0,5 виден, VIOLATED нет;
- существующий тест 1 − 2u ожидает тот же класс UNRESOLVED_ROUNDING с разрывом 2⁻⁵²;
- в отчёте (разд. 10, п. 3) заменить «значение SVD ниже 1 — округление SVD» на «вероятно, округление SVD; причина не установлена, строгой оценки ошибки SVD нет».

После исправления выполнены оба требования п. 6: нет ложного VIOLATED и нет необоснованного строгого численного HOLDS.
