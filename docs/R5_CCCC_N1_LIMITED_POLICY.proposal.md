## 1. Постановка и область

**Непрерывная задача** [принято: MATH_SPEC, разд. 1.4, 1.5, 10; В-31; D-024].

- Ω = (0, a) × (0, b), начало координат в углу; линейная изотропная однородная пластина Кирхгофа–Лява, D∇⁴w = q, q = const.
- CCCC: w = ∂w/∂n = 0 на ∂Ω [АВТОР P81, с. 369; P82, с. 78, (2)].
- Энергия Π(w) = ½D‖Δw‖² − (q, w), H_T = W̊₂²(Ω), решение ω₀ существует и единственно (В-31).
- Одномерные условия полушагов: Y = Y′ = 0 при y = 0, b; X = X′ = 0 при x = 0, a (В-33).
- Представление N = 1: w = X(x)Y(y); чередование полушагов — авторская схема МВИ (уровень А). Дискретизация ниже — **работа проекта
  (уровень Б), авторам не приписывается**: одномерные условия и разностные шаблоны авторов не напечатаны (MATH_SPEC, разд. 10).

**Область первой версии.** Вне её — отказ до вычислений.

| Параметр | Значение | Основание |
|---|---|---|
| N | только 1; параметра `--N` нет | D-049.7, п. 5; N ≥ 2 — отдельные решения (D-060, п. 4) |
| Форма | прямоугольник, 0,2 ≤ b/a ≤ 5 (проверка `validate_r3_sides`) | выборка D0: r от 1/5 до 5 |

## 2. Дискретная задача [принято: D-049.1; NS 2–4]

Сетка: x_i = i·h_x, h_x = a/n_x, i = 0…n_x; y аналогично; неизвестные — внутренние узлы, на границе w = 0.

- Энергия: Π_h^C(w) = (D/2)(Δ_h^C w)ᵀ(W_x ⊗ W_y)(Δ_h^C w) − q h_x h_y Σ w_ij, где Δ_h^C = Ł_x ⊗ E_y + E_x ⊗ Ł_y, W = diag(h/2, h, …, h, h/2).
- Ł: (Łf)_i = (f_{i−1} − 2f_i + f_{i+1})/h² внутри; (Łf)₀ = 2f₁/h², (Łf)_n = 2f_{n−1}/h² (чётное отражение w₋₁ = w₁).
- D4 := ŁᵀWŁ/h = L² + (2/h⁴)(e₁e₁ᵀ + e_me_mᵀ), m = n − 1. Внутренние строки (1, −4, 6, −4, 1)/h⁴, первая и последняя — (7, −4, 1)/h⁴.
- **Граничная схема SSSS не переносится** (D-049.1, п. 1).

**Полушаг.** Точный минимум Π_h^C по множителю решаемого направления при заданном g направления f. Для N = 1 (ЧФ-C1, ЧФ-C2):

$$D\,[A\,D4_s-2B\,L_s+C\,I]\,y=F\,\mathbf 1,$$
$$A=h_f\,g^{\mathsf T}g,\quad B=-h_f\,g^{\mathsf T}L_fg,\quad C=h_f\,g^{\mathsf T}D4_fg,\quad F=q\,h_f\,g^{\mathsf T}\mathbf 1 .$$

Индексы f и s — заданное и решаемое направления. Система положительно определена при g ≠ 0 (ЧВ4-5 на Π_h^C, D-049.1, п. 5).

## 3. Сборка коэффициентов: C-3⁺ [принято: D-054.3; теорема С-3⁺, PROVEN при П-1…П-5]

Эквивалентность C_{C-3⁺} = C доказана (исследование сборки C, разд. 3.3): C = h XᵀX + (2/h³)(g₁² + g_m²), X = Lg. Уровень В.

**Обязательный порядок операций.** Он нормативен: на этой арифметике получены данные разд. 7.1. `g` — вещественный массив длины m, `G = g[:, None]`.

```python
h  = l_f / n_f
A  = h * (G.T @ G)[0, 0]
P  = zeros(m + 2); P[1:-1] = g
Lg = (P[:-2] - 2.0 * P[1:-1] + P[2:]) / h**2         # двойной путь, как в прототипе; C-3+ касается только C (D-054.3)
B  = -h * (G.T @ Lg[:, None])[0, 0]
F  = q * h * g.sum()

Y3 = rd(g[i-1] - 2*g[i] + g[i+1])                    # точная сумма в Fraction, затем float(): одно корректное округление;
                                                     # значения вне сетки равны 0
h2 = h * h;  h3 = h2 * h;  s = 2.0 / h3
X  = (Y3 / h2)[:, None]
C_L = h * (X.T @ X)[0, 0]
E   = s * (g[0] * g[0] + g[-1] * g[-1])
C   = C_L + E
```

**Запрещено:** собирать C через шаблон D4 в double (способ OLD: ошибка C до 5,6·10⁻⁸ в данных CA); использовать CONTROL или OLD как запасной путь
(D-057.3, OD-8, тот же принцип); пересобирать B через Y3 (не проверено, UNRESOLVED в исследовании сборки C).

**Предпосылки на каждом полушаге, до решения.** П-4 проверить нельзя; остальные проверяются.

| Предпосылка | Проверка | При нарушении |
|---|---|---|
| П-1 | пробы округления к ближайшему (Python, NumPy, `@`) до сборки и после решения | `UNRESOLVED_C3PLUS_PREMISE` |
| П-2 | конечны Y3, X, g₁, g_m, C, C_L, E, h, h², h³, 2/h³; m·max\|X\|² и 2·max(g₁², g_m²)·s меньше DBL_MAX | то же |
| П-3 | нет субнормальных в перечисленных величинах; квадраты наименьших ненулевых \|X\|, \|g₁\|, \|g_m\| и произведение с s не ниже 2⁻¹⁰²²; пробы FTZ/DAZ до и после | то же |

## 4. Решение полушага: B-C [принято: D-049.2; NS 5, 5.1]

𝒦₀ = D[A L² − 2B L + C I] диагонализуется DST-I. Поправка ранга 2 учитывается формулой Шермана–Моррисона–Вудбери. S ≻ 0 доказано (рецензия `4b18761`, 4.1).

```python
h   = l_s / n_s;  m = n_s - 1;  k = arange(1, n_s)
dst = lambda v: scipy.fft.dst(v, type=1, norm="ortho")
mu  = 4.0 / h**2 * sin(k * pi / (2 * n_s))**2
DM  = D * (mu**2 * A + 2.0 * mu * B + C)             # должно быть > 0 для всех k, и A > 0
Minv = 1.0 / DM
x0  = dst(F * dst(ones(m)) / DM)
Y0  = column_stack([dst(Minv * dst(e_1)), dst(Minv * dst(e_m))])
psi = sqrt(2.0 / n_s) * sin(k * pi / n_s)
z   = stack([psi, where(k % 2 == 1, 1.0, -1.0) * psi], axis=1)
S   = h**4 / (2.0 * D) * (1.0 / A) * eye(2) + einsum("k,ks,kt->st", Minv, z, z)     # путь ёмкости "modal"
c   = linalg.solve(S, x0[[0, m - 1]])
y   = x0 - Y0 @ c
```

**A-C — только внешний контроль QA** (D-049.2, п. 2), в решатель не входит. Факторизация R2 (`kkvim.linear_solver`) не используется: на ней нет данных с D4.

**Невязка исходной системы** (NS 5, У-R2), без модального преобразования:

```python
r   = F - D * (A * D4_apply(y, h) - 2.0 * B * L_apply(y, h) + C * y)
eta = max(abs(r)) / (D * (16 * abs(A) / h**4 + 8 * abs(B) / h**2 + abs(C)) * max(abs(y)) + abs(F))
```

Здесь `D4_apply`, `L_apply` — шаблоны разд. 2 в double с делением на `h**4`, `h**2`. **`kkvim.grid.fourth_difference` не подходит:** это L² схемы SSSS.

## 5. Старт, нормировка, последовательность

1. **Старт** (В-32, D-049.3): `g = sin(pi * arange(1, n_x) / n_x)**2`, сопряжённый множитель — нули (w⁽⁰⁾ = 0). Формула фиксирована; её биты зависят от
   платформы (D-057.2, OD-12).
2. **Полушаг s:** при нечётном s решается Y (f = x, s = y), при чётном — X (f = y, s = x). Счётчики s и k = ⌊s/2⌋ пишутся оба (D-030).
3. **Порядок внутри полушага** (NS 5.1 при N = 1, QR нет): g ≠ 0 → предпосылки и C-3⁺ (разд. 3) → B-C (разд. 4) → η и защита по η → нормировка → запись.
4. **Нормировка И-4** (D-049.1, п. 4; NS 4.4), **до** формирования и записи поля:

```python
sigma = 1.0 if math.fsum(y.tolist()) >= 0 else -1.0  # fsum округляет корректно: знак равен знаку точной суммы
c = sigma * max(abs(y))                              # y == 0 всюду → STOP_ZERO_FIELD
f_next, g_next = y / c, g * c
```

5. **Передача.** Заданный множитель полушага s + 1 — `f_next`; сопряжённый — `g_next`. Поле: w⁽ˢ⁾ = X⊗Y, где при нечётном s X = `g_next`, Y = `f_next`, при чётном наоборот.
6. **Конец:** после заданного числа полушагов — `COMPLETED_FIXED_HALF_STEPS`. Остановки по стабилизации нет.

## 8. Ограниченный режим исполнения

**`FIXED_HALF_STEPS_RESEARCH`** — единственный режим первой версии.

| Свойство | Значение |
|---|---|
| Что выполняется | ровно заданное число полушагов 1…8, без умолчания |
| Что он означает | решение дискретной задачи Π_h^C в подпространстве N = 1 с проверками разд. 6 |
| Что он **не** означает | сходимость при s → ∞, близость к ω₀ или ω_h^C, квалификацию B-C на рабочих сетках, приёмку R5, Q4 или Q5 |
| Метка каждого результата | `application_status = "RESEARCH_ONLY / PROVISIONAL / NOT_QUALIFIED"`, `mode = "FIXED_HALF_STEPS_RESEARCH"` |
| Запрещено выводить | `CONVERGED`, `converged`, `qualified`, `PASS` как статус расчёта, `field.csv` |

**Чем он отличается от сходящегося решателя.** Сходящийся решатель останавливается по утверждённому критерию и заявляет свойство результата. Этот режим такого не заявляет: «завершено»
значит только «выполнено заданное число шагов и защиты не сработали». Переход к сходящемуся решателю требует tol_∞, tol_E, s_min, s_max и квалификации (D-049.6) — отдельным решением.

**Наблюдения для пользователя.** В `result.json` записывается текст об ограничениях:

- фиксированный N = 1 не сходится к ω_h^C, если её ранг больше 1: разность — мера ранга (NS 9, О-8). SCRATCH: α при s = 8 на 1 × 1 — 1,27413·10⁻³ (32 × 32), 1,26824·10⁻³ (40 × 64);
  опубликованное L-120 — 1,265319·10⁻³. Разница включает сетку и приближение N = 1 и допуском не является;
- при больших s изменения энергии уходят ниже сертифицируемого уровня. SCRATCH: на пяти малых сетках внешняя классификация даёт PASS при s = 1…5 и `UNRESOLVED_RESOLVABILITY` при s = 6…8.
  Это не ошибка, но содержательность больших s энергетически не подтверждена.
