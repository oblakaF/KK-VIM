ID решений постоянные (D-001 и далее). Номера не переиспользуются. Отменённое или заменённое
решение остаётся в реестре с новым статусом и ссылкой на заменяющее.

**Основание решений D-001–D-020:** явные решения пользователя (владельца проекта) и согласованный
план проекта, зафиксированные 2026-10-11. Это **организационные решения**, а не научные
утверждения. Где решение зависит от содержания первоисточников, нужная проверка указана в поле
«Требует проверки». До её выполнения соответствующее научное положение считается неподтверждённым.

**Основание решений D-021–D-033:** явные решения владельца проекта. Для D-022–D-024 указано,
что проверено непосредственно по оригинальным PDF первоисточников. Ссылки даются в формате AGENTS.md.

**Редакция 2026-10-11 (D-026).** Записи D-001 и D-019 переформулированы без ссылок на материалы
прежних проектов; смысл и статус-история решений сохранены.

### D-022. Вложенность для физически нелинейной постановки: МППУ — внешний цикл, МВИ — внутренний

- **Статус:** Принято. Заменяет часть D-012 о вложенности.
- **Содержание:** для воспроизведения оригинальной физически нелинейной постановки:
  - внешний цикл — метод переменных параметров упругости (МППУ, Биргер);
  - внутренний цикл — метод вариационных итераций Кириченко–Крысько: на каждом шаге МППУ
    линеаризованная задача решается МВИ;
  - координатные полушаги X/Y выполняются внутри МВИ;
  - следующий шаг МППУ использует функции предыдущего шага.

  Другую вложенность нельзя выдавать за алгоритм P82.
- **Область:** R11, R12 (G7); воспроизведение авторского примера P82.
- **Основание:** явное решение владельца. Проверено по оригинальному PDF P82 (2026-10-11):
  - [P82, с. 78] — порядок этапов: нелинейная задача линеаризуется по МППУ, затем на каждом шаге
    МППУ линеаризованная задача решается МВИ;
  - [P82, ур. (3), с. 78; ур. (4), с. 79] — полушаги: по заданным φ_i⁰(x) находятся ψ_i¹(y),
    затем φ_i²(x) и т. д.; верхний индекс n у w_N^n — номер шага МППУ;
  - [P82, с. 80] — «на каждом следующем шаге МППУ итерации МВИ начинались с функций,
    получаемых на предыдущем шаге МППУ».
- **Требует проверки:** начальная жёсткость первого шага МППУ; правило пересчёта J на каждом шаге;
  смысл индексов и нормировка (Q-015, Q-018). На с. 78–80 P82 формула пересчёта параметров
  упругости явно не выписана.

### D-042. Ограниченное разрешение: политика допустимых типов входа единого валидатора Reference R3

  - согласовать политику с вводом R2 и основным решателем `kkvim`.
