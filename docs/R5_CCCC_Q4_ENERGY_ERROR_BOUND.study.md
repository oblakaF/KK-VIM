## 1. Объект: E_s и вычислительный путь QA

### 1.1. Точные объекты

Полушаг s задан сохранёнными массивами binary64:

- Û — заданный набор после QR прототипа;
- Ṽ_prev = C′ — сопряжённый фактор предыдущего поля в том же базисе;
- V̂ — решение B-C (AU 377–379; ориентация `orient`).

Все массивы берутся как точные рациональные числа. Шаги сетки h = l/n точные, Π_h^C — по D-049.1, ω — минимизатор Π_h^C.

## 3. Точное разложение E_s (проверка ВОК-6 и разделение по заданию)

**Предложение Э-1. PROVEN** (алгебра; используются только билинейность a_h, l_h(·) = a_h(ω, ·) и ВОК-2).

$$E_s=\underbrace{E^{(1)}}_{\text{формирование}}+\underbrace{E^{(2)}}_{\text{энергии}}+\underbrace{E^{(3)}}_{\text{разность}}+\underbrace{E^{(4)}}_{Q_s}+\underbrace{E^{(6)}}_{\text{заключ.}},$$

$$E^{(1)}=a_h(e,\,d)+a_h(\tilde w_s-\omega,\ e'-e),\qquad
E^{(2)}=\bigl[\hat P_p-\Pi_h^C(\hat w_p)\bigr]-\bigl[\hat P_s-\Pi_h^C(\hat w_s)\bigr],$$

$$E^{(3)}=-a_h(\hat d,\delta d)+\tfrac12\|\delta d\|_a^2,\qquad E^{(4)}=-\bigl[\hat Q-\tfrac12\|\hat d\|_a^2\bigr],\qquad E^{(6)}=0\ \text{(путь QA)}.$$

**Доказательство.** ΔP̂ − Q̂ = E^(2) + [Π(ŵ_p) − Π(ŵ_s)] − ½‖d̂‖² + E^(4).

Далее Π(ŵ_p) − Π(ŵ_s) = f(ŵ_p, ŵ_s) + ½‖d‖² и ½‖d‖² − ½‖d̂‖² = E^(3), так как d = d̂ − δd. Отсюда
E_s = E^(2) + E^(3) + E^(4) + [f(ŵ_p, ŵ_s) + γ_s], а f(w̃_p, w̃_s) = −γ_s (ВОК-2).

Наконец, f(v, w) = a_h(w − ω, v − w) (RO ВОК-6, доказательство). Поэтому

f(ŵ_p, ŵ_s) − f(w̃_p, w̃_s) = a_h(w̃_s + e − ω, d) − a_h(w̃_s − ω, d̃) = a_h(e, d) + a_h(w̃_s − ω, d − d̃),

где d − d̃ = e′ − e. ∎

**Сверка с ВОК-6.** RO записывает ту же величину как a_h(d̃, e) + a_h(w̃_s − ω, e′ − e) + a_h(e, e′ − e). Это тождественно
E^(1): подставить d̃ = d − (e′ − e). Член второго порядка a_h(e, e′ − e) исчезает, если первое слагаемое записать через точную
разность d вычисленных полей. ВОК-6 подтверждён.

**Соответствие разбиению QA.** В AU 415–417 «часть формирования» f(ŵ) + γ — это ровно E^(1). «Часть сборки» (ΔP̂ − Q̂) − f(ŵ)
равна E^(2) + E^(3) + E^(4). EQ вычисляет обе части точно (984/984, `numerator_split_exact`).

**E^(6).** На пути QA ΔP̂ − Q̂ и сравнения теста вычисляются точно (AU 411–414, `k_interval`), поэтому E^(6) = 0
(VERIFIED-IMPL). Для пути, где r = fl(fl(P̂_p − P̂_s) − Q̂) считается в double, из П-1 получается
|r − (ΔP̂ − Q̂)| ≤ u(1+u)|ΔP̂| + u|ΔP̂ − Q̂|. Этот член пришлось бы добавить к B_E. Он не мал относительно RΣ: при s = 8 |ΔP̂|
порядка нескольких ulp(P̂_p) (ER, И-1). Это ограничение переноса на другой путь (разд. 8).

## 4. Леммы о слагаемых

Обозначения для поля w ∈ V_h (внутренние узлы):

- t := Δ_h^C w во всех узлах (точно);
- A := |Δ|^C|w| — мажоранта RO ВОК-3, `_abs_delta_exact` (EN 252–271);
- S_q(w) := (D/2)Σ W·|t|·A и S_l(w) := |q|hₓh_y Σ|w| — две части Ŝ^C, `majorant_S` (EN 274–281);
- **новая величина** S₂(w) := (D/2)Σ W·A².

Константы сетки (И-2; все — точные рациональные числа):

$$\eta:=\max_{x,y}\max\Bigl\{\tfrac{(1+u)^3}{1+\delta_c}-1,\ 1-\tfrac{(1-u)^3}{1+\delta_c}\Bigr\},\qquad \eta_t:=\eta(1+u)+u,$$

$$\psi:=\max\bigl\{\phi(1+u)^4-1,\ 1-\phi(1-u)^4\bigr\},\quad \psi_L:=\max\bigl\{\phi(1+u)^3-1,\ 1-\phi(1-u)^3\bigr\},\quad \phi:=(1+\delta_{h,x})(1+\delta_{h,y}),$$

$$c_q:=\psi+2(1+\psi)\eta_t,\qquad \nu:=(1+\psi)\eta_t^2,\qquad c_l:=\psi_L .$$

**Л-3 (попарная сумма). PROVEN | П-1.** Для `pairwise_sum` M слагаемых x̂_k:
|ŝ − Σx̂_k| ≤ γ_L Σ|x̂_k|, L = ⌈log₂M⌉.

Доказательство: на каждом уровне дерева слагаемое проходит ровно одно сложение. Сложение с дополняющим нулём точное.
Поэтому ŝ = Σ x̂_k Π_{ℓ≤L}(1 + δ_{kℓ}), и остаётся применить Л-1. Оценка не зависит от потоков и BLAS. ∎

**Л-4 (значение шаблона). PROVEN | П-1, П-3′, И-1, И-2.** В каждом узле |t̂ − t| ≤ η_t·A.

Доказательство. Внутренний узел, направление x: L̂ₓ = [(a − 2b)(1+δ₁)(1+δ₂) + c(1+δ₂)](1+δ₃)/(h²(1+δ_c)). Множитель каждого
слагаемого отличается от 1 не более чем на η: максимум достигается на границах |δᵢ| = u, а у слагаемого c меньше множителей.
Отсюда |L̂ₓ − Lₓ| ≤ η(|a| + 2|b| + |c|)/h² = η(|Ł|ₓ|w|). Граничная строка 2P₁/c даёт то же с одним множителем.

Далее t̂ = (L̂ₓ + L̂_y)(1+δ₄), поэтому |t̂ − t| ≤ ηA + u(|t| + ηA) ≤ η_tA, так как |t| ≤ A. ∎

**Л-5 (квадратичный член и нагрузка). PROVEN | П-1, П-3′, И-1, И-2.** Для T := (D/2)W t² и вычисленного T̂:

|T̂ − T| ≤ (D/2)W [c_q|t|A + νA²].

Для члена нагрузки ℓ := q hₓh_y w_ij: |ℓ̂ − ℓ| ≤ c_l|q|hₓh_y|w_ij|.

Доказательство. T̂ = (D/2)Wφ̃t̂², где |φ̃ − 1| ≤ ψ. Множитель φ̃ включает h_dx = hₓ(1+δ_{h,x}), h_dy и четыре округления разд. 1.2.
Тогда |T̂ − T| ≤ (D/2)W(ψ t̂² + |t̂² − t²|). Подставляя t̂² ≤ (|t| + η_tA)², |t̂² − t²| ≤ η_tA(2|t| + η_tA) (Л-4) и t² ≤ |t|A,
получаем требуемое. Для нагрузки: (q·h_dx)·h_dy·w — три округления и δ_{h,x}, δ_{h,y}. ∎

**Л-6 (мажоранта S₂). PROVEN.** S₂(w) ≤ (D/2)Λ²‖w‖_h², и потому S₂(w) ≤ Λ̄_h²·S_q(w).

Доказательство. A = |Δ|^C|w|, где |Δ|^C — неотрицательная матрица «все узлы × внутренние узлы». Тогда
ΣWA² ≤ λ_max(G)‖w‖₂², G := |Δ|^{Cᵀ}W|Δ|^C ≥ 0. Для неотрицательной симметричной G λ_max ≤ max строковой суммы
(G𝟏)_k = Σ_{IJ}|Δ|_{IJ,k}W_{IJ}(|Δ|𝟏)_{IJ}. Используются два факта:

- (|Δ|𝟏)_{IJ} ≤ Λ во всех узлах, включая граничные строки 2/h²;
- взвешенная сумма столбца Σ_{IJ}|Δ|_{IJ,k}W_{IJ} = hₓh_yΛ. Граничная строка с весом h/2 и коэффициентом 2/h² даёт то же, что
  внутренняя строка с весом h и коэффициентом 1/h².

Значит, λ_max(G) ≤ hₓh_yΛ² и ΣWA² ≤ Λ²‖w‖_h². Вторая оценка: S_q ≥ (D/2)ΣWt² = ½‖w‖²_a (NS 2.2) и
‖w‖_a ≥ D^{1/2}μ_low‖w‖_h (RO ВОК-1, п. 4). ∎

**Л-7 (разность полей). PROVEN | П-1, П-3′(а).** Пусть β := u D^{1/2}Λ‖d̂‖_h. Тогда

- ‖δd‖_a ≤ β ≤ uΛ̄_h‖d̂‖_a;
- |E^(3)| ≤ β‖d̂‖_a + ½β².

Доказательство: |δd| ≤ u|d̂| поэлементно (Л-2), затем RO ВОК-1, п. 4 и Коши–Буняковский. ∎
Первое слагаемое совпадает со вторым членом R_Q^C ВОК-8 (`model_RQ`, EN 296–297). Это уже строгая граница, а не модель.

**Л-8 (формирование). PROVEN | П-1, П-3′, П-4′.** Пусть B_ω ≥ ‖w̃_s − ω‖_a — любая доказанная граница. Тогда

|E^(1)| ≤ ε_a^C(s)(‖d̂‖_a + β) + B_ω(ε_a^C(s−1) + ε_a^C(s)).

Доказательство. При П-4′ из Л-1 получается RO ВОК-4: |e| ≤ γ_N|Û||V̂|ᵀ. Каждое произведение проходит не более N округлений, FMA их
только уменьшает. ВОК-5 в форме `eps_a_C` (EN 301–308; ‖S‖_h — точно, корень — сверху) даёт ‖e‖_a ≤ ε_a^C(s), ‖e′‖_a ≤ ε_a^C(s−1).

Далее |a_h(e, d)| ≤ ‖e‖_a‖d‖_a, где ‖d‖_a ≤ ‖d̂‖_a + β (Л-7), и |a_h(w̃_s − ω, e′ − e)| ≤ B_ω(‖e′‖_a + ‖e‖_a). При s = 1 поле
w̃_p = 0 точно (C′ = 0), e′ = 0, ε_a^C(s−1) = 0 (AU 284). ∎

**Какая B_ω допустима.** Маршрут ВОК-7 (б) кампании EQ: `b_omega(…, None)` (EN 311–325) = точная невязка D2 поля ŵ_s,
делённая на D^{1/2}μ_low, плюс ε_a^C(s). Это граница ‖ŵ_s − ω‖_a + ‖e‖_a ≥ ‖w̃_s − ω‖_a: невязка точная (`d2.residual_exact`,
D1 = D2 по D-049.1), корень сверху, знаменатель снизу. Маршрут (а) с сертификатом ВОК-14 тоже допустим, если сертификат действителен
(Q3).

**Важно:** член второго порядка ε_a^C(s)(ε_a^C(s−1) + ε_a^C(s)), который ВОК-8 «в кандидат не включает», в реализованном R_f^C с
маршрутом (б) **уже содержится**: B_ω включает +ε_a^C(s). В форме Э-1 другого члена второго порядка от формирования нет.

## 5. Теорема Э-2: вычислимая граница |E_s| ≤ B_E,s

### 5.1. Формулировка

**Теорема Э-2. PROVEN | П-1, П-3′, П-4′, И-1, И-2** (П-2 — по Л-0). Для пути QA G-4 (разд. 1.2) и любой доказанной
B_ω ≥ ‖w̃_s − ω‖_a:

$$|E_s|\le B_{E,s}:=B_P(\hat w_p)+B_P(\hat w_s)+B_Q(\hat d)+\beta\|\hat d\|_a+\tfrac12\beta^2+\varepsilon_a^C(s)\bigl(\|\hat d\|_a+\beta\bigr)+B_\omega\bigl(\varepsilon_a^C(s-1)+\varepsilon_a^C(s)\bigr),$$

$$B_P(w):=\kappa_P S_q(w)+\kappa_L S_l(w)+(1+\gamma_L)\nu S_2(w),\qquad \kappa_P:=\gamma_L+(1+\gamma_L)c_q,\quad \kappa_L:=\gamma_L+(1+\gamma_L)c_l,$$

$$B_Q(\hat d):=\kappa_Q S_q(\hat d)+(1+\gamma_{L_Q})\nu S_2(\hat d),\qquad \kappa_Q:=\gamma_{L_Q}+(1+\gamma_{L_Q})c_q .$$

### 5.2. Доказательство

По Э-1 |E_s| ≤ |E^(1)| + |E^(2)| + |E^(3)| + |E^(4)|, E^(6) = 0.

- **E^(2).** P̂ = ŝ — попарная сумма вычисленных членов x̂_k (квадратичных и нагрузки). Π(ŵ) = Σx_k. По Л-3 и Л-5
  |P̂ − Π(ŵ)| ≤ (1+γ_L)Σ|x̂_k − x_k| + γ_LΣ|x_k|, где Σ|x̂_k − x_k| ≤ c_qS_q + νS₂ + c_lS_l. Кроме того,
  Σ|x_k| ≤ (D/2)ΣWt² + S_l ≤ S_q + S_l. Отсюда |P̂ − Π(ŵ)| ≤ B_P(ŵ).
- **E^(4).** То же для `q_double`: только квадратичные члены, глубина L_Q.
- **E^(3)** — Л-7. **E^(1)** — Л-8. ∎

**Вычислимость.** Все величины вычисляются в рациональной арифметике по сохранённым массивам. S_q, S_l, ‖d̂‖_h, ‖d̂‖_a, ε_a^C и B_ω
уже вычисляются функциями EN. S₂ использует тот же массив A, что `majorant_S`. Стоимость B_E — того же порядка, что RΣ.

## 6. Отношение к RΣ: Теорема Э-3

### 6.1. RΣ кампании

RΣ = R^C(ŵ_p) + R^C(ŵ_s) + R_Q^C(d̂) + R_f^C (RO ВОК-3, ВОК-8; AU 277–297), где:

- R^C(w) = u(L + 22)(S_q + S_l);
- R_Q^C = u(L + 22)S_q(d̂) + β‖d̂‖_a;
- R_f^C = ε_a^C(s)‖d̂‖_a + B_ω(ε_a^C(s−1) + ε_a^C(s)).

Каждый член вычислен в рациональной арифметике и округлён вверх (`up`, `sqrt_interval`; группировка AU 288–295). Поэтому
вычисленное RΣ не меньше суммы этих формул (**VERIFIED-IMPL**, чтение кода).

### 6.2. Формулировка

**Теорема Э-3. PROVEN | предпосылки Э-2.**

$$B_{E,s}\le K^*\,R_\Sigma,\qquad K^*:=\max(K_P,K_Q,K_f),$$

$$K_P:=\frac{\max\{\kappa_P+(1+\gamma_L)\nu\bar\Lambda_h^2,\ \kappa_L\}}{u(L+22)},\quad
K_Q:=\max\Bigl\{\frac{\kappa_Q}{u(L+22)},\ 1+\tfrac12u\bar\Lambda_h+\frac{(1+\gamma_{L_Q})\nu\bar\Lambda_h}{2u}\Bigr\},\quad
K_f:=1+u\bar\Lambda_h .$$

### 6.3. Доказательство

- **Энергии:** по Л-6 (1+γ_L)νS₂ ≤ (1+γ_L)νΛ̄_h²S_q, поэтому B_P(w) ≤ K_P·R^C(w).
- **Q и разность.**
  - Из Л-6 и ‖d̂‖_a ≥ D^{1/2}μ_low‖d̂‖_h: S₂(d̂) ≤ (D/2)Λ²‖d̂‖²_h ≤ (Λ̄_h/(2u))·β‖d̂‖_a.
  - По Л-7 ½β² ≤ ½uΛ̄_h·β‖d̂‖_a.
  - Отсюда B_Q + β‖d̂‖_a + ½β² ≤ K_Q·R_Q^C.
- **Формирование:** ε_a^C(s)β ≤ uΛ̄_h ε_a^C(s)‖d̂‖_a ≤ uΛ̄_h R_f^C, поэтому этот вклад ≤ K_f·R_f^C.
- Сумма даёт B_E ≤ K*·RΣ. ∎

### 6.4. Значения K* (SCRATCH; арифметика точная, константы И-2 — этой платформы)

| Величина на 36 сетках Q3 | Значение |
|---|---|
| \|δ_h\|/u; \|δ_c\|/u | 0 (h и h² точные: 23 сетки); до 0,5 и 1,75 (13 сеток с l_y = 0,2, ⅓ или n ∉ 2ᵏ) |
| c_q/u (коэффициент первого порядка + остатки) | 12,000…16,000 |
| c_l/u | 3,00…3,56 |
| K_P | 0,706…0,857 (< 1) |
| K_Q − 1 | ≤ 3,96·10⁻¹⁰ (член β; максимум — 1 × 0,5 : 1024 × 512 и 1 × 2 : 512 × 1024, Λ̄_h = 4,19·10⁵) |
| K_f − 1 | ≤ 4,66·10⁻¹¹ |
| **K* − 1** | **≤ 3,96·10⁻¹⁰** |

### 6.5. Следствия

1. **c_R = 22.** В путь G-4 входит первый порядок
   c_q ≈ (12 + (|δ_{h,x}| + |δ_{h,y}|)/u + 2max|δ_c|/u)·u. Это 12u при точных h и h² и ≤ 16u на сетках Q3.
   - Если `pow(h, 2) = fl(h·h)` (И-2), то для **любой** сетки |δ_c| ≲ 3u и c_q ≲ 20u < 22u.
   - Подсчёт QA c_R = 22 (EN 16–28) **достаточен**, но не минимален. В нём ошибка h² учтена как 4u (2u от округления h, 2u от
     pow). При `pow(h, 2) = fl(h·h)` она не больше ≈ 3u, на сетках Q3 — не больше 1,75u.
   - Строгость R^C даёт не число 22, а неравенство κ_P + (1+γ_L)νΛ̄_h² ≤ u(L + 22), проверяемое на каждой сетке.

   **VERIFIED-IMPL** для 36 сеток на этой платформе; c_R не назначается.
2. **R_Q^C и R_f^C** — строгие границы своих частей. Множитель (1 + O(uΛ̄_h)) учитывает β, остатки второго порядка уже внутри
   (разд. 5.3). Поэтому статус MODEL этих частей в ВОК-8 может быть заменён на PROVEN | П после проверки Reviewer. Этот документ
   статусы RO не меняет.
3. **Форма теста** (GP 5.3; алгебра — GR разд. 2, PROVEN). Пусть K_E ≥ K*. Тогда при предпосылках Э-2

   |ΔP̂ − Q̂| ≤ |γ_s| + |E_s| ≤ Γ_up + K*RΣ ≤ τ = Γ_up + K_E·RΣ,

   и E1 следует из E2, так как Q̂ ≥ 0: все члены `q_double` неотрицательны, и округление знак не меняет. Значит, **ложный FAIL
   исключён**, а FAIL указывает на нарушение предпосылок или дефект реализации.
   - Для K_E < K* доказательства нет: тест остаётся наблюдательным (OBSERVATION по EQ).
   - Разрешимость Q̂ ≥ K_E·τ доказательством не улучшается и не ухудшается.
4. **K* — не рекомендация K_E.** Это наименьший множитель, при котором неравенство Э-3 доказано. Вычислимая B_E даёт и другую
   возможную форму: τ′ = Γ_up + B_E, без множителя. Выбор формы — решение владельца (GP, В-2). Здесь ни одна форма не утверждается.

## 8. Ограничения применимости

1. **Только путь QA G-4:**

   - поля — `numpy.matmul`, разность — вычитание NumPy, ΔP̂ − Q̂ и тест — в точной арифметике (AU).

3. **Константы И-2** (δ_h, δ_c, `pow`) установлены для 36 сеток Q3 на одной платформе (Python 3.13.15, NumPy 2.5.4, Windows 10).
   Для других сеток или платформ K* пересчитывается по формулам разд. 4 и 6.2; это дёшево и точно.
4. **K* растёт как Λ̄_h** (член β в K_Q, примерно 8uΛ̄_h). Для Λ̄_h ≤ 4,2·10⁵ K* − 1 ≤ 4·10⁻¹⁰. Э-3 верна при любой сетке, но
   K* ≈ 1 — только пока uΛ̄_h ≪ 1.
5. **Предпосылки П-1, П-3′, П-4′** не доказываются. П-1 — свойство платформы. П-3′ и П-4′ на данных кампании EQ не проверены
   (разд. 9).
6. **N ≥ 2 — RESEARCH_ONLY / NOT_QUALIFIED** (D-049.5, D-053.2, п. 5). Э-2 и Э-3 от N зависят только через γ_N в ε_a^C, но статус
   данных N ≥ 2 не меняется.
7. **Граница худшего случая.** B_E превышает фактический |E_s| примерно в 2·10³ раз (раздел 7). Это не влияет на строгость, но
   влияет на разрешимость при выборе K_E ≥ K*.
8. **Независимость.** Вывод, константы и SCRATCH-проверка выполнены одним исполнителем (Claude, Literature). Независимой
   математической проверки ещё нет.
