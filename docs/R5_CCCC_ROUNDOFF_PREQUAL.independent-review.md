## 2. ВОК-10 — ёмкость S: доказательство проверено

1. S = G⁻¹ + Zᵀ𝒦₀⁻¹Z, G⁻¹ = (h_y⁴/(2D))A⁻¹ ⊗ I₂. Из L_y = −ΨΛΨᵀ: 𝒦₀ = DΣₖMₖ ⊗ ψₖψₖᵀ, Mₖ = μₖ²A + 2μₖB + C, поэтому Zᵀ𝒦₀⁻¹Z = D⁻¹ΣₖMₖ⁻¹ ⊗ zₖzₖᵀ.
2. B = −hₓUᵀLₓU ⪰ 0 и C ⪰ 0 ⇒ Mₖ ⪰ μₖ²A ⇒ Mₖ⁻¹ ⪯ A⁻¹/μₖ².
3. B ⪯ β_U A, C ⪯ χ_U A, μ² + 2μβ + χ ≤ (μ + β + √χ)² ⇒ Mₖ⁻¹ ⪰ A⁻¹/(μₖ + ϑ_U)² ⪰ ϱ²A⁻¹/μₖ²; функция μ/(μ + ϑ) возрастает.
4. (Xₖ − ϱ²A⁻¹/μₖ²) ⊗ zₖzₖᵀ ⪰ 0 ⇒ после суммирования ϱ²A⁻¹ ⊗ T₀ ⪯ Σₖ Mₖ⁻¹ ⊗ zₖzₖᵀ ⪯ A⁻¹ ⊗ T₀, где T₀ = Pᵀ(L_y²)⁻¹P.
5. (−L)⁻¹ = h²K, K_ij = min(i, j)(n − max(i, j))/n:
   - T₀₁₁ = h⁴(n − 1)(2n − 1)/(6n), T₀₁₂ = h⁴(n² − 1)/(6n);
   - собственные значения h⁴(n − 1)/2 и h⁴(n − 1)(n − 2)/(6n) — выведено заново.
   - Проверено в `fractions` при n = 2, 3, 5, 8, 33, включая K = (−L)⁻¹. При n = 2 λ_min(T₀) = 0, и оценка остаётся верной.
6. cond(S) ≤ cond(A)·n/(1 + ϱ²(n − 1)(n − 2)/(3n)) ≤ cond(A)·n; предел 3/ϱ².
7. Следствие для 𝒯_N:
   - β_U, χ_U^{1/2} ≤ μ_Nˣ ≤ (2Nπ/a)²;
   - μ₁ʸ ≥ 4/b², так как sin x ≥ 2x/π;
   - ⇒ ϱ ≥ 1/(1 + 2π²N²(b/a)²) — верно.

**Численно (Н-3):** 60 случаев (𝒯_N, случайные, почти зависимые; с QR и без; N = 1–3; b/a = 0,2…5) — ни одного нарушения S ⪰ нижней, S ⪯ верхней, cond(S) ≤ cond(A)𝒞_S, cond(Mₖ) ≤ cond(A)/ϱ², λ_min(𝒦^C) ≥ μ₁²λ_min(A). Отношение cond(S) к границе — 0,023…0,89.

Следствие 1 («строгое основание У-R5») верно в своей формулировке: после QR cond(S) ≤ 𝒞_S ≤ n не зависит от обусловленности исходного базиса. При больших n граница — до ~n, а не O(1); O(1) остаётся гипотезой H-S1.

## 3. ВОК-12 и ВОК-13: ошибка переноса нормы (З-1)

**ВОК-12** утверждает нерастяжимость только в паре энергетических норм. В 2-норме оператор 𝒦^{C,−1}𝒦₀ = I − Y₀S⁻¹Zᵀ **растягивает**, и растяжение растёт с сеткой (Н-5; nₓ = 20, a = b = 1, 𝒯_N после QR):

| n_y | 15 | 31 | 63 | 127 |
|---|---|---|---|---|
| ‖𝒦^{C,−1}𝒦₀‖₂, N = 1 | 3,4 | 10,2 | 29,6 | 85 |
| ‖𝒦^{C,−1}𝒦₀‖₂, N = 3 | 3,5 | 10,4 | 30,2 | 86,7 |
| ‖x₀‖/‖x‖ | 1,61…1,67 | | | |

Рост примерно как n^{1,5}. Верхняя граница — (λ_max(𝒦₀)/λ_min(𝒦^C))^{1/2} ~ n².

**Где ошибка.**

1. ВОК-12, абзац «Смысл»: «Ошибка модального решения x₀ **не усиливается** поправкой Вудбери» — верно только для энергетических норм. В 2-норме и max-норме, в которых записаны ε_mod (DST, 3.2) и η, — неверно.
2. ВОК-13: из δx ≈ 𝒦^{C,−1}𝒦₀δx₀ − δY₀c + Y₀S⁻¹δS c выведено ‖δx‖/‖x‖ ≲ ε_mod[1 + κ_c(1 + cond(S))].
   - Множитель «1» у первого слагаемого опирается на ВОК-12, применённую в 2-норме, и теряет ‖x₀‖/‖x‖.
   - Правильная первая оценка: ‖𝒦^{C,−1}𝒦₀‖₂·‖x₀‖/‖x‖·ε_mod. В примере это ≈ 5,6 при n_y = 15 и ≈ 140 при n_y = 127, а не 1.
   - Во втором и третьем слагаемых κ_c = ‖Y₀c‖/‖x‖ надо заменить на ‖Y₀‖₂‖c‖₂/‖x‖ (норма произведения не мажорирует ‖δY₀‖‖c‖). В примерах значения близки (0,63…0,70), но в общем случае различаются.

**Следствие.** Модель ВОК-13 занижает первое слагаемое в растущее с n число раз. Е-4 («модель против факта») тогда систематически «опровергал» бы неверную модель, а не измерял константы.

**Минимальная правка** — один из вариантов:

- **(а)** формулировать ВОК-13 в энергетической норме, последовательно с ВОК-12: ‖δx‖_{𝒦^C} ≲ ‖δx₀‖_{𝒦₀} + …, с ε_mod в соответствующей норме;
- **(б)** оставить 2-норму, но писать ε_mod[‖𝒦^{C,−1}𝒦₀‖₂‖x₀‖/‖x‖ + κ̄_c(1 + cond(S))] с κ̄_c := ‖Y₀‖₂‖c‖₂/‖x‖₂. Все множители вычислимы a posteriori и должны журналироваться в Е-6.

Абзац «Смысл» ВОК-12 дополнить: «в энергетических нормах; в 2-норме растяжение до ‖𝒦^{C,−1}𝒦₀‖₂, растущего с n».
