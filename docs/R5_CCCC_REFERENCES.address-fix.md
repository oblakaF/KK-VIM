## Уточнения при внесении

1. **«Существенно ближе» (ЭР-1).** По `d2_external.csv` внешние значения ближе к неуточнённым решениям QA, чем к уточнённым, в 24 из 27
   точек. Отношение расстояний — от 1,0 до ~490, медиана 1,5, поэтому слово «существенно» к каждой точке не относится. В отчёт записано
   количественно.
2. **Пример r = 1, n = 256.** В рецензии он приведён как «6,3·10⁻¹⁴ отн.». Столбец `unref_vs_external` в CSV — абсолютный: 6,3·10⁻¹⁴ абс.,
   то есть 5,0·10⁻¹¹ отн. Против 9,0·10⁻¹⁰ отн. для уточнённого решения вывод рецензии («ближе к неуточнённому») верен. В отчёт записаны
   относительные значения.
