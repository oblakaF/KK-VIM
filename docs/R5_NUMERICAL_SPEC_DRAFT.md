## 1. Непрерывная задача

**Постановка** [ПРИНЯТО MATH_SPEC 1.4, 1.5, 10]:

- область Ω = (0, a) × (0, b), начало координат в углу (MATH_SPEC 1.1);
- изотропная линейная пластина Кирхгофа–Лява, D∇⁴w = q, q = const;
- условия CCCC: w = ∂w/∂n = 0 на ∂Ω [АВТОР P81, с. 369; P82, с. 78, (2)];
- энергия Π(w) = ½D‖Δw‖² − (q, w) (интеграл определителя гессиана исчезает, MATH_SPEC 10);
- H_T = W̊₂²(Ω), решение ω₀ существует и единственно (В-31).

**Одномерные условия полушагов** [ПРИНЯТО MATH_SPEC 10, В-33]: Y(0) = Y(b) = 0, Y′(0) = Y′(b) = 0; аналогично для X.
Оба условия главные.

**Безразмерные величины** [ПРИНЯТО MATH_SPEC 2.5, В-12]: w̄ = wD/(qa⁴), x̄ = x/a, ȳ = y/b, r_MS = b/a. Решение зависит только от
x̄, ȳ, r_MS.

**Контрольная величина R5** — нормировка по полной короткой стороне ℓ = min(a, b):

α = w(a/2, b/2)·D/(qℓ⁴) = w̄_c·(a/ℓ)⁴, r = max(a, b)/ℓ ≥ 1.

Связь с MATH_SPEC: при a ≤ b α = w̄_c; при a > b α = w̄_c·(a/b)⁴. В таблицах R5 всегда указывается, какая сторона короткая.

**Моменты** — вне R5-V как объект квалификации: краевые моменты не контролируются ни одним эталоном (разд. 9). Квалификация
моментов — R6 (ROADMAP).

## 2. Сетки и полная дискретная энергия Π_h^C

### 2.1. Сетки и неизвестные

- G(a, nₓ): xᵢ = i·hₓ, hₓ = a/nₓ, i = 0…nₓ; G(b, n_y) — аналогично.
- Неизвестные — значения во внутренних узлах; в граничных узлах w = 0.
- Центр — узел при чётных nₓ, n_y. Для таблиц R5 [ИНЖ]: n по короткой стороне, r·n — по длинной, hₓ = h_y.
- Пространство V_h — все сеточные функции на внутренних узлах; ограничение одно: w = 0 в граничных узлах.

### 2.2. Функционал [ОСНОВА R5; ВЫВОД — предварительная математическая подготовка, разд. 9.4]

Одномерные операторы (размеры: E, Ł — (n + 1) × (n − 1)):

- **Ł** — вторая разность, продолженная на граничные узлы через чётный фиктивный узел:
  - (Łf)ᵢ = (f_{i−1} − 2fᵢ + f_{i+1})/h², i = 1…n − 1, с f₀ = f_n = 0;
  - (Łf)₀ = 2f₁/h², (Łf)_n = 2f_{n−1}/h².
- **E** — вложение внутренних значений с нулями на границе.
- **W** = diag(h/2, h, …, h, h/2) — трапеции.

Двумерные: Δ_h^C = Łₓ ⊗ E_y + Eₓ ⊗ Ł_y.

$$\Pi_h^{C}(w)=\frac D2\,(\Delta_h^Cw)^{\mathsf T}(W_x\otimes W_y)(\Delta_h^Cw)-q\,h_xh_y\sum_{\text{внутр.}}w_{ij}.$$

### 2.3. Реализация защемления

- **w = 0** — главное условие: граничные узлы исключены из неизвестных.
- **∂w/∂n = 0** входит через Ł. Значение в фиктивном узле не является неизвестным; оно задано отражением w₋₁ = w₁. Это центральная
  разность (w₁ − w₋₁)/(2h) = 0, аппроксимация условия с O(h²).
- Дополнительного ограничения на сеточную функцию нет.

### 2.4. Свойства [ВЫВОД; рецензия R-18 PASS]

1. **Предложение D:** гессиан Π_h^C равен D·hₓh_y·𝒜, где 𝒜 — матрица 13-точечной схемы D2 (разд. 3.3).
2. 𝒜 симметрична и положительно определена, поэтому минимизатор **ω_h^C** = D1 = D2 существует и единственен.
3. Энергия в минимуме: Π_h^C(ω_h^C) = −½·q·hₓh_y·Σω_h^C.

### 2.5. Согласованность коэффициентов с непрерывными [SCRATCH; разд. 14, П-S5]

Для X = sin²(πx/a):

| Коэффициент | Сходимость к непрерывному значению |
|---|---|
| C^C = h·XᵀD4X (по Π_h^C) | **второй порядок**: ошибка 3,18 → 0,80 → 0,20 → 0,050 → 0,0125 при n = 20 … 320 |
| C_{L²} = h·XᵀL²X (граничная вторая разность := 0, как в SSSS) | **только первый порядок**: 22,3 → 10,5 → 5,07 → 2,49 → 1,23 |

Это **количественное основание** не переносить граничную дискретизацию SSSS на CCCC: у функций с X = X′ = 0 и X″ ≠ 0 на концах
обнуление граничной второй разности даёт ошибку O(h).

## 4. Полушаги КК-МВИ

### 4.1. Подпространства и функционал [ПРИНЯТО R4_NUMERICAL_SPEC 2.1 по структуре; функционал — ОСНОВА R5]

M_h(U) = span(U) ⊗ V_h^y (Y-полушаг) и M_h(V) = V_h^x ⊗ span(V) (X-полушаг). Полушаг — **точный минимум Π_h^C** на M_h.
Один функционал на всех полушагах.

### 4.2. Коэффициенты [ВЫВОД]

Для заданного набора U ∈ ℝ^{(nₓ−1)×N} (суммы с шагом hₓ):

$$A_{ij}=h_xU_i^{\mathsf T}U_j,\quad B_{ij}=-h_xU_i^{\mathsf T}L_xU_j,\quad C^C_{ij}=h_xU_i^{\mathsf T}D4_xU_j,\quad F_i=q\,h_xU_i^{\mathsf T}\mathbf 1 .$$

- A, B, C^C — симметричные неотрицательно определённые матрицы Грама. В частности, C^C = (ŁₓU)ᵀWₓ(ŁₓU) ⪰ 0, так как
  ŁᵀWŁ = h·D4.
- Отличие от R4 только в C: **C^C = C_{L²} + (2/hₓ³)(u₁u₁ᵀ + u_{n−1}u_{n−1}ᵀ)**, где u₁ — первая строка U.
  [SCRATCH П-S4: при N = 1 и X = sin² равенство выполняется точно.]

### 4.3. Системы полушагов [ВЫВОД; рецензия R-18 PASS]

**Y-полушаг** (порядок кронекеровых множителей — как в R4: сначала индекс члена):

$$\mathcal K^C=D\bigl[A\otimes D4_y-2B\otimes L_y+C^C\otimes I_y\bigr],\qquad \mathcal K^C\mathrm{vec}(V)=F\otimes\mathbf 1 .\qquad(\text{ЧФ-C1})$$

**X-полушаг** — симметрично: коэффициенты по y из заданного V, операторы по x (ЧФ-C2).

- Проверка: a_h^C(UṼᵀ, UṼᵀ) = h_y·vec(Ṽ)ᵀ𝒦^C vec(Ṽ) [SCRATCH П-S1: 1,9·10⁻¹⁶].
- Отличие от R4 (ЧФ-1): L² → D4 в операторе и в C; B и F не меняются.

### 4.4. N = 1 [ВЫВОД; стартовая функция — ПРИНЯТО MATH_SPEC 10, В-32]

K = D[A_h·D4 − 2B_h·L + C^C_h·I], KY = F_h𝟏.

  Вывод не выполнен; MATH_SPEC 10 такой контроль прямо не выводит — ОВ-S6.

**Нормировка множителей N = 1 между полушагами** [ПРИНЯТО NUMERICAL_SPEC 9.1, И-4 (R2); перенос на CCCC — ВЫВОД по однородности].

После полушага s вычисленный множитель f (Y при нечётном s, X при чётном) и заданный множитель g преобразуются так же, как в R2:

c = σ‖f‖∞, σ = sign⟨f, 𝟏⟩; f ← f/c, g ← g·c.

- Нормировка выполняется **до** формирования и сохранения w⁽ˢ⁾ и Π_h^C(w⁽ˢ⁾).
- Поле w⁽ˢ⁾ = g ⊗ f не меняется: в точной арифметике точно, с округлением — не более 2u относительно в узле.
- Математическая задача и физическое поле не меняются.
- **Почему И-4 верна для CCCC.**
  - Коэффициенты A_h = hgᵀg, B_h = −hgᵀLg, C^C_h = hgᵀD4g однородны степени 2 по g, F_h = qhgᵀ𝟏 — степени 1. Поэтому A_h, B_h, C^C_h → c²·,
    F_h → c·, и решение следующего полушага переходит в решение, делённое на c.
  - Оператор (L или D4) в этом рассуждении не участвует.
- Нормировочно-инвариантные величины — B_h/A_h, C^C_h/A_h, F_h²/A_h (по образцу NUMERICAL_SPEC 9.1).
- Критерии остановки и сравнения используют только поле и Π_h^C.
- Нормированные дискретный и непрерывный множители по отдельности не сравниваются.
- Для N ≥ 2 роль нормировки играет QR и допустимая замена базиса (R4_NUMERICAL_SPEC 5.4, 5.4.1); разд. 5.1.

### 4.5. N = 2–3 — **блокирующий пробел** (Б-2)

Часть B MATH_SPEC (Б.1–Б.20; D-045) доказана для **SSSS**. Для CCCC при N ≥ 2 не установлены:

1. распространение слабых и сильных форм Б.3–Б.5 и разрешимости Б.9 на V = W̊₂² по обеим переменным;
2. **допустимый стартовый набор.** Нечётные синусы R4 (Б.16, РВ4-1) **недопустимы как стартовые функции КК-МВИ для CCCC**: по
   условиям допустимости MATH_SPEC 4.6 и 10 стартовая функция должна удовлетворять X = X′ = 0 на концах. Производная
   sin((2i − 1)πx/a) на концах не равна нулю, поэтому функции нарушают **непрерывные** граничные условия CCCC.

   Дискретное пространство V_h формально содержит их сеточные значения: это любые векторы с нулями в граничных узлах. Однако это
   не делает их допустимым стартом (У-R3).

   Кандидаты [ИНЖ — предложение]:
   - X_i⁰ = (1 − cos(2iπx/a))/2, i = 1…N (при i = 1 — sin²);
   - X_i⁰ = sin(πx/a)·sin((2i − 1)πx/a).

   Для каждого кандидата нужны допустимость, независимость, симметрия, ненулевые нагрузки и условия дискретной независимости
   (аналог ЧВ4-8).

   **Замечание о независимости.** Первое семейство совпадает с одномерным базисом эталона B (ОВ-М7). Стартовое подпространство
   первого полушага совпало бы с подпространством Ритца по x. Это не нарушает независимости процедуры, но должно быть явно
   учтено в решении.
3. Дискретные условия ранга, аналоги ЧВ4-8 и ЧВ4-9.

Формулы (ЧФ-C1)/(ЧФ-C2) от этого пробела **не зависят**. Зависят допустимость старта и доказательства свойств последовательности.
