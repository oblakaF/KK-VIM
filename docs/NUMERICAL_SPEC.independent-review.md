## 2. Блокирующие замечания

### Б-1. Тест А-11 невыполним на сетках n ≥ 320 из-за правила конфигурации разд. 11.2 (доказанный дефект)

- **Место.** Разд. 11.2 (последний абзац: «Если tol_E < 10·ε_floor, где ε_floor = 10u(max(n_x, n_y)/π)², — ошибка конфигурации ERROR_INPUT»);
  разд. 11.2, строка «строгий режим … tol_∞/100, tol_E/100»; разд. 11.4; табл. 18.1, А-11 («все сетки проверки»); разд. 3.4 (сетки 20…320, +640).
- **Причина (арифметика по формулам документа).** В строгом режиме tol_E = 10⁻⁸/100 = 10⁻¹⁰. Правило требует tol_E ≥ 10·ε_floor = 100u(n/π)²:
  n = 320: 100·1,11·10⁻¹⁶·(320/π)² = **1,15·10⁻¹⁰ > 10⁻¹⁰** ⇒ ERROR_INPUT; n = 640: 4,6·10⁻¹⁰ ⇒ ERROR_INPUT; n = 1280: 1,8·10⁻⁹ ⇒ ERROR_INPUT.
  При n = 160 (2,9·10⁻¹¹) строгий режим допустим.
- **Численное подтверждение, что противоречие порождено правилом, а не свойством задачи.** Фактический пол ε^E (собственный расчёт, s ≥ 8):
  1,9·10⁻¹² (n = 320), 7·10⁻¹² (640), 2,8·10⁻¹¹ (1280) — в 5–50 раз ниже строгого tol_E. Пол ε^∞: ≤ 5·10⁻¹⁴ на всех n ≤ 1280. Без правила
  конфигурации строгий режим сходится (n = 320: CONVERGED при s = 8; обычный режим — при s = 7), и S_stop ≈ 2·10⁻¹⁴ ≪ 0,01·E_disc.
- **Последствия.** Обязательный тест группы A (PASS/FAIL) нельзя выполнить на n = 320 и 640 ⇒ приёмка R2 по таблице 18.1 невозможна;
  если реализация обойдёт правило, она нарушит собственную спецификацию.
- **Минимальное исправление (любой из вариантов):**
  1. строгий режим: tol_E,strict = max(tol_E/100, 10·ε_floor), tol_∞,strict = tol_∞/100 (связующим фактически является ε^∞, см. НБ-8); или
  2. определить строгий режим как «обычный критерий + ещё два полушага (один полный цикл)» и S_stop как max|w^{(s*+2)} − w^{(s*)}|/max|w|; или
  3. ослабить правило конфигурации до tol_E ≥ ε_floor (без множителя 10).

### Б-2. Порядок при фиксированном s: пропущен шаг возмущения коэффициентов; утверждение «для s = 1 доказательство полное» неверно в записанном виде

- **Место.** Разд. 5.5 (ЧВ-8, шаг 4 и фраза «Для s = 1 доказательство полное (X⁰ задана точно, разд. 6)»); разд. 14, п. 4 («ЧВ-7 при точных X⁰|, ЧВ-6:
  коэффициенты с относительной ошибкой O(h_x²)»); разд. 22.1, первый пункт; табл. 22.1a, Н-6; основание допусков А-4а, А-5а, А-5в (табл. 18.1).
- **Причина.** ЧВ-7 доказан для системы K f_h = g **с теми же точными A, B, C**. В R2 (вариант B, И-2) уже при s = 1 система решается с сеточными
  B_h = (a/2)μ₁ ≠ B, C_h ≠ C, F_h ≠ F (ЧВ-6). Переход «ошибка коэффициентов O(h²) ⇒ ошибка решения O(h²) в ‖·‖_h и ‖L·‖_h» и есть шаг 4 ЧВ-8,
  который документ сам называет недетализированным. Следовательно, и при s = 1 доказательство неполно; это не «набросок только для s ≥ 2».
  Кроме того, индукция сравнивает узловые множители X_h и X|, а И-4 нормирует их по-разному (по сеточному и непрерывному максимуму) — условие
  согласования нормировок не оговорено.
- **Проверка восполнимости (собственный вывод Reviewer).** Пробел закрывается без новых предположений:
  *Лемма о возмущении.* Пусть K = D[A L² − 2B L + C I], K̃ = D[Ã L² − 2B̃ L + C̃ I], A, Ã ≥ A₀ > 0, B, B̃, C, C̃ ≥ 0, Y = K⁻¹(F·1), Ỹ = K̃⁻¹(F̃·1).
  Тогда Ỹ − Y = K̃⁻¹(F̃ − F)1 − K̃⁻¹(K̃ − K)Y. Все операторы — функции симметричной L с собственными значениями −μ_k, μ_k ≥ μ₁ ≥ 4/ℓ², поэтому
  ‖K̃⁻¹(K̃ − K)‖₂ ≤ |ΔA|/Ã + 2|ΔB|/(Ãμ₁) + |ΔC|/(Ãμ₁²) =: ϰ, ‖K̃⁻¹‖₂ ≤ 1/(DÃμ₁²), ‖LK̃⁻¹‖₂ ≤ 1/(DÃμ₁), и по коммутативности
  ‖L(Ỹ − Y)‖_h ≤ |ΔF|‖1‖_h/(DÃμ₁) + ϰ‖LY‖_h, ‖Ỹ − Y‖_h ≤ |ΔF|‖1‖_h/(DÃμ₁²) + ϰ‖Y‖_h. При ΔA, ΔB, ΔC, ΔF = O(h²) и ограниченных ‖Y‖_h, ‖LY‖_h
  (следует из ЧВ-7) обе разности O(h²) равномерно; Ã ≥ A/2 выполняется при h ≤ h₀(s). Вместе с ЧВ-7, шагами 2–3 ЧВ-8 и дискретным неравенством
  Соболева (шаг 6 ЧВ-7) это даёт утверждение ЧВ-8 для каждого фиксированного s при h ≤ h₀(s). Нормировку достаточно исключить: индукцию вести
  для ненормированных множителей (поле от нормировки не зависит, ЧВ-14/В-13, с округлением ≤ 2u).
- **Последствия.** Сейчас теоретическое основание допусков порядка (А-4а, А-5а, А-5в) опирается на неполный вывод, а текст объявляет его полным
  для s = 1. Дефект — в обосновании, не в схеме: численно порядок 2,00 подтверждён (разд. 5).
- **Минимальное исправление.** Добавить лемму о возмущении (текст выше) как ЧВ-8a; в разд. 5.5, 14 п. 4, 22.1 и 22.1a заменить «для s = 1 полное /
  набросок для s ≥ 2» на «доказано для каждого фиксированного s при h ≤ h₀(s) (ЧВ-7, ЧВ-8, ЧВ-8a); константы и h₀ зависят от s и не оцениваются»;
  указать, что индукция ведётся для ненормированных множителей.

## 7. Факторизация и численная устойчивость (приоритет № 3)

**Аналитика (проверено).** Корни A r² − 2B r + C: r₁,₂ = (B ± √(B² − AC))/A; (L − r₁)(L − r₂) = L² − (2B/A)L + (C/A) — верно. Re r ≥ 0 при A > 0, B ≥ 0.
- B² = AC — двойной вещественный корень (s = 1, вариант B: r = μ₁^x); B² < AC — комплексно-сопряжённые (s ≥ 2: (AC − B²)/(AC) ≈ 1,2·10⁻², собственный
  расчёт синусной рекурсией); B² > AC — только в тестах (дискретное Коши–Буняковского исключает это для коэффициентов из множителя).
- −L + r: собственные значения μ_k + r, \|μ_k + r\| ≥ μ₁; слабое диагональное преобладание во внутренних строках и строгое в крайних, неприводимость ⇒
  невырожденность; LU без выбора ведущего существует.
- **Почти кратные корни.** Корни по отдельности вычисляются с погрешностью ~√u·B/A (сокращение в B² − AC), но в оператор входят только r₁ + r₂ = 2B/A
  и r₁r₂ = C/A + O(uC/A) — поэтому почти кратность точности не портит (это более точное основание, чем «каждый множитель обусловлен независимо»).
  Последовательное решение (а не разложение на простые дроби) не содержит деления на r₁ − r₂ — верно.
- **Вещественность.** При r₂ = r̄₁ и вещественной g точное Y вещественно; взятие Re Y корректно.
- **Почему точнее Холецкого (собственный вывод Reviewer).** Нормовая оценка через cond(K) одинакова для обоих способов. Выигрыш факторизации
  следует из покомпонентной обратной устойчивости трёхдиагонального LU при диагональном преобладании и гладкости решения: относительная прямая ошибка
  ≲ c·u[κ(M₁)·‖M₂⁻¹‖‖Z‖/‖Y‖ + κ(M₂)], где Z = M₂Y и ‖Z‖ ≤ (‖LY‖ + \|r\|‖Y‖) ⇒ O((2n/π)²u) для гладких Y. Для произвольной (негладкой) правой части такой
  гарантии нет. Покомпонентная устойчивость LU — стандартный результат, в библиотеке не зарегистрирован (Н-3 документа); для приёмки достаточно прямой
  проверки А-1а.
