## 3. Методика

### 3.1. Постановка и масштаб

Постановка (RM 9.3, 9.8): CCCC, D∇⁴w = q, q = D = 1, короткая сторона ℓ = 1, длинная r. На короткой стороне n интервалов, на длинной rn; h = 1/n по обеим осям.

- h_x = r/(rn) в double совпадает с fl(1/n): это корректно округлённое частное одного и того же вещественного числа.
- Z — целочисленный шаблон h⁴(δ⁴ₓ + 2δ²ₓδ²ᵧ + δ⁴ᵧ): центр 20, четыре соседа −8, четыре диагональных 2, четыре через узел 1.
- Фиктивные узлы w₋₁ = w₁ и w_{n+1} = w_{n−1} складываются с отражённым узлом. Граничные узлы (w = 0) отбрасываются.
- 𝒜 = Z/h⁴ = n⁴Z. Из Z y = 𝟏 следует w = y/n⁴ и α = w_c·D/(qℓ⁴) = y_c/n⁴. Это точное масштабирование, **PROVEN**.

### 3.2. Варианты

Варианты зафиксированы до сравнения. Упорядочение основных расчётов — COLAMD, как у консультанта.

| Вариант | Сборка | Уточнение | Решатель |
|---|---|---|---|
| **V1** | F (h = 1.0/n в double) | нет | `spsolve(A_F, 1, permc_spec="COLAMD")`, SuperLU |
| **V2** | тот же A_F | по **точной** невязке самого A_F: сходится к точному решению округлённого оператора, поэтому V2 − V4 — вклад только сборки | `splu(A_F)` + уточнение |
| V2X | тот же A_F | по точной невязке n⁴Z (округление остаётся только внутри LU) | `splu(A_F)` + уточнение |
| **V3** | целочисленный Z | нет | `spsolve(Z, 1)`, α = y_c/n⁴ |
| **V4** | целочисленный Z | по точной невязке Z = **α_ref QA** | `splu(Z)` + уточнение |

**F-сборки.** Это типовые учебные сборки, **не** код консультанта:
- **F_KRON:** D4⊗I + 2L⊗L + I⊗D4, где L = tridiag(1, −2, 1)/h\*\*2 и D4 = L·L + (2/h\*\*4)(e₁e₁ᵀ + e_m e_mᵀ).
- **F_D4H4:** D4 = пентадиагональная (1, −4, 6, −4, 1)/h\*\*4 с граничными элементами 7/h\*\*4; смешанный член 2L⊗L с L = …/h\*\*2.
- **F_DIV:** Z/h\*\*4 поэлементно.

**Чувствительность.** В 5 целевых точках V1 и V3 повторены с упорядочением MMD_AT_PLUS_A.

**Точная невязка.**
- Элементы матрицы и итераты — двоичные дроби. b − A·x вычисляется в целых числах Python с общим знаменателем 2ᵏ и один раз округляется до double (деление `int / int` корректно округляется).
- Уточнение по PL §1.4, п. 2: до 5 шагов, останов, когда max|δx| перестаёт убывать или равен нулю.
- **Невязка относительно целочисленного оператора** для каждого варианта: точная 1 − Z·y, y = n⁴w. Обратная ошибка η = max|r|/(‖Z‖∞‖y‖∞ + 1), ‖Z‖∞ = 64.

**Эквивалентный сдвиг диагонали ε** (OBSERVATION, однопараметрическая сводка, не модель консультанта):
- если бы оператор консультанта был n⁴(Z + εI), то в первом порядке α_ext − α_ref = −ε(Z⁻²𝟏)_c/n⁴;
- ε_equiv = −(α_ext − α_ref)·n⁴/(Z⁻²𝟏)_c, в единицах u = 2⁻⁵³;
- основание — резольвентное тождество (Z+εI)⁻¹𝟏 − Z⁻¹𝟏 = −ε(Z+εI)⁻¹Z⁻¹𝟏, проверено точно в тестах.

Систематическое возмущение оператора даёт ε, не зависящий от r при том же h; независимые ошибки решения — нет.

## 6. Сравнение четырёх вариантов

1. **Целочисленная сборка без уточнения (V3) расхождение не устраняет.** При (5, 192) её ошибка — до 1,1·10⁻⁹ (COLAMD) и 3,8·10⁻⁹ (MMD). Это порядок cond·u, как у F-сборок без уточнения.
2. **Уточнение по точной невязке Z устраняет и ошибку LU, и округление сборки.** V2X, то есть LU округлённого A_F с невязкой n⁴Z, совпадает с V4 до 1,7·10⁻¹⁶ во всех 162 расчётах. Округлённая матрица внутри LU на результат не влияет.
3. **Уточнение по невязке самого округлённого оператора (V2) сходится к его точному решению**, а не к решению D2. Вклад сборки V2 − V4 при n = 48 / 96 / 192:

   | Сборка | n = 48 | n = 96 | n = 192 |
   |---|---|---|---|
   | F_KRON | 0 | 0 | 0 |
   | F_D4H4 | −3·10⁻¹²…−7,5·10⁻¹² | −4,8·10⁻¹¹…−1,2·10⁻¹⁰ | −7,7·10⁻¹⁰…−1,9·10⁻⁹ |
   | F_DIV | ≈ та же величина с обратным знаком | ≈ то же | ≈ то же |

   При диадических n вклад сборки равен 0 для всех трёх.
4. **Разделение расхождения консультанта** (α_ext − α_ref) = вклад сборки + ошибка решения без уточнения:
   - при диадических n первое слагаемое равно нулю для всех проверенных сборок (PROVEN), а второе сопоставимо с разбросом QA без уточнения (OBSERVATION);
   - при недиадических n есть систематическая часть с ε ≈ 7–8 u, не зависящая от r (OBSERVATION). По величине и знаку она того же класса, что вклад сборки F_D4H4 (57–102 %), но точная операция не установлена (UNRESOLVED).

## 7. Причины расхождений: подтверждённое и неподтверждённое

**Проверяемая цепочка** (на примере F_D4H4 при (5, 192)):

| Шаг | Факт | Статус |
|---|---|---|
| Операция сборки | `1/h**4` при h = fl(1/192) не равно 192⁴, а `1/h**2` равно 192² | PROVEN |
| Отличие матрицы | 728 076 элементов D4-части отличаются от n⁴Z на относительные 1,75·10⁻¹⁶; смешанная часть точна | PROVEN |
| Изменение α | V2 − V4 = −1,93·10⁻⁹ отн. (точное решение округлённого оператора, последняя поправка 8·10⁻¹⁷) | VERIFIED на этой платформе |
| Сопоставление с консультантом | α_ext − α_ref = −2,25·10⁻⁹; тот же знак, 86 %. V1 F_D4H4 отличается от числа консультанта на 8,3·10⁻¹¹ — в 26 раз меньше, чем V1 F_KRON (2,2·10⁻⁹), но не до 14 знаков | OBSERVATION |

**Подтверждено:**
- **PROVEN.** Пять точек NOT_REPRODUCED, (1, 48), (3, 96), (5, 48), (5, 96), (5, 192), — все с недиадическим n. Ни одна из 15 диадических точек кандидат B_ext не нарушила (CSV Q1).
- **PROVEN.** При диадическом n проверенные сборки с округляемым h точны, поэтому округление сборки там расхождений дать не может.
- **VERIFIED.** Целочисленная сборка без уточнения даёт ошибку порядка cond·u, как и F-сборки. Устраняет её только уточнение по невязке точного оператора.
- **OBSERVATION.** Отклонения консультанта при недиадических n ведут себя как систематическое возмущение оператора порядка u: ε не зависит от r и одинаков для n = 96 и 192, имеющих одну мантиссу h.

**Не подтверждено (UNRESOLVED):**
- какая именно операция сборки была у консультанта: F_D4H4 — ближайшая из трёх проверенных, но не воспроизводит;
- его упорядочение, версия SuperLU и платформа;
- есть ли другая причина систематической части. Однопараметрическая модель εI — сводка, а не доказанный механизм;
- происхождение небольшого положительного ε при n = 128, 256 (0,3–3,5 u) без согласованности по r.

**Уточнение гипотезы Q1.** Прежняя формулировка «ошибка решения без итеративного уточнения» (QA Q1, разд. 2.1) неполна для недиадических n: там данные указывают на дополнительную систематическую составляющую того же порядка. Именно она объясняет, почему 5 точек вышли за кандидат B_ext: его член 10·|α_unref − α_ref| строится по случайной ошибке решения QA и систематическую часть не покрывает.
