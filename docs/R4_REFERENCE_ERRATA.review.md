## 3. Замечания

**Блокирующих нет.**

**Редакционные:**
- **Р-1 (9.1, путь (а)).** «Относительная ошибка растёт примерно как u/α⁴» для формы ЧВ-Л1 неточно; формулировка унаследована из `3aaca8e`, разд. 2.1.
  - В ЧВ-Л1 главные слагаемые имеют порядок f(α) ≈ α/2, а скобка в центре T ≈ (5/24)α⁴. Поэтому множитель усиления ≈ 2,4/α³, и ошибка
    растёт как **u/α³**.
  - Своя проверка: α³·err ≈ 4,2; 2,9; 3,2 при α = 0,157; 0,0785; 0,039, тогда как α⁴·err → 0. Закон u/α⁴ верен для прямой формы со
    слагаемыми порядка единицы.
  - Приведённые измеренные значения верны. Вывод о непригодности ЧВ-Л1 при α_m < π/2 не меняется.
  - Предлагается: «примерно как u/α³ (в форме ЧВ-Л1; u/α⁴ — для прямой формы)».
- **Р-2 (9.1, путь (б); А4-7; РВ4-8).** «Предпочтительна при α_m < π/2» слабее, чем следует из текста: там путь (а) допустим только как
  диагностика. Значит, для количественного сравнения путь (б) — единственный (как в `3aaca8e`: «нормативный путь — Навье-m»).
  Предлагается: «при α_m < π/2 — **основной** (единственный для количественного сравнения) способ».
- **Р-3 (9.1).** Выбор «по α_m» применяется к членам одной суммы m ∈ {1, …, 2N − 1}. Надо уточнить:
  - если хотя бы один член имеет α_m < π/2, то либо эти члены, либо вся сумма вычисляются по пути (б);
  - при смешанном вычислении бюджет — сумма раздельно указанных хвоста и моделей округления по членам.
  - Граница α_m = π/2 встречается среди контрольных r **точно** при m·r = 1: r = 1/5, m = 5 и r = 1/3, m = 3. Там предпосылка модели (а) не
    выполнена (≈ 9u), поэтому до пересчёта постоянной QA эти члены также относятся к пути (б).
- **Р-4 (ссылки).** Проект ссылается на `3aaca8e` и на отчёт QA `42f1f15`; ни один из них не входит в `main` @ `c45f950`. При интеграции
  нужно влить эти документы вместе с поправками либо указать их ветки, иначе принятая спецификация будет ссылаться на документы вне `main`.
- **Р-5 (статус).** Пометки «проект», «не интегрирован», «требуется подтверждение владельца», «Reviewer этот текст не проверял» до
  интеграции верны. При принятии их нужно заменить по перечню разд. 4.
- **Р-6 (D-046).** Предлагается датированное уточнение (разд. 5). Сам текст D-046 не переписывается.
