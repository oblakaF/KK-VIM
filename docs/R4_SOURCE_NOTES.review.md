## 4. Независимый вывод: одновременно или последовательно

**Вывод Reviewer: CONFIRMED.** На каждом полушаге все N функций одной переменной определяются **совместно**, как решение одной
связанной системы N уравнений, или, что то же, как одна проекция на всё подпространство M_sᴺ. Последовательного определения
отдельных членов в P80, P81, P82 и P81-S (с. 55, 57) нет.

**Прямые утверждения авторов [АВТОР]:**
1. **P81, с. 367, процедура:** «a system of N functions v₁¹(y), …, v_N¹(y) is determined from the first N equations of the system (3)».
   Система функций находится из системы уравнений, а не каждая функция из своего уравнения.
2. **P81, с. 367, Definition 1:** «computing one system of functions from another given system is called one VIM step».
3. **P81, с. 368–369, доказательство Теоремы 2:** «every ω_N¹ is a projection of element ω₀ into the subspace M_N¹ = {Σu_i⁰(x)v_i(y)},
   … for every i the function v_i(y) runs through the entire space»; ω_N¹ = P_Nω₀.
4. **P82, с. 78–79, (3), (4):** одно операторное уравнение P₁(A[Σφ_i⁰ψ_i] − g) = 0 с проекцией на M₁ᴺ, где все ψ_i варьируются;
   аналогично P₂, P₃. С. 79: w_N^{n,1} — минимум по всему M₁ᴺ.
5. **P80, с. 2188, (10):** «N неизвестных функций ω_j(x₁) находят из следующей системы уравнений», l = 1, …, N. Каждое уравнение
   содержит Σ_j ω_jg_j.

**Что является выводом Reviewer.** Слово «одновременно» авторы не печатают. Это строгое следствие трёх фактов:
- (а) каждое уравнение системы содержит все неизвестные (см. ниже);
- (б) результат полушага определён как проекция на всё M_sᴺ;
- (в) последовательное определение членов — каждая функция из своего уравнения при уже найденных предыдущих — в общем случае
  не удовлетворяет всей системе. Проекция на сумму подпространств u_i ⊗ V равна сумме проекций только при их взаимной
  ортогональности в H_T.

**Математическое объяснение связи.** Для T = DΔ², SSSS и заданных u_j ∈ V_a (u = u″ = 0 на концах) уравнение i левого столбца (3) имеет
вид (собственная выкладка):

$$D\sum_{j=1}^{N}\bigl[a_{ij}v_j''''-2\beta_{ij}v_j''+\gamma_{ij}v_j\bigr]=\int_X g\,u_i\,dx,\quad
a_{ij}=\int_X u_iu_j,\ \beta_{ij}=\int_X u_i'u_j',\ \gamma_{ij}=\int_X u_i''u_j'',\ i=1,\dots,N.$$

Вывод:
- T(u_jv_j) = D(u_j''''v_j + 2u_j''v_j'' + u_jv_j'''');
- функции y выносятся из интеграла по x;
- ∫u_iu_j″ = −β_ij, ∫u_iu_j'''' = γ_ij — интегрирование по частям, внеинтегральные члены равны нулю по u = u″ = 0;
- при N = 1 получаются A, B, C части A.

Связь индексов i и j идёт через три симметричные матрицы. Система распадается на N независимых задач, если все три матрицы
диагональны. Заменой базиса оболочки по ВР4-4 её можно расщепить, только если пучки (a, β) и (a, γ) одновременно диагонализуемы.
В общем случае связь неустранима.

**Неоднозначности (прямо указываю):**
1. **Способ решения связанной системы** авторы не задают («which we assume to be solvable», Remark 1). Задан результат — совместное

   Последовательное *определение* членов (АБСМ, жадное добавление) — противоречит.
2. **L-104, с. 12:** «defines only one of the functions» — см. разд. 7: речь об одном из двух направлений, не об одном члене.
3. **Норма проекции в P82** (W̊₂² при положительной определённости в L₂, Q-019) на вывод о совместности не влияет.
