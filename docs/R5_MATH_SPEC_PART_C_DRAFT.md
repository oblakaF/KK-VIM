## C.1. Область применимости

**Область.**

- линейная изотропная однородная пластина Кирхгофа–Лява, прямоугольник Ω = (0, a) × (0, b), a, b > 0 любые;
- закрепление CCCC: w = ∂w/∂n = 0 на ∂Ω [АВТОР P81, с. 369; P82, с. 78, (2)];
- нагрузка q = const ≠ 0. Разрешимость отдельного полушага верна и при q ∈ L₂ (как MATH_SPEC 1.6). Гладкость, принадлежность D(T_CC)
  и все утверждения о ранге — только при q = const. **Это граница области, а не открытый вопрос** (уточнено по РЧ-4; прежний
  ОВ-PC2 снят);
- число членов N фиксировано в течение расчёта. Утверждения о ранге первого полушага сформулированы для N = 2, 3. Для N ≥ 4
  выполнено только необходимое условие ВБC-20, п. 1, доказанное при любом N; полный ранг при N ≥ 4 не рассматривается
  (ROADMAP: N = 4–6 — исследование). **Это граница области** (уточнено по РЧ-4; прежний ОВ-PC3 снят).

**Различение по N:**

| Положения | N |
|---|---|
| Непрерывная постановка, разрешимость, проекционность, GL(N), энергия (C.2–C.6; ВБC-1…ВБC-11) | любое N ≥ 1 |
| Дискретные формулы полушагов (C.9; ВБC-12…ВБC-14) | любое N ≥ 1 |
| Старт 𝒯_N, точные формулы коэффициентов, дискретная независимость (C.7, C.9; ВБC-13 пп. 3–4, ВБC-15…ВБC-18) | любое N ≥ 1; проверено и рекомендовано для N = 2, 3 |

## C.2. Функциональное пространство, граничные условия, энергия

### C.2.1. Принятые положения части A

[ПРИНЯТО MATH_SPEC 10, В-31, В-33; D-031]:

- **H_T = W̊₂²(Ω)** с [w, z]_{H_T} = D(Δw, Δz): интеграл определителя гессиана исчезает на W̊₂²(Ω);
- Π(w) = ½D‖Δw‖² − (q, w); ω₀ — единственный минимизатор Π на H_T (Рисс), [m, ω₀] = (q, m) для m ∈ H_T;
- одномерные условия при разделённом представлении: на краях y = 0, b — **Y = Y′ = 0**; на краях x = 0, a — **X = X′ = 0**. Оба условия
  главные;
- D(T_CC) ⊂ W̊₂²(Ω) (MATH_SPEC 1.4, 10, Н-8).

**Уровень:** А. **Статус:** ПРИНЯТО (D-031).

### ВБC-1. Тензорная лемма для W̊₂²

**Утверждение.** Для u, ũ ∈ V_a и v, ṽ ∈ V_b:

1. u ⊗ v ∈ H_T = W̊₂²(Ω);
2. $$[u\otimes v,\tilde u\otimes\tilde v]_{H_T}=D\bigl[(u'',\tilde u'')(v,\tilde v)+2(u',\tilde u')(v',\tilde v')+(u,\tilde u)(v'',\tilde v'')\bigr];\qquad(\text{Ф-1C})$$
3. (q, u ⊗ v) = q(∫u)(∫v) при q = const;
4. ‖u ⊗ v‖_{H_T} ≤ 2D^{1/2}‖u‖_{W₂²}‖v‖_{W₂²}.

**Доказательство.**

1. Для u, ũ ∈ C_c^∞(0, a), v, ṽ ∈ C_c^∞(0, b) произведения лежат в C_c^∞(Ω), Δ(uv) = u″v + uv″, и
   ∬Δ(uv)Δ(ũṽ) = (u″, ũ″)(v, ṽ) + (u″, ũ)(v, ṽ″) + (u, ũ″)(v″, ṽ) + (u, ũ)(v″, ṽ″).
   Интегрирование по частям (функции и первые производные равны нулю на концах): (u″, ũ) = −(u′, ũ′), (v, ṽ″) = −(v′, ṽ′). Два средних
   слагаемых равны (u′, ũ′)(v′, ṽ′). Это (Ф-1C).
2. Из (Ф-1C): ‖f ⊗ g‖²_{H_T} = D[‖f″‖²‖g‖² + 2‖f′‖²‖g′‖² + ‖f‖²‖g″‖²] ≤ 4D‖f‖²_{W₂²}‖g‖²_{W₂²}. Это п. 4 для гладких множителей.
3. Пусть uₙ → u в W₂²(0, a), vₙ → v в W₂²(0, b), uₙ, vₙ ∈ C_c^∞ (определение V_a, V_b). По п. 2 и билинейности (uₙ ⊗ vₙ) фундаментальна
   в H_T. Её предел z лежит в W̊₂²(Ω) (замкнутость). Так как uₙvₙ → uv в L₂(Ω), z = uv.
4. Обе части (Ф-1C) непрерывны по W₂²-нормам множителей; формула и п. 4 переходят к пределу. П. 3 — непосредственно. ∎

**Уровень:** А. **Происхождение:** ВЫВОД ПРОЕКТА. **Статус:** ДОКАЗАНО (R-CM, ВБC-1 — PASS).
**Связь:** аналог ВБ-1 части B. Отличие: синусные ряды и D(T_SS) не используются; достаточно определения W̊₂² как замыкания C_c^∞.
**Ограничения:** п. 3 — только q = const.

## C.3. Разделённое представление и связанная система

### ВБC-2. Низкоранговое представление и энергия

**Утверждение.**

1. N-е приближение — w_N = U ⊗ Y = Σᵢ₌₁ᴺ uᵢ(x)vᵢ(y), uᵢ ∈ V_a, vᵢ ∈ V_b [АВТОР P81, с. 366, (2); с. 367, Definition 2].
2. w_N ∈ H_T (ВБC-1).
3. $$\Pi(w_N)=\tfrac12\|U\otimes Y\|^2_{H_T}-(q,U\otimes Y),\quad
\|U\otimes Y\|^2_{H_T}=D\sum_{i,j}\bigl[(u_i'',u_j'')(Y_i,Y_j)+2(u_i',u_j')(Y_i',Y_j')+(u_i,u_j)(Y_i'',Y_j'')\bigr].$$

**Доказательство** — билинейность и ВБC-1. ∎

**Уровень:** А. **Происхождение:** п. 1 — АВТОР; пп. 2–3 — ВЫВОД ПРОЕКТА. **Статус:** ДОКАЗАНО (R-CM — PASS).
**Связь:** Б.2 (ВБ-2: ранг и единственность представления — алгебра в L₂, переносится дословно).
**Ограничения:** множество 𝓡_N полей ранга ≤ N — не подпространство (как в Б.2).

### Процедура [АВТОР; ПРИНЯТО D-044]

- Задан набор X⁰ ∈ V_aᴺ. Полушаг s = 1 определяет **совместно** все N функций Y¹ из первых N уравнений системы (3) P81; затем X², Y³, …
  [АВТОР P81, с. 367, (3), Definition 1].
- Каждый полушаг — проекция ω₀ на подпространство M_s [АВТОР P82, с. 78–79, (3), (4); P81, с. 368–369].
- Последовательное добавление членов (АБСМ, D-004) схему не подменяет.

**Уровень:** А. **Статус:** ПРИНЯТО (D-044; часть B, Б.1).

### ВБC-3. Подпространства полушагов и слабые формы

**Утверждение.** Для заданного набора U ∈ V_aᴺ подпространство Y-полушага — M(U) := {U ⊗ Ỹ : Ỹ ∈ V_bᴺ}. Коэффициенты по x:

aˣᵢⱼ = (Xᵢ, Xⱼ), βˣᵢⱼ = (Xᵢ′, Xⱼ′), γˣᵢⱼ = (Xᵢ″, Xⱼ″), Fˣᵢ = q∫₀ᵃXᵢ.

**Слабая форма Y-полушага:** найти Y ∈ V_bᴺ такой, что для всех Ỹ ∈ V_bᴺ

$$b_U(Y,\tilde Y):=D\!\int_0^b\!\bigl[\tilde Y''^{\mathsf T}a^XY''+2\tilde Y'^{\mathsf T}\beta^XY'+\tilde Y^{\mathsf T}\gamma^XY\bigr]dy=\int_0^b\tilde Y^{\mathsf T}F^X\,dy=:\ell_U(\tilde Y).\qquad(\text{Ф-2C})$$

X-полушаг: M(Y) := {X̃ ⊗ Y : X̃ ∈ V_aᴺ}, коэффициенты aʸ, βʸ, γʸ, Fʸ по y, форма c_Y на V_aᴺ (Ф-3C).

**Доказательство.** По (Ф-1C) [U ⊗ Y, U ⊗ Ỹ]_{H_T} = b_U(Y, Ỹ), (q, U ⊗ Ỹ) = ℓ_U(Ỹ). Функционал полушага 𝒥_U(Ỹ) = Π(U ⊗ Ỹ) =
½b_U(Ỹ, Ỹ) − ℓ_U(Ỹ); b_U симметрична. Поэтому (Ф-2C) — условие стационарности 𝒥_U. X-полушаг выводится тем же путём с переменой ролей
x ↔ y, а не переносом. ∎

**Уровень:** А (вариационное условие полушага). **Происхождение:** ВЫВОД ПРОЕКТА. **Статус:** ДОКАЗАНО (R-CM — PASS).
**Связь:** ВБ-3, ВБ-4 части B; отличие — только пространство V_b = W̊₂²(0, b). Формулы коэффициентов те же.
**Ограничения:** нет сверх C.1.

### ВБC-4. Сильные формы и граничные условия

**Утверждение.** Пусть U линейно независим (aˣ ≻ 0, ВБC-7), q = const, Y решает (Ф-2C). Тогда:

## C.5. Разрешимость, проекционность, GL(N)-инвариантность

### ВБC-6. Эквивалентность проекционной постановке

**Утверждение.** Пусть U ∈ V_aᴺ и M(U) замкнуто (ВБC-7, п. 6). Для w ∈ M(U) равносильны:

1. w = U ⊗ Y, где Y решает (Ф-2C);
2. Π(w) = min_{M(U)} Π;
3. w = P_{M(U)}ω₀ (ортогональная проекция в H_T);
4. [w − ω₀, m]_{H_T} = 0 для всех m ∈ M(U).

Если, кроме того, w ∈ D(T_CC), то 1–4 равносильны также
5. ∫₀ᵃ(Tw − q)Xᵢ dx = 0 для всех y и i.

П. 5 выполняется, например, когда U ⊂ C⁴ с X = X′ = 0, U независим и Y ∈ C^∞ по ВБC-4.

**Доказательство.**

1. **1 ⇔ 4:** [m, ω₀] = (q, m) [ПРИНЯТО MATH_SPEC 10], поэтому b_U(Y, Ỹ) − ℓ_U(Ỹ) = [U ⊗ Y − ω₀, U ⊗ Ỹ].
2. **4 ⇔ 3** — определение проекции.
3. **3 ⇔ 2** — по ВБC-9, п. 1: Π(v) = ½‖v − ω₀‖² − ½‖ω₀‖².
4. **4 ⇔ 5:** для w ∈ D(T_CC), m ∈ W̊₂²(Ω) формула Грина даёт [w, m] = (Tw, m); граничные члены содержат m и ∂ₙm, равные нулю
   [ПРИНЯТО MATH_SPEC 10, «Симметрия»]. Далее — как ВБ-9, п. 4 ⇔ 5.
5. **Поле в D(T_CC):** на x = 0 w = ΣXᵢ(0)Yᵢ = 0, wₓ = ΣXᵢ′(0)Yᵢ = 0; на остальных сторонах — аналогично. ∎

**Уровень:** А (проекционная постановка авторов). **Происхождение:** ВЫВОД ПРОЕКТА. **Статус:** ДОКАЗАНО (R-CM — PASS).
**Связь:** ВБ-9 части B. Отличие: в SSSS для п. 5 требовалось X″ = 0 на концах заданного набора (Б.5). В CCCC набор из V_a ∩ C⁴ сразу
даёт полные условия CCCC поля.

### ВБC-11. Сходимость при N → ∞ (условно)

## C.7. Допустимое стартовое подпространство 𝒯_N

**Требования к старту** [ПРИНЯТО MATH_SPEC 4.6, 10]: X⁰ ∈ V_aᴺ (X = X′ = 0 на концах), X⁰ независим; для гладкости и проекционности

### ВБC-15. Эквивалентность тригонометрических наборов

**Утверждение.** Aᵢ(t) = sin²(iπt), Bᵢ(t) = sin(πt)sin((2i − 1)πt), A₀ := 0, t = x/a. Тогда **Bᵢ = Aᵢ − Aᵢ₋₁** при всех i ≥ 1 и
span{B₁…B_N} = span{A₁…A_N}.

**Доказательство.** Bᵢ = [cos(2(i − 1)πt) − cos(2iπt)]/2; Aᵢ = (1 − cos 2iπt)/2; Aᵢ − Aᵢ₋₁ = [cos(2(i − 1)πt) − cos(2iπt)]/2. Матрица
перехода — нижняя двухдиагональная с единицами на диагонали, определитель 1. ∎

**Следствие.** A и B — два базиса **одного** подпространства и дают одну последовательность полей (ВБC-9, п. 4). Различается только
обусловленность представления.

**Уровень:** А (входные данные процедуры). **Статус:** ДОКАЗАНО (R-CM — PASS).

**Определение.** **𝒯_N := span{sin²(iπx/a), i = 1…N} = span{1 − cos(2kπx/a), k = 1…N}.**

### ВБC-16. Полиномиальное семейство 𝒫_N

**Утверждение.** Pᵢ(t) = t²(1 − t)²(2t − 1)^{2(i−1)}; Qᵢ: Qᵢ″ = P_{2i}(2t − 1) (многочлен Лежандра), Qᵢ = Qᵢ′ = 0 при t = 0. Тогда:

1. Pᵢ, Qᵢ ∈ C^∞, f = f′ = 0 на обоих концах;
2. span{P₁…P_N} = span{Q₁…Q_N} =: 𝒫_N;
3. 𝒫_N ≠ 𝒯_N.

**Доказательство.** П. 1: множитель t²(1 − t)²; для Q — P_{2i} ортогонален 1 и s на (−1, 1), поэтому Q′(1) = ∫P_{2i} = 0,
Q(1) = ∫(1 − τ)P_{2i}dτ = 0. П. 2: обе системы — базисы пространства t²(1 − t)²·(симметричный многочлен степени ≤ 2N − 2) размерности N.
П. 3: элементы 𝒯_N — тригонометрические, не алгебраические многочлены. ∎

**Уровень:** А. **Статус:** ДОКАЗАНО (R-CM — PASS). **Роль:** только исследовательская конфигурация (влияние старта); стартом

## C.8. Ранг первого полушага: результат для N = 2, ограничения для N = 3

### ВБC-18. Связанная система первого полушага для 𝒯_N

**Утверждение.** При X⁰ = (A₁…A_N), K = diag(κᵢ), κᵢ = 2iπ/a, система (Ф-4C) первого полушага —

(a/8)D[(I + 2·11ᵀ)Y⁗ − 2K²Y″ + K⁴Y] = (qa/2)𝟏.

Эквивалентно: LᵢYᵢ = g, Lᵢ := (D² − κᵢ²)², Yᵢ = Yᵢ′ = 0 при y = 0, b, где **g := 4q/D − 2·ΣⱼYⱼ⁗ — одна и та же функция для всех i**.

**Частичный результат.** Если ΣdᵢYᵢ ≡ 0 при d ≠ 0, то P(D)g = 0 с многочленом P(ξ) := Σᵢdᵢ·Πⱼ≠ᵢ(ξ² − κⱼ²)² ≢ 0.

**Доказательство.**

1. Умножение на 8/(aD) и выделение 𝟏ᵀY⁗: Yᵢ⁗ − 2κᵢ²Yᵢ″ + κᵢ⁴Yᵢ = 4q/D − 2·𝟏ᵀY⁗.
2. Операторы Lⱼ с постоянными коэффициентами коммутируют. Применяя ΠⱼLⱼ к ΣdᵢYᵢ = 0: Σᵢdᵢ(Πⱼ≠ᵢLⱼ)g = 0.
3. P(±κₖ) = dₖ·Πⱼ≠ₖ(κₖ² − κⱼ²)²; κ попарно различны, поэтому при dₖ ≠ 0 P(±κₖ) ≠ 0 и P ≢ 0. ∎

**Уровень:** А. **Статус:** ДОКАЗАНО (R-CM — PASS; статус уточнён по У-C3 — AR, PASS).

### ВБC-19. Полный ранг первого непрерывного полушага при N = 2

**Утверждение.** rank w⁽¹⁾ = 2.

**Условия:** непрерывная задача CCCC; q = const ≠ 0, D > 0; любые a, b > 0; X⁰ = (sin²(πx/a), sin²(2πx/a)); первый полушаг точный.

**Доказательство.** κ₂ = 2κ₁. Заданный набор независим (ВБC-17), поэтому rank w⁽¹⁾ = dim span(Y₁, Y₂) (ВБ-2). Пусть Y₁, Y₂ зависимы.

1. **Y₂ ≡ 0.** Тогда g = L₂Y₂ ≡ 0 и L₁Y₁ = 0 с защемлением. ∫Y₁L₁Y₁ = ‖Y₁″‖² + 2κ₁²‖Y₁′‖² + κ₁⁴‖Y₁‖² (граничные члены равны нулю при
   Y = Y′ = 0), поэтому Y₁ ≡ 0. Но тогда g = 4q/D ≠ 0 — противоречие.
2. **Y₁ ≡ 0** — симметрично.
3. **Y₂ ≢ 0, Y₁ = cY₂, c ≠ 0.**
   - (а) L₁Y₁ = L₂Y₂ даёт Q(D)Y₂ = 0, Q(ξ) := c(ξ² − κ₁²)² − (ξ² − κ₂²)² ≢ 0 (при c ≠ 1 — разные старшие коэффициенты; при c = 1
     Q = 2(κ₂² − κ₁²)ξ² + κ₁⁴ − κ₂⁴). Значит, Y₂ — экспоненциальный многочлен по корням Q.
   - (б) Подстановка Y₁⁗ = cY₂⁗ в g = L₂Y₂: R(D)Y₂ = 4q/D, R(D) := (3 + 2c)D⁴ − 2κ₂²D² + κ₂⁴. Оператор с постоянными коэффициентами
     сохраняет показатели экспонент; функции y^m e^{ξy} с различными (m, ξ) линейно независимы. Если Q(0) ≠ 0, левая часть не содержит
     компоненты с показателем 0, а правая — ненулевая постоянная. Противоречие.
   - (в) Следовательно, Q(0) = cκ₁⁴ − κ₂⁴ = 0, c = (κ₂/κ₁)⁴ = **16**.
   - (г) 16L₁ − L₂ = **15D⁴ − 24κ₁²D²**.
   - (д) Из (а): 15Y₂⁗ − 24κ₁²Y₂″ = 0. Умножение на Y₂ и интегрирование с Y₂ = Y₂′ = 0: 15‖Y₂″‖² + 24κ₁²‖Y₂′‖² = 0, откуда Y₂ ≡ 0 —
     противоречие. ∎

### ВБC-20. Необходимое условие вырождения при любом N; N = 3

**Утверждение.**

1. **Любое N (необходимое условие).** Если ΣdᵢYᵢ¹ ≡ 0 при d ≠ 0 (старт 𝒯_N, непрерывно, q = const ≠ 0), то **Σᵢdᵢ/i⁴ = 0**.
2. **N = 3.** Условие оставляет двумерное множество d — плоскость d₁ + d₂/16 + d₃/81 = 0. Противоречие не получено: **rank w⁽¹⁾ = 3 —
   UNRESOLVED**.

**Логический статус п. 1.** Это **только необходимое** условие вырождения. Оно исключает направления d с Σdᵢ/i⁴ ≠ 0. Оно **не**
утверждает, что направление с Σdᵢ/i⁴ = 0 даёт вырождение, и **не** доказывает полного ранга при N = 3.

**Доказательство п. 1.**

2. P(0) = Σᵢdᵢ·Πⱼ≠ᵢκⱼ⁴ = (Πⱼκⱼ⁴)·Σᵢdᵢ/κᵢ⁴, κᵢ = 2iπ/a. Поэтому P(0) = 0 ⇔ Σdᵢ/i⁴ = 0.

   P(0) ≠ 0; тогда ни один показатель g не равен 0.
   - Совпадение показателей с ±κₖ не исключено. Если dₖ = 0, каждое слагаемое P с i ≠ k содержит (ξ² − κₖ²)², поэтому
     P = (ξ² − κₖ²)²·P̃ₖ и ±κₖ — корни **кратности не меньше двух**; кратность больше, если P̃ₖ(±κₖ) = 0 (АП-1).
   - Пример, N = 3, κᵢ = iκ: d = (0, 9, −64) даёт **P(ξ) = +5(ξ² − κ²)³(59κ² − 11ξ²)** — тройные корни ±κ₁; P(0) = 5·(−κ²)³·59κ² =
     −295κ⁸ = (9·81 − 64·16)κ⁸. Аналогично d = (9, 0, −25) и (64, −25, 0) дают тройные корни ±κ₂ и ±κ₃. Кратность 4 при N = 3 невозможна:
     она влечёт d = 0. Это d теоремой исключается: Σdᵢ/i⁴ = 9/16 − 64/81 ≠ 0.
   - Тогда g может содержать компоненты p(y)e^{±κₖy}, deg p меньше кратности корня.
4. **Показатели Yⱼ.** Yⱼ — гладкое решение LⱼYⱼ = g с защемлением, то есть частное решение плюс однородная часть.
   - Нерезонансные компоненты (ξ ≠ ±κⱼ): Lⱼ(ξ) ≠ 0, частное решение p̃(y)e^{ξy}, deg p̃ = deg p.
   - Резонансные (ξ = ±κⱼ, возможно только при dⱼ = 0): частное решение p̃(y)e^{±κⱼy}, deg p̃ ≤ deg p + 2 — при любой кратности корня P.
   - Однородная часть: показатели ±κⱼ.

   Показатели Yⱼ и Yⱼ⁗ лежат в {корни P} ∪ {±κⱼ}; это множество не содержит 0 (P(0) ≠ 0, κⱼ ≠ 0).
5. **Противоречие.** Так как y^m e^{ξy} с различными (m, ξ) линейно независимы, из 4q/D = g + 2ΣⱼYⱼ⁗ следует 4q/D = 0 — противоречие с
   q ≠ 0. ∎

### ВБC-13. Коэффициенты, матрицы полушагов, независимость

**Утверждение.**

1. **Коэффициенты Y-полушага** по заданному U ∈ ℝ^{(nₓ−1)×N}: A = hₓUᵀU; B = −hₓUᵀLₓU;
   C^C = hₓUᵀD4ₓU = C_{L²} + (2/hₓ³)(u₁u₁ᵀ + u_{n−1}u_{n−1}ᵀ); F = q·hₓUᵀ𝟏.
   Система: 𝒦^C vec(V) = F ⊗ 𝟏, 𝒦^C = D[A ⊗ D4_y − 2B ⊗ L_y + C^C ⊗ I]. X-полушаг — симметрично.
2. **Матрица полушага.** 𝒦^C симметрична; **𝒦^C ≻ 0 ⇔ столбцы U независимы**.
   - 𝒦^C = 𝒦₀ + D(A ⊗ E₂), 𝒦₀ := D[A ⊗ L_y² − 2B ⊗ L_y + C^C ⊗ I] (C^C уже входит в 𝒦₀). Поправка D(A ⊗ E₂) имеет ранг 2N при A ≻ 0
     (У-C1).
   - Относительно SSSS-формы D[A ⊗ L² − 2B ⊗ L + C_{L²} ⊗ I] разность D[A ⊗ E₂ + (C^C − C_{L²}) ⊗ I] имеет ранг
     **≤ 2N + r_c(n_y − 3)**, r_c := rank(u₁u₁ᵀ + u_{n−1}u_{n−1}ᵀ) = dim span{u₁, u_{n−1}} ≤ 2 (u₁, u_{n−1} ∈ ℝᴺ — строки U в первом и
     последнем внутренних узлах). r_c = 1, когда эти строки зависимы и не обе нулевые (пример — u₁ = ±u_{n−1}, симметричный набор; другой —
     u₁ = 2u_{n−1}); при N = 1 r_c ≤ 1 (АП-5).
3. **Точная дискретная структура 𝒯_N.** При Uᵢ = sin²(iπl/nₓ), i ≤ N, и **2N < nₓ**:
   $$A=a\Bigl(\frac I8+\frac{\mathbf 1\mathbf 1^{\mathsf T}}4\Bigr),\quad B=\frac a8\operatorname{diag}(\mu_i),\quad C^C=\frac a8\operatorname{diag}(\mu_i^2),\quad F_i=\frac{qa}2,\quad \mu_i=\frac4{h_x^2}\sin^2\frac{i\pi}{n_x}.$$
4. **Дискретная независимость 𝒯_N:** U независим ⇔ **N ≤ ⌊nₓ/2⌋**.
5. **Дискретная независимость 𝒫_N:** достаточно nₓ ≥ 2N.

**Доказательство.**

1. Пп. 1–2 — тензорная структура Π_h^C (NS 4.2–4.3; R-18). 𝒦^C ≻ 0 ⇔ U независим — ЧВ4-5 по структуре (a_h^C ≻ 0 на V_h). Граница ранга:
   пространства столбцов слагаемых — ℝᴺ ⊗ span{e₁, e_{n−1}} и range(C^C − C_{L²}) ⊗ ℝ^{n_y−1}; их пересечение содержит
   range(C^C − C_{L²}) ⊗ span{e₁, e_{n−1}} размерности 2r_c; dim ≤ 2N + r_c(n_y − 1) − 2r_c.
2. П. 3: Uᵢ = (1 − cᵢ)/2, cᵢ(l) = cos(2iπl/n). Чётное n-периодическое продолжение совпадает с отражением, поэтому Ł и L действуют как

   (mod n), что выполнено при 2N < n. Для B: Σₗ₌₁^{n−1}cⱼ = −1. Отсюда формулы.
3. П. 4: {1, c₁…c_N} независимы на периоде при N ≤ ⌊n/2⌋. Векторы 1 − cₖ равны нулю при l = 0, поэтому комбинация, равная нулю в узлах

4. П. 5: ΣcᵢPᵢ — многочлен степени ≤ 2N + 2 с двойными нулями в 0, 1 и нулями в nₓ − 1 узлах; при nₓ ≥ 2N он тождественно равен нулю. ∎

### C.10.2. Что из ВБ-19 переносится и что нет

| Величина | Чем обеспечивается | Где используется |
