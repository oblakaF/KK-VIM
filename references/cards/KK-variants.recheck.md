## 1. Формула (95) L-005 (с. 4804, разд. 3.9 «Vaindiner's Method»)

Изображение: `scratch/review-t2b/recheck/p024.png` (увеличенный фрагмент, в git не входит).

### 1.1. Что напечатано (НАПЕЧАТАНО)

Пробная функция: w(x, y) = sin²(πx)Y₁₁(y) + X₁₂(x)sin²(πy) (с. 4804); X₁ = sin²(πx), Y₁ = sin²(πy).
Система (94): A₁₁Y₁₁⁽⁴⁾ + B₁₁Y₁₁⁽²⁾ + C₁₁Y₁₁ = D₁₁; A₁₂X₁₂⁽⁴⁾ + B₁₂X₁₂⁽²⁾ + C₁₂X₁₂ = D₁₂. Формула (95):

| Коэффициент | Определение, как напечатано | Напечатанное значение |
|---|---|---|
| A₁₁ | λ² ∫₀¹ X₁² dx | λ²·3/16 |
| B₁₁ | ∫₀¹ 2X₁⁽²⁾X₁ dx | −π²/2 |
| C₁₁ | (1/λ²) ∫₀¹ X₁⁽⁴⁾X₁ dx | π⁴/λ² |
| D₁₁ | Q₁ ∫₀¹ X₁ dx | Q₁·1/4 |
| A₁₂ | (1/λ²) ∫₀¹ Y₁² dy | (1/λ²)·3/16 |
| B₁₂ | ∫₀¹ 2Y₁⁽²⁾Y₁ dy | −π²/2 |
| C₁₂ | λ² ∫₀¹ Y₁⁽⁴⁾Y₁ dy | λ²π⁴/2 |
| D₁₂ | Q₂ ∫₀¹ Y₁ dy | Q₂·1/4 |

Определения согласуются с уравнением (18) (с. 4790): (1/λ²)∂⁴ₓ + 2∂²ₓ∂²ᵧ + λ²∂⁴ᵧ, — после проекции
Бубнова–Галёркина по второй переменной. Множитель **2 входит в определения B₁₁ и B₁₂**.

### 1.2. Независимый расчёт интегралов (ВЫВОД ПРОЕКТА, аналитически)

X = sin²(πx) = (1 − cos 2πx)/2; X″ = 2π² cos 2πx; X⁗ = −8π⁴ cos 2πx; X(0) = X(1) = X′(0) = X′(1) = 0.

| Интеграл | по [0, 1] | по [0, ½] |
|---|---|---|
| ∫ X² | 3/8 | 3/16 |
| ∫ X X″ | −π²/2 | −π²/4 |
| ∫ 2X″X | −π² | −π²/2 |
| ∫ (X′)² | π²/2 | π²/4 |
| ∫ X⁗X = ∫ (X″)² | 2π⁴ | π⁴ |
| ∫ X | 1/2 | 1/4 |

Совпадает со значениями, установленными независимо (3/8, −π²/2, π²/2, 2π⁴).

|---|---|---|---|

### 1.4. Ответы на вопросы дополнения

1. **Какие коэффициенты определены.** Коэффициенты двух ОДУ (94) метода Вайндинера: при Y₁₁⁽⁴⁾, Y₁₁⁽²⁾, Y₁₁
   и правая часть — с весом X₁ = sin²(πx); при X₁₂⁽⁴⁾, X₁₂⁽²⁾, X₁₂ и правая часть — с весом Y₁ = sin²(πy).
   B₁₁, B₁₂ по определению содержат множитель 2: B = ∫2X″X, а не ∫X X″.
2. **Откуда 3/16.** 3/16 = ½·3/8 = ∫₀^{½} sin⁴(πx)dx. Все четыре значения строки 11 и три значения строки 12
   (A₁₂, B₁₂, D₁₂) равны **половине** интегралов по [0, 1] при напечатанных определениях, то есть интегралам
   по [0, ½]. Происхождение множителя ½ (интеграл по половине отрезка с учётом симметрии, нормировка или иное)
   в статье **НЕ УКАЗАНО**.
3. **Чья ошибка.**
   - Совпадение −π²/2 с ∫X X″ — **различие определений, а не ошибка карточки**: напечатанное B₁₁ = ∫2X″X, поэтому
     соответствующий интеграл равен −π², и −π²/2 — его половина. Утверждение карточки «∫₀¹sin⁴ = 3/8,
     ∫₀¹2X₁″X₁ = −π² — напечатанные значения равны половине интегралов» для A₁₁ и B₁₁ **верно**. Рабочая
     гипотеза «авторы просто опустили множитель 2 в B₁₁» хуже согласуется с данными: тогда пришлось бы считать
     независимыми ошибками ещё A₁₁, C₁₁, D₁₁, а общий множитель ½ объясняет все четыре сразу.
   - Для строки 11 общий множитель ½ **не меняет ОДУ** (уравнение делится на константу) — утверждение карточки
     о строке 11 верно.
   - **Реальная несогласованность в публикации: C₁₂ = λ²π⁴/2.** По напечатанному определению λ²∫₀¹Y₁⁽⁴⁾Y₁dy =
     2λ²π⁴; при общем множителе ½, как у остальных коэффициентов строки 12, ожидалось бы λ²π⁴. Напечатанное
     значение меньше ещё в 2 раза. Если оно использовано в расчёте, второе уравнение (94) отличается от
     вытекающего из определений (относительный вес члена C₁₂X₁₂ занижен вдвое). Опечатка это или ошибка
     расчёта — **НЕ УСТАНОВЛЕНО**: численные результаты табл. 10–11 по одной формуле проверить нельзя.
   - **Ошибка интерпретации (неполнота) — в карточке и в рецензии.** Карточка (строка L-005 вар. 2, разд. 2 итогов
     «с множителем ½ [sic]», таблица исправлений E-6) обобщает: «значения для sin²(πx) равны половине интегралов»
     и «общий множитель ½ не меняет ОДУ». Для C₁₂ это неверно. Обобщение восходит к замечанию E-6 рецензии,
     которое перечисляло только значения строки 11 и аномалию C₁₂ не отметило — **неполнота рецензии**.
