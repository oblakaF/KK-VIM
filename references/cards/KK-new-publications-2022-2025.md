## 1. L-109 (2022, IJNLM) — «быстрый и надёжный» расчёт гибких пластин Кармана

### 1.1. Математическая модель
- Изотропная упругая пластина постоянной толщины, гипотезы Кирхгофа; геометрическая нелинейность — уравнения Кармана (1) относительно
  w и функции напряжений F [Н, с. 5]; D = Eh³/[12(1−μ²)], h — толщина [Н, с. 5]; безразмерная форма (15), (16): w̄ = w/h,
  q̄ = a²b²q/(Eh⁴), λ = a/b [Н, с. 6].
- Граничные условия: шарнир (2); шарнир на гибких нерастяжимых рёбрах (3); защемление (4); защемление на рёбрах (5); варианты (6)–(9), (13),
  (14) [Н, с. 5–6].
- Физической нелинейности, пористости, FGM, размерных эффектов нет [Н, по тексту]. Динамический член вводится только для метода
  установления (101) [Н, с. 23].

### 1.2. Метод решения
- Сравниваются: BGM (метод Бубнова–Галёркина) в высших приближениях (разд. 3); ABSM — метод Аграновского–Баглая–Смирнова, уточнение
  по невязке (разд. 4, 5); KVM — метод Канторовича–Власова первого и второго приближений (разд. 6); VIM — метод вариационных итераций
  (разд. 8); VIM + ABSM; FDM2 — метод установления с МКР второго порядка (разд. 10) [Н, с. 5, 7–23].
- **VIM — это КК-МВИ в смысле P81** по описанию:
  - «generalization of the KVM»; на каждом шаге функции одного направления заданы, другого — ищутся; первая итерация — KVM [Н, с. 14–15];
  - ссылки на Кириченко, Крысько (INDEX.md, разд. 4.2);
  - разд. 9 — пересказ Definition 1, Remark 1, Definition 2, Теоремы 1, Леммы, Теоремы 2, Remark 3, 4 P81 [Н, с. 22–23].
- **N:** «VIM 1 approx.» — N = 1, w = x̃(x)ỹ(y), F = X(x)Y(y) [Н, разд. 8.2, с. 15]. «VIM 2 approx.» — двучленное представление
  с начальными функциями sin(πx), sin(3πx) [Н, с. 11–12, разд. 8.5, с. 19–21].
- **Начальные функции.** Удовлетворяют граничным условиям [Н, с. 9, 17]:
  - (2): x̃ = sin(πx), X = sin(πx);
  - (3): x̃ = sin(πx), X = sin²(πx);
  - (4): x̃ = sin²(πx), X = sin²(πx);
  - (5): x̃ = sin²(πx), X = sin(πx);
  - (14) — sin²(πx).

  Утверждение о произвольных функциях, не удовлетворяющих ГУ, — только в выводах, без примера [Н, с. 30].
- **Координатные итерации.** Проекция Бубнова–Галёркина по x даёт нелинейную систему ОДУ по y (71)–(73); затем роли меняются
  [Н, с. 15]. Коэффициенты (73) записаны в «сильной» форме: ∫x̃⁽⁴⁾x̃, 2∫x̃⁽²⁾x̃, ∫x̃² с множителями λ [Н, с. 15]. Это согласуется с формой
  коэффициентов SOURCE_MAP/MATH_SPEC для линейного оператора [В].
- **Связь с Канторовичем–Власовым:** первая итерация VIM — KVM [Н, с. 15, 30]. Сходимость KVM — разд. 7, по структуре совпадает
  с теоремой P80 (вполне непрерывный оператор, условия 1–3, Лемма) [Н, с. 13–14]. Построчная сверка с P80 — [НП].

### 1.3. Численная реализация
- Нелинейные ОДУ — МКР второго порядка; система 2n нелинейных АУ решается **методом Ньютона**; разбиение [0, 1] на **n = 97** частей
  [Н, с. 10, 15, 27].
- **Внутренние узлы.** В (74) напечатан стандартный пятиточечный шаблон четвёртой производной (y_{i+2} − 4y_{i+1} + 6y_i − 4y_{i−1} + y_{i−2})/h⁴
  и трёхточечные шаблоны второй и первой производной [Н, с. 15].
  - [sic]: (74) использует коэффициенты с индексом 1 (A₁ … P₁), а (72), (73) — с индексом 3; «+ +G₁».
- **Граничные узлы.** Задание ГУ в разностной форме (законтурные узлы) — [НУ].
- **Остановка VIM:** «until the solutions at two successive iterations coincide within the accepted computational accuracy» [Н, с. 15]; значение
  не указано. В разд. 8.3 указано ε = |w_{i+1} − w_i|/|w_i| < 10⁻³ «at each loading step» [Н, с. 18].
- **Нагрузки:** равномерная; локальная в центре; локальная в углу (Tables 1–15, Figs. 13–30) [Н, с. 15–29]. Шаговое нагружение и экстраполяция
  начального приближения — [Н, с. 18].
- **FDM-эталоны:**
  - «FDMs» — последовательное решение двух уравнений (16) с линеаризацией и методом Гаусса;
  - «FDM» — совместное решение методом Ньютона [Н, с. 26].

### 1.4. Точность и производительность
- **Аналитические решения:** нет; задача нелинейная. Сравнение с Yamaki [94] и Wang [96]: различие «does not exceed 3 %» [Н, с. 18, Figs. 22–23].
- **МКЭ:** ANSYS, SHELL181 — сравнение только на графиках q(w) (Figs. 22–23) и только для ГУ (13), (14) [Н, с. 18–19]. Параметры сетки МКЭ —
  [НУ]; время МКЭ не приводится [НУ].
- **МКР:** Tables 13–15 [Н, с. 26–28]. Эталон — BGM N = 5, «treated as the standard» [Н, с. 29].
- **Время** — «a computer with a clock frequency of 2.5 GHz» [Н, с. 29]. Примеры [Н, Table 13, с. 26]: q̄ = 30, ГУ (2):
  - VIM 1 approx. (n = 25): 0,54 с;
  - VIM 1 approx. (n = 97): 8,26 с;
  - FDM 17·17·2 = 578: 50,3 с;
  - FDM 49·49·2 = 4082: 4050 с;
  - BGM N = 5: 92,8 с.
- **Память:** не приводится [НУ].
- **Сопоставимость измерений не установлена** [В]:
  1. Не указаны язык, решатель линейных систем (плотный или разреженный), число потоков, допуски Ньютона, число итераций Ньютона по методам.
     Время FDM 50 с для 578 неизвестных указывает скорее на свойство реализации (например, плотные матрицы), чем на свойство метода.
  2. **Одинаковые времена для разных задач.** FDM 25·25·2 — 235 с, 33·33·2 — 750 с, 49·49·2 — 4050 с; BGM N = 5 — 92,8 с; N = 3 — 2,22 с;
     N = 1 — 0,005 с. Эти числа совпадают в Tables 13, 14 и 15 (равномерная, локальная в центре, локальная в углу)
     [Н, с. 26–28]. Для нелинейной задачи с Ньютоном время обычно зависит от нагрузки. Совпадения указывают, что время, вероятно, измерялось
     один раз на размер задачи или переносилось между таблицами. Это не утверждается — НЕ УСТАНОВЛЕНО, — но независимые измерения на каждую
     задачу не продемонстрированы.
  3. **Эталон BGM N = 5 не доказан сходящимся.** В Table 13 ошибка FDM относительно BGM5 не убывает со сгущением сетки: 0,0105 % (17²),
     0,2847 % (25²), 0,3795 % (33²), 0,4112 % (49²) [Н]. Значения FDM 0,9512 → 0,9521 → 0,9524 сходятся примерно к 0,9525–0,953, а BGM5 = 0,9485.
     Значит, эталон отличается от предела МКР примерно на 0,4 %, а «ошибки» VIM в сотые доли процента относительно BGM5 не являются ошибками
     относительно точного решения [В].
  4. В Table 14 (локальная нагрузка) FDM ещё не сошёлся: 1,0837 → 0,9008 при сгущении, «ошибка» 26 % → 5 % [Н]. Сравнение времени
     при недостигнутой сходимости одного из методов не отвечает условию «равная точность».
  5. Арифметика: «49·49·2 = 4082» [sic, Tables 13–15]. Верно 4802, как и напечатано в L-113, с. 10 [В].

  **Вывод:** утверждение авторов об ускорении («fast», «most efficient in terms of machine time» [Н, с. 1, 29]) — **заявление, не доказанное
  сопоставимыми измерениями** [В].

## 2. L-110 (2023, CAMWA) — количественное сравнение reduced-order методов для размерно-зависимых пластин

### 2.1. Математическая модель
- Кирхгоф; **модифицированная моментная теория упругости** (MCST) (1.2)–(1.6); переменные параметры упругости Биргера в общей постановке
  (1.4)–(1.13) [Н, с. 63–65].
- Численные примеры — при E, ν = const: модифицированные уравнения Кармана (1.14), (1.20) с D = Eh³/[12(1−ν²)] + Ehγ²/[2(1+ν)];
  γ — размерный параметр [Н, с. 65–66].
- Граничные условия (1.15)–(1.18) [Н, с. 65]; безразмерная форма (1.19): w̄ = w/h, q̄ = a²b²q/(Eh⁴) [Н, с. 65].
- Пористости и FGM нет; физическая нелинейность — только в общей постановке, в расчётах [НУ] [Н, с. 65].

### 2.2. Метод решения
- BGM (разд. 2), ABSM (разд. 3), BGM + ABSM (разд. 4), KVM 1 и 2 приближений ± ABSM (разд. 5), VIM ± ABSM (разд. 6) [Н, с. 66–80].
- **VIM:** «generalization of the KVM … At the first step, the functions are determined by solving the equations by the KVM» [Н, с. 74].
  Схема P81 для N = 1, (6.1)–(6.8) [Н, с. 74–75].
- **N:** VIM — только первое приближение (N = 1) [Н, с. 75]; KVM 2 — с sin(πx), sin(3πx) [Н, с. 72].
- **Начальные функции** удовлетворяют ГУ [Н, с. 70, 74]:
  - (1.15): x̃ = X = sin(πx);
  - (1.16): x̃ = sin(πx), X = sin²(πx);
  - (1.17): x̃ = X = sin²(πx);
  - (1.18): x̃ = sin²(πx), X = sin(πx).

### 2.3. Численная реализация

- ГУ «written in terms of finite differences of the second order accuracy» — конкретный вид [НУ] [Н, с. 70, 75].
- Сетка: «Sufficient partition of the interval [0;1] turned out to be 25 segments» [Н, с. 70, 76, 79].
- Остановка: «until the solutions at two successive iterations coincide within the accepted computational accuracy»; значение [НУ] [Н, с. 75–76].
- Нагрузки: равномерная, локальные в центре и в четверти (Table 2.1) [Н, с. 67].

### 2.4. Точность и производительность
- **МКР, МКЭ, аналитика:** сравнений с МКР и МКЭ **нет**; аналитических решений нет [В, по всему тексту].
- **Tables 7.1, 7.2** [Н, с. 82, сверено по изображению]: w(0,5; 0,5) и d — отличие от **VIM 1 approx. + ABSM**, «the decision which was

    Не объяснено.
- «Proof of convergence of VIM was presented in [24]» [Н, с. 80]; аннотация говорит о «a number of theorems» [Н, с. 61]. В тексте L-110
  теорем нет (поиск по тексту «Theorem», «Lemma» — пусто) [В].

## 3. L-111 (2023, Изв. ТПУ) — пористые геометрически нелинейные металлические нанопластины с влажностью

### 3.1. Математическая модель
- Кирхгоф; Карман; MCST Янга; пористый металл с E(z), ν(z) и коэффициентом влажностного расширения β(z) — три модели пористости ПМ 1–3 (1)–(3);
  влажностный момент M_C [Н, с. 38–39].
- Уравнения (8) в смешанной форме (w, F) [Н, с. 39]; ГУ (9)–(12) [Н, с. 39]; безразмерная форма (13): q̄ = qa²b²/(Eh⁴) [Н, с. 40].
- Есть пористость, геометрическая нелинейность, влажность, размерный эффект; FGM в смысле керамика–металл нет [Н].

## 6. Ответы на вопросы задания

1. **Какие статьи полезны для программирования KK-VIM?** Непосредственно для R2 — **ни одна** не является источником: все примеры нелинейные
   или неклассические [В]. Как согласование для NUMERICAL_SPEC.md (Q-010, Q-009) полезны L-109 и L-110:
   - напечатанный стандартный пятиточечный шаблон четвёртой производной для внутренних узлов (L-109 (74), с. 15; L-110 (5.7), (6.6), с. 70, 75);
     частично закрывает пробел, отмеченный в KK-variants.md, разд. 4;
   - Ньютон для нелинейных АУ внутри полушага;
   - относительный критерий по прогибу ε < 10⁻³ (L-109, с. 18).

   L-113, Table 4 — качественное согласование: при допустимой sin(πx) сходимость за 2–3 итерации. Задание граничных условий в разностной
   форме по-прежнему **не опубликовано** ни в одной из пяти работ [В]. Проектные выборы делаются в NUMERICAL_SPEC.md самостоятельно.
2. **Какие статьи полезны для исследования скорости КК-МВИ относительно МКР и МКЭ?**
   - Систематические времена есть в **L-109** (Tables 13–15) и **L-113** (Table 3, с. 10). Их данные **непригодны как доказательство
     ускорения** (разд. 1.4, 4a.4):

   - **L-111** повторяет данные L-109. **L-112** даёт одну пару чисел без условий. **L-110** времени не содержит.

     SSSS — Навье), фиксированная достигнутая точность, учёт памяти, собственный расчёт МКЭ. Такого этапа в ROADMAP.md нет; включение —
     решение владельца [В].
