## 5. Первый полушаг: аналитические коэффициенты и граничный эффект (L-005)

**НАПЕЧАТАНО.**
- Первый полушаг [4795, (53)–(57)]: w = X₀(x)Y₁(y), X₀ = sin(πx) задана для шарнира (15); Галёркин по x
  с весом X₀ даёт (56) A₁Y₁⁗ + B₁Y₁″ + C₁Y₁ = D₁; коэффициенты — интегралы от X₀ и её производных,
  вычисленные в замкнутом виде (57).
- Недопустимая функция: в L-005 sin(πx) используется **только для шарнира**, где она допустима; для
  защемления — sin²(πx) [4795]. Пример sin(πx) при защемлении в L-005 **отсутствует**.
- Граничный эффект [4796]: дословно — «The increase in the number of partitions is directly related to the
  edge effect caused by boundary condition (16)». Речь о МКР-решении ОДУ по y с условием защемления; разностный
  шаблон и способ задания условия ∂w/∂n = 0 НЕ УКАЗАНЫ.
- Непрерывная и разностная форма [4795]: «Equation (56) can be solved numerically, for example, by the finite
  difference method … O(h²). A very important point plays a number of partitions of variable y» — аналитическое
  решение (58)–(60) и численное (табл. 3) приведены рядом.

**ВЫВОД ПРОЕКТА.**
- Для заданной гладкой X₀ коэффициенты первого полушага — числа, определяемые интегралами (57). При их
  аналитическом вычислении никакая сетка по x в первом полушаге не участвует: шаблоны и законтурные узлы
  по x на коэффициенты A₁…D₁ не влияют.
- Для sin(πx) на [0, 1]: sin(πx) = (sin πx)″ = 0 на концах, поэтому ∫X₀⁗X₀ = ∫(X₀″)² без граничных членов
  (интегрирование по частям); коэффициенты определены однозначно и при защемлении, хотя X₀′(0) ≠ 0.
- Следствие для Q-017. Механизм гипотезы (законтурный узел f₋₁ = f₁, искусственная граничная кривизна) может
  действовать, **только если** sin(πx) и её производные в коэффициентах первого полушага берутся по сеточным
  значениям с наложенным условием защемления. При аналитическом вычислении, как в L-005 (для шарнира), этот
  механизм в первом полушаге не возникает. Если бы P81/P82 вычисляли коэффициенты так же, как L-005, гипотеза
  о граничном эффекте первого полушага потеряла бы основание. Однако **L-005 описывает другой случай** (шарнир,
  допустимая функция, 2021 г.) и численной реализации P81/P82 не описывает. Поэтому гипотеза Q-017
  **не опровергнута и не подтверждена**: способ вычисления коэффициентов в P81/P82 — НЕ УСТАНОВЛЕНО.
- Отдельно (связь с наблюдением N-6 R1-T2a): после первого полушага w = X₀(x)·Y₁(y) при любом способе
  вычисления коэффициентов, поэтому профиль по x пропорционален sin(πx). Способ вычисления коэффициентов
  влияет на амплитуду и форму Y₁, но не на профиль по x. Объяснить непропорциональность строки Step 1 табл. 1
  P81 граничным шаблоном первого полушага нельзя, если Step 1 — первый полушаг, а профиль идёт вдоль x
  (это согласуется с проверяемым условием Q-017).

**Гипотеза проекта (не установлено):** что P81/P82 хранили sin(πx) на сетке «60 × 60» и брали её производные
разностно. Текст P81 («differencing procedure on a 60 × 60 partition») этого не утверждает.

**Знак ошибки и вариационный характер (ВЫВОД ПРОЕКТА).** Для точного решения полушагов (Галёркин по
подпространству допустимых функций при симметричном положительно определённом операторе) приближение
удовлетворяет a(w_k, w_k) = (q, w_k) и a(w_k, w_k) ≤ a(w₀, w₀). При равномерной нагрузке отсюда следует
∫ w_k dΩ ≤ ∫ w₀ dΩ — занижение **среднего** (интегрального) прогиба. О прогибе **в точке** (центре) это
ничего не говорит: точечное значение может быть и больше точного. Кроме того, неравенство теряет силу при
недопустимом старте до первого допустимого приближения, при неточном (разностном) решении одномерных
задач и при неизвестном числе выполненных шагов. Поэтому +2,7 % в центре **не противоречит** вариационному
характеру метода и **не доказывает** ни ошибки реализации, ни граничного эффекта. Знак отклонения по
опубликованным данным не объясняется.

Переносить 2,7 % (CC, иная нормировка, неясная сетка) на линейную SSSS-постановку R2 **нельзя**: для
шарнира в тех же таблицах отклонение 0,099 %.

## 10. Открытые вопросы и рекомендации для R2 / R5 / R12

**Неопределённости в обзоре сохранены корректно:** смысл Step 1 и направление профиля P81; нормировка P82;
законтурные узлы; численная реализация первого полушага; граничные шаблоны CCCC — везде НЕ УСТАНОВЛЕНО, без
подмены поздними работами. Требуется лишь поправка E-2 к абзацу о Q-017 (противоречие 0,6 % / 2,7 % и ссылка [40]).

**Q-017 не блокирует линейный R2 (SSSS) — обоснование (ВЫВОД ПРОЕКТА).**
- Условия шарнира на краях x = 0, 1 (L-107, (110), (111)): w = 0 и M_x = −D(w_xx + ν w_yy) = 0.
- Для w = sin(πx)·v(y): w(0, y) = w(1, y) = 0; w_xx = −π² sin(πx) v(y) = 0 и w_yy = sin(πx) v″(y) = 0 при x = 0, 1.
  Следовательно, M_x = 0 при **любом** ν и любой v. Условия по y = 0, 1 обеспечивает решение ОДУ первого полушага
  с шарнирными условиями.
- Значит, для SSSS начальная функция sin(πx) удовлетворяет и главному (w = 0), и естественному (M = 0) условию;
  произведение u⁰v* лежит в D(T) при v*, удовлетворяющей условиям по y и достаточно гладкой, и условие P81
  отождествления шага с проекцией выполнено уже на первом шаге.
- Для разностной реализации: стандартное отражение для шарнира f₋₁ = −f₁ (из w = w″ = 0) точно согласуется
  с нечётностью sin(πx) относительно края, так что искусственной граничной кривизны не возникает.
- Конфликт недопустимой начальной функции (sin′(0) ≠ 0 при ∂w/∂n = 0) относится **только к CCCC** (R5, ранняя
  проверка N = 1 CCCC, воспроизведение P81/P82).

**Рекомендации.**
- R2 (SSSS): Q-017 не блокирует; использовать sin(πx) как допустимую начальную функцию; способ вычисления
  коэффициентов первого полушага (аналитически или квадратурой) зафиксировать в NUMERICAL_SPEC.md как
  инженерный выбор (Q-011).
- R5 / ранняя CCCC: проверяемое разделение процедур А/Б (раздел 6) и аналитический либо сеточный учёт
  sin(πx) — предмет NUMERICAL_SPEC.md и Q-017; данные L-005 о росте числа разбиений при CC (15 → 55) учитывать
  при выборе сетки, не перенося их на P81/P82.
- R11/R12: раздел 8.
