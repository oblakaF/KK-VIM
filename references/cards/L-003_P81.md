**Схема МВИ** (с. 366–367):
- ур. (1): `Tω(x, y) = g(x, y); x, y ∈ Ω(x, y)`; T — оператор на D(T) в L₂(Ω). В пояснении к (1)
  напечатано: «**q(x, y)** is a prescribed function of two variables x and y» [sic: в (1) — g(x, y)];
- ур. (2): `ω_N(x, y) = Σ_{i=1}^{N} u_i(x) v_i(y)`, при Ω(x, y) = X × Y;
- ур. (3): `∫_X (Tω_N − g) u_i(x) dx = 0` (i = 1…N); `∫_Y (Tω_N − g) v_i(y) dy = 0` (i = 1…N);
- порядок (с. 367, дословно): «A certain system of N functions of one of the variables is given, say
  u₁⁰(x), u₂⁰(x), …, u_N⁰(x), a system of N functions v₁¹(y), v₂¹(y), …, v_N¹(y) is determined from the
  first N equations of the system (3), these functions are substituted into the remaining N equations of
  the system (3), a new set of functions of the variable x is determined, u₁²(x), u₂²(x), …, u_N²(x), then
  this set is used to obtain new functions of y, v₁³(y), v₂³(y), …, v_N³(y), and so on.»
- **Definition 1** (с. 367): «The process of computing one system of functions from another given system
  is called one VIM step. The number of steps executed in order to determine a particular set of functions
  corresponds to the superscript attached to the functions of the given set.»
- обрыв на k-м шаге (с. 367): «[which, for example, corresponds to acquisition of the set of functions
  v₁ᵏ(y), v₂ᵏ(y), …, v_Nᵏ(y)]», `ω_Nᵏ = Σ_{i=1}^{N} u_i^{k−1}(x) v_iᵏ(y)` (без номера);
- **Definition 2** (с. 367): N-е приближение — N членов в (2);
- первое приближение (с. 367): `ω₁(x, y) = u(x) v(y)`, ур. (4):
  `∫_X (Tu(x)·v(y) − g) u(x) dx = 0; ∫_Y (Tu(x) v(y) − g) v(y) dy = 0`.

**Remark 4** (с. 369, дословно): «For implementation of the VIM it is not necessary to construct an initial
approximation that satisfies, for example, the boundary conditions of the stated problem. Thus, let us
suppose that operator T determines a certain boundary-value problem. As the initial approximation we take
any function from the domain of definition of the differential operator of the given problem. Then in the
first step we obtain a system of functions satisfying the boundary conditions with respect to one of the
variables, and in the second step the same is accomplished for both variables.»

Статус смысла Remark 4 — **НЕОДНОЗНАЧНО** (N-9). Первое предложение допускает начальное приближение,
не удовлетворяющее граничным условиям. Третье требует брать функцию «from the domain of definition of the
differential operator of the given problem». В Remark 1 (с. 367) T — «differential operator defined on the
set D(T)». Возможны два прочтения:
- «domain of definition» = D(T) краевой задачи (с граничными условиями) — тогда третье предложение
  противоречит первому;
- «domain of definition» = область определения дифференциального выражения без граничных условий —
  тогда противоречия нет.

Текст не уточняет, какое прочтение имеется в виду. Наблюдение (без вывода о смысле): в эксперименте
(с. 370) авторы «in accordance with Remark 4» берут sin(Πx) — функцию, которая, по их же словам,
не удовлетворяет условиям закрепления; это применение согласуется со вторым прочтением, но Remark 4
этим не уточняется. Трактовка D(T) — раздел Б.4.

### Б.4. Условие D(T) в P81, условие ∈ M₁¹ в L-104, пространства H_T и W̊₂² (N-3, N-5)

Разделено: (А) что напечатано; (С) собственное пояснение проекта — не утверждение авторов, требует
проверки Reviewer и в спецификацию не входит.

**1. Условие D(T) в P81 (с. 367).**
- (А) T определён на D(T) в L₂(Ω) (с. 366, Remark 1). Теорема 1 предполагает D(T) ⊂ H_T.
- (А) M₁¹ задан как подмножество H_T с u⁰(x) ∈ H_T(x). Условие (6) записано в скалярном произведении
  [·,·]_{H_T}.
- (А) Совпадение (6) с первым уравнением системы (4) утверждается при условии **u⁰(x)v*(y) ∈ D(T)**.
  Условие наложено на элемент u⁰v*, построенный из заданной u⁰ и найденной v*.
- (А) Следующая фраза (с. 368, «Thus, … is a projection») условия не повторяет.
- (А) Что происходит, если u⁰v* ∉ D(T), — как тогда понимается первое уравнение (4) и является ли его
  решение проекцией — в P81 **не сказано**.
- (С) Пояснение, почему условие нужно. Для элементов D(T) энергетическое произведение совпадает
  с (Tu, v)_{L₂} (стандартное свойство энергетического пространства). Поэтому при u⁰v* ∈ D(T) условие (6)
  можно переписать через T, то есть в форме первого уравнения (4). Вне D(T) такое переписывание
  не обосновано.
- (С) Для эксперимента P81 (с. 370): sin πx имеет ненулевую производную при x = 0 и x = 1. При
  защемлении (`ω|_S = ∂ω/∂σ|_S = 0`) произведение sin πx · v*(y) не удовлетворяет условию ∂ω/∂σ = 0 на
  сторонах x = 0; 1. Если D(T) включает граничные условия, то u⁰v* ∉ D(T), и первый шаг эксперимента
  лежит вне условия, при котором P81 отождествляет шаг с проекцией. Если H_T(x) понимать как W̊₂²(0, 1),
  то и u⁰ ∉ H_T(x), то есть M₁¹ ⊄ H_T. Авторы этого не обсуждают — **НЕ УСТАНОВЛЕНО**.

**2. Условие «∈ M₁¹» в L-104 (PDF-с. 11).**
- (А) L-104 заменяет условие P81 «∈ D(T)» на «∈ M₁¹», ссылается на «system (97)» [sic: (97) — неравенство
  Теоремы 12; система — (96)] и утверждает проекционный характер первого шага без оговорки.
- (С) Поскольку u⁰v* ∈ M₁¹ по построению, условие L-104 ничего не ограничивает. Это отличие формулировки,
